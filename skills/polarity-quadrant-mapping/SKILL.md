# 极性四象限镜像反推：用"我对他的看法"反推"我在哪"

## R — 原文 (Reading)

> "对方离中心点的距离与你是完全一样的。所以，如果你极端正向独立，你的伴侣也会显得极端负向依赖。"

> — 克里斯多福·孟，第六章 一直在你身边

> "你对伴侣的看法，是严格地由你的位置决定的。……'我把伴侣看成是爱批评、没有耐心的；因此，我肯定在正向依赖型的象限，感到紧张而尴尬。'"

> — 克里斯多福·孟，第六章 一直在你身边

> "此后，关键不在于设法改变你是如何看待对方的，而是注意你正在体验着什么。"

> — 克里斯多福·孟，第六章 一直在你身边

## I — 方法论骨架 (Interpretation)

人极擅长回答"我的伴侣是什么样的人"，极不擅长回答"我在体验什么"。这个 skill 把前者当探针，去够后者。

**模型。** 两条轴交叉出四个象限：**需求轴**（独立 ↔ 依赖）说明你要不要对方、**情绪轴**（正向 ↔ 负向）说明你怎么处理不适感。四象限：正向依赖（围着对方转、讨好、道歉、紧张尴尬）／正向独立（显得漠不关心、否认与解离感觉）／负向依赖（陷在情绪故事里、抱怨、觉得被忽视）／负向独立（批评、评判、指责、吹毛求疵）。中心点不是"平衡的好位置"，作者把它等同于超越灵魂的桥梁、量子场、无门之门——移向中心的唯一方法被他明确指向过程。

**三条运作律。** ①**镜像律**：你占一个象限，伴侣就占对角象限；②**等距律**：两人离中心的距离永远相同；③**同步律**：你靠近中心，对方也跟着靠近；你转移，对方也转移。

**核心操作（本 skill 的全部价值所在）。** 四句填空：我把伴侣看成是___ → 因此我肯定在___象限 → 因此我正在体验着___ → 我这么看待伴侣，唯一的原因是，我正在体验着___。

**三道防误用。** ①填空的最后一格必须落在**体验**上（"我正在体验着胸口发紧"），若又落回对伴侣的描述，反推失败；②**不要修正你对伴侣的看法**——修正看法等于把探针扔掉；③**为了让他消气而调整位置不算靠近中心**，那只是模仿移动的动作，对方会无意识地读出你的需求和恐惧并反映出来。

**判据。** 不是"我是什么性格"，而是"冲突发生时我往哪个象限掉"。象限会动：作者明说几乎没有人在所有时候都只处于一个极性中，你有时会移到其他象限，但往往有一个象限你很少在那儿。

**一条诚实的保留**：作者的对角镜像律与他给的四个例句并不全部吻合（"伴侣粗心大意、丢三落四"被对应到"我的负向独立面"，而非对角的负向依赖）。因此**反推以四句模板为准，不要用对角规则硬推**。

## A1 — 书中的应用 (Past Application)

### 案例 1：极性四象限的两则对话示例（第六章，表 6.3 场景）
- **问题**：模型太抽象，读者无法代入。
- **方法**：两则日常场景对照演示镜像——① 你是正向依赖型，围着正在处理家庭财务的伴侣转悠、问长问短、聊孩子学校的事；伴侣是负向独立型，从叹气不耐烦到"你打扰了我的工作"。② 你是负向独立型，受够了伴侣招待客人时滔滔不绝讲无关紧要的话题；伴侣是正向依赖型，一再道歉、像受伤的动物、甜言蜜语哄你——"但伴侣的语气进一步激怒了你"。
- **结论**：规律不是"他是什么样的人"，而是**对方离中心点的距离与你完全一样**。你转移位置，伴侣也转移；你靠近中心，对方也跟着靠近。
- **结果**：由此给出四句可套用的自检句式（"我把伴侣看成是爱批评、没有耐心的；因此，我肯定在正向依赖型的象限……"），把抽象模型变成了可填空的对话脚本。

### 案例 2：独立型的崩溃——直到对方真的离开（第六章，表 6.1）
- **问题**：独立型的一方"表现得漠不关心、无动于衷，避免表达需求或关爱"，看起来确实不那么需要对方，于是"我不需要他"这个自我叙事显得成立。
- **方法**：不看当下的姿态，看**序列**——直到依赖型的伴侣确定自己受够了、离开了这段关系，独立型的一方才"突然崩溃，陷入无可救药的依赖"。
- **结论**：独立不是需求的缺席，是需求的掩饰。这是本 skill 最常用的一记戳破：当用户在正向独立象限里觉得自己"很成熟、不需要人"时，用这条序列检验。
- **结果**：作者补了一句更狠的——如果离开的爱人回来了，独立和依赖的角色往往也跟着回来，只是程度比以前轻些。所以"离开—崩溃—回来"这个循环本身就是检验独立叙事的天然实验。

### 案例 3：马克·吐温的父亲（第三章，镜像效应的跨域使用）
- **问题**：读者问"我坚持让伴侣停止唠叨，会不会是我促成了他的成长？"作者答：我从未见过任何证据，能证明我与妻子或孩子的情绪成长有任何关系。
- **方法**：给出替代解释——**镜像效应**：是你在情绪成熟上迈了一步，才让你以更成熟的眼光看待伴侣。"你在伴侣身上见证的，实际上可能是你自身的情绪成年。"引马克·吐温收尾：十四岁时受不了父亲的愚蠢，二十一岁时惊讶地发现"七年的时间他竟然变聪明了这么多"。
- **结论**：你对伴侣的看法变化，其时点与**你的评判**更相关，与伴侣的实际成长关系不大。作者给出的可观察规律是"当你在关系中迈一步时，伴侣也会迈一步"，时差可能两分钟、两天、两周，有时两个月。
- **结果**：这条案例证明镜像反推不只是第六章的局部技巧——它在本册第三章已经被用来解释"他好像变好了"这类日常困惑，是本 skill 唯一的跨章应用证据。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. 能详细描述伴侣的行为、性格、态度，但被问"你现在什么感觉"时答不上来。
2. 抱怨伴侣"太黏/太冷/太挑剔/太不在乎"，而这个描述在过去一年里反复出现、内容稳定。
3. 觉得两人"性格刚好相反"，且这种相反在冲突时会自动加剧（我越追他越退，我越退他越追）。
4. 冲突后复盘时，能列出对方的三条错，却说不出自己当时身体是什么感觉。
5. 已经知道"不该怪他"，但不知道除了怪他之外还能做什么——需要一个能落地的自我定位动作。
6. 想知道自己这次的"独立"是真的不需要，还是在掩饰害怕被拒绝。

### 语言信号（用户的话里出现这些就应激活）

- "我说不清自己什么感觉，但我很清楚他是什么人"
- "他太黏人了，我喘不过气"／"他一点都不需要我"
- "他老是挑我毛病"／"他动不动就生气"
- "我们俩性格刚好相反"／"我越急他越淡定"
- "我一吵架就变成那个指责他的人"
- "他总是那么疏远，根本不顾及我的感受"
- 英文：*he's so needy* / *he's so distant* / *he's always criticizing me* / *I don't know how I feel but I know exactly what he's like* / *we're complete opposites* / *I become the nagging one during fights*

### 与相邻 skill 的区分（★防撞车关键）

- **与 `shadow-figure-integration`（第 1 册）——同源，必须划界 ★★★**
  两者是同一机制的两种表述，但**输入口径和产出都不同**：

  | | `shadow-figure-integration` | 本 skill |
  |---|---|---|
  | 输入 | 对某个**具体特质**的强烈情绪反应（反感、鄙视、嫉妒、羡慕） | 对伴侣**整体位置**的判断（他太依赖 / 他太冷漠） |
  | 产出 | 认出并整合被自己否认的部分 | 在四象限里定位自己，并读出这意味着什么 |
  | 尺度 | 强度高、失控、反复 | 位置判断，可以平静陈述 |

  **分辨句（具体到用户原话）**：
  - "我就是受不了他那种虚伪"／"他老批评我，每句话都戳得特别疼"／"一看到他就来气" → **shadow-figure-integration**
  - "他太黏人了，我需要空间"／"他一点都不需要我"／"我们俩刚好相反" → **本 skill**

  **以下情况请改用 `shadow-figure-integration`（路由清单，宁可收窄触发面也不要抢调用）**：
  1. 用户说的是一个**特质词**（自私、虚伪、懒惰、冷漠、爱出风头、不上进），而不是一种关系位置；
  2. 用户描述的是**强烈到失控的反感**（恨、恶心、看到就烦、反复在心里跟他辩论、幻想反驳他）；
  3. 用户说的是"他老批评我／他看不起我"——这是镜子法场景，归 shadow；
  4. 用户要的是"我怎么才能不这么讨厌他"——目标是整合阴影，不是定位象限；
  5. 反感的对象**不是伴侣**（同事、家人、朋友、公众人物）——本 skill 只处理亲密关系中的位置反推。

  **唯一的合成点**：若反推出的象限位置引发强烈自我厌恶（"我居然是依赖型，我最讨厌依赖的人"）→ 本 skill 停止，转 `shadow-figure-integration` 整合"依赖"这个被否认的部分。

- **与 `family-loyalty-attachment`（第 1 册）**：那个处理**动机层**——依附情结是"为换取不被离弃而压抑真实自我"，问的是"我为什么不敢说"。本 skill 处理**位置层**——此刻我在坐标的哪一端，问的是"我落在哪"。分辨句："我不敢说真实想法，我怕他不要我" → 那个；"他太黏了我喘不过气"／"我一吵架就掉进指责" → 本 skill。**本 skill 的依赖象限描述的是冲突当下的行为位置，不是童年形成的依附模式，不得用它给用户贴"你是焦虑型依恋"的标签。**

- **与 `two-boats-differentiation`（第 2 册）**：那个处理**结构性的自我区分**——粘连与两条船，判据是"压抑"不是"距离"，问的是"我该不该为了这段关系放弃自己的船"。本 skill 处理**冲突当下的极性定位**，问的是"我此刻在哪一端，这告诉我我正在体验什么"。分辨句："我们是不是太黏了／我该不该保留自己的事业和朋友" → 那个；"他太依赖了／我一冲突就变成批评他的人" → 本 skill。两者都涉及独立与依赖，但时间尺度不同（长期结构 vs 当下切片），且本 skill 明确**不作"我该留还是该走"的判断**。

- **与 `process-walk`（第 2 册）**：本 skill 是它的**前置定位器**。本 skill 的终点（"注意我正在体验着什么"）就是走过程的入口。分辨句：用户说"帮我处理这个感觉" → 那个；用户说"我说不清自己的感觉，但我很清楚他是什么人" → 本 skill。

- **与 `power-struggle-old-wound`（第 1 册）**：那个处理"为明显不值得的小事爆发剧烈冲突、强度不成比例"，找的是**旧痛**。本 skill 不找原因，只做位置反推。分辨句："我知道反应过度了但还是受不了" → 那个；"他太……了我说不清自己的感觉" → 本 skill。

## E — 可执行步骤 (Execution)

> **第 0 步：安全拦截（不可跳过，先于一切反推）**
> 命中以下任一条，**立即停止本 skill 的全部向内反推**，转向安全评估与资源连接：
> 1. 关系中存在身体暴力、威胁、破坏物品或阻挡去路；2. 存在监控、社交隔离、经济控制、限制人身自由；3. 存在针对儿童、老人或其他无议价能力第三方的伤害（含体罚分歧）；4. 存在成瘾、长期欺骗、财务隐瞒；5. 用户正在用"这是我设计的功课""他在帮我成长""这是我的梦"来解释**正在发生的伤害**；6. 用户出现闪回、解离、惊恐发作、自杀意念，或因使用本方法中断了正在进行的专业治疗；7. 用户报告"我移到中心之后，我更该留下了"。
> **完成标准**：七条逐条过完，得到明确的是/否。**若任一命中，不再执行以下步骤。**
> **本 skill 的特有拦截**：若用户正试图用象限解释对方的虐待行为（"他打我是因为他离中心太远"），或想用象限回答"我该留还是该走"——**立即停止**，本 skill 是描述工具，不是决策工具，也不是责任分配工具。

### 第 1 步：锁定一个冲突切片（不是整体评价）
- 问：**"最近一次你明确觉得'他就是这样'的**具体时刻**是哪一次？那一天他说了/做了什么？"**
- 完成标准：用户给出一个含**时间 + 具体事件**的切片（"周三晚上我跟他提报税的事，他嗯了一声就继续看手机"），而不是一句人格总结。
- **判停条件**：若用户三轮之后仍只能给出整体评价（"他就是个冷漠的人"），拿不出任何切片 → **这不是位置判断，是特质性反感。停止本 skill，转 `shadow-figure-integration`。**

### 第 2 步：说出探针句——"我把伴侣看成是___"
- 请用户就第 1 步那个切片，完成一句：**"在那一刻，我把伴侣看成是______。"**
- 规则：填**位置或态度描述**（"对我毫不在意的人""随时会挑我错的人""离不开我的人"），不要填特质标签（"自私的人"）。
- 完成标准：得到一句具体的、就事论事的描述句。
- **判停条件**：若填出来的是特质标签 + 强烈情绪（"虚伪的人，我想起来就恶心"）→ **转 `shadow-figure-integration`。**

### 第 3 步：反推象限
- 用四句模板对照定位（**以模板为准，不要用对角规则硬推**）：

  | 我把伴侣看成 | 我大概率在 | 书中给出的下一问 |
  |---|---|---|
  | 爱批评、没有耐心 | **正向依赖型**（围着对方转、讨好、道歉） | "感到紧张而尴尬" |
  | 多愁善感、陷在情绪里出不来 | **正向独立型** | "我正在否认或解离什么样的感觉呢？" |
  | 粗心大意、丢三落四 | **负向独立型**（批评、评判、指责） | "我内在有某种深深的不快乐" |
  | 疏远、不顾及我的感受 | **负向依赖型**（抱怨、觉得被忽视） | "迷失在我的情绪故事中" |

- 完成标准：用户能自己说出"因此我肯定在___象限"，且能认出该象限的行为特征里至少有一条是自己的。
- **判停条件**：若用户四条都不认（"我一条都不像"）→ 不要强行指派象限。这可能说明他拿不到观察位，跳到第 5 步的身体体验入口；若仍无感，结束本 skill，建议先做稳定化或专业支持。

### 第 4 步：填体验空 ★（本 skill 的核心步）
- 请用户完成：**"我这么看待伴侣，唯一的原因是，我正在体验着______。"**
- 硬规则：空格里必须是**一个感觉或一处身体感受**（"胸口发紧""被丢下的慌""胃里下沉"），**不能是**另一个对伴侣的描述（"他很烦"）或一句解释（"因为他从小就这样"）。
- 完成标准：用户填出一个感觉词或身体位置。
- **判停条件（对冲不可证伪性，必须执行）**：**若 10 分钟内连续两次填出的仍然是对伴侣的描述或解释，而不是"我正在体验着___" → 立即停止镜像反推。** 明确告知用户：这一步拿不到不是你的失败，说明此刻观察位不在。此时：① 若情绪强度高 → 先接住、不做定位；② 若情绪平稳但无感 → 转 `process-walk` 走过程；③ 若伴随强烈自我厌恶 → 转 `shadow-figure-integration`。

### 第 5 步：不修正看法，转向身体体验
- 明确禁止两件事：①**不要去修正你对伴侣的看法**（"我不该这么想他"）——修正看法等于把探针扔掉；②**不要给伴侣定性**（"所以他就是负向独立型咯"）。
- 动作：请用户把手放在第 4 步指出的身体位置，只是感受它，不改变它、不追问它为什么在这里。
- 完成标准：用户能报告一个**可观察的身体层面的变化或事实**（"呼吸浅""肩膀是耸着的""胃这里一直是紧的"），而不是"我想通了"。
- **判停条件（本 skill 最高频的误用，必须拦截）**：若用户开始用象限给伴侣或自己**定性**（"那他就是依赖型，难怪""原来我是讨好型人格"）→ **立即纠正**：象限是用来反推"我正在体验什么"的探针，不是人格分类，也不是给伴侣定性的依据。纠正后回到第 4 步。
- **判停条件**：**若 10 分钟内没有任何可观察的身体层面的变化，或用户越做越烦躁、越做越紧 → 停止，跳到第 7 步出口 B。** 不要用"你还在排斥""再试一次"来推进。

### 第 6 步：议题限定 + 防操纵检查（两步打包，都要过）
- **6a 议题限定（V2 补丁，必做）**：请用户把前面所有的结论**钉在同一个议题上**（钱、孩子、性、家务、社交、长辈，选一个），并明确告知：
  > **"离坐标中心的距离"只在同一个议题内、前后对比时才有意义。你在这个议题上偏独立、在那个议题上偏依赖，这不是不成熟，很可能只是分工。跨议题的偏斜不作情绪成熟度的判断。**
  - 完成标准：用户能说出一个议题名，并能在该议题内做一次前后对比（"同样是谈钱，我以前觉得他苛刻，现在觉得他只是焦虑"）。
  - **判停条件**：若用户想用"我在钱上独立、在孩子上依赖"来问"那我到底成不成熟" → **明确拒绝回答成熟度问题**，改为逐议题单独使用本 skill。
- **6b 防操纵检查**：问一句——**"你刚才调整自己的位置／想换个方式跟他说话，是不是主要为了让他消气、让冲突赶紧结束？"**
  - 完成标准：明确的是/否。
  - **判停条件**：答"是" → 明确告知：这是出于需求或恐惧的无意识行动，你的行为在**模仿**往中心的移动，但不会产生你想要的结果，伴侣会无意识地读出这份需求并反映出来。此时**不得**判定为"靠近中心"，回到第 4 步。

### 第 7 步：出口路由（三个出口，必须选一个并说清）
- **出口 A（已触到体验）**：完成标准 = 用户能说出"我正在体验着___"并能指认身体位置 → 交给 `process-walk` 继续（接纳 → 觉知 → 欣赏，过程能直接把你领到中心）。本 skill 到此结束。
- **出口 B（拿不到体验 / 10 分钟无变化 / 越做越紧）**：**停止镜像反推。** 此时用户要的很可能不是定位而是被听见——先接住，不做任何归因。可选项：① 只是继续说这件事，不做分析；② 若核心是长期粘连与自我区分 → 转 `two-boats-differentiation`；③ 若核心是"他做了一件我不能接受的具体事" → 转具体沟通或边界设定，不再向内。
- **出口 C（安全或外部处境）**：第 0 步命中，或用户在过程中说出需要改变外部处境的具体事项 → 优先处理外部处境与安全，列出至少一个本周内可执行的外部动作（向可信赖的人说明情况、联系专业支持、法律或财务咨询、就医）。
- **完成标准**：用户拿到一个明确的方向，而不是"我再想想他到底是什么型"。若用户得到的结论仍是"我需要更准确地判断他属于哪一型" → **本 skill 失败**，回到第 5 步纠正"象限不是用来给伴侣定性的"。

> **降级内容**：正向型／负向型的一般特征清单（各 9 条，第六章附录）已降级为查词表，见 `references/polarity-trait-checklist.md`。**它只用于帮助用户认出象限的行为特征，不得用于给伴侣或自己贴人格标签。**

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **★ 用象限给伴侣定性**——本 skill 最高频、也最有害的误用。写成"我判断出他是负向独立型"＝**用反了**。象限的唯一功能是反推"我正在体验什么"；一旦它变成对伴侣的描述，就从探针变成了标签，而且会成为改造工程的新武器（"权威说他是不健康的那一型"）。同理，不得用它给孩子、同事、父母定性——作者自己在第六章提醒：把模型用在孩子身上时，你会发现自己几乎总是落在独立那一边，这不是孩子的属性，是位置使然。
- **用户只有整体人格评价、给不出任何冲突切片**——那是特质性反感，转 `shadow-figure-integration`。
- **关系中存在家暴、精神虐待、PUA、跟踪、经济控制、成瘾、财务隐瞒**——此时"他只是反映了我的象限"是对施害者的开脱。见第 0 步。
- **用户正在试图用象限回答"我该留还是该走"**——象限是描述工具，不是决策工具。
- **用户正处在急性崩溃、闪回、解离或惊恐发作中**——本 skill 需要观察位。
- **正向型特征明显的易感用户**（过度信任、容易讨好、隐藏问题）——这三条特征与全书教义高度亲和，而这类人恰是情感操控与诈骗的高易感人群，书中对此零提示。对这类用户，本 skill 的"向内看"会进一步削弱其对外界风险的识别，需先做安全与现实检验。
- **用户只是想被听见**——先接住。被定位的体验会让人觉得被敷衍。

### 作者在书中警告的失败模式

- **施虐被映射为象限位置的函数（本 skill 最危险的一条，counter-extractor 编号 CE-S17）**：第六章说"一位负向独立型的人极少会施虐，除非他们离中心太远，行动完全没有意识"，紧接着说"对方离中心点的距离与你是完全一样的"。**failure_mode 的实质是责任再分配**：把道德行为（施虐）映射到描述性坐标（离中心远近），坐标是中性的，于是施虐失去了道德属性，只剩位置属性；再叠加等距律，施虐的强度就成了受害者自己意识状态的函数。机制是**中性框架承载了非中性内容**——作者说"没有对错，只是不同象限"，但他描述的象限内容包括施虐、批评、评判、操纵。
  可观测的预警信号：① 用"他在负向独立象限"来解释虐待行为；② 认为对方的施虐强度反映了自己的意识状态，因此自己应先改变；③ 把象限模型用于评估"我该留还是该走"；④ 用"我移到中心他就变了"来说服自己留下。
- **为操纵而移动 ≠ 靠近中心（作者明写）**："如果你调整行为，是为了操纵伴侣让他消气，你就没有向中心靠拢。可能你的行为在模仿往中心的移动，但这无法产生你想要的结果。"（第六章）**这是本 skill 最容易被反向利用的入口**——象限知识会变成更高级的操纵技术（"我只要表现得独立一点，他就会黏上来"）。第 6b 步的检查不可省略。
- **把象限当性格类型**：作者明说"几乎没有人在所有时候都只处于一个极性中"（第六章附录），并说"你有时会移到其他象限，但往往有一个象限，你很少会在那儿"。把四象限读成 MBTI 式的人格分类，会直接摧毁它的诊断价值。
- **把"中心"当成应该抵达的道德目标**：作者专门驳回了"必须先带头吗"这个问题——"这不是担子，这是一个成长的机会。而且也不是必须的问题，必须是应该的另一个说法。"把"靠近中心"变成 KPI，就是第 6b 步要拦截的那种模仿。
- **正向型人格的受害者易感性（CE-S12）**：第六章附录描述的三条特征——过度信任（"想要生活在没有坏人的世界中"）、容易讨好、隐藏问题（"如果他们觉得身体不舒服，他们不太可能去看医生"）——与全书教义高度亲和，而正向型正是情感操控与诈骗的高易感人群，书中零提示。

### 作者的盲点 / 时代局限

- **单章来源（本 skill 的立身弱点，必须明示）**：词频实测显示"极性/象限"在本册仅跨 3/11 章（06 章 18 次、07 章 2 次、10 章 2 次），是**本册内的单章概念**。它之所以通过 V1 跨域验证，靠的是与第 1 册 `shadow-figure-integration`（投射）的**跨册同源**——同一机制的两种表述。这意味着：本 skill 的独立证据基础弱于本册其他单元，使用时不应把它当成被反复验证的规律。
- **不可证伪的封闭系统（本册最强反对意见）**：反推成功 = 模型有效；反推失败 = 你还在排斥／还没到能看的时候。这个结构让方法无法被检验。**对冲方式已写入 E 段**：第 4 步设 10 分钟双次失败即停止的中止条件，第 5 步设"10 分钟无身体变化即停止"，第 6a 步拒绝回答成熟度问题，第 7 步强制三出口选一。
- **模型本身是比喻的比喻**：作者自承"记住，这只是我用的一个比喻，好说明这个极性的模型如何运作。**用一个比喻去解释另一个比喻。**"（第六章）来源是恰克·史匹桑诺与荣格的极性理论，未经独立检验。附录的正向/负向二分（乐观 vs 悲观人格）本身就是常识，其"总裁/副总"式的配对描述带有明显的时代与性别模板痕迹。
- **四个例句并不全部符合对角镜像律**（例："我的伴侣粗心大意、丢三落四"被对应到"我的负向独立面"，而非对角的负向依赖）。作者未说明这是例外还是模型松弛。因此本 skill 明确采用"以四句模板为准、不用对角规则硬推"的处置。
- **语料限制**：mobi 转换丢失了全部表格，**表 6.1／6.2／6.3 的内容在语料中不存在**。本 skill 不声称引用这三张表的任何内容；四象限的行为特征描述来自正文与第六章附录的文字段落，反推模板来自正文原句。
- **V2 补丁的局限（已实现）**：书中暗示象限相对稳定（"往往有一个象限，你很少会在那儿"），未处理议题依赖型分布。**因此：模型可以逐议题使用，但"离坐标中心的距离决定情绪成熟度"这一变量跨议题失效**——议题间的偏斜本身可能是健康的分工，而非未整合。见第 6a 步与上方"不要在以下情况使用"。
- **作者的划界被判定为不够**：他试图用"我只谈情绪不适，不谈身体伤害"来划界。五点失效理由：① 虐待的核心伤害形态正是情绪不适；② 划界是一次性的，全书再未回归；③ 划界是排他的而非累积的，等于宣布情绪领域无例外；④ 作者自己守不住——他用掠走妻子并企图谋杀的罗波那演示"连敌人也只是在演好自己的角色"；⑤ 全书**零处**写有"如果你正在经历 X，请不要使用本书的方法"。因此**不能依赖作者的划界**，第 0 步的 7 条拦截集是必需的。
- **证据基础与样本局限**：唯一的疗效证据是作者自己的婚姻（N=1），且他自评"情绪上只是从六岁提升到八岁"。案例全部是北美中产异性恋模板；被反推的一方多为女性视角的抱怨，情绪劳动的结构性分配未被处理。近二十五年的依恋神经科学、情绪调节（DBT/ACT）、复杂型 PTSD 研究完全未纳入。
- **两条 agent 特异性风险**：① **复制给伴侣看**——用户可能把"他是负向独立型"这句话转发给伴侣，作为"权威说你该改"的证据，此时你成为改造工程的第三方背书。**本 skill 的反推结果不得用作要求对方改变的依据**，且第 5 步必须拦截定性冲动；② **状态相关的适用性**——同一句"你把他看成什么样"，在用户安全时是洞察工具，在脆弱时是攻击。按用户**当下状态**设限，而不是按句子内容。

### 容易混淆的邻近方法论

- **不是依恋理论（焦虑型／回避型）**：四象限看起来像依恋风格的变体，但依恋理论把风格当作**相对稳定的人格维度**并追溯到早期养育关系；本 skill 的象限是**冲突当下的位置**，会随议题、随时间段移动（作者：几乎没有人在所有时候都只处于一个极性中）。**不要把用户定位成"你是焦虑型依恋"**——那是跨册越界，也是定性误用。
- **不是性格类型学（MBTI / 九型 / 大五）**：类型学回答"我是什么样的人"，本 skill 回答"我此刻站在哪、因此我正在体验什么"。类型学的结果是稳定的自我认同，本 skill 的结果是**一个要被放下的探针**。
- **不是"性格互补"的鸡汤**：常识会说"你们刚好互补，所以要互相包容"。本 skill 说：你看到的"互补"是你自己位置的镜像，因此不存在两个独立的人需要协调，只存在一个位置需要被认出——**这个主张比常识强得多，也因此更容易被滥用**（见 CE-S17）。
- **不是沟通技巧或冲突解决**：本 skill 的唯一产出是"我正在体验着___"。它不改善沟通、不解决分歧、不告诉你该说什么。要沟通转 `truth-based-communication`，要处理分歧转 `two-boats-differentiation`。
