# 古德哈特定律（Goodhart's law）

## R — 原文 (Reading)

> 古德哈特定律（Goodhart's law）总结了这个问题：当一项措施本身成为目标时，它就不再是一项好措施。
>
> — 《思维模型》, 第2章 > 许愿须谨慎

---

## I — 方法论骨架 (Interpretation)

任何指标都只是你想达到的真实价值的一个**代理变量**——代码行数不等于产出，点击率不等于满意度，住院天数不等于健康。指标之所以能当代理用，是因为在没有人刻意针对它的情况下，它碰巧与真实价值高度相关。

一旦把指标挂上奖惩，这个前提就崩了。人们会优化指标本身，而不是指标本欲代表的那个东西：不是把工作做得更好，而是让数字更好看。当优化压力足够大时，指标与真实价值的相关性被主动摧毁，指标的信息价值随之归零。

古德哈特 1975 年的原话其实更精确：「任何观察到的统计规律一旦用于管制，就会趋于崩溃。」——注意这里说的是**统计规律**（一种相关关系），不是某个具体指标。这解释了为什么连看似客观的经济规律（如菲利普斯曲线）在被当作政策目标后也会失效。

关键判据是一个组合：**可量化 + 高利害**。两者同时存在时，被钻空子几乎是必然的，不是"人品问题"。所以设计激励时，必须把"人们会用什么方式钻这个指标"当作设计流程里的必答项，而不是事后补救。

## A1 — 书中的应用 (Past Application)

### 案例: 苏联国家计划委员会的布匹与钉子

- **问题**: 苏联国家计划委员会需要用量化指标考核工厂产出，于是按不同计量单位给布匹和钉子下指标。
- **方法论的使用**: 作者展示了指标被当作目标后如何脱离真实价值：按码数考核布匹，布就织得松松垮垮（码数够了，布不能用了）；按数量考核钉子，就生产像别针一样细的钉子；改成按重量考核，就生产需要用起重机才能吊起的巨钉——苏联《鳄鱼》杂志曾就此刊登漫画讽刺。
- **结论**: 无论换成哪个单一计量维度，工厂都能在不提升真实价值的前提下把数字做上去。作者借此说明该定律的常见版本由人类学家玛丽莲·斯特拉森于 1997 年提出，却得名于经济学家古德哈特，属于命名与出处的分离。教训是：设计任何量化激励前，先自问"人们会用什么方式钻这个指标"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 正在设定 KPI/OKR/考核方案，尤其是第一次把某个数字与奖金、晋升、排名挂钩。
2. 团队出现"数字好看但业务没起色"的违和感：DAU 涨了留存没涨、工单处理量涨了满意度跌了、代码行数涨了功能没多。
3. 设计 A/B 实验的唯一评价指标，担心被实验组行为污染。
4. 做数据看板上线前的评审：这个指标公开后会被怎么利用？
5. 复盘一个失败的激励制度：为什么执行得越认真，结果越糟。

### 语言信号 (用户的话里出现这些就应激活)

- "我们要把这个指标和绩效挂钩"
- "数字是涨了，但我感觉业务没变好"
- "能不能想办法把这个数做上去"
- "上有政策下有对策"
- "这个 KPI 定完大家就开始刷量了"
- "Goodhart's law / gaming the metric / metric becomes the target / KPI"

### 与相邻 skill 的区分

- 与 `mm-cobra-effect` 的区别: 古德哈特定律描述"指标失去信息价值"（数字与真实价值脱钩），眼镜蛇效应描述"解决方案让问题变得更糟"（问题本身被放大）。前者是度量失效，后者是干预反效果；眼镜蛇效应通常是古德哈特定律的下一步。
- 与 `mm-campbell-s-law` 的区别: 坎贝尔定律强调"社会决策中量化压力越大，指标越容易被腐蚀"，与古德哈特定律高度重叠；古德哈特更强调"统计规律一旦用于管制就崩溃"的宏观层面，实践中可视为同源。
- 与 `mm-perverse-incentives` 的区别: 不当诱因是泛称（任何导致行为扭曲的激励安排），古德哈特定律给出了其中最常见、最可预测的**触发条件**：可量化 + 高利害。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出指标背后的真实价值**
   - 明确：这个数字本来想代表什么？它为什么曾经与真实价值相关？
   - 完成标准: 一句"X 是 Y 的代理变量，因为……"。
   - 判停条件: 若用户要度量的就是数字本身（如真实的交易金额），腐蚀风险低，可简化步骤 4-5。
2. **评估腐蚀风险：可量化 × 高利害**
   - 分别给"可量化程度"和"利害高低"打分，两者都高才进入强防护流程。
   - 完成标准: 两个维度各有一句判断。
3. **列举"钻空子清单"**
   - 至少列出 3 种在不提升真实价值的前提下把数字做上去的方法（如拆分订单、刷无效点击、挑选简单工单）。
   - 完成标准: 3 条具体的、可操作的钻法。
   - 判停条件: 若一条都想不出来，说明该指标可能确实不易被操纵，可适度放行。
4. **为每种钻法设计对偶指标或护栏**
   - 采用指标组合/比率而非单一绝对值（转化率而非点击数）、加入质量下限、设置随机抽检。
   - 完成标准: 每条钻法至少对应 1 个护栏，且护栏本身也做过钻空子检查。
5. **设定指标的退役与更换机制**
   - 指标必然被腐蚀，因此要预先定好复查周期与更换条件，并保留一部分不可量化的定性判断。
   - 完成标准: 写明复查周期（如每季度）与"指标失效"的判定信号。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯粹描述性、不与任何奖惩挂钩的度量：没有优化压力就不存在腐蚀动机（推导，非书中明示）。
- 指标尚未被被考核者知晓或理解的早期阶段：腐蚀需要时间，但这也意味着它一定会来（推导，非书中明示）。
- 度量对象就是价值本身（如营收金额、实际事故数）且难以造假的场景：可操纵空间小，强防护反而增加成本（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 书中给出的边界是命名问题：该说法更常见的版本由人类学家玛丽莲·斯特拉森 1997 年提出，却得名于经济学家古德哈特，属于命名与出处分离——引用时要注意区分"古德哈特 1975 原话（统计规律用于管制即崩溃）"与"常见版本（措施成为目标就不再是好措施）"。
- 容易误以为"换个更聪明的指标"就能解决。只要保持"可量化+高利害"的组合，任何指标都会被腐蚀，正确做法是组合指标 + 护栏 + 定期更换（推导，非书中明示）。
- 容易把指标腐蚀当成执行者的道德问题。它是对激励的理性反应（推导，非书中明示）。

### 容易混淆的邻近模型

- 与眼镜蛇效应：古德哈特定律是"指标失真"，眼镜蛇效应是"问题变严重"。前者通常先发生，后者是它的升级版——先有人刷指标，再有人靠问题本身牟利。
- 与不当诱因：不当诱因是类别，古德哈特定律是该类别中最可预测的一条触发规则（可量化+高利害）。
