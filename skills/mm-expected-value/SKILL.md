# 期望值（expected value）

## R — 原文 (Reading)

> 你可以将每个潜在结果出现的概率乘以它的成本，然后全部加起来，就能估算出每个承包商的预期值（expected value）。根据所有潜在结果算出的总数，就是你预期要为每个承包商支付的价格。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

期望值 = 每个可能结果的数值 × 该结果发生的概率,再全部加起来。它回答的是"**如果同样的事重复很多次,平均每次会怎样**"。

理解它的关键,是接受一件事:期望值通常**不是任何一次的真实结果**。作者用这个类比说明——2015 年美国母亲平均有 2.4 个孩子,但没有哪个母亲真的有 2.4 个孩子。同理,新承包商的期望成本是 2212.50 美元,但把场景重复 100 次,平均每次付 2212.5 美元,而你永远不会恰好支付这个数。

这个区别决定了它的适用条件:**只有在可重复的赌局里,期望值才等于你真正会拿到的东西**。你买一次保险、开一次公司、做一次手术,都是单次博弈,此时期望值是个参考,不是预言。

判据:新承包商可能收 3000 美元,但只要大概率只收 2000 美元,期望值仍低于报价 2500 美元的旧承包商,理性上就应选他。而当两个期望值接近时,说明决策对概率高度敏感,需要更谨慎地估计概率——而不是再算两位小数。

---

## A1 — 书中的应用 (Past Application)

### 案例: 新承包商期望值 2212.50 美元

- **问题**: 旧承包商一口价 2500 美元,新承包商报价 2000 美元但有 50% 概率拖期,拖期还要按周加钱。哪个更便宜?
- **方法论的使用**: 作者把每个潜在结果的概率乘以它的成本再全部加总:1000 + 562.50 + 500 + 150 = 2212.50 美元,这就是新承包商的期望值。
- **结论**: 2212.50 < 2500,理性上应选新承包商。但同时作者强调:若场景重复 100 次,平均每次支付 2212.5 美元,而你永远不会恰好支付这个数——期望值是平均值,不是这一次的实际结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在可重复的场景里做选择:投放渠道、采购批次、招聘漏斗、日常定价——这些都是"赌很多次",期望值直接等于长期结果。
2. 用户凭直觉说"这个更划算",但直觉只盯着最好或最坏的那个结果,没有加权。
3. 用户面对"高概率小收益 vs 低概率大收益"的选择,需要一把统一的尺子。
4. 用户算完发现两个选项期望值几乎一样,需要知道下一步该干什么。

### 语言信号 (用户的话里出现这些就应激活)

- "平均下来哪个更划算"
- "长期做下去会赚吗"
- "这个概率乘上收益是多少"
- "收益高但概率小,那个概率大但收益少,选哪个"
- "期望值怎么算"
- "expected value" / "on average" / "in the long run"

### 与相邻 skill 的区分

- 与 `mm-decision-tree` 的区别: 期望值是计算规则,决策树是承载它的结构;单个机会节点的加权求和用本 skill,多层分叉/序贯决策用决策树。
- 与 `mm-utility-values` 的区别: 期望值用**金钱**加权,效用值用**主观满足度**加权;当"担心""麻烦""面子"这些无形项会改变选择时,要把树叶上的钱换成效用值,结论可能反转。
- 与 `mm-sensitivity-analysis` 的区别: 期望值给出单点答案,敏感性分析告诉你这个单点有多脆;两者必须配套使用。

## E — 可执行步骤 (Execution)

1. **确认这是可重复的场景**
   - 完成标准: 明确回答"这个选择会不会重复很多次"。
   - 判停条件: 若是单次且后果具毁灭性(破产、死亡、不可逆),跳到步骤 4,不要以期望值作为唯一依据。
2. **列出全部可能结果及其概率**
   - 完成标准: 结果互斥且穷尽,概率之和 = 100%。
   - 判停条件: 若概率没有任何依据,先说明这一点,并把未知概率反解成"需要多大概率才值得做"的门槛,而不是硬填。
3. **逐项相乘并加总**
   - 完成标准: 每个结果数值 × 概率,加总得到期望值;明确指出"这个数不是任何一次的真实结果,而是长期平均值"。
4. **检查风险分布,而不只看均值**
   - 完成标准: 明确列出最坏结果及其概率,并回答"如果最坏结果发生在我身上,我承受得起吗";若承受不起,即使期望值更优也应避开——这正是保险存在的理由。
   - 完成标准(补): 对最关键的概率做敏感性分析。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性、不可重复、且后果毁灭性的决策:期望值会把"99% 平安 + 1% 破产"算成一个温和的平均值,从而系统地误导你。
- 概率完全无依据时的装点式计算:算出 2212.50 这种带两位小数的数字会制造虚假精确。
- 结果不能用同一单位衡量(钱、健康、关系、时间混在一起)且未做效用转换时。

### 书中警告的失败模式 / 容易误用的地方

- 期望值相同不代表风险相同:低概率高后果(如破产)时,即使平均更省钱也应避开,这正是保险存在的理由。(书中明示)
- 概率一旦估计错误,结论立刻翻转——所以必须做敏感性分析。(书中明示)
- 期望值不是"这一次你会得到的结果":作者用"平均 2.4 个孩子"作类比强调这一点,把期望值当成预测是最常见的误读。(书中明示)

### 容易混淆的邻近模型

- 与大数定律(law-of-large-numbers): 大数定律是"期望值会被兑现"的**前提条件**——重复次数足够多时平均值才收敛到期望值;次数少时不成立。
- 与效用值: 期望值假设你对钱的感受是线性的;现实中 100 万和 200 万的差别不等于 0 和 100 万的差别,这时要用效用值。
