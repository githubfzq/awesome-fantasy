# 锁定效应（lock-in）

## R — 原文 (Reading)

> 拥有有效“护城河”的组织和个人就创造出了“锁定效应”（lock-in）。有很多方式都可以创造出“转换成本”，包括取消服务费、值得信赖的关系、新设备成本、学习曲线
>
> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

**锁定效应（lock-in）** 是指因转换成本过高，而被现有服务、关系或局面绑住、难以脱离的状态。

**它描述什么**：当客户认为转换成本非常高，就会被当前使用的服务锁定；拥有有效护城河的组织和个人，据此创造出锁定效应。书中列出的成本来源包括：取消服务费、值得信赖的关系、新设备成本、学习曲线。

**为什么成立**：高转换成本使客户（或个人、组织）**失去退出选项**。一旦退出在心理账本上被判为"不可行"，供给方就获得了持续的支配力——不必每年重新赢一次，客户会自己留下来。锁定的本质不是"满意"，而是**退出这个选项被移出了考虑范围**。

**它在商业之外同样运作**：书中明确指出，很多人感觉被某段关系锁定，因为改变的**情绪与心理成本**太高；住房、城市同样如此；甚至国家层面的外交安排（如英国脱欧）也会因为转换成本过高而被锁住。

**关键判据（本 skill 的核心动作）**：区分三种不同的"走不掉"——

1. **真实锁定**：退出确实要付高昂代价，且这个代价是**未来**才发生的。理性上值得留下，或值得为脱离做长期准备。
2. **沉没成本幻觉**：其实没什么未来代价，只是已经投入太多而不甘心。这不是锁定，是偏误——该走。
3. **惯性/恐惧**：代价存在但被情绪放大，实际远小于想象。需要先校准感知。

三者都会产生"走不掉"的体感，但应对方式完全不同：真实锁定要规划脱离路径，沉没成本要果断止损，惯性要先做小剂量试探。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "明知道没前途也走不掉"——工作、关系、城市、合伙关系。
2. 组织被关键员工、单一供应商或单一大客户锁住（书中提到甚至有"关键人物保险"）。
3. 作为供给方，想评估自己对客户的锁定有多强、是否可持续。
4. 感觉被困住，但说不清是客观约束还是自己不想动。
5. 在纠结要不要承受一次性代价换取长期自由。

### 语言信号

- "走不掉 / 离不开 / 换不动 / 被困住了"
- "明知道不好也只能这样"
- "我们已经在这上面投太多了"
- "整个公司离了他就转不动"
- "想走但是代价太大"
- "是不是我这辈子就这样了"
- "lock-in / stuck / trapped / can't leave / no way out / too costly to exit"

### 与相邻 skill 的区分

- 与 `mm-switching-costs` 的区别: 转换成本是**原因**——客户要付出的代价清单；锁定效应是**结果状态**——因此被绑住、难以脱离。要量化或设计成本用前者，要判断"我是不是被困住、该不该脱离"用后者。
- 与 `mm-sunk-cost-fallacy` 的区别: 沉没成本谬误是**认知偏误**——不该因为已经投入而继续；锁定是**真实的未来退出成本**。两者都会让人留下，但性质相反：一个该走却被拖住，一个留下是理性的。本 skill 的关键动作就是把这两者分开。
- 与 `mm-barriers-to-entry` 的区别: 进入壁垒/退出壁垒是**结构化清单**（阻止进入与退出的各类障碍）；本 skill 是**被困者的处境判断与脱离决策**。要列障碍清单用壁垒，要决定走不走用本 skill。
- 与 `mm-concorde-fallacy` 的区别: 协和谬误特指**因为已投入而承诺升级**（继续加码）；本 skill 中的沉没成本幻觉是其中一种成因，但真实锁定与惯性属于另外两类，处理方式不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先问"不愿走"还是"走不了"**
   - 完成标准: 让用户明确回答——如果所有代价由别人承担，他还会留下吗。会 → 不是锁定，是不舍或恐惧，转步骤 2 的情绪线；不会 → 进入成本分析。
2. **列出退出成本清单，逐项标"真实的 / 想象的"**
   - 完成标准: 得到一份退出成本清单（可调用 `mm-switching-costs` 的六类框架），每项标注是"确实会发生"还是"我害怕会发生"，并给出粗略量级。
   - 判停条件: 若清单里绝大部分是"想象的"，判定为惯性/恐惧而非真实锁定，进入步骤 4 的试探方案。
3. **把沉没成本单独剔出去**
   - 完成标准: 明确把"已经投入的时间/钱/感情"从清单中划掉，并说明理由——已投入的部分无论走不走都收不回，它不构成未来的退出成本。剔除后若清单几乎清空，则这是沉没成本幻觉，结论应指向止损。
4. **若为真实锁定，计算脱离的总代价与时间表**
   - 完成标准: 给出脱离所需的总成本、可分几步走、每步降低哪一项成本、以及完整脱离需要多久。
5. **给出降低退出成本的预案与检查点**
   - 完成标准: 至少给出 2 条具体的"降低退出成本"动作（备选供应商、可迁移技能储蓄、并行过渡、合约重谈），以及一个明确的复查时间点——避免"暂时走不了"演变成"永远走不了"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 局面本来就令人满意、用户只是想确认——不存在"难以脱离"的问题。
- 明显是沉没成本在起作用（已投入的收不回，未来无代价）——应直接用沉没成本谬误/协和谬误，本 skill 的成本分析会替偏误提供伪理性包装。
- 需要量化迁移代价以做采购决策——用转换成本。
- 涉及受法律或人身安全约束的处境（如有暴力风险的亲密关系）——这超出思维模型范畴，应建议寻求专业与现实支持。

### 容易误用的地方

- （推导, 非书中明示）把一切"不想走"都说成锁定。书中强调的是**情绪与心理成本**也能造成锁定，所以心理成本是真实的；但"因为已经投入而不甘心"不是成本，是偏误。必须走第 3 步把它们分开。
- （推导, 非书中明示）把锁定当成宿命。转换成本可以被主动降低——备选方案、并行过渡、技能储蓄都是在削减未来的退出成本。第 5 步不是可选项。
- （推导, 非书中明示）用锁定合理化不行动。"暂时走不了"很容易滑成"永远走不了"，必须有复查时间点。
- （推导, 非书中明示）站在供给方一侧时高估锁定的稳定性。学习曲线会趋同、迁移工具会成熟、网络会迁移，锁定需要持续再投资，不是一劳永逸的资产。
