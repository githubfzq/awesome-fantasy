# 不当诱因（perverse incentives）

## R — 原文 (Reading)

> 利益攸关的考核文化（例如学校考试、工作面试或专业许可证考试）会创造出"应试教育"的不当诱因（perverse incentives），甚至造成更糟糕的情况——作弊。
>
> — 《思维模型》, 第2章 > 许愿须谨慎

---

## I — 方法论骨架 (Interpretation)

不当诱因指的是：你设计了一套激励，人们按字面把它兑现了，但兑现的方式与你想要的相反，结果比不激励时更糟。

它的机制在于人会对激励的**字面定义**做出反应，而不是对激励背后的**意图**做出反应。人们会去找愿望里的漏洞。古生物学家孔尼华承诺每块人类化石付 10 美分，当地人于是把大块化石敲成小片——他们没有违反约定，只是按计件单位最大化了自己的收益。2011 年亚特兰大 178 名教育工作者篡改学生标准化考试答卷，11 人被判刑，最长 20 年，则是高利害考核把"应试教育"推到了作弊。

所以最实用的判据是：**激励的计量单位与真实目标的计量单位是否一致？** 按化石碎片数量付钱，计量单位是"块"，真实目标是"化石的完整科学价值"，两者错位，于是大化石被敲碎。凡是计量单位比目标更粗糙、更容易观测的地方，就留着让人钻的缝。

它与古德哈特定律、眼镜蛇效应同属一族：古德哈特定律讲**指标失效**（数字不再代表价值），眼镜蛇效应讲**问题被放大**（有人开始生产问题），本条讲的是**被诱导出的行为本身**——行为跑偏、投机、甚至作弊。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 设计销售提成、拉新奖励、按件计酬、按发现数量付费的合作。
2. 把某个行为写进晋升或奖金的硬条件（提交数、工时、单量、考试分）。
3. 设计政府或平台补贴（节能补贴、内容创作激励、举报奖励）。
4. 观察到团队在做明显无意义但能拿分的事（凑数、拆单、刷时长）。
5. 复盘一起作弊/数据造假事件，追溯激励设计的漏洞。

### 语言信号
- "我们打算按数量给奖励"
- "大家都在为了拿奖金做表面功夫"
- "这个考核一出来，行为就变味了"
- "他们这是在钻空子吧"
- "为了达标，什么都做得出来"
- "perverse incentive / gaming the system / hitting the number but not the goal"

### 与相邻 skill 的区分
- 与 `mm-goodhart-s-law` 的区别: 古德哈特定律是"指标失去信息价值"（数字与真实价值脱钩），本 skill 是"被诱导出的行为改变了现实"（有人开始投机甚至作弊）；前者是度量的问题，后者是行为的问题。
- 与 `mm-cobra-effect` 的区别: 眼镜蛇效应是其中最具破坏性的一类——方案反过来**放大了原问题**（养蛇的人出现了），本 skill 是泛称，包含一切行为跑偏，问题本身未必变严重。
- 与 `mm-campbell-s-law` 的区别: 坎贝尔定律强调高利害指标产生的**腐化压力**会破坏被监控的进程，本 skill 强调**激励的计量单位与真实目标错位**这一具体成因。
- 与 `mm-hydra-effect` 的区别: 九头蛇效应是打掉一个冒出两个（供给侧被打击后需求侧拉来新玩家），本 skill 的成因是激励结构，不是需求侧的补偿反应。

## E — 可执行步骤 (Execution)

1. **把激励的"字面定义"写下来**
   - 用一句话写出：做什么、得到什么。
   - 完成标准: 一句不含意图、只含规则的陈述。
2. **把真实目标也写下来，做单位比对**
   - 问：激励的计量单位是什么？真实目标的计量单位是什么？
   - 完成标准: 明确指出两者是否一致；若不一致，标出被忽略的维度（质量、长期、外部性）。
   - 判停条件: 若单位一致且无法低成本伪造，风险较低，可只做轻量检查。
3. **做"如果我要最大化收益，我会怎么做"推演**
   - 至少推演 3 条路径，其中必须包含一条完全合规但违背意图的路径。
   - 完成标准: 3 条路径都写成具体可观察的行为。
4. **改计量单位，让它更难钻**
   - 手段：从数量改为与真实结果挂钩（按节能量而非改造面积）、加入质量门槛与去重、改为相对基线的增量、加入滞后核验与随机抽检、设置奖励上限。
   - 完成标准: 每条套利路径至少 1 条封堵措施，且优先改计量单位而不是加监管。
5. **设计兜底：作弊的代价**
   - 完成标准: 明确"发现后怎么处理"，且代价必须高于套利收益。
6. **设定上线后的观察指标**
   - 完成标准: 明确看哪 2-3 个信号（分布异常、卡线、集中度）以及多久复查一次。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 激励尚未改变任何人行为、只是你担心会出问题：可以做轻量推演，但不必上升到完整检查。
- 激励与真实目标高度一致且无法伪造（如按实际销售额分成且无法拆单）：风险本来就低。
- 问题纯粹是数字失真而行为未变：那是古德哈特定律（推导，非书中明示）。

### 容易误用的地方
- 作者也用这个模型批评医院和大学为追求排名而牺牲本该被排名衡量的教育质量和护理质量（书中明示）——即被激励者会牺牲目标本身去换取目标的替代品，这是最高危的一类。
- 只加监管不改计量单位是最常见的错误：监管会随激励一起被套利，而改计量单位能从源头消灭套利空间（推导，非书中明示）。
- 忽略"完全合规但违背意图"的那条路径：作弊好抓，钻空子难防，而后者造成的损失通常更大（推导，非书中明示）。
