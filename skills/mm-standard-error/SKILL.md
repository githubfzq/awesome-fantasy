# 标准误差（standard error）

## R — 原文 (Reading)

> 分布的标准误差等于"样本的标准差"除以"样本量的平方根"。这就意味着，如果你想将误差范围减少一半，就需要将样本量增加4倍。
>
> — 《思维模型》, 第5章 > 钟形曲线

---

## I — 方法论骨架 (Interpretation)

标准误差衡量的是**"如果我再抽一次样，样本均值会偏离多少"**——它是抽样分布的标准差，而不是原始数据本身的标准差。这两者常被混为一谈，但含义完全不同：样本标准差描述"个体之间差多少"，标准误差描述"我这个估计值本身有多不稳定"。

公式是：标准误差 = 样本标准差 ÷ √样本量。

真正有决策价值的是那个平方根。因为样本量待在分母的根号下，精度提升呈**边际急剧递减**：想让误差范围减半，样本量得翻 4 倍；想减到 1/3，得翻 9 倍。这直接决定了"再多招点样本"值不值——它不是线性的买卖，越往后越贵。

书中给了最直观的对照（"是/否"型民调）：

| 样本量 | 误差范围 |
|---|---|
| 96 | ±10% |
| 384 | ±5% |
| 1067 | ±2% |
| 2401 | ±1% |

从 384 到 2401（6 倍样本）只换来误差从 5% 降到 1%（5 倍精度）。

关键判据：**先问"我需要多窄的误差范围才能做这个决定"，再倒推样本量**，而不是先招样本再看结果够不够准。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计问卷调查/用户访谈/AB 测试，需要决定样本量，或在"精度"与"预算/时间"之间做取舍。
2. 看到某份报告说"支持率 52%，误差范围 ±3%"，想知道这个 ±3% 是怎么算出来的、够不够用。
3. 结果已经出来了，两组差异很小，需要判断"这点差异是不是在噪声里"。
4. 有人提议"再补几百个样本就能说明问题了"，需要评估这个投入换来的精度提升值不值。

### 语言信号

- "这个结果误差范围是多少"
- "多少样本量才够"
- "再多抽一点样本能不能更准"
- "误差能不能压到 2% 以内"
- "两组差了 1.5%，这算有差别吗"
- "How many respondents do we need / margin of error / is this statistically reliable"

### 与相邻 skill 的区分

- 与 `mm-margin-of-error` 的区别: 误差范围是标准误差乘上一个置信系数后的**对外表述**（±X%）；标准误差是它的**计算来源**。想知道"±3% 怎么来的"用本 skill，想知道"±3% 意味着什么"用前者。
- 与 `mm-standard-deviation` 的区别: 标准差描述**样本内个体的离散程度**，标准误差描述**样本均值这个估计值本身的波动**。前者反映总体多样性，后者反映你的测量精度。
- 与 `mm-sample-size` 的区别: 样本量权衡覆盖成本、时间、受试者风险等全部取舍维度；本 skill 只提供其中"精度—样本量"这一条定量曲线，是它的计算内核。

## E — 可执行步骤 (Execution)

1. **确认这是抽样估计，不是全量普查**
   - 判断：结论是否来自总体中的一部分样本？全量数据不需要标准误差。
   - 完成标准: 明确写出"总体是什么、样本是什么、样本量 n 是多少"。
2. **拿到样本标准差 s**
   - 若是"是/否"型比例，可用 p(1−p) 的平方根代替。
   - 完成标准: 得到 s（或比例 p）的具体数值。
3. **算出标准误差 SE = s / √n**
   - 完成标准: 给出 SE 的数值，并口头校验（n 翻倍时 SE 应约为原来的 0.707 倍）。
4. **换算成误差范围并对照决策需求**
   - 常用 95% 置信度下约为 ±2×SE；明确写出"真实值大概落在 [估计值 − 2SE, 估计值 + 2SE]"。
   - 完成标准: 判断这个区间宽度是否足以支撑当前决策（例如两组差异是否大于误差范围）。
   - 判停条件: 若区间已经窄到足以定夺，停止加样本；若太宽，进入步骤 5。
5. **按平方反比倒推所需样本量，并说明代价**
   - 误差减半 → 样本量 ×4；误差减到 1/3 → ×9。用书中民调对照表（384→5%、1067→2%、2401→1%）做直观校准。
   - 完成标准: 给出目标精度对应的样本量，并明确说明边际递减——让用户判断这笔投入是否值得，而不是默认"样本越多越好"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 数据是总体本身（全量日志、全部用户）而非抽样：此时没有抽样误差，算标准误差没有意义（推导，非书中明示）。
- 样本不是随机/代表性抽样：公式给的是抽样误差，**不覆盖**选择性偏差、无反应偏差等系统性偏差。样本量再大，偏差也不会消失（推导，非书中明示）。

### 容易误用的地方

- 书中明示的警告：**别把标准误差与此前算出的样本标准差混为一谈**，这是两个不同的值。混淆会导致把"个体多样性"当成"估计精度"，或反过来。
- 容易忽略平方根带来的边际递减，以为"样本翻倍精度翻倍"。实际是样本翻 4 倍精度才翻倍（书中明示）。
- （推导，非书中明示）容易只报点估计不报误差范围。没有标准误差的均值几乎无法用于决策。

### 容易混淆的邻近模型

- 标准差（standard-deviation）：衡量个体离散度，不随样本量系统性缩小。
- 置信区间（confidence-interval）：标准误差的直接产物，是"估计值 ± 若干倍标准误差"的区间表述。
