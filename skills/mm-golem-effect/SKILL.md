# 魔像效应（golem effect）

## R — 原文 (Reading)

> 相反，魔像效应（golem effect）形容的则是期待值降低导致表现变差。（这个模型得名于犹太神话中一种能自行活动的黏土造物，它会变得越来越腐坏，越来越暴力，最终不得不被摧毁。）
>
> — 《思维模型》, 第8章 > 释放潜能

---

## I — 方法论骨架 (Interpretation)

魔像效应是**期待值降低导致表现变差**。它是皮格马利翁效应的镜像——后者是高期待带来高表现，前者是低期待带来低表现。两者共享同一机理：都是自我实现的预言。

名字取自犹太神话中一种能自行活动的黏土造物（魔像），它会变得越来越腐坏、越来越暴力，最终不得不被摧毁。这个意象点出了效应的要害：**被看低的对象会朝被期待的方向腐坏**，而不是保持不变。

管理含义很重：对员工或孩子不抱期待，会造成重大阻碍。而且这种不抱期待往往不需要说出口——减少的反馈、跳过的机会、降低的任务难度、被省略的解释，全都是信号，接收者读得懂。

解法是书中给出的：**开诚布公地把期待说清楚**，让人认清目标、把握机会。不是鼓励式地"你很棒"，而是明确"我对你的期待是 X，你要做到 Y，机会是 Z"。

关键判据：**表现下滑是否紧随期待降低之后**。如果一个人换了领导/老师后表现明显下降，且能力没有变化，先查期待信号。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某位成员在被认为是"能力一般"之后表现持续下滑，出现"反正我也不行"的姿态。
2. 管理者/老师发现自己已经对某人"不抱希望"，并正在据此减少投入（不派重要任务、不给反馈、不解释背景）。
3. 新人被贴上"背景一般/学历不高/转行过来的"标签后迟迟起不来。
4. 孩子在某科被认定"不是这块料"之后成绩加速下滑。

### 语言信号

- "他就这样了，不用在他身上花太多时间"
- "反正我怎么做都没人满意"
- "反正我也不行"
- "这个任务别给他了，他做不好"
- "我不是这块料"
- "He always underperforms, so I stopped giving him the hard stuff" / "why bother trying"

### 与相邻 skill 的区分

- 与 `mm-pygmalion-effect` 的区别: 皮格马利翁效应是**期待升高带来表现提升**，魔像效应是**期待降低带来表现下降**，二者是同一机理的镜像。诊断时先定方向：期待是升了还是降了。
- 与 `mm-observer-expectancy-bias` 的区别: 观察者期望偏差讲的是**观察者看到的结果被自己的期望扭曲**（测量端失真）；魔像效应讲的是**被期待者的真实表现被改变**（对象端改变）。一个是"看错了"，一个是"变坏了"。
- 与 `mm-managing-to-the-person` 的区别: 以人为本的管理关注**方法要因人而异**；魔像效应关注**期待本身会制造结果**。前者是形式，后者是内容。

## E — 可执行步骤 (Execution)

1. **确认是不是期待降低在前**
   - 完成标准: 理清时间线——期待降低的信号（少派活、少反馈、少解释、降难度）出现在表现下滑之前还是之后。若是之后，退出本 skill，查能力与资源。
2. **清点已经泄露的低期待信号**
   - 完成标准: 列出具体的行为证据：哪些重要任务跳过了他、哪些反馈被省略、哪些机会没告知。不要只凭态度判断。
3. **把期待开诚布公说清楚**
   - 完成标准: 输出一段可直接说出口的话，包含三要素——我对你的期待是 X（具体标准）、你要达成的是 Y、机会是 Z。避免空洞鼓励。
4. **恢复实质性投入**
   - 完成标准: 给出至少一个与期待匹配的**真实动作**：派一个需要跳一跳才够得着的任务、给一次完整反馈、或补上此前省略的背景说明。
5. **设定复检点**
   - 完成标准: 约定具体时间与观察指标，用于判断表现是否随期待恢复而回升；若未回升，转查能力/流程问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 表现下滑的真实原因是能力不足、资源缺失或流程阻塞——抬高期待不能替代补能力与给资源。
- 期待并未降低、只是目标设得高——那是目标设定问题，不是魔像效应。
- 需要做出客观的人事判断（是否留任、是否调岗）——此时应基于证据，避免被"要给他高期待"的道德压力带偏。

### 容易误用的地方

- （推导, 非书中明示）书中未提局限。由机制可推导：把期待**说出来**不等于把期待**抬起来**——嘴上说高期待但行为仍跳过他，接收者读的是行为，效应不会反转。
- （推导, 非书中明示）反向误用：因为害怕造成魔像效应而不敢如实指出问题，把低期待伪装成高期待。书中明说的解法是"开诚布公把期待说清楚"，诚实本身包含如实反馈差距。
- （推导, 非书中明示）期待必须可信。给出明显超出当前水平的期待，一旦失败会被读作"你本来就不行"，反而强化效应。

### 容易混淆的邻近模型

- **皮格马利翁效应（pygmalion-effect）**: 本模型的镜像——高期待带来高表现。
- **观察者期望偏差（observer-expectancy-bias）**: 期望扭曲观察结果，而非改变对象表现。
