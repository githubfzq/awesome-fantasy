# 过滤气泡（filter bubble）

## R — 原文 (Reading)

> 随着网上个性化推荐和新闻推送的兴起，可得性偏差的问题正在变得越来越严重。在网络上，这个模型被称为"过滤气泡"（filter bubble）。
>
> — 《思维模型》, 第1章 少犯错 > 各持己见

---

## I — 方法论骨架 (Interpretation)

过滤气泡是可被算法放大的可得性偏差。链条是这样的：你更愿意点开熟悉、顺眼的内容（可得性偏差也让你觉得"到处都在说这件事"）→ 平台的目标是点击量，于是它把更多同类内容推给你 → 展示位有限，与你观点相反的内容被挤掉 → 你看到的世界越来越像你自己，于是更愿意点击同类内容。循环闭合。

它危险在哪？不在于"你看到的东西你不喜欢"，而在于**你根本不知道自己被过滤了什么**。气泡是无形的：被删掉的内容不会给你发通知。所以你以为自己在看"全部信息"，实际上看的是"为你定制的信息"，并且会把这个样本当作世界的真实分布。

书里引用的 DuckDuckGo 研究把这一点说得很硬：同一时间、相同的关键词搜索同一议题，不同人得到截然不同的结果集，即使退出账号、使用隐身模式也仍然如此。

判据：**同一时间、同一关键词，别人搜到的结果和我一样吗？** 不一样，你就住在一个气泡里。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. **对某个议题形成了强烈判断，且"所有人都这么说"**：需要检查这个"所有人"是不是推荐算法为你挑选的。
2. **做舆情/市场/竞品调研只看一个平台**：结论高度一致反而可疑。
3. **感到信息流越来越窄**：刷来刷去都是同一类内容、同一批博主。
4. **跨地域/跨群体做判断**：你看到的版本和另一群人看到的版本可能完全不同。
5. **依赖算法推荐做重要决策**（投资、择业、健康）（推导, 非书中明示）。

### 语言信号
- "怎么我刷到的全是这类说法"
- "大家都在说……"
- "网上都说……"
- "他的信息怎么跟我的完全不一样"
- "我搜了一下，结果全是一样的"
- "Everyone is saying…" / "My feed is all the same"

### 与相邻 skill 的区分
- 与 `mm-availability-bias` 的区别: 可得性偏差是**认知层面的**——你按"想起来多容易"估计频率；过滤气泡是**环境层面的**——信息环境真的被改造了，让你的样本本身有偏。气泡是可得性偏差的放大器和成因之一。
- 与 `mm-confirmation-bias` 的区别: 证实偏差是**你自己**挑着看、挑着信；过滤气泡是**系统**替你挑好了。前者是主动的，后者是你被动接受的，二者叠加时危害最大。
- 与 `mm-echo-chamber` 的区别: 回音室强调**人群内部**互相强化（你身边的人都在说同一套），过滤气泡强调**算法**替你筛选。现实中两者常常共存。

## E — 可执行步骤 (Execution)

1. **把用户的信息来源列出来**
   - 完成标准: 写出他实际获取该议题信息的 3-5 个渠道，并标注每个渠道是否有个性化推荐机制。
2. **做一次跨源对照**
   - 完成标准: 指定一组对照组（不同平台 / 不同立场的人 / 不同语言或地区 / 无痕模式搜索同一关键词），明确"去哪里看、看什么"。
   - 判停条件: 若用户无法或不愿跨源，退而求其次——直接问他"有没有一个你尊敬的、立场不同的人，他会怎么说？"
3. **列出被过滤掉的那部分观点**
   - 完成标准: 至少写出 2 条在用户当前信息流里不会出现、但确实存在的相反观点或事实，并注明来源或"待查证"。
4. **重新估计立场强度**
   - 完成标准: 让用户在看到相反证据后，明确说出自己的判断是"维持 / 减弱 / 改变"，并给出理由。
   - 判停条件: 若用户在看到相反证据后立场反而更强，转 `mm-backfire-effect`。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **单次内容推荐**：某一条推荐结果不代表气泡，气泡指的是长期、系统性的过滤。
- **用户已主动跨源取样**：此时问题不在信息环境，而在判断本身，应转向其他偏差模型。

### 容易误用的地方
- **书中未给边界**。以下基于机制推导：
- （推导, 非书中明示）**"我处在气泡里"不等于"我的观点错了"**：气泡说明的是**样本有偏**，不是**结论为假**。破泡之后仍需独立判断证据。
- （推导, 非书中明示）**把气泡当成人身攻击**："你这是信息茧房"常被用来否定对方，正确用法是让双方各自说明信息来源。
- （推导, 非书中明示）**破泡的代价**：主动订阅对立观点会大幅增加信息成本，且可能被推向另一个极端；平衡做法是选择高质量的对立信源，而不是越多越好。
