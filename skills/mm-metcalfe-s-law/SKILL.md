# 梅特卡夫定律（Metcalfe's law）

## R — 原文 (Reading)

> 描述了节点彼此相连时网络价值的非线性增长。
>
> — 《思维模型》, 第4章 > 利用链式反应

---

## I — 方法论骨架 (Interpretation)

梅特卡夫定律说，网络的价值与节点数的平方成正比。直觉来自连接数：n 个节点之间可能的连接数是 n(n-1)/2，约为 n² 量级，所以网络规模翻倍时，价值增长远超两倍。书中用电话网络举例：如果电话网络中有 100 万部电话，它的价值就是拥有 50 万部电话的网络的两倍。

为什么重要：它解释了为什么临界点之后增长会突然加速。早期每个新节点带来的连接增量很小，跨过一定规模后，新增节点既提升网络对新用户的吸引力，也提升网络对外部观望者的吸引力，两条曲线叠加就出现了"忽然起飞"。

关键判据是：节点之间是否真的互相连接、且连接对每个节点有价值。如果 100 万人各自用同一个工具但彼此不交互，价值随人数线性增长，本定律不适用。

作者自己给这条定律打了折：它假设每个节点对整个网络有同样的价值，而且每个节点都希望彼此联系——这两条在现实中通常不成立。所以它是量级模型，不是估值模型。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在评估一个网络型产品/社区/平台值多少钱、值不值得补贴早期用户。
2. 用户在判断"再拉多少人才会起飞"，或解释为什么早期增长慢、过了某个点突然加速。
3. 用户在两种产品形态或两个市场之间做选择：哪个有网络价值、哪个只是线性累加。
4. 用户要做平台战略，需要说明"为什么要先砸钱铺节点"。

### 语言信号

- "用户越多越值钱 / 这个有网络效应吗？"
- "我们现在 5 万用户，到多少才能起飞？"
- "要不要补贴早期用户 / 免费拉人？"
- "为什么前面很慢，过了某个点突然就快了？"
- "network effects / Metcalfe's law / value scales with the number of users"

### 与相邻 skill 的区分

- 与 `mm-network-effects` 的区别: 网络效应是定性描述——"用户增加会提升产品对每个用户的价值"；梅特卡夫定律是定量的粗略估计——价值按 n² 量级增长。前者判断是否成立，后者估算增长有多陡。
- 与 `mm-critical-mass` 的区别: 临界量是"网络跨过哪个点就能自持"的阈值概念；梅特卡夫定律描述的是价值随规模变化的**曲线形状**，可用于解释为什么越过阈值后会加速。

## E — 可执行步骤 (Execution)

1. **判断是不是真网络**
   - 检查节点之间是否存在有价值的连接；若各节点独立使用、彼此无交互，价值线性增长。
   - 完成标准: 明确回答"是/否"，并给出"连接"的具体定义（谁能对谁做什么）。
   - 判停条件: 若否，停止本 skill，改用线性价值估算。
2. **数节点，估连接**
   - 估算当前有效节点数 n 与实际活跃连接数；低频、单向、一次性连接要打折。
   - 完成标准: 给出 n 的量级与活跃连接占比。
3. **算增长弹性**
   - 按 n² 量级估算：节点翻倍时价值大约变成几倍，再除以获客成本看是否划算。
   - 完成标准: 给出量级估算而非精确数字，并明确算出"翻倍带来的价值增长 / 获客投入"。
4. **识别临界区间**
   - 结合留存与互动率，估算"网络开始自持"的规模区间，而不是单点。
   - 完成标准: 给出一个区间，并说明达到后应观察哪些指标（可转 `mm-critical-mass`）。
5. **标注过度简化的地方**
   - 明确提醒：定律假设每个节点价值相同、且所有节点都希望彼此相连，现实中通常不成立。
   - 完成标准: 至少指出当前场景下哪一条假设最不符合，以及它会让估算偏高还是偏低。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 节点间无连接或连接无价值（单机工具、纯内容消费型产品）——价值线性增长，用 n² 会严重高估。
- 需要精确估值或作为投资决策的唯一依据——这是量级模型。
- 网络已经很大但新增节点质量下降、连接稀疏——此时 n² 严重失真，实际可能接近线性。

### 容易误用的地方

- 书中明示：作者指出「这一定律过分简化了现实，因为它假设每个节点对整个网络有同样的价值，而且每个节点都希望彼此联系。」尽管如此，它仍是相当不错的模型。
- （推导，非书中明示）用 n² 论证补贴烧钱时最容易出错：若新增节点不活跃、不连接，实际带来的是 n 甚至更少，而不是 n²。

### 容易混淆的邻近模型

- **网络效应**: 定性 vs. 定量，见 A2 区分。
- **幂律分布（power-law distribution）**: 幂律说的是"少数节点占据绝大多数连接"，这恰恰是梅特卡夫定律的等价值假设失效的原因——真实网络的价值往往由少数枢纽节点决定。
