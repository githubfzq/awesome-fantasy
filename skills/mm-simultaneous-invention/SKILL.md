# 同步发明／多重发现（simultaneous invention / multiple discovery）

## R — 原文 (Reading)

> 这种现象被称为同步发明（simultaneous invention），也称为多重发现（multiple discovery）。
>
> — 《思维模型》, 第9章 > 秘密武器

---

## I — 方法论骨架 (Interpretation)

**相互独立的人在同一时期做出相似发现，或创办相似企业**——这就是同步发明／多重发现。书里的例子是牛顿与莱布尼兹几乎同时独立发明微积分，达尔文与华莱士独立发现自然选择理论。

**为什么成立**：当某项思想或技术诞生的**潜在条件已经成熟**，机会窗口就**同时向多人打开**。也就是说，发明不完全取决于某个天才的灵光一现，更多取决于"素材是否已经齐备"——一旦前置条件（知识积累、基础设施、成本下降、需求出现）到位，走到那一步的人往往不止一个。

由此得到关键推论：**"为什么是现在"（why now）能解释这种聚集**。因为条件成熟是一个时间点上的客观状态，所有站在相近位置上的人都会同时看见它。所以"为什么是现在"既是判断时机的工具，也是解释"为什么撞车"的工具。

**实践含义有三条**：

1. **你的想法大概率不是独家的**。发现竞品雷同时不必恐慌，也不必假定是泄密——独立撞车是常态。
2. **保密的价值被高估**。既然条件成熟时不只你一人行动，护城河不能建立在"没人想到"之上。
3. **真正值得问的是"为什么是现在"**：是哪项条件刚刚成熟？如果你答不出来，可能既不成熟也不独特。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业/立项时坚信"这个点子没人想到过"，需要检验这个假设。
2. 发现有竞品与自己的想法高度相似，怀疑泄密或感到挫败。
3. 判断一个方向现在做是不是时候，需要找出条件成熟的具体证据。
4. 写商业计划书或融资材料，要回答"为什么是现在"。
5. 评估一个机会窗口能持续多久——如果别人也能想到，多久会挤满。
6. 团队在争论要不要保密、要不要抢先公布。

### 语言信号 (用户的话里出现这些就应激活)

- "这个点子绝对没人想到过"
- "他们是不是抄我们的"
- "怎么突然冒出来好几家做一样的"
- "现在做这个时机对吗"
- "为什么是现在"
- "我们的想法还独特吗"
- "someone else is building the same thing / why now / is our idea still unique"

### 与相邻 skill 的区分

- 与 `mm-why-now` 的区别: **"为什么是现在"是判据/提问**，本 skill 是被它解释的现象。书中明确说"为什么是现在能解释这种聚集"——即 why now 是原因，同步发明是结果。判断时机用 why-now，理解撞车用本 skill。
- 与 `mm-secret` 的区别: 秘密模型讲的是**寻找别人没看到的真实认知**；本 skill 对它构成重要约束——既然条件成熟时会有多人同时行动，"秘密"的稀缺性比想象中低，不能靠保密维持。
- 与 `mm-first-mover-advantage` 的区别: 先发优势处理的是"既然会撞车，抢先有没有用"以及抢先可能反成劣势；本 skill 只解释撞车**为什么必然发生**。前者是策略层，后者是现象层。
- 与 `mm-idea-maze` 的区别: 创意迷宫讲的是**在创意空间中导航**的方法；本 skill 说明为什么你不是迷宫里唯一的人，以及为什么条件成熟会让多人同时找到出口。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先区分"独立撞车"与"实际泄密"**
   - 完成标准: 检查时间线、公开痕迹、人员流动、文档往来。明确给出判断：若双方起始时间相近且无接触路径，倾向独立发明。
   - 判停条件: 若确有证据指向泄密，本 skill 只用于说明背景，转法律/保密处置。
2. **把"独家想法"假设推倒，列出同赛道的人**
   - 完成标准: 实际搜索并列出至少 3 个在做相近事情的个人/组织，说明他们的切入点。核心是打破"只有我想到"的幻觉。
3. **追问"为什么是现在"——找出刚成熟的条件**
   - 完成标准: 列出 2-3 项最近才具备的前置条件（技术成本下降、基础设施普及、法规变化、需求出现、人才可得）。若一条都列不出，明确告知：条件可能尚未成熟，或这根本不是个新机会。
4. **重新定位竞争优势来源**
   - 完成标准: 明确说明既然"没人想到"不可依赖，优势应改建立在执行速度、独有数据/渠道、产品市场匹配、团队等不可同时复制的方面。可结合 `mm-first-mover-advantage` 说明抢先的真正价值在于率先实现产品/市场匹配，而非抢先发布。
5. **估计窗口长度**
   - 完成标准: 基于第 2 步列出的同赛道者数量与第 3 步的条件成熟度，给出窗口期估计与关键观察信号（如新进入者增速、融资事件密度）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 已有确凿泄密证据的情形——那是法律与保密问题，不是统计现象。
- 需要判断该不该抢先发布——用先发优势与先发劣势。
- 真正的个人独创领域（纯艺术创作、个人风格表达）——条件成熟度模型不适用。
- 用它否认所有首创——同步发明是统计倾向，不否认具体个案中的首创。

### 容易误用的地方

- 书中未给本模型的边界说明，以下均为基于机制推导。
- （推导, 非书中明示）用它作为泄密的挡箭牌。独立撞车是常态，但**不排除**真实泄密；应当先查证据再下结论，而非直接套用。
- （推导, 非书中明示）推到"想法毫无价值"的极端。模型否定的是**想法的稀缺性**，不是执行与洞察的价值；同样的想法在不同团队手里结果差异巨大。
- （推导, 非书中明示）忽略"条件成熟"需要被具体指认。若答不出是哪一项条件刚刚成熟，这个模型就不该被用来支撑"时机已到"的结论。
- （推导, 非书中明示）用它否定保密的**全部**价值。它削弱的是"靠没人想到来维持优势"，短期保密在特定情境（如谈判、投标）中仍有作用。

### 容易混淆的邻近模型

- **为什么是现在（why now）**: 是解释本现象的判据；本 skill 是被解释的现象。
- **先发优势（first-mover advantage）**: 处理撞车之后的策略选择；本 skill 只解释撞车为何必然。
