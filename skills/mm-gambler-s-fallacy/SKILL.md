# 赌徒谬误（gambler's fallacy）

## R — 原文 (Reading)

> 这个谬误得名于轮盘赌玩家，他们认为只要多转几把，轮盘转出红或黑的概率就会对自己有利。假设你看见连续转出了十把黑，存在这种谬误的人就会心存期待，认为下一把转出红的概率会更高。而事实上，每把转出红或黑的概率并没有改变。
>
> — 《思维模型》, 第5章 > 警惕小数定律

---

## I — 方法论骨架 (Interpretation)

人们把"大数定律"用错了地方。大数定律说的是：随着次数趋于无穷，平均结果会贴近真实概率；它并不承诺在短期里存在一股把结果"拉回去"的力量。于是看見连出十把黑，就觉得下一把该出红——好像概率会记账、会补偿。

对于**独立**事件，每一次的概率都从头开始，历史结果不携带任何关于下一次的信息。轮盘没有记忆，硬币也没有。

关键判据是独立性检验：**这件事的结果，会不会被上一次的结果改变？** 若不会，那么"该轮到我了"这句话没有物理基础。作者还提醒反面同样会犯错：也不该根据少许短期成果做出长远预期。

有意思的是，这种谬误不只出现在赌场——研究发现移民法官若在前两起案件中批准了庇护，第三起就不太可能批准；贷款专员与棒球裁判身上也有同样的模式。

---

## A1 — 书中的应用 (Past Application)

### 案例: 轮盘赌、移民法官与棒球裁判

- **问题**: 面对一连串相同结果，人会本能地预期下一次会反转。
- **方法论的使用**: 作者先以轮盘赌命名这个谬误——连出十把黑之后，人们期待下一把更可能出红，而事实上每把的概率并未改变。随后引《经济学季刊》的研究：移民法官若在前两起案件中批准了庇护，第三起就不太可能批准；同样的模式也出现在贷款专员与棒球裁判身上。作者还举了一个日常版本：学生连选四个 B 也会浑身不对劲。
- **结论**: 独立事件没有"补偿机制"；把短期序列的偏离当成概率已经改变，会系统性地做出错误判断。作者同时提醒：也不该根据少许短期成果做出长远预期。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 抽奖、抽卡、转盘、掷骰子：连着没中，觉得"下一次总该中了"。
2. 面试/审批/投稿连着被拒，于是认为"下一次概率更高"（或更低）。
3. 投资中连跌后加仓，理由是"跌了这么多，该反弹了"。
4. 质量控制或风控中，认为"刚出过一次事故，接下来一段时间会安全"。

### 语言信号 (用户的话里出现这些就应激活)

- "连着好几次都……，这次总该……"
- "手气该转了吧"
- "已经很久没出现了，概率应该很高了"
- "跌这么多了，该反弹了"
- "I'm due for a win"

### 与相邻 skill 的区分

- 与 `mm-law-of-small-numbers` 的区别: 小数定律是**用小样本去估总体**（三次正面就断言硬币不公）；赌徒谬误是**用历史序列去预测下一次**（连出黑就押红）。
- 与 `mm-regression-to-the-mean` 的区别: 均值回归说的是"极端成绩之后多半更普通"，因为极端里含运气；赌徒谬误说的是"概率本身变了"，这是对独立性的误判。两者外表相似，机制完全不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定事件序列并检验独立性**
   - 完成标准: 明确写出"每次结果是否受上一次影响"，并说明机制（有无记忆、有无消耗）。
   - 判停条件: 若事件并不独立（如牌堆不放回、设备磨损、人因疲劳），停止，本 skill 不适用，改用状态变化分析。
2. **复述每次的真实概率**
   - 完成标准: 给出下一次的客观概率，并明确指出它与历史序列无关。
3. **识别表面的"纠正"其实来自什么**
   - 完成标准: 若确实观察到回落，判断它是不是均值回归（极端里含运气）或真实的因果变化，而不是概率补偿。
4. **改写决策**
   - 完成标准: 把"该轮到我了"替换为基于期望值与基础比率的判断。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 事件之间并不独立：抽牌不放回、库存有限、设备状态随使用变化、"抽到即移除"的池子。
- 存在真实的状态变化或趋势（选手状态下滑、市场基本面改变），此时序列确实携带信息。

### 书中警告的失败模式 / 容易误用的地方

- 作者同时提醒反面：**"你也不该根据少许短期成果做出长远预期"**——两个方向都会犯错。
- （推导，非书中明示）不要把"连出十把黑"与"出千/设备故障"混为一谈：极端序列确实可以成为**怀疑独立性**的理由，合理的下一步是去检验机制，而不是押反面。

### 容易混淆的邻近模型

- 小数定律（law-of-small-numbers）：用小样本推断总体规律。
- 均值回归（regression-to-the-mean）：极端后回落的数学必然，而非概率补偿。
