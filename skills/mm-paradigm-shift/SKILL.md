# 范式转换（paradigm shift）

## R — 原文 (Reading)

> 新的科学真理的胜利不是靠反对者的信服和领悟。不如说是因为它的反对者终于死了，而熟悉它的新一代成长起来了。
>
> — 《思维模型》, 第1章 少犯错 > 进步总在葬礼后

---

## I — 方法论骨架 (Interpretation)

普朗克这句被反复引用的话（书中以类似表述呈现），描述的不是"新理论说服了旧理论的支持者"，而是**支持者的更替**。库恩在《科学革命的结构》里给出的机制是这样的：

1. **常规科学期**: 一个范式（共享的解释框架、问题清单、评价标准）稳定运行，研究者在其内部解谜。
2. **反常积累**: 出现旧框架解释不了的现象。初期的典型反应是**忽略或抹消**——把它们当成测量误差、个案、暂时无法解释的例外，塞进旧框架的角落里。
3. **危机**: 反常堆积到无法再被忽视，学科陷入危机，人们开始尝试替代框架。
4. **转换**: 新范式确立，进入新的稳定期。

关键机制在于**既得利益者的顽固**。旧范式的权威把自己的声誉、教职、资助、方法论都投在了旧框架上，接受新框架意味着承认自己一生的方向错了。因此他们会坚持到退出舞台为止——这就是"进步总在葬礼后"的字面意思：**转换的速度受制于人员的更替速度，而不只是证据的强度**。

这解释了一个反直觉的现象：新范式往往不是由本领域的资深者提出的。局外人不深信现有范式，也不怕声誉受损，因此更容易做出突破（书中在"证实偏差"一节里明确指出了这一点）。

关键判据（用于区分两种反常）：
- **可吸收的例外**: 被当作例外塞进旧框架，旧框架的解释力基本不受影响。
- **转换的前夜**: 反常正在催生新框架——不只是"解释不了某件事"，而是**已经开始有人用一个不同的框架解释它，且这个框架也能解释旧框架解释得了的东西**。

书中还提醒了一个重要的对称性：魏格纳和塞麦尔维斯的理论**本身确有缺陷**，说明新范式在初期往往不完善，不能因为新理论有毛病就判定它是错的。

## A1 — 书中的应用 (Past Application)

### 案例: 魏格纳的大陆漂移说与塞麦尔维斯的洗手主张
- **问题**: 作者要说明范式转换是混乱、坎坷、跨越数十年的过程，且新理论的提出者往往生前得不到承认。
- **方法论的使用**: 两个平行案例。其一，魏格纳提出大陆漂移说，被地质学界压抑约 40 年——当时学者宁可坚持没有实证支持的"冈瓦纳陆桥"理论，也不愿深究大陆漂移；直到古地磁学提供了数据，范式才完成转换。其二，塞麦尔维斯发现洗手能大幅降低产褥热，主张被同行拒绝，他死后约 20 年巴斯德证实细菌理论，其主张才被接受。
- **结论**: 转换的阻力不只来自证据不足，更来自守旧派的既得利益。同时书中指出这两人的理论本身都有缺陷——新范式初期往往不完善，这既解释了阻力为何看起来"有道理"，也提醒判断者不要把"不完美"等同于"错误"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **所在行业出现了解释不了的新现象**: 原有方法论持续失效、指标与现实的关联断裂、用户行为无法用现有模型解释。
2. **有人提出一个被主流排斥的新框架**: 用户需要判断该跟随、观察还是抵抗（如 AI 对某个行业的冲击、新的技术路线）。
3. **自己提出的想法被领域内权威否定**: 需要判断这是"我错了"还是"范式阻力"。
4. **评估一个"颠覆性"说法的真伪**: 大量说法自称范式转换，需要一套判据筛掉伪装的时髦概念。
5. **组织内部的方法论之争**: 新旧两派各执一词，需要看清争的是什么（是证据之争还是框架之争）。

### 语言信号 (用户的话里出现这些就应激活)

- "行业要变天了"
- "这套老方法解释不了现在的情况"
- "他们就是不接受，怎么解释都没用"
- "这是不是一次范式转换？"
- "新出来的这个东西会不会颠覆我们"
- "专家都说不行，但我总觉得有戏"
- "paradigm shift" / "the old model doesn't explain this" / "they just won't accept it"

### 与相邻 skill 的区分

- 与 `mm-confirmation-bias` 的区别: 证实偏差是**个体层面**的筛选证据倾向；范式转换是**共同体层面**的现象——一个领域集体性地忽略反常。证实偏差是范式阻力得以维持的心理机制之一。
- 与 `mm-disruptive-innovations` 的区别: 颠覆性创新是**市场/商业**层面的更替（低端切入、最终取代在位者）；范式转换是**认识论**层面的更替（解释框架本身换了）。一次技术变革可能只造成前者而不造成后者。
- 与 `mm-semmelweis-reflex` 的区别: 塞麦尔维斯反射是"自动拒绝违反既有范式的新发现"这一**具体反应**；范式转换是整个**历史过程**（含危机、转换、稳定期）。反射是范式维持自身的免疫机制。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出旧范式解释不了的反常，并计数**
   - 完成标准: 具体列出 3-5 条反常现象，每条写清"旧框架预测什么、实际观察到什么"。
   - 判停条件: 若只有个别反常且已被合理解释为误差/个案，停止——这是常规科学，不是危机。
2. **判断这些反常是被"吸收"还是被"抹消"**
   - 完成标准: 对每条反常标注：是给了真实解释（吸收），还是被贴标签搁置（"个案""数据有问题""暂时无法解释"）。被抹消的比例越高，越接近危机期。
3. **检查是否已存在替代框架，且它覆盖旧框架的解释力**
   - 完成标准: 若能指出一个新框架，它既解释了旧框架解释得了的现象，又解释了那些反常——范式转换的条件才真的成立。
   - 判停条件: 若新说法只能解释反常、解释不了旧现象，那它还不是一个候选范式，只是一个观察。明确告知用户，不要升级判断。
4. **识别阻力来源：证据之争还是既得利益之争**
   - 完成标准: 明确写出反对者的具体理由，并判断这些理由是证据性的（可检验、可回应）还是立场性的（涉及声誉、投入、身份）。
   - 判停条件: 若反对理由主要是证据性的，本 skill 的"范式阻力"解释不成立，应回到证据检验（去风险化）。
5. **允许新范式不完美**
   - 完成标准: 明确列出新框架当前的缺陷，并说明"有缺陷 ≠ 错误"——书中用魏格纳与塞麦尔维斯说明新范式初期往往不完善。同时评估这些缺陷是**可修补的**还是**根本性的**。
6. **给出行动建议：跟随 / 观察 / 抵抗**
   - 完成标准: 基于以上判断给出明确建议，并写明触发重新评估的信号（什么证据出现后应改变立场）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **普通的渐进改良**: 效率提升 20%、新增一个功能、流程优化——这是常规科学，不是范式转换。把它叫成范式转换会稀释概念。
- **一时风尚 / 营销话术**: 大量新概念自称"范式转换"。若没有旧框架解释不了的反常堆积，它就不是。
- **需要快速决策的日常运营问题**: 范式转换以数十年计，用它来思考下季度的排期是错配。

### 书中警告的失败模式 / 容易误用的地方

- **书中未给明确边界，但指出魏格纳与塞麦尔维斯的理论本身确有缺陷，说明新范式初期往往不完善**（`boundary` 字段原文）。这有两面含义：不能因缺陷否定新理论；也不能因为是新理论就豁免检验。
- （推导, 非书中明示）**把"我被打压"直接等同于"我是魏格纳"**: 这是最诱人的误用。绝大多数被否定的想法确实只是错的。第 4 步（区分证据之争与立场之争）就是为这道自我辩护设的关卡。
- （推导, 非书中明示）**低估转换的时间尺度**: 大陆漂移说被压抑了 40 年。若用户以"范式转换"为由押上全部资源，需要考虑自己能否撑过这个时间尺度。
- （推导, 非书中明示）**用"葬礼后进步"来正当化不沟通**: 知道旧派不会改变，不等于可以放弃论证与记录。新范式最终胜出靠的是数据与新一代，仍需把证据留下来。

### 容易混淆的邻近模型

- **颠覆性创新（disruptive-innovations）**: 商业/市场层面的取代；范式转换是解释框架的更替。可同时发生也可以只有其一。
- **塞麦尔维斯反射（semmelweis-reflex）**: 是范式对新发现的免疫反应，属于范式转换过程中的一个环节。
