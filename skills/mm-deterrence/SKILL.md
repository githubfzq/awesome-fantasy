# 威慑（deterrence）

## R — 原文 (Reading)

> 这套模型始于"威慑"（deterrence），或者说是靠威胁来阻止（制止）对方的行动。
>
> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

威慑是靠威胁后果来阻止对方采取某种行动。它不消灭对方的能力,而是改变对方的**收益矩阵**:让对方认为行动的代价高于收益,从而自己选择不做。

可信的相互确保毁灭(MAD)就是一种强威慑——但威慑本身更通用,可以是单方面的(法律对潜在犯罪者、平台对违规卖家)。

最关键、也最反直觉的一点是:**威慑效力主要来自"被抓到的确定性",而不是"惩罚的严厉程度"**。研究显示,确信会被逮捕定罪比可能受到的惩罚更有威慑力;刑期加长甚至可能增加再犯。原因不难理解:人对"会不会被抓"的概率判断远比对"判几年"的想象敏感,而且重刑往往伴随更复杂的程序,反而降低了确定性。

作者强调的难点:必须评估威慑是否真的有效、会不会带来意外后果——很多惩罚措施会催生规避行为(参见眼镜蛇效应、不当诱因)。

关键判据:**问对方"觉得会被抓到的概率有多大"**,而不是"惩罚够不够狠"。

---

## A1 — 书中的应用 (Past Application)

### 案例: 三振出局法、存款保险与沃尔玛压价

- **问题**: 怎么用威胁后果来阻止某些行为?
- **方法论的使用**: 作者举了三个不同领域的例子——刑事司法的"三振出局"法(用累进重罚威慑惯犯);存款保险(用制度安排威慑银行挤兑,让储户不必抢着取钱);沃尔玛以规模压价(用潜在的价格战威慑新进入者)。
- **结论**: 威慑的手段不限于惩罚,可以是制度设计、能力展示或结构性优势;共同点是让对方重新计算行动的代价。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户打算立规矩、加处罚来遏制一类违规行为(抄袭、作弊、违约、刷单、乱停车)。
2. 用户已有的惩罚措施看起来越来越严,违规却没减少,需要诊断。
3. 用户想阻止某个竞对/合作方的某种行为,在考虑"要不要先放狠话"。
4. 用户在设计制度(保证金、违约金、黑名单),想知道怎么设计才真的有效。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要立个规矩 / 加大处罚力度"
- "罚得还不够狠,所以没人怕"
- "怎么才能让他们不敢这么做"
- "杀鸡儆猴 / 以儆效尤"
- "违约金额定多少合适"
- "deter them" / "crack down on" / "tougher penalties"

### 与相邻 skill 的区分

- 与 `mm-mutually-assured-destruction` 的区别: 威慑通常是**单方面**的(我有能力惩罚你,你没有对等筹码),MAD 是**相互的对称**结构;若双方互相能毁灭对方,改用 MAD。
- 与 `mm-cobra-effect` / `mm-perverse-incentives` 的区别: 那两个模型描述"激励/惩罚设计催生出更坏的规避行为",威慑描述**意图本身**;设计威慑时必须预判会不会触发前者——作者强调要评估会不会带来意外后果。
- 与 `mm-red-line` 的区别: 红线是"划定不可逾越的界限并公开",是威慑的一种**表达形式**;威慑是机制,红线是它的沟通手段。

## E — 可执行步骤 (Execution)

1. **明确要阻止的行为与对方的计算方式**
   - 完成标准: 写出具体行为、谁在做、他们从中能得到什么收益。
   - 判停条件: 若双方互相握有毁灭性筹码,改用相互确保毁灭。
2. **先算"被抓到的确定性",再谈惩罚力度**
   - 完成标准: 给出对方当前感知的被抓概率估计,并明确指出——提升这个概率比加重惩罚更有效;列出具体的提高确定性措施(监测、留痕、抽查、公开通报)。
3. **检查惩罚力度与确定性的组合**
   - 完成标准: 明确警告"刑期加长甚至可能增加再犯";若现行惩罚已经很重却无效,优先把资源从加重处罚转向提高查处率。
4. **预判意外后果与规避路径**
   - 完成标准: 列出对方可能的三条规避方式(转移阵地、更隐蔽、钻规则漏洞),并逐条给出应对;明确指出这是作者强调的必答题——"威慑会不会带来意外后果"。
5. **设验证环节**
   - 完成标准: 给出可观测的衡量指标与复核时间点,明确"怎么知道威慑真的有效",而不是靠感觉。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 双方互相握有毁灭性筹码的对称对峙——用相互确保毁灭。
- 行为本身是无意的、由能力或流程缺陷导致的(不是算计后的选择):威慑惩罚不了无心之失,要解决根因。
- 对方根本不相信你会执行威胁:没有可信度的威胁不是威慑,只是噪声。

### 书中警告的失败模式 / 容易误用的地方

- 作者强调难点: 必须评估威慑是否真的有效、会不会带来意外后果。(书中明示)
- 研究显示: 确信会被逮捕定罪比可能受到的惩罚更有威慑力;刑期甚至可能增加再犯。(书中明示)
- 常见误用:把"加大惩罚"当成唯一杠杆——在查处率很低时,把刑期从 3 年提到 10 年几乎没有边际效果。(推导,非书中明示)

### 容易混淆的邻近模型

- 与相互确保毁灭: MAD 是相互的、对称的;威慑可以是单方面的。功能上 MAD 是一种极强的威慑。
- 与眼镜蛇效应: 眼镜蛇效应是威慑/激励设计失败后的典型症状(为赏金养蛇),设计威慑时必须预判它。
