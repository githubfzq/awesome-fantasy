# 后果-信心矩阵（consequence-conviction matrix）

## R — 原文 (Reading)

> 如果后果微乎其微，而你对自己的决定没什么信心，那就应该选择委派。也就是彻底委托给别人，让别人去犯错，从错误中汲取经验。反过来，如果显然后果严重，而你非常确信自己的决定是正确的，那就不该任由下级员工犯错。
>
> — 《思维模型》, 第8章 > 熟能生巧

---

## I — 方法论骨架 (Interpretation)

这是一个 2×2 决策矩阵，两条轴是：**决策后果的严重性** × **你对自己决策的信心程度**。它回答一个管理者每天都要回答的问题：这件事，我亲自拍板还是放手？

两个象限给出了明确指令：

- **后果轻微 + 信心不足 → 委派**。彻底委托给别人，让别人去犯错、从错误中汲取经验。既然你自己也不确定，强行拍板没有信息增益，反而剥夺了别人的学习机会。
- **后果严重 + 信心充足 → 亲自拍板**。不该任由下级员工犯错。你已经知道正确答案，让对方去试错只是把可避免的损失变成学费。

这个矩阵还有第二重用途，是它容易被忽略的价值：**它是为团队制造刻意练习机会的工具**。位于"信心充足、后果轻微"象限的活动最适合做刻意练习——因为任务恰好达到或略超对方的能力极限，你又能给出准确反馈（你有信心），而失败也没有大碍。三要素同时满足。

关键判据是拆成两个独立问题，不要混在一起问：

1. **这件事做错了，后果有多大？**（严重 / 轻微）
2. **我有多确信正确答案是什么？**（信心足 / 没信心）

很多决策纠结，是因为把"我不放心"当成了"后果严重"，或者把"我很在行"当成了"必须我来做"。

## A1 — 书中的应用 (Past Application)

### 案例: 让孩子去做失败也不会受伤的事

- **问题**: 作为家长/带队人，不知道哪些事该放手让孩子自己去做。
- **方法论的使用**: 作者用矩阵筛选——尽可能让孩子去做**即使失败也不会受伤**的事，例如自己去店里买东西、自己做午餐。这些活动落在"后果轻微"一侧，同时作者作为家长对正确做法有充分信心（信心充足），因此可以给出高质量反馈。
- **结论**: 后果轻微且自己有把握的任务，是给他人练习的最佳区间；既不至于造成实质伤害，又能提供有效指导。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 管理者纠结"这个方案要不要我直接定，还是让下属自己拿主意"。
2. 想培养团队成员，但不知道该把哪类任务交出去练手。
3. 家长/导师在判断哪些事该让孩子/学生自己尝试。
4. 用户感到"什么都得我亲自来"，需要一套放手的判据。

### 语言信号 (用户的话里出现这些就应激活)

- "这事我要不要亲自盯"
- "让他自己决定我放心不下"
- "要不要给他试错的机会"
- "我怕他做砸了"
- "什么都得我来拍板，累死了"
- "Should I delegate this or decide myself / let them fail"

### 与相邻 skill 的区分

- 与 `mm-eisenhower-decision-matrix` 的区别: 艾森豪威尔矩阵按"重要/紧急"排**自己的时间**；后果-信心矩阵按"后果/信心"决定**决策权归谁**，且第二重用途是选练习任务。
- 与 `mm-deliberate-practice` 的区别: 刻意练习规定训练的三要素；后果-信心矩阵负责从任务池里**挑出**适合当练习的那些（信心足 + 后果轻）。
- 与 `mm-reversible-vs-irreversible-decisions` 的区别: 可逆/不可逆按"能不能撤回"分类，用于决定决策速度；本模型按"后果与我方信心"分类，用于决定决策权归属。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确待决策的具体事项**
   - 完成标准: 写出一个具体的决策点（不是"这个项目"，而是"选 A 方案还是 B 方案"）。
2. **评估后果严重性**
   - 完成标准: 给出"严重 / 轻微"的判断，并写出最坏情况下的具体损失（金额、时间、关系、不可逆性）。
3. **评估自己的信心程度**
   - 完成标准: 给出"信心充足 / 信心不足"的判断，并说明信心来源（过往经验、数据、可验证的规则）。
   - 判停条件: 若"信心不足"且"后果严重"，说明既不该拍板也不该放任——需要先做信息收集降低不确定性，跳到步骤 5。
4. **定位象限并给出行动**
   - 完成标准: 输出二选一结论：委派（后果轻 + 信心不足）或亲自拍板（后果重 + 信心足），并写明委派时的授权边界（他可以错到什么程度）。
5. **顺带挑选练习任务**
   - 完成标准: 从当前任务池中标出 1-2 项"信心充足 + 后果轻微"的任务，指定给某人做刻意练习，并配套反馈安排。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要集体共识才能执行的决策——即使你信心十足，绕过共识会让执行落空。
- 已有明确授权规则与流程的常规事项，逐次判断反而降低效率。
- 后果严重且信心不足的情形下，本模型不直接给答案（象限中它只说"别拍板也别放任"），需要配合信息收集与专家咨询。

### 书中警告的失败模式 / 容易误用的地方

- 书中未提边界。以下是基于机制推导的警告，标明「(推导, 非书中明示)」：
  - 委派不等于甩锅：书中说"彻底委托给别人"，但委派后仍需提供反馈，否则只是把失败外包出去。
  - 把"我不放心"误判为"后果严重"，会导致过度亲力亲为，团队永远练不出来。
  - "后果轻微"的评估会随时间变化——某些任务前期轻微、后期严重，需要重新定位。
- 书中给出的明确指令是双向的：后果轻微且信心不足要委派；后果严重且信心充足不要任由下级犯错。

### 容易混淆的邻近模型

- **艾森豪威尔决策矩阵（Eisenhower decision matrix）**: 排自己的时间，不决定授权。
- **刻意练习（deliberate practice）**: 本模型为其挑选合适的练习任务。
