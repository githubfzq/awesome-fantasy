# 最后通牒博弈（ultimatum game）

## R — 原文 (Reading)

> 在大多数文化中，第二个人通常会拒绝低于总金额30%的分配方案，因为这被视为不公平。
>
> — 《思维模型》, 第7章 > 视角决定一切

---

## I — 方法论骨架 (Interpretation)

最后通牒博弈的规则:一方(提议者)提出分钱方案,另一方(应答者)只能接受或拒绝;拒绝则双方一无所获。

纯逻辑下,应答者应该接受任何大于零的分配——拿到 1 块总比 0 块好。但真实情况不是这样:在大多数文化中,低于总额 30% 的方案会被拒绝,因为它被视为不公平。

这揭示了什么:**公平感的驱动力足以让人牺牲自身利益去惩罚对方**。应答者宁可自己一分不得,也要让那个提出侮辱性方案的人一无所获。这不是非理性,而是在维护一种对社会有价值的规范——如果你接受了不公平,你就参与了让不公平成为常态。

对提议者的含义非常实际:一个"理性上对方应该接受"的悬殊方案,在现实中会被否决,让你连本来能拿到的那一大份也拿不到。

作者特别提醒:涉及家人(家务、遗嘱)或同事(薪酬、晋升)的决策尤其要顾及这种对公平的强烈渴望。这类场景最危险的地方在于,人们常误以为"都是自己人,不会计较"。

关键判据:**在提出分配方案前,先问"如果我是对方,我会不会把这当成侮辱"**,并以 30% 作为经验下限。

---

## A1 — 书中的应用 (Past Application)

### 案例: 10 美元的分配

- **问题**: 给你 10 美元,由你提出分给另一个人的方案,对方只能接受或拒绝,拒绝则两人都拿不到钱。给多少?
- **方法论的使用**: 纯逻辑上,对方应该接受任何正数;但实验反复显示,在大多数文化中低于总额 30% 的方案会被拒绝,因为它被视为不公平。
- **结论**: 提议者给出极低份额时,应答者宁可自己一分不得也要否决——公平感的驱动力足以让人牺牲自身利益去惩罚对方。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在分配合伙股权、项目奖金、团队功劳,准备拿大头并觉得"对方应该会接受"。
2. 用户在处理家庭事务:家务分工、赡养、遗嘱、遗产分配。
3. 用户在做薪酬、晋升名额、裁员补偿这类高度敏感的组织分配。
4. 用户想不通"我明明给了他好处,他为什么宁可不要"——被拒绝后复盘。

### 语言信号 (用户的话里出现这些就应激活)

- "他凭什么不同意,白给的钱都不要"
- "我出的力最多,拿大头不是应该的吗"
- "股权/奖金/遗产怎么分才不会翻脸"
- "他宁可两败俱伤也不接受"
- "分他一点点意思一下就行了吧"
- "they refused a free offer" / "that's not fair" / "how should we split it"

### 与相邻 skill 的区分

- 与 `mm-prisoner-s-dilemma` 的区别: 囚徒困境里双方**同时**选择、各自的背叛是占优策略;最后通牒是**序贯**的——一方先提、另一方否决,且公平感会让"理性"方案被拒。
- 与 `mm-nash-equilibrium` 的区别: 最后通牒博弈的均衡分析(给最少正数、接受)与真实人类行为严重不符,所以它恰恰是"纯均衡预测会失效"的典型案例;当模型预测与人的反应冲突时,信人。
- 与 `mm-distributive-justice` 的区别: 分配正义讨论"什么叫公平的分配"的规范理论,本模型给出一个可操作的**经验阈值(约 30%)**和被否决的真实后果;谈哲学用前者,谈"我这个方案会不会被掀桌"用本 skill。

## E — 可执行步骤 (Execution)

1. **确认真的是最后通牒结构**
   - 完成标准: 明确判断——对方是否只有"接受/拒绝"两个选项、拒绝是否让双方都归零、对方是否有可比的外部替代方案。
   - 判停条件: 若双方都能自由出价、有市场价格可参照,那是普通议价,改用谈判/BATNA 思路,不要套 30% 阈值。
2. **用 30% 校验自己的方案**
   - 完成标准: 算出对方所得占总值的比例,明确标注是否低于 30%;若低于,直接警告"这个方案大概率会被否决,你会连本来能拿到的那份也失去"。
3. **识别对方会不会把它当侮辱**
   - 完成标准: 明确回答"如果角色互换,我会怎么感受";特别注意书中的提醒——家人(家务、遗嘱)和同事(薪酬、晋升)场景下,公平渴望最强,千万别假设"自己人不会计较"。
4. **重设为可接受的方案**
   - 完成标准: 给出不低于 30% 的替代方案,并建议用**可解释的分配规则**(按贡献、按投入、按需求)来支撑比例——被解释过的方案比同样的数字更容易被接受。
5. **若已经翻车:复盘而非指责**
   - 完成标准: 明确指出对方的行为不是非理性,而是在维护"不接受不公平"这一规范;建议重启时先修复关系与尊重感,再谈数字。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 有可比的外部市场价格、双方都能自由议价的买卖:那是普通谈判,不存在"要么接受要么归零"。
- 对方是纯粹的利益最大化机器(算法竞价、完全匿名的单次金融交易):公平感不起作用。
- 一方明显没有否决权(事实上不能拒绝):那就不是最后通牒博弈。

### 书中警告的失败模式 / 容易误用的地方

- 作者提醒: 涉及家人(家务、遗嘱)或同事(薪酬、晋升)的决策尤其要顾及这种对公平的强烈渴望。(书中明示)
- 常见误用:用"理性上他应该接受"来给自己提悬殊方案找理由——模型恰恰说明这种理性预测在人类身上不成立。(推导,非书中明示)
- 30% 是跨文化的大致阈值,不是精确常数;具体情形下公平观差异很大,别把它当公式硬套。(推导,非书中明示)

### 容易混淆的邻近模型

- 与囚徒困境: 两者都是博弈论,但囚徒困境的失败源于**互不信任**,最后通牒的失败源于**公平感受到冒犯**;补救方式也相反——前者要改参数建立信任,后者只要把比例提到可接受区间即可。
- 与公地悲剧: 公地悲剧是多人对公共资源的过度索取;最后通牒是两方对一次性分配的否决权之争。
