# 动量（momentum）

## R — 原文 (Reading)

> 在物理学中，动量是质量与速度的乘积，而惯性只与质量成正比。
>
> — 《思维模型》, 第4章 > 别跟自然对着干

---

## I — 方法论骨架 (Interpretation)

动量和惯性都跟"质量"有关，但差了一个关键变量：速度。惯性只与质量成正比，动量是**质量 × 速度**。

这个区别带来几个有用的推论：

- 一个静止的重物，惯性很大但动量为零。它难推动，但一旦动起来，就会迅速获得可观的动量。
- 因为惯性不变，动起来的东西速度不容易改变——既不容易加速，也不容易刹车。

所以"大"和"在动"是两件必须分开看的事。作者由此给出两条实用判断：**已经在得势的事物值得加入**（借它的势头事半功倍）；**正在失势但根深蒂固的事物会缓慢衰落**（质量大、惯性大，但速度已经在反向）。

典型例子是传真：它不断失势，却因深植于商业流程而惯性巨大，衰落速度极慢。判据是同时看两件事——它的规模（质量）有多大、它的方向（速度）是正是负、有多快。

---

## A1 — 书中的应用 (Past Application)

### 案例: 传真机的缓慢衰落 / 加入刚起步的组织

- **问题**: 为什么一些明显过时的技术和做法迟迟不消失？为什么有些投入能事半功倍？
- **方法论的使用**: 作者用动量（质量×速度）解释：传真不断"失势"（速度为负），但因深植于商业流程而惯性巨大（质量大），所以衰落速度极慢；反过来，作者建议加入刚起步的组织，或创建利用新技术的新组织，借其发展势头（正向速度）事半功倍。
- **结论**: 判断一个事物要同时看质量与方向速度——大的东西不会立刻倒，但在动的东西才值得借力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在多个机会/组织/赛道之间做选择，想知道"哪个值得加入"。
2. 用户疑惑某个明显过时的技术、产品或模式为什么还没消失，想知道它会怎么退场。
3. 用户想借某个趋势的力，需要判断这个趋势是否真的在动、动得多快。

### 语言信号 (用户的话里出现这些就应激活)

- "现在加入这个赛道还来得及吗"
- "这个技术明明过时了，怎么还在用"
- "要不要借这波趋势做点什么"
- "它在走下坡路，但感觉还能撑很久"
- "should I jump on this bandwagon"

### 与相邻 skill 的区分

- 与 `mm-inertia` 的区别: 惯性只与质量有关，描述"抗拒改变"；动量还乘上速度，描述"正在朝哪个方向走、走得多快"。静止的重物惯性大但动量为零。
- 与 `mm-lindy-effect` 的区别: 林迪效应看"已存活多久→还能活多久"；动量看"当前方向与速度→该不该借力或撤离"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分别估计对象的"质量"：规模、嵌入深度、切换成本**
   - 完成标准: 给出质量的三项评估——用户/资产规模、被流程或习惯嵌入的程度、离开它的成本。
2. **判断"速度"的方向与大小：在增长、停滞还是衰退，有多快**
   - 完成标准: 明确方向（正/零/负）并给出可观测的速率指标（增长率、使用量变化、人才流入流出）。
   - 判停条件: 若完全无法观测速度，本模型判断力有限，退出。
3. **组合判断：大质量+正向速度 → 值得加入；大质量+负向速度 → 缓慢衰落**
   - 完成标准: 给出四象限式结论，并说明对用户的具体含义。
4. **给出行动建议：借势 / 撤离 / 观望**
   - 完成标准: 结论三选一，且附一条可验证的观察指标用于后续复核。
5. **提醒：大质量意味着刹车也慢，别把"还在"误读为"还在赢"**
   - 完成标准: 明确指出存在感不等于势头，需持续看速度指标。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需要判断改变难不难、不涉及方向时，用惯性就够了，引入速度反而是噪音。
- 短期噪声很大的指标（日活、股价），速率容易被误读，应看更长窗口的趋势。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示：惯性大的事物即使越过峰值也需要很长时间才衰落（报纸、有线电视、传真机、AOL 拨号上网、百视达门店）——"还没倒"不等于"还在赢"。
- （推导, 非书中明示）动量本身不保证方向正确：高速冲向悬崖的事物动量也很大，加入前必须独立判断方向的可持续性。

### 容易混淆的邻近模型

- 与飞轮（flywheel）混淆：飞轮描述动量如何被持续累积的机制，本模型是对当前"质量×速度"状态的静态刻画。
- 与网络效应（network-effects）混淆：网络效应是质量（价值）随规模增长的成因之一，本模型不解释质量从哪来。
