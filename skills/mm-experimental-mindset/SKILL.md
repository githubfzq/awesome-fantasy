# 实验思维（experimental mindset）

## R — 原文 (Reading)

> 你也可以通过接受实验思维（experimental mindset），简单地将这种方法付诸实践。最成功（且适应性最强）的人和组织都在不断完善自己的工作内容和方式，从而提高效率。

> — 《思维模型》, 第4章 > 开篇（师法自然）

---

## I — 方法论骨架 (Interpretation)

实验思维是把科学方法**降维成日常可执行的态度**：不是做正式实验、写方案、设对照组，而是保持一种"凡事都可以当成一个试验来跑"的持续姿态。

它的核心主张藏在原文后半句：**最成功且适应性最强的人和组织，都在不断完善自己的工作内容和方式**。注意是"不断完善"，不是"找到了最优解"——实验思维承认环境在变，所以不存在一劳永逸的做法，只有持续的微调。

它把"适应"从被动变成主动：不是等环境逼你变、被竞争对手打疼了才改，而是主动试错、提前演化。这就是为什么它与"反脆弱"天然相容——主动的小失败换取整体更强的适应力。

书中给的个人层面的例证很有说明力：作者本人作为高速发展公司的 CEO，工作内容从"打造产品"变成"打造公司"，再变成"打造可持续商业模式"——**岗位没变，但"该做什么"每过一段时间就被重新实验了一次**。实验思维在个人层面的表现就是：定期重问"我现在该做的事还是这件事吗"。

关键判据是：**看改动是被当作"一次性决策"还是"一轮试验"**。前者追求一次做对（于是一拖再拖、害怕失败），后者追求快速拿到反馈（于是敢小步试）。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 明知道现有做法效率不高，但不确定改成什么样，于是迟迟不动。
2. 想尝试新方法，但担心试错成本太大、怕把事情搞砸。
3. 业务增长停滞，需要找到新的突破点却不知从何下手。
4. 个人职业发展进入平台期，怀疑"我现在做的事还是不是该做的事"。
5. 团队陷入"我们一直是这么做的"的惯性，需要引入改变的机制。

### 语言信号

- "想换个做法，但不知道会不会更糟"
- "有没有低成本先试试的办法"
- "我们一直是这么做的，要不要改"
- "感觉到了瓶颈，但不知道该往哪使劲"
- "别人都在做XX，我们要不要跟"
- "experimental mindset / let's just try it / continuous improvement / iterate"

### 与相邻 skill 的区分

- 与 `mm-scientific-method` 的区别: 科学方法是**完整的规范流程**（假设—实验—分析—结论），实验思维是把它**简化后的日常态度**。需要可发表、可复现的严格结论用前者，日常工作改进用本 skill。
- 与 `mm-randomized-controlled-experiment` 的区别: 随机对照实验是**具体的验证工具**（设对照组、随机分配、测因果），实验思维是决定"要不要用工具去试"的**前置姿态**。先有实验思维，才有动力去做 RCT。
- 与 `mm-pivot` 的区别: 转型是**方向性的重大改辙**（往往是多次试验之后的结论），实验思维是**日常的小步微调**。频繁小试验是本 skill，改航向用转型。

## E — 可执行步骤 (Execution)

1. **把"要不要改"改写成"先试什么"**
   - 把用户那个大而模糊的改动念头，拆成一个可以在一两周内跑完的小试验。
   - 完成标准: 得到一个具体的试验描述，包含改什么、在哪个范围内改、持续多久。
   - 判停条件: 若改动完全不可逆（一次性重大决策），本 skill 只能作为辅助，需配合正式评估。
2. **为试验设定可观测的判据**
   - 明确"什么结果说明该继续、什么结果说明该放弃"，最好是一个数字。
   - 完成标准: 有一句话写清成功与失败的判定标准，且这个标准在试验开始前就定好。
3. **限定试验的爆炸半径**
   - 明确这个试验最坏会损失什么（时间、一小部分用户、一段预算），并确保可承受。
   - 完成标准: 能说出"最坏情况是……，可以接受"。
4. **跑完并诚实对照判据**
   - 到预定时间后，用步骤 2 定好的标准判定，不允许事后修改标准。
   - 完成标准: 得出继续/放弃/调整的明确结论。
5. **定期重问"我现在该做的事还是这件事吗"**
   - 用作者的亲身例证作提醒：工作内容从打造产品→打造公司→打造可持续商业模式，是不断被重新实验的结果。
   - 完成标准: 设定一个固定周期（如每季度）重问这个问题，并记录答案的变化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要严格因果结论的场合（药物有效性、政策效果评估）：必须做随机对照实验，态度代替不了方法。（推导，非书中明示）
- 不可逆且代价极高的决策（大额并购、不可逆的架构重写）：实验思维的"先试再说"在这里会低估风险。（推导，非书中明示）
- 有既定行业标准与安全规范的领域（医疗操作、航空流程）：这些领域不允许随意试错。（推导，非书中明示）

### 容易误用的地方

- 把"随便试试"当成实验思维。真正的试验必须**事前定好判据**，否则事后总能找到支持自己的解释。（推导，非书中明示）
- 只试验不复盘，试过就忘。原文强调的是"不断完善"——没有记录与判定的试验只是忙碌。（书中明示）
- 用实验思维逃避做决策。当信息已经充分、该拍板时，"再做个试验"可能是拖延的体面说法。（推导，非书中明示）

### 容易混淆的邻近模型

- 与科学方法：一个是日常态度，一个是有规范的完整方法。实验思维是科学方法的轻量版，代价是结论更弱。
- 与 A/B 测试：A/B 测试是实验思维最常用的**具体工具**；有思维没工具则流于口号，有工具没思维则只会在局部优化。
