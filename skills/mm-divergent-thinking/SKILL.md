# 发散思维（divergent thinking）

## R — 原文 (Reading)

> 它是发散思维（divergent thinking）的基础。发散思维是指，你积极尝试让思维发散开来，以便找出多种可能的解决方案。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

发散思维是主动把思维向多个方向撑开、以找出多种可能解决方案的思考方式,与之相对的是聚合思维(收敛到一个答案)。它是情景分析的基础动作。

书中给出的具体做法很反直觉:**开会只过一遍目标,然后就解散**——把人分成小团队,各自给一个提示(比如同一份调查数据)或让他们从零开始设计自己的思维实验,各自产出自己的情景设定,之后再汇总。

为什么要拆开:因为只要大家坐在一起讨论,最先被说出来的那个想法就会锚定全场,从众效应与群体思维会迅速压制异见,最后得到的"多种方案"其实是同一个方案的变体。分散独立发散,正是为了让不同人的不同信息真正被用上。

关键判据:发散阶段唯一的衡量标准是**覆盖了多大不同的空间**,而不是"哪个方案更好"。评估属于聚合阶段的事,两件事混在一起做,必然两件都做不好。

作者也点明:发散之后必须接聚合,把情景缩减到几个,再对留下来的深入。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做情景分析、战略预演、风险评估,只想到一两种未来,担心漏掉重要可能性。
2. 用户开会讨论方案,发现讨论五分钟就锁定了一个方向,想让团队真的产出不同意见。
3. 用户卡在某个问题里反复绕圈,需要一个结构化的方式打开思路。
4. 用户怀疑团队里有人有不同看法但没说,想把真实的分歧挖出来。

### 语言信号 (用户的话里出现这些就应激活)

- "想不出别的办法了"
- "除了 A 和 B 还有别的可能吗"
- "一开会大家的想法都差不多"
- "我想多列几种情景 / 多想几个方向"
- "怎么才能让大家真的说出不同意见"
- "let's brainstorm" / "divergent thinking" / "what are the alternatives"

### 与相邻 skill 的区分

- 与 `mm-convergent-thinking` 的区别: 发散负责把可能空间撑大(求异),聚合负责把选项缩减并深入(求优);两者必须**顺序执行**,不能同时进行。用户说"选哪个好"时用聚合,说"还有哪些可能"时用发散。
- 与 `mm-brainstorming` 的区别: 头脑风暴通常是一屋子人当场喊想法,发散思维在书中强调的是**先拆成小团队各自独立产出**再汇总,重点在独立性而非热闹程度。
- 与 `mm-scenario-analysis` 的区别: 情景分析是一整套方法(发散出多个情景 → 缩减 → 深入),发散思维是其中的第一步动作。

## E — 可执行步骤 (Execution)

1. **先把目标对齐,只对齐目标**
   - 完成标准: 用一两句话写清楚要解决的问题与判定边界,所有人确认;此时不讨论任何具体方案。
2. **拆开独立发散**
   - 完成标准: 把人分成小组(或让每个小组成员先独立写),给每组一个不同的提示(如同一份调查数据的不同切片、不同的思维实验起点),各自产出自己的方案/情景设定,过程中互不通风。
3. **按差异而不是按优劣汇总**
   - 完成标准: 把所有产出摊开,先做去重与聚类,得到一张"可能空间"清单;明确标注哪些是真正不同质的方向。
4. **交接给聚合**
   - 完成标准: 明确宣布发散阶段结束,把情景缩减到 2–4 个,再对留下来的做深入分析;禁止在这一步之前评判想法好坏。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 用户手上已经有一组备选方案,要做的是筛选和取舍——那是聚合思维。
- 问题存在唯一正确解或强合规约束(如报税流程、法律条款适用):强行发散只会制造无效选项。
- 时间极度紧张、需要立即决策时:完整发散流程成本过高,可简化为"再想一个反方向方案"。

### 书中警告的失败模式 / 容易误用的地方

- 书中强调发散之后必须接聚合,把情景缩减到几个再深入;只发散不聚合,产出就是一堆没人负责的清单。(书中明示)
- 常见误用:把发散开成了"大家一起在会上自由喊",结果第一个被说出的想法锚定全场。(推导,基于书中对独立性的强调,非书中明示)
- 常见误用:在发散阶段就开始评判优劣,导致少数派想法被过早淘汰。(推导,非书中明示)

### 容易混淆的邻近模型

- 与横向思维(lateral thinking): 横向思维强调换一个切入角度重构问题,发散思维强调在同一个问题下扩张解的数量;前者改问题,后者扩答案。
- 与头脑风暴(brainstorming): 高度重叠,区别在于书中版本强制要求"独立分组 + 事后汇总"。
