# 颠覆性创新（disruptive innovations）

## R — 原文 (Reading)

> 克莱顿·克里斯坦森展示了这样的颠覆性创新（disruptive innovations）是如何渐渐波及整个行业，促使新的行业冲击者占据市场主导地位，留下老牌企业尸横遍野的。

> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

这个模型描述的是一种特定的"改朝换代"路径，不是泛指一切技术更替。

它的起点是反直觉的：颠覆性技术在刚出现时，在**大多数主流购买者看重的指标上不如现有技术**——更贵、更慢、画质更差、功能更少。所以它一开始根本打不进主流市场，只能在主流客户看不上的边缘地带（低价、小众、非消费场景）活下来。

它靠什么活？靠一个主流技术**不重视的新属性**：便利性、便宜、简单、随身可得。这个新属性对边缘用户价值极高，对主流用户一开始价值为零。

关键的动态在于第二条曲线：新技术的价格与性能差距在**稳定缩小**。它不是静止地"便宜点"，而是沿着自己的改进斜率持续上移。一旦它跨过"足够好到能吸引大多数消费者"的那条线，市场就爆炸式增长，旧技术被迅速清场。

为什么在位企业几乎必然失败？因为应对它需要**主动牺牲自己当下最赚钱的业务**——采纳新技术意味着收入结构重置、渠道重训、利润骤降。理性地在位者会算这笔账，然后每一次都选择"再等等"。等到临界点已过，就再也来不及了。

判据有三条，缺一不可：(1) 在主流指标上当前更差；(2) 在另一个维度上明显更优；(3) 这个更优维度的改进速度足以追平主流需求。

---

## A1 — 书中的应用 (Past Application)

### 案例: 数码摄影挤垮柯达，智能手机相机再挤垮数码相机厂商

- **问题**: 要解释为什么行业龙头会成片地倒下，而不是被更强的同类对手击败。
- **方法论的使用**: 用"主流指标更差 + 新属性更优 + 差距持续缩小"这条路径去套：早期数码相机在画质上远不如胶卷，但胜在"立即可见、不用冲洗、可无限复制"；手机相机在画质上远不如数码相机，但胜在"永远随身、随时可拍可分享"。两轮都是同一个故事，只是主角换了一批。
- **结论**: 颠覆不是一次技术碾压，而是一轮从边缘往中心渗透、跨过临界点后爆发的过程；上一轮的颠覆者（佳能、索尼、尼康）在下一轮里成了被颠覆的老牌企业。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 行业里出现一项在画质/性能/精度等主流指标上明显更差，但因为便宜、方便、随身、免维护而开始被边缘客户采用的新技术，用户需要判断"这玩意儿会不会成事"。
2. 用户在一家在位企业，正在评估要不要主动上马一个会蚕食自己现有高利润产品线的新业务，纠结"现在动手是不是太早/代价太大"。
3. 创业者/投资人要判断一个"从低端/非消费市场切入"的打法，是否具备最终翻盘的可能，还是只是永远的边缘生意。
4. 用户复盘某个巨头的倒下（柯达、诺基亚、传统零售），想找出可迁移的结构性原因，而不是归因于"管理层愚蠢"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个东西现在还很粗糙，但会不会以后把我们干掉？"
- "我们要不要自己做一个便宜版来打自己的高端产品？"
- "他们从低端切入，能成吗？"
- "柯达/诺基亚为什么会死？"
- "这个新技术在关键指标上还不如我们，为什么投资人那么兴奋？"
- "This looks worse on every metric we care about — is it a threat?"
- "low-end disruption / disruptive innovation / innovator's dilemma"

### 与相邻 skill 的区分

- 与 `mm-s-curves` 的区别: S 形曲线描述单一技术的性能随投入先慢后快再饱和的形状，不区分谁是颠覆者谁是在位者；颠覆性创新讲的是**两条曲线交叉**以及交叉对组织决策的后果。
- 与 `mm-crossing-the-chasm` 的区别: 跨越鸿沟处理的是新技术如何从小众早期用户走向主流客户（采纳侧的推广问题）；颠覆性创新处理的是**在位者为什么理性地输掉**（结构侧的激励问题）。
- 与 `mm-technology-adoption-life-cycle` 的区别: 采纳生命周期刻画用户类型序列（创新者→早期大众→落后者），是描述性曲线；颠覆性创新额外给出"为什么在位者明明看见了也不动"的解释。
- 与 `mm-first-mover-advantage` 的区别: 先发优势讨论"早进入是否有利"；颠覆性创新恰恰说明在很多颠覆浪潮里，**先发并不重要，重要的是你在不在正确的那条改进曲线上**。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定主流性能指标**
   - 让用户列出当前主流客户真正买单的 2-3 个指标（画质、速度、精度、可靠性）。
   - 完成标准: 得到一张"主流价值维度清单"，且用户确认这是当下利润来源所在。
2. **给新技术做"更差/更优"双侧打分**
   - 在新技术的主流指标上打分（应更差），再找出它明显更优的另类维度（便宜、方便、随身、免安装、低门槛）。
   - 完成标准: 两侧各至少一项，且"更优"那一项是当前主流玩家**不重视或无法兼顾**的。
   - 判停条件: 若新技术在所有维度上都不差、只是推广慢 → 这不是颠覆性创新，跳到步骤 5 并转用 `mm-s-curves` / `mm-technology-adoption-life-cycle`。
3. **识别它正在吃下的边缘用户群**
   - 找出第一批买单的人是谁、为什么是他们在买、主流客户为什么不要。
   - 完成标准: 能说出"谁在用 + 主流客户为什么看不上"。
4. **估算差距收敛速度与临界点**
   - 问：这个新技术的改进斜率是多少？多久能跨过"足够好"那条线？跨越后市场会以多大速度重排？
   - 完成标准: 给出一个带时间尺度的判断（如"约 2-3 年内跨过主流可用门槛"），并标明不确定性。
5. **若在位者：算自我颠覆 vs 被颠覆两笔账**
   - 量化"现在动手"的代价（短期收入骤减、团队重训、转型动荡）与"等它跨过临界点再动"的代价（市场被清场）。
   - 完成标准: 两笔账都写成可比较的量级，并明确指出哪一边是不可逆的。
6. **输出决策建议 + 监测指标**
   - 给出"现在动 / 设触发条件再动 / 不动"的建议，并给出 2-3 个可观测的临界点信号（如某指标达到 X、某客户群开始迁移）。
   - 完成标准: 建议带明确触发条件，不是"保持关注"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **新技术在所有主流指标上都更强、只是贵**: 这是延续性创新（sustaining innovation），在位者通常能靠既有渠道和客户赢下来，套颠覆框架会得出错误的恐慌结论。
- **短期业绩或股价波动问题**: 这个模型的时间尺度是数年，解释不了一个季度的数字。
- **一次性政策/监管冲击导致的行业重排**: 驱动力来自外部规则而非"边缘性能曲线收敛"，用 `mm-regulatory-capture` 或 `mm-externalities` 更贴切。

### 书中警告的失败模式 / 容易误用的地方

- **尽早回应颠覆意味着重大动荡**: 短期收入骤减、从头培训，本质上是一次巨大的转型。书中明确点出这一点——所以"我们应该及早自我颠覆"这句话说起来轻巧，做起来是整个组织的重置，不能当成口号用。
- **把"便宜"误当成"颠覆"**: 便宜但没有改进斜率、永远够不到主流门槛的，只是低价替代品，不会改朝换代。（推导, 非书中明示）

### 容易混淆的邻近模型

- **延续性创新 vs 颠覆性创新**: 前者在主流指标上更强，后者在主流指标上更弱但靠新属性切入。判断时必须先回答"它在主流客户看重的维度上是更差还是更好"。
- **颠覆性创新 vs 范式转换（`mm-paradigm-shift`）**: 范式转换改变的是"什么问题值得问"，颠覆性创新改变的是"谁来供应"，市场结构仍在。
