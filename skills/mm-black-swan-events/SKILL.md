# 黑天鹅事件（black swan events）

## R — 原文 (Reading)

> 所谓的“黑天鹅事件”是指有重大后果的极端性事件（例如最终造成巨大的经济损失），但它出现的概率要比你最初预期的高得多。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

名字来自一个真实的历史误会：欧洲人几百年里都认定天鹅全是白的，直到在澳大利亚看到黑天鹅——"你以为它不存在，只是因为你没见过"。黑天鹅事件就是这种东西：**后果极端严重，但真实发生概率远高于你最初的估计**。

为什么我们会系统性低估它？作者给出三个来源：一是把**肥尾分布**当成正态分布，于是尾部概率被压到近乎为零；二是现实是多种分布叠加，却按单一分布估计（例如侏儒症、马凡氏综合征）；三是低估**连锁故障**（cascading failure）发生的概率与影响——一个节点倒下会带走一片。

它在决策上的用法很直接：在决策树里，对那些低概率、高影响的分支（比如破产），**审慎的做法是人为把概率估计调高**。因为你很可能是错的，而错的方向几乎总是"低估"。

关键判据：这件事的后果是否极端严重，且你的概率估计来自"我没见过它发生"而不是数据。两条都成立，就要人为上调。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做风险清单或压力测试，把某个高影响条目判为"概率太低不用管"。
2. 用户所在的系统刚发生了一起"说好的 X 年一遇"却连续出现的事件。
3. 用户在估一个从未发生过的失败模式（系统整体宕机、核心客户流失、政策一刀切）的概率。
4. 用户把"历史上没出现过"直接当成"不会发生"来论证。

### 语言信号
- "这个基本不可能发生"
- "说是百年一遇，结果三年三次"
- "我们从来没遇到过这种情况"
- "概率太小了，不用考虑"
- "最坏能坏到哪去？大不了……"
- "black swan" / "once in a lifetime" / "it'll never happen"

### 与相邻 skill 的区分
- 与 `mm-fat-tailed-distributions` 的区别: 肥尾分布是**造成黑天鹅的统计结构**（尾部比正态厚）；黑天鹅是**那个被低估的具体事件**。前者解释为什么，后者是要处理的对象。
- 与 `mm-antifragile` 的区别: 黑天鹅是"承认你会被击中"，反脆弱是"设计成被击中后变得更强"；识别风险用本 skill，设计结构用反脆弱。
- 与 `mm-scenario-analysis` 的区别: 情景分析构造多套自洽未来，但黑天鹅在定义上超出任何一套构造出的图景——做完情景分析不等于覆盖了极端事件。

## E — 可执行步骤 (Execution)

1. **把"不可能"条目单独拎出来**
   - 从风险清单中挑出后果极端严重、但被判为低概率的条目（破产、整体宕机、核心人离开、政策突变）。
   - 完成标准: 得到 3-5 条"高影响低概率"条目，每条写明后果量级。
2. **逐条追问概率从哪来**
   - 问：这个概率是算出来的，还是"我没见过它发生"？
   - 完成标准: 标注每条概率的来源；凡来源是"没见过"的，一律标记为可疑。
3. **人为上调并做重算**
   - 对可疑条目把概率上调（例如上调一个数量级），重算决策树或期望值。
   - 完成标准: 明确写出上调后的结果，并检查结论是否翻转。
4. **检查三个误判来源**
   - 逐一检查：是否把肥尾当正态？是否多种分布叠加却按单一分布估？是否低估连锁故障？
   - 完成标准: 对每条可疑概率至少命中一个来源，并写明修正方式。
5. **为翻转后的情形准备动作**
   - 完成标准: 针对概率上调后改变决策的那几条，给出具体的对冲/冗余/保险动作，而不只是"注意风险"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 已知概率的常规波动（日活起伏、正常退货率）：人为上调只会让决策瘫痪。
- 需要精确概率估计的场合：本 skill 只提醒"你可能低估了"，不提供准确数字。
- 把任何小概率事都叫黑天鹅，用它回避量化责任——那是滥用。

### 容易误用的地方
- 书中未给出边界说明，但指出它常出现在保险赔付、美国收入分布等肥尾分布中，且气候变化会持续改变"百年一遇"类事件的真实概率。（书中明示）
- 上调概率不等于放弃估计：如果人为上调后所有方案都变得不可接受，说明缺少的是结构性冗余，而不是更精细的数字。（推导，非书中明示）
- "百年一遇"是基于历史数据的估计，在条件已变（气候、技术、监管）时，历史频率本身就失效了。（推导，非书中明示）

### 容易混淆的邻近模型
- 与肥尾分布（fat-tailed distributions）：分布结构 vs. 具体事件。
- 与连锁故障（cascading failure）：连锁故障是黑天鹅的成因之一，不是同义词——有的黑天鹅来自单点极端值，不靠连锁。
