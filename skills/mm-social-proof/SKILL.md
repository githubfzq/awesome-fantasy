# 社会认同（social proof）

## R — 原文 (Reading)

> 你更可能去做看见别人在做的事，因为你有一种与生俱来的本能，希望成为群体中的一员
>
> — 《思维模型》, 第7章 > 影响力模型

---

## I — 方法论骨架 (Interpretation)

社会认同是西奥迪尼影响力六原则之一:人会把"别人正在这么做"当作判断正确与否的社会暗示,从而跟随多数人的行为。

它为什么成立:源于希望成为群体一员的本能(书中把它与"群内偏爱"in-group favoritism 关联起来)。在不确定的情境下,模仿他人是一条低能耗、高生存价值的启发式——"大家都在跑,那我也跑"通常是对的。

关键、也最容易被忽视的一点:**这个机制对不良行为同样有效,方向完全由你展示的"多数行为"决定**。暗示"很多人在做坏事",会提高坏事的发生率。所以措辞必须小心:一块写着"每年有大量游客偷走木化石"的公告牌,实际效果是提高了盗窃率。

作者甚至强调它会提高自杀率——媒体报道自杀之后,自杀率会上升。这不是比喻,是被反复验证的维特效应。

关键判据:**问"我到底在把什么行为展示为常态"**。任何一句描述现状的话,都是在给看到它的人下指令。

## A1 — 书中的应用 (Past Application)

### 案例: 酒店毛巾牌与石化森林公园的公告牌

- **问题**: 怎么让客人重复使用毛巾?怎么让游客不要偷木化石?
- **方法论的使用**: 酒店的提示牌改为"多数客人都会重复使用毛巾",把"别人正在做"这个社会暗示摆出来,重复使用率提升 25%。石化森林公园则做了反例——竖起强调偷窃行为普遍的负面公告牌,结果木化石盗窃率提高了 3 倍。
- **结论**: 社会认同是双向的。它既能扩散好行为,也能以同样的效率扩散坏行为;你描述"多数人在做什么",就等于在推广那个行为。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户用"大家都这么做""这是行业标准做法"来为一个决定辩护,需要区分这是真信号还是从众。
2. 用户在写公告、文案、安全提示、内部通知,想改变群体行为,需要检查措辞实际在暗示什么。
3. 用户看到某产品"销量第一""最多人选择",想判断这个信息值多少权重。
4. 用户在设计产品(排行榜、热销标记、实时购买提示),需要知道其效力与伦理边界。

### 语言信号 (用户的话里出现这些就应激活)

- "大家都这么做,应该没错"
- "别人都在买 / 都在用 / 都转行了"
- "销量最高 / 评价最多 / 最多人选择"
- "为什么越宣传不要做,做的人反而越多"
- "怎么让大家养成这个习惯"
- "everyone is doing it" / "most popular" / "best seller" / "social proof"

### 与相邻 skill 的区分

- 与 `mm-authority` 的区别: 社会认同是"跟随**多数人**",权威是"跟随**某个被公认的人/符号**";一个横向、一个纵向。看用户引用的是"大家"还是"专家/名人"。
- 与 `mm-bandwagon-effect` 的区别: 从众效应更偏描述"加入正在获胜的一方"这一倾向(常见于选举、舆论),社会认同强调"用他人行为判断什么是正确"这一更广的机制;前者是后者的子集。
- 与 `mm-in-group-favoritism` 的区别: 群内偏爱回答"我模仿**谁**"(我认同的那个群体),社会认同回答"我是否要模仿";两者常一起出现,书中也明确把它们关联起来。

## E — 可执行步骤 (Execution)

1. **确认用户是在跟随"多数人的行为"**
   - 完成标准: 明确指出用户引用的是"大家/多数人/行业普遍"还是某个具体权威。
   - 判停条件: 若引用的是专家、名头、头衔或粉丝量,改用权威模型。
2. **检查这个"多数"是否真实且可比**
   - 完成标准: 追问三个问题——这个"多数"是谁(样本与用户处境可比吗)、数据来源是否独立、是否只展示了被筛选过的部分(如只展示好评)。
3. **区分"减少不确定性"与"放弃判断"**
   - 完成标准: 明确判断:在不熟悉、后果小、且有大量可比样本的领域,跟随多数是高效启发式;在专业性强、后果大、或群体明显非理性时,跟随多数是放弃判断。
4. **若用户在写文案/公告:逐句检查暗示了什么常态**
   - 完成标准: 把每句描述现状的话改写成"这句话告诉读者:多数人在做 X",并把所有指向不良行为的描述改写为指向良好行为;明确指出措辞必须小心,避免暗示不良行为是常态(如把"很多人偷木化石"改为"绝大多数游客都把木化石留在原地")。
5. **补充警示**
   - 完成标准: 若涉及自杀、自伤、暴力等敏感行为的传播,明确指出社会认同会提高其发生率,报道与文案需遵循"不描述方法、不normalize行为"的原则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户是在服从明确的指令或专家判断——那是权威模型。
- 已有确凿的事实与数据可以判断对错时:拿"大家都这样"当理由是逃避论证。
- 群体明显处于非理性状态(泡沫、恐慌):跟随多数在此恰恰是最危险的。

### 书中警告的失败模式 / 容易误用的地方

- 作者强调它也会提高自杀率(媒体报道自杀后自杀率上升);因此措辞必须小心,避免暗示不良行为是常态。(书中明示)
- 石化森林公园的公告牌是教科书级反例:想减少盗窃的公告,把盗窃率提高了 3 倍。(书中明示)
- 常见误用:以为"负面警示"能遏制不良行为——描述不良行为的普遍性,本身就是在传播它。(书中明示)

### 容易混淆的邻近模型

- 与权威(authority): 两者都让人"跟着别人走",但一个的参照是多数人,一个的参照是被认证的个人;当网红代言时,两者会叠加(他既有很多粉丝,又是"权威")。
- 与稀缺(scarcity): 稀缺暗示"再不行动就没了",社会认同暗示"别人都在行动";电商页面常把两者放在一起制造紧迫感。
