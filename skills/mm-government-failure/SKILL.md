# 政府失灵 / 政治失灵（government failure / political failure）

## R — 原文 (Reading)

> 不幸的是，这些干预措施本身也可能失灵。这种结果被称为政府失灵（government failure）或政治失灵（political failure）。
>
> — 《思维模型》, 第2章 > 危险行业

---

## I — 方法论骨架 (Interpretation)

这个模型是市场失灵的**镜像与刹车**：市场会失灵，所以我们要干预；但干预者同样是人，同样受信息约束和激励驱动，所以干预本身也会失灵，有时失灵得更严重。

它之所以成立，有三个原因。第一，干预者没有比市场更多的信息——他不知道真实的成本曲线在哪。第二，干预者有自己的激励（连任、政绩、部门预算），这些激励与被治理的目标常常不一致。第三，也是书中反复强调的一点：**对于不同实体来说，风险和回报都是分开的**——做决定的人不承担决定的代价，承担代价的人没有参与决定。

抗生素的例子把三层叠在了一起：专利法本意是奖励创新，但"世界末日"储备药在被需要之前专利就到期，且须持续小批量生产、药品还会过期，制药公司几乎无利可图，于是多数大药企完全停止该领域研发。一个为纠正市场失灵而设计的制度（专利），在另一个维度上制造了新的失灵。

关键判据：**这个纠正手段有没有制造出新的、有时更严重的市场失灵？** 以及——**风险和回报是不是落在不同实体身上？**

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 设计补贴、税收优惠、产业扶持政策，需要预判套利路径。
2. 一项管制/审批落地后，出现了预料之外的规避行为或供给萎缩。
3. 讨论"要不要加强监管"时，需要评估监管本身的能力与激励。
4. 内部制度设计：考核、审批流、合规要求推出后部门行为扭曲。
5. 复盘一项政策/制度：初衷良好，结果更糟。

### 语言信号
- "补贴一发就有人专门来骗"
- "政策一出，大家都在钻空子"
- "管得太死，正经做事的也做不了了"
- "这个审批到底有什么用"
- "做决定的不承担后果"
- "government failure / regulatory capture / unintended consequences / perverse outcome"

### 与相邻 skill 的区分
- 与 `mm-market-failure` 的区别: 市场失灵是"没有干预时市场走不到好结果"，本 skill 是"有了干预反而更糟"；在书里两者是**必须连着看的一对**，不能只判定前者就动手干预。
- 与 `mm-perverse-incentives` 的区别: 不当诱因描述**被诱导出的行为**本身（应试教育、作弊），本 skill 聚焦于**干预主体这一层**——强调设计者自身的信息与激励约束，以及风险与回报错配。
- 与 `mm-regulatory-capture` 的区别: 管制俘获是本 skill 的一种**具体成因**（被管制者反过来控制了管制者），本 skill 涵盖更广，也包括信息不足、激励错配、意外后果。
- 与 `mm-cobra-effect` 的区别: 眼镜蛇效应强调方案反过来**放大了原问题**，本 skill 更宽：干预可能只是无效、昂贵、或制造了一个不同方向的新问题。

## E — 可执行步骤 (Execution)

1. **先确认原始的市场失灵是什么**
   - 写清：干预要解决的具体问题，以及它的量级。
   - 完成标准: 一句"这项干预是为了解决 X，规模约 Y"。
   - 判停条件: 若说不清原问题，先回到 market-failure，不要分析干预的副作用。
2. **列出干预改变了谁的行为**
   - 包括被治理对象、执行者、以及制定者自己。
   - 完成标准: 得到一张"主体—新获利/新避损方式"表，至少覆盖 3 个主体。
3. **做风险与回报的归属检查**
   - 对每项关键决定问：做决定的人承担后果吗？承担后果的人能影响决定吗？
   - 完成标准: 明确指出是否存在归属分离；分离越严重，失灵风险越高。
4. **做信息约束检查**
   - 问：制定者需要哪些信息才能做对？这些信息他拿得到吗？谁提供？
   - 完成标准: 列出 2-3 项关键不可得信息，并给出替代方案（用市场揭示信息，如拍卖、可交易许可）。
5. **预演三条失灵路径**
   - 至少覆盖：套利与骗补、被管制者俘获、供给萎缩或创新停滞。
   - 完成标准: 每条路径配一条兜底设计（事后核验、随机抽检、日落条款、退出机制）。
6. **设定日落条款与评估指标**
   - 完成标准: 写明"运行多久后评估、达到什么指标才算有效、达不到就终止"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 完全没有外部干预、纯市场自行运转的情形：那是市场失灵的分析对象。
- 干预刚刚落地、还没有观察到任何行为变化时：此时只能做预演，不能下失灵结论。
- 单纯的执行不力（人手不够、系统没上线）：那是执行问题，不是制度失灵（推导，非书中明示）。

### 容易误用的地方
- 容易滑向"既然干预也会失灵，那就什么都别管"：书中是在确认市场失灵**之后**加的一道检查项，不是取消干预的理由（书中明示的语境）。
- 作者借此提醒"对于不同实体来说，风险和回报都是分开的"，要警惕与风险有关的意外后果（书中明示）。检查风险归属是本 skill 最核心的一步。
- 容易只盯着被治理者的套利，忽略制定者与执行者自身的激励（推导，非书中明示）——第 2 步必须把制定者自己列进去。
