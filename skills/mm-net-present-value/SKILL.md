# 净现值（net present value, NPV）

## R — 原文 (Reading)

> 将未来所有年份的折现后收益相加，就能算出彩票奖金的净现值（net present value，简称NPV）。

> — 《思维模型》, 第3章 > 摆脱坏习惯

---

## I — 方法论骨架 (Interpretation)

净现值就是把未来所有年份的收益各自折成现值、再加总得到的那个总额。它提供了一个统一的比较基准：**把不同时点的钱放到同一把尺子上量**。

书中用它解决彩票奖金的经典难题：每年 100 万美元、共 2000 万美元的奖金，按 5% 折现率算出的 NPV 大约就等于今天一次性拿 2000 万美元；但如果折现率取 20%，同样这笔分期奖金的 NPV 只相当于今天的 500 万美元。也就是说，**"分期 2000 万"到底等于今天多少钱，完全取决于你用的折现率。**

由此得出关键判据，也是本模型最实用的一条：**如果你能以高于折现率的利率进行投资，选一次性结款并拿去投资更划算**；反之，如果你的投资回报率跑不赢折现率，分期领更安全。

但作者紧接着给出了一个重要的反例式提醒：**很多中奖者后悔选了一次性结款，因为拿到钱很快就花掉了。** 这是纯 NPV 算不出来的部分——NPV 假设钱会理性地被投资，而现实中的人会被即时满足带走。所以 NPV 是必要条件，不是充分条件。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 中了奖/拿到补偿金/拿到股权，要在"一次性结款"与"分期领取"之间做选择。
2. 收到"分 N 年付款"的报价或offer，需要判断它等价于今天多少钱。
3. 评估一个需要前期投入、后期逐年回收的项目到底划不划算（NPV 是否为正）。
4. 在多个跨年度投资方案之间做横向比较，需要一个统一口径。

### 语言信号

- "一次性拿还是分期拿，哪个划算"
- "这 20 年分期付清，实际上相当于现在给我多少钱"
- "这个项目的现值是多少，值得投吗"
- "他们说总共给我 2000 万，可我感觉没那么多"
- "买断和年金选哪个"
- "net present value / NPV / lump sum versus annuity / present value of payments"

### 与相邻 skill 的区分

- 与 `mm-discounted-cash-flow` 的区别: DCF 是**方法**（逐期折现的算法），NPV 是这个方法算出的**结果指标**（加总后的总额、再减去初始投入）。用户问"怎么折算"用前者，问"折算完总共值多少、选哪个方案"用本 skill。
- 与 `mm-discount-rate` 的区别: 折现率是**输入参数**。NPV 对折现率极度敏感——书中同一个 2000 万奖金，5% 与 20% 差出四倍。若用户纠结的是"折现率该取几"，转向折现率 skill。
- 与 `mm-hyperbolic-discounting` 的区别: 双曲折现描述人**实际**如何非理性地高估当下（描述性），NPV 是**应该**怎么算（规范性）。前者解释为何很多人明知 NPV 更高仍选错，后者给出理性基准。

## E — 可执行步骤 (Execution)

1. **列出两个方案各自的现金流时间表**
   - 方案 A（一次性）与方案 B（分期）分别按年份写出金额。
   - 完成标准: 两张年份—金额表，包含年份数与每期金额。
   - 判停条件: 若两方案都在同一时点发生，本 skill 不适用，直接比价。
2. **选定折现率**
   - 用一个现实中可获得的投资回报率作为折现率，并说明它由通胀、风险、机会成本中的哪部分主导。
   - 完成标准: 给出具体百分比及理由。
3. **逐年折现并加总，算出 NPV**
   - 现值 = 未来值 ÷ (1 + 折现率)^年数；加总得到 NPV。
   - 完成标准: 得到方案 B 的 NPV，并直接与方案 A 的一次性金额并列对比。
4. **做折现率敏感性检验**
   - 至少用三个折现率（如 5%/10%/20%）重算，观察结论是否翻转。
   - 完成标准: 标出两个方案等价的那个临界折现率，并明确告诉用户"你的选择取决于你能不能跑赢这个数"。
5. **补上非经济因素**
   - 明确提醒：书中指出很多中奖者后悔选一次性结款，因为拿到钱很快花掉。询问用户的自控能力与现金流需求。
   - 完成标准: 在结论后附加这条提醒，并视情况建议分期锁定（推导，非书中明示）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 不涉及跨期的静态比价：两个方案都在当下发生，直接比大小即可。（推导，非书中明示）
- 现金流本身高度不确定（早期创业、长周期研发）：NPV 会把猜测包装成精确数字，应改用情景分析。（推导，非书中明示）
- 用户真正的问题是"我控制不住花钱"：那是自控问题，算得再准也会被行为偏差吃掉，应转向双曲折现/现时偏好。（书中明示：很多中奖者后悔选一次性结款）

### 容易误用的地方

- 只用一个折现率下结论。书中同一笔奖金在 5% 与 20% 下的 NPV 相差四倍（约 2000 万 vs 500 万），单点估算是危险的。（书中明示）
- 把 NPV 当成决策的全部。作者明确提醒要"考虑非经济因素"——大额现金到手后的行为风险不在模型内。（书中明示）
- 忽略流动性需求：NPV 更高的方案可能在最需要用钱的那几年给不出钱。（推导，非书中明示）

### 容易混淆的邻近模型

- 与现金流折现法：NPV 是 DCF 的输出。混用无害，但追问"为什么是这个数"时必须拆开。
- 与折现率：NPV 是被折现率支配的因变量，先有折现率才有 NPV。
