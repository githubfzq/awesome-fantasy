# 多米诺骨牌效应（domino effect）

## R — 原文 (Reading)

> 一系列不可避免的连锁反应就像多米诺骨牌连续倒下……会带来更多的负面后果。
>
> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

多米诺骨牌效应描述的是:一个事件触发下一个,下一个再触发下一个,像骨牌连续倒下,带来不断放大的负面后果。

在博弈情境里,它可以表现为玩家的一系列选择把你拖入糟糕的纳什均衡——比如重复囚徒困境中,一个人的背叛引发众人效仿,合作就此崩塌。

这个模型的正确用法不是"喊一声会连锁反应",而是**把逻辑链逐环写下来,估算每一块牌倒下的概率,再判断整体可否接受、要不要遏制**。因为链条越长,总概率是各环概率的乘积——五环各 80% 的链条,整体只有约 33%。

作者的警告正是针对这一点:**别过度援引**。人们通常既不确定事件发生的概率,也不确定因果链是否成立。这种误判在书里具体体现为三个模型——滑坡论(slippery slope)、破窗理论(broken windows)、入门毒品理论(gateway drug theory),它们都预设了"第一块牌必然推倒第二块"。

关键判据:**每一环都要单独给出成立概率**,并且问"有没有可能停在某块牌上"。

## A1 — 书中的应用 (Past Application)

### 案例: 枪支管制的民意调查

- **问题**: 公众对枪支管制的态度,是否呈现出"一旦支持某项管制就会连锁支持更多管制"的模式?
- **方法论的使用**: 作者引用民调数据说明公众对具体措施的态度是叠加而非滑落的——72% 的美国人同时赞成禁止突击式武器与禁止高载弹量弹夹。
- **结论**: 这个数据被用来说明"滑坡式连锁"的假设在民意层面并不成立;支持一项具体管制并不会自动把人推向全面禁止。援引多米诺效应前,必须先检验链条是否真的存在。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在辩论一个政策/规则/先例,一方声称"一旦开这个口子后面就刹不住了"。
2. 用户在评估一次事故/一次公开失误会不会引发声誉、客户、舆论的连锁崩塌。
3. 用户在设计系统或组织,担心单点故障会层层传导(级联失败)。
4. 用户在复盘"一个小问题怎么演变成大危机",需要还原传导链。

### 语言信号 (用户的话里出现这些就应激活)

- "一旦这样,后面就停不下来了"
- "会引发一连串的问题"
- "第一张牌倒了就全完了"
- "这个口子不能开"
- "会不会越滚越大"
- "domino effect" / "slippery slope" / "it'll snowball"

### 与相邻 skill 的区分

- 与 `mm-slippery-slope-argument` 的区别: 滑坡论是**谬误**——未经检验地断言 A 必然导致 Z;多米诺效应是**中性模型**,要求你逐环给出概率。当对方说"必然连锁"而拿不出每环的证据,就是滑坡论。
- 与 `mm-cascading-failure` 的区别: 级联失败是工程/系统语境下的具体故障传导(一个节点挂掉拖垮下一批),多米诺效应是更一般的因果链比喻;前者通常有明确的技术机制,后者常被滥用。
- 与 `mm-butterfly-effect` 的区别: 蝴蝶效应强调**初始条件的极小差异**导致巨大分叉,且不可预测;多米诺效应强调**可追溯的线性因果链**,且每环可估概率。

## E — 可执行步骤 (Execution)

1. **把"连锁反应"写成显式的链条**
   - 完成标准: 写出 A → B → C → ... 的每一环,每环一句话,不允许出现"然后就完了"这种跳跃。
   - 判停条件: 若只有一步后果,不存在传导,直接按单一后果评估即可。
2. **给每一环单独估概率并相乘**
   - 完成标准: 每环都有明确的概率估计与依据;算出整条链成立的总概率(各环相乘);明确指出链条越长、整体概率越低。
3. **寻找断点:哪里可以停下来**
   - 完成标准: 至少找出 1-2 个"即使前一环发生,后一环也不会发生"的断点,并说明有什么机制能让它停在那儿(缓冲、冗余、制度闸门、人的干预)。
4. **判断可否接受、要不要遏制**
   - 完成标准: 结合总概率与最终后果的严重度,给出"接受/遏制/预防"三选一的建议;若选遏制,指出最该加固的是哪一环(通常是概率最低或最便宜可切断的那环)。
5. **回检是否只是滑坡论**
   - 完成标准: 明确指出——若拿不出每环的概率与依据,这就是作者在书中点名的过度援引,应拒绝据此决策。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 后果单一、不存在传导链条的事件:用不上链条分析。
- 系统极度复杂、各要素互相反馈而非线性传导:线性多米诺链会严重失真,应用因果循环图/系统思考。
- 争论已经变成政治修辞而非因果判断:先把讨论拉回"每一环的证据是什么"。

### 书中警告的失败模式 / 容易误用的地方

- 作者警告别过度援引: 人们通常既不确定事件发生概率,也不确定因果链是否成立。(书中明示)
- 误判会具体体现为三个模型: 滑坡论、破窗理论、入门毒品理论——它们都预设了未被证实的必然传导。(书中明示)
- 常见误用:只说"会连锁反应"而不给每环概率——这恰恰是把修辞伪装成分析。(推导,非书中明示)

### 容易混淆的邻近模型

- 与级联失败(cascading-failure): 级联失败是系统工程中真实存在且可建模的传导,多米诺效应在日常论证中多为比喻;前者要算负载与冗余,后者要算每环概率。
- 与蝴蝶效应: 蝴蝶效应不可预测、非线性;多米诺效应可追溯、线性。用错会导致要么过度恐慌、要么过度自信。
