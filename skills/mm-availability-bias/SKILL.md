# 可得性偏差（availability bias）

## R — 原文 (Reading)

> 所谓的"可得性偏差"，是指根据最近可以获得的信息，使你对现实的客观认知在无意中出现了偏差或失真。
>
> — 《思维模型》, 第1章 少犯错 > 各持己见

---

## I — 方法论骨架 (Interpretation)

人估计"这件事有多常见/多可能发生"时，用的方法不是去查统计，而是**在记忆里搜索例子**：能想起来的例子越多、越容易想起来，就判断它越常见。这个启发在多数时候是有效的（常见的东西确实更容易被回忆），但它会被一个与频率无关的因素污染——**可得性**。

三样东西会让一件事在记忆里格外可得，而它们都与真实频率无关：

1. **媒体曝光度**: 被大量报道的事件，"只要流血，就能上头条"。
2. **近期性**: 刚刚发生的事，回忆成本最低。
3. **情绪强度**: 生动、可怕、令人愤怒的画面，记忆留存最久。

于是偏差的系统方向是固定的：**被报道的、刚发生的、情绪强烈的风险被系统性高估；安静的、缓慢的、常见的风险被系统性低估**。Lichtenstein 等人 1978 年的研究给出了最有力的证据：人们把龙卷风致死率高估了 50 倍，把中风致死率低估到实际的百分之一——而中风的实际致死人数远高于龙卷风。差别恰恰在于：龙卷风上新闻，中风不上新闻。

它的定义里还有一个关键词：**无意中**。这不是偷懒或愚蠢，是认知结构的默认行为，因此只能靠显式调用统计数据来校正，不能靠"我会注意的"。

关键判据（一问）：**我这个印象，来自"刚看到的故事"，还是"统计数据"？** 如果答"故事"，就必须去查基础比率。

---

## A1 — 书中的应用 (Past Application)

### 案例: 非法移民、暴力犯罪率与龙卷风的致死率
- **问题**: 作者要说明可得性偏差会让人对现实的认知系统性失真，而且失真的方向可以被预测。
- **方法论的使用**: 三个对照。其一，美国的非法移民数量实际处于 50 年最低点，却被普遍认为"史无前例地多"——因为相关报道密集。其二，"只要流血，就能上头条"使得暴力犯罪率被严重高估（盖洛普 2014 年的调查显示多数美国人认为犯罪率在上升，实际在下降）。其三，Lichtenstein 等 1978 年的研究发现，人们对致死率的估计与媒体报道量高度相关而与真实数据几乎无关：龙卷风致死率被高估约 50 倍，中风致死率被低估到实际的百分之一。书中还举了经理写年度评估时只记得员工最近几周表现的例子——近期性同样污染了对他人的评价。
- **结论**: 印象的强度与事件的频率无关，只与曝光度、近期性、情绪强度有关。因此任何频率/概率判断都必须回到基础比率。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **估计风险/频率/概率时凭印象**: "这种病是不是很常见""创业失败的很多吧""这个行业是不是在走下坡路"。
2. **被新闻密集报道影响判断**: 某个事件刷屏后，用户认为它变得非常普遍或非常危险。
3. **刚刚经历了一次事件**: 一次航班延误、一次被拒、一次投诉之后，用户认为此类事"总是发生"。
4. **对他人的评价基于最近表现**: 写绩效评估、评价合作者、判断团队状态，只用了最近几周的样本。
5. **用身边样本推断整体**: "我认识的几个人都……"——样本既小又经过了自我筛选。

### 语言信号 (用户的话里出现这些就应激活)

- "最近老看到这种事"
- "我身边好几个都这样"
- "新闻天天在说，肯定很严重"
- "感觉越来越多了"
- "我记得上次……所以我觉得很常见"
- "这种概率有多大？" （且用户已在用印象作答）
- "It seems like it's happening all the time." / "I keep hearing about it." / "off the top of my head"

### 与相邻 skill 的区分

- 与 `mm-base-rate` / `mm-base-rate-fallacy` 的区别: 基础比率是**校正工具**（真实发生率是多少）；可得性偏差是**失真来源**（为什么你的主观估计会偏离）。一个是答案，一个是病因。
- 与 `mm-anecdotal-evidence` 的区别: 轶事证据指用个案代替数据的**错误论证方式**；可得性偏差解释的是**为什么个案会显得有说服力**（因为它容易想起来）。二者常同时出现，但一个是规范问题一个是心理机制。
- 与 `mm-survivorship-bias` 的区别: 幸存者偏差是**样本本身被筛选过**（只看到成功者）；可得性偏差是**记忆中的样本被取材难度筛选过**（只记得好提取的）。筛选机制不同：一个在数据源头，一个在检索环节。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把用户的印象性判断转成一个可测量的频率问题**
   - 完成标准: 把"是不是很常见"改写成明确的量：在**什么总体**中、**多长时间内**、发生**多少次**（发生率 / 占比 / 绝对数）。
   - 判停条件: 若用户的问题本身不需要频率估计（例如"我这次经历是不是合理""我该怎么办"），停止，本 skill 不适用。
2. **追溯印象来源并标注偏差方向**
   - 完成标准: 问清"这个印象从哪来"（新闻推送 / 身边案例 / 刚发生的事 / 强烈情绪事件），并据此标出偏差的预期方向——被高估还是被低估。
3. **查基础比率，做数量级对照**
   - 完成标准: 给出该事件的基础比率或可查的统计数据（至少给数量级），并与用户的印象做对比，明确说清差多少倍。
   - 判停条件: 若确实无公开数据，如实说明"缺乏数据"，改用可获取的最接近的代理指标，并明确标注这是代理而非直接数据，禁止用印象填补空白。
4. **提醒"无意中"这一特性**
   - 完成标准: 明确告知用户：这不是他偷懒，而是认知默认行为；因此"我知道有这个偏差"不足以免疫，必须形成查数据的习惯。
5. **检查近因对被评价对象的影响**（若涉及对人的评价）
   - 完成标准: 若用户在评价一个人/团队，要求把样本窗口从"最近几周"拉长到完整周期，并按时间段分别列举表现，防止近因污染整体评价。
6. **（可选）给出个性化推荐时代的额外提醒**
   - 完成标准: 若用户的印象来源是推送/推荐流，明确指出这会放大可得性偏差（书中指出该问题正随个性化推荐与新闻推送变严重），建议主动更换信息源。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **个人独特经历的价值判断**: "我这次面试被拒了，是不是我能力不行"——这不是频率估计问题，用可得性偏差分析会是答非所问。
- **用户确实拥有代表性样本时**: 若用户手上有完整的、未经筛选的数据（自家系统的全部日志、全员考核记录），直接用那些数据，不需要偏差提醒。
- **突发事件正在发生的实时判断**（推导, 非书中明示）: 此时"最近发生"就是真实信息（地震刚发生、系统正在告警），把它当作可得性偏差来打折扣会误事。

### 书中警告的失败模式 / 容易误用的地方

- **书中未给明确边界，但指出随着个性化推荐和新闻推送兴起，这一问题正在变严重**（`boundary` 字段原文）。这意味着在现代信息环境下，每个人接触到的"可得样本"都是被算法个性化筛选过的，偏差不再随机，而是被系统性放大。
- （推导, 非书中明示）**用该模型否定个案的真实性**: "你觉得常见是因为可得性偏差"不等于"这件事没发生"。校正的是频率估计，不是事实认定。
- （推导, 非书中明示）**反向误用**: 不能因为"媒体夸大"就认定真实风险一定低。有时报道密集正是因为风险真的在上升。判断依据是数据，不是对媒体的不信任。
- （推导, 非书中明示）**缺乏数据时用印象顶替**: 第 3 步查不到数据时，最危险的做法是退回印象。应明确标注不确定性，或改用代理指标。

### 容易混淆的邻近模型

- **基础比率谬误（base-rate-fallacy）**: 是**忽略**已知基础比率而依赖个案特征；可得性偏差是**压根没有**正确的基础比率可用（因为记忆样本被污染）。前者是有而不用，后者是拿到的是坏的。
- **选择性偏差（selection-bias）**: 是样本的采集方式有问题；可得性偏差是样本的**提取**方式有问题。
