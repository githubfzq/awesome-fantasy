# 幸存者偏差（survivorship bias）

## R — 原文 (Reading)

> 类似的调查通常也无法纳入前雇员的看法，这会导致调查结果出现另一种偏差，也就是所谓的"幸存者偏差"（survivorship bias）。过得不自在的员工可能已经选择了离职
>
> — 《思维模型》, 第5章 > 隐藏的认知偏差

---

## I — 方法论骨架 (Interpretation)

淘汰过程本身就是一次非随机筛选。能通过筛选、留到今天被你看见的个体，已经带着一整套"通过了筛选"的属性；而没通过的那批，连同它们失败的模式，从未进入你的样本。

于是你会系统性地得出过于乐观的结论：你只看见返航的飞机，只看见上市的公司，只看见盖茨和扎克伯格，只看见还立着的漂亮老建筑。失败者不说话，所以"失败的模式"在数据里根本不存在——你会以为成功有规律，其实你看到的只是筛选的结果。

关键判据是一句追问：**"被淘汰的那批在哪里？我为什么看不见它们？"** 作者指出这不会让调查完全无效，但必须补救：去查辞职者的面试数据，甚至专门针对离职员工做调查。

---

## A1 — 书中的应用 (Past Application)

### 案例: 弹孔装甲、辍学亿万富翁与漂亮的老建筑

- **问题**: 人们习惯从眼前可见的成功样本里提炼规律：给返航飞机弹孔多的地方加装甲、从盖茨和扎克伯格推出"辍学是好主意"、感叹老建筑比新建筑更美。
- **方法论的使用**: 作者引用瓦尔德的洞见——返航飞机的弹孔分布是**幸存者样本**，真正致命的部位中弹的飞机根本没飞回来，所以应该给"没有弹孔"的区域加装甲。同理，辍学成功者是极少数被看见的幸存者，绝大多数辍学者无声无息；老建筑更美只是因为丑的早被拆掉了。
- **结论**: 从幸存样本归纳出的规律，方向性地偏向乐观，且遗漏了最关键的失败信息；必须先找到被淘汰者，才能谈规律。作者给出的补救办法之一是：调查无法纳入的前雇员，或去研究辞职者的数据。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "那些成功的人都做了 X，所以我们也该做 X"（创业方法论、投资策略、学习习惯的归纳）。
2. 只看在职员工调研/在线评论/公开案例集来判断组织健康度或产品口碑。
3. 感叹"过去的东西质量更好""以前的人更能吃苦"，用今天存留下来的样本对比。
4. 评估一个策略的历史胜率，但数据里只有活到今天的基金/账号/项目。

### 语言信号 (用户的话里出现这些就应激活)

- "那些成功的公司都有一个共同点"
- "为什么老家具/老建筑比现在的结实"
- "比尔·盖茨也辍学了"
- "我们员工满意度 90%，没人抱怨"
- "Why do we only hear about the winners?"

### 与相邻 skill 的区分

- 与 `mm-selection-bias` 的区别: 选择性偏差是**分组不随机导致组间不可比**（两组都看得见）；幸存者偏差是**失败者整批缺席样本**，你手里连对照组都没有。
- 与 `mm-publication-bias` 的区别: 发表偏倚专指"阴性结果没被发表"这一文献层面的淘汰；幸存者偏差是更一般的淘汰筛选机制。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别淘汰环节**
   - 完成标准: 明确指出"谁被淘汰了、被什么机制淘汰的"（离职、阵亡、退市、拆除、未发表）。
2. **命名看不见的那批**
   - 完成标准: 说出失败者的数量级与特征，以及它们为何没有留下记录。
   - 判停条件: 若失败者确实被完整记录并已进入样本，停止，本 skill 不适用。
3. **翻转结论方向**
   - 完成标准: 把原结论从"成功靠 X"改写为"在幸存者中观察到 X"，并指出该结论对尚未通过筛选的个体是否仍然成立（书中范式：弹孔少的地方才该加装甲）。
4. **给出补救性数据源**
   - 完成标准: 至少提出 1 条能触达失败者的渠道（书中模板：查辞职者面试数据、针对离职员工做调查）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 样本未经任何淘汰筛选、失败者已在其中（例如完整记录了全部被试的对照实验）。
- 用户只是在描述现状（"目前在职员工有多少人"），没有从样本归纳规律或做推广。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确说，这**不一定让调查"毫无效果"**，但必须补救，例如查辞职者面试数据、甚至针对离职员工做调查。
- （推导，非书中明示）反向误用：把任何"样本不全"都叫幸存者偏差而拒绝一切经验归纳。正确的动作是估计缺失部分的规模与方向，而不是拒绝全部证据。

### 容易混淆的邻近模型

- 选择性偏差（selection-bias）：非随机分组使两组不可比，但两组都在样本里。
- 发表偏倚（publication-bias）：阴性结果未发表造成的文献层面幸存者偏差。
