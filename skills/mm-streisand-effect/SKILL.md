# 史翠珊效应（Streisand effect）

## R — 原文 (Reading)

> 史翠珊效应（Streisand effect）适用于更加特殊的情况：当你试图隐藏某样东西时，会无意中将注意力吸引到它上面。
>
> — 《思维模型》, 第2章 > 许愿须谨慎

---

## I — 方法论骨架 (Interpretation)

史翠珊效应描述的是一个反直觉的传播现象：遮盖的动作本身，会把注意力引向被遮盖的东西，而且引来的量级远大于原内容本会获得的。

2003 年，芭芭拉·史翠珊起诉摄影师网站发布其豪宅航拍照。诉讼前那张照片只被下载了 6 次；报道一出，网站访问量飙升至数十万，如今那张照片在维基百科等地随处可见。原本无人问津的东西，因为"被禁止"而变成了新闻。

机制在于传播动力的转移：人们关注的不再是内容本身，而是"这件事被压下去了"这个事实。遮盖动作天然具备新闻要素——有权势的一方、被隐藏的真相、可以参与的转发——它比原始内容更有传播价值，也更容易被二次创作。

所以关键判据是：**你的遮盖动作是不是比被遮盖物更有新闻价值？** 作者用"关键不在于罪行，而在于掩饰"点明了适用边界：只有当压制动作会引发公众好奇时才触发。对已经广泛传播、或本就无人关心的内容，压制的边际效果完全不同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 收到负面曝光、差评、爆料，第一反应是"能不能删掉"。
2. 准备用投诉、发函、平台举报的方式处理一条内容。
3. 内部出现丑闻或事故，考虑是否对外声张。
4. 评估一次压制行为的代价：删了会不会反而引爆。
5. 处理已经删过但仍在扩散的内容（截图、镜像、二次传播）。

### 语言信号
- "能不能想办法把它删了"
- "发律师函让他撤稿"
- "这事千万别传出去"
- "投诉到平台让他们下架"
- "为什么越删传得越广"
- "Streisand effect / take it down / gag order / bury the story"

### 与相邻 skill 的区分
- 与 `mm-backfire-effect` 的区别: 逆火效应发生在**信念层面**（摆出反面证据反而让对方更坚信），本 skill 发生在**注意力层面**（遮盖反而让更多人看见）；前者加固信念，后者扩大传播。
- 与 `mm-chilling-effect` 的区别: 寒蝉效应是压制**成功**的后果（人们因此不敢说话），本 skill 是压制**失败**的后果（反而放大了传播）；两者是同一动作的两种结局。
- 与 `mm-cobra-effect` 的区别: 眼镜蛇效应是方案放大了**原问题本身**（蛇变多了），本 skill 是方案放大了**问题的可见度**（关注变多了），原问题未必变严重。
- 与 `mm-hydra-effect` 的区别: 九头蛇效应强调移除一个源头后冒出更多**替代源头**，本 skill 的放大来自遮盖动作的新闻性，而不是新源头的产生。

## E — 可执行步骤 (Execution)

1. **先测"当前实际可见度"**
   - 查：浏览量、转发量、搜索结果条数、是否已有缓存/截图/镜像。
   - 完成标准: 得到一个量级数字（几十 / 几千 / 几十万）。
   - 判停条件: 若已有镜像或截图广泛流传，删除已无技术可能，直接跳到步骤 4。
2. **评估遮盖动作的新闻价值**
   - 问三件事：遮盖方是否比内容本身更有话题性？是否存在"以大欺小"的叙事？有没有人愿意报道"被封"这件事？
   - 完成标准: 三条里命中 ≥2 条即为高危，判定压制很可能触发史翠珊效应。
3. **比较"压"与"不压"的预期传播量**
   - 完成标准: 给出两个量级估计的对比结论。
4. **选替代路径**
   - 候选：直接回应事实（降低信息真空）、补充语境与更正、让内容自然沉没、用更高权重的正面内容覆盖、走法律但只针对明确违法部分且同步公开说明。
   - 完成标准: 选定 1 条主路径，并写明为什么不选压制。
5. **若必须压制，先压住扩散条件**
   - 手段：同步准备公开说明、只针对违法/侵权的最小范围、不追求全网消失、预留"被问起时怎么说"的一句话。
   - 完成标准: 写出那句对外说明，并明确"不做什么"。
6. **设定观察与止损点**
   - 完成标准: 明确观察周期、观察指标（声量、新增源头数）、以及达到什么阈值就改换策略。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 内容属于依法必须处理的违法信息（儿童侵害、明确侵权、涉密）：此时处理是义务，风险应由法务判断而非传播效果判断。
- 用户只是在做正常的隐私设置或权限管理：不涉及公开压制，没有新闻价值。
- 内容本就无人关注且不会被报道：遮盖不会引发好奇，效应不成立（推导，非书中明示）。

### 容易误用的地方
- 作者引"关键不在于罪行，而在于掩饰"说明其适用边界：**只有当压制动作会引发公众好奇时才触发**（书中明示）。不要把所有删除行为都算作史翠珊效应。
- 容易把"已有截图流传"的场景当成还能删：一旦存在镜像，删除只在源站点生效，反而制造"被删了"的第二波叙事（推导，非书中明示）。
- 用它来为不当行为辩护是本末倒置：模型只说明压制在传播上不划算，不说明被曝光的事可以被接受（推导，非书中明示）。
