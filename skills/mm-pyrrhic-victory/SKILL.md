# 皮洛士式的胜利（Pyrrhic victory / hollow victory）

## R — 原文 (Reading)

> 赢得其中一次战斗不过是有名无实的胜利（hollow victory），有时也称为徒有虚名的胜利或皮洛士式的胜利（Pyrrhic victory）
>
> — 《思维模型》, 第7章 > 改变战局

---

## I — 方法论骨架 (Interpretation)

皮洛士式胜利指的是：**你在计分板上赢了，但赢下来的代价损害了你继续打下去的能力。** 它是净收益为负的胜利——不是"险胜"，而是"胜了之后处境比开打前更糟"。

它为什么会发生？因为人对"赢"的感知是局部的、当下的，而对"代价"的感知是延迟的、分散的。一场诉讼赢了，但三年时间、律师费、团队精力和行业关系都消耗掉了；一次争吵赢了，但关系没了。计分板上记的是胜负，成本记在别的地方。

它与消耗战（war of attrition）直接相关：在消耗战中，双方比的是谁的资源先耗尽。如果某场战斗让你损失的资源占你总量的比例**高于**对手（即便你赢），你就在这局消耗战里相对变弱——赢三场这样的仗，你就输了整场战争。

关键判据是两条：
1. **打完这一仗，我相对于对手的位置是变好了还是变差了？** 不是绝对看自己得失，要看相对变化。
2. **我损失的是可再生资源还是不可再生资源？** 钱能再赚、时间是单向的、核心成员走了很难补、声誉崩了最难修。用不可再生资源换可再生战利品，是最典型的惨胜。

作者同时给出它的反面：**为赢得整场战争而主动输掉若干战斗（弃子战略）是合理的长期战略。** 也就是说，判断标准从来不是这一仗的胜负，而是它对终局的影响。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 考虑打一场官司/仲裁：能赢，但律师费和时间可能超过标的额。
2. 项目竞标或价格战：拿下这个客户要压到亏本价、且要抽掉主力团队。
3. 组织内部争权或争论：可以赢下这次决议，但会得罪关键同事或上级。
4. 亲密关系或家庭冲突：用户"吵赢了"，但关系明显冷了。
5. 已经投入很久，用户在纠结"要不要坚持到底"——需要区分是想赢还是不想承认输。

### 语言信号 (用户的话里出现这些就应激活)

- "就算赢了也没什么意思"
- "这场官司打得赢，但花的钱比赔的还多"
- "吵赢了，但两个人都不说话了"
- "拿下这个项目我们得亏三年"
- "赢了这一仗，输了整个战争"
- "we won, but at what cost / Pyrrhic victory / hollow victory"

### 与相邻 skill 的区分

- 与 `mm-war-of-attrition` 的区别: 消耗战描述的是"比谁先耗尽"的整体格局与策略选择；皮洛士式胜利是对**单场战斗结果**的净收益判定。用户问"要不要继续耗"用消耗战，问"这一仗赢了值不值"用本 skill。
- 与 `mm-sacrifice-play` 的区别: 弃子战略是**主动**放弃局部以换取全局，是有意为之；皮洛士式胜利是**无意中**用过量代价换来局部，是失误。判据是有没有预先算过。
- 与 `mm-cost-benefit-analysis` 的区别: 成本收益分析是通用核算工具；本 skill 专指"赢了但净收益为负"这一类特定结构，并强调相对位置与资源可再生性。
- 与 `mm-pick-your-battle` 的区别: 有选择地参战解决的是"哪些仗值得打"的选择问题，本 skill 解决的是"已经（或即将）打的这一仗代价是否划算"的核算问题。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出战利品**
   - 完成标准: 明确写出"赢了能拿到什么"，尽量量化（金额、职位、市场份额、话语权），并标注其中哪些是**可再生**的。
2. **列出全部代价，含隐性项**
   - 完成标准: 至少覆盖四类——直接金钱、时间、关键关系、不可逆资源（声誉、健康、核心人员、机会窗口）。每项标注是否可再生。
3. **做相对而非绝对的比较**
   - 完成标准: 估算对手在同样过程中的损失，回答"打完之后我和他的力量对比是拉大还是缩小"。
   - 判停条件: 若战利品小于代价、且相对位置变差，明确判定为皮洛士式胜利，跳到步骤 5。
4. **检查是否被沉没成本绑架**
   - 完成标准: 追问"如果今天刚接手这件事、还没投入任何东西，我还会打吗"。答案为否，说明当前动机是挽回已投入而非追求未来收益。
5. **给出三条出路并选一**
   - 完成标准: 至少给出——(a) 不打/撤退的具体方式；(b) 换一种代价更低的打法（缩小诉求、换渠道、引入第三方）；(c) 若必打，限定投入上限与止损点。三者中明确推荐一条并说明理由。
6. **写止损线与退出条件**
   - 完成标准: 产出一句可被客观触发的止损规则（"若 X 在 Y 时点前未达成，则停止"），并指定由谁执行。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 代价与收益都在正常范围、只是过程辛苦——不必把所有硬仗都诊断成惨胜。
- 该仗涉及原则、安全、法律底线，即使代价高于战利品也应当打——此时"值不值"不是唯一标准。
- 用户已经主动算过账、明确这是为全局而做的取舍——那是弃子战略，不是惨胜，不要用"得不偿失"去动摇他。
- 只有情绪疲惫、没有实际资源损失——那更接近倦怠而非本模型。

### 容易误用的地方

- 书中明示：作者同时指出另一面——为赢得整场战争而故意输掉若干战斗（弃子战略）是合理的长期战略。**不要把所有局部失败都当成惨胜，也不要把所有惨胜美化成战略取舍**，判据是事前是否算清。
- （推导, 非书中明示）只算钱、不算时间和关系，是最常见的漏算——多数惨胜都是漏在隐性科目上。
- （推导, 非书中明示）沉没成本谬误（sunk cost fallacy）会让人在已经代价过高时继续加码，把"打完就赢"当成唯一出路。

### 容易混淆的邻近模型

- **弃子战略（sacrifice play）**: 主动、算过账的局部放弃；与惨胜方向相反。
- **消耗战（war of attrition）**: 惨胜常发生在消耗战过程中，是消耗战的典型失误形态。
