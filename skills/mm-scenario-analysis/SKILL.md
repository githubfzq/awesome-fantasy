# 情景分析（scenario analysis / scenario planning）

## R — 原文 (Reading)

> 有一个相关模型能帮你发现“未知的未知数”，它就是情景分析（scenario analysis），也称为情景规划（scenario planning），用于更深入思考可能的未来。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

情景分析是这样一个动作:构造若干套**彼此不同但都自洽合理**的未来图景,然后逐一推演"在那套图景里我们会怎样"。它的目的不是预测未来,而是**发现你原本没想到的东西**——那些在单一预测视角下根本不会出现的未知未知。

难点在于人的认知倾向:我们倾向于抓住脑海里蹦出的第一个念头(锚定),而那个念头往往只是现状的直接外推,不会挑战任何前提假设。于是你以为自己在想未来,其实只是在把今天延长。

两个破解技巧:一是先列出可能发生的重大事件(股市崩盘、政府调控、行业并购),再推演各自的影响;二是用思维实验提出"如果……会怎么样"。流程上建议**先发散再聚合**:分组独立设计情景,再汇总讨论、收敛到几个深入探索。

重要的一点:独自做情景分析非常困难,必须引入外部视角。可辅以众包、预测市场、超级预测家的技巧来提高准确度。

作者也明说:它听起来简单,实际上很复杂。

关键判据:**几套情景之间必须真的不同**(不是"乐观/中性/悲观"三个版本的同一条曲线),否则你只是在给同一个未来上色。

## A1 — 书中的应用 (Past Application)

### 案例: 政府与大企业的专职未来研究

- **问题**: 如何在不确定性极高的环境里,提前发现那些没人预料到的变化?
- **方法论的使用**: 各国政府与大型企业雇专职人员持续撰写未来世界报告;政治学、城市规划、经济学学者做预测;作者还指出,科幻小说本质上就是情景分析——它构造一个自洽的不同世界,然后认真推演其中的生活。
- **结论**: 情景分析是有分工的专业活动,不是拍脑袋想三种可能。把它制度化、持续化,才能对抗"抓住第一个念头"的锚定倾向。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做 3-5 年的战略/职业规划,但只沿一条路径推演,需要挑战前提假设。
2. 用户所处行业正面临政策、技术或竞争格局的剧变,需要判断不同走向下的应对。
3. 用户刚遇到一个突发事件(新监管、新竞品、融资环境变化),需要快速推演后续连锁影响。
4. 用户说"我觉得未来就是这样",且其判断明显建立在现状外推上。

### 语言信号 (用户的话里出现这些就应激活)

- "未来几年这个行业会怎么变"
- "如果政策突然收紧会怎样"
- "最坏的情况是什么"
- "我们的战略能扛住什么级别的冲击"
- "这事要是真发生了,后面会怎么样"
- "what if..." / "scenario planning" / "worst case scenario"

### 与相邻 skill 的区分

- 与 `mm-unknown-unknowns` 的区别: 四象限是**盘点结构**(有哪些格子要填),情景分析是**往最难那格里填内容的生成方法**;先用前者建格,再用后者填格。
- 与 `mm-superforecasters` / `mm-prediction-market` 的区别: 那些是**给单一事件估概率**的方法,情景分析刻意不给概率、只构造自洽的多种未来;要"多准"用前者,要"多广"用本 skill。
- 与 `mm-thought-experiment` 的区别: 思维实验是一次性的反事实推演工具("如果光速不变会怎样"),情景分析是把多个思维实验组织成几套完整图景的系统工程。

---

## E — 可执行步骤 (Execution)

1. **先列出可能发生的重大事件**
   - 完成标准: 写出 5-10 个可能改变局面的事件(监管变化、技术突破、关键玩家并购、宏观冲击),不判断概率。
2. **分组独立发散,构造情景**
   - 完成标准: 构造 3-4 套**彼此不同**的未来图景,每套都有自洽的因果链;明确检查它们不是同一条曲线的乐观/悲观版本。
   - 判停条件: 若用户独自一人,明确指出这一步会很困难,建议引入外部视角或用"列重大事件 + 如果……会怎么样"两个技巧自行逼近。
3. **聚合收敛**
   - 完成标准: 汇总各套情景,合并重复项,收敛到 2-4 套值得深入探索的;每套写清楚"触发它的前提假设是什么"。
4. **逐套推演影响与应对**
   - 完成标准: 对每套情景写出"我们会怎样"以及"提前做什么能在那套图景里活得好";重点找跨情景都成立的动作(鲁棒策略)和只在某套情景下才值得做的押注。
5. **设触发线并定期重做**
   - 完成标准: 给每套情景设定可观测的前兆信号与触发阈值,明确"看到什么就切换到哪套预案";情景分析不是一次性的。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需要一个带概率的单点预测("下季度销量是多少"):用超级预测家或预测市场的技巧。
- 一次性小决策:构造多套未来的成本远超收益。
- 已有确凿的、短期内会兑现的事实,却还要"构想去另一种可能"——那是拒绝接受现实,不是情景分析。

### 书中警告的失败模式 / 容易误用的地方

- 作者明说它"听起来挺简单,实际上却很复杂"。(书中明示)
- 独自一人做会很困难,必须寻求外部意见,同时警惕群体思维(groupthink)。(书中明示)
- 常见误用:把"乐观/中性/悲观"三档当成三套情景——这只是同一模型的不同参数,无法发现真正的未知未知。(推导,非书中明示)

### 容易混淆的邻近模型

- 与敏感性分析: 敏感性分析拨动单个参数看结果变化(参数层面),情景分析更换整套前提假设(世界观层面);前者是后者的机械化简化版。
- 与黑天鹅事件: 情景分析能扩展想象边界,但黑天鹅在定义上超出任何一套构造出来的图景;不要以为做完情景分析就覆盖了所有极端事件。
