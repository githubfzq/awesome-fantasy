# 假阳性与假阴性（false positive / false negative）

## R — 原文 (Reading)

> 如果公投最终失败了，但民意调查员随机选择的人更赞成提案，就会出现假阳性（false positive，又称"误报"）——错误地得出阳性结果（就像出错的酒精浓度测试一样），而事实上结果是阴性的。
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

任何需要给出"是/否"判断的系统，都会犯两类错误：**假阳性（误报）** 是错误地得出阳性结果，事实上结果是阴性；**假阴性（漏报）** 是错误地得出阴性结果，事实上结果是阳性。加上判断正确的两种情形，一共有四种结果——真阳、真阴、假阳、假阴。

关键在于两者**此消彼长**：在样本量固定的情况下，压低一类错误率必然抬高另一类。想少误报，就会多漏报；想少漏报，就会多误报。

所以设计原则不是"把错误降到零"，而是**先权衡两类错误各自的后果，再设定容忍度**。作者举美国刑事司法为例：宁可漏放罪犯（假阴性），也不要误判无辜者（假阳性）。垃圾邮件过滤则是另一个权衡样本——把小侄女的照片邮件判成垃圾（假阳性很烦人），但真垃圾漏进收件箱（假阴性）也能忍。

---

## A1 — 书中的应用 (Past Application)

### 案例: 乳腺 X 光检查与垃圾邮件过滤

- **问题**: 任何判断系统都会出错，而两类错误的代价并不相同，需要一套思考框架。
- **方法论的使用**: 作者用乳腺 X 光检查列出全部四种结果（真阳/真阴/假阳/假阴）；又用垃圾邮件过滤说明权衡的具体形态：把新生小侄女的照片邮件判为垃圾是假阳性，真垃圾邮件漏进收件箱是假阴性。
- **结论**: 错误不可避免，必须在不同类型的错误之间进行权衡取舍；作者强调不存在同时消灭两类错误的免费午餐（唯一能同时压低两者的办法是增加样本量，见统计功效一节）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设定告警阈值、风控阈值、审核通过线，纠结"松一点还是紧一点"。
2. 系统误报/漏报引发投诉，用户问"是不是模型不行"。
3. 设计筛查流程（体检、安全扫描、代码扫描），需要决定偏向哪一侧。
4. 争论"宁可错杀一百不可放过一个"这类原则是否适用于当前场景。

### 语言信号 (用户的话里出现这些就应激活)

- "又误报了，这系统能不能准点"
- "漏掉的那几个更严重"
- "宁可错杀，不可放过"
- "阈值定在多少合适"
- "False positives are killing us"

### 与相邻 skill 的区分

- 与 `mm-power` 的区别: 统计功效关心的是**假阴性率**（1−β，有没有把握不漏掉真效应）；本 skill 关心的是**两类错误之间的权衡取舍**。
- 与 `mm-base-rate-fallacy` 的区别: 基础比率谬误是"把误报率当成结论概率"的反推错误；本 skill 是设计系统时的事前权衡。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出四种结果**
   - 完成标准: 明确写出真阳/真阴/假阳/假阴各自的现实含义（书中模板：乳腺 X 光的四格）。
2. **为两类错误分别定价**
   - 完成标准: 给假阳性与假阴性各自一个可比较的代价（金钱、时间、信任、风险），并指出哪一类更不可接受。
   - 判停条件: 若两类代价相当且都极低，说明本权衡不重要，简化处理即可。
3. **据此设定容忍度与阈值**
   - 完成标准: 给出具体的错误率目标与阈值位置，并说明它偏向哪一侧。
4. **说明无法通过调阈值同时压低两者**
   - 完成标准: 明确指出在样本量固定时二者此消彼长；若必须同时降低，提出需要增加信息量/样本量的方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 场景根本不需要做二元判断（只是描述、排序、生成）。
- 两类错误的后果都很轻微且接近，做精细权衡的收益低于成本。

### 书中警告的失败模式 / 容易误用的地方

- 作者强调错误不可避免，**"必须在不同类型的错误之间进行权衡取舍"**，不存在同时消灭两类错误的免费午餐。
- （推导，非书中明示）常见误用：只优化"准确率"这个总体指标——在某一类极罕见的场景里，99% 的准确率可能意味着所有正例全被漏掉。

### 容易混淆的邻近模型

- 统计功效（power）：等价于 1 − 假阴性率，专注"别漏掉真效应"。
- 第一类/第二类错误（type-i）：假阳性/假阴性在假设检验中的正式命名。
