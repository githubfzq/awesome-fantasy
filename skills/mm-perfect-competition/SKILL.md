# 完全竞争／商品化（perfect competition / commodities）

## R — 原文 (Reading)

> 另一种极端情况是完全竞争（perfect competition）。它是指市场上的众多竞争者提供完全相同的产品，也就是完全替代品
>
> — 《思维模型》, 第9章 > 开篇

---

## I — 方法论骨架 (Interpretation)

完全竞争是市场支配力谱系的**另一个极端**：众多竞争者提供**完全相同的产品，也就是完全替代品**，因此任何供给者都不具备市场支配力。

**为什么成立**：产品完全同质时，客户没有理由为某个供给者多付钱，于是选择标准坍缩成单一维度——价格。后果是**提价就等于把客户送给竞争对手**：你涨一块钱，客户就换一家，因为你和别人没有区别。因此商品提供者只能接受市场价格，无法协商溢价。

书中的例子是异丙醇：无论从谁那里买，一瓶 32 盎司异丙醇都是同样的异丙醇，提价就会被比价淘汰。

**关键判据**：判断的锚点是**客户视角的完全替代性**，不是生产者视角的"我们其实不一样"。你觉得自己的服务更用心没有意义，只要客户认为可以无成本互换，你就处在完全竞争里。

由此推出的行动含义很硬：在完全竞争状态下，**提升价格的唯一路径是离开这个状态**——做出客户认可且不可互换的差异。继续在价格上优化（降本、拼效率）可以活下去，但不会带来溢价。同样的逻辑也适用于个人：当你可替代、无差异化时，你的薪酬完全由市场供求决定。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 客户反复比价，销售反馈"就差那几百块"，用户在纠结要不要跟降。
2. 一门生意毛利率持续下滑，团队加班更努力但价格上不去。
3. 个人职业发展：感觉自己"谁都能替代"，薪水涨不动。
4. 考虑进入一个看起来热闹的行业，需要判断进去后能不能赚到钱。
5. 产品团队讨论"要不要再加功能"，但竞品功能几乎全对齐。
6. 制定定价策略时，先要确认自己有没有定价权。

### 语言信号 (用户的话里出现这些就应激活)

- "客户只看价格"
- "跟对手比我们没区别"
- "一提价客户就跑了"
- "是不是只能降价"
- "这行已经做烂了 / 太卷了"
- "我的工作谁都能干"
- "commoditized / race to the bottom / we can't raise prices / no differentiation"

### 与相邻 skill 的区分

- 与 `mm-monopoly` 的区别: 两者是**同一根轴的两个极端**。完全竞争=众多竞争者、完全替代品、零支配力；垄断=缺乏竞争者、巨大支配力。判断时先定位在轴的哪一端，中间的绝大多数情形更适合用市场支配力。
- 与 `mm-market-power` 的区别: 市场支配力是连续谱，本 skill 描述的是**谱上支配力为零的那一端**及其特有后果（价格坍缩为唯一选择标准）。想量化"我们到底有多少定价权"用市场支配力；想确认"我们是否已彻底商品化"用本 skill。
- 与 `mm-supply-and-demand` 的区别: 供求关系决定**市场价格的水平**（稀缺则价高）；本 skill 描述的是**你能否偏离那个价格**。在完全竞争中你只能接受供求决定的价格，无法溢价。两者常连用：供求定基准，竞争格局定你能否偏离基准。
- 与 `mm-moat` 的区别: 护城河是**防止被商品化**的建设性框架（品牌、网络效应、转换成本等）；本 skill 先帮你诊断"是否已经商品化"。前者是解法，后者是诊断。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **从客户视角检验"完全替代性"**
   - 完成标准: 明确回答"若我们把价格提高 X%，客户换成竞品需要付出什么代价"。若答案是"几乎零成本"，确认处于完全竞争。注意锚点是客户视角，不是团队自认为的差异。
   - 判停条件: 若客户换供应商有明显代价（学习成本、迁移风险、关系、切换成本），说明存在支配力，转 `mm-market-power`。
2. **确认竞争集是否真的"众多"**
   - 完成标准: 列出客户实际会询价的供给方数量。若只有少数几家，不适用本 skill，转市场支配力/寡头相关分析。
3. **接受价格约束，停止无效动作**
   - 完成标准: 明确指出在此状态下"更努力地销售""强调我们更用心""小幅提价"均无效——提价等于把客户送给竞争对手。让用户在**接受市场价 + 拼成本效率**与**离开这个状态**之间做明确选择。
4. **若选择差异化，指定具体的不可替代来源**
   - 完成标准: 给出 1-2 个客户认可且竞品难以复制的差异点（转换成本、网络效应、品牌信任、专有数据、捆绑服务、地域/时效），并说明验证方式（客户是否愿意为此多付钱或忍受不便）。
5. **若选择接受，转为成本与规模策略**
   - 完成标准: 明确把目标从"提价"改为"成为成本最低者或退出"，给出成本结构优化或退出的判断标准（如连续 N 个季度毛利率低于某阈值）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 产品有实质差异但没被客户感知——那是营销与定位问题，不是商品化。
- 市场只有少数几家供给者——不是完全竞争，用市场支配力。
- 客户切换成本高（已上线、深度集成）——存在锁定效应，不适用。
- 价格由管制或协议决定——市场机制不发挥作用。

### 容易误用的地方

- 书中未给本模型的边界说明，以下均为基于机制推导。
- （推导, 非书中明示）把"竞争激烈"等同于"完全竞争"。完全竞争要求**完全替代品**；多数"卷"的市场仍存在差异化空间，误判会让人过早放弃定价努力。
- （推导, 非书中明示）从生产者视角判断差异。判据是客户视角的可替代性——自认为的"我们服务更好"若客户不愿为此付费，就不构成差异。
- （推导, 非书中明示）认为降本能解决根本问题。降本只能改善存活，不能创造溢价；书中明确说商品提供者只能接受市场价格。
- （推导, 非书中明示）用它否定所有价格竞争。在某些阶段（抢占份额、规模爬坡）主动接受低毛利是理性策略，前提是清楚这是选择而非无奈。

### 容易混淆的邻近模型

- **垄断（monopoly）**: 同一根轴的另一个极端——缺乏竞争者、巨大支配力。
- **供求关系（supply and demand）**: 决定市场价格水平；本 skill 决定你能否偏离那个水平。
