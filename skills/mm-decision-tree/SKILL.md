# 决策树（decision tree）

## R — 原文 (Reading)

> 它是一幅示意图，看起来像一棵倒着的树，能帮你分析结果不确定的决策。树干（通常用方框表示）是决策点，树叶代表可能出现的不同结果（通常用空心圆圈表示机会节点）。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

当"选了 A 会花多少钱"这个问题的答案不是一个数、而是一组可能时,成本收益分析就失效了——它没有处理概率的结构。决策树补上这个结构:画一棵倒着的树。

元件与画法:方框 = 决策点(你能选什么),空心圆圈 = 机会节点(会分叉出哪些可能结果),实心点/树叶 = 该结果的成本,横线上标概率,且**同一个机会节点分叉出的概率之和必须是 100%**。

算法:把每个结果的成本乘以它的概率,再加总,得到该选项的期望值(expected value),比较后择优。

一个进阶用法是把树叶上的数字从"实际价格"升级为**效用值(utility values)**——把无形的担忧、麻烦、机会成本一并"计入"。这一步常常让结论反转:一个期望成本更低但让你天天提心吊胆的选项,计入焦虑的效用后可能就不再便宜。

适用范围:多个报价、多种时间/质量结果、以及低概率高后果的情形(如医疗保险自付额的选择)。

关键判据:**每个机会节点的概率必须加总为 100%**,且结论对概率估计高度敏感——所以画完树一定要做敏感性分析。

## A1 — 书中的应用 (Past Application)

### 案例: 泳池维修的两个承包商

- **问题**: 常用的承包商固定报价 2500 美元;新承包商只要 2000 美元,但只有 50% 概率按时完成,剩下 50% 里还有拖延 1 周加 250、拖延 2 周加 500、拖 3 周以上返工加 1000 三种可能。该选谁?
- **方法论的使用**: 作者画决策树——决策点后分两支,新承包商那支接一个机会节点,分叉出"按时/拖1周/拖2周/拖3周以上"四个结果,每条支线标概率与成本,逐项相乘后加总。
- **结论**: 新承包商期望值 = 1000 + 562.50 + 500 + 150 = 2212.50 美元,低于旧承包商的 2500 美元。虽然新承包商"可能"收 3000 美元,但只要大概率只收 2000,期望值仍更低,理性上应选他。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在多个报价/多个供应商间选择,其中某个选项便宜但有"做不完/做不好/延期"的风险。
2. 用户在选保险自付额、维保方案、SLA 等级——典型的低概率高后果。
3. 用户在决定要不要给某个方案加一道备份/冗余,需要权衡"多花的钱"与"出事的概率 × 损失"。
4. 用户纠结是否接受一个有风险的要约(新工作、新合作方),后者收益高但结果分布很宽。

### 语言信号 (用户的话里出现这些就应激活)

- "便宜是便宜,万一做不完怎么办"
- "有几成把握 / 概率大概多大"
- "最坏会坏到什么程度"
- "保险买哪个档 / 免赔额定多少"
- "要不要加个备份方案"
- "might not work out" / "what if it fails" / "probability of..."

### 与相邻 skill 的区分

- 与 `mm-expected-value` 的区别: 期望值是决策树里的**计算规则**(概率×后果再求和);决策树是**结构**——当你有三个以上选项、两层以上分叉、或需要做序贯决策时,才是决策树。
- 与 `mm-cost-benefit-analysis` 的区别: 成本收益分析假设每条成本收益都是确定的,只是发生在不同年份;一旦出现"可能发生也可能不发生",就该换决策树。
- 与 `mm-sensitivity-analysis` 的区别: 决策树负责建模与求解,敏感性分析负责检验概率估计错了会怎样;画完树必须接一步敏感性分析。

## E — 可执行步骤 (Execution)

1. **画出决策点与第一层分叉**
   - 完成标准: 明确写出 2-4 个互斥选项(方框),每个选项通向哪些**确定的**成本。
   - 判停条件: 若某选项不存在多种可能后果,把它当作确定成本处理即可,不要硬造机会节点。
2. **给每个不确定的选项加机会节点**
   - 完成标准: 每个机会节点下列出互斥且**穷尽**的可能结果(按时/延期1周/2周/3周以上),每条支线标注概率,且同一节点概率之和 = 100%。
3. **给每片树叶标成本,并考虑升级为效用值**
   - 完成标准: 每个结果都有成本;若有无形的担忧、麻烦、机会成本明显影响判断,明确指出并尝试换成效用值,说明这一步可能让结论反转。
4. **计算各选项期望值并择优**
   - 完成标准: 概率×后果逐项相乘后加总,得到每个选项的期望成本/收益,给出推荐。
   - 判停条件: 若两个期望值非常接近,进入步骤 5。
5. **对概率与后果做敏感性分析**
   - 完成标准: 至少把最关键的概率(如"3000 美元账单的概率")在合理区间内改动,确认结论是否翻转;书中案例把该概率从 5% 改成 50%,结论就翻转了。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 后果确定、只是发生在不同年份——用成本收益分析加折现。
- 完全没有概率依据(新领域、零历史数据)——硬填数字会产出虚假精确;此时更适合情景分析或先做小实验拿数据。
- 涉及低概率但毁灭性的后果(破产、死亡、不可逆损伤):期望值会告诉你"平均更省钱"从而避开保险,而正确的做法恰恰相反。

### 书中警告的失败模式 / 容易误用的地方

- 书中强调: 结果高度依赖概率估计,因此应随时对概率和后果做敏感性分析——把 3000 美元账单的概率从 5% 改成 50%,结论就翻转。(书中明示)
- 当两类期望值接近时,决策本身就变得棘手,不能靠再算两遍小数解决,而应去核实输入或改选对概率不敏感的方案。(书中明示)
- 常见漏项: 忘记检查同一机会节点概率之和是否为 100%,导致漏掉一类结果。(推导,非书中明示)

### 容易混淆的邻近模型

- 与收益矩阵(payoff-matrix): 收益矩阵处理的是**双方互动**(我选什么 × 对方选什么),决策树处理的是单人面对自然的随机性;若结果取决于另一个有意图的玩家,用博弈论。
- 与情景分析: 情景分析构造宏观未来图景,决策树在给定结构下算期望值;前者发散,后者收敛。
