# 超级预测家（superforecasters）

## R — 原文 (Reading)

> 它的合作创始人菲利普·泰洛克（Philip E. Tetlock）研究了成千上万的参与者，发现了超级预测家（superforecasters），也就是反复做出准确预测的人。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

超级预测家是反复做出准确预测的人。泰洛克的"善断计划"(Good Judgement Project)众包预测世界大事,这批人持续击败世界顶尖情报机构——而他们并不掌握后者能获得的机密信息。

它为什么重要:这说明预测的优势主要不来自信息特权,而来自**怎么用信息**。书中列出八项特质:智力(能迅速进入新领域)、专业知识、实践(预测是可磨炼的技能)、团队合作(在避免群体思维的前提下,群体胜过个体)、开放心态(愿意向自己的观念挑战)、审视过去(看基础比率)、花时间、修正预测(按新信息更新,以避免证实偏差)。

这八项指向同一个内核:**可校准、可更新、不被单一叙事绑架**。可校准,是指你宣称 70% 的事长期看真的发生约 70%;可更新,是指新证据出现时你肯改口,而不是替原来的说法找理由。

关键判据:预测是一项技能,不是天赋——"实践"和"花时间"都在八项之列。另一个判据是团队合作那一条附带的前提:只有在避免群体思维时群体才胜过个体,否则团队反而是减分项。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要做一个重要预测(市场、项目、政策、竞争),希望提高准确度而不只是"凭感觉"。
2. 用户想评估某个专家或机构的预测到底值不值得信。
3. 用户想组建一个做预测/判断的团队,想知道怎么选人、怎么组织。
4. 用户发现自己的判断长期系统性偏差(总是过于乐观或总是过于自信),想校正。

### 语言信号 (用户的话里出现这些就应激活)

- "这事到底会不会发生,有多大把握"
- "我的预测一直不准,怎么改进"
- "这个专家的预测能信吗"
- "要不要多找几个人一起判断"
- "我估计八成能成 / 十拿九稳"
- "superforecaster" / "calibration" / "forecasting accuracy" / "track record"

### 与相邻 skill 的区分

- 与 `mm-prediction-market` 的区别: 预测市场用价格聚合所有人的判断(包括外行),超级预测家用加权挑出少数校准良好的高手;一个是聚合装置,一个是选人与训练方法。两者可以叠加。
- 与 `mm-base-rate` 的区别: 基础比率是超级预测家八项特质中的具体一项(审视过去);本 skill 是完整的能力画像,基础比率只是其中一个抓手。
- 与 `mm-foxes-versus-hedgehogs` 的区别: 狐狸与刺猬讲的是"用许多小假设拼世界"vs"用一个大理论解释一切"两种认知风格;超级预测家普遍是狐狸型,但本 skill 的重点是可操作的八项特质与校准结果。

## E — 可执行步骤 (Execution)

1. **把模糊判断改写成可判定的概率命题**
   - 完成标准: 事件有明确时限与判定标准,用户给出一个具体数字概率(而不是"很可能""应该没问题")。
2. **先从基础比率起步**
   - 完成标准: 先查出这类事件的一般发生率作为锚,再讨论本次有哪些具体理由使之上移或下移;禁止跳过基础比率直接讲故事。
3. **向自己的结论发起挑战**
   - 完成标准: 至少列出三条"我错了会是因为什么"的具体情形,并说明每条的触发信号;这是对抗证实偏差的强制动作。
4. **设定更新条件并记下来**
   - 完成标准: 在预测时一并写下"如果观察到 X,我就把概率调到 Y"以及复盘时间;新信息出现时按此更新,而不是事后改写记忆。
5. **若以团队形式预测,先处理群体思维**
   - 完成标准: 明确采用独立提交后再汇总(或匿名),并做加权(历史上校准更好的人权重更高);禁止先公开讨论再统一口径。
6. **记录并校准**
   - 完成标准: 建立预测记录,事件揭晓后回填;定期统计——你标注 70% 的事件实际发生了百分之多少,据此调整自己的自信度尺度。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 纯确定性计算问题(如成本加总):不需要预测技巧,直接算。
- 为单次猜对的人背书:超级预测家的定义是"反复"准确,单次命中无法区分能力与运气。
- 缺乏反馈闭环的领域:没有事后揭晓,就谈不上校准与训练。

### 书中警告的失败模式 / 容易误用的地方

- 书中指出"团队合作"这一项的前提是避免群体思维;若成员互相看齐,团队预测反而比个体更差。(书中明示)
- 常见误用:把八项特质当成天赋清单——书中明确"实践"与"花时间"都在其中,预测是可磨炼的技能。(书中明示 + 推导标注:可磨炼为书中明示)
- 常见误用:只更新不校准,或只校准不更新;两者缺一,长期准确率都不会提升。(推导,非书中明示)

### 容易混淆的邻近模型

- 与证实偏差(confirmation bias): 超级预测家的"开放心态"与"修正预测"两项,本质上就是在对抗证实偏差。
- 与基础比率(base rate): 基础比率是八项特质之一的具体工具,也是起步时最先该用的那一个。
