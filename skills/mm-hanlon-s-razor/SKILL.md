# 汉隆的剃刀（Hanlon's razor）

## R — 原文 (Reading)

> 另一种给别人的行为做无罪推定的方式称为"汉隆的剃刀"（Hanlon's razor）：永远不要将能合理解释为粗心的做法视为恶意。
>
> — 《思维模型》, 第1章 少犯错 > 换位思考

---

## I — 方法论骨架 (Interpretation)

汉隆的剃刀是奥卡姆剃刀在动机归因上的具体应用：**能用粗心解释的，就不要用恶意解释**。这里的"剃刀"逻辑和奥卡姆一样——恶意是一种额外的假设，它要求对方"有意图、有动机、并且选择了伤害你"；而粗心只需要一条：他选了最省力的路径。假设更少的那条路，通常是对的。

它为什么在当下特别有用？书里点明了一个场景：**网络交流**。线上沟通缺少肢体语言、表情和语调，中性信息极易被读成负面。你发出一段话，对方回一个"OK"，你脑中自动生成"他懒得理我"——而真实情况大概率是他在开会、在地铁上、在同时处理五件事。伤害你的行为，通常只是对方在自己那一摊事里选了最省力的路径，根本没把你考虑进去。

要注意它是一条**默认项**而不是**结论**：它说的是"先别引入恶意"，不是"恶意不存在"。如果有明确证据（反复的、有针对性的、有收益的伤害），剃刀就该收起来。

判据：**"蠢 / 懒 / 忙"是否已经足以解释这件事？** 若是，就别引入"坏"。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. **线上沟通里感到被冒犯**：简短回复、已读不回、语气生硬、被@得突然。
2. **觉得流程/规定是"故意为难我"**：审批卡住、系统报错、窗口不通过。
3. **同事"忘了"通知你、漏了你、排错了你的顺序**。
4. **跨部门协作中的推诿与延误**（推导, 非书中明示）：大部分是优先级不同，不是敌意。
5. **公开场合被点名、被抢话、被忽略**（推导, 非书中明示）。

### 语言信号
- "他是不是故意针对我"
- "这就是在为难我们"
- "已读不回，太不尊重人了"
- "明明可以做好，他就是不上心"
- "他们是不是成心的"
- "Is he doing this on purpose?" / "Never attribute to malice what can be explained by stupidity"

### 与相邻 skill 的区分
- 与 `mm-most-respectful-interpretation` 的区别: MRI 的原则更宽——在所有可能解释里选**最善意的**（可能是在帮我、是有苦衷）；汉隆剃刀只做一件事——把"恶意"替换为"能力/精力不足"。后者是前者最常用、最锋利的那一种。
- 与 `mm-ockham-s-razor` 的区别: 奥卡姆剃刀是通用的**假设精简原则**；汉隆剃刀是它在**动机归因**这一个具体问题上的固定应用。前者是元规则，后者是专用结论。
- 与 `mm-fundamental-attribution-error` 的区别: 基本归因错误解释"为什么会错归因为是坏人"；汉隆剃刀给出"应该改归因为粗心"。一个是诊断，一个是处方。

## E — 可执行步骤 (Execution)

1. **写出让你不适的那件事（只写可观察的行为）**
   - 完成标准: 一句话描述对方做了/没做什么，不含评价词（去掉"故意""不尊重""针对"）。
2. **构造一个纯"非恶意"解释**
   - 完成标准: 用"不知道 / 忘了 / 太忙 / 能力不足 / 系统限制 / 优先级不同"中的一个或几个，把这件事完整解释一遍。
3. **做充分性检验**
   - 完成标准: 明确判定"非恶意解释是否已经足以解释全部现象"。若是 → 采用它，进入第 4 步。若否 → 说明缺了哪一块，转入 `mm-most-respectful-interpretation` 或收集更多证据。
   - 判停条件: 若存在明确敌意证据（有针对性、有收益、重复发生、有第三方证实），停止——此时不是粗心，进入边界与应对。
4. **按非恶意解释行动一次**
   - 完成标准: 给出一句具体的下一步话术或动作（补一次提醒、问一句优先级、把要求写清楚），并说明它比"以恶意对恶意"更可能拿到想要的结果。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **有明确敌意证据时**：针对性的、重复发生且对方从中获益的行为，不是粗心。
- **安全、欺凌、歧视、系统性伤害的场景**：此时"他只是不懂事"会阻止受害者采取必要保护。

### 容易误用的地方
- **书中未给边界**。以下基于机制推导：
- （推导, 非书中明示）**用它为反复失职开脱**：同一个人第三次犯同样的错，"粗心"已经不足以解释——问题是他的系统不行，应转向流程与责任，而非继续宽容。
- （推导, 非书中明示）**把"不用恶意解释"变成"不许生气"**：剃刀管的是**归因**，不是**情绪**。你依然可以要求对方改进，只是不必先假定他是坏人。
- （推导, 非书中明示）**反向误用**：系统性的、设计出来的伤害（如黑暗模式）确实出于恶意设计，别用"他们只是没考虑周全"替设计者开脱。
