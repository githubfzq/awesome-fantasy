# 垄断（monopoly）

## R — 原文 (Reading)

> 市场支配力的极端表现是垄断（monopoly）。垄断者由于缺乏竞争者而拥有巨大的市场支配力。
>
> — 《思维模型》, 第9章 > 开篇

---

## I — 方法论骨架 (Interpretation)

垄断是**市场支配力的极端情况**：因为缺乏竞争者，垄断者拥有巨大的定价权——客户要么多付钱，要么放弃该商品。

**为什么成立**：定价权的来源不是"想定多高就定多高"，而是**客户没有替代品**。当放弃是唯一替代方案时，客户的选择集被压缩成"付钱"或"不要"，于是价格由垄断者决定。

**关键的强度判据在书中给得很明确**：在**刚需**（如救命设备）场景下，放弃不是有吸引力的选项，因此支配力最强。这解释了为什么垄断的伤害不是均匀分布的——同样是垄断，救命药的提价空间远大于可选消费品。

书中的 EpiPen 案例展示了垄断的三个来源叠加：竞品召回、FDA 未批准同类设备上市，于是迈兰得以长期维持垄断式提价。注意这里**没有一个来源是"做得比别人好"**——是竞争被行政与事件性地清除了。

**最重要的一条边界**：作者提醒**垄断并非永存**——垄断者会倒台、专利会过期、法规会演变。因此任何基于"永远垄断"的估值或战略都是错的。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对唯一供应商大幅提价，用户在判断有没有议价空间与替代方案。
2. 评估一家公司/一门生意值不值得投，需要判断它的高毛利是来自能力还是来自垄断。
3. 自己的产品似乎"没有对手"，用户在判断这是真垄断还是只是暂时没被发现。
4. 依赖某项专利/独家授权，需要评估保护期结束后的风险。
5. 采购或供应链上出现卡脖子环节，要做风险预案。
6. 讨论某行业"是不是垄断"的公共议题，需要先把定义理清。

### 语言信号 (用户的话里出现这些就应激活)

- "只有这一家能做，涨价我们也没办法"
- "他们想涨多少涨多少"
- "这算不算垄断"
- "专利到期了会怎么样"
- "客户根本没得选"
- "毛利这么高是因为产品好吗"
- "is this a monopoly / sole supplier raising prices / no alternative but to pay"

### 与相邻 skill 的区分

- 与 `mm-market-power` 的区别: 市场支配力是**连续谱上的通用概念**（任何程度的定价能力）；垄断是它的**极端端点**。多数现实情形（如强势品牌、寡头）是中间态，用市场支配力更准确；只有"缺乏竞争者"到接近唯一供给时才用垄断。
- 与 `mm-perfect-competition` 的区别: 完全竞争是**另一个极端**——众多竞争者提供完全相同的完全替代品，谁都没有支配力。两者是同一根轴的两端，判断时要先定位在轴的哪一端。
- 与 `mm-barriers-to-entry` 的区别: 进入壁垒解释垄断**为什么能维持**（别人进不来）；本 skill 描述垄断**是什么以及它产生什么后果**。前者是成因，后者是状态与结果。
- 与 `mm-moat` 的区别: 护城河讲的是**可持续竞争优势**的多种来源（品牌、网络效应、成本等），是一套建设性框架；本 skill 聚焦"缺乏竞争者"这一种状态及其定价后果，且明确提醒它不永存。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先检验是否真的"缺乏竞争者"**
   - 完成标准: 明确列出客户实际会考虑的替代方案（包括不消费、二手、自建、跨品类替代、灰色渠道）。真垄断的判据是替代集里只剩"放弃"。
   - 判停条件: 若存在 2 个以上实质替代，说明这只是较强的市场支配力而非垄断，转 `mm-market-power`。
2. **评估支配力强度：放弃是不是可接受选项**
   - 完成标准: 判定该商品是刚需（如救命设备）还是可选。明确结论：刚需场景下放弃不是有吸引力的选项，支配力最强；可选品则提价会显著抑制需求。
3. **追溯垄断的来源**
   - 完成标准: 明确归因为法规/审批、专利、事件（竞品召回）、网络效应、资源独占、还是行政授权。EpiPen 案例提示：来源常常不是"做得更好"，而是竞争被外部因素清除。
4. **评估可持续性——这是最容易被跳过的一步**
   - 完成标准: 按"垄断并非永存"逐项检查：专利何时到期、法规是否可能演变、是否有潜在进入者、垄断者自身是否可能倒台。给出明确的时间窗口估计。
5. **给出现实应对**
   - 完成标准: 依用户角色给出具体动作——采购方：寻找/培育第二供应源、锁定长约、评估自建；投资方：检验高毛利在垄断消失后是否站得住；在位者：利用窗口期加固壁垒，而非依赖现状。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 市场上有多个实质竞争者，只是份额不均——这是市场支配力问题，不是垄断。
- 讨论如何建立长期竞争优势——用护城河/持续竞争优势框架更合适。
- 需要判断新玩家能否进入市场——用进入壁垒。
- 把"市场份额第一"直接等同于垄断——份额高但有活跃竞争者的市场（如多数科技市场）不适用。

### 容易误用的地方

- 书中明示：**垄断并非永存**——垄断者会倒台、专利会过期、法规会演变。任何把当前垄断外推到永久的分析都是错的。
- （推导, 非书中明示）把垄断等同于高利润的原因。利润可能来自效率、品牌或周期；只有"缺乏竞争者"才是垄断。混淆会导致对未来的错误外推。
- （推导, 非书中明示）忽略"放弃"本身也是替代品。书中明确把"放弃该商品"列为客户选项之一，支配力强度取决于这个选项有多糟糕。
- （推导, 非书中明示）把行政/法规造成的垄断与能力造成的垄断混为一谈。EpiPen 的支配力来自竞品召回与审批未通过，不是产品更好——这两者的可持续性完全不同。
- （推导, 非书中明示）用垄断指控代替分析。判定是否垄断需要先穷举替代集，否则只是情绪表达。

### 容易混淆的邻近模型

- **市场支配力（market power）**: 连续谱上的通用概念；垄断是它的极端端点。
- **完全竞争（perfect competition）**: 同一根轴的另一个端点——完全替代品、无支配力。
