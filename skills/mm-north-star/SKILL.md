# 北极星（north star）

## R — 原文 (Reading)

> 在商业领域，有一个思维模型从北极星上汲取了灵感。这个模型被称为“北极星”（north star），指的是一家公司的指导愿景。
>
> — 《思维模型》, 第3章 > 开篇（善用时间）

---

## I — 方法论骨架 (Interpretation)

北极星的位置几乎固定在北极正上方，抬头就能辨向，因此被借喻为一个**不变的长期目标**——公司或个人的指导性愿景。

它的作用机制不是"激励"，而是**筛选**。有了北极星，各项人生或商业抉择都能按同一个问题来决定："这个选项让我离它更近，还是更远？"于是大量看起来都不错的机会被快速否掉，剩下的行动方向一致，缓慢但稳步地接近目标。没有它，每一次取舍都要重新从零论证，方向会随机会漂移。

关键特征是它的**长期性与稳定性**：书中指出北极星是长期愿景，短期内到不了也没关系。这与它作为"方向标"的功能一致——方向标不需要你明天就抵达。

同时它不是终身不变的：它会随人生阶段变化，抵达之后需要换一颗新的。结婚、生子、换工作这类人生大事会推动它改变。

关键判据只有一句：**我知不知道自己要去哪里？** 如果这个问题答不上来，任何优先级排序都是无根的——你无法判断什么更重要，因为你不知道"重要"是相对于什么而言。

## A1 — 书中的应用 (Past Application)

### 案例: 鸭鸭搜索的北极星与个人北极星

- **问题**: 作者需要为一家公司、也为个人找到一个能指导所有抉择的长期方向，否则日常的选择会各自漂移、无法积累。
- **方法论的使用**: 鸭鸭搜索（DuckDuckGo）的北极星是"提高上网的安全性和可信度"——这句话的作用不是宣传口号，而是筛选器：任何功能、合作、商业化的取舍，都可以问"它让我们离这个目标更近还是更远"。作者列举的个人北极星包括"努力做个好家长""四十岁退休"等，同样用于给人生抉择定向。
- **结论**: 北极星的价值在于让分散的抉择指向同一个方向，从而缓慢但稳步地接近目标。书中也指出它是长期愿景，短期到不了没关系；人生大事会推动它改变，抵达后需要换一颗新的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对多个"看起来都不错"的机会，缺乏统一的取舍标准。
2. 感觉很忙、但说不清自己在往哪走，年度复盘时发现方向漂移。
3. 为公司/团队/个人制定愿景或年度方向，需要一句能真正用于筛选的话。
4. 优先级排序争执不下：各部门都说自己重要，缺一个共同参照。
5. 人生阶段发生变化（结婚、生子、换工作），需要重新校准方向。

### 语言信号 (用户的话里出现这些就应激活)

- "我这些年在忙什么"
- "这个机会要不要接，我说不上来"
- "我们的愿景到底该怎么定"
- "各部门都说自己重要，怎么排"
- "感觉一直在动，但没往前走"
- "north star / our vision / long-term goal / what are we aiming at"

### 与相邻 skill 的区分

- 与 `mm-high-leverage-activities` 的区别: 高杠杆活动解决"哪件事投入产出比最高"（效率层面），北极星解决"往哪个方向走"（方向层面）。方向未定时先定北极星，方向已定时才谈杠杆。
- 与 `mm-compound-interest` 的区别: 复利描述"持续投入会加速累积"的增长机制，北极星决定"往哪里持续投入"。复利保证走得快，北极星保证走得对——方向错了，复利只会让你更快地到达错误的地方。
- 与 `mm-pareto-principle` 的区别: 帕累托法则用于"从已有事项中找出关键的少数"（分配资源），北极星用于"判断这些事项值不值得存在"（确定方向）。前者是优化，后者是定向。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先测"知不知道要去哪"**
   - 直接问用户：用一句话说出你/你们三年后要成为什么样子。
   - 完成标准: 用户能给出一句具体的陈述，而不是"做得更好""增长"这类空话。
   - 判停条件: 若用户已有清晰且可用的愿景，跳过步骤 2，直接进步骤 3 做筛选检验。
2. **把愿景写成可筛选的一句话**
   - 要求：具体到能判断"某个选项是靠近还是远离"；避免把指标当愿景（那是 KPI，且会触发 `mm-goodhart-s-law`）。
   - 完成标准: 一句话，且能用它判断至少 3 个真实选项的取舍。
3. **用最近的决策做回溯检验**
   - 列出过去半年 3-5 个重要决定，逐个问：它让我们更近还是更远？
   - 完成标准: 得到一个"符合/偏离"的清单；若多数偏离，说明实际方向与宣称方向不一致。
4. **识别并清掉偏离项**
   - 找出消耗资源最大却与北极星无关的事项，给出停做/降级/移交的具体建议。
   - 完成标准: 至少 1 项明确的"停止做"，并说明释放出的资源去向。
5. **设定复核与更换机制**
   - 因为人生阶段会推动它改变，需定期复核；抵达后要换一颗新的。
   - 完成标准: 写明复核周期，以及"什么情况出现时说明该换一颗北极星"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短期排期与日常执行细节：那是时间管理与优先级工具的范围，动用愿景框架会把简单问题复杂化（推导，非书中明示）。
- 已有清晰、可量化的短期目标且只需执行时：直接执行即可。
- 危机状态下的应急决策：此时需要的是止损，不是方向校准（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 书中未提硬性局限，但指出北极星是长期愿景，因此短期内到不了也没关系——把它当成季度目标会导致频繁更换、失去定向作用（书中明示的方向）。
- 人生大事（结婚、生子、换工作）会推动它改变，抵达后需要换一颗新的——把北极星当成永恒不变的承诺是误用（书中明示）。
- 容易把 KPI 或指标当成北极星：指标会被腐蚀（见 `mm-goodhart-s-law`），愿景应当是对"要成为什么"的描述（推导，非书中明示）。

### 容易混淆的邻近模型

- 与高杠杆活动：方向 vs 效率。判断顺序是先方向后效率，方向未定时谈杠杆是在加速漂移。
- 与复利：复利是引擎，北极星是方向盘。两者常组合使用，但不可互相替代。
