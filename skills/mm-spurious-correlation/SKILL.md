# 虚假相关（spurious correlation）

## R — 原文 (Reading)

> 如今，测试各种信息之间的相关性比以往任何时候都容易，因此必然会发现许多虚假的相关性。事实上，有一个有趣的网站（也有同名书籍）叫作"虚假相关"（Spurious Correlations）
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

虚假相关是两组变量在统计上呈现高度相关、但只是随机巧合，彼此没有任何机制上的联系。

为什么它会越来越多地出现：测试相关性比以往任何时候都容易（数据多了、工具便宜了），而变量越多、检验次数越多，出现"看起来显著"的相关的**期望次数**就越多。这不是信号变多了，而是噪声的绝对量变多了——这是多重比较的自然结果，不是发现。

关键判据有两条，两条都要过：
1. **机制**：能不能说出一个把两者联系起来的具体、可检验的因果链？说不出，就只是数字上的巧合。
2. **复现**：这个相关能不能在独立的数据集或时间段上重复出现？虚假相关几乎总是一次性的。

书中举的例子是奶酪消费量与"被床单缠绕致死"人数的高度相关——两者都随时间缓慢上升，所以统计上高度相关，但你编不出一个可信的机制把它们连起来。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿两条看起来同步变动的数据得出因果或强关联结论（"销量和这个指标高度相关，所以……"）。
2. 用户在做数据挖掘或探索性分析，从几十上百个指标里"发现"了一个漂亮的相关。
3. 用户看到一张"两条曲线几乎重合"的图（尤其是都随时间上升的宏观序列），问是不是真有关系。
4. 用户要评估别人的研究报告或媒体报道里那个惊人的相关性结论。

### 语言信号

- "这两个数据居然高度相关。"
- "数据显示 A 和 B 几乎同步变动。"
- "相关系数 0.9，肯定是相关的吧？"
- "我从数据里挖出来一个规律。"
- "两条曲线几乎重合了。"
- "these two are highly correlated / correlation of 0.9 / the charts line up perfectly"

### 与相邻 skill 的区分

- 与 `mm-correlation-does-not-imply-causation` 的区别: 后者说"相关不等于因果"——相关可能真实存在，只是方向或第三因未知；虚假相关更进一步：**连相关本身都是假的**，换个数据集就消失。判据：先问相关是否可复现（虚假相关），再问因果方向（相关不代表因果）。
- 与 `mm-data-dredging` 的区别: 数据捕捞是**行为**（反复检验直到找出显著结果，即 p 值篡改）；虚假相关是这种行为**产出的结果**。控制数据捕捞（预先注册假设、多重比较校正）是预防虚假相关的手段。
- 与 `mm-clustering-illusion` 的区别: 聚集性幻觉是在**空间或随机序列**里看出并不存在的簇（如"癌症高发区""点球有热手"）；虚假相关是在**两个变量的配对数据或时间序列**上看出并不存在的相关。

## E — 可执行步骤 (Execution)

1. **复述并锁定声称的相关**
   - 明确：哪两个变量、什么数据范围、相关系数多少、谁算的。
   - 完成标准: 变量、时间范围、样本量、系数都写清楚。
2. **做机制检验**
   - 要求给出一个具体、可检验的因果链：A 通过哪些步骤影响 B？
   - 完成标准: 若给不出机制链，标记为"机制缺失"；若能给出，检查是否存在可验证的中间变量。
3. **做复现检验**
   - 换时间段、换样本、换数据集重算。
   - 完成标准: 明确报告在独立数据上是否依然相关；若无法复现，判定为虚假相关。
4. **做多重比较核算**
   - 问：一共检验了多少对变量？按这个次数，随机出现这种强度相关的期望次数是多少？
   - 完成标准: 给出检验次数与期望次数的粗算（例如"检了 200 对，出现 r>0.8 的期望约 X 次"），并与实际观察到的数量对比。
5. **给出结论与后续**
   - 若判定虚假相关，明确告知，并建议把该"发现"降级为待验证假设，需预先注册后再检验。
   - 完成标准: 结论明确（真 / 假 / 存疑），且给出下一步的验证方式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 相关有明确的机制支持、且已在多个独立数据集上复现——这是真信号，不要用它制造无谓怀疑。
- 用户只是在做描述性统计（"这两个指标都涨了"），尚未提出因果主张。
- 需要判断的是因果方向或第三变量——那是 `mm-confounding-factor` / `mm-correlation-does-not-imply-causation`。

### 容易误用的地方

- 书中未给出该模型的边界说明。（以下为推导，非书中明示）
- 反向误用：用"可能是虚假相关"来拒绝一切不合意的数据。判据是机制 + 复现两条检验，不是"我不喜欢这个结论"。
- 特别警惕随时间共同上升的宏观序列：两个各自有趋势的变量几乎总会相关，这类相关最容易骗人。

### 容易混淆的邻近模型

- **相关性不代表因果性**: 相关是假的 vs. 相关是真的但推不出因果。
- **混淆因素**: 混淆因素解释的是"为什么两个本无因果的变量会真实相关"（存在第三方共同原因），此时相关不是虚假的，只是被误解了。
