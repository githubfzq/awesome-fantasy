# 催化剂（catalyst）

## R — 原文 (Reading)

> 催化剂能减少启动化学反应所需的活化能。例如，炎热干燥的日子更容易发生火灾，这是因为气温升高、水分减少成了催化剂。
>
> — 《思维模型》, 第4章 > 别跟自然对着干

---

## I — 方法论骨架 (Interpretation)

催化剂是降低反应活化能、但自身不被消耗的东西。这句话里有三个必须同时成立的条件，缺一个就不是催化剂：

第一，它降低的是**门槛**，不是终点。反应最终放出多少能量、生成什么产物，催化剂一概不改变——它只改变到达那里的速度和难易。所以催化剂不能把一个注定失败的事变成成功，只能让本会发生的事更快发生。

第二，它**自身不被消耗**。这是催化剂与"投入"的分界线：加三倍人手是投入，不是催化；设计一个让三个人自动协作的机制才是催化。

第三，它通常是**环境条件**而非主角。炎热干燥的天气让火灾更容易发生，但天气不是火——它只是改变了燃料被点燃的门槛。

映射到社会层面，书中明确指出：个人的"承诺"与组织的"强制函数"都可以充当强大催化剂。原因是它们改变的是默认状态与约束条件，而不是增加推力。

关键判据：如果我把它拿走，这个变化还会发生吗？如果会，只是慢一点——那是催化剂。如果不会——那是必要条件，不是催化剂。

## A1 — 书中的应用 (Past Application)

### 案例: #MeToo 与拆除纪念像运动

- **问题**: 这两场社会运动为何能在短时间内迅速扩散、演变成大规模集体行动？
- **方法论的使用**: 作者指出"社交媒体上的帖子和记者的报道成了催化剂，成了其他人主动宣传这些运动的蓝图和渠道"——它们没有创造诉求（诉求早已存在），只是把参与门槛从"我要独自发声"降到"转发即可"。
- **结论**: 潜在的不满早已积累，缺少的是那条低门槛的参与路径；一旦它被提供出来，运动就自行加速。这印证了催化剂"只改变速度、不创造内容"的特性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户已经明确目标（要推广、要改变习惯、要推动变革），在问"用什么能让它自己跑起来"——需要帮他找杠杆物而非更多投入。
2. 用户的方案本身正确但扩散太慢、采纳率太低——需要识别是门槛问题并设计催化剂。
3. 用户在设计组织机制，希望减少监督与推动成本——需要考虑承诺、强制函数这类改变默认状态的装置。
4. 用户投入了大量资源却收效甚微，怀疑方向没错——需要检查是不是一直在加"反应物"而从未加催化剂。

### 语言信号 (用户的话里出现这些就应激活)

- "有没有什么办法能让这件事自己转起来？"
- "我们投入了很多人力，效果还是一般，是不是缺个什么？"
- "怎么能让大家不用催就主动去做？"
- "我想找个杠杆，少花钱多办事。"
- "How do I make this spread on its own?"
- "What's the force multiplier here?"

### 与相邻 skill 的区分

- 与 `mm-activation-energy` 的区别: 活化能是那道门槛的**高度**（诊断）；催化剂是**降低它的那个东西**（处方）。用户问"为什么启动不了"用活化能，问"用什么能启动"用催化剂。
- 与 `mm-leverage` 的区别: 杠杆作用泛指"小投入大产出"的放大效应，可以靠投入技巧实现；催化剂特指"自身不被消耗、只降低门槛"的作用物，强调它不参与反应、不改变终点。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认目标反应已确定**
   - 明确问：你希望发生的那个变化具体是什么？它现在为什么没发生——是方向错，还是门槛高？
   - 完成标准: 用户能说清目标变化；若说不清，停止本 skill，转向目标澄清。
2. **定位当前最高的那道门槛**
   - 问：从现状到目标，卡在哪一步？是启动（没人开始）、扩散（开始的人传不开）、还是持续（传开了但留不住）？
   - 完成标准: 指出一个具体的卡点环节。
3. **候选催化剂头脑风暴（至少 3 个）**
   - 从三类里各取：环境条件（改变默认选项、改变物理环境、改变信息可见度）、承诺与强制函数（公开承诺、截止日、不可逆的小动作）、渠道与蓝图（给他人一个可复制的模板）。
   - 完成标准: 至少 3 个候选，每个都写明"它降低的是谁的什么门槛"。
4. **用三条件筛掉伪催化剂**
   - 对每个候选问：它自身被消耗吗？它改变了终点吗？拿走它变化还会发生吗（只是慢）？
   - 完成标准: 至少留下 1 个通过三条件检验的真催化剂。
   - 判停条件: 若所有候选都被消耗、或改变了终点，说明用户找的是"投入"或"方向调整"，明确告知并转向 `mm-expected-value` 或 `mm-cost-benefit-analysis`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标本身还没验证、方向存疑时——催化剂只会让你更快地到达一个可能错误的地方。
- 问题出在能力或资源绝对不足（团队不会做、预算根本不够）——这不是门槛问题，加催化剂无用。
- 系统存在安全约束的场景（医疗、金融合规、安全关键系统）——"让变化自己发生"恰恰是需要避免的。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给出该模型的边界说明。（以下为推导，非书中明示）
- 把"加资源"误当催化剂：招更多人、投更多广告是增加反应物，不是降低活化能，成本线性增长。
- 忽视催化剂的中立性：天气既能让营火更容易生起，也能让山火更容易失控——催化剂不问方向，坏的变化同样会被加速。
- 催化剂不改变终点：不要指望用一个催化剂救活一个收益为负的项目。

### 容易混淆的邻近模型

- 与**活化能**: 见 A2 区分——诊断 vs. 处方，二者成对出现。
- 与**强制函数（forcing function）**: 强制函数是催化剂的一种具体形式（用不可逆约束改变默认状态），但催化剂的外延更广，还包括环境、渠道、信息可见度等。
