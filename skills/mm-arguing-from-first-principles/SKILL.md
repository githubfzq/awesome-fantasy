# 从第一性原理出发（arguing from first principles）

## R — 原文 (Reading)

> 自下而上地思考问题，运用你认为是正确的基本构件得出合理的（有时是全新的）结论。所谓的"第一性原理"是一套不言而喻的假设，也是构成你结论的基础。
>
> — 《思维模型》, 第1章 少犯错 > 保持简洁，笨蛋！

## I — 方法论骨架 (Interpretation)

两种推理方向：

- **类比推理（reasoning by analogy）**: 别人怎么做、过去怎么做、行业惯例是什么，然后在此基础上微调。快，但会继承源头的全部错误和全部约束——包括那些已经不再成立的约束。
- **第一性原理（first principles）**: 把问题拆到"我确信为真的最基本事实"（物理定律、原材料市价、数学关系、不可违背的约束），再从这些事实向上重建结论。慢，但得到的结论不受历史路径污染。

为什么类比会系统性地出错？因为惯例里沉淀着大量**当时的约束**：某条供应链在二十年前稀缺所以贵，某个流程因为旧系统限制才存在，某个价格包含了早已消失的渠道成本。惯性会让这些约束在成因消失后继续存在，而类比推理永远看不见它们——它从"现状"出发，而现状本身就是一堆历史的沉积。

第一性原理的威力在于**它能算出真实的下限**。当你问"电池组现在卖多少钱"，你得到的是市场给出的一个数，这个数包含了所有人的利润、渠道、惯例；当你问"钴、镍、铝、碳这些原料在交易所值多少钱"，你得到的是物理和化学给出的下限。两个数字之间那五倍的差距，就是惯例占据的空间，也是创新的空间。

关键判据有三个：
1. 当前结论是**从某个类比/惯例继承来的**，还是**从基本事实推出来的**？
2. 能否把问题拆到"我们确信为真、且无法再往下拆"的构件？（像食材，或数学公理）
3. 自下而上推出的结果，与自上而下接受的惯例，差多少？差得越多，越值得追问惯例里锁着什么已失效的约束。

书里给了一个重要的补充：**即使最终接受传统结论，这个过程本身也会让你对主题理解得深得多**——所以它不是只在要颠覆时才用。

## A1 — 书中的应用 (Past Application)

### 案例: 马斯克拆解电池组成本
- **问题**: 业界普遍认为电池组很贵，每千瓦时约 600 美元，电动车因此在成本上无法与燃油车竞争。这个数字被当作一个给定的前提。
- **方法论的使用**: 不问"电池组现在卖多少钱"，而是问"它的原材料在伦敦金属交易所值多少钱"——把电池组拆成钴、镍、铝、碳、以及一些用于分隔的聚合物和一个钢罐，逐一查这些原料的市场价格，再加总。
- **结论**: 算出来的原料成本约每千瓦时 80 美元，与 600 美元的市价认知相差近一个数量级。差距不在物理定律，而在制造工艺与供应链惯例——因此它是可以被工程改进压缩的，而不是一个不可逾越的天花板。

（书中另举《阿波罗 13 号》的例子：工程师用宇航员桌上现有的零件——纸、胶带、塑料袋——解决方形滤罐塞进圆洞的问题，同样是不接受"我们手头只有什么"的现状，而是回到"要密封通气，物理上需要什么"。）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **被"行业惯例/别人都这样"卡住**: 用户在设计一个方案，但所有参考对象的做法都一样，于是以为这是唯一解。需要算出真实边界，找出惯例锁死的空间。
2. **成本/时间/资源的估算被质疑，却说不出依据**: 报价、工期、预算都来自"上次差不多是这个数"。需要拆到底层构件重新加总。
3. **要判断某件事在物理/数学上到底可不可行**: 不是"难不难"，而是"可能不可能"。可行性判断必须落到不可违背的约束上。
4. **进入成熟行业，想找结构性机会**: 惯例价与基本事实价之间的差额，就是新进入者的空间。
5. **学一个领域但只会背结论**: 用户想真正理解而非记住，重建一遍推导过程。

### 语言信号 (用户的话里出现这些就应激活)

- "行业里都是这么做的，没办法"
- "别人报价就是这样，我们已经谈到最低了"
- "这个东西成本到底能低到什么程度？"
- "物理上/理论上这可能吗？"
- "我们要不要从头算一遍，而不是参考同行"
- "这个价格里到底包含了什么"
- "Let's reason from first principles." / "What's the theoretical minimum?" / "Why is it done this way?"

### 与相邻 skill 的区分

- 与 `mm-ockham-s-razor` 的区别: 奥卡姆剃刀是**削减**工具——在多个都能解释同一现象的假设里删掉不必要的；第一性原理是**重建**工具——从底部往上搭一个新的。一个做减法，一个做加法后重算。
- 与 `mm-de-risking` 的区别: 第一性原理推出的结论本身仍然只是**假设**，必须回到现实检验；去风险化就是那个检验环节（书中明示"光靠空想不够，必须在现实中检验"）。二者是前后工序：先推导，再检验。
- 与 `mm-reframe-the-problem` 的区别: 重新定义问题是换一个**问法**（也许我们要解决的不是 X 而是 Y）；第一性原理是保持问法不变，换一个**推导起点**（不接受继承来的答案）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别并写出当前的"继承结论"**
   - 完成标准: 明确写出用户当前接受的那个数字/做法/判断，以及它是从哪来的（同行惯例、上次经验、权威说法、供应商报价）。写不出来源，说明它可能是凭直觉，直接进第 2 步。
2. **把它拆到不可再拆的基本构件**
   - 完成标准: 拆到"我们确信为真"的一层——物理定律、原材料市价、数学关系、法定约束。每个构件都要能回答"凭什么它是真的"。
   - 判停条件: 若某个构件只能是"行业经验值"，标记它为假设而非事实，不许混入基本事实层。
3. **自下而上重新加总/推导**
   - 完成标准: 只用第 2 步的事实层做推导，得到一个独立结果（成本下限、时间下限、可行性判定）。推导过程可被他人逐步复核。
4. **对比两个结果，定位差额的来源**
   - 完成标准: 算出"继承结论"与"基本事实推导"的差额，并说明这个差额由什么构成（利润、渠道、过时工艺、已失效的历史约束、真实但必要的复杂性）。
   - 判停条件: 若差额来自仍成立的真实约束（如法规、稀缺产能），则传统结论可能是合理的，如实告知用户，不要为了创新而创新。
5. **把结论转成待检验的假设，交给去风险化**
   - 完成标准: 输出 1-3 条明确的、可用最低成本在现实中检验的假设（书中明示：第一性原理只是假设，必须在现实中检验）。
   - 判停条件: 若某条假设无法被低成本检验，明确标注风险等级，不要假装它已被验证。
6. **（可选）即使维持原结论，输出新增的理解**
   - 完成标准: 列出至少 2 条"不推这一遍就不会知道"的认识（哪个构件占成本大头、哪条约束已经失效、瓶颈在哪里）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **日常小决策**: 书中的立场是简化、别过度复杂化。中午吃什么、选哪个模板，用类比就够，从零推导是浪费。
- **决策可逆且成本低时**: 直接试，比推导快。用去风险化替代。
- **缺乏基本事实层的领域**（推导, 非书中明示）: 涉及人的偏好、审美、文化、政治博弈的领域，没有"确信为真的基本构件"，强行推导会得到伪精确的结论。
- **时间压力下**: 第一性原理推导是昂贵的操作，需要查证与计算。来不及就先按惯例走，留待事后复盘。

### 书中警告的失败模式 / 容易误用的地方

- **第一性原理只是假设，可能错也可能介于两者之间，光靠空想不够，必须在现实中检验**（书中明示，并明确指向"去风险化"）。推导出的 80 美元不等于能造出 80 美元的电池。
- **作者强调它不是万能钥匙**（推导补充）: 有时传统智慧之所以是传统智慧，正是因为它压缩了大量已经验证过的经验。不接受它，就要付出重新发现这些经验的成本。
- （推导, 非书中明示）**伪第一性原理**: 把"我觉得理所当然的商业常识"当成基本事实（如"用户一定更便宜的"）。真正的事实层只接受物理定律、市场价格、数学、法律这类可查证的陈述；任何关于人行为的陈述都应标记为假设。
- （推导, 非书中明示）**忽略加总成本**: 拆开看每个构件都很便宜，但把它们组装起来的工艺、良率、供应链协调往往才是主要成本来源。只算原料价会严重低估总成本。

### 容易混淆的邻近模型

- **类比推理（reasoning by analogy）**: 不是谬误，是默认模式，只是会继承源头的约束。第一性原理用于怀疑它，不用于取代它。
- **苏格拉底式提问 / 5 Whys**: 追问"为什么"是为了找原因；第一性原理追问"这是什么做的、物理上要花多少"，是为了重建答案。
