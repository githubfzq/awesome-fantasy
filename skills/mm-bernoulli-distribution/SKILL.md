# 伯努利分布（Bernoulli distribution）

## R — 原文 (Reading)

> 像这样的二元数据通常会用另一种概率分布来分析，也就是所谓的"伯努利分布"（Bernoulli distribution）。它呈现的是某个"是/否"型实验或问题（例如市场调查或民意调查）的结果。

> — 《思维模型》, 第5章 > 钟形曲线

---

## I — 方法论骨架 (Interpretation)

伯努利分布描述的是最简单的一类随机结果：**只有两个值，二选一**——是或否、点或未点、买或没买、治愈或未愈。

它的巧妙之处在于一个记账技巧：把"是"记作 1、"否"记作 0。这样一来，一堆看起来没法做统计的"是/否"答案就变成了一串数字，于是——**支持率就是所有答案的平均值**。问了 100 个人有 43 个说"是"，那 43 个 1 和 57 个 0 的平均数就是 0.43。转化率的本质就是一个均值。

这一步转换的意义很大：一旦二元结果变成了均值，所有适用于均值的工具就都可以用了。特别是配合**中心极限定理**，这个平均值可以被当作正态量来处理——于是你就能给它算抽样分布、误差范围、置信区间，判断"43% 这个数到底有多可信"。

书里点出的典型场景是市场调查、民意调查，以及三类"是否"型结果：广告宣传（是否购买）、临床试验（是否对治疗有反应）、A/B 测试（是否点击）。

关键提醒：单个观测是伯努利（0/1），但**我们关心的量——比例——不是伯努利**，它是很多次伯努利试验的平均值，其分布要靠中心极限定理才能当正态处理。这是使用这套工具的前提，不是附赠品。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要分析一个转化率/点击率/通过率，并想进一步做显著性判断或误差范围估计。
2. 用户在设计 A/B 测试，需要知道"是否点击"这类指标该怎么建模和估算样本量。
3. 用户在做民调或满意度调查（是否推荐），想知道这个比例的可信度。
4. 用户把二元结果当连续量处理（比如直接对比两组的"平均 0/1 值"却不知道这就是比例），需要澄清口径。

### 语言信号

- "我们的转化率是 4.3%，这个数准吗？"
- "点击/没点击这种数据怎么算显著性？"
- "问 100 个人有 43 个说会买，能下结论吗？"
- "是不是可以用正态分布来算？"
- "Bernoulli" / "binary outcome" / "conversion rate significance"

### 与相邻 skill 的区分

- 与 `mm-normal-distribution` 的区别: 正态分布描述连续型钟形数据（身高、血压）；伯努利分布描述 0/1 二元结果。二者通过中心极限定理连接——**是均值（比例）近似正态，不是单个观测正态**。
- 与 `mm-sample-distribution` 的区别: 伯努利分布是**单次**"是/否"结果的分布；抽样分布是**多次抽样后那个比例**的分布。前者是原材料，后者是你真正用来做推断的东西。
- 与 `mm-central-limit-theorem` 的区别: 中心极限定理是把二元结果的比例"变成"可当正态处理的理论依据；伯努利分布是被处理的对象。

## E — 可执行步骤 (Execution)

1. **确认结果确为二元** — 完成标准: 每个观测只能取两个值（是/否、1/0）；若有第三类（如"不知道""部分转化"），需先明确归并为二元或改用多分类方法。
2. **用 0/1 编码并算出比例** — 完成标准: 把结果编码为 0/1，明确"支持率 = 所有答案的平均值"这一等价关系，得到比例 p。
3. **检查正态近似的前提** — 完成标准: 检查 np 与 n(1-p) 是否都足够大（常用经验是各 ≥5~10）；不满足则明确告知中心极限定理的正态近似不可靠，需改用精确方法。
4. **接上抽样分布工具** — 完成标准: 在前提满足时，把 p 当作正态量处理，继续做误差范围/置信区间的计算（转 `mm-sample-distribution` / `mm-margin-of-error`）。
5. **把结论说回业务语言** — 完成标准: 最终输出是"转化率约为 X%，我们有 Y% 的把握真实值落在 A–B 之间"这类可直接用于决策的表述。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **结果是计数或多分类**: "用了几次""满意度 1-5 分"不是伯努利，强行二值化（如把 4-5 分算作"满意"）会丢信息且引入人为切点。
- **样本量极小或比例极接近 0/1**: 此时 np 或 n(1-p) 太小，正态近似失效，结论会严重失真。
- **观测之间不独立**: 同一用户的多次点击、同一家庭的多份问卷互相相关，独立同分布前提不成立，比例的分布不再是简单的伯努利平均。

### 容易误用的地方

- **把单个 0/1 观测当正态处理**: 正态近似适用于**多次试验的平均（比例）**，不是单次结果。（推导, 非书中明示）
- **书中未给出边界条件**: 原书只说明伯努利分布适用于"是/否"型实验并给出三类应用场景，未讨论样本量或比例极端时正态近似何时失效。（书中未提）
