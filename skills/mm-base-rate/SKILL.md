# 基础比率（base rate）

## R — 原文 (Reading)

> 结果取决于醉酒司机所占的基础比率（base rate）。请考虑以下情况：假设每个人都做出了正确的决定，没有人酒后驾车，那么无论酒精浓度测试结果如何，这个人没醉酒的概率都是100%。
>
> — 《思维模型》, 第5章 > 具体情况具体分析

---

## I — 方法论骨架 (Interpretation)

基础比率是**某件事在总体中的先验发生率**——它是所有条件概率推算的分母。脱离它去谈"检测准不准"是没有意义的。

直觉上，人们会认为"测试错误率 5%，所以测出阳性就有 95% 概率是真的"。这个推理漏掉了分母。书中用酒驾检测给出了完整演算：

- 醉酒司机的基础比率：1/1000（千分之一）
- 测试错误率：5%
- 警察拦下 1000 人 → 平均 1 个真酒驾者，但要经历约 **50 次测试出错**
- 所以"测出醉驾且真的醉驾"的概率只有约 **2%**，司机其实清醒的概率是 **98%**

为什么会这样？因为真阳性只有 1 个，而假阳性有 50 个——**假阳性在数量上淹没了真阳性**。基础比率越低，同样的错误率产生的假阳性占比就越高。

书中那个极端的说法把这个机制推到了底：如果根本没人酒驾（基础比率为 0），那无论测出什么结果，"这个人没醉"的概率都是 100%。

关键判据：**拿到任何"命中/阳性/告警"的结论前，先问三件事——这件事在总体里有多常见？测试的错误率是多少？两者哪个更大？** 当基础比率远小于错误率时，绝大多数命中都是假的。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 部署或评估筛查系统（疾病筛查、风控拦截、内容审核、安全告警），需要估算"命中里真阳占比"（精确率）。
2. 看到"某某检测准确率 99%"的宣传，需要判断它在实际场景中有没有用。
3. 排查"为什么告警这么多但几乎全是误报"。
4. 评估一个罕见风险（欺诈、故障、事故）的预警方案是否值得投入。

### 语言信号

- "这个检测准确率 99%，应该够用了吧"
- "告警一大堆，但基本都是误报"
- "这种情况到底有多常见"
- "筛查阳性里真正有问题的能占多少"
- "千分之一的发生率，测出来准吗"
- "what fraction of these alerts are real / precision vs accuracy"

### 与相邻 skill 的区分

- 与 `mm-base-rate-fallacy` 的区别: 基础比率是**正确的概念与计算**（"我该把这个分母放进去"），基础比率谬误是**忘记放它时犯的错**。教人算精确率用本 skill，指出某人推理出错用谬误版。
- 与 `mm-false-positive` 的区别: 假阳性关注**单次判断的错误类型与两类错误的权衡**；基础比率解释**为什么在罕见场景下假阳性会占压倒性多数**。前者是错误分类，后者是数量结构。
- 与 `mm-prior` 的区别: 先验是贝叶斯框架里"新证据到来之前的已有认知"，适用范围更广（可以是主观信念强度）；基础比率特指可统计的**总体发生率**，是先验的一种常见形式。

## E — 可执行步骤 (Execution)

1. **确定目标事件的基础比率**
   - 问：在没有任何检测结果的情况下，这件事在总体中发生的比例是多少？
   - 完成标准: 得到一个具体数字（哪怕是量级估计），并说明数据来源或估计依据。
   - 判停条件: 若基础比率完全无法估计，明确标注结论的不确定性，改用"需要多少基础比率才能让这个检测有用"的反向提问。
2. **取一个具体总体，把四类结果的人数填出来**
   - 用 1000（或 10000）人做假想总体：真阳性 = 总数 × 基础比率 × 敏感度；假阳性 = 总数 × (1−基础比率) × 误报率。
   - 完成标准: 得到四格人数表，尤其要算出假阳性的绝对数量。
3. **计算精确率：真阳性 ÷ 所有阳性**
   - 完成标准: 给出"命中里真阳占比"的具体百分比，并与直觉中的"准确率"对比，指出差距。
4. **给出改进杠杆的优先级**
   - 三条路：降低误报率（提高特异度）、缩小筛查范围以提高局部基础比率（先筛高危人群）、接受低精确率并设计二次确认流程。
   - 完成标准: 明确指出在当前基础比率下，哪条杠杆最有效（通常不是继续提高检测准确率，而是缩小筛查范围）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 基础比率接近 50%（事件并不罕见）：此时假阳性不会淹没真阳性，精确率与准确率接近，做这套演算收益有限（推导，非书中明示）。
- 目标是"不漏掉"而非"命中要准"（如高危传染病首轮筛查）：此时应优先看敏感度与假阴性，而不是精确率（推导，非书中明示）。

### 容易误用的地方

- 书中未提边界，但案例本身给了最强的警告：**不要脱口而出"99% 准确率 = 99% 可信"**。准确率与精确率是两回事（推导，非书中明示）。
- （推导，非书中明示）容易把"总体发生率"套到"已被筛过的高危子群"上，从而低估精确率。基础比率必须对应当前实际的筛查人群。
- （推导，非书中明示）容易只强调"大部分告警是假的"而让人放弃系统。实际上低精确率的筛查在高危子群里仍然有价值，正确反应是分层筛查而非取消。

### 容易混淆的邻近模型

- 先验（prior）：更广义的"证据前认知"，基础比率是可统计的那一种。
- 假阳性与假阴性（false-positive）：错误分类本身；基础比率决定了各类错误的数量对比。
