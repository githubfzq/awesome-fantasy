# 收益递减法则（law of diminishing returns）

## R — 原文 (Reading)

> 在经济学中，这个模型被称为“收益递减法则”（law of diminishing returns）。它是指，在取得的成果达到一定程度后，随着付出努力的增加，工作效率却不断降低。
>
> — 《思维模型》, 第3章 > 事半功倍

---

## I — 方法论骨架 (Interpretation)

在一件事上持续加码，起初产出增长很快，但越过某个点之后，每多投入一单位，换回的产出越来越少——这就是收益递减。再往后推，投入还可能变成净损耗（负收益）。

关键的是，这个模型**不告诉你"到这里就停"**。正确的退出判据是比较机会成本：如果同样的劳动放到别的事上能带来更大收益，就该转去做；如果别处也没有更好的用途，那么继续做这件事仍然是有进展的，哪怕效率已经降低。

所以完整的用法是双问：一问"边际产出是不是已经明显下降"，二问"我有没有更符合二八定律的高杠杆活动被漏掉了"。后者需要定期头脑风暴来检验，而不是默认"眼前这件事就是最值得做的"。

判据是边际量，不是总量：不要问"总共投入了多少"，要问"再投入一小时能换来什么"。

## A1 — 书中的应用 (Past Application)

### 案例: 葛兰素史克的临床研究报告改到第六稿

- **问题**: 外部咨询团队为葛兰素史克评估临床研究报告时，发现报告被反复修改，团队投入了大量时间打磨。
- **方法论的使用**: 作者用"边际产出"的视角逐稿检查：从第二稿开始，质量其实并没有实质提升，第三到第六稿明显是在浪费时间。
- **结论**: 越过收益递减点之后的额外投入不再产生价值；此时应停止打磨，把精力转向其他更高杠杆的活动。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在反复打磨同一份产出（方案、设计稿、文章、代码），说不清什么时候算"够了"。
2. 用户在某个方向持续投入（投放预算、学习时间、优化迭代），感觉效果越来越差，想确认是不是该停。
3. 用户陷入无止境的精修，交付被拖延，需要一条可执行的止损线。

### 语言信号 (用户的话里出现这些就应激活)

- "已经改到第六版了，感觉也没变好多少"
- "再投入还有意义吗"
- "这个指标越优化越难提升，是不是到头了"
- "我不确定什么时候可以交付/收手"
- "is it worth polishing this any further"

### 与相邻 skill 的区分

- 与 `mm-pareto-principle` 的区别: 二八定律回答"该抓哪 20%"，收益递减回答"抓住之后该投到什么程度为止"。
- 与 `mm-sunk-cost-fallacy` 的区别: 沉没成本谬误处理"已经投入的拿不回来"带来的非理性坚持；收益递减是**客观的边际产出下降**，即便没有心理因素也成立。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认当前处在曲线的哪一段：把已完成的投入分段，标出每段的产出增量**
   - 完成标准: 得到一个"投入段 → 产出增量"的粗略表，能看出增量是否在下降。
2. **估算下一单位投入的边际产出**
   - 完成标准: 明确回答"再投入 X（一小时/一天/一笔预算）大概能换来什么"，并给出判断依据。
   - 判停条件: 若边际产出仍与之前相当，说明还没到递减区，本模型暂不适用。
3. **比较机会成本：同样的投入放到别处能换回什么**
   - 完成标准: 至少列出 2 个替代用途及其预期产出，与当前边际产出对比。
4. **给出结论：继续 / 转向 / 停止，并设一条明确的止损线**
   - 完成标准: 结论是三者之一，且止损线可度量（如"再改一版，若评分不提升就发"）。
5. **做一次头脑风暴检查：有没有被漏掉的高杠杆活动**
   - 完成标准: 列出至少 3 个候选的替代高杠杆活动，确认没有明显更优选项被忽略。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 处于学习曲线早期或复利效应的领域（技能积累、内容资产、关系网络），早期边际产出低是暂时的，此时退出会错失后续拐点。
- 存在硬性的质量门槛或合规要求（医疗、航空、安全）时，"够用就好"的边际逻辑不适用。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示：达到收益递减点**不意味着必须立刻停下**，取决于机会成本——如果别处没有更好的用途，继续做仍有进展。
- 书中明示：也不该死脑筋地认为永远没有更好的事可做，应该定期头脑风暴检查是否漏掉了高杠杆活动。
- （推导, 非书中明示）"边际产出下降"常被主观感受误判：熟练度提升带来的加速期与真正的递减期在体感上相似，应看数据而非感觉。

### 容易混淆的邻近模型

- 与效用递减法则（law-of-diminishing-utility）混淆：后者指消费越多、每单位带来的满足感越低，本模型指生产投入的边际产出下降。
- 与负收益（negative-returns）混淆：负收益是越投入总产出越少的阶段，是收益递减推到极端之后的状态。
