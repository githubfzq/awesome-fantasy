# 聚集性幻觉（clustering illusion）

## R — 原文 (Reading)

> 随机数据通常包含一定的规律。当你发现，抛20次硬币有一半的概率能连续抛出4次正面，是不是会觉得特别惊讶？类似的规律常常被错误解读，误认为能证明某种现象不是随机的。这种出于直觉犯的错被称为聚集性幻觉（clustering illusion）。
>
> — 《思维模型》, 第5章 > 警惕小数定律

---

## I — 方法论骨架 (Interpretation)

随机并不等于均匀。恰恰相反，随机过程必然产生簇——抛 20 次硬币，有一半的概率能连续抛出 4 次正面。人类的模式识别系统却拒绝承认随机，一旦看见抱团，就执意要给出一个解释。

于是出现了那个反直觉的事实：真正随机的数据看起来"抱团"，而人为均匀排布的数据看起来才"像随机"。这一错觉在二战伦敦人身上表现得最清楚——他们坚信德军轰炸有规律、某些区住着同情德国的人，而统计分析表明没有证据支持非随机。

关键判据是把直觉换成基线：**先算出"纯随机下出现这种簇的概率"，再决定它是否需要解释。** 作者补充了必要的另一半："不太可能发生"不等于"绝不可能发生"——尝试足够多次，极罕见的事也会发生。美国每年调查 1000 多起可疑癌症群，绝大多数只是随机。

---

## A1 — 书中的应用 (Past Application)

### 案例: 平克的两幅图与伦敦轰炸

- **问题**: 人们习惯凭"看起来抱不抱团"判断一组数据是随机还是有序。
- **方法论的使用**: 作者引用平克《人性中的善良天使》中的两幅图：看起来"抱团"的左图才是真随机，而看似随机均匀的右图其实是怀托摩岩洞萤火虫的分布——萤火虫为争夺食物刻意保持距离。随后举二战伦敦人的信念：他们坚信德军轰炸有规律、某些区有同情德国人士，但统计分析表明无证据支持非随机。
- **结论**: "看起来有规律"不能作为非随机的证据；必须先算出纯随机下该簇出现的概率。作者补充：不太可能发生不等于绝不可能发生，尝试足够多次，罕见事也会发生——美国每年调查 1000 多起可疑癌症群，绝大多数只是随机（40 多万家 50 人以上企业中几人同时患癌并不罕见）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 事故/工单/故障在一段时间内扎堆，用户断言"一定有人在搞鬼"或"系统一定出了某种规律性问题"。
2. 地图上病例、投诉、流失客户成簇，用户想立即启动专项整治。
3. 连续几单成交（或连续几单失败），用户认为"今天手气/运气不一样"。
4. 看到 A/B 数据某段时间持续偏高，就宣称发现了周期性规律。

### 语言信号 (用户的话里出现这些就应激活)

- "这也太巧了吧，肯定有原因"
- "为什么偏偏都集中在这几天/这个区"
- "这不可能只是巧合"
- "你看这个图，明显抱团了"
- "This can't be a coincidence"

### 与相邻 skill 的区分

- 与 `mm-texas-sharpshooter-fallacy` 的区别: 得州神枪手是**先有数据、再画靶**（先射箭后画圈，挑选子集）；聚集性幻觉是**把随机必然产生的簇误当成信号**，两者常一起出现但错在不同环节。
- 与 `mm-gambler-s-fallacy` 的区别: 赌徒谬误期待簇被"纠正"；聚集性幻觉把簇解读成"有因"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把"看起来抱团"翻译成一个可计算的问题**
   - 完成标准: 明确定义簇（多长窗口内出现多少次、多大地理半径内多少个点），而不是停留在"看起来"。
2. **算随机基线**
   - 完成标准: 给出纯随机假设下出现同等强度簇的概率（书中范式：抛 20 次硬币有一半概率连续 4 次正面）。
   - 判停条件: 若观测到的簇强度在随机基线之内，停止寻找原因，跳到步骤 4。
3. **检验"尝试了多少次"**
   - 完成标准: 说明观察窗口与搜索范围—— inspections 越多，罕见簇越必然出现（书中范式：每年调查 1000 多起可疑癌症群，绝大多数只是随机）。
4. **给出结论与沟通口径**
   - 完成标准: 要么给出支持"存在真实成因"的证据门槛，要么明确告诉用户"该强度与随机一致，无需解释"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有明确的机制假设且事前登记过（例如已知某设备存在周期性老化），此时簇是待验证的假设而非幻觉。
- 簇的强度远超随机基线（统计检验显著）时，本 skill 不再适用，应转向因果排查。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确补充：**"不太可能发生"不等于"绝不可能发生"**；尝试足够多次，极罕见的事也会发生。
- 美国每年调查 1000 多起可疑癌症群，绝大多数只是随机——40 多万家 50 人以上企业中几人同时患癌并不罕见。
- （推导，非书中明示）反向误用：把一切簇都斥为"随机"而拒绝排查，会放过真实的聚集性成因（如真实的污染源）。基线计算是双向工具。

### 容易混淆的邻近模型

- 得州神枪手谬误（texas-sharpshooter-fallacy）：事后挑选子集制造显著性。
- 赌徒谬误（gambler-s-fallacy）：期待随机序列自我纠正。
