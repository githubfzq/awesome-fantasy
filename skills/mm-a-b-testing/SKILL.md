# A/B 测试（A/B testing）

## R — 原文 (Reading)

> 这种实验设计比较流行的一个版本是"A/B测试"（A/B testing），也就是比较使用网站或产品的A版本（实验组）和B版本（对照组）的用户行为。

> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

A/B 测试是**随机对照实验**在互联网产品里的流行形态：把用户分成两组，一组看到 A 版（对照组），一组看到 B 版（实验组），然后比较他们的行为。

它解决的是一个很具体的问题：你改了页面，转化率从 3% 涨到 3.4%，这个涨幅到底是你改得好，还是那天流量本来就好？没有对照组，你永远无法把"改动的效果"从"其他一切"里分离出来。

它的力量几乎全部来自一条纪律：**一次只改一样东西**。页面切换、文案、图片、色彩——如果 B 版同时换了标题、换了按钮颜色、还挪了位置，那么即使转化率涨了，你也不知道是哪一个起的作用，甚至不知道是哪个在拖后腿。书中强调"必须设计周全，将你研究的那个因素孤立出来"，最简单的做法就是让两版只有一样东西不同。

另外两个支柱是**随机分流**（两组人必须在统计上可比，否则组间差异和改动效果混在一起）和**客观指标**（"用户是否点击了某个按钮"这类可以直接计数、不需要用户主观汇报的行为）。

所以 A/B 测试不是一个"做实验"的泛泛说法，它是一套用随机化 + 单变量 + 客观计数，把因果归属钉死在某个具体改动上的程序。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户改了产品/页面/文案/价格，看到数字变好（或变差），问"这个变化是真的吗""是不是我这次改动带来的"。
2. 用户准备上线一个改动，想知道该怎么组织验证，而不是上线后凭感觉判断。
3. 用户拿两个版本的数据来比较，但两个版本之间改了好几处、或者两组人群来源不同，需要被指出结论不可信。
4. 团队为"红色按钮还是蓝色按钮""长文案还是短文案"争执不下，需要一个能结束争论的机制。

### 语言信号

- "我们改了之后转化率涨了，是真的有效吗？"
- "两版一起改了标题和配色，现在数据好了，是哪个起的作用？"
- "要不要做个 A/B 测试验证一下？"
- "灰度发布了一半用户，能说明问题吗？"
- "Should we A/B test this?" / "is the lift real?" / "split test"

### 与相邻 skill 的区分

- 与 `mm-randomized-controlled-experiment` 的区别: 随机对照实验是更一般的实验设计范式（含医学、政策、线下场景，强调随机分配与对照）；A/B 测试是它在网站/产品里的具体流行形式，落点在"页面/元素改动的变量隔离"。
- 与 `mm-sample-size` 的区别: 样本量权衡回答"要跑多久、多少人才够"；A/B 测试回答"实验该长什么样才有效"。前者是 A/B 测试的前置参数问题。
- 与 `mm-statistical-significance` 的区别: 统计显著性是实验跑完之后对结果是否可信的判定工具；A/B 测试是包含设计、执行、判读在内的完整流程。

## E — 可执行步骤 (Execution)

1. **把改动收敛成一个变量** — 完成标准: 能一句话说清"A 版和 B 版唯一的不同是 X"；若有第二处不同，驳回并要求拆成两个实验或改为多臂实验。
2. **确认分流是随机的、两组可比** — 完成标准: 用户能说明流量是按什么规则分配的，且该规则与用户特征无关（不是"老用户看新版""某个渠道走新版"）。
3. **选定客观可计数的结果指标** — 完成标准: 指标是可直接观测的行为（是否点击、是否下单、停留时长），不是"用户是否更喜欢"这类主观评价。
4. **在开跑前确定样本量与停止规则** — 完成标准: 给出所需样本量或最短运行时长，并约定"不许中途偷看、不许看到显著就停"（否则转 `mm-data-dredging` 风险）。
5. **跑完后先判显著、再判幅度** — 完成标准: 先问差异是否超出随机波动（显著），再问幅度是否值得上线（实际意义），两者都要说。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **无法随机分流的历史事件**: 比如"去年改的版，今年数据变好了"——没有对照组、没有随机化，用 A/B 框架包装只会给伪因果背书。
- **样本量极小的场景**: 几十个人的对比，随机波动远大于改动效应，跑 A/B 只会得到噪声。
- **纯品牌调性/审美取舍**: 这类选择不由点击率决定，强行用 A/B 会把长期品牌问题压成短期指标问题。

### 容易误用的地方

- **一次改多样东西却按单变量解读**: 书中明确要求把研究的因素孤立出来；多变量同改时结论不可归属。（书中明示）
- **把"跑了个 A/B"当作因果证明的终点**: 如果分流不随机、中途停止规则随意、指标事后挑，A/B 只是给偏见盖了个章。（推导, 非书中明示）
