# 博弈论（game theory）

## R — 原文 (Reading)

> 博弈论（game theory）研究的是如何在冲突情境下制定策略、做出决策。
>
> — 《思维模型》, 第7章 > 参与博弈

---

## I — 方法论骨架 (Interpretation)

博弈论研究在冲突情境下如何制定策略、做出决策。它的做法是把冲突简化为一个规则明确、结果可量化的"博弈"。

它的关键前提是:你我的选择互相影响结果。所以不能只算自己的最优解,必须同时考虑**对手会如何回应你的行动**——你的每一步都要预演对方的最佳回应,再在这个回应之上做选择。这是它和决策树的根本区别:决策树里"另一个玩家"是自然状态(天气、市场),它不会因你而改变;博弈论里"另一个玩家"是另一个同样在算计你的人。

作者给出的操作建议:从自己的立场绘制收益矩阵,用决策树列出选项与后果。

作者也诚实地指出,博弈论模型(如囚徒困境、最后通牒博弈)并非适用于所有情况,但大多数情况可以从博弈论角度审视——这其实是它的真正用法:不是套模型,而是养成"先确认有没有另一个会回应的玩家"这个习惯。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做定价、投放、发布节奏等决策,而竞品会立刻做出反应。
2. 用户在谈判(薪资、采购、合作条款),需要预判对方对己方报价的回应。
3. 用户在处理团队或部门间的资源争夺,各方都在等别人先动。
4. 用户发现自己"单方面做的最优计划"落地后完全失效,因为对方变了招。

### 语言信号 (用户的话里出现这些就应激活)

- "我们这么干的话,对方肯定会……"
- "他会不会跟着降价 / 跟进 / 反制"
- "谈不下来,怎么出价才合适"
- "大家都盯着对方下一步"
- "我算下来明明划算,为什么结果这么糟"
- "game theory" / "how will they respond" / "strategic interaction"

### 与相邻 skill 的区分

- 与 `mm-payoff-matrix` 的区别: 博弈论是整个学科与分析视角;收益矩阵是它最基础的可视化工具(把"我做什么 × 他做什么"的收益摊成表格)。分析具体博弈时用矩阵,判断"这是不是博弈"时用本模型。
- 与 `mm-decision-tree` 的区别: 决策树的分支是自然状态或概率事件,不会因你而改变;博弈论的分支是另一个理性玩家的回应。用户说"如果下雨就……"用决策树,说"如果他们降价我就……"用博弈论。
- 与 `mm-prisoner-s-dilemma` 的区别: 囚徒困境是一个具体的、有固定结构的博弈;博弈论是一般框架。认出具体结构后应切到囚徒困境等具体模型。

## E — 可执行步骤 (Execution)

1. **确认这是一场博弈,并点名玩家**
   - 完成标准: 明确指出"另一个会回应你的玩家"是谁(竞品/供应商/谈判方/同事),以及他有哪些可选项。
   - 判停条件: 若结果只受自然状态或概率影响、没有会回应的对手,改用决策树。
2. **从自己立场画收益矩阵**
   - 完成标准: 列出"我的选项 × 他的选项"的组合矩阵,每个格子里填入双方各自的收益(可用相对排序,不必精确数字)。详见 `mm-payoff-matrix`。
3. **为每个组合找出对方的最佳回应**
   - 完成标准: 对每一列(我选某策略),标出他会选哪个;再据此标出哪些组合是稳定的(双方都不想单方面改变)——那就是均衡。
4. **若均衡不理想,改博弈参数而不是改态度**
   - 完成标准: 明确指出改变结果的手段是改变对方的收益结构(引入押金/惩罚/合同/声誉后果/把单次博弈变成重复博弈),而不是指望对方"讲道理"。
5. **检查是否可重复**
   - 完成标准: 判断这局之后是否还会再见;若会,转 `mm-iterated-game`,合作的余地比单次博弈大得多。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 结果由自然状态或概率决定、没有会回应的对手:用决策树。
- 双方利益完全一致、纯协作问题:博弈论的冲突框架只会制造对立想象。
- 对手并非理性、信息极度不对称或行为不可预测时:均衡解的指导意义有限。

### 书中警告的失败模式 / 容易误用的地方

- 作者指出博弈论模型(如囚徒困境、最后通牒博弈)并非适用于所有情况,但大多数情况可以从博弈论角度审视。(书中明示)
- 常见误用:只算自己的最优,忘了对方会回应——这是没有博弈论视角的典型症状。(书中明示的反向推论)
- 常见误用:把现实硬套进教科书模型,忽略了真实博弈里玩家不止两个、选项不止两个。(推导,非书中明示)

### 容易混淆的邻近模型

- 与决策树(decision tree): 分水岭在于分支的另一端是不是一个会思考、会回应的玩家。
- 与零和(zero-sum): 博弈论包含零和与非零和;误把所有竞争当零和,会错过双赢解。
