# 蜜罐（honeypot）

## R — 原文 (Reading)

> 在计算机领域，这种策略被称为蜜罐（honeypot），用来吸引并诱捕恶意行为者

> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

蜜罐是**设置一个看起来有价值、实为隔离环境的目标,用来吸引并诱捕恶意行为者**。

它的价值不在防御,而在**情报与不对称**:真实资产不动,攻击者的时间、工具和方法全部落在你能完整观测的地方。你付出的只是维护一个假目标的成本,换到的是攻击手法、来源特征、意图判断——这些在真实系统里往往要等事故之后才能拿到。

书中举的具体形态是**伪装成存储有价值数据核心服务器的隔离服务器**,以及警方的**线下蜜罐**——把罪犯引到诱捕地点。两个例子说明了它的通用结构:**(1) 看起来值得下手;(2) 实际是隔离的,碰不到真的;(3) 对方一动手就暴露。**

关键判据是**隔离性是否被严格保证**。蜜罐一旦与真实资产存在未切断的通路,它就从陷阱变成了后门——这是这套方法唯一但致命的失败模式。其次是**可信度**:假目标要足够像真的(真实的数据形态、合理的命名、符合攻击者预期的入口),否则没人上钩,成本白付。

它继承自粘蝇纸理论的思路:不阻止对手来,而是让他来错地方。区别是蜜罐的靶子是假的、目的是观测,粘蝇纸的靶子可以是真的、目的是在有利地形交战。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做安全或风控设计,想提前拿到攻击者的手法而不是等出事后复盘。
2. 用户怀疑内部有人在爬数据、刷量、滥用权限,想设一个能识别来源的标记。
3. 用户在设计反爬/反垃圾策略,想知道对方用的是什么工具和模式。
4. 用户在考虑要不要用"假数据/假接口/诱饵账号"做检测与迟滞。

### 语言信号

- "放个假接口看看有没有人来扫"
- "能不能布个陷阱账号抓内鬼"
- "想提前知道他们怎么打进来"
- "在数据库里埋几条假数据做标记"
- "搞个看起来像核心库的假库"
- "honeypot" / "canary token" / "decoy server" / "set a trap"

### 与相邻 skill 的区分

- 与 `mm-flypaper-theory` 的区别: 粘蝇纸是**上位思路**——把对手引到他更容易受伤的地方;蜜罐是它在计算机领域的**具体实现**,靶子是假的、目的是观测与诱捕。若你想在真实战场上引诱对手,用粘蝇纸;若你要设假目标做观测,用蜜罐。
- 与 `mm-quarantine` 的区别: 隔离是**被动设闸阻断传播**,蜜罐是**主动设假目标吸引**;一个关门,一个开门,但蜜罐内部必须是隔离环境。
- 与 `mm-trojan-horse` 的区别: 特洛伊木马是**攻击者**把危险藏进诱人的礼物送进来(攻方视角),蜜罐是**防御者**摆出诱饵让人来(守方视角);方向完全相反。

## E — 可执行步骤 (Execution)

1. **明确目的:观测、迟滞、还是取证**
   - 完成标准: 写清你要拿到的东西(手法特征、来源 IP、内鬼身份、攻击时间窗),目的不同则蜜罐设计不同。
2. **设计诱饵的可信度**
   - 完成标准: 假目标在命名、数据结构、访问入口、可见性上都要符合攻击者的预期;给出"为什么对方会觉得它值得下手"的说明。
3. **严格验证隔离性**
   - 完成标准: 逐条确认并列出——网络隔离、权限隔离、数据不出假环境、无法横向移动、无真实凭据;任何一条未确认不得上线。这是本 skill 最关键的一步。
   - 判停条件: 若无法保证隔离,放弃蜜罐,改用隔离或常规加固。
4. **部署观测与告警**
   - 完成标准: 明确记录哪些行为(访问、登录、下载、外发)、告警阈值、日志留存时长,以及触发后由谁在多久内响应。
5. **明确蜜罐的边界**
   - 完成标准: 书面说明蜜罐不阻止攻击、只是情报手段;同步给出与之配套的真实防御措施,并确认不会误伤真实用户。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 把蜜罐当主要防御:它不阻止攻击,只提供情报与迟滞,必须配套真实加固。
- 无法保证严格隔离时:蜜罐会变成后门,危害大于收益。
- 会误伤真实用户的场景:真实用户可能接触到的假目标(如假页面、假入口)会造成体验与信任损失。

### 容易误用的地方

- 书中未提边界;以下为基于机制推导的警告(推导,非书中明示)。
- 隔离性检查走过场:这是蜜罐唯一致命的失败模式,未切断通路等于主动开后门。
- 诱饵太假:没人上钩,蜜罐只剩维护成本。
- 用蜜罐数据做过度推断:蜜罐捕获的是愿意碰诱饵的那部分攻击者,不代表整体攻击面。
- 把"诱捕"扩大到真实用户身上(钓鱼式反制):法律与伦理风险远高于收益。

### 容易混淆的邻近模型

- 与粘蝇纸理论(flypaper-theory): 具体安全实现 vs 上位战略思路。
- 与特洛伊木马(trojan-horse): 守方诱饵 vs 攻方礼物,方向相反。
