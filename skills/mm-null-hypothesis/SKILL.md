# 原假设（null hypothesis）

## R — 原文 (Reading)

> 大多数实验（包括这个实验）背后的统计学安排都基于一个假设——测试组和对照组没有任何区别。这被称为原假设（null hypothesis）。
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

假设检验的默认起点是"什么都没发生"：测试组与对照组之间没有任何区别。这就是原假设（null hypothesis）。整个推理结构是先假定无效应，只有当收集到足够的证据**能否定**它时，才接受效应存在——这是证伪，而不是证实。

具体做法是先画出原假设下的差异分布（一条以 0 为中心的钟形曲线：即使真的没效应，随机波动也会让两组出现差异），再看实际观测到的差异落在多远的尾部。落得越远，说明"无效应"这个默认假设越难自圆其说。

关键判据是**举证责任的分配**：原假设把"证明存在"的负担交给提出效应的一方。书中也点明，即便原假设为真，由于随机波动仍可能测出差异，因此否定与否要看是否越过显著性阈值。

---

## A1 — 书中的应用 (Past Application)

### 案例: 助眠应用实验

- **问题**: 想验证一款助眠应用是否真的能帮助用户更快入睡，需要一套不靠直觉的判断结构。
- **方法论的使用**: 作者把实验的原假设设为"用不用应用，10 分钟内入睡的比例没有差别"；只有当两组观测到的差异足够大、落在原假设分布足够远的尾部时，才否定它。
- **结论**: 假设检验采用"先假定无差异、再看证据能否否定"的证伪结构；书中同时指出，即便原假设为真，随机波动仍可能制造出差异，因此必须靠显著性阈值来判定。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计 A/B 测试/对照实验，需要写清"我们要检验的假设是什么"。
2. 有人用"两组数据看起来不一样"就宣称有效果，用户需要判断这种说法够不够。
3. 讨论"没有证据证明有害"是否等于"证明无害"。
4. 决定实验的对照组如何设置、差异度量用什么。

### 语言信号 (用户的话里出现这些就应激活)

- "这两组有没有显著差异"
- "我们的假设应该怎么设"
- "没测出问题是不是就说明安全"
- "对照组该怎么设"
- "What's the null hypothesis here?"

### 与相邻 skill 的区分

- 与 `mm-alternative-hypothesis` 的区别: 原假设是"无差异"的默认起点；对立假设是你想证明的那个具体效应（如"差异 15%"），功效计算正依赖它。
- 与 `mm-p-value` 的区别: 原假设是**被检验的命题**；P 值是在该命题成立的前提下**数据有多极端**的度量。

---

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把问题写成"无差异"的命题**
   - 完成标准: 明确写出原假设（书中模板："用不用应用，10 分钟内入睡的比例没有差别"），并指明比较的是哪两组、度量是什么。
2. **写出对立假设与最小有意义效应**
   - 完成标准: 给出希望能检出的具体差异量（这一步是后续功效计算的输入）。
3. **画出/描述原假设下的差异分布**
   - 完成标准: 说明"即使无效应，随机波动也会产生多大差异"，即以 0 为中心的钟形曲线。
   - 判停条件: 若观测差异落在分布中央（远未到尾部），直接判定不能否定原假设。
4. **按阈值判定并正确表述**
   - 完成标准: 明确说出"否定原假设"或"未能否定原假设"，且不说成"证明了无效应"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯探索性数据分析、生成假设阶段——此时没有需要证伪的命题。
- 已明确采用贝叶斯模型比较/可信区间的框架时，原假设显著性检验不是必需环节。

### 书中警告的失败模式 / 容易误用的地方

- 书中指出：**即便原假设为真，由于随机波动仍可能测出差异**，因此否定与否要看是否越过显著性阈值。
- （推导，非书中明示）"未能否定原假设"常被误说成"证明了无效应"——书中在 P 值一节明确反对这种说法（"没有证据证明存在"不等于"有证据证明不存在"）。

### 容易混淆的邻近模型

- 对立假设（alternative-hypothesis）：原假设被否定后接受的那个具体效应假设。
- P 值（p-value）：在原假设成立下衡量数据极端程度的量。
