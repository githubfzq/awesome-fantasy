# 黑暗模式（dark patterns）

## R — 原文 (Reading)

> 所谓的"黑暗模式"，是指一些网站利用经过伪装的广告、将信息藏在隐蔽的收费背后，或是使取消订阅或获得支持变得极为困难

> — 《思维模型》, 第7章 > 底线在哪儿

---

## I — 方法论骨架 (Interpretation)

黑暗模式指的是用伪装、隐藏、制造障碍等方式来操纵和迷惑用户的界面与做法。

它的关键机制在于:**影响力模型本身是中性的,一旦被用来摆布你就成了黑暗模式。**互惠、稀缺、社会认同、承诺一致这些杠杆,在正常情况下帮助你做出决策,在被刻意用来让你做出你本不会做的选择时,就成了黑暗模式。所以判断标准不在于用了哪个杠杆,而在于**意图与结果**:用户是否被引导去做了一件在充分知情下不会做的事。

书中强调黑暗模式不限于网络。特洛伊木马、诱购、波将金村、雾件都是它的线下形态——这提示了一个更一般的判据:**凡是靠信息不对称与认知杠杆,而非靠产品本身的价值来促成交易的做法,都是这个家族的成员。**

作者在这一节真正提出的是一个道德灰度问题,而非一条清晰红线:非营利组织寄送免费地址标签来募捐,同样使用了互惠与社会认同,但目的是做善事且不构成欺骗——这算不算黑暗模式,由你自己定底线。这说明判据不是"有没有用影响力杠杆",而是**是否构成欺骗**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户被某个订阅、会员、免费试用套住,发现取消流程异常复杂或找不到入口。
2. 用户在结账时才发现有一笔之前没看到的费用,或被默认勾选了附加项。
3. 用户在做产品设计/增长,想知道某个提升转化的改动是否越线。
4. 用户在评估一家供应商、平台或 SaaS 的商业伦理(退出成本、计费透明度)。

### 语言信号

- "想取消却怎么也找不到入口"
- "付钱的时候才冒出来一笔费用"
- "这个广告长得跟正文一模一样"
- "默认帮我勾了,我没注意就买了"
- "客服电话藏得特别深"
- "dark patterns" / "roach motel" / "can't cancel my subscription" / "hidden fees"

### 与相邻 skill 的区分

- 与 `mm-trojan-horse` 的区别: 特洛伊木马是**进入方式**(用诱人的礼物绕过你的防御检查),黑暗模式是**整体类别**(包含进入、留存、退出各环节的操纵设计);木马通常是一次性的入口动作,黑暗模式可以是持续的流程障碍(如极难取消)。
- 与 `mm-bait-and-switch` 的区别: 诱购是**一种具体的调包手法**(用低价吸引,卖你更贵的东西),黑暗模式是**上位类别**;诱购属于黑暗模式的线下形态之一。
- 与 `mm-default-effect` 的区别: 默认效应是**机制**(人倾向于接受默认选项),黑暗模式是**对该机制的操纵性使用**;默认效应本身可以用于好的目的(如默认加入养老金计划)。

## E — 可执行步骤 (Execution)

1. **定位具体的操纵动作**
   - 完成标准: 明确指出是哪一个具体设计(隐藏收费、伪装广告、极难取消、默认勾选、确认羞辱),而不是笼统地说"这产品设计很坏"。
   - 判停条件: 若只是体验差、流程繁琐但无操纵意图,移交常规可用性分析。
2. **判断它借用的是哪条影响力杠杆**
   - 完成标准: 说明该设计动用了哪个机制(互惠、稀缺、社会认同、承诺一致、默认效应、损失规避),并指出该杠杆本身中性、问题在于被用来摆布用户。
3. **执行"充分知情"检验**
   - 完成标准: 明确回答——如果用户在充分知情、有同等退出自由、且不受认知杠杆影响的情况下,是否还会做同样的选择?若不会,判定为黑暗模式。
4. **给出应对或整改动作**
   - 完成标准: 若用户是被影响方——给出具体脱身路径(取消入口、申诉渠道、截图留证、支付渠道止损)与预防做法(用虚拟卡、设置续费提醒、签约前先查退出流程);若用户是设计方——给出整改方案(把退出做得和进入一样容易、费用前置明示、默认项恢复为不选),并明确说明欺骗性设计既是伦理问题也是合规风险。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 界面体验差、流程繁琐,但没有操纵意图或欺骗成分:那是可用性问题,不是黑暗模式。
- 一个设计明显有利于用户(如默认勾选更安全的设置)却动了影响力杠杆:机制相同,性质不同。
- 把它当作万能指控:商业设计普遍使用说服技巧,判据是欺骗而非说服。

### 容易误用的地方

- 作者提出道德灰度:非营利组织用免费地址标签募捐也用了互惠与社会认同,但目的是做善事且不构成欺骗,是否算黑暗模式由你自定底线。(书中明示)
- 把"用了影响力杠杆"直接等同于黑暗模式,会误伤大量正常设计——真正的判据是是否构成欺骗与是否剥夺了知情选择。(推导,基于书中道德灰度的论述)
- 黑暗模式不限于网络:木马、诱购、波将金村、雾件都是其线下形态,只盯着界面会漏掉线下的同类做法。(书中明示)

### 容易混淆的邻近模型

- 与特洛伊木马(trojan-horse): 整体类别与一种进入手法。
- 与诱购(bait-and-switch): 上位类别与具体调包手法。
