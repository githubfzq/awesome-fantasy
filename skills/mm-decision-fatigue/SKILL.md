# 决策疲劳（decision fatigue）

## R — 原文 (Reading)

> 随着做出的决定越来越多，你会感到疲惫不堪，导致决策质量下降。经过精神上的短暂休憩后，你可以有效地恢复原状，再一次做出高质量的决策。
>
> — 《思维模型》, 第2章 > 好事过头成坏事

---

## I — 方法论骨架 (Interpretation)

决策疲劳把决策能力看成一种**会被消耗的资源**：随着做出的决定越来越多，人会疲惫，决策质量随之下降；经过精神上的短暂休憩后，可以有效恢复原状。

它为什么危险？因为疲惫后不是"决策变慢"，而是"决策方式退化"。连续决策之后，人们倾向于选择默认项、维持现状、或走捷径——这些都是认知上最省力的选项。也就是说，疲劳让你**不再真正做决定**，而是让默认设置替你做决定。这意味着重要的、需要审慎的判断如果在疲劳时段做出，结果实际上是被默认值决定的。

最有力的证据是 2011 年《司法裁决中的外界因素》研究：假释裁决中对犯人有利的比例，在每次裁决过程中从约 65% 逐渐下降到近乎为零，短暂休息后又突然恢复到约 65%。同一个法官、同一类案件，唯一的变量是"已经连续做了多少个决定"。

值得强调的是恢复方式：靠**休息与减量**，不是靠意志力硬撑。对策因此有两条主线：减少日常决策数量（奥巴马只穿蓝灰西装、乔布斯 likewise、加布里埃尔的七条同款牛仔裤与固定午餐），以及在低压力时段预先决定一周的穿着饮食，把决策能力留给真正重要的事。

## A1 — 书中的应用 (Past Application)

### 案例: 假释裁决中的外界因素

- **问题**: 2011 年《司法裁决中的外界因素》研究观察了假释裁决的结果分布，发现一个反常模式：对犯人有利的裁决比例，在每次裁决过程中从约 65% 逐渐下降到近乎为零，而短暂休息之后又突然恢复到约 65%。
- **方法论的使用**: 作者用这个研究说明决策能力是可耗竭的资源——决定做得越多，后续决策质量越低，而休息能使之恢复。疲劳后的表现不是更慢，而是退化到默认选项（在假释场景中，默认就是"不批准"）。
- **结论**: 应对方式不是靠意志力硬撑，而是减少日常决策数量与安排休息。作者举例：奥巴马只穿蓝灰西装、乔布斯 likewise、加布里埃尔的七条同款牛仔裤与固定午餐；若希望生活变化多一些，可在选择压力小的一天预先做决定，把工作日的决策能力解放出来。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 安排重要决策的时段：重要面试、评审、谈判排在一天的第几个。
2. 连续审批/连续面试/连续评审后，发现自己开始"都行""按你说的办"。
3. 日程被琐事填满，重要决定只能在最疲惫时处理。
4. 设计流程时，默认选项被大量采用（说明多数人已疲劳）。
5. 复盘一个"当时怎么会同意这个"的决定，怀疑与时段有关。

### 语言信号 (用户的话里出现这些就应激活)

- "随便吧，就按你说的来"
- "都行，你定"
- "太累了，明天再说"
- "我懒得比较了，就选第一个"
- "连着开了五个会，最后一个基本没细看就过了"
- "decision fatigue / too many decisions / default option / worn out"

### 与相邻 skill 的区分

- 与 `mm-analysis-paralysis` 的区别: 决策疲劳是**资源耗尽**（做太多决定后质量下降，靠休息可恢复），分析瘫痪是**信息过多导致卡住**（不是累了，是选不出来）。判断方法：休息一晚明天能决定吗？能 → 疲劳；仍不能 → 瘫痪。
- 与 `mm-paradox-of-choice` 的区别: 选择的悖论讲"选项越多越不满意"（选择本身的心理代价），决策疲劳讲"决定做得越多越疲惫"（跨决策的资源消耗）。前者是单次选择的体验问题，后者是连续决策的累积问题。
- 与 `mm-default-effect` 的区别: 默认效应是"人们倾向接受预设选项"这一现象，决策疲劳是**导致**默认效应被放大的原因之一。处理疲劳时，默认选项的设置变得极其关键。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认"退化到默认"的模式**
   - 检查近期决策：是否越来越多地选择默认项、维持现状、或照搬上一个决定？
   - 完成标准: 找出至少 2 个"本来会认真想、却直接放行"的实例。
   - 判停条件: 若决策质量稳定只是速度变慢，停止本 skill。
2. **定位一天中的疲劳时段**
   - 统计重要决策被安排在什么时候、之前已经做了多少个决定。
   - 完成标准: 画出"决策数量—质量"的粗略曲线，标出质量下降的拐点。
3. **把重要决策前移或安排休息**
   - 重要且不可逆的判断安排在决策负载最低的时段，并在连续决策之间插入休息。
   - 完成标准: 给出具体的排程调整（哪个会挪到哪、什么时候休息）。
4. **削减日常决策数量**
   - 固定化：着装、餐饮、常规流程模板化；把重复决定变成规则。
   - 完成标准: 列出至少 3 项被固定化/规则化的日常决定。
5. **在低压力时段预先决定**
   - 书中建议：若希望生活变化多一些，可在选择压力小的一天预先决定一周的穿着饮食，解放工作日的决策能力。
   - 完成标准: 有具体的"预先决定"清单与执行日。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单次孤立的决策失误：那更可能是信息、能力或流程问题，不能归因于疲劳（推导，非书中明示）。
- 纯粹的体力疲劳或情绪问题：机制不同，对策也不同（休息类型不同）（推导，非书中明示）。
- 把任何"随便吧"都当成疲劳：有时那是真实的偏好表达或信任授权，需要区分（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 作者建议若希望生活变化多一些，可在选择压力小的一天预先做决定，解放工作日的决策能力（书中明示）——这说明"减少决策"不等于"减少生活的多样性"。
- 隐含前提是决策疲劳靠休息与减量缓解，而非靠意志力硬撑（书中明示的方向）。用意志力对抗疲劳通常无效。
- 疲劳时默认选项的设定会直接决定结果，因此在高疲劳流程中，默认值的设置本身就是一种高杠杆设计（推导，非书中明示）。

### 容易混淆的邻近模型

- 与分析瘫痪：一个是"累了"，一个是"卡住"。判断口诀——休息一晚能不能决定？能 → 决策疲劳；不能 → 分析瘫痪。
- 与默认效应：默认效应是现象，决策疲劳是成因之一；处理疲劳问题时常需要同时重新设计默认项。
