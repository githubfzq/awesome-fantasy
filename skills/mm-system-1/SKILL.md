# 快思考与慢思考（System 1 / System 2）

## R — 原文 (Reading)

> 诺贝尔经济学得主丹尼尔·卡尼曼（Daniel Kahneman）在著作《思考，快与慢》（Thinking, Fast and Slow）中对这种"出于直觉的快速思考"和"当你放慢脚步、质疑直觉做出的假设时，更加深思熟虑的逻辑思考"做了区分。
>
> — 《思维模型》, 第1章 少犯错 > 别相信直觉

---

## I — 方法论骨架 (Interpretation)

这个模型把思考分成两套系统。快思考是自动、无意识、几乎不耗力的：熟练开车、简单算术、说出自己的名字。慢思考是刻意、需集中注意力、会累的：在陌生路段开车、复杂运算、绞尽脑汁回忆一个老同学的名字。

区分两者的关键不是"快"和"慢"，而是**你有没有可用的编码经验**。经常做的事会在脑中形成编码，交给快思考接管既省事又准确；遇到不确定的新情况，没有编码可用，快思考就只能靠相似度去套，这时必须切到慢思考。

问题在于：快思考不会在你没有编码经验的时候主动让位，它照样给出一个"感觉"。所以在不确定的情境里盲信直觉，就会一头撞进锚定、可得性偏差、框架效应这些陷阱——它们全都是快思考用替代问题糊弄过去的产物。

作者的立场并不是否定直觉：直觉可以作为探索的指南，而且你掌握的思维模型越多、喂给自己的信息越准，直觉本身也会越准。判据是：**这件事我有可靠的编码经验吗？有就用快思考，没有就用慢思考。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户用"我感觉/应该是/直觉告诉我"给出一个判断，且这件事对他而言并不熟悉。
2. 用户在新领域、新岗位、新市场做判断，套用了旧经验的答案。
3. 用户抱怨"想都没想就答应了/就发了"，事后后悔。
4. 用户纠结一件事到底要不要花时间仔细算，还是凭经验拍板就行。
5. 用户被时间压力推着做决定，问"来不及想了怎么办"。

### 语言信号
- "我直觉觉得这个不靠谱"
- "想都没想就……"
- "这种情况我见多了，肯定是这样"
- "来不及细想了，先拍吧"
- "我是不是该再想想？"
- "gut feeling / go with my instinct / System 1 / off the top of my head"

### 与相邻 skill 的区分
- 与 `mm-heuristic` 的区别: 启发式是快思考具体使用的那些经验法则（可用工具箱），本 skill 是判断"该不该用快思考"的调度规则；一个是工具，一个是开关。
- 与 `mm-anchoring` 的区别: 锚定是快思考在陌生情境下出错的一种具体表现（被先入数字带跑），本 skill 是更上层的成因诊断。
- 与 `mm-availability-bias` 的区别: 可得性偏差是快思考用"想得起来的例子"替代"真实频率"，同样属于快思考的具体失效模式，不负责判断何时该切换系统。

## E — 可执行步骤 (Execution)

1. **判断这件事用户有没有编码经验**
   - 直接问三个问题：做过多少次？反馈周期多短？反馈是否准确？
   - 完成标准: 三个问题都有答案；"做过很多次 + 反馈快且准"才算有编码经验。
   - 判停条件: 若三项全满足，判定用快思考，直接放行并说明为什么可以信直觉。
2. **把直觉答案里隐含的假设揪出来**
   - 追问："你这个感觉，是基于什么在跟什么相似？"
   - 完成标准: 至少写出 2 条"我把 A 当成了 B"的相似性假设。
3. **逐条检验相似性假设是否成立**
   - 对每条问：这两个东西在关键变量上真的一样吗？差在哪？
   - 完成标准: 每条假设标注成立 / 不成立 / 待验证。
4. **切到慢思考的替代动作**
   - 至少选一项：粗略估算（back-of-envelope）、列对立假设、找基础比率、找懂这个领域的人问一句。
   - 完成标准: 产出至少一个独立于直觉的数字或反面证据。
5. **给结论定一个置信度与复核点**
   - 完成标准: 明确"我有几分把握"以及"什么信号出现时我要推翻这个结论"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 高重复性、反馈快的熟练工作（打字、常规驾驶、熟悉的运维操作）：这里快思考更可靠，强行慢思考反而降低表现。
- 用户只是在倾诉情绪、并不需要做判断：不要把它变成认知纠错。
- 时间窗极短且不可逆的紧急情况：此时只能靠训练过的直觉，复盘可以留到事后（推导，非书中明示）。

### 容易误用的地方
- 作者并不否定直觉：直觉可作探索指南，且掌握思维模型越多、输入信息越准，直觉也越准（书中明示）。因此不要把它当成"直觉一律不可信"。
- 容易把"慢思考"理解成"想久一点"：慢思考的核心是**质疑直觉做出的假设**，不是延长时间。延长但不质疑，仍然是快思考（推导，非书中明示）。
- 慢思考消耗大、会疲劳，在决策疲劳或深夜时段强行切换，质量并不比直觉高（推导，非书中明示）。
