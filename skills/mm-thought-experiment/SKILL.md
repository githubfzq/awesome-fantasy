# 思维实验（thought experiment）

## R — 原文 (Reading)

> 另一种畅想未来情景的技巧叫作思维实验（thought experiment）。它是指只在你的思维中进行的实验，也就是在现实世界中不会发生。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

思维实验就是**只在思维中进行、现实中并不实际发生的实验**。它的操作形式极其简单，就是"如果……会怎么样"：如果预期寿命延长 40 年会怎样？如果资金雄厚的对手抄袭我们的产品会怎样？如果我转行会怎样？

它的力量不在给出答案，而在**打开新的情景空间**。它能提出那些看似无法回答、却能让争论持续数十年的问题——薛定谔的猫就是典型：密封箱里的猫与极少量放射性物质、盖革计数器、锤子和氢氰酸瓶相连，一小时内原子是否衰变决定猫的生死，借此追问"打开箱子前猫究竟是死是活"。作者明说这个答案超出了本书范围，科学家也争论数十年未决。

这一点恰恰说清了它的性质：一个好问题比一个坏答案更有价值。在情景分析里，思维实验是往最难那个格子里填内容的生成工具——它逼你面对那些"不可能发生所以没人想"的分支。

关键判据：这个问题在现实中确实无法做实验（成本、伦理、时间、物理上都不行）吗？如果其实能做，就别只在脑子里做。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在一个争论里打转，双方都拿不出现实证据，需要换个角度打破僵局。
2. 用户在做情景分析，需要往"未知的未知"那格里生成内容。
3. 用户面对一个被当作常识的前提，需要把它推到极端来检验是否真的成立。
4. 用户要评估一个现实中无法试错的重大决策（不可逆、无先例）。

### 语言信号
- "如果……会怎么样"
- "假设这件事真的发生了"
- "我们能不能想一个极端点的情形"
- "想象一下十年后"
- "这个没法做实验验证，只能推想"
- "what if..." / "thought experiment" / "imagine a world where..."

### 与相邻 skill 的区分
- 与 `mm-scenario-analysis` 的区别: 思维实验是**一次性的反事实推演工具**，情景分析是**把多个思维实验组织成几套完整自洽图景**的系统工程；前者是零件，后者是整机。
- 与 `mm-counterfactual-thinking` 的区别: 反事实思维针对**过去**（如果当时没那么做会怎样），思维实验面向**未来或假设情形**（如果发生 X 会怎样）；时间轴方向相反。
- 与 `mm-arguing-from-first-principles` 的区别: 第一性原理是**拆解到不可再拆的基本事实再往上推**，思维实验是**构造一个虚构情形再往下推**；一个求真，一个求广。

## E — 可执行步骤 (Execution)

1. **确认这个问题确实无法现实实验**
   - 完成标准: 明确说明为什么做不了（成本、伦理、不可逆、物理上不可能）。若其实能做 A/B 测试或查数据，停止本 skill。
2. **把假设写得极端且具体**
   - 完成标准: 假设是一个可判定的具体情形（"巨头以 1/3 价格抄袭且三个月内上线"），而不是模糊的"如果情况变差"。
3. **认真推演因果链，不急于下结论**
   - 顺着假设往下推至少三层，包括二阶后果。
   - 完成标准: 写出完整的后果链，且链上每一环都能自圆其说。
4. **明确它证明了什么、没证明什么**
   - 完成标准: 区分"打开了哪个新情景"与"得出了哪个结论"；若问题本身无法定论（如薛定谔的猫），如实说明。
5. **把结果并入情景分析或决策**
   - 完成标准: 把推演出的新情景交给情景分析归档，或转化为具体的预案与观察信号。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 本可以用真实数据、A/B 测试或小范围试点回答的问题：思维实验的替代品成本更低、可信度更高。
- 需要给出确定结论的场合：作者明说薛定谔的猫的答案超出本书范围，科学家争论数十年未决——思维实验可以没有答案。
- 用它替代论证：构造一个虚构情形不等于证明了什么，别把"想象出来的后果"当证据使用。

### 容易误用的地方
- 作者明说薛定谔的猫的答案"超出了本书讨论的范围"，且科学家争论数十年未决。（书中明示）
- 假设推得不够极端：温和的假设只会复现已知结论，思维实验的价值恰恰在于推向现实中不会发生的地方。（推导，非书中明示）
- 把推演出的后果当成预测：思维实验打开的是可能性空间，不是概率——不要给推演结果附上似是而非的概率。（推导，非书中明示）

### 容易混淆的邻近模型
- 与反事实思维（counterfactual thinking）：面向未来/假设 vs. 面向过去，时间轴方向相反。
- 与情景分析（scenario analysis）：零件 vs. 整机。
