# 频率学派与贝叶斯学派（Frequentist vs Bayesian）

## R — 原文 (Reading)

> 统计学中有两大流派——频率学派（Frequentist）和贝叶斯学派（Bayesian）。你在新闻报道中听到的大多数研究都基于频率统计。这种统计方式需要对同一事件进行多次观测，然后才能做出可靠的统计推定。
>
> — 《思维模型》, 第5章 > 具体情况具体分析

---

## I — 方法论骨架 (Interpretation)

两派的分歧只有一个：**允不允许把先验知识代入推断。**

频率学派认为，概率是长期频率，缺少观测的概率毫无意义；你必须反复观测同一事件，才能做出可靠推定。代价是数据少时结论极不确定——置信区间会大得没法用。

贝叶斯学派允许你从一个先验出发，随新数据不断更新。这更接近人自然形成观点的方式：街上捡到一分钱，即使从未抛过这枚硬币，你也能推测正面概率约五成。作者用人际关系作比：弱先验是第一印象，强先验是持续终身的关系。

两派最终会随数据增加而趋同，因为它们估算的是同一个基本事实。作者的立场是实用主义：**用最适合当下情况的那种。**

---

## A1 — 书中的应用 (Past Application)

### 案例: 捡到的一分钱与人际关系

- **问题**: 面对一枚从未观测过的硬币，频率学派无法给出正面概率（没有观测数据），而人在现实中却能毫不犹豫地判断。
- **方法论的使用**: 作者用"街上捡到一分钱"说明：即使从未观测过这枚硬币，也能推测抛出正面的概率是五成——这是贝叶斯而非频率的思路。又用人际关系说明强弱先验之别：弱先验是第一印象，强先验是持续终身的关系。
- **结论**: 贝叶斯方法更直观、更贴近人形成观点的方式，且在数据稀少时仍可用；作者立场是实用主义——按当下情况选择更合适的那种，并指出随着数据增加两派会趋同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 数据极少（冷启动、新市场、罕见事件），用户问"能不能凭经验先判断"。
2. 解读置信区间时，想把"95% 置信区间"直接说成"真实值有 95% 概率落在这里"。
3. 团队争论"该不该把我们过去的经验/行业基准放进模型"。
4. 选择技术方案：A/B 显著性检验 vs 贝叶斯 A/B、贝叶斯 A/B 的先验怎么设。

### 语言信号 (用户的话里出现这些就应激活)

- "数据太少了，能不能先凭经验估一个"
- "置信区间是不是就是真实值有 95% 概率在里面"
- "该不该把行业基准作为先验"
- "频率派和贝叶斯派到底差在哪"
- "Should we use a Bayesian approach here?"

### 与相邻 skill 的区分

- 与 `mm-bayes-theorem` 的区别: 贝叶斯定理是**数学恒等式**，两派都承认；本 skill 是**方法论立场的取舍**（该不该用先验、怎么解释结果）。
- 与 `mm-confidence-interval` 的区别: 置信区间是频率学派的产物，其解释方式与贝叶斯可信区间不同——这正是两派分歧最常爆发的地方。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断数据充裕度**
   - 完成标准: 明确说明当前数据量下，两派结论是否会实质分歧（数据充足时趋同，可跳过取舍）。
   - 判停条件: 若数据充足且结论一致，直接给结论并说明无需选边。
2. **检查先验的可用性与可靠性**
   - 完成标准: 判断手上的先验（行业基准、历史数据、专家判断）是否有据、强弱如何。
   - 判停条件: 若先验可能源自证实偏差等认知错误，改走频率路径或先清洗先验——书中明示此时强先验会使人离真相更远。
3. **按情境选派并说明取舍**
   - 完成标准: 给出选择（数据少/需可解释的直白概率 → 贝叶斯；要求客观性/需与传统文献口径一致 → 频率派），并说明代价。
4. **统一解释口径**
   - 完成标准: 明确写出结果该如何表述（频率派："重复实验下约 95% 的区间会命中真值"；贝叶斯："真实值有 95% 概率落在区间内"），避免混用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 数据量充足、两派结论已趋同，此时选边没有实际意义，只是增加沟通成本。
- 纯工程实现细节（选哪个库的 API）与统计立场无关。

### 书中警告的失败模式 / 容易误用的地方

- 作者指出贝叶斯方法曾因计算困难而不流行，现代计算机正消弭这一难题。
- 但**"强先验"若源自证实偏差等认知错误，反而会使贝叶斯学派离真相更远、需要更长时间才能纠正**；此时频率学派"从零算起"反而更接近真相。
- 作者的明确立场是**实用主义：用最适合当下情况的那种**。

### 容易混淆的邻近模型

- 贝叶斯定理（bayes-theorem）：数学工具，非流派之争。
- 证实偏差（confirmation-bias）：污染强先验、使贝叶斯推断失准的认知根源。
