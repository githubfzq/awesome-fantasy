# 刻意练习（deliberate practice）

## R — 原文 (Reading)

> 心理学家安德斯·艾利克森（K. Anders Ericsson）致力于研究如何迅速擅长做某件事，他将这个模型称为“刻意练习”（deliberate practice）。具体就是刻意让人处于能力极限，持续练习越来越难的技能，并获得实时反馈。
>
> — 《思维模型》, 第8章 > 熟能生巧

---

## I — 方法论骨架 (Interpretation)

安德斯·艾利克森研究"如何迅速擅长做某件事"，结论是刻意练习：让人处于**能力极限**，练习**越来越难**的技能，并获得**实时反馈**。

三要素缺一不可，这也是它区别于普通重复的地方：

- **能力极限**——必须离开舒适区。做已经会的事只是维持，不是提高。
- **递增难度**——达成当前水平后要把难度往上推，否则极限点就变成了新的舒适区。
- **实时反馈**——错了要马上知道错在哪里。没有反馈，错误会被固化成习惯。

所以"孩子们把球踢来踢去"不是刻意练习：既没触及极限，也没有反馈。而"反复击中靶子、每次接受'错在哪里'的指导、逐步把靶子移远"才是。

两个常被忽略的约束：

1. **它几乎无法独自完成**——除非有能提供反馈的模拟环境，否则你需要私人教练、体育教练、音乐老师、管理者或导师。这意味着"练习"是一个需要他人参与的社会活动。
2. **不能强加**——强加给某人必定失败，须先征得指导者与受训者双方认同。

强度上它远超常规练习，对身心都是考验。组织里难以控制练习环境，机会有限且有后果，所以要挑影响不大的项目或在业余时间练习。

关键判据：**这次练习中，有没有一个时刻你做错了并且立刻知道了？** 没有，就是重复，不是练习。

## A1 — 书中的应用 (Past Application)

### 案例: 足球传球的刻意练习

- **问题**: 想快速提高足球传球水平，但常规踢球（把球踢来踢去）不产生明显进步。
- **方法论的使用**: 设计成刻意练习——反复击中靶子；每试几次接受一次指导（错在哪里）；目标从连续 1 次、3 次、5 次递进；达成后把靶子移远，重新开始。
- **结论**: 三要素齐备（触及极限、难度递增、每次都给反馈）才构成刻意练习；单纯花时间踢球不满足任何一条。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在某项技能上投入大量时间却停滞不前（"练了两年还是这样"）。
2. 管理者要为团队成员设计成长计划/带教机制。
3. 用户在自学某项技能（写作、编程、演讲、销售）并想知道怎么练才有效。
4. 组织要安排培训，需要判断"这个培训算不算有效练习"。

### 语言信号 (用户的话里出现这些就应激活)

- "我练了很久，怎么还是没进步"
- "日常工作重复了三年，感觉没什么长进"
- "怎么才能快速擅长这件事"
- "我要不要找个教练/导师"
- "这个培训有用吗"
- "I've been doing this for years but not improving / deliberate practice"

### 与相邻 skill 的区分

- 与 `mm-10000-hour-rule` 的区别: 一万小时定律强调时间积累，且已被指出"时间本身不保证成效"；刻意练习强调时间必须被结构化（极限+递增+反馈）才有效。
- 与 `mm-radical-candor` 的区别: 坦诚相待解决的是"反馈怎么给才有效"（直接挑战 × 个人关怀）；刻意练习要求的实时反馈正是它的用武之地，两者是供应与需求关系。
- 与 `mm-learning-curve` 的区别: 学习曲线描述进步速率的形状；刻意练习是改变这条曲线斜率的方法。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位当前能力极限**
   - 完成标准: 明确写出"目前做到什么程度会开始频繁出错"，这个出错点就是极限。
2. **把任务拆到可反馈的粒度**
   - 完成标准: 把技能拆成能在几十秒到几分钟内完成、且结果可判定的小任务（例：击中靶子，而非"踢好球"）。
3. **安排实时反馈来源**
   - 完成标准: 指定一个具体的人或模拟环境，并明确他在每次（或每几次）尝试后给出"错在哪里"的具体信息。
   - 判停条件: 若找不到反馈来源，明确告知用户：没有反馈就不构成刻意练习，先解决反馈来源问题。
4. **设定递增阶梯**
   - 完成标准: 给出 3 级递进目标（如连续 1 次 / 3 次 / 5 次），并写明达成后如何把难度推高（把靶子移远）。
5. **确认双方认同**
   - 完成标准: 明确指导者与受训者都已同意——不能强加。
6. **选择低后果的练习场**
   - 完成标准: 指出在哪里练：组织内挑影响不大的项目，或在业余时间；明确哪些真实项目不宜当练习场。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是需要信息/答案，不需要训练（例：查一个 API 用法）。
- 高后果、不可逆的场合不适合当练习场（真实手术、生产环境事故处理）。
- 强加给不想练的人——书中明确：须先征得指导者与受训者双方认同，强加必定失败。

### 书中警告的失败模式 / 容易误用的地方

- 强度远超常规练习，对身心都是考验，**不能强加**。
- 组织内难以控制环境：练习机会有限且有后果，需挑影响不大的项目或业余时间练习。
- （推导, 非书中明示）"实时反馈"被误做成"事后评价"——反馈滞后到第二天，练习效果大幅衰减。
- （推导, 非书中明示）只推难度不给反馈会把人推向挫败而非成长；三要素必须同时具备。

### 容易混淆的邻近模型

- **一万小时定律（10000-hour rule）**: 强调时间量，缺少结构化要求。
- **坦诚相待（radical candor）**: 提供刻意练习所需的反馈质量。
