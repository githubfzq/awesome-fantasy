# 搭便车现象（free rider problem）

## R — 原文 (Reading)

> 造成公地悲剧等问题的另一个原因是搭便车现象（free rider problem），指某些人通过免费使用资源来"搭便车"。偷税漏税的个人或公司就是搭了政府服务（例如基础设施和法律体系）的便车。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

搭便车现象指的是：某些人免费使用一项资源、靠别人的付出来获益，却不承担相应的成本。偷税漏税者享用基础设施与法律体系，团队项目里混日子的人享用队友的成果，蹭用别人的无线网或视频账号，都是同一结构。

它为什么成立，取决于资源的两个属性：**难以排他**（因为是"公共"的，你没法把没付钱的人挡在外面）和**非竞争性**（一个人多用一点也不明显减少别人的可用量）。这两点合起来让搭便车在个体层面显得无害：我一个人不付，路照样在、网照样通。

真正的问题在于阈值效应。作者明确指出，单个人搭便车"看起来似乎没有多大危害"，但当搭便车者足够多时，供给方失去继续投入的动力，公共物品要么被耗尽、要么根本没人生产——这就滑向了公地悲剧。所以搭便车不是一个道德问题，而是一个**结构性激励问题**：只要收益归自己、成本归众人，理性个体就会选择搭便车。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队/项目贡献不均：有人不出力却共享成果、奖金、署名或绩效。
2. 共享成本分摊：部门共用云资源、合租办公、联合采购，怎么分摊才不养懒人。
3. 公共物品的维护缺位：内部知识库、工具链、开源库人人用但没人修。
4. 社区与平台治理：内容平台、开源社区、共享出行的用户只取不予。
5. 为公共品设计投入机制：如何让受益者付费，而不是全靠少数人义务投入。

### 语言信号

- "有人什么都不干，最后功劳平分"
- "大家都在用，但没人愿意维护"
- "能不能蹭一下你们的账号/资源"
- "这些成本谁来出？反正我不用也照样能用"
- "白嫖 / free rider / 搭便车 / 出工不出力"

### 与相邻 skill 的区分

- 与 `mm-tragedy-of-the-commons` 的区别: 公地悲剧讲的是**存量资源被过度使用而耗尽**（过度取用），搭便车讲的是**没人愿意为供给付钱而导致供给不足**（投入不足）。一个是抢着用，一个是躲着付；前者要限制取用，后者要落实付费。
- 与 `mm-public-goods` 的区别: 公共物品是**被搭便车的那个对象**（难排他、非竞争的物品本身），搭便车现象是**发生在这类物品上的行为**。判断顺序：先确认对象是不是公共物品，再看有没有人白用。
- 与 `mm-aligning-incentives` 的区别: 激励一致是设计手段（让自利支持目标），搭便车是诊断结论；先诊断出搭便车结构，再用激励一致去设计排他或计量机制。

## E — 可执行步骤 (Execution)

1. **确认被搭的"车"是什么**
   - 明确写出共享资源与其真实成本（谁在付钱/付时间维护，成本多少）。
   - 完成标准: 一句话说清"资源 X 的成本由 A 承担，B 免费使用"。
2. **检验两个属性：能不能排他、竞不竞争**
   - 判断该资源是否难以排除未付费者、一个人的使用是否明显减少他人可用量。
   - 完成标准: 两个属性各给出明确判断。
   - 判停条件: 若可以低成本排他（技术上能挡住未付费者），问题退化为执行问题，直接加门槛即可。
3. **估算搭便车比例，判断是否越过阈值**
   - 书中强调单个人搭便车看似无害，危害是阈值效应：比例越高，供给方越没有动力继续投入。
   - 完成标准: 给出受益者中不付费者的占比，并判断供给方还能维持多久。
4. **设计排他或计量机制**
   - 手段：按使用量计费、身份与权限绑定、贡献度与收益挂钩、把公共品转为俱乐部物品、对不贡献者设可见成本。
   - 完成标准: 每条机制都对应到步骤 1 中被搭的那项成本。
5. **给供给方补激励**
   - 让投入者的收益显性化（署名、结算、绩效、直接付费），使其继续供给是理性的。
   - 完成标准: 明确写出"投入者因此得到什么"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 只有两三个人的小团队或亲密关系：直接沟通远优于设计机制，上机制会破坏信任（推导，非书中明示）。
- 权责与付费关系本就清晰的双边交易：那没有"公共"属性，谈搭便车是错用概念。
- 目的是普及而非回收成本的战略投入（如蓄意免费获客、公益开放）：此时"被搭便车"是设计意图，不是问题（推导，非书中明示）。

### 容易误用的地方

- 作者明确指出：单个人搭便车"看起来似乎没有多大危害"——所以不要因为发现一两个搭便车者就上重机制，危害是阈值效应，只有足够多的人搭便车才触发公地悲剧（书中明示）。
- 把能力不足或沟通不畅误判为搭便车：对方可能是不会做、不知道要做什么，而非故意白用（推导，非书中明示）。
- 为排他付出过高成本：若排他成本高于搭便车造成的损失，维持开放往往更划算（推导，非书中明示）。
