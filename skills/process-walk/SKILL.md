# 走过程：不适感升起时，当场把它走完

## R — 原文 (Reading)

> "在每个让我们恼火或焦虑的关系问题背后，你都会发现三种人类体验，其中一种会比另外两种更明显：
> 被遗弃——不配得——心碎"

> — 克里斯多福·孟，第二章 傲慢、偏见与过程 · 三道门

> "我想再次提醒你，描述出的步骤并非体验本身；步骤只是为了帮助你去体验的。"

> — 克里斯多福·孟，第二章 傲慢、偏见与过程 · 过程：通向妙不可言之门

> "5.岔路口：此刻，你可以停下强迫性的反应与行为，转向走过程，或继续在故事囚牢中转圈。"

> — 克里斯多福·孟，第四章 故事时间 · 提纲

## I — 方法论骨架 (Interpretation)

这个 skill 处理的是**已经升起的不适感**，不是"我该怎么办"。它不问原因、不解决问题、不改任何人。

**一、入口是身体，不是事件。** 伴侣的言行最差只是催化剂——作者断言"在这个情境出现前，你内在就已经有那些感觉了"。所以入口信号不只是"他做了什么让我生气"，也可以是**没有任何事件、只有身体发紧**（无对象入口）。如果你认为这个感觉是伴侣"造成"的，你还没进门。

**二、三道门替代"我为什么生气"。** 不问为什么，只做直觉三选一：被遗弃（恐惧/孤单/被排斥）、不配得（内疚/无价值/不够格）、心碎（绝望/失落/遭背叛）。这是归类，不是分析；"你的直觉马上就会告诉你"。

**三、动作只有三个：接纳 → 觉知 → 欣赏。** 接纳 = 按实际体验接受这个感觉，放下"为什么/怎么样"，用"这就是正在发生的"把故事挡在门外；觉知 = 留意它的部位与形式（振动、脉动、云雾、颜色），认出它是能量，**既不好也不坏**；欣赏 = 敬畏、爱、感恩的流动，**不指向对象**——不是找对方优点，也不需要你喜欢正在发生的事。

**四、终点不是"我感觉好了"。** 感觉可能消融，留下平静或喜悦；也可能引导觉知深入，触到一股宁静、无振动的力量（作者称之为"本质"）。但可观察的终点是**循环检查**：内在是否还有更多不快乐？有，就再走一次。

**五、它刻意不是技巧。** 作者三次否认：不是一系列步骤、不是一个技巧或工具、不是疗愈。判据——**当你还在使劲记住步骤的顺序，说明你仍在技巧层**。步骤是拐杖，不是方法本身。

**六、痛苦 ≠ 受苦。** 痛苦是任何形式的不适，受苦是对它的拒绝反应。本 skill 处理的是前者；一旦你在问"它为什么在这里""我怎么让它停"，你已在后者里。

## A1 — 书中的应用 (Past Application)

### 案例 1：约翰与玛丽（一）—— 加班晚归引发的十一步愤怒动力（第二章）
- **问题**：玛丽连续第三晚加班晚归。约翰哄双胞胎睡下后恼火焦虑，换电视频道时脑中上演一整段独白为愤怒找理由（"也许她跟那个浑蛋老板发生了点什么！"），玛丽进门他甩出"没什么"，之后冷战数日、周末总爆发，最后形成"谨慎的休战"。
- **方法**：作者把这段拆成十一个基本步骤，并指出——**第一步到第八步全都在一分钟之内发生，而且在玛丽出现前，约翰早就陷入了权力争斗**。要打断它，只需在最前面加一步：认出自己到底在体验什么。由此引出三道门。
- **结论**：约翰的底层体验是"微不足道"（不配得门），它**在玛丽回家之前就已经在他体内**；情境只是把它照出来的镜子。
- **结果**：这个案例同时是**反例**——约翰没有走过程，结局是休战而非解脱，那个微不足道感只是"暂时进入休眠，或驱使他从孩子或工作中寻求重要感"。它说明了不走的代价。

### 案例 2：约翰与玛丽（三）—— 鸡蛋吵架的"基于真相的沟通"重演版（第八章）
- **问题**：同一个"忘了买鸡蛋"的场景，作者刻意保留玛丽的**全部台词不变**，只改变约翰的出发点，用来回答"在真实生活情境中，这看上去像什么"。
- **方法**：约翰在对话**进行中**实时走过程——④ 把手放在胃部，说出"突然内在涌现了失败感"（定位身体部位 + 三道门归到不配得）；⑥ 被骂"胆小鬼"时停下反击，承认"你是对的，我确实认为自己是个胆小鬼"，然后**闭上眼睛坠入胸口的悲伤，进一步放松、如实接受**，"一种中立性再次渗入觉知"。
- **结论**：你的有意识沟通**不取决于你伴侣的沟通**——玛丽的表现与未走过程的版本几乎没差别，改变的是约翰一个人。
- **结果**：他睁开眼，玛丽"看上去也没那么难过了"，两个孩子进厨房各选一位家长拥抱。作者同时给出预期管理：**"约翰反反复复好几次"**，上下起伏、犯错又纠正是常态；防卫系统还是会完成它的本职工作。

### 案例 3："情绪上只是从六岁提升到八岁"——走过程的诞生时刻（序言 + 第八章）
- **问题**：作者婚前做各种灵性追求，婚后花十八年在个人成长、疗愈、自我改善、情商、冲突解决、转化性沟通与婚姻咨询上。自评：自己对不适感的反应"只是比我四岁时的略微复杂，但情绪反应大致上维持不变。耍脾气就是耍脾气"。结论是"成长可真是件苦差事！"
- **方法**：转折点是一个放弃——"**我放下了惯性，不再设法修补、疗愈、转化感觉，或用正面肯定语、灵性肯定语来掩盖感觉；不管我体会到了什么感觉，就简单地去接受。正是在这个时候，我明白了什么是真正的'过程'。**"
- **结论**：过程**成立于放弃修补**，而不是成立于一门更好的修补技术。它与作者此前十八年做的所有事方向相反。
- **结果**：作者自己的疗效证据仅此一例（N=1），且他自评"从六岁提升到八岁""我更多是个情绪的青少年"。这个诚实的低分是本 skill 预期管理的一部分。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. 伴侣说了、做了或没做某件具体的事，自己心烦、生气或焦虑，且**愿意在身体里处理它**而不是继续谈。
2. **什么都没发生**——远程办公一整天、伴侣在隔壁房间没说话，但自己身体发紧、心里堵得慌，说不出具体为什么（无对象入口）。
3. 反复问"我为什么生气""他为什么这样对我"，越想越乱，需要一个不问为什么的替代品。
4. 自述"我什么都感觉不到""我知道该感受情绪但我感受不到"，卡在定位身体这一步。
5. 独处时不适感升起，想要一个可独立完成、不需要伴侣配合的动作。
6. 对话正在升温，想在不中断对话的前提下实时降低执着（用觉知回路变体）。

### 语言信号（用户的话里出现这些就应激活）

- "我心里堵得慌"／"胸口发紧"／"胃里难受"
- "我一想到他那句话就不舒服"
- "我什么都感觉不到"／"我说不出是什么感觉"
- "我知道该接纳，但做不到"／"我想把这个感觉处理掉"
- "我为什么总是生气"／"他为什么这样对我"（→ 替换为三道门）
- "走过程"／"the Process"
- 英文：*I feel tight in my chest* / *I can't feel anything* / *I have a knot in my stomach* / *I'm upset and I don't know why* / *I want to sit with this feeling*

### 与相邻 skill 的区分（★防撞车关键）

- **与 `quantum-tunnel-surrender`（第 1 册）★必须显式互斥**：**臣服是决策层的跃迁，过程是感觉层的操作。** 臣服处理"两个都不想要"的左右为难——走也痛、留也痛，于是**直接想象"如果现在已经在爱中我会怎么做"，然后照做**，它不需要先碰到感觉。本 skill 处理"痛正在升起"——必须先碰到身体里的那个不适，再放松进入。分辨句：用户说"**我该走还是该留，两个我都不想**" → 那个；用户说"**我心里堵得慌／他这句话让我难受**" → 本 skill。**硬约束**：用户正在左右为难时不得给走过程——感觉层的操作解决不了决策层的问题，反而会把"选不出来"重新诠释为"我还没接纳够"。
- **与 `acceptance-or-tolerance`（第 2 册，本 skill 的入口闸门）**：它判定"我是不是真的碰到感觉了"，不处理感觉。它判为真接纳/已触及感觉 → 交给本 skill 走完；**判为无奈（有气馁感）、解离（用肯定语/道理盖住）或仍在情绪宣泄 → 不给流程**，因为此时走过程是在给排斥续电（愤怒、悲伤、焦虑本身就是排斥感觉的尝试）。用户说"我这是在接纳还是在忍" → 那个；"我知道这是感觉了，帮我走完" → 本 skill。**若用户能详述事件经过却说不出身体任何部位，先退回它。**
- **与 `eight-questions-communication`（第 1 册）**：八问是**当场把一次冲突谈完的对话流程**，需要对方在场或至少以对方为对象；本 skill 是**独处时（或对话中向内）处理自己升起的不适**，不需要对方配合，也不产出任何要说给对方的话。分辨句："我要跟他谈谈" → 八问；"我心里堵得慌" → 本 skill。
- **与 `power-struggle-old-wound`（第 1 册）**：那个做的是**归因**——"强度明显不成比例 = 童年旧痛被触发"，它回答"这个痛是从哪来的"。本 skill **不做任何归因**：不问它从哪来、不问是谁造成的，只处理当下身体里这一团。**分辨句**："我为什么为这点小事炸成这样" → 那个；"我知道了，现在我想把这个感觉走掉" → 本 skill。
- **与 `anger-three-forms`（第 2 册）**：它判别愤怒的外在形态（攻击/撤退/被动攻击），目标是**避免痛苦**；当用户认出自己在攻击或撤退时，可转本 skill 处理那个被避免的痛苦本身。

## E — 可执行步骤 (Execution)

> **第 0 步：安全拦截 + 医学排除（不可跳过，先于一切动作）**
> 命中以下任一条，**立即停止本 skill 的全部向内工作**，转向安全评估与资源连接：
> 1. 关系中存在身体暴力、威胁、破坏物品或阻挡去路；2. 存在监控、社交隔离、经济控制、限制人身自由；3. 存在针对儿童、老人或其他无议价能力第三方的伤害（含体罚分歧）；4. 存在成瘾、长期欺骗、财务隐瞒；5. 用户正在用"这是我设计的功课""他在帮我成长""这是我的梦"来解释**正在发生的伤害**；6. 用户出现闪回、解离、惊恐发作、自杀意念，或因使用本方法中断了正在进行的专业治疗；7. 用户报告"**走过程之后我更该留下了**"——这是奖励函数被劫持的确定性信号。
> **医学排除（本册特有）**：作者明说"这适用于一切痛——关节炎、心碎、偏头疼、不配得"。**写入操作时必须先排除器质性疼痛**。若用户描述的是新出现的、局限的、加重的、伴发热/麻木/放射/夜间痛/体重下降/大小便改变的身体疼痛，**先建议就医排查，不把器质性信号当作"需要接纳的能量"**。只有在器质性原因已被排除、或用户明确说的是情绪性不适时，才继续。
> **完成标准**：七条逐条过完得到明确是/否；医学排除得到一句明确的"这不是我这次要处理的对象"或"先去查"。**若任一命中，不再执行以下步骤。**

### 第 1 步：识别入口——有对象 / 无对象（V2 补丁）
- **有对象入口**（书中所有案例的形态）：伴侣说了、做了或没做某件具体的事，你心烦、生气或焦虑。
- **无对象入口**（本书未写、由方法自身推导出）：**什么都没发生**，但你身体里有紧绷、发堵、发闷。此时**跳过"是谁/因为什么"，直接从身体的紧绷处进入**——入口信号从"捕捉到自己在起反应"扩展为"捕捉到身体的紧绷/不适本身"。不需要先找到一件事来解释它。
- 请用户回答一句：**"你现在身体哪里不舒服？或者，是哪件事让你心烦？"**
- **完成标准**：用户能说出**一个身体位置**（哪怕模糊：胸口、胃、喉咙、太阳穴）或**一件具体的事**。
- **判停条件**：
  - 若用户能详述事件经过，却**说不出任何身体位置**，且不属于无对象入口 → **判为尚未触及感觉，停止本 skill，转 `acceptance-or-tolerance` 做入口闸门**。此时给流程 = 给排斥续电。
  - 若用户此刻正在强烈宣泄（号啕、长时间抖动、怒气冲天）→ 允许宣泄，明确"这不等于已经在走过程了"，等平息后回到本步。

### 第 2 步：岔路口（★全书唯一的决策点，来自第四章提纲第 5 步）
- 问一句：**"此刻，我还在找'谁该改变'吗？"**
- 若**是** → 你还在故事囚牢的第 2–4 步里转圈（问题 → 反应 → 意义）。此时不要走过程，先回到接纳句：**"这就是正在发生的。" / "事实就是如此。"** 并把"为什么""怎么样"这两个疑问词放下。
- 若**能说出"这就是正在发生的"** → 已过岔路口，进入第 3 步。
- **完成标准**：用户说出这两句中的一句，且**这句话里没有"他本来应该……""如果他肯……"**。
- **判停条件**：**若 5 分钟内用户仍反复回到"他本来可以/他就是不肯" → 停止走过程。** 这不是"还没接纳够"，而是本次议题的性质是外部处境，转到第 7 步出口 B（把它降级为一条具体的、可谈判的偏好或外部改变）。**不要用"你还在排斥"来推进。**

### 第 3 步：三道门定位（被遗弃 / 不配得 / 心碎）
- 直觉三选一，**不分析、不追问为什么**。配套词表供归口：恐惧/孤单/被排斥 → 被遗弃；内疚/无价值/不够格 → 不配得；绝望/失落/遭背叛 → 心碎。
- **关键判据**：**这个感觉在情境出现之前就已经在了。** 若用户坚持"是他让我这样的"，说明这一步没完成。
- **完成标准**：用户说出一个词，且同意"它在我体内，不是他放进去的"。
- **备用入口（三道门选不出时用）：信念填空四句**（第二章「判官来了！」章末，逐句填）：
  1. 当我的伴侣______时，我不喜欢。
  2. 当我的伴侣有这种行为时，我的反应是______（生气／恼火／焦虑／触怒／愤怒）。
  3. 如果我去看，我会发现在我的反应之下的感觉是______。
  4. 与这个感觉相关联的信念是：**我是______**。
  > 第 3 句原书让你参考"表 2.1 人类不适感类型表"，**该表在 mobi 转换中已丢失**。改为让用户**自己生成描述**——作者原话支持这一点："你或许能够想出一些我没有提到的不适感，所以请尽管把这些写到表中去"。**不得声称在引用表 2.1 的内容。** 填完后："把手放在你身体似乎有这个感觉的部位，闭上眼睛，让过程带你去穿越。"
- **判停条件**：三道门选不出 **且** 第 4 句填不出一个以"我是"开头的信念（如"我是不重要的"）→ 说明还停在行为层，**停止，转 `acceptance-or-tolerance`**。

### 第 4 步：选档（三档变体，问一句就够）
> 作者给了 5 步 / 7 步 / 3 要素三种表述，并明说"**希望你能找到一种最符合你性格的描述**"。三档并存本身就是设计，**不要把它们统一成一个"标准流程"**。

只问一句判据，然后走对应档：

- **"你能不能现在就指出身体哪个部位不舒服？"**
  - **能** → **档 A（五步·标准版）**，适合已能定位身体感受的人。
  - **不能**（或自述"我什么都感觉不到""我对身体感觉不熟""我可能是麻木的"）→ **档 B（七步·含麻木绕行）**。
  - **用户已走过多次、只是来要一句提醒 / 或用户明确说自己不是灵性取向** → **档 C（三要素·压缩提醒）**，一句话即可，不需要逐步引导。
- **完成标准**：明确选定 A / B / C，并告知用户"这只是拐杖"。
- **判停条件（"过程不是技巧"的操作化判据）**：**当用户开始追问"下一步是第几步""我刚才那步做对了吗" → 说明已跌回技巧层。此时停止给步骤，改说一句话：接纳 → 觉知 → 欣赏，然后闭嘴。** 判据就是那句——**当你还在使劲记住步骤的顺序，说明你仍在技巧层。**

### 第 5 步：走过程（按第 4 步选档执行）

#### 档 A｜五步（标准版，第二章「过程：通向妙不可言之门」）
1. **捕捉反应 + 三道门定位**（已在第 3 步完成）。
2. **找出部位，把手放上去。** *完成标准：手有一个具体落点。*
3. **放松，进入这个体验。** 放松会把你更深地引入感觉，带到感觉的中心。*完成标准：用户报告一个可观察的身体变化（呼吸变慢、某处松开、温度或重量感），而不是"感觉好一点了"。*
4. **认出这个感觉是种能量。** 平静地关注，它会显现为波形、脉动或星云，可能有色彩或声音；它**既不好也不坏**。*完成标准：用户能用一个感官词描述它（振动／一团／发紧／发烫／有颜色）。*
5. **让过程带领你，无论会去到何方。** 感觉可能消融，留下平静或喜悦；也可能引导觉知深入，触到一股宁静、无振动的力量。**可在此终止。**
- **判停**：若在第 3–4 步**感觉明显增强或变成更强、更深的不适** → 这是作者预告的正常现象（"感觉也可能会增强"），**不是做错**；除非伴随恐慌或解离，否则继续放松。若出现恐慌/解离 → 立即停止，回到第 0 步。

#### 档 B｜七步（含麻木绕行，适合"我什么都感觉不到"）
1. 注意到恼火，捕捉到对外在刺激起反应的倾向。
2. 问：恼火背后必定在体验的是被遗弃、不配得还是心碎？**倾听直觉的回应**（不是分析）。
3. 问：我在身体的哪个部位有不舒服？注意到紧绷之类的感受。
   - **若有情绪麻木倾向 → 问直觉："假如我知道位置，那么是我身体的哪个部位，体验到了不舒服呢？"信任你的直觉或想象给出的任何回应。**
   - **★ 必须保留的兜底补丁（作者原话）："要不然，就编一个回答。"** ——编出来的位置同样可以作为起点，不要在这一步卡住用户。
   *完成标准：有一个部位，无论它是"感觉到的"还是"编出来的"。*
4. 把手放到那个部位，把注意力带到那里。可能把它看成某种能量模式（颜色、振动、脉动、声音）。**预告：感觉也可能会增强，或变化成更强、更深的不适感**——这是正常，不是失败。
5. 提醒自己：**这种感觉不是真的；它其实是真正的平和与喜悦乔装而成的。** 接着放松，进入感觉，让觉知深入，进入感觉的中心。**预期管理：首次体验一般是平淡而了无生机的**——不要把它当成做错。
6. **欣赏内在的美丽。**
7. 过程在此结束，或就着这份寂静继续深入。**开放式收尾，不设终点。**
- **判停**：若第 3 步连"编一个回答"都做不到（>3 分钟）→ 停止，转 `acceptance-or-tolerance`（先判别是不是解离/无奈，再决定要不要回来）。

#### 档 C｜三要素（熟练后的压缩提醒，一句话）
> **"接纳它，觉知它是能量，欣赏它。"**
- 展开只在用户要时才给：① 接受不适感，放松进入；放下"为什么/怎么样"，用"这就是正在发生的""事实就是如此"把故事挡在门外。② 留意它在身体哪个部位、什么形式，觉察能量模式中心的动力源。③ 欣赏这虚幻能量模式的美妙——**欣赏不指向对象，不是找优点，也不需要你喜欢正在发生的事**。
- **判据（作者原话的反向使用）**：当你不再觉得自己在应用技巧、不再需要记住顺序，才是"过程的自然流动"。**还需要的就回退到档 A 或 B，不要硬撑。**

### 第 6 步：收尾——循环检查 + 时间盒（对冲不可证伪性）
- **循环检查**（唯一给出循环终止条件的表述）：**"检查一下内在是否还有更多不快乐的感觉，如果有，就再走一次过程。"**
- **时间盒（硬约束）**：单次走过程**以 20 分钟为上限**。
- **完成标准（三选一，必须是可观察的）**：① 感觉消融，留下平静或喜悦；② 身体出现明确变化（松开、变暖、呼吸顺畅）；③ 即使感觉还在，你能说出"**这就是正在发生的**"而没有攻击或防卫。
- **★ 中止条件（必须执行）**：**若 20 分钟内三者都没出现，或用户越走越紧、越走越烦躁、越走越想证明自己走对了 → 立即停止走过程，转到第 7 步。** **禁止**使用"你还在排斥""你还在自我改进号列车上""你的信念还在阻挡"来推进——这三句是本书不可证伪闭环的入口（走对=有用，没用=你还在列车上），agent 不得替作者补完这个闭环。
- **重复上限**：同一议题最多走 3 次。3 次后仍无可观察变化 → 停止，转第 7 步。

### 第 7 步：出口路由（三个出口，必须选一个并说清）
- **出口 A（走完了）**：达成第 6 步的任一完成标准 → 结束。不必追求"触及本质"，那不是可操作目标。
- **出口 B（还在找谁该改变 / 时间盒耗尽）**：**停止向内**。请用户把"我不接受的是什么"降级为一条**具体的、可谈判的偏好或外部改变**（表达偏好、设立边界、协商分工、安排独处时间）。若核心是"走还是留" → 转 `quantum-tunnel-surrender`；若核心是付出-回报失衡 → 转 `sacrifice-indulgence-pendulum`；若用户其实不确定自己在不在接纳 → 转 `acceptance-or-tolerance`。
- **出口 C（安全/医学命中）**：优先处理外部处境与安全，或就医排查。**完成标准：列出至少一个本周内可执行的外部动作。**
- **完成标准**：用户拿到一个明确方向。若结论仍是"我还需要更努力地走过程" → **本 skill 失败，回到第 2 步岔路口**。

### 实时变体：觉知回路（对话进行中使用，第二章「觉知」）
> 这是本册**唯一能在对话进行中实时使用**的工具（其余都需要暂停独处），自带防解离设计：同时防"只向外"（执着于伴侣和故事）与"只向内"（从感觉中解离）。
1. 用**一分钟左右**倾听伴侣在说什么。
2. **5–10 秒内**转向内在，留意你的感觉与伴侣的表述如何呼应（防卫、愤怒、悲伤……）。
3. 注意力再向外，放在伴侣的表述上，约一分钟。
4. 再向内，留意当下体验。**每次向内，都更多地注意你脆弱的感觉，更少地注意你的防卫性反应。**
5. 讲话时尽量避免防卫性或攻击性的话，让话语出自尽可能深的地方；讲话的同时留意内在。
6. 保持回路：注意对方的沟通，同时持续留意自己的内在体验。
- **完成标准**：至少完成 2 个完整的"外—内"回合。
- **质量判据（不是"我坚持了多久"）**：**向内时你留意到的是脆弱的感觉，还是防卫性反应？** 前者 = 回路在正确运转；后者 = 回路尚未建立，回到第 1 步。
- **判停**：若向内时出现解离、空白、与现实断开 → 立即停止，回到外部，不做更多向内工作。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **未排除器质性疼痛**。作者说"所有的痛都是一样的——关节炎、心碎、偏头疼，不配得"，这个断言在医学上不成立。新出现、加重、局限、伴报警症状的疼痛先就医；把器质性信号当作"需要被接纳的能量"是本 skill 最危险的用法，构成延误就医风险。
- **关系中存在家暴、精神虐待、PUA、跟踪、经济控制、成瘾、长期欺骗、财务隐瞒**——此时"向内处理我的不适"是延迟离开的机制。见第 0 步。
- **用户正处在急性崩溃、闪回、解离或惊恐发作中**——本 skill 需要观察位，崩溃中拿不到。
- **用户还在问"我该走还是该留"**——那是决策层问题，`quantum-tunnel-surrender` 的地盘。在感觉层做操作解决不了它。
- **用户只是想被听见，或想把一次冲突谈完**——先接住 / 转 `eight-questions-communication`。被上流程的体验会让人觉得被敷衍。
- **用户不确定自己是在接纳还是在忍**——先用 `acceptance-or-tolerance` 判定。判为无奈或解离时给流程，会变成给排斥续电。
- **涉及儿童、老人或无议价能力第三方的安全议题**——不用走过程处理，转安全评估与专业支持。

### 作者在书中警告的失败模式

**核心一条（第三章，作者列的"塑造伴侣的方法"清单，原文逐条）**——这些全部是**以改进为名的操纵**，作者把它们列在"你并不知道，通常会有一种正义凛然的感觉伴随着这些操纵行为"之下：
- **"走过程，但同时偷看你的过程是否有你所期盼的效果（即：你的伴侣有没有变得更好了）。"** ← 这是本 skill 的头号失败模式：**过程一旦带 KPI，就退化成它要取代的东西**。可观测信号：走完之后第一件事是去观察伴侣有没有变化；走的时候心里有个"这样他就该……"的预期。
- **"强烈要求你的伴侣负责。"**
- **"'坦诚地'沟通你的感觉，而潜台词是你的伴侣为此应做些什么，哪怕你坚称这些感觉是你自己的责任。"** ← 注意这条与第 1 册的冲突：第 1 册教"为感觉负责 + 坦诚沟通"，第 2 册指出**这句话本身可以是最精致的操纵**。
- **"祈求神（灵、宇宙，等等）代表你来干预——当然是为了你的伴侣好。"**
- 同清单其余各条（指责伴侣造成你的不快乐 / 批评恼人的习惯 / 纠正 / 抱怨 / 给建议帮他改进 / 要求履行承诺 / 记分）也都是**把过程当作改造工程的变体**。

其余：
- **把过程当技巧练习**（作者专门否认过三次）。原文："**"过程"仅仅是一个词，它不是一系列的步骤，也不是一个技巧或工具。**" 可观测信号：用户在数步骤、在意顺序、问"我这步对不对"。**后果是把过程降级成它要取代的东西。**
- **把情绪当感觉来走**：愤怒、悲伤、焦虑**都不是感觉**，是排斥感觉的尝试。去"走我的愤怒"等于给排斥续电。信号：越走越激动、身体越来越紧、伴随强烈叙事冲动。
- **把宣泄的量当进展**（作者自曝：曾用"每天有多少人落泪"衡量工作坊成功）。机制是可观测性偏误——释放外显、可计数、反馈强烈；真正的指标内隐且短期无反馈。
- **用肯定语/灵性话术覆盖不适 = 解离，不是接纳**。判据是**你是在接近脆弱，还是在逃离脆弱**。
- **"首次体验平淡而了无生机"被误判为失败**（作者原话预告）——进而加码、追求更强的体验，正好走到过程的反面。

### 作者的盲点 / 时代局限

- **不可证伪的封闭系统（本册最强反对意见）**：走过程有用 = 你走对了；没用 = 你还在自我改进号列车上 / 你还在排斥 / 你的信念还在阻挡 / 你还没到入茧阶段。**这个结构让方法无法被检验。** 对冲已写入 E 段：每一步都有可观察的完成标准，第 2 步设 5 分钟岔路口判停，第 6 步设 **20 分钟时间盒** + 3 次重复上限，并**明确禁止 agent 用"你还在排斥"来推进**。
- **"所有的痛都是一样的"**：关节炎、心碎、偏头疼、不配得被归为同一种能量，只是部位和强度不同。这等同于把**器质性疼痛与心理痛苦混为一谈**。本 skill 做了**与作者原意相反的修订**：医学排除是第 0 步的硬动作，不是可选提醒。
- **作者的划界被判定为「不够」**：他试图用"目前，我们只关注情绪不适"＋"我从未见证过任何人是我情绪不适的起因"来划界。五点失效理由：① 家暴、精神虐待、PUA、跟踪、经济控制的伤害**恰恰主要表现为情绪不适**；② 划界是一次性的，全书再未回归；③ 划界是排他的而非累积的，等于宣布情绪领域无例外；④ **作者自己守不住**——同章末尾他用掠走妻子并企图谋杀的罗波那演示"连敌人也只是在演好自己的角色"；⑤ 全书**零处**写有"如果你正在经历 X，请不要使用本书的方法"。因此**不能依赖作者的划界**，第 0 步的拦截集是必需的。
- **本册特有风险表**：「伴侣完美地按剧本演出」在虐待关系中直接构成对施害者的开脱；「我都没法控制自己的言行」「也许我是个木偶」的**责任取消是双向的**——施害者可引申为"我的暴力也是设计"；体罚被列为「普通分歧领域」涉及**儿童安全**，全书对第三方零保护性说明；成瘾 / 外遇 / 财务隐瞒被列为普通分歧，用"各走各的 + 走过程"处理会延误戒断与财务保护；「管好你自己的事」会变成**不干预许可**，同时取消求助与保护的必要性；「拯救者不是出路」对需要专业干预的人本身是危险建议；「没有一个信念是真的」自相矛盾。
- **"阶段不可由意志推进"**：作者明说从未听说有人靠意志力从一个阶段进展到下一个阶段。**这直接取消了所有 actionable 建议的有效性基础——包括本 skill 的全部步骤。** 因此第 4 步必须同时声明"这只是拐杖"，第 6 步必须设时间盒，且不得承诺任何阶段跃迁。
- **证据基础与样本局限**：唯一疗效证据是作者自己的婚姻（N=1），且他自评"情绪上只是从六岁提升到八岁""我更多是个情绪的青少年"。近二十五年的依恋神经科学、情绪调节（DBT/ACT）、复杂型 PTSD 研究完全未纳入。**走过程的失败案例（走了没用、走不下去）在书中一次也没有出现**——这是案例池的系统性缺口，B 段的失败模式是补写的，不是作者给的。案例全部是北美中产异性恋模板（在家办公的程序设计师 + 房产中介 + 双胞胎）；无跨文化、双职工、单亲、丁克、同性伴侣案例。
- **两条 agent 特异性风险**：① 用户可能把你的回答转发给伴侣，作为"权威说你该改"的证据——**本 skill 的任何内容都不得用作要求对方改变的依据**；② 同一句追问"你身体哪里不舒服"在用户安全时是引导，在脆弱时是逼迫——**按用户当下状态设限，而不是按句子内容**。

### 容易混淆的邻近方法论

- **不是情绪释放 / 宣泄疗法**：宣泄是外放喧闹带戏剧性的（打滚、尖叫、捶垫子），作者明说那可能"什么感觉都没有"——是用情绪排斥感觉。走过程的肢体语言是**安静、内敛**的。判据：你在靠近脆弱，还是在把脆弱排出去。
- **不是正念 / 身体扫描**：正念是观察且不评判，到此为止；本 skill 除此之外还要**三道门归类、认出它是能量、走到欣赏**，并且**设终点与中止条件**。纯正念练习者若已落在无奈档，继续观察会强化压抑。
- **不是 ACT / 认知重构**：本书**不问"为什么"、不评估信念真假**（作者说"没有一个信念是真的"，包括这句本身），也不服务于价值导向的行动。档 B 第 5 步的"这种感觉不是真的"是**体验性的提醒，不是认知辩论**——不要跟用户争论这个信念合不合理。
- **不是第 1 册的受害者监牢 / 故事囚牢判别**：第 1 册问"**谁是迫害者**"，出口是单边行动；第 2 册说"**问题根本不需要被解决**"，问题只是出租车（"可以带我们围着故事囚牢一圈又一圈地转，也可以把我们送到真知的大门口"）。**两者同源但出口不同**——用户问"这到底是谁的错" → `victim-prison-exit`；用户说"我不想再绕了，我想把这个感觉走掉" → 本 skill。
- **不是解决问题的步骤**：解决问题问"谁该改变"，走过程问"我身体里正在发生什么"。**这个分界就是第 2 步的岔路口**，也是本 skill 与所有"解决方法"的分界线。

### 安全红线（必须随本 skill 一并执行）

以下 7 条为**最小拦截集**，命中任一 → **立即停止一切向内归因的方法**，转向安全评估与资源连接（与 E 段第 0 步完全一致，此处列出以便盲测与人工复核）：

1. 关系中存在**身体暴力、威胁、破坏物品或阻挡去路**；
2. 存在**监控、社交隔离、经济控制、限制人身自由**；
3. 存在**针对儿童、老人或其他无议价能力第三方的伤害或体罚分歧**；
4. 存在**成瘾、长期欺骗、财务隐瞒**；
5. 使用者正在用"**这是我设计的功课**""**这是我的梦**""**他在帮我成长**"来解释**正在发生的伤害**；
6. 使用者出现**闪回、解离、惊恐发作、自杀意念**，或因使用本方法而**中断了正在进行的专业治疗**；
