# 欣赏三途径（含"在气头上也能启动的捷径"）（R04 降级内容）

> 归属：`process-walk`。触发面窄，故降级为 references。
> 出处：第二章「欣赏（哇哦！）」+ 第六章。

## 前置：欣赏不是什么

- 欣赏 = **敬畏 + 爱 + 感恩**，**不指向对象**——"感恩充满了觉知，但不是针对某个人或某件事的"。
- **不是找对方优点**。作者明说：不是让你在坏情况中去找优点——"好和坏都是对情境的评判，都是时来时去的"。
- **不需要喜欢**："你不是非要喜欢正在发生的事，才能去欣赏的。"

## 三条途径

**途径一（过程的自然延伸）**：欢迎感觉进入觉知 → 看见这感觉是纯粹的喜悦与平和乔装而成的 → 觉知扩展 → 欣赏触及那个"帮你觉察到恼火"的人。
> 若不能表达欣赏，说明还有更多限制或伤害要面对——不必强求，但仍可在直觉中欣赏这一切。

**途径二（捷径，在气头上也能启动，不涉及过程的其他步骤）**：
1. 认出伴侣的言行是完美设计好让你醒悟的；
2. 欣赏那个让你愤怒的人"完美地完成了自己的本职工作"；
3. 起点可以是**勉强承认或钦佩他们如何把你逮个正着**——"即使你不能公开地欣赏他们，你也可以从勉强承认或钦佩他们如何把你逮个正着开始"。
> 作者保证"这种欣赏练习与走过程练习的效果是一样的"。

**途径三（和谐期）**：自发表达对伴侣本来面目的欣赏；拥抱时注意到"一个身体在拥抱另一个身体"，让这个认识的敬畏打开爱和感激。

## 激发句模板（第六章）

- "我真的很欣赏我的伴侣这么惹火我，支持我放松进入过程。"
- "我欣赏我的伴侣完全地忽视了我，支持我面对我的依赖感和不重要的感觉。"
- "即使我的伴侣真的对我很恼火，我也欣赏对方是在多么完美地按剧本演出。" ⚠ 见下方红线

## 真假欣赏的判据

最初表达可能显得造作——"**如果你不能在内心看到真相，就会一直造作下去**"。
若直觉地体会到欣赏的真实感，话语能帮你洞穿情绪反应。**造作不是失败，但长期造作说明还没看到真相。**

## ⚠ 红线（必读）

**第三条模板句「完美地按剧本演出」不得在以下情境使用**：家暴、精神虐待、PUA、跟踪、经济控制、成瘾。
在这些关系中，它直接构成**对施害者的开脱**，并会延迟离开。
作者自己也无法守住这条线——同章他用掠走妻子并企图谋杀的罗波那演示"连敌人也只是在演好自己的角色"，
工作坊学员的普遍反感（"你想把世上所有坏人都放一马"）正是这条红线的原始出处。
