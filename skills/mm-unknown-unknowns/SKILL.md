# 未知的未知数（四象限）（unknown unknowns）

## R — 原文 (Reading)

> 有些东西，我们知道自己知道。我们也知道，存在“已知的未知数”；也就是说，有些东西，我们知道自己不知道。但是，也同样存在“未知的未知数”；也就是说，有些东西，我们不知道自己不知道。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

人类盘点风险时会系统性地漏掉一整类东西。这个模型用"你知道什么"和"你不知道什么"两个维度交叉出四个象限,逼你把漏掉的那类显性化:

- **已知已知(known knowns)**: 你知道会发生,也有成熟应对——别人看是风险,你有经验所以不是。
- **已知未知(known unknowns)**: 你知道有风险,但不知道怎么解决——这类可以直接做去风险化(de-risking)。
- **未知已知(unknown knowns)**: 你压根没想到的风险,但解法是现成的——顾问、有经验的人能一眼认出来。
- **未知未知(unknown unknowns)**: 既不显而易见,连它的概率和后果你都无从估计——只能靠集思广益去发现。

为什么成立:人的想象力被自身经验边界所限,你无法"想到"一个你连概念都没有的东西。四象限的作用不是消除这个限制,而是给你一个**结构化的提问流程**,让你主动去找那些格子里的东西,而不是等它发生。

用法:逐格列举,然后努力把所有格子都转成"已知的已知数"。它本质上是风险版的全面盘点,与系统思考互为补充。

关键判据:识别出来还不够——**必须再做去风险化练习**,把风险真正转成已知已知,否则你只是多了一份焦虑清单。

## A1 — 书中的应用 (Past Application)

### 案例: 生孩子

- **问题**: 一对夫妇即将迎来第一个孩子,自认为准备充分,需要全面盘点即将面对的未知。
- **方法论的使用**: 作者按四象限举例——请产假、买安全座椅是"已知已知";孩子的吃睡偏好属于"未知已知"(新手父母没想到,但儿科医生和长辈有现成经验);"把孩子裹进襁褓"这类技巧是别人告诉你的"未知未知";而孩子是否有学习障碍,则没人能提前知道。
- **结论**: 大部分真正打乱生活的,不在"我都准备好了"的那一格里。四象限的价值是让人承认并主动寻找那些自己叫不出名字的风险。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户即将首次进入一个重大且陌生的情境:第一次当父母、第一次创业、第一次带团队、第一次出国工作。
2. 用户说"我想得很周全了",但其经验明显局限于某一类场景,你怀疑存在系统性盲区。
3. 用户正在做项目启动前的风险评估,已经列了一版风险清单,需要检查清单本身的完备性。
4. 用户在复盘一次"完全没想到会出这种事"的意外,需要一套框架防止下次再漏。

### 语言信号 (用户的话里出现这些就应激活)

- "我都想清楚了,应该没什么风险"
- "还有什么是我没考虑到的吗"
- "这个领域我完全没经验,不知道该问什么"
- "怎么会出这种事,完全没预料到"
- "帮我做个全面的风险盘点"
- "unknown unknowns" / "what am I missing?" / "blind spots"

### 与相邻 skill 的区分

- 与 `mm-scenario-analysis` 的区别: 四象限是**盘点工具**(穷举有哪些风险),情景分析是**生成工具**(构想未来图景以发现未知未知);先用本 skill 建立格子,再用情景分析往"未知未知"格里填内容。
- 与 `mm-de-risking` 的区别: 本 skill 负责**找出**风险,去风险化负责**处理**风险;作者明确指出仅识别还不够,仍须做去风险化练习把风险转成已知已知。
- 与 `mm-black-swan-events` 的区别: 黑天鹅强调"极端、不可预测、事后被合理化";本 skill 强调"通过结构化的提问和集思广益,一部分未知未知其实是可以被提前发现的"——前者认命,后者行动。

## E — 可执行步骤 (Execution)

1. **画出 2×2 并先填已知已知**
   - 完成标准: 明确写出两轴(知道/不知道 × 知道/不知道),先把用户已经想到的、且知道怎么应对的风险填入第一格。
2. **填已知未知**
   - 完成标准: 列出"知道有风险但不知如何解决"的事项,并逐条标记可去风险化的动作。
3. **借外部视角填未知已知**
   - 完成标准: 明确指出"这一步不能只靠用户自己想"——给出具体该问谁(做过这件事的人、该领域的顾问、过来人社区),并列出他们可能会点出的、用户没想到的风险与现成解法。
   - 判停条件: 若用户拒绝或无法获取外部视角,明确说明"未知已知"这一格将基本空白,矩阵的覆盖面大打折扣。
4. **集思广益攻克未知未知**
   - 完成标准: 用头脑风暴、"如果……会怎么样"的思维实验、以及情景分析往第四格里填;明确承认即便如此,这一格也无法穷尽,且这些风险的**概率与后果都无从估计**。
5. **转成已知已知:接去风险化**
   - 完成标准: 对每一条非第一格的风险,给出"如何把它变成已知已知"的具体动作(小实验、预先踩点、买保险、设触发线);没有这一步,本次盘点等于没做完。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 风险已经识别清楚,现在需要的是量化概率、算期望值——用决策树,矩阵给不了你数字。
- 低风险且可轻易逆转的日常选择:做全面盘点的成本高于风险本身,会造成分析瘫痪。
- 用户已处于危机中、需要立刻止损:此时先止血,盘点留到事后复盘。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给出边界,但明确指出它的目标是"尽可能全面了解某个情景",因此把它当成"列出几条风险就完事"的清单是误用。(书中明示)
- 仅识别还不够,仍需做去风险化练习把风险转成已知已知——停在识别这步等于只制造焦虑。(书中明示)
- "未知未知"这一格在定义上无法穷尽:任何声称"我把未知未知都列全了"的说法都是自相矛盾的,填完必须承认残余不确定性。(推导,非书中明示)

### 容易混淆的邻近模型

- 与黑天鹅事件: 黑天鹅是那些即便穷尽想象也难以预测的极端事件;本模型认为通过外部视角和集思广益,一部分盲区是可以提前发现的——不要把两者混为一谈,前者无法靠盘点消除。
- 与系统思考(systems-thinking): 系统思考关注要素之间的相互作用与反馈回路,本模型关注个体认知的盲区;作者说两者互为补充。
