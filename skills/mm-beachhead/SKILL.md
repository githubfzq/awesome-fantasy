# 滩头堡（beachhead）

## R — 原文 (Reading)

> 实际上，这借鉴了滩头堡（beachhead）这个军事概念。它是指一股军事力量占领并保卫一片海滩，以便更多兵力经过滩头抵达陆地。
>
> — 《思维模型》, 第9章 > 缺少执行的愿景不过是幻想

---

## I — 方法论骨架 (Interpretation)

**滩头堡（beachhead）** 是军事概念：一支部队不是一次性全面登陆，而是先占领并保卫一小片海滩，让后续兵力能经由这个安全的落脚点源源不断上岸。

**它描述什么**：引申到商业，就是**先在一个狭窄领域站稳脚跟，再向相邻市场扩张**。亚马逊的滩头堡是书籍，特斯拉的滩头堡是电动敞篷跑车 Roadster——都不是它们最终的主战场，而是第一个能被完全占领的窄口子。

**为什么成立**：资源有限时同时开战，等于在每条战线都是少数派，任何一条都守不住。把资源压到一个足够窄的范围，你才有机会在这个范围内形成压倒性优势、形成事实标准、形成口碑与现金流——这些东西是向外扩张时的弹药。宽度的代价是指数级的，窄度的收益是可守。

**关键判据**：一个合格的滩头堡必须同时满足三点——

1. **足够窄**：窄到以你现有资源能形成局部优势，而不是"又一个全面战场"。
2. **守得住**：占领之后能保卫，不会刚上去就被赶下来。
3. **连得出去**：从这片海滩能走向你真正想去的大陆。占领一个与终点无关的口子，是纯粹的浪费。

**职业上同样成立**：你的当前技能与岗位就是滩头堡，据此迈向更高的岗位——不是先跳到终点，而是先确认脚下这块地站得稳、走得出。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队资源有限，却同时在推 3-5 个方向/客群，每条都推不动。
2. 要进入一个大市场，纠结"先做哪个细分"、"先服务谁"。
3. 已经有了一个不错的立足点，在纠结"站稳了吗，能不能开始扩张"。
4. 职业上想跳到更高岗位，但资历/技能还没到，需要规划中间那一步。
5. 刚找到产品亮点，需要决定把它发展成什么规模的第一战场。

### 语言信号

- "我们是不是摊得太开了"
- "先做哪个细分市场"
- "全面铺开还是先聚焦"
- "从哪里切入比较好"
- "这块站稳了吗，能不能往旁边扩"
- "我想往上走一步，但现在还不够格"
- "beachhead / foothold / land and expand / which segment first / narrow focus"

### 与相邻 skill 的区分

- 与 `mm-bright-spots` 的区别: 亮点是**诊断**——在消极中定位积极迹象、判断该不该继续；滩头堡是**行动**——确定要继续之后，选一个窄口子集中推进。典型链条是"先找亮点，再把亮点变成滩头堡"。
- 与 `mm-barriers-to-entry` 的区别: 进入壁垒回答**能不能进去、进去有多难**；滩头堡回答**既然要进，从哪里进**。前者是可行性判断，后者是路径选择。
- 与 `mm-idea-maze` 的区别: 创意迷宫是**认知地图**——搞清楚这个行业里哪些路通、哪些是死路；滩头堡是**首攻地点**。地图告诉你怎么走，滩头堡是你决定先落到哪一格。
- 与 `mm-first-mover-advantage` 的区别: 先发优势处理**进入时序**（抢不抢第一个）；滩头堡处理**进入位置**（从哪里进）。一个是时间策略，一个是空间策略。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认是否真的处于"多线作战"**
   - 完成标准: 列出当前同时在推的方向/客群/战线，并给出每条线上的相对投入强度。
   - 判停条件: 若实际只有一条线但资源仍不够——问题是资源不足而非战线过宽，直接讨论聚焦即可。
2. **列出候选滩头堡并逐项打分**
   - 完成标准: 至少 2-3 个候选，每个按三点打分——是否**足够窄**（现有资源能否形成局部优势）、是否**守得住**（占领后能否保卫）、是否**连得出去**（能否通向最终目标市场）。任一为否即淘汰。
3. **为选定的滩头堡定义"站稳"的可观测判据**
   - 完成标准: 给出 2-3 个具体指标与阈值（如某细分市场的份额、留存、口碑推荐率、现金流自给），能明确回答"站稳了没有"。
4. **定义相邻扩张的顺序**
   - 完成标准: 写出从滩头堡出发的下一站、再下一站，并说明每一站为何与上一站相邻（共享客群/渠道/技术/供应链）。
   - 判停条件: 若两个候选滩头堡通向的大陆完全不同，明确指出这是战略分歧，必须先定终点再定起点。
5. **设定扩张的触发门槛与检查点**
   - 完成标准: 明确"达到什么指标才允许开始下一站"，以及一个复查时间点——避免没站稳就扩张、也避免站稳了不敢动。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 资源充足、可以在多个方向同时形成优势——收窄反而是自我限制。
- 市场窗口极短、必须一次性全面铺开（如强网络效应的赢家通吃市场）——先占小块可能来不及。
- 还在判断"要不要做这件事"——先解决可行性，再谈切入点。
- 问题出在执行力而非战线选择——收窄战线救不了执行不落地。

### 容易误用的地方

- （推导, 非书中明示）选的滩头堡不够窄。最常见的失败是"我们聚焦中小企业"——这仍然是全面战场。窄到能形成压倒性优势才算合格。
- （推导, 非书中明示）占领了一个与终点无关的口子。滩头堡的全部意义在于"以便更多兵力经过滩头抵达陆地"，与终点不相连的立足点只是消耗。
- （推导, 非书中明示）没站稳就扩张。必须有第 3 步的可观测判据，否则"站稳了"会变成主观感觉。
- （推导, 非书中明示）站稳了却不敢动。滩头堡是手段不是目的地，长期停在小海滩上等于放弃了当初收窄的意义。
