# 内部化（internalizing the externality）

## R — 原文 (Reading)

> 解决负外部性的方法通常被称为"内部化"（internalizing），就是试图要求引起负外部性的实体为此付出代价。最理想的情况下，与不受欢迎的活动有关的"价格"要高到足以支付处理该活动后果的成本。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

内部化是处理负外部性的标准手段：让制造外部成本的实体自己为后果付代价，把原本甩给他人的成本重新记回他的账上。

它的运作逻辑是价格。任何一项有副作用的活动，都有一个"理想价格"——等于处理该活动全部后果的成本。只要实际价格低于这个值，活动就会被过度从事，因为从事者只承担了一部分成本，剩下部分由别人默默消化。内部化就是把价格补到这个水平。补到位之后有两重效果：一是收上来的钱可以用来处理后果；二是价格足够高时，会从根本上阻止危害的发生——行为方自己就会选择不做。

手段有四类：税收（香烟税）、罚款（乱扔垃圾罚五百美元）、规章制度，以及通过市场交易（如排放权交易）。书中举的例子都很直白：香烟的负外部性通过香烟税和提高吸烟者保险费被内部化；交通拥堵通过道路通行费被内部化；"乱扔垃圾罚款五百美元"的牌子一立，路人就会主动去找垃圾桶。

判据是：**这个行为的后果里，有没有一块成本现在记在别人账上？** 如果有，内部化就是要找到那块成本、给它定价、然后收回到行为方身上。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 环境与安全外部性：排放、噪音、废弃物、安全事故，需要让企业为后果付费。
2. 拥堵与公共资源过度使用：道路、带宽、会议室、客服排队，用定价缓解。
3. 平台治理：垃圾内容、骚扰、刷单，让发布方承担审核与处置成本。
4. 组织内跨部门甩成本：某团队图快把返工、运维、客服成本甩给别人。
5. 产品设计定价：把售后、退换、环境处理成本计入售价或押金。

### 语言信号

- "这个成本不该我们承担，是他们造成的"
- "乱扔也没人管，罚得不够重"
- "能不能让他们自己为后果买单"
- "排污要不要收钱 / 拥堵费 / 押金"
- "internalizing the externality / polluter pays / Pigouvian tax"

### 与相邻 skill 的区分

- 与 `mm-externalities` 的区别: 外部性是**诊断**（成本被甩给了第三方，市场因此失灵），内部化是**处方**（把成本收回到行为方账上）。先诊断有外部性，才谈要不要内部化。
- 与 `mm-cap-and-trade` 的区别: 总量控制与交易是内部化的一种**市场型**实现（先定总量再允许交易），内部化是更大的范畴，还包括税收、罚款、直接管制。选哪种取决于能否界定总量、交易成本高低。
- 与 `mm-coase-theorem` 的区别: 科斯定理说的是产权明确且交易成本低时双方会自行谈判出有效结果，内部化是外部力量（通常是政府/平台方）主动定价。能用科斯谈判就不用管制，谈不成才内部化。

## E — 可执行步骤 (Execution)

1. **定位被甩出去的那块成本**
   - 写明：行为方是谁、受益是什么、受损的第三方是谁、受损的具体形式与规模。
   - 完成标准: 一句完整的"X 做 A 得到 B，成本 C 却由 Y 承担"。
   - 判停条件: 若找不到明确的第三方受损，则不存在负外部性，本 skill 不适用。
2. **给该后果定价**
   - 估算处理后果的全部成本（清理、医疗、修复、审核、客服、返工工时）。
   - 完成标准: 得到一个单位行为的成本金额（如每吨、每次、每人时）。
3. **选择内部化工具**
   - 按情境在税收/费用、罚款、规章制度、押金返还、市场交易（配额）之间选择。
   - 完成标准: 说明选该工具的理由（可计量性、可执行性、是否需控总量）。
4. **把价格设到"足以处理后果"的水平**
   - 校验：价格是否真的接近步骤 2 的成本？低了等于补贴该行为，高了会不必要地扼杀活动。
   - 完成标准: 给出定价区间并说明与估算成本的关系。
5. **验证行为是否真的改变**
   - 设定观察指标（发生率、排放量、投诉量）与观察窗口，检查行为方是否减少该行为或改用更清洁的方式。
   - 完成标准: 指标定义 + 复检时间点；若未改变，回到步骤 3 换工具或重新定价。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 成本已经完全由行为方自担（如一次性付费的私有服务）：没有外部性可内部化。
- 无法识别受损第三方或无法计量后果（很多分散、长期、间接的伤害）：强行定价会产生任意数字，反而制造不公（推导，非书中明示）。
- 参与方少且产权清晰、交易成本低时：优先让双方自行谈判（科斯定理），管制可能是多余的（推导，非书中明示）。

### 容易误用的地方

- 书中未给出本模型的边界，以下为基于机制推导：只收费不处理。收上来的钱若没用于善后，就退化成财政工具而非内部化（推导，非书中明示）。
- 定价过低反而给有害行为"发牌照"：一旦付了费就被视为合规，行为方可能更无忌惮（推导，非书中明示）。
- 忽略执行成本与转嫁：被内部化的一方常把成本再转嫁给下游消费者，需检查最终由谁承担（推导，非书中明示）。
- 书中强调"价格要足以支付处理后果的成本"，因此只做象征性罚款达不到内部化目的（书中明示机制）。
