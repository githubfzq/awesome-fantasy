# 相互确保毁灭（mutually assured destruction (MAD)）

## R — 原文 (Reading)

> 双方都囤积了足以摧毁对方的武器，因此任何核冲突都将迅速升级为相互确保毁灭……结果，双方都没有动机使用武器进攻对方
>
> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

相互确保毁灭(MAD)是一个反直觉的结构:双方都拥有摧毁对方的能力,任何冲突都会升级为同归于尽,**反而形成了稳定的和平**。

机制在于两条路都被堵死:
- **进攻没有收益**——动手等于自毁;
- **裁军也没有收益**——单方面放弃威慑就把自己暴露在对方的打击之下。

于是双方被锁在一个紧张态势里维持和平。它本质上把"可能爆发冲突"转化成了"没人敢开第一枪"的均衡。

商业上的对应物很常见:各大企业囤积成千上万项专利却互不诉讼,因为担心诉讼升级会破坏整个行业的稳定,最终伤到自己。

关键判据:整个结构建立在**可信性(credibility)**之上——每一方都必须相信对方真的有能力、也真的会在被打后反击。一旦有一方相信能先发制人(比如能一次性摧毁对方的反击能力),均衡立即破裂。

---

## A1 — 书中的应用 (Past Application)

### 案例: 美苏核对峙与企业专利囤积

- **问题**: 为什么两个敌对方在长期紧张对峙中反而不打起来?
- **方法论的使用**: 作者用冷战中美苏核武对峙说明:双方都囤积了足以摧毁对方的武器,进攻招致毁灭、裁军丧失威慑,于是双方都没有动机使用武器;再用商业案例对照——各大企业囤积成千上万专利却互不诉讼,担心诉讼升级破坏全行业稳定。
- **结论**: 这是一种靠"共同脆弱"维持的均衡。它的稳定不来自善意,而来自对同归于尽的共同恐惧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户所处的行业里,几家头部公司互相握有大量专利/数据/渠道筹码却彼此克制,想理解为什么。
2. 用户在评估"要不要起诉/反击",担心一旦动手会引发连锁升级、全行业受损。
3. 用户在分析国际关系、安全政策或企业间的威慑态势。
4. 用户困惑于"明明双方都有能力干掉对方,为什么多年来相安无事"。

### 语言信号 (用户的话里出现这些就应激活)

- "谁都不敢先动手"
- "一打起来大家都完蛋"
- "互相握着把柄 / 互相能卡死对方"
- "专利那么多,为什么不起诉"
- "打不起来,因为代价太大"
- "mutually assured destruction" / "MAD" / "if we attack, we both lose"

### 与相邻 skill 的区分

- 与 `mm-deterrence` 的区别: 威慑是**通用机制**(靠威胁后果阻止行动,通常是单方面的),MAD 是**特定的对称结构**(双方互相确保毁灭);一方有威胁能力用威慑,双方互相能毁灭对方才是 MAD。
- 与 `mm-nash-equilibrium` 的区别: MAD 就是一个纳什均衡的实例(谁单方面动手/裁军都会更糟);纳什均衡是识别工具,MAD 是具体的历史与商业结构。
- 与 `mm-arms-race` 的区别: 军备竞赛描述双方**持续加码**的过程,MAD 描述加码到某个点之后的**稳定状态**;前者是动态,后者是稳态。

## E — 可执行步骤 (Execution)

1. **确认是两个玩家互相握有毁灭性能力**
   - 完成标准: 明确指出双方各自能把什么"摧毁"掉,以及这个能力是否对称。
   - 判停条件: 若只有一方有威胁能力、另一方没有对等筹码,改用威慑模型。
2. **验证三条支柱**
   - 完成标准: 逐条确认——(a) 每一方都有能力在挨打后反击;(b) 对方相信你会反击;(c) 双方都清楚这一点。缺任何一条,MAD 都不成立。
3. **检查先发制人的诱惑**
   - 完成标准: 明确回答"有没有一方相信能一击解除对方的反击能力";若存在这种信念或技术(如首次打击优势、突袭窗口),明确指出均衡已不稳固,风险陡增。
4. **评估误判与意外升级的通道**
   - 完成标准: 列出可能意外触发冲突的路径(误报、第三方行为、自动化触发、沟通中断),并给出降低误判的具体措施(热线、透明机制、降级预案)。
5. **给出行动建议**
   - 完成标准: 明确说明在此结构下,理性的选择通常不是进攻也不是单方面裁军,而是维持可信威慑 + 建立防误判机制;若用户想打破僵局,建议改变的是博弈参数(降低相互摧毁的程度、引入第三方仲裁),而不是试探对方。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单方面有威胁能力、另一方没有对等筹码:那是威慑,不是 MAD。
- 双方实力悬殊到一方可以一击制胜且不受惩罚:不存在相互确保。
- 冲突代价其实有限、可以体面收场的商业摩擦:套用 MAD 会夸大风险、导致过度克制。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给出失效条件,但明确暗示它依赖"可信"——若一方相信能先发制人,均衡即破裂。
- 常见误用:把它当成"和平"的同义词。MAD 下的是**恐怖平衡**,紧张态势长期存在,且对误判极其脆弱,不能被视为已解决的问题。(推导,非书中明示)
- 另一误用:以为"双方都不动手"意味着"双方都很理性且稳定"——实际上个体误判、自动化系统或第三方行为都可能击穿这个结构。(推导,非书中明示)

### 容易混淆的邻近模型

- 与威慑(deterrence): MAD 是相互的、对称的威慑;威慑可以是单方面的(法律对潜在犯罪者)。
- 与军备竞赛: 军备竞赛是通往 MAD 的过程,MAD 是到达之后的稳态;分析"为什么还在加码"用前者,"为什么打不起来"用后者。
