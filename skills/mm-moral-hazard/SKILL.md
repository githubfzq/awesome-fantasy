# 道德风险（moral hazard）

## R — 原文 (Reading)

> 这种现象被称为"道德风险"（moral hazard）。也就是说，一旦你相信自己受到保护，就会愿意承担更大的风险，或是冒更大的危险。
>
> — 《思维模型》, 第2章 > 危险行业

---

## I — 方法论骨架 (Interpretation)

道德风险描述的是一种行为变化：**当损失由别人承担时，人会主动承担更多风险**。买了额外租车险之后开车更鲁莽，戴上头盔之后骑车更大胆——保护本身没有改变客观风险，它改变的是行为者对风险的定价。

它成立的机制是风险与收益的分离。任何一项冒险都有 upside 和 downside：正常情况下downside 由行为者自己吃，所以他会克制；一旦 downside 被保险公司、委托人、政府兜底，行为者就只剩下 upside，最优策略立刻变成"尽量冒险"。这不是道德败坏，而是完全理性的反应——所以叫"道德风险"其实有点误导，它是个激励结构问题，不是人品问题。

在代理关系中它尤其明显：代理人承担的风险**小于**委托人独立行动时的风险，因此天然更激进。理财顾问用客户的钱比用自己的钱更敢冒险，就是这个结构。

关键判据只有一句：**谁承担失败的代价？** 如果答案不是做出决策的那个人，就存在道德风险。这个判据可以套用到保险、雇佣、 rescue 政策、KPI 保底、乃至父母替孩子兜底的每一种场景。

## A1 — 书中的应用 (Past Application)

### 案例: 租车险、头盔与理财顾问

- **问题**: 作者给出一组同构的日常例子——人们在租车时买了额外保险后开车更鲁莽；戴上头盔带来的安全感让骑车人动作更大胆；理财顾问替客户操作时，比用自己的钱更愿意冒险。
- **方法论的使用**: 三件事表面上毫无关联，作者用同一个判据串起来：失败的代价由谁承担？租车时是保险公司，骑车时是"头盔已经保护了我"的错觉，理财时是客户。承担者一旦不是决策者，风险偏好就会上升。
- **结论**: 保护性措施的效果必须把行为反应算进去再评估，不能只看物理层面的保护力。作者还指出，这个问题从 17 世纪以来就一直是保险业关注的重大议题——它是结构性的、长期的，不是个别现象。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计保险、保修、赔付、退款、SLA 承诺等任何"兜底"条款时，评估它会不会改变被保護方的行为。
2. 设立对赌、保底、补助、救助（bailout）机制前，预判对方会不会因此放松风控。
3. 委托他人代为决策（投资、采购、招聘、外包）时，判断代理人会不会比你自己更激进。
4. 引入安全机制（头盔、护栏、备份、回滚、代码评审）后，检查是否出现了"因为有所以敢"的行为反弹。
5. 解释一个反常现象：为什么加了保护之后事故率/故障率没降，甚至升了。

### 语言信号 (用户的话里出现这些就应激活)

- "反正有保险"
- "亏了也不是我的钱"
- "上面会兜底的"
- "有备份就大胆改吧"
- "怕什么，能回滚"
- "moral hazard / too big to fail / someone else bears the downside / insured"

### 与相邻 skill 的区分

- 与 `mm-principal-agent-problem` 的区别: 委托代理问题关注"代理人的利益与委托人不一致导致结果次优"（包括偷懒、快速成交等），道德风险专指其中"因为不承担下行风险所以更敢冒险"这一支。所有道德风险都属于代理问题的一个子类，反之不成立。
- 与 `mm-asymmetric-information` 的区别: 信息不对称是**成因**（一方看不到另一方的行为或风险），道德风险是**结果**（行为因保护而改变）。诊断时先用信息不对称找原因，再用道德风险描述行为变化。
- 与 `mm-adverse-selection` 的区别: 逆向选择发生在**签约前**（高风险者更愿意买保险），道德风险发生在**签约后**（买了保险后行为更冒险）。判断方法是问"这个行为变化是在合同订立前还是后"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位决策者与下行承担者**
   - 明确写出：谁在做这个冒险的决定？如果失败，谁付钱/谁受损？
   - 完成标准: 得到两个主体名称；若二者不同，确认道德风险成立。
   - 判停条件: 若决策者完全自担后果，停止本 skill。
2. **枚举保护机制，逐条问"它覆盖了哪一部分下行"**
   - 列出所有兜底：保险、保底、救助预期、回滚能力、他人担责、有限责任。
   - 完成标准: 一张清单，每条注明覆盖了多大比例的损失。
3. **预测行为变化的方向与大致幅度**
   - 对每个被覆盖的下行，问：如果没有这层保护，行为者会怎么做？有了之后会怎么做？
   - 完成标准: 至少 2 条具体的行为变化预测（如"会更少做上线前的手工验证"）。
4. **设计让行为者保留一部分下行的机制**
   - 手段：免赔额/共付比例、追责条款、延后兑付、保证金、把代理人的自有资金按比例跟投、信息披露。
   - 完成标准: 每条措施都写明"行为者现在要自担 X% 的下行"。
5. **复核是否矫枉过正**
   - 保留过多下行会让行为者过度保守、放弃有价值的冒险；需与保护目标平衡。
   - 完成标准: 明确写出保留比例的理由，以及"过度保守"的监测指标。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 风险真正回到行为者身上的情形：作者明确指出，当风险由行为者自担时不适用。
- 行为变化来自能力或信息改变、而非风险转移时（例如培训后更敢做，那是能力提升，不是道德风险）。
- 把任何"有了保护后出事"都归为道德风险：需要先验证行为确实因保护而改变了，而不是保护本身不足（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 作者指出它"从 17 世纪以来一直是保险业关注的重大问题"——这说明它是**结构性的、不可根除的**，正确的目标是把风险控制住，而不是指望消除它（书中明示的方向）。
- 容易把它当成品德指控。它是激励结构的必然产物，指责个人操守无效，必须改结构（推导，非书中明示）。
- 消除道德风险的手段（如加大自担比例）本身可能抑制有益的冒险，需要权衡（推导，非书中明示）。

### 容易混淆的邻近模型

- 与逆向选择：两者常被并列误用。判断口诀——签约**前**的筛选问题叫逆向选择，签约**后**的行为改变叫道德风险。
- 与不当诱因：不当诱因泛指任何被扭曲的激励（含指标造假），道德风险特指"不承担下行 → 更敢冒险"这一机制，是它的一类。
