# 重复博弈（iterated game / repeated game）

## R — 原文 (Reading)

> 如果双方玩家都认为博弈会反复进行，而不是只玩一局，就可能得到更好的结果，这称为重复博弈
>
> — 《思维模型》, 第7章 > 参与博弈

---

## I — 方法论骨架 (Interpretation)

重复博弈是同一批玩家反复进行的博弈。核心机制只有一句话:**因为存在"未来的报复",合作比单次博弈更容易维持**。

它为什么成立:把时间拉长后,一次背叛换来的是一次性的收益,而失去的是此后所有回合的合作收益。当未来收益的贴现值高于一次性背叛的收益时,合作就成了理性选择——不需要任何一方变得更高尚,只要双方都看得见未来。

现实中的等价物是声誉机制:被视为"叛徒"的人,以后没人愿意跟他合作。这个长期损失足以压过单次背叛的短期收益。

关键判据:先问一句"这局之后还会不会再见"。一次性、匿名、无后续交往的博弈不适用——单次囚徒困境中背叛仍是占优策略。

一个必须注意的反面:**终局效应**。当双方都知道这是最后一局时,"未来的报复"消失,重复博弈就坍缩成单次博弈。所以长期合作的结尾往往是最危险的时刻,除非有外部机制(合同、押金、声誉跨场景传递)接住。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在考虑要不要在一次合作里占对方便宜,而双方此后还会长期打交道。
2. 用户面对一个看似双输的僵局(互相压价、互相防备),想知道有没有办法让合作成为理性选择。
3. 用户在设计长期机制(供应商考核、平台规则、团队激励),想让"合作"成为参与者的最优解。
4. 用户遭遇了一次背叛,在想是报复、断交还是继续合作。

### 语言信号 (用户的话里出现这些就应激活)

- "反正以后还要合作"
- "这次坑了他,下次他肯定不会放过我"
- "为什么跟老客户就能谈成,一次性的就谈崩"
- "我们要长期打交道,不能把关系搞僵"
- "合作结束了,最后这一单要不要紧"
- "iterated game" / "repeated game" / "shadow of the future" / "long-term relationship"

### 与相邻 skill 的区分

- 与 `mm-prisoner-s-dilemma` 的区别: 囚徒困境通常指**单次**博弈,背叛是占优策略;重复博弈是同一结构**反复进行**,结论翻转成"合作可以成为理性"。用户一描述"以后还要打交道",就要从前者切到后者。
- 与 `mm-tit-for-tat` 的区别: 重复博弈是情境(博弈会反复发生),以牙还牙是这种情境下的一个具体**策略**(先合作、然后照搬对方上一轮)。本模型判断合作是否可能,以牙还牙给出具体怎么打。
- 与 `mm-burning-bridges` 的区别: 过河拆桥描述的是主动切断后路的行为;从重复博弈看,那等于把未来的报复从自己的收益表里删掉,从而为自己赢得一次背叛的自由——代价是此后无人合作。

---

## E — 可执行步骤 (Execution)

1. **判断这局会不会再见**
   - 完成标准: 明确回答三个问题——之后还会打交道吗、对方是否知道你是谁、有没有声誉可以传递。
   - 判停条件: 三问皆否(一次性、匿名、无声誉传递)→ 明确说明这是单次博弈,背叛是占优,不要指望合作,应改用合同/押金等外部强制。
2. **估算背叛收益 vs 未来合作收益的贴现值**
   - 完成标准: 给出粗略对比——一次背叛多赚多少,此后每次合作损失多少、预计还能合作多少次;明确结论是合作占优还是背叛占优。
3. **若合作占优但对方不信,主动拉长未来的影子**
   - 完成标准: 给出具体措施——把大交易拆成多期付款/分期交付、公开承诺、引入第三方托管、签订带违约金的合同,让"未来"变得可信。
4. **处理终局效应**
   - 完成标准: 若合作临近结束,明确指出博弈已坍缩为单次,给出兜底手段(尾款押后、质保金、声誉跨场景的公开记录)。
5. **选择合适的长期策略**
   - 完成标准: 给出明确的打法建议并转 `mm-tit-for-tat`(开局合作、对等回报、对规律性背叛才报复)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 一次性、匿名、无后续交往的博弈:单次囚徒困境中背叛仍是占优策略,重复博弈的结论不适用。
- 双方都知道这是最后一局(终局效应):应视同单次博弈处理。
- 未来收益被极度折现时(如公司随时可能倒闭、对方马上离职):贴现值过低,合作不再理性。

### 书中警告的失败模式 / 容易误用的地方

- 书中只以"是否要一次又一次跟同一个人玩游戏"设问,未给具体故事;边界为推导。(推导,非书中明示)
- 常见误用:假设对方也认为博弈会重复,而对方其实把这当成最后一局——判断必须基于双方**共同**的认知,不是你一厢情愿。(推导,非书中明示)
- 常见误用:以为时间越长合作越稳。若没有报复能力或报复意愿,时间再长也吓不住背叛。(推导,非书中明示)

### 容易混淆的邻近模型

- 与囚徒困境(prisoner's dilemma): 单次版本 vs 重复版本,结论相反,是本书第 7 章最容易搞混的一对。
- 与以牙还牙(tit-for-tat): 情境 vs 策略,通常连用。
