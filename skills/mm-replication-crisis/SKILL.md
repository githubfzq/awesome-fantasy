# 可重复性危机（replication crisis）

## R — 原文 (Reading)

> 在某些领域（例如心理学领域），人们一直努力让阳性结果重复出现，但经过不断努力，却发现只有不到50%的阳性结果是能够重现的。这个比例相当低，而这种现象容易导致可重复性危机（replication crisis）。
>
> — 《思维模型》, 第5章 > 能否重现

---

## I — 方法论骨架 (Interpretation)

在心理学等领域，已发表的阳性结果中，不到一半能被重复实验复现。可怕的地方在于：**这并不需要一个造假者**。作者用算术演示了一种自然发生的机制——假设 60% 的研究是真阳性、40% 是假阳性，真阳性的重现概率是 80%–90%，假阳性的重现概率只有 5%；代入后算出的重现率恰好约 50%，与观测吻合。而且其中约 1/4 的失败，其实是重复研究本身功效不足造成的。

三类来源叠加：原始研究中假阳性的基础比率被严重低估（多重检验、P 值篡改）、重复研究本身功效不足、发表偏倚只让显著结果进入文献。此外还有选择性偏差、幸存者偏差，以及"纯属偶然"——原始研究展示的惊艳效应实际远小（趋于均值），而重复研究样本量不够、功效不足，因而测不出。

关键判据是：**把"一次显著"当成"结论为真"的概率有多低**——只有当被检验的假说本身为真阳性比例高时，显著性才接近真相。

---

## A1 — 书中的应用 (Past Application)

### 案例: 重现率的算术演示

- **问题**: 心理学阳性结果的重现率不足 50%，需要解释这个数字是怎么自然产生的。
- **方法论的使用**: 作者代入数值算了一遍——100 次研究中，60 次为真阳性（重现概率 80%–90%，约重现 48 次），40 次为假阳性（重现概率 5%，约重现 2 次），合计重现约 50 次，即重现率约 50%，与观测吻合；其中约 1/4 的失败源于重复研究功效不足。
- **结论**: 低重现率可以由"假阳性基础比率高 + 重复研究功效不足"自然生成，无需假设造假。作者给出的对策是：采用更小的 P 值、重复研究使用大样本、提前明确规定统计检验方式；并指出其他原因还包括选择性偏差、幸存者偏差与纯属偶然。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队复现了某篇论文/某个竞品结论，做不出来，怀疑自己方法有问题。
2. 准备依据一篇"震惊体"研究（单一实验、样本不大、效应惊人）调整战略或产品。
3. 内部做过一次效果极好的实验，第二次却完全没效果。
4. 评估一个领域（如心理学、营养学、AI 论文）结论的整体可信度。

### 语言信号 (用户的话里出现这些就应激活)

- "这个结论怎么重复不出来"
- "论文都发了，还能是假的吗"
- "我们上次做效果特别好，这次怎么没了"
- "这个领域的结论到底能不能信"
- "Why can't we reproduce this result?"

### 与相邻 skill 的区分

- 与 `mm-publication-bias` 的区别: 发表偏倚是**只发表显著结果**这一具体机制；可重复性危机是**多机制叠加后的总体现象**，发表偏倚只是其中一环。
- 与 `mm-data-dredging` 的区别: 数据捕捞是**制造假阳性的具体手法**；本 skill 覆盖的是从假阳性到低重现率的整体链条（还包含功效不足与偏倚）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **区分"复现失败"的三种可能**
   - 完成标准: 明确判断属于——原始结果是假阳性 / 重复研究功效不足 / 两者效果其实一致但被误读。
2. **检查重复研究的功效**
   - 完成标准: 给出重复研究在该效应量下的检出概率（书中对照：真阳性重现概率 80%–90%）。
   - 判停条件: 若重复研究功效明显不足，先补样本再谈"是否复现失败"。
3. **估算原始领域中假阳性的基础比率**
   - 完成标准: 说明该领域是否大量使用多重检验/小样本/只报阳性，从而抬高假阳性比例。
4. **给出证据升级路径**
   - 完成标准: 给出书中对策——更小的 P 值阈值、重复研究用大样本、提前明确规定统计检验方式；并建议查系统综述/荟萃分析而非单篇。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 工程上的"可复现"（代码跑不起来、环境不一致）是另一回事，与本模型无关。
- 已经被多个独立团队、大样本、预注册重复验证过的结论，不应再用"可能有危机"来贬低。

### 书中警告的失败模式 / 容易误用的地方

- 作者指出其他原因还包括**选择性偏差、幸存者偏差，以及"纯属偶然"**——原始研究展示的惊艳效应实际远小（趋于均值），而重复研究样本量不够、功效不足因而测不出。
- 对策明确：**用更小的 P 值、重复研究用大样本、提前明确规定统计检验方式**。
- （推导，非书中明示）反向误用：把"复现失败"一律归因于原始研究造假——书中的算术演示恰恰说明，无需任何造假也能得到 50% 的重现率。

### 容易混淆的邻近模型

- 发表偏倚（publication-bias）：只让显著结果进入文献的筛选机制。
- 数据捕捞（data-dredging）：人为制造假阳性的具体做法。
