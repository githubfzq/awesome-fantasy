# 创意迷宫（idea maze）

## R — 原文 (Reading)

> 投资家巴拉吉·斯里尼瓦桑称之为创意迷宫（idea maze）。你可以想象一座实实在在的迷宫……迷宫入口是你畅想的开始，迷宫出口是你的创意最终大获成功。
>
> — 《思维模型》, 第9章 > 缺少执行的愿景不过是幻想

---

## I — 方法论骨架 (Interpretation)

**创意迷宫（idea maze）** 把实现一个创意比作穿越一座真实的迷宫：入口是你开始畅想，出口是创意最终大获成功，中间的路上布满了死路。

**它描述什么**：优秀创始人与糟糕创始人的差别，不在于谁跑得快，而在于**谁能预见哪些方向通往财富、哪些方向通往死亡**。糟糕的创始人只会闷头冲进"照片分享"迷宫的入口，对行业历史与可能改变前提假设的技术一无所知。

**为什么成立**：迷宫里的死路大多已经被别人走过一遍了。行业历史上那些失败，把某些路径封死了；现存玩家把某些位置占住了；而某些正在成熟的技术会"移动墙壁"，让原本的通路变成死路、或让原本的墙忽然开一个口。这些信息在迷宫外部是可见的——你不看，就只能用自己的时间和钱去撞。

**穿越迷宫需要四类知识**：

1. **行业发展史**——哪些路已经被人走过、怎么死的。
2. **迷宫中的玩家**——谁在哪一段、占住了什么位置。
3. **过去的事故**——哪些坑反复出现。
4. **可能移动墙壁的技术**——什么变化会让既有前提失效。

此外，穿越迷宫还意味着理解各方的期待与需求，走错时**能清醒察觉**，并具备绕开障碍的**适应力**——迷宫不是一次画完就固定的地图。

**关键判据**：你能不能说出这个迷宫里至少三条已知的死路，以及它们各自是怎么死的。说不出来，说明你还在入口。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备 all-in 一个创业方向，需要评估自己对这个行业的理解是否够格。
2. 投资人/决策者在评估一个创始人团队值不值得投。
3. 已经做了半年，隐约觉得方向不对，需要判断是撞墙了还是只是慢。
4. 出现一项新技术，需要判断它会"移动迷宫的墙壁"还是只是噪声。
5. 团队在争论要不要进一个看起来很热、但没人说得清历史的赛道。

### 语言信号

- "这个方向以前有人做过吗"
- "我们算不算真的懂这个行业"
- "为什么之前那些公司都失败了"
- "这个赛道还有谁在做"
- "新技术出来会不会把我们颠覆了"
- "感觉撞墙了，但说不清是哪儿不对"
- "idea maze / do we know this space / who else tried this / what happened to the last ones"

### 与相邻 skill 的区分

- 与 `mm-heat-seeking-missiles` 的区别: 迷宫强调**发射之前的地图**——事先研究历史、玩家、死路与技术变量；导弹强调**发射之后的修正**——持续收集数据、调整轨迹。两者互补：先尽力画地图，再靠数据修正，不能用一个否定另一个。
- 与 `mm-beachhead` 的区别: 创意迷宫是**认知地图**（哪些路通、哪些是死路）；滩头堡是**首攻地点**（先落到哪一格、怎么向外扩）。地图告诉你怎么走，滩头堡告诉你先站哪儿。
- 与 `mm-pivot` 的区别: 转型是**撞墙之后的具体动作**；本 skill 既要求事先降低撞墙概率，也要求**走错时能清醒察觉**——它是转型的预警系统，不是转型本身。
- 与 `mm-why-now` 的区别: 为什么是现在判断**时机是否成熟**（外部条件到位了吗）；本 skill 判断**你是否掌握这个迷宫的结构**（内部认知够不够）。条件成熟但你不懂迷宫，照样会撞死路。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先画出用户当前已知的迷宫**
   - 完成标准: 得到一张草图——入口（现在的起点）、出口（成功长什么样）、已知的路径与已知的分叉点。
2. **补齐四类信息**
   - 完成标准: 逐项产出——(a) 行业发展史关键节点；(b) 迷宫中的玩家及其位置；(c) 过去的事故（尤其是失败案例的具体死因）；(d) 可能移动墙壁的技术及其时间尺度。
   - 判停条件: 若四项中任一项完全空白，明确指出这是认知盲区而非"创新机会"。
3. **强制列出至少三条已知死路**
   - 完成标准: 每条死路都写明"是谁走的、什么时候、怎么死的、尸体在哪"。列不满三条，判定为还在入口。
4. **标出当前位置与下一步**
   - 完成标准: 明确"我们现在在迷宫的哪一段"，以及下一个分叉点是什么、选哪条、为什么。
5. **定义撞墙的识别信号与重画周期**
   - 完成标准: 给出 2-3 个可观测的"我们已经走错"的早期信号，以及一个重画迷宫的固定周期（技术会移动墙壁，地图会过期）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 已经验证过方向、只需要执行——画迷宫会变成拖延的借口。
- 纯执行层的技术/运营问题（"这个功能怎么实现"）——迷宫不涉及具体施工。
- 真正全新的领域，历史上确实没有可参照的路径——此时迷宫画不出来，应改用快速实验去探路。
- 用户要的是市场容量、财务测算等定量分析——本 skill 提供的是结构性认知，不是数字。

### 容易误用的地方

- （推导, 非书中明示）把画迷宫当成纸上谈兵。迷宫必须落到"当前位置 + 下一个分叉点 + 选哪条"，否则只是行业综述。
- （推导, 非书中明示）以为迷宫是静态的。书中明确指出有"可能移动墙壁的技术"，地图会过期——必须有第 5 步的重画周期。
- （推导, 非书中明示）只画通路不画死路。死路才是迷宫最有价值的信息，只画通路等于自我论证。
- （推导, 非书中明示）用"没人做过"当优势。在迷宫语境下，"没人做过"更可能意味着那是一条已知的死路，别人已经替你试过了。
