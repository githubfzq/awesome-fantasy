# 总量控制与交易（cap-and-trade）

## R — 原文 (Reading)

> 各国政府试着通过"总量控制与交易"（cap-and-trade）制度解决燃烧化石燃料带来的负外部性（例如气候变化），这一制度正是科斯定理在现代社会的应用。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

总量控制与交易是一套两步走的机制设计：先由外部力量（通常是政府）设定一个**上限**（cap），把这个上限切成若干份许可发放下去；然后允许这些许可**自由交易**（trade）。

它同时满足了科斯定理的三个条件：许可明确了产权（谁有权排多少），企业理性地追求利润最大化，公开交易所提供低交易成本。三条齐了，市场自己就能把配额配置到减排成本最高的地方——减排便宜的企业多减、把配额卖出去，减排贵的企业买配额。同样的总量，用更低的成本实现。

"总量"这一步对应的是波士顿公园限牛数的逻辑：只谈产权不谈上限，草场照样会被吃光；先把牛的总数封死，再谈谁放几头才有意义。

关键设计判据：**上限是否真的封住了总量，以及许可是否被真实持有者自由交易。** 上限松动、配额超发、交易成本过高，三条里断任何一条，这套机制就会退化成一份昂贵的台账。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 设计或评估碳交易、排污权、用能权等环境政策方案。
2. 组织内部要分配稀缺资源（算力、预算、发布窗口、招聘名额），考虑是否允许团队之间转让配额。
3. 讨论"政府该直接管制还是建市场"这类政策工具选择。
4. 评估一个现有配额制度为什么没起作用（配额超发、交易冷清、价格失灵）。
5. 把外部性内部化的方案设计：需要给某个负外部性定一个可交易的价格。

### 语言信号
- "能不能让企业之间买卖排放权"
- "这个配额能不能转让"
- "直接限制每家排多少，还是搞交易"
- "我们内部算力不够用，能不能让部门之间交易额度"
- "碳交易到底有没有用"
- "cap-and-trade / emissions trading / carbon market / tradable permits"

### 与相邻 skill 的区分
- 与 `mm-coase-theorem` 的区别: 科斯定理是这套机制的**理论基础**（产权明确 + 理性人 + 低交易成本 → 私人谈判可达有效解），本 skill 是它的一个**具体制度实现**且多了一步"政府先设总量上限"；科斯定理本身不要求上限。
- 与 `mm-externalities` 的区别: 外部性用来**诊断**（有人的成本没被定价），本 skill 是**处方**（怎么给总量封顶并让它可交易）；先有诊断再有处方。
- 与 `mm-market-failure` 的区别: 市场失灵是"开放市场自行产生次优结果"这一大类问题的总称，本 skill 只是纠正其中负外部性这一种的具体手段之一。
- 与 `mm-government-failure` 的区别: 政府失灵提醒纠正手段本身也会失灵；设计 cap-and-trade 时必须同步检查它会不会被配额寻租、管制俘获所扭曲。

## E — 可执行步骤 (Execution)

1. **确认这是不是"总量必须封顶"的问题**
   - 问：危害取决于总量还是局部浓度？若是局部浓度（如某一个排污口的毒性），交易会让污染集中到一处，不适用。
   - 完成标准: 明确回答"取决于总量"或"取决于局部分布"。
   - 判停条件: 若是局部问题，退出本 skill，改用直接管制。
2. **设定并核对总量上限**
   - 上限必须是物理量（吨、立方米、次数），且逐年有收紧路径。
   - 完成标准: 写出上限数值与收紧节奏；并检查是否超发（历史排放远高于上限说明上限形同虚设）。
3. **设计初始分配方式**
   - 免费发放（按历史排放量祖父制）还是拍卖。说明各自的激励后果：祖父制奖励历史高排放者。
   - 完成标准: 选定一种并写明理由与副作用。
4. **降低交易成本**
   - 检查：有没有公开交易平台？交易是否需要层层审批？信息是否对称？
   - 完成标准: 指出当前交易成本的主要来源，并给出至少一条降低措施。
5. **设计监测、核查与惩罚**
   - 没有可信的计量，配额就是纸面数字。
   - 完成标准: 明确谁测、多久测一次、超标罚多少；罚款必须高于减排成本。
6. **做一次失灵预演**
   - 检查配额寻租、管制俘获、配额囤积、价格剧烈波动。
   - 完成标准: 列出 2-3 种可能的失灵路径及对应的兜底条款（价格上下限、储备配额、逐步缩减免费配额）。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 危害取决于**局部浓度**而非总量时：可交易会让排放集中到特定区域，总量达标但局部受害加重（推导，非书中明示）。
- 排放源太少、形不成市场时：两三家之间谈不上交易，直接管制更简单（推导，非书中明示）。
- 无法可信计量排放时：没有核查就没有配额，机制会退化成形式（推导，非书中明示）。

### 容易误用的地方
- 把"设了交易机制"当成"问题已解决"：真正起作用的是**上限**，交易只决定谁减排更便宜。上限定松了，交易再活跃也没用（推导，非书中明示）。
- 初始分配方式被忽略：按历史排放量免费发放（祖父制）等于奖励过去的高排放者，是新进入者的壁垒（推导，非书中明示）。
- 书中未给出该制度的边界说明，但书中在别处提醒纠正市场失灵的干预本身也可能失灵（见政府失灵），设计时应同步做失灵预演。
