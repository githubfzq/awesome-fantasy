# 沉没成本谬误（sunk-cost fallacy）

## R — 原文 (Reading)

> 如果你任由这些无法挽回的成本蒙蔽自己的决策，就会成为“沉没成本谬误”（sunk-cost fallacy）的受害者。
>
> — 《思维模型》, 第3章 > 摆脱坏习惯

---

## I — 方法论骨架 (Interpretation)

沉没成本是已经花出去、再也拿不回来的东西——钱、时间、精力，都在其中。理性地说，它不该影响当前的决策，因为它不因你的选择而改变。

但人很难做到。阻力来自三个方向：一是损失规避，"接受这笔损失"在感受上太难受；二是下注之后信心反而上升（诺克斯与英克斯特的赛马场实验发现，人下注后会更相信自己选的那匹马）；三是担心声誉受损，怕被看成半途而废的人。

一旦被这些力量牵着走，就会出现一个荒诞的结果：**因为已经投入了很多，所以继续投入更多**。而每一次追加投入，又让下一次的退出变得更难。

纠正方法有三步：从现实角度评估成功的概率（不是"已经投了多少"，而是"再投下去赢面多大"）；按机会成本比较"继续"与"转向新机会"；必要时主动打破既有承诺。

判据只有一句：这笔钱/时间，如果现在还没花，你还会花吗？

---

## A1 — 书中的应用 (Past Application)

### 案例: 看完不喜欢的电影 / 往濒临倒闭的公司继续投钱

- **问题**: 面对已经投入且表现糟糕的事（一部不喜欢的电影或书、一家濒临倒闭的公司、一段走下坡路的工作或恋情），人们倾向于继续投入而不是退出。
- **方法论的使用**: 作者指出沉没成本（包括已花掉的时间）无法捞回，任其影响决策即成谬误；并从三个来源解释心理阻力——损失规避、下注后信心上升（诺克斯与英克斯特的赛马场实验）、担心声誉受损。
- **结论**: 正确的做法是从现实角度评估成功概率，按机会成本比较"继续"与"转向新机会"，必要时打破既有承诺。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在描述一个明显走下坡路的项目/产品/合作，但结论落在"已经投入这么多了，再坚持一下"。
2. 用户在止损与坚持之间摇摆，需要一个不靠感觉的判断标准。
3. 用户在考虑要不要退出一段消耗型的关系、工作或学习路径，卡在"前面几年白费了"。

### 语言信号 (用户的话里出现这些就应激活)

- "已经投了这么多，现在放弃太可惜了"
- "都做到这一步了，再撑撑吧"
- "前面几年不就白费了吗"
- "这本书我看一半了，虽然不喜欢但还是看完吧"
- "we've come too far to quit now"

### 与相邻 skill 的区分

- 与 `mm-loss-aversion` 的区别: 损失规避是让人难受的**情绪机制**（怕失去），沉没成本谬误是被这种情绪驱动出来的**决策错误**。要纠正谬误，往往要先处理损失规避。
- 与 `mm-opportunity-cost` 的区别: 机会成本看未来还能选的选项，沉没成本看过去已经花掉的投入——一个必须进决策，一个必须排除出决策。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把已投入的和未来要投入的明确分开**
   - 完成标准: 输出两栏——"已经花掉、不可收回的"（钱/时间/精力）与"如果继续，接下来还要花的"。
2. **宣布已投入部分退出决策，并说明为什么**
   - 完成标准: 明确指出这部分不因当前选择而改变，因此不相关。
3. **从现实角度评估继续下去的成功概率**
   - 完成标准: 给出一个概率估计及其依据，而不是"也许会好起来"。
   - 判停条件: 若成功概率仍然可观（并非明显不利），本模型不适用，应转向常规决策分析。
4. **按机会成本比较"继续"与"转向"**
   - 完成标准: 至少列出 2 个替代用途及其预期价值，与继续的预期价值并列比较。
5. **识别心理阻力来源并给出破解动作**
   - 完成标准: 指出阻力主要来自损失规避、"下注后信心上升"还是声誉顾虑，并给出对应的破解动作（预设止损线、请未参与的人评估、公开重设承诺）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 涉及对他人的承诺与责任（团队、客户、家人）时，退出不只是个人成本收益问题，声誉与信任是真实成本，不能简单归入"谬误"。
- 需要韧性与长期投入才能见效的事（研究、创业早期、关系修复），过早用本模型退出反而会错失回报。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示：有些经济学家认为，亏损时考虑沉没成本可能有损声誉；硬撑不走同样损害个人形象。
- 书中明示：对成功而言，"灵活度"与"韧性"同等甚至更重要——不要把及时止损当成万能正确。
- （推导, 非书中明示）把一切坚持都标签为"沉没成本谬误"，会让人变成没有长期承诺的人。

### 容易混淆的邻近模型

- 与协和谬误 / 承诺升级（concorde-fallacy）混淆：几乎是同一现象的另一种命名，本模型是更通用的说法。
- 与损失规避（loss-aversion）混淆：见上方区分——一个是情绪机制，一个是决策错误。
