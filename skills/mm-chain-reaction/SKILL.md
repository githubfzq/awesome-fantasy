# 链式反应（chain reaction）

## R — 原文 (Reading)

> 在链式反应过程中，一个反应的副产物将成为下一个反应的原料，各个反应以自给自足的方式链接在一起。
>
> — 《思维模型》, 第4章 > 利用链式反应

---

## I — 方法论骨架 (Interpretation)

链式反应中，一个反应的副产物成为下一个反应的原料，各环节以自给自足的方式链接下去。核裂变是最典型的例子：中子撞击原子核，释放出的新中子成为下一次裂变的原料。

关键判据是**自持性**：每一环能否自发触发下一环。如果每一环都需要你从外部重新供能，那就不是链式反应，只是一条流水线。

自持性有规模门槛。书中用原子弹说明：低于临界量的核原料相对无害，高于临界量则足以促成爆炸。也就是说，链式反应不是"越多越好"的线性关系——它在某个规模上会发生质变，跨过之前怎么投都点不着。

在社会传播中，它对应"一个人说服另一个人"的口碑扩散：每个被说服的人成为说服下一个人的原料。

要注意它不是必然的好事。书中明确提示：失控时会变成灾难性的连锁反应（见「连锁故障」）；同一原理也可以被约束起来持续输出能量——用于制造相对安全、基本无穷无尽的核能。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在设计增长或传播机制（推荐计划、病毒循环、口碑），问"怎么让它自己滚起来"。
2. 用户在分析一个正在加速扩散的现象（舆情、流行、习惯传染），需要一个能解释"加速"而非"叠加"的模型。
3. 用户在找投入的杠杆点——想知道"补上哪一环，后面就能自己走"，或诊断"为什么循环走不下去"。
4. 用户在评估风险：某个环节出问题会不会一路传导到底（此时应转到 `mm-cascading-failure`）。

### 语言信号

- "怎么让它自己增长？"
- "用户能不能带来用户？"
- "为什么突然就扩散开了？"
- "一个带一个 / 一传十十传百"
- "我们投了很多钱，一停就归零。"
- "Can this grow on its own / viral loop / self-sustaining?"

### 与相邻 skill 的区分

- 与 `mm-cascading-failure` 的区别: 两者机制相同，但链式反应关注**正向的自持增长**（如何让它滚起来），连锁故障关注**负向的传导失控**（如何切断）。判据是方向：你要加速还是熔断。
- 与 `mm-network-effects` 的区别: 网络效应是"用户越多，产品对每个用户越有价值"（价值侧）；链式反应是"每个环节的产出成为下一环节的原料"（过程侧）。网络效应可以没有链式传播（用户各自独立加入），链式反应可以没有网络价值（谣言传播）。

## E — 可执行步骤 (Execution)

1. **画出环节与"原料"**
   - 列出环节序列，标明每一环的**副产物**是什么、它如何成为下一环的**原料**。
   - 完成标准: 每一环都写明了具体产出物与接收方；若某环的产出不流入下一环，标记为断裂点。
2. **检验自持性**
   - 问："如果外部供能停止，下一环还会发生吗？"对每个环节给出是/否。
   - 完成标准: 逐环判定完毕。
   - 判停条件: 若有环节为"否"，说明这不是链式反应而是线性流程——停止本 skill，改用流程优化或获客渠道分析。
3. **估算临界量**
   - 估算维持自持所需的最小规模或密度（多少用户、多高的转化率、多快的循环周期）。
   - 完成标准: 给出一个数量级估计，并说明当前距该门槛多远。
4. **找最高杠杆的那一环**
   - 判断哪一环的转化率提升对整体循环次数影响最大（通常是循环周期最长或流失最大的那环）。
   - 完成标准: 指出 1 个环节并给出计算理由。
5. **设计熔断（若用户同时关心失控风险）**
   - 明确指出在哪一环可以切断，以及切断信号是什么。
   - 完成标准: 有具体切断点；若风险为主，转交 `mm-cascading-failure`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 环节之间本无耦合，只是多件事顺序发生——那是流程，不是链式反应。
- 要解决的是传导失控、止损和熔断——那是 `mm-cascading-failure`。
- 增长来自"每个用户的价值随总人数上升"而非"用户带来用户"——那是 `mm-network-effects` / `mm-metcalfe-s-law`。

### 容易误用的地方

- 书中明示：失控时会变成灾难性的连锁反应（见「连锁故障」）；同一原理也可用于制造相对安全、基本无穷无尽的核能。
- （推导，非书中明示）把所有增长都讲成链式反应，会掩盖"你其实一直在花钱买每一环"的事实——用自持性检验（步骤 2）可以避免自欺：停止投放后还涨，才是真链式反应。

### 容易混淆的邻近模型

- **连锁故障**: 同一机制的负向版本，方向不同，解法相反（加速 vs. 熔断）。
- **临界量（critical mass）**: 临界量是链式反应能自持所需的那个量；链式反应是机制本身。
