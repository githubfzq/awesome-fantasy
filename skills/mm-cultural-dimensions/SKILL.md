# 文化维度谱系（cultural dimensions）

## R — 原文 (Reading)

> 严密（存在许多规范，对违反这些规范的容忍度极小）与松散：在松散的组织文化中，你可能会看见人们通过许多不同的方式做同一件事（例如安排项目）；严密的组织文化则会发展出更为严格的规章制度。
>
> — 《思维模型》, 第8章 > 携手共进

---

## I — 方法论骨架 (Interpretation)

高/低语境之外，社会学家还用**四组维度**来描述文化。每一组都是一个连续的谱，不是二选一：

- **严密 vs. 松散**：严密=规范多、对违规容忍度极小、会发展出严格规章制度；松散=同一件事（例如安排项目）允许许多不同做法。
- **等级制 vs. 平等主义**：等级制=权力分工明确；平等主义=权力共享，更多协商一致与群体决策。
- **集体主义 vs. 个人主义**：集体主义=群体成功优先；个人主义=个人绩效突出，典型产物是"员工排名制"（管理者不得不给直属员工打分排序）。
- **客观 vs. 主观**：客观=重视经验证据；主观=非数据导向。

**为什么成立**：文化这个词太模糊，直接问"你们文化什么样"只能得到形容词。把它拆成几个正交维度后，就能定位、能比较、能讨论——这是把不可言说的东西变成可操作的坐标。

**关键判据**：作者给出了这个模型最重要的用法——**设定清晰的价值观，其本质就是在明确"你的组织在各种文化维度中所处的位置"**。也就是说，价值观不是挂在墙上的口号，而是坐标选择。你选了"松散"，就别再期望流程统一；你选了"平等主义"，决策慢是必然代价，不是 bug。

由此推出一个实用推论：**维度上没有优劣，只有一致与不一致**。痛苦通常不来自"我们太松散"，而来自"嘴上说平等、实际按等级行事"这种内部错位，或跨地区协作时双方默认坐标不同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要写公司/团队价值观，但写出来全是"创新、协作、诚信"这类放到哪家都成立的空话。
2. 两个团队（或并购后的两家公司、跨国的两地办公室）合作摩擦，双方都觉得对方"不可理喻"。
3. 组织在争论流程要不要统一——有人要上 SOP，有人说这会扼杀灵活性。
4. 管理者困惑于"决策太慢"或"员工不服管"，想知道这是人的问题还是文化设定的必然结果。
5. 要判断自己适不适合某个组织，或某个候选人与团队合不合。

### 语言信号 (用户的话里出现这些就应激活)

- "我们公司的文化到底是什么"
- "价值观怎么写才不像空话"
- "两边团队就是磨合不到一起"
- "要不要统一流程"
- "他们那边做事方式和我们完全不一样"
- "决策太慢了 / 太随意了"
- "what's our culture like / tight or loose culture / flat vs hierarchical"

### 与相邻 skill 的区分

- 与 `mm-high-context-versus-low-context-communication` 的区别: 高/低语境只描述**沟通风格**（信息多大程度依赖语境）；本 skill 用四组维度描述**整个文化的结构性特征**，语境只是其中一个侧面。两者常连用，但层次不同。
- 与 `mm-culture-eats-strategy-for-breakfast` 的区别: 那句名言强调文化的**优先性**（文化会压过战略）；本 skill 提供**描述文化的方法**（文化由哪些维度构成）。前者讲重要性，后者讲怎么刻画。
- 与 `mm-loyalists-versus-mercenaries` 的区别: 效忠者/雇佣兵讨论的是**成员与组织的绑定动机**；本 skill 讨论组织本身的特征。文化是吸引效忠者的四个要素之一。
- 与 `mm-toxic-culture` 的区别: 有毒文化是**一种具体的病态结果**（已经坏了）；本 skill 是中性的坐标系统，用来定位任何文化，包括健康的。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认要刻画的对象与范围**
   - 完成标准: 明确是"整个公司""某个部门""某个地区的团队"还是"两个对象之间的对比"。文化的粒度错了，结论全错。
   - 判停条件: 若用户其实在问某个具体人的问题，转 `mm-big-five-personality-traits` 或 `mm-managing-to-the-person`。
2. **逐维度定位当前坐标**
   - 完成标准: 对四组维度各给出一个位置（可写"偏 X"或"X 与 Y 之间"），每条都要附上**具体观察证据**，不能只写形容词。例如"严密：所有项目必须走同一套立项模板，违反会被 review"。
3. **检查内部一致性**
   - 完成标准: 找出至少一处"宣称坐标"与"实际坐标"的错位（如宣称平等主义但所有决策由 CEO 单独拍板），并明确指出这种错位正在造成什么具体摩擦。
4. **若是两方对比，直接对齐坐标差异**
   - 完成标准: 用同一张坐标表把两方并排，指出差异最大的 1-2 个维度，并说明这个差异会如何解释他们已经发生的冲突。
5. **输出坐标选择而非口号**
   - 完成标准: 若用户是在写价值观，输出的是"我们在 X 维度选择偏 A，因此我们会接受 B 这个代价"这样的取舍陈述，而不是形容词列表。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 问题是某个具体的人不合群——那是个体层面，不是文化坐标问题。
- 文化坐标已经清楚，卡在执行落地——需要的是管理与激励设计，不是再刻画一遍文化。
- 只是沟通误会（邮件措辞、会议风格）——用高/低语境更精准。
- 用来给歧视或排挤背书：维度是描述工具，不是评判优劣或筛选人的标准。

### 容易误用的地方

- 书中明示：这四组只是**"一些常用的维度"**，作者并未声称穷尽。不要把它当成文化的完整定义。
- （推导, 非书中明示）把维度当打分表。维度是连续谱，切成分数会丢掉"我们在这个维度上内部就不统一"这个更重要的信息。
- （推导, 非书中明示）认为某一端更好。书里对每一端都只做中性描述（如平等主义=更多协商一致与群体决策，代价是慢），没有优劣判断。
- （推导, 非书中明示）刻板印象化：把国家/民族层面的文化坐标直接套到个体身上。书中这些维度用于描述组织文化，套到个人会严重失真。
- （推导, 非书中明示）指望改坐标很快。严密/松散这类特征由长期实践固化，"发展出更为严格的规章制度"是演化结果，不是一次制度发布就能切换。

### 容易混淆的邻近模型

- **高语境与低语境沟通**: 只覆盖沟通这一个侧面；本 skill 覆盖四组结构性维度。
- **有毒文化（toxic culture）**: 是一种坏结果；本 skill 是中性的定位坐标系。
