# 一万小时定律（10000-Hour Rule）

## R — 原文 (Reading)

> 格拉德威尔借鉴了艾利克森的理论，指出世界一流的专家通常需要经过一万小时的刻意练习，才能达到世界顶尖水平。请注意，艾利克森和其他人都指出，这并不是一成不变的“定律”。
>
> — 《思维模型》, 第8章 > 熟能生巧

---

## I — 方法论骨架 (Interpretation)

一万小时定律说的是：世界一流的专家通常要经过约一万小时的刻意练习，才能达到顶尖水平。它来自格拉德威尔对艾利克森研究的借鉴与普及。

它的真正用途是**量级校准**，不是精确预测。一万这个数字的意义在于告诉你"顶尖水平是几千小时量级的事，不是几百小时量级的事"——这足以改变一个人对学习周期的预期：练了三百小时还没成为专家，不是失败，是还差两个数量级。

但作者明确提醒：**这不是一成不变的"定律"**。艾利克森本人和其他研究者都指出过这一点。实际所需小时数取决于四个变量：练的是什么（领域本身的复杂度与竞争强度）、刻意程度（是重复已会的还是有针对性地攻弱点）、教练水平、以及你追求的精通程度（世界第一和"足够专业"不是同一个目标）。

关键判据：**用它来校准预期与坚持，不要用它来计时打卡**。小时数是结果的表征，不是投入的替代品——机械堆一万小时重复已掌握的内容，达不到刻意练习的效果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 制定长期学习计划或职业规划时问"要多久才能到顶尖"，需要一个量级参照来设预期。
2. 练了几百小时仍不见明显进步，开始怀疑自己没天赋、想放弃。
3. 评估某个目标的可行性：想在两年内达到某领域的世界级水平，判断这个预期是否现实。
4. 有人把"一万小时"当成硬指标（招聘要求、晋升门槛），需要指出它的适用边界。

### 语言信号

- "我练了半年了，怎么还是这么菜"
- "到底要多久才能成为专家"
- "是不是我没有天赋"
- "一万小时真的够吗"
- "我们招人要不要卡一万小时经验"
- "How long until I'm an expert?" / "10,000 hours — is that real?"

### 与相邻 skill 的区分

- 与 `mm-deliberate-practice` 的区别: 刻意练习讲的是**怎么练**（针对弱点、有反馈、走出舒适区），一万小时讲的是**练多久**。前者决定单位时间的质量，后者给出总量级——两者相乘才是真实进度，缺一不可。
- 与 `mm-spacing-effect` 的区别: 间隔效应讲的是**怎么安排训练的时间分布**（分散优于填鸭、各项技能轮流练），属于训练编排；一万小时是总量估算。
- 与 `mm-learning-curve` 的区别: 学习曲线描述**进步速度随练习变化的形状**（初期陡峭、后期平缓）；一万小时给出达到顶尖所需的**总量**。前者解释"为什么前期爽后期难"，后者解释"总量还有多大"。

## E — 可执行步骤 (Execution)

1. **先确认问的是量级还是精确值**
   - 完成标准: 若用户要精确预测"我还要多久"，先说明这不是定律、无法精确预测，再给量级区间。
2. **锁定四个变量**
   - 完成标准: 逐项给出——练的是什么（领域）、刻意程度如何、有无教练/反馈、目标精通程度（"世界级"还是"够用"）。目标越接近世界级，量级越接近一万。
3. **换算成可执行的年周期**
   - 完成标准: 用用户每周可投入的真实小时数（而非理想值）反推年数，给出"按当前投入，达到 X 水平大约需 N 年"的结论。
4. **检查是否在堆无效小时**
   - 完成标准: 若用户已有大量时长但进步停滞，判断他是在重复已掌握内容还是攻弱点；若是前者，转 `mm-deliberate-practice`。
5. **明确禁止当作门槛使用**
   - 完成标准: 若用户想把一万小时用作招聘/晋升硬指标，指出书中明示它不是恒定定律，且小时数不等于水平。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要安排具体的短期训练计划——用间隔效应与刻意练习，本 skill 只给总量参照。
- 作为招聘、晋升、评价他人的量化门槛——作者明说它不是定律，且小时数不直接等于水平。
- 领域本身竞争强度低或天花板低（如多数工具型技能）——此时所需小时数远低于一万，套用会吓退人。

### 容易误用的地方

- 书中明示：作者特别提醒**这不是一成不变的"定律"**，艾利克森和其他人都指出过。实际小时数因练什么、刻意程度、教练水平与精通目标而异。把它当公式是典型误用。
- （推导, 非书中明示）"一万小时"里的关键是"**刻意练习**"而非"小时"——机械重复已掌握内容的一万小时不产生专家级提升，这是流传中最常见的失真。
- （推导, 非书中明示）它是描述性统计（专家回顾起来大致花了这么久），不是承诺（花够一万小时就能成专家）。因果方向不能倒置。

### 容易混淆的邻近模型

- **刻意练习（deliberate-practice）**: 决定单位时间的质量，本 skill 只给总量。
- **学习曲线（learning-curve）**: 描述进步速度的形状，本 skill 给总量级。
