# 随机对照实验（randomized controlled experiment）

## R — 原文 (Reading)

> 你可以采用随机对照实验（randomized controlled experiment）。这通常被称为实验设计中的"黄金标准"。具体来说，就是将参与者随机分为两组，然后比较实验组（接受治疗的人）与对照组（没接受治疗的人）的实验结果。
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

随机对照实验的做法：把参与者**随机**分成两组，实验组接受处理，对照组不接受，比较两组的结局。

它的威力来自"随机"二字，而不是"对照"。为什么随机这么关键？因为随机化使两组在**所有维度上期望相同**——包括那些你根本没想到、甚至无法观测的维度。这就一举切断了混淆因素与选择性偏差两条污染路径：不是逐个排除第三变量，而是让两组在统计上成为彼此的替身。于是两组结局的唯一系统性差异，就锁定在你研究的那个因素上。

操作上有三条应用指引：
- **一次只改一个变量**——同时改三处，即使结果变好也不知道是哪一处起的作用。
- **配合盲测减少期望偏差**——如果参与者或评估者知道自己属于哪组，期望本身会改变结果（参见 `mm-placebo-effect`、`mm-observer-expectancy-bias`）。
- **预先定义可客观度量的终点**——事后挑选指标等于给自己无数次机会撞上显著结果。

作者强调这个设计不限于医学，也可用于广告与产品开发——这是它最被低估的地方。

## A1 — 书中的应用 (Past Application)

### 案例: 假手术对照

- **问题**: 如何判断手术本身的疗效，而不被"接受了治疗"这件事的心理效应污染？
- **方法论的使用**: 医学上用"假手术"作为对照——对照组经历同样的流程但不做实际治疗。作者引用 BMJ 一项评论：53 项研究中 74% 的假手术组症状改善，51% 的实验中改善程度与真实手术组相似。
- **结论**: 不做对照就会把安慰剂效应误算成手术疗效；作者同时指出该设计不限于医学，也可用于广告与产品开发。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要评估一个改动是否有效（新功能、新文案、新流程、新疗法），现有结论只来自观察或直觉——需要设计一次随机对照验证。
2. 用户在争论"到底是哪个因素起了作用"——需要一次只改一个变量的实验设计。
3. 用户的实验跑完了但结论不可信（中途改了方案、指标是事后挑的）——需要指出设计缺陷并给出重跑方案。
4. 用户想跳过实验直接全量上线一个高成本改动——需要评估实验的性价比与风险。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么才能确认这真的是它的效果？"
- "要不要做个 A/B 测试？"
- "我们同时改了三个地方，现在效果好但不知道是哪个起的作用。"
- "这个结论靠谱吗？有没有更严格的验证方式？"
- "How do we know it actually caused the improvement?"
- "Should we run an A/B test on this?"

### 与相邻 skill 的区分

- 与 `mm-placebo-effect` 的区别: 安慰剂效应是**为什么必须设对照组**的原因之一（不设对照组，光是"被治疗"就能产生效果）；随机对照实验是**整套设计方案**。前者是后者的理论依据之一。
- 与 `mm-confounding-factor` 的区别: 混淆因素是随机对照实验要**解决的问题**；随机化是**解决手段**。观察性研究里逐个排查混淆变量，永远不如随机化一次性打散来得彻底。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认可行性：随机化是否道德且可操作**
   - 问：把人/用户随机分到"不接受处理"这一组，会不会造成实质伤害或严重不公？样本量够吗？
   - 完成标准: 明确回答可行/不可行。若不可行（如不能让孕妇开始吸烟），直接进入步骤 5。
2. **锁定单一变量与分组方案**
   - 明确：这次只改哪一个变量？随机化的单位是什么（用户/会话/地区）？如何保证分配真正随机？
   - 完成标准: 写出"本次只改 X"的陈述 + 具体的随机化单位与分配方式。
3. **预先定义客观终点**
   - 在开跑前写下：主指标是什么、如何度量、跑多久、达到什么阈值算有效。
   - 完成标准: 主指标唯一且可客观测量，判定标准已写死（不许事后改）。
4. **设置对照与盲测**
   - 对照组的具体形式是什么（不做处理 / 现状 / 假处理）？需要单盲还是双盲？
   - 完成标准: 对照组定义明确，并说明是否已尽量减少期望偏差。
5. **不可随机化时的替代方案**
   - 若步骤 1 判定不可行，改用观察性研究 + 统计控制，并**显著下调结论的措辞强度**。
   - 完成标准: 明确写出"这是相关而非因果"以及残余风险。
   - 判停条件: 若实验成本高到远超决策价值，直接说明"这个决策不值得做实验"，给出低成本替代判断方式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 随机化不道德或不现实时（不能让孕妇开始吸烟、不能随机拒绝提供服务）——作者明确指出此时只能接受非随机研究，结论必须格外谨慎。
- 决策成本极低、可快速回滚的小改动——实验本身的成本可能超过收益。
- 样本量太小、效应量太小的场景——实验只会给出噪声。

### 书中警告的失败模式 / 容易误用的地方

- 有时不道德或不现实（如不能让孕妇开始吸烟），此时只能接受非随机研究，结论必须格外谨慎。（书中明示）
- 一次只改一个变量——同时改多处会让结果无法归因。（书中明示）
- 需要配合盲测以减少期望偏差；需预先定义可客观度量的终点。（书中明示）

### 容易混淆的邻近模型

- 与**盲测（blinded experiment）**: 盲测是随机对照实验中的**一个组件**（控制期望偏差），本 skill 是完整设计。
- 与**安慰剂效应**: 见 A2 区分——理论依据 vs. 完整方案。
