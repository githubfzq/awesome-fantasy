# 程序正义（procedural justice）

## R — 原文 (Reading)

> "程序正义"则围绕遵守程序描述什么是公平，认为透明客观的程序更公平。

> — 《思维模型》, 第7章 > 视角决定一切

---

## I — 方法论骨架 (Interpretation)

程序正义是"公平"的第二种定义方式:不问结果分得均不均等,只问**规则是否透明、客观,并被一致地执行**。只要程序站得住,即使结果差距很大,也被认为是公平的。

它为什么成立:结果往往受能力、努力、运气等不可完全控制的因素影响,而程序是制定者可以控制的。让可控的部分(规则)先站住,是公平感更可靠的来源。同时,透明客观的程序具有可预期性——参与者知道该往哪个方向努力,这本身就有独立价值。

关键判据:**看一个人判断公平时引用的是"规则"还是"数额"**。凡是论证中出现"标准是不是一致的""有没有提前告知""是不是所有人适用同一套""有没有可以复核的记录",用的就是程序正义框架。

书中给出的判例非常清楚:照顾祖父二十年的子女应该多分——这是从**过程与贡献**角度得出的公平判断,与"平均分最公平"的分配正义结论相反。这两套标准的冲突,正是"收入不平等""平权行动"等政治辩论的主轴。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 晋升、评优、招聘、招标的结果引发争议,而用户真正不满的是过程不透明或标准不一致。
2. 用户在设计一套分配或评审规则,想知道什么样的程序才算"站得住"。
3. 用户发现规则形式上都走完了,但明显有人被特殊对待,不知道该怎么说。
4. 用户在辩论公共政策(税收、平权、录取标准),需要区分对方的公平指的是程序还是结果。

### 语言信号

- "规则说变就变,谁受得了"
- "流程都走了,但明显是内定的"
- "为什么他可以例外,我就不行"
- "标准到底是什么,能不能提前说清楚"
- "同样的情况上次不是这么处理的"
- "due process" / "the rules weren't applied consistently" / "it's rigged"

### 与相邻 skill 的区分

- 与 `mm-distributive-justice` 的区别: 程序正义看**规则是否被一致公开执行**,分配正义看**结果是否均等**;同一个方案常在一套标准下公平、在另一套下不公平(书中祖父遗产案)。
- 与 `mm-fair-share-versus-fair-play` 的区别: 后者是两套标准在政治辩论中的**对立表述**,程序正义是其中**过程侧**的那一支(对应 fair play)。
- 与 `mm-aligning-incentives` 的区别: 激励一致关注的是规则**能否让自利行为支持目标**,程序正义关注的是规则**是否被公平地执行**;前者讲效果,后者讲正当性。

## E — 可执行步骤 (Execution)

1. **确认争议焦点在过程而非结果**
   - 完成标准: 明确回答——用户不满的是"分到多少"还是"怎么决定的"?若是前者,移交 `mm-distributive-justice`。
2. **逐条检验程序的四个要素**
   - 完成标准: 就以下四问给出明确的是/否——规则是否事先公开?标准是否客观可衡量?是否对所有人一致适用?是否有可复核的记录或申诉通道?
3. **区分形式合规与实质合规**
   - 完成标准: 明确指出"流程都走完了"不等于程序正义——若存在例外、事后变更标准、或结果先于评审确定,属于形式合规实质不公,并要求用户拿出可核实的证据再主张,避免停留在猜测。
4. **给出修复动作**
   - 完成标准: 至少给出一条可执行动作——把标准书面化并提前公布、为本次决策补充复核/申诉环节、对例外情况要求书面说明理由并公示。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 争议焦点是结果差距本身("凭什么他多我少")——用分配正义。
- 只涉及效率、不涉及公平判断的场景——用成本收益分析。
- 用它为一套形式合规但实质不公的规则背书:程序正义要求的是实质的一视同仁,不只是流程动作齐全。

### 容易误用的地方

- 与分配正义的冲突构成"收入不平等""平权行动"等政治辩论的主轴,双方常误以为在争论事实,实际在争论标准。(书中明示)
- 形式合规是程序正义最常见的伪装:走完流程、留好记录,但结果早已内定。(推导,非书中明示)
- 过度追求程序完备会把决策拖入流程成本,在后果小、可逆的事项上不值得。(推导,非书中明示)

### 容易混淆的邻近模型

- 与分配正义(distributive-justice): 同一枚硬币的两面,过程侧 vs 结果侧。
- 与激励一致(aligning-incentives): 一个讲规则的正当性,一个讲规则的效果。
