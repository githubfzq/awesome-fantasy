# 误差范围（margin of error）

## R — 原文 (Reading)

> 类似的民意调查通常会标出误差范围（margin of error）。介绍民意调查结果的文章中可能会提到"国会支持率为24%，误差范围±3%"
>
> — 《思维模型》, 第5章 > 钟形曲线

---

## I — 方法论骨架 (Interpretation)

误差范围就是估计值旁边那个"±X%"。它的本质是**置信区间的半宽**：真实值大概率（默认约 95%，即两个标准误差）落在"估计值 ± 误差范围"这个区间里。

它成立的原因是中心极限定理：多次抽样的样本均值会围绕真值呈正态分布，标准误差衡量这个分布的离散程度，取两个标准误差就覆盖约 95% 的情况。

**最关键的判据是平方反比关系**：标准误差与样本量的平方根成反比，所以误差范围减半需要样本量翻 4 倍。书中的阶梯是 96 人→±10%，384 人→±5%，1067 人→±2%，2401 人→±1%。这意味着从"大致有个印象"到"精确到 1 个百分点"，成本不是线性增长而是指数级增长——绝大多数商业决策不需要 ±1%，±5% 往往就够用。

由此推出两个实用判断：

1. **重叠即打平**。两个候选人的支持率区间若重叠（如 45%±3% 对 43%±3%），就不能说谁领先——这是媒体最常犯的错。
2. **先看有没有标，再看标的是多少**。没标误差范围的数字基本没有解读价值；标了也要追问对应的置信度，因为同一个 ±3% 在 90% 和 99% 置信度下含义完全不同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到一份民调、满意度调研或市场份额报告，问"这两个数字谁更高""是不是真的涨了"。
2. 自己做了一次抽样调查或小样本 A/B 测试，要判断结果的可靠程度。
3. 计划做调研，需要决定"到底要多少样本才够"，或被告知"100 份问卷就能代表全体用户"。
4. 拿一个小样本结论（如"我问了 8 个客户，7 个说喜欢"）去支撑一个重大决策。
5. 看到媒体报道"某指标小幅上升"，怀疑这其实只是噪声。

### 语言信号 (用户的话里出现这些就应激活)

- "这个民调误差范围 ±3%，是真的领先吗"
- "这两组数据差不多，到底哪个更好"
- "我们做了 200 份问卷，结论能用吗"
- "要多少样本才能做到 ±2%"
- "涨了两个点，算涨了吗"
- "margin of error / is this statistically significant / how many respondents do we need"

### 与相邻 skill 的区分

- 与 `mm-confidence-interval` 的区别: 置信区间是**通用工具**（任意置信度、任意参数，可 asymmetric）；误差范围是它在民调语境下的**通俗说法**，默认 95%、默认对称、默认针对比例。要精确推断用置信区间，要快速读懂一份民调用误差范围。
- 与 `mm-standard-error` 的区别: 标准误差是**输入**（衡量抽样分布的离散程度），误差范围是**输出**（≈2×标准误差，翻译成人话的区间半宽）。前者是技术量，后者是沟通量。
- 与 `mm-sample-size` 的区别: 样本量权衡讨论的是"样本多少带来的各种代价与偏差"这一更宽的问题；本 skill 只聚焦其中一条硬约束——样本量与误差范围的平方反比。
- 与 `mm-central-limit-theorem` 的区别: 中心极限定理是误差范围**为什么成立**的底层依据；本 skill 是可以直接拿来用的结论。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认这个数字是不是抽样估计**
   - 完成标准: 明确区分"抽样得来的估计值"（有误差范围）与"全量统计/确定性事实"（没有误差范围，如公司内部全量订单数）。
   - 判停条件: 若是全量数据或确定性事实，直接说明"此处不适用误差范围"，结束。
2. **找出或补出三个要素：估计值、误差范围、置信度**
   - 完成标准: 三项齐全。缺误差范围则按 ±1/√n（95% 保守近似）自行估算并标注为估算；缺置信度则默认按 95% 处理，并明确提示"报道未标明置信度"。
3. **算出区间并做重叠判断**
   - 完成标准: 写出每个估计值的完整区间。若比较两个数字，明确给出"区间重叠 → 不能断定有差异"或"区间不重叠 → 差异可信"的结论。
4. **反推样本量是否撑得住结论**
   - 完成标准: 用阶梯（96→±10%、384→±5%、1067→±2%、2401→±1%）核对，指出当前样本量实际能达到的精度，以及若要把误差减半还需多少样本（×4）。
5. **给出可操作的下一步**
   - 完成标准: 明确输出三种之一——(a) 现有精度已够，可以决策；(b) 需追加样本到具体数量，说明成本；(c) 这个精度下本就不该做此决策，应改用别的信息源。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 手上是全量数据而非抽样——不存在抽样误差，谈 ±X% 会人为制造不确定性。
- 差距巨大且远超误差范围（如 70% vs 30%）——此时纠结误差范围是浪费时间。
- 真正需要的是严格的显著性检验、多重比较校正或贝叶斯推断——用对应的统计 skill。
- 样本本身有严重的选择性偏差——误差范围只覆盖随机抽样误差，修不了系统性偏差。

### 容易误用的地方

- 书中明示：媒体报道"很少会解释它的来源或真实含义"，且多半不标示所用的置信度。看到裸数字要先怀疑。
- 书中明示：误差范围本身由中心极限定理与标准误差推出，默认约 95% 置信度——**不等于**"真值一定在区间内"。
- （推导, 非书中明示）误差范围只反映随机抽样误差，不覆盖无反应偏差、提问方式偏差、样本框偏差。一个 ±3% 但抽样框错误的民调，实测误差可能是 15%。
- （推导, 非书中明示）把"区间重叠"误读成"两者一定相等"。重叠只说明**无法断定有差异**，不等于证明了没有差异。
- （推导, 非书中明示）盲目追求 ±1%。平方反比意味着精度每提升一倍成本涨四倍，多数决策在 ±5% 就该动手。

### 容易混淆的邻近模型

- **置信区间（confidence interval）**: 同一件事的通用/正式版本；误差范围是它在民调里的通俗包装。
- **标准差（standard deviation）**: 描述**个体数据**的离散程度，不随样本量系统性缩小；标准误差/误差范围描述**估计值**的精度，随样本量增大而缩小。两者常被混为一谈。
