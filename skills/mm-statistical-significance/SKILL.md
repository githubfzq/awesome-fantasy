# 统计显著性（statistical significance）

## R — 原文 (Reading)

> 虚线表示统计显著性（statistical significance）的阈值。所有大于该阈值（右侧）的值都将导致原假设被否定。因为如果原假设是真的，那么如此大的差异就不可能出现。
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

统计显著性的逻辑是反证法：**假设原假设（"没差别"）为真，那么观测到这么大的差异是"不太可能"的；既然它出现了，就否定原假设。**

书中用两钟形曲线给了一个画面：原假设的分布与对立假设的分布会有重叠，显著性阈值就是画在两者之间的一条**虚线**。落在虚线右侧（差异足够大）的结果，就否定原假设。

那条虚线位置由 α 决定。书中的例子：助眠应用中，若原假设为真，出现如此大差异的概率不到 5%——这正是研究者设定的假阳性率。

而**重叠区就是两类错误的来源**：落在重叠区里，你可能把原假设的样本误判为对立（浅灰区 = 假阳性可能区），也可能把对立假设的样本误判为原假设（深灰区 = 假阴性可能区）。显著性阈值往哪边挪，就是在两类错误之间做取舍。

作者给出的最关键警告：**不要把统计显著性与科学、人文或经济显著性相混淆。** 样本量足够大时，连 1% 的微小差异也能达到统计显著——但它对消费者毫无意义。美国统计协会也告诫：不该只根据概率是否超出某个特定阈值来下结论。

关键判据：**"显著"只回答"这个差异不太可能纯属偶然"，不回答"这个差异有多大、值不值得行动"。** 两个问题必须分开问。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到实验结果（p 值），需要判断"能不能说有效"。
2. 结论是"统计显著但提升只有 0.5%"，纠结要不要上线。
3. 样本量极大（百万级日志），几乎每个指标都显著，需要判断哪些值得看。
4. 结论是"不显著"，需要区分"真的没效果"与"样本不够"。
5. 评审外部研究报告，需要检查显著性是否被滥用。

### 语言信号

- "p 值 0.04，是不是就可以说有效了"
- "统计显著但实际提升很小，要不要上线"
- "我们有几百万条数据，啥都显著"
- "不显著是不是就等于没效果"
- "这个结论有统计学意义吗"
- "statistically significant / p < 0.05 / is this difference real"

### 与相邻 skill 的区分

- 与 `mm-p-value` 的区别: p 值是**具体的概率数值**（若原假设为真，看到这么大差异的概率），统计显著性是**拿它跟阈值比较后的是否判定**。想算/解释数字用 p 值，想做"算不算数"的判定用本 skill。
- 与 `mm-type-i` 的区别: α 是**设定阈值的设计参数**（事前），统计显著性是**用这个阈值做出的判定**（事后）。讨论容忍度去前者，讨论结论去本 skill。
- 与 `mm-sample-size` 的区别: 样本量决定了显著性的"灵敏度"——样本越大越容易显著，这正是书中"连 1% 也能显著"警告的机制来源。样本不够导致的"不显著"，要去样本量权衡里解决。

## E — 可执行步骤 (Execution)

1. **确认原假设与阈值 α 是事前设定的**
   - 问：这个 0.05 是什么时候定的？是不是看到数据之后才选的？
   - 完成标准: 明确阈值在实验前已冻结。
   - 判停条件: 若阈值是事后挑的，或跑了很多指标/很多次才挑出这一个显著的，标注为数据捕捞风险，结论不可直接使用。
2. **把 p 值解释成人话**
   - 正确表述："如果原假设为真，看到这么大（或更大）差异的概率是 p。"
   - 完成标准: 用户能说出这个解释，且不把它说成"结论有 1−p 的概率正确"。
3. **分开评估统计显著性与实际显著性**
   - 问：这个差异的绝对幅度有多大？值不值得为之行动？够不够覆盖改动成本？
   - 完成标准: 给出效果量的业务解读，并明确说明"显著 ≠ 有意义"。
   - 判停条件: 若样本量极大导致微小差异也显著，改用"有意义的最小差异"作为判据（见对立假设）。
4. **检查是"没效果"还是"没检出"**
   - 若结论不显著，核算当前样本量下的功效：若功效不足，说明可能是假阴性而非无效果。
   - 完成标准: 明确区分"有证据表明无效果"与"证据不足"。
5. **给出行动建议而非只给判定**
   - 完成标准: 结论落到"上线/不上线/继续收集数据"三者之一，并说明理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要在设计阶段设定阈值参数：那是 α 与对立假设的职责，本 skill 处理的是结果判定（推导，非书中明示）。
- 讨论"这件事重不重要"的日常含义：统计显著性只指"是否可能纯属偶然"，与重要性无关（书中明示）。

### 容易误用的地方

- 书中明示的警告：**不该将统计显著性与科学、人文或经济显著性相混淆**——样本量足够大时连 1% 的微小差异也能达到统计显著，但对消费者毫无意义。
- 书中明示：美国统计协会告诫**不该只根据概率是否超出特定阈值来下结论**。
- （推导，非书中明示）容易把"不显著"读成"证明了没效果"。不显著只意味着证据不足，步骤 4 的功效核算是必要的补充。

### 容易混淆的邻近模型

- P 值（p-value）：被拿来与阈值比较的那个概率数值本身。
- 第一类错误（type-i）：阈值 α 的正式名称，"显著"判定所犯的错误就是假阳性。
