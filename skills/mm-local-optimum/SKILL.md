# 局部最优与全局最优（local optimum / global optimum）

## R — 原文 (Reading)

> “局部最优”是公认还不错的解决方案，但不是最佳解决方案。如果可以的话，你更希望朝着最佳解决方案，也就是全局最优（global optimum）努力。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

作者用一串山丘作比：你登上附近的那座小山，站在山顶，四周都是下坡——从你的视野看，你已经到顶了。但远处还有一座高得多的山，只是你从山坳里看不见它。附近的山就是**局部最优**，远处那座就是**全局最优**。

这个比喻里藏着整个模型的机制：局部最优之所以危险，不是因为它差，恰恰是因为它**足够好**。它让你在任何局部比较中都赢，于是你没有理由移动，也就永远走不到那座更高的山。

由此推出这个模型唯一真正重要的前提：**只有先完整了解整个系统，你才知道还有更高的山**。不了解全貌时，你无法分辨"我已经到顶了"和"我只是没看见更高的山"——这两者从内部视角看完全一样。

这正是系统思考的动机所在：先求全局认识，再选那个能把你带向全局最优的决策。顺序反了，你只是在把局部最优打磨得更精致。

关键判据：你能否说清自己看过哪些替代方案、以及为什么视野里没有更高的山？说不清，就还没到定案的时候。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户准备给一个"还行"的方案定稿，且备选方案来自同一思路的小改动。
2. 用户长期在既有路线上做微调（调参、改文案、改流程），但整体指标停滞。
3. 用户在两个方案间反复横跳，而这两个方案其实属于同一座山。
4. 用户打算重投资源到新方向，需要先确认当前方向确实已接近天花板。

### 语言信号
- "这个方案已经是我们能想到的最好的了"
- "两条路都差不多，选哪个"
- "一直在优化，但整体没什么起色"
- "还有没有别的做法"
- "我们是不是被困住了"
- "good enough" / "best we can do" / "is there a better way entirely"

### 与相邻 skill 的区分
- 与 `mm-systems-thinking` 的区别: 局部最优是**要解决的问题**（你只看到了附近的山），系统思考是**解决它的方法**（先纵览整个系统再决策）；二者是动机与解法。
- 与 `mm-premature-optimization` 的区别: 过早优化是**在错误的时间做优化**（结构未定就抠细节），局部最优是**在错误的范围里做优化**（不知道山外有山）；前者是时序错误，后者是视野错误。
- 与 `mm-path-dependence` 的区别: 路径依赖解释"你怎么会走到这座山脚下"（历史决定了你现在的位置），局部最优解释"你为什么下不了这座山"。

## E — 可执行步骤 (Execution)

1. **确认当前方案处在哪种最优上**
   - 问：你比较过多少个备选方案？它们是不是同一思路的变形？
   - 完成标准: 若备选方案彼此高度相似，判定为"疑似局部最优"，进入步骤 2。
2. **先扩展视野，再谈优化**
   - 用系统思考画出整个系统，找出你此前没纳入考虑的要素或维度。
   - 完成标准: 至少新增 2 个此前未被考虑的候选方向（换山头，不是换路线）。
   - 判停条件: 若视野已覆盖全系统且新方向均劣于当前方案，可跳到步骤 5 定案。
3. **做一次跨山头的粗评估**
   - 对新老方向做粗粒度比较，不追求精度，只判断量级。
   - 完成标准: 明确回答"有没有可能在别的山上拿到显著更好的结果"。
4. **若有更高的山，切换并接受短期下坡**
   - 完成标准: 明确写出切换路径与必须经历的短期下滑（从一座山到另一座山，中间必然要先下坡）。
5. **确认已无更高的山后，才开始精修**
   - 完成标准: 视野盘点完成、确认当前山头是可达范围内最高的，此时才投入细节优化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 需要立刻定案的小决策：搜索更高山的成本远超收益，"够好"就是正确答案。
- 已经做过充分的全局搜索并确认无更好方向：此时继续怀疑只是拖延。
- 用它无限推迟决策：作者没说局部最优不可接受，只说"如果可以的话"你更希望全局最优。

### 容易误用的地方
- 书中未给出边界说明，但隐含：不了解系统全貌时无法识别全局最优，此时应先用系统思考拓展视野。（书中明示的隐含前提）
- 以下为推导（非书中明示）：
- 误以为换山头不需要付出代价：从局部最优走向全局最优，中间必然要先下坡（短期指标变差），若组织不接受这个下坡，切换会在半途被叫停。
- 把"还没优化完"当成"处在局部最优"：前者是当前山头没爬到顶，后者是山头选错了，两者的动作完全相反。

### 容易混淆的邻近模型
- 与系统思考（systems thinking）：问题 vs. 解法。
- 与过早优化（premature optimization）：视野错误 vs. 时序错误。
