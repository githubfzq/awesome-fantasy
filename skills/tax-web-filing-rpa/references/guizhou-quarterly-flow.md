# 贵州省电子税务局 季度申报流程（用户提供，2026-10-11）

站点：https://tpass.guizhou.chinatax.gov.cn:8443/#/
登录：企业业务标签 → 扣缴义务人识别号 + 身份证 + "企业电子税务网站"入口 → 短信验证码（飞书往返）→ 登录。
所有要办理的业务都在 **"我的待办"** 里。

## 1. 增值税及附加税费申报（小规模纳税人）

1. 待办中事项名称"增值税及附加税费申报（小规模纳税人）"，点"填写申报表"。
2. 进入综合关联申报页面，自动勾选"增值税及附加税费"和"工会经费"两个项目（工会经费与增值税统一办理，无需单独办）。
3. 点"去办理"。
4. 确认合计 0 元。
5. 应税项填入 0 → 点"下一步"，进入确认表。
6. 点"提交申报" → 出现"申报成功" → 点"返回首页"。

## 2. 个人所得税经营所得（A 表）× 2 项

待办中有两项"经营所得（A表）待申报"，每项都走一遍：

1. 点"填写申报表"。
2. 录入被投资单位信息：统一社会信用代码填**扣缴义务人识别号**搜索。
3. 所属期止选**季度最后一个月**。
4. "下一步"进入"计税信息"："是否均在综合所得中扣除"选 **"是"**。
5. "下一步"进入"录入减免税额" → 直接"下一步"。
6. "确认申报信息"确认都是 0 → "提交" → "申报信息提交成功并已保存"。

**已知阻塞**：点"填写申报表"会弹"您的电子税务局账户实名认证登录未满足要求，请您返回原系统进行相关操作。"——需要用户在自然人电子税务局侧先完成实名认证等级要求，自动化脚本遇此弹窗应停下并报告，而不是绕过。

## 3. 财务报表报送

1. 待办点"填写申报表"。
2. 报送期间选 **"季报"** → "下一步"进入财报导入。
3. 首次填报需先**下载模板**。
4. Excel 打开填入：纳税人识别号、纳税人信息、所属期起、所属期止（运行时计算：Q3 = 07-01 ~ 09-30，1-3 月属 Q1，以此类推）。
5. 上传 Excel 导入报表 → "提交申报" → "报送成功"。

## 申报期限

季度申报每 3 个月过后的**下一月 15 日之前**完成（Q3 → 10 月 15 日前）。

## 硬性约定

- 所属期/所属期间一律运行时计算，绝不硬编码。
- 零申报也要逐项在确认页核对"合计 0 元"再提交；不为 0 立即停下报告。
- 每一步截图留痕到 `~/Documents/rpa/quarterly/pipeline/`，最终写 declare_report_<YYYY-MM>.json 汇总。
