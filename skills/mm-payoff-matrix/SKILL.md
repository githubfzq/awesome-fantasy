# 收益矩阵（payoff matrix）

## R — 原文 (Reading)

> 收益矩阵（payoff matrix）就以矩阵的形式展示了各个可能选项的收益
>
> — 《思维模型》, 第7章 > 参与博弈

---

## I — 方法论骨架 (Interpretation)

收益矩阵把一次博弈的结构摊平成一张表格:行是"我"的选项,列是"他"的选项,每个格子填上这一组合下双方各自的收益。书中用它展示了囚徒困境的刑期矩阵,也用它展示军备竞赛的结果矩阵(大赢家／小赢家／小输家／大输家)。

它为什么有用:把"我做什么 × 他做什么"的每种后果量化以后,就能直观地看出哪个结果是稳定的、哪个结果其实对双方都更优——很多争论之所以僵持,就是因为双方脑子里各只有一个格子。

它第二个、也是最实用的用途:**改变矩阵中的数字,就能改变对手的决策**。博弈的结果由收益结构决定,而不是由态度决定。想让对方换选择,就去改他那一格里的数字(加押金、设违约金、引入第三方惩罚、给出返点),而不是劝他"顾全大局"。

关键判据:找出均衡——哪个格子里,双方都没有动机单方面离开。那就是最可能实际发生的结果,即使它对双方都不是最好的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在谈判或对抗前,想把"如果我这样他会怎样"的几种情况一次看清。
2. 用户陷入"合作还是先下手"的两难(降价、抢发、挖人),需要一个结构化的判断依据。
3. 用户发现双方都卡在一个谁都不想动的位置,想弄明白为什么谁都不敢先变。
4. 用户想改变对手的行为,但不知道该从哪儿下手。

### 语言信号 (用户的话里出现这些就应激活)

- "几种情况的结果能列出来吗"
- "我们降价他们跟不跟,算一下"
- "合作好还是先下手好"
- "为什么谁都不愿意先让步"
- "怎么才能让他选另一条路"
- "payoff matrix" / "game matrix" / "what happens if we both..." / "normal form game"

### 与相邻 skill 的区分

- 与 `mm-game-theory` 的区别: 博弈论是整个分析视角与学科,收益矩阵是它最基础的可视化工具;判断"这是不是博弈"用前者,把博弈摊开算用后者。
- 与 `mm-decision-tree` 的区别: 决策树处理**序列**决策(我先动、他看到后再动),收益矩阵处理**同时**决策(双方同时选、互不知情);用户描述里有明确的先后顺序时用决策树。
- 与 `mm-2-2-matrices` 的区别: 2×2 矩阵是通用的四格分类工具(如重要/紧急);收益矩阵特指博弈中带双方收益数值的矩阵,格子里必须填两个玩家的收益对比。

## E — 可执行步骤 (Execution)

1. **点名玩家与各自的选项**
   - 完成标准: 明确写出"我"有哪 2–3 个选项、"他"有哪 2–3 个选项;若选项过多,先归并到最有代表性的几个。
2. **逐格填入双方收益**
   - 完成标准: 每个格子写一对数字(我的收益, 他的收益);无法精确量化时用相对排序(1 最差、4 最好)代替,并说明这是排序不是绝对值。
   - 判停条件: 若收益完全无法赋值、连排序都给不出,停止建模,改用定性讨论。
3. **标出双方各自的最佳回应**
   - 完成标准: 对"我"的每个选项,标出他会选的最优回应;再反过来做一遍;两轮标记重合的格子即为均衡。
4. **比较均衡与最优**
   - 完成标准: 明确指出均衡结果是什么、是否存在一个对双方都更好但不稳定的结果;若存在,说明这就是需要改规则的信号。
5. **若要改变结果,改数字**
   - 完成标准: 给出至少一条具体的结构化改动(押金、违约条款、返点、第三方仲裁、把单次变重复),并说明它把对方哪一格的收益改成了多少。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 没有会回应的对手的单方决策:用决策树。
- 收益完全无法量化、连相对排序都给不出时:强行填数字只会给出假精确。
- 玩家超过两方、选项连续(如任意价位):矩阵会爆炸,需要换用其他建模方式。

### 书中警告的失败模式 / 容易误用的地方

- 书中未提边界;但矩阵依赖可量化的收益,现实中很多冲突(面子、信任、士气)的收益难以精确赋值。(推导,非书中明示)
- 常见误用:只填自己的收益、不填对方的——那不是收益矩阵,只是清单,算不出均衡。(推导,非书中明示)
- 常见误用:把矩阵当预测工具。它给出的是在给定收益结构下的稳定结果,而收益结构本身可能你估计错了。(推导,非书中明示)

### 容易混淆的邻近模型

- 与决策树(decision tree): 同时决策 vs 序列决策,是两者最直接的分水岭。
- 与纳什均衡(nash equilibrium): 纳什均衡是收益矩阵里标出来的那个"谁都不想单方面离开"的格子,矩阵是载体、均衡是结论。
