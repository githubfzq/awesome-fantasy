# 第一类错误与第二类错误（type I / type II error）

## R — 原文 (Reading)

> 在统计学中，假阳性（误报）也被称为第一类错误（type I error），假阴性（漏报）也被称为第二类错误（type II error）。
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

统计学给两类判断错误起了正式名字：

- **第一类错误（type I error），记作 α** = 假阳性 / 误报——原假设其实为真，你却否定了它（"没效果"被误判成"有效果"）。
- **第二类错误（type II error），记作 β** = 假阴性 / 漏报——真实效应存在，你却没检出（"有效果"被误判成"没效果"）。

两个量都不是算出来的，而是**研究者在实验前主动选定的容忍度**：

- α = 100% − 置信度。所以常说的"95% 置信度"就是 α = 5%。
- β = 100% − 功效（power）。功效 80% 意味着 β = 20%。

书中用 α = 5% 给了最直观的解释：**如果原假设本来是对的，那么平均 20 次实验中会有 1 次得到假阳性结果。**

关键机制是两者的**此消彼长**：在样本量固定的情况下，把 α 压得越低，β 就升得越高。作者明确警告：虽然你可以自选把假阳性率压到 1% 甚至 0.1%，但**在样本量一定时假阴性率会大幅上升**，结果可能是你根本无法检出真实存在的效应。

所以没有"把错误率压到最小"这回事，只有"哪一类错误我更不能接受"的权衡。这个选择必须发生在看数据之前——事后改 α 就是数据捕捞。

关键判据：**先给两类错误分别定价（哪一类后果更严重），再据此选 α 与 β，最后让样本量去适配它们。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计实验，需要设定显著性水平（α）与目标功效（1−β）。
2. 有人要求"把置信度提到 99.9%，这样结论才稳"，需要评估代价。
3. 讨论"为什么我们做了很多实验都没检出效果"（可能是 β 太高）。
4. 评审他人研究时，检查对方是否事先声明了 α 与 β。
5. 争论"宁可错杀还是宁可放过"这类原则在统计上怎么落地。

### 语言信号

- "显著性水平定多少合适"
- "95% 置信度是什么意思"
- "要不要提到 99%"
- "为什么我们总是测不出效果"
- "误报和漏报哪个更严重"
- "alpha / beta / significance level / statistical power / false discovery rate"

### 与相邻 skill 的区分

- 与 `mm-false-positive` 的区别: 假阳性/假阴性是**错误本身的通俗说法与四格分类**，第一类/第二类错误是它们在**假设检验中的正式命名与参数化（α、β）**。讨论"这属于哪类错误"用前者，讨论"容忍度设多少"用本 skill。
- 与 `mm-power` 的区别: 统计功效 = 1 − β，专注**假阴性**一侧（有多大把握不漏掉真效应）；本 skill 覆盖**两类错误的联合设定与权衡**。
- 与 `mm-statistical-significance` 的区别: 统计显著性是**判定阈值的落点**（差异多大算数），α 是**设定这个阈值的参数**。前者是结果判据，后者是设计参数。

## E — 可执行步骤 (Execution)

1. **明确写出原假设与两类错误的现实含义**
   - 完成标准: 用业务语言（不是统计术语）说清"第一类错误在我们的场景里具体指什么后果""第二类错误指什么后果"。
2. **为两类错误分别定价**
   - 问：误报一次损失多少？漏报一次损失多少？哪一类更不可接受？
   - 完成标准: 给出可比较的代价，并指出优先压制哪一侧。
   - 判停条件: 若两类代价相当且都很低，用常规 α = 5%、功效 80% 即可，不必深究。
3. **据此选定 α 与 β**
   - α = 100% − 置信度；β = 100% − 功效。把选中的数值写下来，并说明它们意味着"平均多少次里错一次"。
   - 完成标准: 得到 α、β 的具体数值与通俗解释（如 α=5% 即 20 次里 1 次假阳性）。
4. **检查这个组合需要多少样本量，若不现实则回到第 2 步重新权衡**
   - 完成标准: 给出所需样本量，或明确指出"在可负担的样本量下这两类错误不能同时压到这个水平"。
   - 判停条件: 若样本量付不起，必须调整的是 α/β 的容忍度（并获用户知情同意），而不是偷偷改数据或反复偷看。
5. **在实验开始前冻结设定**
   - 完成标准: α、β、样本量、停止规则被明确记录，事后不再修改。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 只做描述性统计或不下判定：没有"否定/不否定"的动作就没有两类错误（推导，非书中明示）。
- 贝叶斯框架下的决策：那里用的是损失函数和后验概率，不是 α/β 的频率学派参数（推导，非书中明示）。

### 容易误用的地方

- 书中明示的警告：**把假阳性率压到 1% 甚至 0.1% 虽可自选，但在样本量一定时假阴性率会大幅上升**，可能因此无法检出真实结果。
- 书中以 α=5% 为例说明它意味着"平均 20 次实验中会有 1 次假阳性"，暗示多次重复实验时假阳性会累积出现，不能把单次 5% 当成"几乎不会错"（推导，非书中明示）。
- （推导，非书中明示）容易事后调 α 来让结果变显著。这是数据捕捞，正确做法是在实验前冻结设定（步骤 5）。

### 容易混淆的邻近模型

- 统计功效（power）：等于 1 − β，只覆盖假阴性一侧。
- 假阳性与假阴性（false-positive）：同一组错误的通俗表述，本 skill 提供正式命名与参数化。
