# 系统综述（systematic review）

## R — 原文 (Reading)

> 所谓的"系统综述"，就是运用围绕某个主题的综合研究成果，有组织、有条理地评估一个问题。它会拿出详细而全面（系统）的计划，评估某个领域的研究成果，包括判断并找出相关研究，以便消除评估过程中的认知偏差。
>
> — 《思维模型》, 第5章 > 能否重现

---

## I — 方法论骨架 (Interpretation)

系统综述是**按预先制定的详细计划，有组织地找出并评估某一领域的全部相关研究**，而不是挑几篇看。

它的核心设计意图是**消除评估过程中的认知偏差**。普通综述的致命问题是：作者（有意或无意）会先有结论再去挑文献，只引用支持自己的研究，漏掉反面的。系统综述用"事前制定检索与筛选方案"这个机制把这条路堵上——检索词、数据库、纳入排除标准都在看到结果之前就定死了，你不能再根据结论去调整样本。

作者给出的定位非常明确：**审视某个主张的有效性时，首先会看研究者有没有做全面的系统综述。** 它是评估证据的**首选入口**，而不是可选的加分项。在医学领域，系统综述（常配合荟萃分析）通常被决策者用于制定医疗指导原则。

关键机制有三条：

1. **全面性**：目标是"所有相关研究"，不是"我找得到的"。
2. **事前方案**：检索与筛选规则先定，避免事后调整。
3. **显性标准**：纳入/排除标准要写出来，让别人能复现你的筛选。

关键判据：**判断一份综述是否"系统"，就看它有没有公开检索策略与纳入排除标准。** 没有这两样，它就只是带引用的观点文章。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要判断某个方法/疗法/工具"到底有没有效"，而网上说法互相矛盾。
2. 要写文献综述、做技术选型调研、准备一份有说服力的论证材料。
3. 发现双方各自引用不同研究互相攻击，需要一个中立的裁决方法。
4. 需要评估某个领域的研究是否已经充分（能做决策了还是证据不足）。
5. 担心自己的调研只找到了支持预设结论的证据。

### 语言信号

- "这个说法到底有没有证据支持"
- "我想系统查一下这方面的研究"
- "两边各引一篇论文，我该信谁"
- "帮我做一份文献综述"
- "有没有人汇总过这些研究"
- "is there a systematic review on this / what does the evidence say"

### 与相邻 skill 的区分

- 与 `mm-meta-analysis` 的区别: 系统综述是**找全并评估研究**的流程，荟萃分析是**把多项研究的数据合并进一次统计分析**的技巧。系统综述可以不含荟萃分析（书中明示：有些但并非全部）。先有综述再谈合并。
- 与 `mm-publication-bias` 的区别: 发表偏倚是系统综述**无法完全克服的缺陷之一**（只能涵盖已发表结果）；系统综述是对抗认知偏差的手段，但对发表偏倚这道系统性缺口无力。
- 与 `mm-confirmation-bias` 的区别: 证实偏差是**产生**"只挑想看的文献"这个行为的心理机制；系统综述是**对抗**它的流程设计。

## E — 可执行步骤 (Execution)

1. **把问题写成可检索的明确问句**
   - 明确：对象（谁/什么）、干预或暴露（做了什么）、对照（跟什么比）、结局（看什么指标）。
   - 完成标准: 一句话问题，四个要素齐全。
2. **事前制定检索方案并冻结**
   - 写下：用哪些数据库/来源、哪些检索词、时间范围、语言范围。
   - 完成标准: 检索策略可被第三方复现。
   - 判停条件: 若领域极新、文献极少（不足 5 篇），系统综述的流程收益有限，改为叙述性综述并明确标注证据不足。
3. **按纳入/排除标准筛选，记录每一步的剔除数量**
   - 完成标准: 给出筛选漏斗（命中 → 去重 → 初筛 → 全文评估 → 最终纳入），每步有数量与剔除理由。
4. **评估纳入研究的质量与异质性**
   - 问：这些研究的设计是否可比？样本与测量差异大不大？
   - 完成标准: 对每项研究给出质量评级，并说明它们能否被放在一起看。
   - 判停条件: 若研究间异质性过大（设计或样本差异太大），不要强行合并，改为描述性综合。
5. **给出带确定性分级的结论**
   - 完成标准: 明确结论 + 证据强度分级（充分/有限/不足），并指出主要缺口（如可能存在的发表偏倚）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要快速判断、决策成本很低的场景：系统综述耗时很长，成本远超收益（推导，非书中明示）。
- 全新领域、几乎没有已有研究：无文献可系统检索，应先做探索性研究（推导，非书中明示）。

### 容易误用的地方

- 书中未提边界，但强调它用于"消除评估过程中的认知偏差"，暗示最大的误用是**把带引用的观点文章当成系统综述**——缺少事前检索方案与纳入标准就失去意义（推导，非书中明示）。
- （推导，非书中明示）容易以为"系统综述 = 结论可靠"。它消除的是筛选偏差，无法消除原始研究本身的缺陷，也受发表偏倚限制。
- （推导，非书中明示）容易忽略步骤 4 的异质性检查，把设计差异极大的研究硬放在一起得出结论。

### 容易混淆的邻近模型

- 荟萃分析（meta-analysis）：系统综述可能包含的统计合并步骤。
- 发表偏倚（publication-bias）：系统综述无法根除的系统性缺口。
