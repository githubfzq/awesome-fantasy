# 后见之明偏差（hindsight bias）

## R — 原文 (Reading)

> 另一个需要考虑的思维模型是后见之明偏差（hindsight bias），也就是当事件发生后，你在事后看来，会认为那件事原本是可以预测的，尽管并没有任何客观依据。
>
> — 《思维模型》, 第8章 > 释放潜能

---

## I — 方法论骨架 (Interpretation)

事件一旦发生，你就会觉得"它本来就是可以预测的"——尽管当时并没有任何客观依据支持这个预测。这就是后见之明偏差。

它的危害不在于让你自我感觉良好，而在于**让你从过去的事件中汲取错误的经验**：你会以为是自己决策错误导致了结果，而实际上按当时可得的信息，你的决策完全正确。把随机结果读成决策失误，会让你在下一次改掉一个本来正确的做法。

书中给出三种缓解手段：

1. **反事实思维（counterfactual thinking）**——迫使你考虑事件的其他可能展开方式，打破"只有这一个结局"的错觉。
2. **幸存者偏差检查**——看失败案例的共同点；成功案例很可能也具备同样的特征（只是它们没失败）。
3. **事件发生时做记录**——会议记录、备忘录、采访录音、执法记录仪。用当时的记录对抗事后的重构。

还有一个更关键的**问法转换**：不要问"这件事能不能预见"（非黑即白），而要问"我当时的风险评估有多准确、能否更准确"——把判断从二值变成连续值。

作者的提醒很要紧：**只有在结果确实无法预见时它才会对你造成影响**。许多失误本来就是可以预测的，与后见之明偏差无关——关键是区分二者。还要警惕自利性偏差：你倾向于说自己的失误无法预料，却拿后见之明偏差指责别人。

## A1 — 书中的应用 (Past Application)

### 案例: 2007—2008 年金融危机、2016 年美国大选与民事过失实验

- **问题**: 重大事件发生后，人人都能解释它为什么发生，但事前几乎没人预测到。
- **方法论的使用**: 2007—2008 年金融危机与 2016 年美国大选，事后电视分析家都能头头是道地解释原因，事前却没几人预测到。民事过失案的实验中，在过失行为完全一致的情况下，**结果越糟，受试者越认为过失方本该预见**——这说明"可预见性"的判断被结果严重污染了。
- **结论**: 结果是判断可预见性的污染源。同样的行为，只因后果不同，就会被事后赋予完全不同的"可预见性"评价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 事后复盘时说"我早该看出来"，并打算据此改掉某个做法。
2. 因为结果不好而追责，需要判断当时的决策是否真的错了。
3. 用户要为一次失败做总结，担心学到错误的教训。
4. 评价他人过去的决策（上级、同事、历史上的决策者）。

### 语言信号 (用户的话里出现这些就应激活)

- "我早就知道会这样"
- "当时就该看出来的"
- "结果这么差，说明决策就是错的"
- "明明信号那么明显"
- "复盘一下我们到底错在哪"
- "I should have seen this coming / hindsight is 20/20"

### 与相邻 skill 的区分

- 与 `mm-self-serving-bias` 的区别: 两者会叠加并被选择性使用——你是用自己的失误"无法预料"来开脱，却用后见之明去指责别人；识别这种双重标准正是本模型的边界提示。
- 与 `mm-survivorship-bias` 的区别: 幸存者偏差是"只看成功样本得出结论"；在本模型中它是**三种缓解手段之一**——用来检查"失败案例的共同点，成功案例是不是也有"。
- 与 `mm-counterfactual-thinking` 的区别: 反事实思维是通用思考工具；本模型把它用作对抗后见之明的特定手段之一。
- 与 `mm-postmortem` 的区别: 事后分析是复盘流程；本模型是复盘时必须先排除的一个认知污染。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分离"决策质量"与"结果好坏"**
   - 完成标准: 明确写出当时的决策，以及做决策时可获得的信息清单——先不看结果。
2. **检查是否存在当时记录**
   - 完成标准: 找到会议记录、备忘录、邮件等当时的材料；若没有，如实标注"只能靠回忆，可靠性低"，并建议未来建立记录机制。
   - 判停条件: 若记录明确显示当时已有人指出该风险却被忽略，则**不是**后见之明偏差，应转为真正的决策失误复盘。
3. **做反事实推演**
   - 完成标准: 写出 2-3 种同样可能发生的其他结局，并说明它们在当时各自的概率。
4. **做幸存者偏差检查**
   - 完成标准: 列出失败案例的"共同特征"，并检查成功案例是否也具备同样特征——若是，则该特征没有解释力。
5. **改用连续问法**
   - 完成标准: 把"能不能预见"改写为"我当时的风险评估有多准确、能否更准确"，并给出下次可改进的具体动作（如记录预测与置信度）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 结果确实可预见、且当时已有明确预警——这是真失误，用后见之明偏差开脱会阻止真正的改进。
- 事前预测任务本身（需要用基础比率、情景分析等工具）。
- 需要追责的法律/合规场景，判断依据是当时的事实与规则，不是认知偏差科普。

### 书中警告的失败模式 / 容易误用的地方

- **只有在结果确实无法预见时它才会对你造成影响**——许多本可预测的失误与它无关，关键是区分二者。这是书中最重要的限定。
- 要警惕**自利性偏差**：你倾向说自己的失误无法预料，却拿后见之明偏差指责别人——双重标准会让这个模型变成免责工具。
- （推导, 非书中明示）把"结果不好"自动等同于"决策错了"仍是这个偏差最常见的表现，即使知道这个模型也会犯。

### 容易混淆的邻近模型

- **幸存者偏差（survivorship bias）**: 本模型的缓解手段之一，不是同层级概念。
- **自利性偏差（self-serving bias）**: 常与本模型叠加形成双重标准。
