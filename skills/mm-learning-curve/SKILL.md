# 学习曲线（learning curve）

## R — 原文 (Reading)

> 学习曲线（learning curve）的迅速上升会让你对自己的能力充满信心。但你可能会骗过自己，误认为这项技能很简单。事实上，你并没有完全掌握这项技能的所有相关知识，也不了解怎么才能做得更好。
>
> — 《思维模型》, 第8章 > 释放潜能

---

## I — 方法论骨架 (Interpretation)

学习曲线描述技能水平随练习与经验积累而提升的轨迹：**初期上升最快，越往后越平缓**。起步阶段投入一点时间就能看到明显进步，后期每一点提升都需要成倍投入。

它的心理效应比形状本身更重要。曲线初期的迅速上升会让人**高估自己**——你确实进步了，但你误以为"这项技能很简单"，因为你还不知道自己不知道什么。随着深入，你开始意识到成为专家还需付出多少努力，信心会骤减。这就是很多人学了三周觉得自己快出师、学了三个月想放弃的原因。

对教练和管理者，这条曲线给出了一条明确的判据：**先判断团队成员处于学习曲线的哪个位置，再决定该做什么**——处在初期陡坡上的人要"压一压"（防止过度自信冒进），处在后期平缓段、信心骤减的人要"加一把鼓励"（防止在临近突破处放弃）。用反了都会出事。

关键判据：**进步速度的边际变化**。如果最近同样投入的产出明显减少，说明已经在平缓段，这是正常的而不是退步。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新人/新手刚上手几天就表现得很自信，用户担心他低估了难度、会在复杂场景上翻车。
2. 某人学到中途信心骤减、进步停滞、想放弃，用户在纠结是安慰还是加码。
3. 作为教练/管理者，要决定对不同的成员采取"压一压"还是"推一把"。
4. 估算某项技能从零到可用需要多久、什么时候会进入平台期。

### 语言信号

- "他刚学两周就说自己会了"
- "越学越觉得自己什么都不懂"
- "是不是我到瓶颈了"
- "前几周进步特别快，现在怎么练都没变化"
- "这个好像也没那么难嘛"
- "I feel like I've plateaued" / "it seemed easy at first, now I'm stuck"

### 与相邻 skill 的区分

- 与 `mm-dunning-kruger-effect` 的区别: 邓宁-克鲁格效应描述**能力低者高估自己**这一认知偏差（含"愚昧山峰"与"绝望之谷"）；学习曲线描述**客观进步速度的形状**。二者解释的是同一个现象的两端：曲线的陡坡制造了高估，而高估的程度由邓宁-克鲁格刻画。定位阶段用曲线，解释误判用邓宁-克鲁格。
- 与 `mm-10000-hour-rule` 的区别: 一万小时给出达到顶尖的**总量级**，学习曲线给出**进步的速率变化**（前快后慢）。前者回答"总共多远"，后者回答"现在跑得有多快"。
- 与 `mm-spacing-effect` 的区别: 间隔效应是**训练编排方法**（分散、轮流练），学习曲线是**进度诊断工具**；诊断出处于平缓段后，可配合间隔效应与刻意练习调整打法。

---

## E — 可执行步骤 (Execution)

1. **定位当前处于哪一段**
   - 完成标准: 用"最近单位投入的产出变化"判断——产出仍快速上升为陡坡段；产出明显放缓为平缓段。给出判断依据而非印象。
2. **陡坡段：压一压，补足认知缺口**
   - 完成标准: 指出对方尚未接触的具体复杂场景（他还没遇到过的难例），并安排一个他当前水平之上的真实任务来校准自我评估。
   - 判停条件: 若对方已表现出谨慎，跳过此步。
3. **平缓段：加鼓励 + 明示这是正常阶段**
   - 完成标准: 明确告知"进步变慢是曲线形状决定的，不是你退步"，并给出他已经跨过的具体里程碑作为证据。
4. **平缓段：改打法而非加时长**
   - 完成标准: 输出一项具体调整——引入教练/反馈、转为针对弱点的刻意练习、或用间隔效应重排节奏；单纯增加时长在平缓段收益最低。
5. **设定阶段性里程碑**
   - 完成标准: 给出下一个可达成的具体水平描述与预计时间，让平缓期的进步可被看见。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要估算总体训练量——用 `mm-10000-hour-rule`。
- 需要安排复习与训练节奏——用 `mm-spacing-effect`。
- 停滞的真实原因是训练方法错误（一直在重复已会的）——先改方法，曲线诊断解释不了方法问题。

### 容易误用的地方

- （推导, 非书中明示）书中未提局限。由机制可推导：曲线形状因领域而异，并非所有技能都是"先快后慢"——有些技能在突破某个关键概念后会突然跃升（阶梯状），把它一律套成平滑曲线会误判"到顶了"。
- （推导, 非书中明示）用"这是平缓期"来安慰真正的退步是危险的。诊断前必须先确认进步确实只是变慢而非停滞或倒退。
- （推导, 非书中明示）"压一压"不等于打击。目的是校准自我评估（让他看到没见过的复杂度），不是贬低。

### 容易混淆的邻近模型

- **邓宁-克鲁格效应（dunning-kruger-effect）**: 解释为什么陡坡上的人会高估自己；本 skill 解释曲线形状本身。
- **一万小时定律（10000-hour-rule）**: 总量级，本 skill 是速率变化。
