# 对立假设（alternative hypothesis）

## R — 原文 (Reading)

> 开发人员还需要明确指定一个对立假设（alternative hypothesis），也就是他们认为两组之间可能出现的最细微的有意义改变
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

对立假设是研究者认为**两组之间可能出现的最细微的、有意义的改变**——也就是你希望被研究证实的那个真实结果。它是原假设（"没差别"）的对立面。

注意定义里的两个限定词，缺一不可：

- **最细微的**：不是"我期待的大提升"，而是"小到这个程度以下我就不在乎了"。
- **有意义的**：这个程度的差异足以让你改变行动。

合起来就是**"有意义的最小差异"**（minimum meaningful effect）。这个设定之所以重要，是因为它同时是**样本量计算的输入**：设定的差异越小，需要的样本量越大（大致平方反比）。

书中的助眠应用案例给出了完整演算：

- 对立假设 = "10 分钟内入睡的人增加 15%" → 需要 **268 人**
- 若改成 "增加 30%" → 只需 **62 人**

看起来是省了 206 人，但作者明确指出代价：**若真实差异只有 15%，用 62 人的方案只有 32% 的概率能检出，即约 2/3 的概率得到假阴性。**

所以对立假设不是一个"填给统计软件看"的技术字段，它是一个**诚实性检验**：你是在问"真实世界到底有没有效果"，还是在问"我能不能用最便宜的方式拿到一个显著结果"。

关键判据：**对立假设应该由"多小的差异值得我改变行动"决定，而不是由"我付得起多少样本"决定。** 顺序反了，实验就变成了自我欺骗。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写实验方案/研究计划，需要把"我们预期提升多少"变成一个可检验的假设。
2. 评审别人的实验设计时，检查对立假设设得合不合理。
3. 有人为了省样本/省时间，提议把预期效果设大一些。
4. 实验结论是"没显著差异"，需要回溯当初的对立假设是否设得过大或过小。
5. 讨论"这个提升虽然显著，但值不值得上线"（效果量与意义的判断）。

### 语言信号

- "我们预期能提升多少"
- "提升 5% 算成功吗"
- "把目标定高一点，样本就不用那么多了"
- "这个实验的假设怎么写"
- "效果显著但实际没意义"
- "minimum detectable effect / effect size / what lift do we expect"

### 与相邻 skill 的区分

- 与 `mm-null-hypothesis` 的区别: 原假设是"没有差异/没有效果"的默认立场，对立假设是你想证实的那个具体差异。两者是一组配对设定；原假设提供被否定的靶子，对立假设提供"多小算有意义"的尺度。
- 与 `mm-sample-size` 的区别: 对立假设是样本量计算的**输入**，样本量是**输出**。想通过改输入来省样本，正是书中警告的做法；若纠结成本取舍本身，用样本量权衡。
- 与 `mm-statistical-significance` 的区别: 统计显著性判定"差异是否大到能否定原假设"，对立假设规定"多小的差异我还在乎"。显著但不有意义，就是这两个尺度脱节的结果。

## E — 可执行步骤 (Execution)

1. **先问业务：多小的差异会让你改变行动？**
   - 问：如果提升只有 X%，你还会上线/推广/投入吗？找到那个"从不在乎到在乎"的临界点。
   - 完成标准: 得到一个具体的、带单位的差异值（如"10 分钟内入睡的人增加 15%"）。
2. **把它写成对立假设**
   - 明确：比较的是哪两组、度量的是哪个指标、差异方向与幅度。
   - 完成标准: 一句话表述，第三方读后能复现这个实验的判定标准。
3. **核算这个假设对应的样本量**
   - 用对立假设 + α + 功效算出所需样本量。
   - 完成标准: 得到样本量数字。
   - 判停条件: 若样本量远超预算，**不要**把对立假设调大——回到步骤 1 重新确认"有意义的最小差异"是否定得过小，或考虑延长周期、改用方差更小的指标。
4. **记录调大假设的代价（若仍要调）**
   - 明确写出：若真实差异是原定的 X，用当前的样本量只有多大概率能检出（书中：15% 差异 + 62 人 = 32% 检出率，约 2/3 假阴性）。
   - 完成标准: 用户是在知情的前提下接受漏检风险，而不是被"样本够用了"蒙蔽。
5. **实验前冻结，并记录理由**
   - 完成标准: 对立假设、α、功效、样本量一起被记录，事后不得修改。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 纯探索性研究（不知道会看到什么、没有预设方向）：此时强行写对立假设会限制发现，应改用描述性分析与假设生成（推导，非书中明示）。
- 不涉及组间比较的单组描述或预测任务：没有"两组差异"就没有对立假设（推导，非书中明示）。

### 容易误用的地方

- 书中明示的警告：**为省时省钱而把对立假设调大（如从 15% 调到 30%），会使所需样本量骤降到 62 人，但真实差异只有 15% 时漏检率高达 2/3。**
- （推导，非书中明示）容易把"我期待的效果"当成"有意义的最小差异"。前者通常偏乐观且偏大，会让实验在真实但较小的效果面前失明。
- （推导，非书中明示）容易事后根据观测到的结果反向设定对立假设，让"没效果"变成"效果显著"。必须在看数据前冻结（步骤 5）。

### 容易混淆的邻近模型

- 原假设（null-hypothesis）：与之配对的默认立场，是被否定的对象。
- 统计功效（power）：在给定对立假设与样本量下，能检出该差异的概率。对立假设定得越小，同样样本下的功效越低。
