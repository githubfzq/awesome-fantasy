# 核选项（nuclear option）

## R — 原文 (Reading)

> 最严重的威胁是所谓的核选项（nuclear option，又译"玉石俱焚选项"），表示你将被迫采取某种极端行为。
>
> — 《思维模型》, 第7章 > 改变战局

---

## I — 方法论骨架 (Interpretation)

核选项是威胁光谱上最末端的一档。普通威胁是"你越线，我惩罚你"；核选项是"你越线，我采取一个**连我自己也会被炸到**的极端行为"。

它的悖论在于：**自伤恰恰是它的效力来源**。一个理性人宣布"我要做一件对我自己也没好处的事"，通常不可信——但正因如此，一旦对方相信你被逼到真会这么做，这个威胁的可信度反而极高，因为它绕开了"他只是在吓我"的怀疑。作者强调的是"被迫"：你不是想这么做，而是被逼到只能这么做。

关键判据有两条：

1. **对方是否相信你会真的执行？** 自伤提升了可信度，但也意味着一旦执行你真的会受伤，所以必须有"我已无路可退"的客观情境支撑，否则就是空话。
2. **代价是否值得？** 核选项改变的是对方收益矩阵，但它同时把你自己的收益也拉到负值。它只在"不这么做损失更大"时才划算。

因此它的正确定位是：**威慑用的最后一张牌，而不是谈判中的加码手段。** 一旦亮出，双方都失去退路。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户被逼到墙角，准备"大不了辞职并把内情公开 / 鱼死网破打官司"，想评估后果。
2. 谈判中对方认为你不敢撕破脸，用户在考虑要不要放一个自伤式狠话逼对方让步。
3. 用户说"我已经不在乎了，我要让他也付出代价"——需要区分这是策略还是情绪。
4. 有人在威胁用户用核选项，用户需要判断对方是真敢还是虚张声势。
5. 用户在写离职谈判、违约纠纷、合作破裂的应对脚本，需要明确最坏手段的边界。

### 语言信号 (用户的话里出现这些就应激活)

- "大不了都别好过"
- "我就把这事捅出去，大家一块完"
- "他欺负到我头上了，我要鱼死网破"
- "我已经无所谓了，我要拉他一起下水"
- "要不要直接掀桌子"
- "I'll burn it all down / we all go down together"
- "nuclear option / scorched earth"

### 与相邻 skill 的区分

- 与 `mm-red-line` 的区别: 红线的后果是"我惩罚你"，执行成本对你可控；核选项的后果是"我也一起受损"，靠自伤换可信度。用户描述的后果若**同时伤己**，就是核选项。
- 与 `mm-mutually-assured-destruction` 的区别: 相互确保毁灭（MAD）是**双方**都握有核选项的对称结构，分析的是"谁都不敢先动"的僵局；核选项是**单方**的极端威胁。用户说"他也能毁了我"时，是 MAD。
- 与 `mm-zero-tolerance-policy` 的区别: 零容忍是制度化、预告过的固定重罚，执行时对执行方伤害有限；核选项是一次性、自伤式的极端行为。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别威胁的自伤成分**
   - 完成标准: 明确写出用户打算做的事，并列出这项行为对用户自己的具体损失（钱、声誉、关系、法律、时间）。若自伤成分为零，说明这只是普通重罚，不是核选项，交回 `mm-red-line` 处理。
2. **做可信度检验**
   - 完成标准: 回答"有没有客观情境让对方相信我已被逼到只能这么做？"——有（如已无退路、已备好替代收入、证据已在第三方手中）则可信；无则判定为虚张声势，跳到步骤 5。
3. **算净收益，而不是只算对方损失**
   - 完成标准: 列出三条：动用后我方的净收益、不动用（接受对方条件）的净收益、升级失败（对方不买账、你真的执行）的净收益。只有当第三条仍优于第二条时，核选项才成立。
4. **寻找同效替代**
   - 完成标准: 至少给出 2 个能达到"改变对方收益矩阵"但自伤更小的方案（如引入第三方仲裁、公开预告而非实际公开、设定分阶段后果）。
   - 判停条件: 若确有同效且自伤更小的方案，则不使用核选项，改用该方案。
5. **若仍要动用，先降级为可撤回的预告**
   - 完成标准: 把威胁表述为"如果 X 发生，我将被迫做 Y"的分阶段预告，而非立即执行，给对方留出退让台阶。
6. **明确事后路径**
   - 完成标准: 写下一句"执行之后我靠什么恢复"，并确认用户已接受最坏结果。没有恢复路径就说明这一步不该走。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 冲突仍在常规谈判区间内、还有可接受的常规选项——此时动用核选项是把可控损失换成不可控损失。
- 双方关系需要长期维持（亲属、长期合伙、同一行业内抬头不见低头见）。
- 用户处于强烈情绪中、刚说完"我不在乎了"——此时先做情绪降温，不协助设计极端动作。
- 所谓"核选项"涉及违法、人身威胁、泄露他人隐私或造谣——一律拒绝协助，改走合法途径。

### 容易误用的地方

- 书中明示：核选项与"焦土战术""相互确保毁灭"同属极端手段——作者把它们放在"极端"而非"推荐"的位置。
- （推导, 非书中明示）最大的误用是**把核选项当加码筹码反复使用**。核选项的价值来自"仅此一次、真的会做"，一旦被当成常规施压话术，可信度立刻归零。
- （推导, 非书中明示）自伤并不自动等于可信。若对方判断你承受不起，自伤式威胁反而暴露你的绝望，让他更敢压你。

### 容易混淆的邻近模型

- **焦土战术（scorched earth）**: 撤退时销毁资源让谁都别想用，是**执行**而非**威胁**，且通常发生在退出阶段。
- **破釜沉舟（burn the boats）**: 自绝退路以激励自己团队，是自己对自己用；核选项是对对手用。
