# 无知之幕（veil of ignorance）

## R — 原文 (Reading)

> 它指出，在思考社会的组织方式时，我们应该想象对自己在世间的特殊地位一无所知，仿佛有一层幕布让我们看不见自己是谁，也就是处于罗尔斯所说的"原初状态"（original position）。
>
> — 《思维模型》, 第1章 少犯错 > 换位思考

---

## I — 方法论骨架 (Interpretation)

罗尔斯的操作是这样的：在设计规则之前，先假设你不知道自己将在其中处于什么位置——不知道自己的性别、种族、家庭出身、健康状况、天赋、财富、职位。这层"幕布"的作用是**强制移除自利偏差**。

为什么有效？因为人设计规则时，几乎总是不自觉地把自己的处境当成默认处境。一个通勤 20 分钟的管理者制定考勤制度，会真心认为"弹性已经很大了"；但他不是在制定规则，他是在把自己的便利写进规则。幕布一旦落下，你无法再假设"我肯定不是那个要照顾失能老人的员工"，于是**必须为最差的位置也留出余地**——不是出于善意，而是出于自利的理性：你有可能是那个人。

这带来一个关键性质：幕布下做出的判断，会系统性地关注**最弱势位置的处境**，而不是平均处境。因为优化平均值的规则在幕布下是危险的——平均值里没有你的保证。

书中把它从政治哲学搬到了组织决策里：管理者在取消远程办公、改动排班、调整考核之前，想象自己可能是任意一名员工，就能看见政策对具体处境者的冲击。

关键判据（一问）：**如果我有可能是受这个决定影响最大的那个人，我还会这么定吗？**

一个重要的补充（书中明示）：**即使全面考虑后仍可能批准该政策**。无知之幕的价值不在于一定推翻决定，而在于让你理解代价、并激发新的替代方案。

---

## A1 — 书中的应用 (Past Application)

### 案例: 奴隶制、难民政策与取消远程办公
- **问题**: 作者要说明无知之幕如何改变道德判断，以及它不只适用于国家层面的制度。
- **方法论的使用**: 三个场景的对照。思考奴隶制时，要设想自己可能生来为奴；思考难民政策时，要设想自己可能就是那个寻求庇护者；而在一个组织里，取消远程办公政策之前，要设想自己是那个需要照顾老人的员工、或是那位单身母亲——规则在这些具体处境下的重量，与在管理者的处境下完全不同。
- **结论**: 幕布的作用是让你无法把自己的处境当成默认处境。它常常不能直接给出"正确答案"，但能暴露出那些被"我反正不会是那个人"掩盖的代价，并促使你设计出兼顾的方案（比如保留远程但设核心协作时段），而不是在"全面取消"与"完全不管"之间二选一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **制定面向多人的规则/制度**: 考勤与远程政策、绩效考核方式、晋升标准、报销规则、裁员方案、排班制度、座位与资源分配。
2. **设计产品规则或算法规则**: 平台的处罚规则、推荐机制、定价分层、准入条件——规则一旦上线，会落到处境各异的用户身上。
3. **分配稀缺资源**: 预算切分、名额分配、奖金分配、危机时期的资源倾斜。
4. **评价一项政策/规定是否合理**: 用户要判断某个外部规定或他人的做法是否公平。
5. **团队意见分裂且各方都从自身处境出发**: 需要把各自的特殊处境显性化，再找一个不依赖具体处境的判断基准。

### 语言信号 (用户的话里出现这些就应激活)

- "这样定公平吗"
- "会不会有人被误伤"
- "少数人的情况怎么办"
- "如果我是他，我能接受吗"
- "这个规则一旦执行，最惨的是谁"
- "我们要不要一刀切"
- "Is this fair?" / "What if I were the one affected most?" / "veil of ignorance"

### 与相邻 skill 的区分

- 与 `mm-utilitarianism` 的区别: 功利主义优化的是**总量/平均值**（最大多数人的最大幸福），允许少数人承受巨大代价；无知之幕关注的是**最差位置的处境**，不允许用平均值的改善来抵消某个位置上的不可接受。两者常常给出相反答案。
- 与 `mm-fundamental-attribution-error` 的区别: 基本归因错误是把他人的处境问题**归因于其品性**（他迟到是因为他不靠谱）；无知之幕是**规则设计层面**的换位，要求在定规则前先不确定自己的位置。一个是对他人的归因偏差，一个是自身的立法偏差。
- 与 `mm-most-respectful-interpretation` 的区别: 最善意的解释是对**某个人的动机**给最善意的解读，用于人际冲突；无知之幕是对**规则的位置不确定性**做思考，用于制度设计。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认这是规则/制度/分配问题，而非私人偏好问题**
   - 完成标准: 明确写出这条规则会影响哪些人、影响多久、是否可申诉。
   - 判停条件: 若只影响用户自己或已明确征得每一位受影响者同意，本 skill 不适用，停止。
2. **列出所有可能被影响的位置（角色清单）**
   - 完成标准: 列出 5-8 种具体处境，必须**包含处境最不利的那一类**（兼职者、需照护者、新人、边缘地区用户、无议价能力者），不能只列主流情形。
3. **拉下幕布：逐个位置代入，写出该处境下的真实体验**
   - 完成标准: 对每个位置写出"这条规则落在我身上，我的实际处境会变成什么样"——要具体到时间、金钱、机会成本、心理负担，不能停留在"会有点不方便"。
4. **对最弱势位置做"可接受性测试"**
   - 完成标准: 明确回答关键判据："如果我有可能是受这个决定影响最大的那个人，我还会这么定吗？"给出是/否及理由。
   - 判停条件: 若答案为"否"但出于效率/成本仍要推进，进入第 5 步，不得跳过。
5. **（若不可接受）设计兼顾的替代方案，而不是在极端间二选一**
   - 完成标准: 给出至少 2 个既保留原目标又为弱势位置留出余地的方案（豁免条款、过渡期、默认例外、可申请机制、分档执行）。
   - 判停条件: 若确实无法兼顾，明确写出"这条规则的代价由谁承担、承担多少"，把代价显式化，而不是让它隐身在平均值里。
6. **明确说明：幕布不必然推翻决定**
   - 完成标准: 输出中写明——即使全面考虑后仍可能批准该政策；本 skill 的价值在于理解代价并激发新方案，而不是给出一个简单的否决议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯私人选择与偏好问题**: 我今晚吃什么、我喜欢哪种风格——不涉及对不同处境的人分配规则，幕布无从落下。
- **受影响者已经充分参与决策时**: 若规则是由所有受影响者共同商定的（真实的协商而非形式征求意见），位置不确定性已经被真实的多元视角替代，幕布是多余的。
- **紧急情况下的快速处置**（推导, 非书中明示）: 危机处置需要速度，完整的幕布推演来不及；但事后复盘时应当补做。

### 书中警告的失败模式 / 容易误用的地方

- **书中未给明确边界，但指出：即使全面考虑后仍可能批准该政策，无知之幕的价值在于理解代价并激发新方案**（`boundary` 字段原文）。因此把它当成"一票否决器"是误用——它不负责拍板，只负责让代价可见。
- （推导, 非书中明示）**假代入**: 表面上想了"如果我是他"，实际仍然假设自己拥有现有资源与支持系统（"我如果是他，大不了换份工作"）。代入必须带上那个位置的真实约束，而不是把自己的能力搬过去。
- （推导, 非书中明示）**只代入平均处境**: 最常见的退化是代入"一个普通员工"，而不是"最不利的那一个"。幕布的力量恰恰在于你**有可能**是那一个，因此必须测最差点，不是测中点。
- （推导, 非书中明示）**用幕布代替真实征求意见**: 想象他人处境不能替代直接询问。能问到真实的人时，去问。

### 容易混淆的邻近模型

- **功利主义（utilitarianism）**: 优化总量，允许牺牲少数；本模型关注最差位置。二者在分配问题上经常冲突。
- **同理心（empathy）**: 是感受他人情绪的能力；无知之幕是一个**制度设计程序**——它不要求你共情，只要求你在不确定自己位置时做出选择。
