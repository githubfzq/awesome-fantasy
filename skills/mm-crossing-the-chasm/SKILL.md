# 跨越鸿沟（crossing the chasm）

## R — 原文 (Reading)

> 商业策划师杰弗里·摩尔在同名著作中将这一变化命名为“跨越鸿沟”（crossing the chasm）。这里的“鸿沟”指的是许多创意、企业和技术都无法实现跨越这一事实。
>
> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

**跨越鸿沟（crossing the chasm）** 由杰弗里·摩尔提出：创意与技术常常卡在**早期采纳者与早期大多数之间的鸿沟**里，无法进入主流。

**为什么存在这道鸿沟**：这两类人的期待完全不同。

- **早期采纳者**：要么爱玩新玩意，要么有某种特殊需求，愿意忍受不成熟、自己动手补全。
- **早期大多数**：要求产品解决**持续存在的真实需求**，要成熟、可靠、有配套、有参照。

这两者之间不是量的差别，是**质的断裂**。让早期采纳者兴奋的东西（新颖、可折腾、前沿），往往正是让早期大多数却步的东西（不稳定、没保障、没人用过）。所以讨好前者的打法，到了后者那里完全失效——这就是鸿沟。

**为什么关键**：许多创意、企业和技术都**无法实现跨越**这一事实，就是这道鸿沟的定义。绝大多数技术停在创新者与早期采纳者阶段，从未进入早期大多数视野。

**怎么用（本 skill 最有价值的地方）**：**若判断某竞争对手很可能跨越鸿沟，就应提高警惕——这标志着采纳速度加快的转折点。** 换句话说，鸿沟是一个**预警指标**：在它之前，威胁还远；在它之后，威胁会以完全不同的速度扑过来。书中用它来判断数码摄影、人工智能这类威胁**何时会真正成势**。

**关键判据**：看用户构成与他们的购买理由。如果购买理由仍是"新"、"酷"、"技术领先"——还在鸿沟左边；如果变成"它能稳定解决我一直在头疼的问题"、"同行都在用"——正在或已经跨越。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一项新技术很火，需要判断它会不会真的成势、什么时候该认真对待。
2. 自己的产品用户增长停滞，怀疑卡在早期采纳者这一层。
3. 竞争对手在小众圈子里很受欢迎，需要判断它会不会杀进主流。
4. 要决定是否为某个"未来方向"投入资源，还是再等等。
5. 团队在用"很多人在讨论"来论证市场已经成熟。
6. 内部在争论要不要为某个遥远威胁做防御投入。

### 语言信号

- "这个到底成势了没有"
- "现在还只是极客在玩吧"
- "它会不会进入主流"
- "什么时候该认真对待这个威胁"
- "我们的用户增长卡住了,是不是到天花板了"
- "很多人都在讨论,是不是时机到了"
- "crossing the chasm / early adopters / early majority / Geoffrey Moore / mainstream adoption / is it real yet"

### 与相邻 skill 的区分

- 与 `mm-technology-adoption-life-cycle` 的区别: 采纳生命周期是**完整曲线**（创新者→早期采纳者→早期大多数→后期大多数→落后者）；鸿沟是这条曲线上**一个具体的断裂点**。要看整体结构用生命周期，要判断"卡没卡在这一关"用本 skill。
- 与 `mm-tipping-point` 的区别: 临界点是**通用阈值概念**（越过之后变化自我加速）；鸿沟特指**早期采纳者到早期大多数之间**这一处，且给出了具体成因（两类用户期待的质的断裂）。通用阈值用临界点，这一处特定的断裂用本 skill。
- 与 `mm-only-the-paranoid-survive` 的区别: 偏执狂是**整体的防御姿态与资源分配原则**（要对哪些微弱威胁投入）；本 skill 是**给单个威胁定位的工具**——它正处在曲线的哪一段。书中的用法是：用鸿沟判断"哪个威胁值得偏执"，再用偏执狂决定怎么投。
- 与 `mm-disruptive-innovations` 的区别: 颠覆性创新描述**颠覆从低端/边缘切入再上行的路径**；本 skill 判断**一项技术能否从尝鲜者扩到主流人群**。一个讲切入位置，一个讲人群扩散。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **在采纳曲线上定位它现在在哪一段**
   - 完成标准: 明确判定处于创新者 / 早期采纳者 / 鸿沟中 / 早期大多数 / 后期大多数，并写明判断依据（不只是"感觉"）。
2. **检查用户构成，而不只看总量**
   - 完成标准: 给出当前用户里早期采纳者与早期大多数的大致占比。总量增长但构成不变，说明还在鸿沟左边原地膨胀。
3. **检查购买理由是否发生了质的变化**
   - 完成标准: 明确当前主流购买/使用理由是"新颖、可折腾、技术领先"（左侧）还是"稳定解决持续存在的真实需求、有配套与参照"（右侧）。这是跨越与否最硬的判据。
4. **判断跨越的先行信号**
   - 完成标准: 列出 2-3 个可观测的跨越信号——成熟配套出现、非技术型买家开始采购、同行开始把它写进标准流程、采购决策从个人变为组织。
   - 判停条件: 若这些信号一个都没出现，明确告知"还在鸿沟左边"，不要因为热度而改变结论。
5. **落到时机决策**
   - 完成标准: 给出明确结论——**继续观察**（左侧，设触发条件与复查点）、**加速投入**（正在跨越，这是采纳速度加快的转折点，应提高警惕）、或**放弃/转向**（长期卡在左侧且无跨越迹象）。作为威胁评估用时，明确指出：跨越鸿沟标志着采纳速度加快的转折点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 只需要判断一个通用阈值是否越过（如用户数、盈亏平衡点）——用临界点。
- 已经在分配防御资源、需要整体姿态——用只有偏执狂才能生存。
- 产品已被主流大规模采用——鸿沟早已跨越，模型无信息量。
- 一次性/无扩散属性的事物（内部工具、单客户服务）——不存在采纳曲线。

### 容易误用的地方

- **书中明示**: **许多技术或创意只吸引创新者与早期采纳者，实际上很少能跃入早期大多数视野，因此不必对每个新威胁过度反应。** 这是本 skill 最重要的克制——它的主要用途往往是**否定**，即证明某个威胁还不值得投入。
- （推导, 非书中明示）把热度当成跨越。"很多人在讨论"通常只说明早期采纳者很兴奋，恰恰是鸿沟左边的特征；真正的信号是购买理由的质变与组织化采购的出现。
- （推导, 非书中明示）用讨好早期采纳者的打法去打早期大多数。这是掉进鸿沟的直接原因——新颖、可折腾、技术领先这套，对要求稳定与配套的早期大多数是负资产。
- （推导, 非书中明示）只看总量不看构成。用户数翻倍但全是同一类人，说明还在左边原地膨胀，不是跨越。
