# 先发优势与先发劣势（first-mover advantage / first-mover disadvantage）

## R — 原文 (Reading)

> 第一个试图靠"秘密"获利的个人或组织确实拥有先发优势（first-mover advantage），能够发挥率先将产品投入市场的竞争优势。但如果他们犯下了很多错误，也会表现为先发劣势（first-mover disadvantage）。
>
> — 《思维模型》, 第9章 > 缺少执行的愿景不过是幻想

---

## I — 方法论骨架 (Interpretation)

率先把产品推向市场可以带来竞争优势，这就是**先发优势**。但它有对称的一面：**如果先行者犯下过多错误，就会表现为先发劣势**——后来者反而占便宜。

**为什么成立**：先行者承担两类成本——**教育市场的成本**与**试错的成本**。这两类成本都由先行者支付，收益却被整个行业共享。跟随者因此可以**复制其做法并规避其踩过的坑**，用更低的成本走到同样甚至更远的位置，从而后来居上。

**关键判据（书中最重要的一句）**：**抢先进入市场并非关键，真正的胜负手是率先实现产品/市场匹配。**

这句话把问题彻底重构了：

- 抢先发布是一个**时间**指标，产品/市场匹配是一个**质量**指标。
- 只追求前者而没达到后者，恰好就是先发劣势的产生机制——你把错误公开地犯了一遍，还替别人付了学费。
- 反过来，晚一点进场但率先做到匹配，才是真正的赢面。

因此实用的判断不是"我们是不是第一个"，而是"我们每多花一周，是在靠近匹配，还是在靠近发布时间表"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 竞品即将发布，团队考虑砍掉测试提前上线抢先机。
2. 手上产品还不够好，但市场窗口看起来正在关闭。
3. 作为先行者已被后来者反超，需要复盘原因。
4. 作为后来者，在评估跟随策略——抄什么、避什么。
5. 内部在争论"先做规模还是先做口碑"。
6. 评估一个已被多家做过的方向还有没有机会进入。

### 语言信号 (用户的话里出现这些就应激活)

- "再不上就被别人占了"
- "先发出来再说，后面再改"
- "我们是第一个做的，怎么被超越了"
- "要不要等竞品先试错"
- "教育市场的成本太高了"
- "快速跟随策略可行吗"
- "first-mover advantage / should we ship early / they beat us to market / fast follower"

### 与相邻 skill 的区分

- 与 `mm-simultaneous-invention` 的区别: 同步发明解释**为什么会同时有多个人在做同一件事**（条件成熟、窗口同时打开）；本 skill 处理**既然如此，抢先有没有用**。前者是现象解释，后者是策略选择。
- 与 `mm-why-now` 的区别: 为什么是现在判断**时机是否成熟**（该不该现在做）；本 skill 判断**成熟之后要不要抢第一个**。时机未成熟就抢先，正是先发劣势的典型来源。
- 与 `mm-product`（产品/市场匹配）的区别: 产品/市场匹配是**目标状态**；本 skill 明确指出它才是真正的胜负手，抢先只是手段之一。要诊断匹配程度用 product，要决定抢先与否用本 skill。
- 与 `mm-beachhead` 的区别: 滩头堡讲的是**从细分市场切入再扩张**的路径选择；本 skill 讲的是**进入时序**的取舍。一个是空间策略，一个是时间策略。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先问清楚"抢先"要付出什么代价**
   - 完成标准: 明确列出为抢先而将被砍掉/压缩的东西（测试范围、核心功能、质量门槛），以及这些会带来的具体风险。
   - 判停条件: 若抢先无需任何实质妥协，直接执行，不必纠结。
2. **用"产品/市场匹配"取代"发布时间"作为决策指标**
   - 完成标准: 明确评估当前离产品/市场匹配有多远，并给出判据（用户是否主动推荐、留存是否达标、是否有自然增长）。若尚未匹配，明确指出：抢先发布等于把错误公开犯一遍并替跟随者付学费。
3. **列出先行者要承担的两类成本**
   - 完成标准: 分别估出教育市场成本（客户还不知道这类产品存在/为什么需要）与试错成本（方向、定价、渠道都未知）。若这两项很高，后来者的位置反而更有利。
4. **给出跟随者的具体动作或先行者的加固动作**
   - 完成标准: 跟随者——明确"复制哪些已被验证的做法、规避哪些已暴露的坑"；先行者——明确如何在被跟随之前把先发优势转为不可逆的东西（数据、渠道、品牌、转换成本、产品/市场匹配）。
5. **设定回头检查点**
   - 完成标准: 给出 1 个明确的时间/指标节点，到点判断是继续抢时间还是回到匹配上——避免"已经抢了，只能继续抢"的承诺升级。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 抢先无需任何实质妥协——直接做，不需要分析。
- 市场存在强网络效应或赢家通吃结构——此时抢先的价值远超本模型描述，需结合网络效应/赢家通吃市场分析。
- 时机本身尚未成熟——先用"为什么是现在"。
- 已进入稳定期、进入时序不再可变——本 skill 无操作空间。

### 容易误用的地方

- 书中明示：如果先行者**犯下了很多错误**，先发优势会表现为先发劣势。"抢先"本身不产生优势。
- 书中明示：**抢先进入市场并非关键，真正的胜负手是率先实现产品/市场匹配**。把发布时间当成胜负指标是本模型最常见的误用。
- （推导, 非书中明示）把"我们是第一个"当资产。在没有匹配、没有壁垒的情况下，第一个只是第一个，跟随者可以复制做法并规避坑。
- （推导, 非书中明示）忽略教育市场成本的双刃性。先行者付费教育出的市场，跟随者可以免费进入——这是先发劣势的核心机制。
- （推导, 非书中明示）已经抢跑后继续加码。要注意承诺升级的陷阱，应回到第 5 步的检查点重新判断。

### 容易混淆的邻近模型

- **同步发明（simultaneous invention）**: 解释为什么会撞车；本 skill 决定撞车后抢不抢。
- **产品/市场匹配（product/market fit）**: 是真正的胜负手；本 skill 把它作为决策指标来用。
