# 样本量权衡（sample size）

## R — 原文 (Reading)

> 确定样本量（sample size），也就是收集的数据点总量，是一种需要进行权衡取舍的做法。一方面，你收集的信息越多，估算出的结果就越准确，对自己的结论就越有把握；另一方面，收集更多数据需要花费更多的时间和金钱
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

样本量从来不是一个纯粹的技术数字，它是**准确性与成本、时间、受试者风险之间的取舍**。

一边是收益：数据越多，估算越准，结论越有把握，也越能检出较小的真实效应。另一边是代价：更多的时间、更多的钱，如果涉及人（医学试验、有风险的产品改动），还要让更多受试者承担风险。

关键的第二层机制：**样本量决定了你能测出的最小差异**。想检出的效应越小，需要的样本越大——大致是平方反比关系（见标准误差）。

书中助眠应用的例子把这个取舍摊开了：

- 对立假设设为"增加 15%" → 需要 **268 人**
- 对立假设改为"增加 30%" → 只需 **62 人**
- 代价：若真实差异其实只有 15%，用 62 人的方案只有 **32% 的概率**能检出，即约 **2/3 概率得到假阴性**

这是本模型最锋利的地方：**"省样本"不是省钱，是把成本换成了漏检风险**。你以为省了 200 个样本，实际上是接受了三分之二的概率看不见真实效果。

作者给出的正确做法：实验应设计成能测出**"有意义的最小差异"**——即"小到不值得为之改变决策"的那个临界值，而不是"我容易检出的大差异"。

关键判据：先定"多小的差异值得我改变行动"，再由它倒推样本量。如果倒推出来的样本量付不起，正确反应是承认"这个实验做不起"，而不是把对立假设调大。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计 A/B 测试、用户实验、临床试验，需要确定样本量或运行时长。
2. 实验跑了几天没结果，纠结"是再等等还是现在就停"。
3. 有人提议"把目标定大一点，这样样本量小也能测出来"，需要评估这个取巧的代价。
4. 资源有限（时间/预算/受试者风险），需要判断这个实验值不值得做、能不能做到有意义。
5. 小规模试点跑出了"没显著差异"，需要判断是真的没效果还是样本不够。

### 语言信号

- "这个实验要多少用户才能跑出结论"
- "跑了一周没差别，是不是可以停了"
- "样本量太少了说明不了问题吧"
- "我们把目标差异设大一点，样本就能少要很多"
- "再给我三天时间，数据会更准"
- "how long should we run this test / is our sample big enough"

### 与相邻 skill 的区分

- 与 `mm-power` 的区别: 统计功效是"在给定样本量下能检出效应的概率"（1−β），是本权衡的**结果指标**；样本量权衡是决定这个指标的**决策过程**。功效不足时要调样本量，就回到本 skill。
- 与 `mm-alternative-hypothesis` 的区别: 对立假设是样本量计算的**输入**（设定多小的差异），样本量是**输出**。想改输入以省样本，正是书中警告的做法。
- 与 `mm-standard-error` 的区别: 标准误差提供"精度随样本量变化"的**定量曲线**，样本量权衡在此之上叠加**成本与风险**的取舍维度。

## E — 可执行步骤 (Execution)

1. **先定"有意义的最小差异"**
   - 问：小到什么程度的差异，我就不会为之改变行动？把这个临界值定为对立假设。
   - 完成标准: 得到一个具体的、有业务含义的差异值（如"10 分钟内入睡的人增加 15%"）。
   - 判停条件: 若用户想把这个值调大以便省样本，明确指出书中警告——这会换来约 2/3 的假阴性率。
2. **设定可容忍的 α 与功效**
   - 常用 α = 5%（对应 95% 置信度）、功效 80%（即 β = 20%）；按后果严重性调整。
   - 完成标准: 明确写出 α、β 的具体数值与选择理由。
3. **据此计算所需样本量**
   - 完成标准: 给出样本量数字，并说明它对应的"能检出的最小差异"。
4. **把样本量换算成成本与风险，做取舍**
   - 问：这些样本需要多少时间、多少钱？如果涉及人，要让多少人承担风险？
   - 完成标准: 明确列出代价，并给出"做 / 不做 / 缩小范围"的建议。
   - 判停条件: 若成本付不起，建议改测更大的差异、延长周期、或承认该实验不可行——而不是偷偷放宽对立假设。
5. **写清提前停止规则**
   - 预先规定：最少跑满多少样本才允许看结果，避免反复偷看导致的假阳性膨胀。
   - 完成标准: 有明确的停止条件（样本量门槛或时间门槛）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 数据已经收集完毕、只做回顾性分析：此时样本量是既成事实，改用功效分析或标准误差评估结论的可靠性（推导，非书中明示）。
- 效应极大且立竿见影（如严重崩溃 vs 完全正常）：小样本就足以定论，精细的样本量计算收益有限（推导，非书中明示）。

### 容易误用的地方

- 书中明示的警告：**为省时省钱而选"差异明显"的对立假设风险很大**——会有约 2/3 概率得到假阴性；理想情况下实验应设计成能测出"有意义的最小差异"。
- （推导，非书中明示）容易反复看数据、一看到显著就停手。这会大幅抬高实际假阳性率，步骤 5 的预注册停止规则是必要的对抗手段。
- （推导，非书中明示）容易把"样本量大"等同于"结论对"。样本量只降低随机误差，不修复选择性偏差、测量错误等系统性问题。

### 容易混淆的邻近模型

- 第一类/第二类错误（type-i）：样本量的设定直接决定了 α 与 β 的实际水平，三者是一组联立参数。
- 统计功效（power）：1 − β，是样本量是否足够的直接度量。
