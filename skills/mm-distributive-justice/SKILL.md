# 分配正义（distributive justice）

## R — 原文 (Reading)

> "分配正义"围绕事物的分配方式描述什么是公平，认为平等分配更公平。

> — 《思维模型》, 第7章 > 视角决定一切

---

## I — 方法论骨架 (Interpretation)

分配正义是"公平"的两大定义方式之一:它只看**结果的分布**,认为分得越均等就越公平。至于东西是怎么来的、谁付出了什么、规则是否透明,它不关心。

它为什么成立(以及为什么有吸引力):结果分布是唯一可以直接看见、直接比较的东西。不需要调查过程,不需要追溯历史,一眼就能判断"一样多还是不一样多"。这使得分配正义成为争论中最省力的公平标准,也因此成为多数人默认的那一个。

关键判据:**看一个人判断公平时引用的是"分到的量"还是"得到它的过程"**。凡是论证里只出现份额、比例、差距、倍数,而不出现规则、贡献、程序,用的就是分配正义的框架。

它的局限在书中被明确指出:只看结果分布、不看过程或贡献,会与程序正义直接冲突。同一个分配方案,在一种框架下"很公平",在另一种框架下"很不公平"——而争论双方往往根本没意识到他们在用两套标准。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队分奖金、分股权、分资源时,有人说"凭什么他比我多",争议集中在数额差距上。
2. 用户在讨论公共议题(税收、再分配、平权、教育资源),发现争论双方对"公平"的用法完全不同。
3. 用户在家族遗产、合伙分家、收益分成等场景里,被要求解释"为什么这么分"。
4. 用户自己感到强烈的不公平感,却说不清这个感觉的来源是哪一套公平标准。

### 语言信号

- "凭什么他拿那么多,我才这么点"
- "大家出力都一样,不该平均分吗"
- "贫富差距这么大,这公平吗"
- "一人一份最省事也最公平"
- "凭什么他们天生就有,我们没有"
- "that's not an equal share" / "fair distribution" / "income inequality"

### 与相邻 skill 的区分

- 与 `mm-procedural-justice` 的区别: 分配正义看**结果是否均等**,程序正义看**规则是否被一致公开地执行**;同一个方案常常在前者下公平、在后者下不公平(书中祖父遗产的例子正是如此)。
- 与 `mm-fair-share-versus-fair-play` 的区别: 后者是这两套标准在政治辩论中的**对立表述形态**("应有份额" vs "规则公平"),分配正义是其中**结果侧**的那一支。
- 与 `mm-veil-of-ignorance` 的区别: 无知之幕是**推导**公平原则的思维装置(在不知道自己位置的前提下选规则),分配正义是**一种现成的公平标准**。

## E — 可执行步骤 (Execution)

1. **确认争议确实围绕"怎么分"**
   - 完成标准: 明确指出用户讨论的是份额、比例、差距等结果量;若争议焦点是规则是否被一致执行,移交 `mm-procedural-justice`。
2. **把各方使用的公平框架显性化**
   - 完成标准: 逐一标注每个人的论据属于"结果均等"还是"过程/贡献",并指出冲突之所以无法收敛,是因为两套标准在同时被使用。
3. **用书中的判例检验该分配方案**
   - 完成标准: 明确回答——若某个参与者的付出/贡献显著不同(如长期照料祖父的子女),平均分配在分配正义下公平、在程序正义下不公平;请把这一冲突直接摆到台面上,而不是替用户选边。
4. **给出可操作的下一步**
   - 完成标准: 至少给出一条可执行动作——先就"我们这次用哪套标准"达成一致,再谈具体数额;或把可量化的贡献维度列出来,做一个混合方案(保底均分 + 按贡献加权)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 争议焦点是规则、程序、资格或执行一致性——用程序正义。
- 场景只涉及效率最大化、不涉及公平判断(如纯成本优化)——用成本收益分析。
- 用它来直接裁定"谁更公平":本模型的价值是让分歧显性化,不是替用户做道德裁决。

### 容易误用的地方

- 与程序正义的冲突是常态而非例外:同一方案在两套标准下评价相反。(书中明示)
- 把"结果均等"当作唯一正确的公平定义,会掩盖贡献差异,反而在参与者中制造新的不公平感。(推导,非书中明示)
- 只看结果分布意味着不需要追溯过程,这使它极易被用作快速的政治修辞。(推导,非书中明示)

### 容易混淆的邻近模型

- 与程序正义(procedural-justice): 同一枚硬币的两面,结果侧 vs 过程侧。
- 与无知之幕(veil-of-ignorance): 一个是现成标准,一个是推导标准的装置。
