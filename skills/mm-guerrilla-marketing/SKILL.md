# 游击营销（guerrilla marketing）

## R — 原文 (Reading)

> 初创企业运用非常规的营销技巧，以相对较少的预算推广产品和服务。
>
> — 《思维模型》, 第7章 > 改变战局

---

## I — 方法论骨架 (Interpretation)

游击营销是游击战在商业领域的直接应用。大公司的营销优势——电视、纸媒、竞价位、头部 KOL——全都建立在**"用钱换确定性曝光"**这个机制上。这套机制的定价是按大公司的预算水平定的，小公司进场就要按对手的成本结构付钱，必输。

所以游击营销的核心动作不是"把广告做得更便宜"，而是**换一套计价方式**：从"花钱买曝光"换成"制造值得被免费传播的素材"。它的货币不是钱，是话题性、意外感、情绪共鸣。

为什么这在今天成立得比过去更充分？因为分发渠道本身已经去中心化——一条内容的传播量不再由媒体预算决定，而由内容和转发意愿决定。这让"内容质量 × 传播机制"可以部分替代"媒体预算"，正是杠杆作用（leverage）所在。

关键判据是：**这一波推广之后，每多获得一个客户的成本是随规模下降还是上升？** 若靠人力逐个做，那是游击但不是营销；若内容/机制本身能自传播，边际成本趋近于零，这才是有效的游击营销。

作者用它来说明"改变战局"：不是在同一维度上以弱敌强，而是改变游戏规则。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 初创公司或独立开发者要推新品，市场预算接近于零，行业里已有巨头在砸广告。
2. 线下小店/本地服务无法承担平台竞价位，需要低成本获客办法。
3. 已有产品但增长停滞，用户在想"要不要也去投流"，需要先评估非常规打法。
4. 内容创作者想让一条内容出圈，但买不起推广。
5. 用户做了一个病毒视频/活动，想复制成功但不确定能不能规模化。

### 语言信号 (用户的话里出现这些就应激活)

- "我们没什么预算，怎么做推广"
- "对手在砸钱投广告，我们投不起"
- "想做一支病毒视频"
- "能不能搞个事件让大家主动转发"
- "有没有不花钱的获客办法"
- "guerrilla marketing / low budget launch / how to go viral / bootstrap marketing"

### 与相邻 skill 的区分

- 与 `mm-guerrilla-warfare` 的区别: 游击战是通用军事/竞争模型（换维度、打骚扰、避正面），游击营销是它在**营销预算**这个具体维度的应用。用户谈的是渠道与传播用本 skill；谈的是产品竞争、组织对抗用游击战。
- 与 `mm-punching-above-your-weight` 的区别: 挑战重量级回答"要不要主动越级参战"的前置判断；游击营销是决定参战后的具体打法。
- 与 `mm-word-of-mouth-referrals` 的区别: 口碑是**结果**与客户间的自然推荐机制；游击营销是**人为设计的非常规动作**，口碑往往是它追求的效果之一。
- 与 `mm-customer-development` 的区别: 客户开发解决"产品该做成什么样、卖给谁"，发生在营销之前；产品-市场匹配未验证就做营销，会把钱和注意力一起浪费掉。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认对手的钱花在哪、为什么有效**
   - 完成标准: 列出对手 2-3 个主要渠道，并指出每个渠道**靠什么机制生效**（例：竞价位靠出价、电视靠覆盖频次）。这决定了你要避开的是什么。
2. **确认产品-市场匹配已初步成立**
   - 完成标准: 能说出至少一个已有用户明确表达过价值的证据。
   - 判停条件: 若还没有任何用户验证，停止营销动作，转 `mm-customer-development`。
3. **找出对手"太笨重而无法做"的传播位**
   - 完成标准: 给出 2-3 个候选——通常是大公司因品牌风险、审批链长、ROI 太小而不愿碰的形式（自黑式幽默、创始人亲自出镜、极端具体的小众梗、争议性观点、线下非常规物料）。
4. **设计可自传播的素材**
   - 完成标准: 每个候选写明三点：核心钩子（为什么有人愿意转发）、制作成本、以及**传播机制**（靠什么人传给什么人，而不只是"发到网上"）。
5. **小成本快测**
   - 完成标准: 先做 2-3 个最小版本投放到不同小渠道，设定 7 天内可观测的指标（转发率、点击率、获客成本），不追求一次押中。
6. **放大赢家并保留机制**
   - 完成标准: 把有效版本加倍投入，并总结出可重复的动作模板（而不是一次性噱头），明确下次可复用的部分。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 预算充足、需要的是稳定可预测的规模化投放——此时非常规打法的方差太大，不如做扎实的渠道运营。
- 产品尚未被任何用户验证——营销只会加速暴露产品问题，并把获客成本花在留不住的人身上。
- 品牌以信任为核心（医疗、金融、教育、政务）——过度博眼球的非常规动作会损害可信度。
- 所谓"创意"依赖欺骗、蹭灾难热点、侵犯隐私或违反平台规则——这类动作短期有量、长期是负债。

### 容易误用的地方

- 书中未提边界；以下为基于机制推导的警告（推导, 非书中明示）。
- 把"低成本"误解为"零成本"——游击营销省的是媒体采买费，代价是创意密度与时间投入，创始人亲自出镜本身就是成本。
- 把"非常规"当成"出格"——真正生效的是**与产品或受众高度相关**的意外感，与品牌无关的噱头带来的是无效流量。
- 病毒传播不可规划，只能提高概率：把公司增长押在"再做一支爆款视频"上，是把不可控事件当成增长模型。

### 容易混淆的邻近模型

- **游击战（guerrilla warfare）**: 上游通用模型，本 skill 是它在营销中的具体化。
- **口碑／熟人推荐（word-of-mouth referrals）**: 常被游击营销当作目标效果，但本身是另一套机制（客户驱动、复利式）。
