# 包以德循环（OODA Loop）

## R — 原文 (Reading)

> 它是一个由观察（observe）、调整（orient）、决策（decide）、行动（act）4个步骤组成的决策循环。
>
> — 《思维模型》, 第9章 > 缺少执行的愿景不过是幻想

---

## I — 方法论骨架 (Interpretation)

这个模型的背景是近距离空战。美国空军上校约翰·包以德发现，赢得格斗的通常不是飞得最快的飞行员，而是**在循环中动得最快的那个**——他能更快地完成"观察→调整→决策→行动"这一整圈，并在对手还没做出下一动作之前就重新评估。

四步各自是：

- **观察（observe）**：收集当前发生的事实——敌机在哪、仪表读数、环境变化。
- **调整（orient）**：最关键也最容易被跳过的一步。把观察到的事实放进你的心智模型、文化背景、以往经验里**重新理解**。同样的信息，在不同的调整框架下会得出完全不同的结论。
- **决策（decide）**：在调整后的理解基础上选定一个动作。
- **行动（act）**：执行，然后立刻回到观察。

为什么快就赢？因为每一次行动都在改变现实，而对手必须对新现实重新做一轮循环。**如果你的循环比他短，你就会不断呈给他一个他还没来得及理解的新局面**——他永远在应对上一秒的世界，于是他的每一个决策在出手时就已经过时了。极端情况下他会陷入"每步都合理、整体却一直在输"的状态。

这套逻辑可以直接迁移：作者指出，在**快速学习能带来优势的领域**（比如科技行业），组织把循环转得更快，就能持续做出更好的决策、更快地适应环境。

书里还给了一个非常贴切的生物学类比——**这像自然选择**。生命周期短、迭代快的物种进化得快；细菌之所以能迅速对抗菌药产生耐药性，正是因为它们一代的时间太短，试错次数太多。

判据一句话：**从"看到变化"到"打出新动作"，你和你的对手各需要多久？**

## A1 — 书中的应用 (Past Application)

### 案例: 包以德的空战观察
- **问题**: 在近距离空战中，双方飞行员面对的是几乎同样的飞机、同样的训练、同样的环境。决定胜负的到底是什么？
- **方法论的使用**: 包以德把空战拆成一个四步循环——观察（我在哪、他在哪、他在做什么）、调整（基于我对空战的理解，他这个动作意味着什么意图、我处在什么态势）、决策（我该做什么机动）、行动（做出来，然后立刻重新观察）。他发现，适应环境更快、在循环里移动得更快的人，通常会赢下格斗。关键不是某一次决策多高明，而是**单位时间你能转几圈**。
- **结论**: 包以德由此提炼出这个通用决策模型，后被推广到军事之外的所有竞争性对抗场景。作者在书中把它放在"缺少执行的愿景不过是幻想"这一节，用意很明确：愿景到执行之间差的不是宏大的规划，而是**循环的速度**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **和对手的实时对抗中**（竞价、算法、谈判、事故响应）: 用户在做的事会被对方回应，需要的是压缩循环周期而不是做一个完美计划。
2. **组织/团队决策链条太长**: 用户抱怨"我们反应太慢，机会都错过了"，需要找出哪一环卡住了。
3. **在高度不确定的新环境里摸索**: 用户不知道正确答案，只能靠高频小步试探逼近。
4. **用丰厚计划应对变化、却一直被打脸**: 需要把"做一次大计划"切换成"转很多圈"。

### 语言信号 (用户的话里出现这些就应激活)

- "我们是不是反应太慢了"
- "对手一变我们就跟不上"
- "每次开会讨论完，情况已经变了"
- "计划赶不上变化"
- "要不要先小规模试试看"
- "我们决策链条太长"
- "We need to move faster." / "Our competitor reacts quicker than us." / "Let's iterate and see."

### 与相邻 skill 的区分

- 与 `mm-analysis-paralysis` 的区别: 分析瘫痪说的是**卡在循环内部出不来**（过度分析导致无法进入决策和行动），包以德循环给的是**完整的四步结构和节奏**。前者描述病症，后者给出运转节律；循环过快跳过"调整"一步则是另一种失败方式。
- 与 `mm-experimental-mindset` 的区别: 实验思维强调"把不确定性交给受控实验去回答"，追求的是**结论可靠**；包以德循环强调"在对抗中比对手更快完成一轮"，追求的是**相对速度**。真刀真枪的对抗里往往没有条件做干净实验。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认环境是不是真的瞬息万变**
   - 完成标准: 明确回答"对手/环境会不会在几小时到几天内对我的动作做出回应"。书中明确说过"有些情况确实如此"，暗示并非所有情境都适用。
   - 判停条件: 若环境稳定、且决策影响长期难以更改，停止使用本模型，改用常规规划。
2. **画出当前的循环并测量周期**
   - 完成标准: 把现状拆成观察/调整/决策/行动四段，给出每段的实际耗时，算出整圈总时长。多数人会发现卡点不在"决策"而在"观察"（信息滞后）或"行动"（审批链）。
3. **找出最短的一环做压缩**
   - 完成标准: 针对耗时最长的一个环节给出 1-2 个具体压缩动作（如把周会改成实时看板、把三级审批改成事后报备、给一线设一个不需要请示的行动阈值）。不要同时改四步。
4. **强化"调整"这一步**
   - 完成标准: 明确列出做调整时依赖的心智模型或假设清单，并指出其中可能过时的部分。这一步最容易被跳过，但它决定了同样的观察能得出多不同的决策——跳过它，快速循环只是快速犯错。
5. **设定不计代价必须回到观察的触发点**
   - 完成标准: 写下 2-3 个可观测信号（指标跌破某值、对手发布某物、客户说某句话），一旦出现就必须重新走一整圈，而不是继续执行原计划。
6. **对比对手的循环速度**
   - 完成标准: 给出对手完成一圈的估计时长，并与自己对比。若明显慢于对手，明确指出这不是努力问题而是结构问题，需要改的是流程而非加班。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **环境稳定、规则明确的任务**: 循环快没有收益，反而会因为频繁改向产生返工和振荡。
- **不可逆的高风险决策**（大额并购、重大架构改动）: 快在这里意味着跳过验证，代价远大于收益。
- **需要深度思考的创造性工作**: 强行压缩周期会牺牲"调整"这一步的质量，产出变成对最近一次反馈的应激反应。

### 书中警告的失败模式 / 容易误用的地方

- **书中明示**: 作者明确指出**并非所有情境都瞬息万变、充满不确定性**——"有些情况确实如此"，这句话暗示稳定情境未必适用这个模型。所以第 1 步必须先确认环境。
- （推导, 非书中明示）**跳过"调整"，把循环退化成"刺激-反应"**: 这是最常见的误用。观察完直接行动，等于放弃了修正心智模型的机会，团队会变成一群被最近一条数据牵着走的人。
- （推导, 非书中明示）**把速度当成目标本身**: 包以德的结论是"比对手快"，不是"越快越好"。在没有对手的领域里追求极致速度，只会消耗组织。
- （推导, 非书中明示）**用循环替代验证**: 快速迭代不能替代受控实验与显著性判断。当条件允许干净测量时，应转投 `mm-experimental-mindset`。

### 容易混淆的邻近模型

- **自然选择（natural-selection）**: 书里用它做类比——生命周期短、迭代快的物种进化更快（细菌迅速产生耐药性）。机制相同，但发生在无意图的演化过程里，而 OODA 是有主体、有意图地压缩循环。
- **动量（momentum）**: 动量描述的是已经积累起来的运动惯性，有助于维持推进；但过大的动量会成为"调整"这一步的阻力——组织因为惯性而无法真正根据观察改向。二者需要平衡。
