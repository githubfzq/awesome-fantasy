# 均值回归（regression to the mean）

## R — 原文 (Reading)

> "均值回归"解释了为什么跟在极端事件之后出现的通常是比较普通的事件，也就是回归接近预期的均值。
>
> — 《思维模型》, 第5章 > 警惕小数定律

---

## I — 方法论骨架 (Interpretation)

任何一次观测都由两部分组成：真实水平 + 运气。一次极端好的成绩，几乎必然意味着"实力不错 + 极端好运"；而极端好运按定义不会重复出现，所以下一次即使实力没变，结果也必然更接近均值。反过来，一次极端差的表现之后也会自然回升。

这不是什么神秘力量在纠正，只是运气成分在平均化。罕见结果重复出现的概率，与它第一次出现时一样稀罕——破纪录的短跑选手下次多半稍差，不是因为压力，而是因为数学。

关键判据是问：**这个极端值里，有多少是运气？** 运气占比越高，回归越猛。作者强调："不该认为基于少量观测得出的结果是典型的"——第一印象可能准确，但应保持怀疑。

---

## A1 — 书中的应用 (Past Application)

### 案例: 二年级生症候群

- **问题**: 乐队第二张专辑往往不如首专好评如潮，新秀赛季亮眼的球员次年击球率下滑，人们习惯归因为心理压力或自满。
- **方法论的使用**: 作者指出，多数情况下这不是心理问题，而是数学上的均值回归——首专/新秀赛季的亮眼成绩里含有极端的运气成分，不可重复。
- **结论**: 极端之后回落是常态，不必急着编造因果解释；破纪录的短跑选手下次多半稍差，同理。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 上个月/上季度业绩破纪录，这个月回落，团队追问"是不是奖励之后松懈了"。
2. 最差的一周之后随便做了个调整，数据就变好了，于是认定该调整有效。
3. 招聘/投资/评审中，依据一次极端亮眼（或极差）的表现给人或项目下定论。
4. 预测"下一个爆款/下一个赛季/第二本书"能否复制上一次的成功。

### 语言信号 (用户的话里出现这些就应激活)

- "上个月太好了，这个月怎么掉这么多"
- "是不是被夸奖之后就松懈了"
- "第二部作品明显不如第一部"
- "新人不像刚来时那么猛了"
- "Is this just regression to the mean?"

### 与相邻 skill 的区分

- 与 `mm-gambler-s-fallacy` 的区别: 赌徒谬误以为**概率会补偿**（连出黑后押红，独立性其实未变）；均值回归说的是**观测值里含运气**，运气不可重复所以回落——前者错在独立性，后者是真实的统计现象。
- 与 `mm-law-of-small-numbers` 的区别: 小数定律讲小样本波动大、容易出现极端；均值回归讲极端之后的必然回落。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位极端观测并估计其罕见程度**
   - 完成标准: 说明该值相对历史分布偏离多少（几个标准差/历史上排第几）。
2. **拆分"实力"与"运气"**
   - 完成标准: 给出该指标的历史波动幅度，指出极端值中可能有多少来自不可重复的运气成分。
   - 判停条件: 若该指标几乎无波动（纯实力、确定性任务），停止，均值回归不适用。
3. **给出回归后的预期区间**
   - 完成标准: 预测下一次落在什么范围，而不是一个点值。
4. **检查是否存在真实的因果变化**
   - 完成标准: 对比"回归预期"与"实际结果"，只有当实际显著偏离回归预期时，才去寻找因果解释（避免把回归误当成干预有效）。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 存在真实的、持续的水平变化（能力确实提升、市场结构性改变、流程已实质优化）时，把所有回落都归因于回归会掩盖真相。
- 指标几乎不含随机成分（确定性任务的计数）时，本模型不适用。

### 书中警告的失败模式 / 容易误用的地方

- 作者强调：**"不该认为基于少量观测得出的结果是典型的"**——它可能既不代表小样本组也不代表大样本组的观测结果；第一印象可能准确，但应保持怀疑。
- （推导，非书中明示）最常见的误用是"干预后变好就归因于干预"：在最差时刻做的任何调整，都会因为回归而看起来有效，需要对照组才能分离。

### 容易混淆的邻近模型

- 赌徒谬误（gambler-s-fallacy）：看似同样说"会回来"，但机制是虚假的补偿预期。
- 二年级生症候群（sophomore-slump）：均值回归在作品/赛季上的具体表现形态。
