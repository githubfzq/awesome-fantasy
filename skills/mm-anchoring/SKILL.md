# 锚定（anchoring）

## R — 原文 (Reading)

> 它描述的是，人们在做决策时会不自觉地过度依赖第一印象。你遇到的第一则发挥"框架效应"的信息就锁定了你的选择。
>
> — 《思维模型》, 第1章 少犯错 > 各持己见

---

## I — 方法论骨架 (Interpretation)

人的判断很少是绝对值的判断，多数是**相对于某个参照点的调整**。问题是：参照点从哪来？锚定效应给出的答案是——**谁先出现，谁就是参照点**。

第一个出现的数字或说法会"锁定"一个区间，后续的所有判断都只是在它附近做相对调整，而调整通常是不充分的：你以为自己做了独立判断，实际上只是在锚附近走了一小步。所以锚的位置，往往比谈判中的论证更能决定最终结果。

两个要点：

1. **锚不限于数字**。它可以是开价、立场、叙述的起点、甚至是一个"市面上通常都这样"的说法。任何先出现并成为比较基准的信息都能当锚。
2. **锚不需要合理，也不需要有信息量**。《经济学人》那个没人会选的"只订阅纸质版 125 美元"，本身是一个无人选择的选项，它的全部作用就是给"纸质+网页 125 美元"提供一个看起来很划算的参照。锚的力量来自它的**存在**，不来自它的合理性。

书中把它与框架效应的关系讲得很清楚：锚是"第一则发挥框架效应的信息"——框架是更上层的现象，锚是它的数值化、先发型特例。

关键判据（一问定胜负）：**如果我没先看到那个数字/说法，我的判断会是多少？** 如果两个答案差距明显，你被锚住了。

对应的两个动作：防守时，在接触对方锚之前先独立估算；进攻时，争取先出锚并保证它偏高但不离谱。

## A1 — 书中的应用 (Past Application)

### 案例: 《经济学人》订阅实验、虚高 MSRP、先定高目标
- **问题**: 作者要证明锚的强大——它能凭空改变选择，而且不需要锚本身有任何吸引力。
- **方法论的使用**: 三个对照。其一，《经济学人》订阅实验：只有"网页 59 美元"和"纸质+网页 125 美元"两个选项时，多数人选便宜的；加入一个明显劣于后者、且价格相同的"只订阅纸质版 125 美元"之后，选 125 美元组合的人从 32% 升到 84%，收入增加 43%。这个没人选的选项纯粹是锚。其二，迈克尔斯、科尔士等零售商标一个虚高的厂家建议零售价（MSRP），再打六折，让顾客以"省了多少"而不是"值多少"来判断。其三，特朗普的做法是先定很高的目标再努力争取——主动设定一个偏高的锚。
- **结论**: 锚的效力来自它作为比较基准的位置，与它本身是否合理无关。因此防守的唯一有效手段，是在看到对方的锚之前，先有自己的独立估算。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **谈判/砍价的开局**: 对方先报了价、先给了预算范围、先说了"市场价一般是多少"。需要判断自己是否被锁在区间里。
2. **购物时看到"原价/折扣/建议零售价"**: 判断折扣是不是真的，还是只是用虚高原价当锚。
3. **定目标、定预算、定工期**: 第一个被提出来的数字会成为整个团队的基准（"上次做了三个月"），而这个数字可能完全没有依据。
4. **估值/报价/薪资谈判**: 需要在被锚住之前先建立自己的估算区间。
5. **主动设定锚**: 用户要发提案、开价、定 KPI，需要知道先出手的威力和边界。

### 语言信号 (用户的话里出现这些就应激活)

- "他先报了个价，我们还到这个数是不是已经赚了"
- "原价 1999，现在只要 699，划算吗"
- "他们开口就是三个月，我不知道该砍到多少"
- "我先开价好还是让他先开？"
- "我们要不要报高一点"
- "市场价一般是多少来着"
- "That's the anchor." / "Let's set the anchor." / "MSRP" / "opening offer"

### 与相邻 skill 的区分

- 与 `mm-framing` 的区别: 框架效应是**整体叙事角度**决定理解与归类；锚定特指**第一个数字/说法**对后续判断区间的数量化牵引。书中明确说锚是"第一则发挥框架效应的信息"——锚是框架的子集。
- 与 `mm-batna` 的区别: BATNA 给出的是**谈判的客观底线**（谈不成时的最佳替代方案），是独立估算的基础；锚定描述的是**心理参照点如何被先发信息劫持**。防守锚定的最好办法就是先算清自己的 BATNA。
- 与 `mm-loss-aversion` 的区别: 损失规避是锚定能起作用的心理机制之一（"省了 1300"被框成收益）；锚定是更具体的"先发信息锁定区间"的现象。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别锚的存在与位置**
   - 完成标准: 明确指出当前场景中被先提出来的那个数字/说法是什么、由谁提出、出现在什么时点。
   - 判停条件: 若用户尚未接触任何先发信息，直接进入第 4 步（建立独立估算），此时是主动设锚的最佳时机。
2. **做"无锚测试"**
   - 完成标准: 让用户回答"如果我从没听过这个数字，我会估多少？"——给出这个无锚估计值，并与当前判断对比，量化差距。
   - 判停条件: 若用户无论如何都给不出独立估计（对该领域完全无信息），说明此时无法靠自己脱锚，转向第 3 步找外部基准。
3. **建立独立估算区间**
   - 完成标准: 用三种独立来源得出区间——(a) 标的的构成/成本侧推导；(b) 可比对象的市场数据；(c) 自己的 BATNA / 替代方案成本。三者交叉，给出一个上下限。
4. **（若用户是接收方）主动脱锚**
   - 完成标准: 明确以独立区间而非对方数字作为谈判起点，并把话题从"相对这个锚调整多少"拉回"这个标的本身值多少"。若对方坚持以其锚为基准，明确指出它缺乏依据。
5. **（若用户是提出方）设计锚**
   - 完成标准: 给出一个"偏高但不离谱"的锚——高到能拉动区间，又不至于让对方直接离场或损害信任。同时准备好支撑它的理由（锚需要理由背书，否则容易被直接否定）。
   - 判停条件: 若关系需要长期维护、或对方有充分信息可识破虚高，改为以真实上限为锚，不做夸大。
6. **复盘：检查是否被次级锚捕获**
   - 完成标准: 谈判结束或决策做出后，回看最终值离谁的锚更近，记录这一差距用于下次校准。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **标的价值可独立精确计算时**: 有活跃市场报价、有明确成本构成、有公式可算——直接算，锚定分析没有增量。
- **没有先后信息暴露的场景**: 双方同时出价、密封投标，不存在"谁先出现"的问题，锚定不适用。
- **纯粹的创造性/非量化判断**: 选一个设计方案、判断一篇文章好坏，没有可被锚定的数值区间。

### 书中警告的失败模式 / 容易误用的地方

- **书中对本模型未给边界**（`boundary` 字段为"书中未提"），以下为基于机制推导的警告（推导, 非书中明示）：
- **知道锚定存在并不能免疫锚定**: 这是最危险的失败模式。谈判者以为"我知道有锚定效应，所以我不会被影响"，结果依然在锚附近成交。唯一有效的防守是**在接触锚之前**先做出独立估算，事后提醒几乎无效。
- **锚过头会反噬**: 一个离谱到荒唐的锚不会拉高成交价，只会让对方认为你缺乏诚意、直接终止谈判，或损害长期信任。
- **被次级锚捕获**: 即便躲开了第一个锚，对方的第二个数字（让步幅度、附加条件）又成了新锚。每一轮都要重新做无锚测试。

### 容易混淆的邻近模型

- **框架效应（framing）**: 是更上层的现象，锚是它的数值化、先发型特例。
- **禀赋效应 / 损失规避（loss-aversion）**: 是锚定起作用的心理机制之一，不是同一件事。
