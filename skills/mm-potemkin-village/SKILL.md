# 波将金村／面子工程（Potemkin village）

## R — 原文 (Reading)

> 称为"波将金村"（Potemkin village，又称"面子工程"），也就是专门打造某些东西，使别人相信情况比实际上好。

> — 《思维模型》, 第7章 > 底线在哪儿

---

## I — 方法论骨架 (Interpretation)

波将金村指**为了让人相信情况比实际更好而专门搭建的虚假展示**。它不是一个比喻性的说法,而是一种有成本结构的策略:搭建一个可看的表面,成本远低于真正把事情做好,于是当观众无法验证后台时,欺骗就比实干便宜。

它的成立依赖三个条件:**(1) 观众只看得到前台**——参观路线、演示脚本、对外材料都是被安排好的;**(2) 后台不可核查或核查成本极高**;**(3) 观众不会主动要求看未安排的东西**。三者同时成立时,造假者只付出"布景"的成本,就换取了"实力"的信用。

所以关键判据不是"展示得漂不漂亮",而是:**能不能看到未被安排的环节**。凡是只能按对方给的路线走、只能看对方指定的样本、只能拿到对方整理过的数据,你就处在波将金村的观测位置上。

书中举的例子横跨各领域:安然在休斯敦总部搭建虚假交易大厅;Theranos 用外部实验室设备冒充自家仪器做演示;历史上也有为外部视察而伪造的集中营。作者也提醒:波将金村这个传说本身未必可靠——这提示我们,指控造假同样需要证据,不能因为"看起来太完美"就反过来推定一定有假。

同时书中指出有**可接受的同型实践**:军方的假枪假坦克(用来误导敌方侦察,对手本就该被骗)、家用假安保摄像头(吓阻而非欺骗利益相关方)。区分点在于:**欺骗的对象是谁、对方是否有权知道真相**。对敌人误导是战术,对投资人、监管方、用户误导是欺骗。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在考察供应商、加盟商、候选公司或合作方,对方安排了"参观/演示/样板点",用户怀疑看到的不是日常状态。
2. 用户看到了一场特别漂亮的产品演示或数据看板,想判断它是真实系统还是预录/手工做出来的。
3. 用户在做尽职调查、投前评估、采购选型,想设计能穿透包装的核查动作。
4. 用户自己被要求准备对外展示,想知道哪里是合理包装、哪里已经越线成造假。

### 语言信号

- "他们的参观路线是不是专门安排的"
- "这个演示看着太完美了,是真的在跑吗"
- "能不能随机抽一个现场看看"
- "去之前他们突击装修了一周"
- "样板间和实际交付一样吗"
- "staged demo" / "dog and pony show" / "smoke and mirrors" / "Potemkin village"

### 与相邻 skill 的区分

- 与 `mm-vaporware` 的区别: 雾件是**宣布还没做出来的东西**(用承诺影响预期),波将金村是**摆出已经做好的样子**(用实物冒充现状);一个骗的是未来,一个骗的是现在。
- 与 `mm-dark-patterns` 的区别: 黑暗模式是**界面/流程层**对用户的小额操纵,波将金村是**整体事实层面**的伪造;波将金村在书中被明确列为黑暗模式的线下形态之一,量级和性质都更重。
- 与 `mm-asymmetric-information` 的区别: 信息不对称是**结构性条件**(一方天然知道得更多),波将金村是**利用该条件主动造假**;前者可以无害,后者有欺骗意图。

## E — 可执行步骤 (Execution)

1. **标出"前台/后台"分界线**
   - 完成标准: 明确列出你目前拿到的一切(参观路线、演示、材料、数据)中,哪些是对方安排的、哪些是你自己选的;若全部来自对方安排,直接判定处于高风险观测位。
2. **要求一个未被安排的样本**
   - 完成标准: 提出具体动作——随机抽一个非样板点、临时改行程、要求现场操作而非播放录屏、要求导出未经加工的原始日志;对方拒绝或需要"准备一下"本身就是信号。
   - 判停条件: 若对方以保密为由拒绝,改为要求第三方审计/出具带责任的书面承诺,而不是接受替代性的精美材料。
3. **用成本反推**
   - 完成标准: 估算"真实做到这个水平"需要多少投入(人、时间、设备、资质),与对方已知规模对比;若明显不匹配,要求给出解释并要求可验证的佐证。
4. **分清战术误导与欺骗**
   - 完成标准: 明确回答——被误导的一方是否有权知道真相(投资人、监管、用户、合作方 = 有权);有权却仍被误导的,判定为波将金村而非可接受的同型实践。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 展示方确实做到了,只是包装、排版、讲得好:准备充分不是造假,要求"不许美化"会误伤正常沟通。
- 面向敌对/竞争方的刻意误导(军事伪装、竞争烟雾弹):这是战术,不是欺骗。
- 你只是觉得"太好了不像真的"但拿不出任何后台不可核查的证据:怀疑不构成指控。

### 容易误用的地方

- 作者指出波将金村的传说本身"未必可靠"——**不要因为展示漂亮就反推一定有假**,指控造假需要后台证据。(书中明示)
- 军方的假枪假坦克、家用假安保摄像头属于可接受的同型实践,关键在被误导者的身份与权利。(书中明示)
- 把"不能用波将金村解释的现象"硬套进来:如果后台本来就是开放的、可随时抽查的,造假机制不成立。(推导,基于机制条件)

### 容易混淆的邻近模型

- 与雾件(vaporware): 一个骗未来(宣布未完成的),一个骗现在(摆出已完成的)。
- 与黑暗模式(dark-patterns): 上位/下位关系,波将金村是更重的事实层面伪造。
