# 众包（crowdsourcing）

## R — 原文 (Reading)

> 另一种方法是将创意众包（crowdsource），也就是从任何想参与的人（群众）那里寻求（外包）创意，这通过互联网很容易实现。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

众包是把创意或信息"外包"给任何想参与的群众,互联网让它几乎零成本。

在情景分析中它一次性解决两个问题:一是提供大量不同视角来支撑情景设定;二是帮你发现未知的未知数(你根本不知道自己不知道的东西)与未知的已知数(你知道、但没意识到别人也知道的东西)。从贝叶斯的角度看,众包本质上是在为更新你的先验提供新数据。

它不是无条件有效的。作者引用索罗维基给出三个必要条件:**观点多样性**(参与者带来不同的知识与经验)、**独立性**(各人表达意见不受他人影响,以免沦为群体思维)、**聚合性**(有机制能把各方意见结合成一个集体决策)。

关键判据有两条:第一,只有当集体的知识储备多于你原本拥有的知识时,利用群体智慧才有意义;第二,必须检查三条件是否成立,尤其是独立性——如果参与者能看见彼此的答案,你得到的是一次从众,不是一次众包。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在做情景分析或战略预演,内部几个人想不出足够多的可能性,想借助外部视角。
2. 用户打算发起公开征集(创意、新闻线索、漏洞悬赏、用户调研),想设计得真正有效而非收一堆噪音。
3. 用户怀疑团队有集体盲区,想找到"我们根本没意识到自己不知道"的东西。
4. 用户看到某个"群众智慧"的结论(榜单、评分、投票),想判断它值多少信任。

### 语言信号 (用户的话里出现这些就应激活)

- "要不我们公开征集一下想法"
- "搞个悬赏 / 众包 / 黑客松试试"
- "内部想不出新东西了,能不能借外部力量"
- "用户投票/评分能信吗"
- "怎么才能发现自己没想到的风险"
- "crowdsource" / "open call" / "bug bounty" / "call for ideas"

### 与相邻 skill 的区分

- 与 `mm-wisdom-of-crowds` 的区别: 群体的智慧讲的是**聚合后的平均判断为何能胜过个体**(统计原理与三条件);众包讲的是**主动向外索取创意与信息这一动作**(组织手段)。众包是手段,群体智慧是它赖以成立的机制。
- 与 `mm-prediction-market` 的区别: 预测市场用真金白银的买卖把分散信息压成一个概率数字,自带激励机制与聚合机制;众包通常没有价格信号,需要你另外设计聚合方式。
- 与 `mm-superforecasters` 的区别: 超级预测家依赖一小批经过筛选与训练的高手;众包强调开放参与、量大面广,参与者通常未经筛选。

## E — 可执行步骤 (Execution)

1. **先确认众包有意义**
   - 完成标准: 明确回答"这个问题的答案是否可能存在于我/团队之外";若集体知识并不多于你已有知识,直接停止并说明不要用众包。
2. **检查并设计三条件**
   - 完成标准: 逐条给出落地措施——多样性:从哪里招来不同背景的人;独立性:如何让参与者在提交前看不到别人的答案;聚合性:用什么规则把意见合成结论(投票、加权、专家复核、预测市场)。
   - 判停条件: 若独立性无法保证(如公开评论区、可见排行榜),明确指出结果会退化为从众,需改用匿名提交或改换方法。
3. **把问题问对**
   - 完成标准: 问题被拆成可被外部人独立回答的具体提问,并说明要找的是"不同的可能"还是"最优解";明确给出提交格式与判定标准。
4. **聚合与回溯**
   - 完成标准: 按预先声明的规则合成结论,并单独列出那些"没人想到过、只有个别人提出"的长尾答案——那往往正是未知的未知数所在。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 问题涉及商业机密、未公开产品、合规敏感信息:公开征集等于公开泄露。
- 需要深度领域知识且外部缺乏合格参与者:此时应找专家,不是群众。
- 没有能力设计聚合规则时:收到的只会是一堆无法处理的原始输入。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确限定:只有当集体知识储备多于你原本拥有的知识时,利用群体智慧才有意义。(书中明示)
- 必须满足多样性、独立性、聚合性三条件,否则众包退化成从众或噪音。(书中明示)
- 常见误用:把公开的、彼此可见的投票当成独立意见汇总——2016 年预测市场失手的一个归因正是"预测者并非独立行事,受最初赔率影响"。(推导,书中该归因针对预测市场,非直接针对众包)

### 容易混淆的邻近模型

- 与群体的智慧(wisdom of crowds): 常成对出现,前者是动作、后者是原理;判断众包结果可信度时必须回到三条件。
- 与未知的未知数(unknown unknowns): 众包是发现未知的未知数的主要手段之一,但不是唯一手段(还可靠类比、思维实验、一线走访)。
