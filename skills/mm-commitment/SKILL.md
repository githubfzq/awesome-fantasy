# 承诺（commitment）

## R — 原文 (Reading)

> 如果你同意（或承诺）某些事，无论这件事有多小，你在未来都可能继续同意。
>
> — 《思维模型》, 第7章 > 影响力模型

---

## I — 方法论骨架 (Interpretation)

这是西奥迪尼(Cialdini)影响力六原则之一。机制:前后不一致会造成心理不适(认知失调,cognitive dissonance),人天生倾向于把自己看成前后一致的人,于是一旦答应过一次,后续拒绝同一方向的请求就会产生额外的心理成本。

所以顺序很重要:**先争取"小小的赞同",能显著提高得到"大大的赞同"的概率**。那个小赞同本身几乎不需要成本(点个"是"、填个邮箱、说一句"我也觉得睡眠很重要"),但它改变的是你对自己的看法——"我是一个支持这件事的人"。

为什么成立:维持自我形象一致的需求,往往强过对具体事项本身的判断。这也是为什么它极易被界面设计和推销话术用作操纵手段:按钮上写"稍后注册"而不是"不用了,谢谢",就是在让你先做一次不拒绝的承诺。

关键判据:**问"我之前答应过什么"**——如果你此刻的同意主要来自"不想显得前后不一致",而不是来自这件事本身的好处,那就是承诺机制在起作用。

## A1 — 书中的应用 (Past Application)

### 案例: "稍后注册"按钮与床垫推销员

- **问题**: 网站想让你注册、推销员想让你买下那张床垫,直接开口容易被拒绝。
- **方法论的使用**: 作者举了两个例子——网站把拒绝按钮写成"稍后注册"而不是"不用了,谢谢",让你在拒绝的那一刻其实作出了"我会注册"的承诺;床垫推销员则先问"你希望晚上睡得更好吗"这种人人都会答"是"的小问题,再往下推进。
- **结论**: 越小、越不设防的赞同,越容易被拿到;而一旦拿到,后续的大请求就顺着一致性压力滑进来了。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户发现自己已经答应了一系列请求,现在被要求做一件明显更大的事,心里不舒服却说不出口。
2. 用户在设计注册流程、销售话术、募捐邮件、产品引导,想提高转化率,需要知道机制原理与伦理边界。
3. 用户被"免费试用→自动续费""先填问卷→再要购买"这类流程套住,想找出该在哪一步退出。
4. 用户在团队里承诺过一个方向,现在证据变了却不敢改口,怀疑自己在被沉没成本绑架。

### 语言信号 (用户的话里出现这些就应激活)

- "我都答应了,现在反悔不太好"
- "一步一步就答应到现在了"
- "当时只是随口说了句好"
- "不好意思拒绝 / 骑虎难下"
- "稍后注册 / 先试用再付款"
- "I already said yes" / "foot in the door" / "hard to back out now"

### 与相邻 skill 的区分

- 与 `mm-reciprocity` 的区别: 互惠靠的是"欠了别人的"(对方先给你东西),承诺靠的是"我对自己说过的话"(你自己先表态);看驱动力是亏欠感还是一致性需求。
- 与 `mm-foot-in-the-door-technique` 的区别: 得寸进尺是承诺原理的**具体战术名称**(先提小请求再提大请求),本 skill 是底层机制;谈机制与防守用本 skill,谈话术设计用前者。
- 与 `mm-sunk-cost-fallacy` 的区别: 沉没成本是"已经投入了资源所以不愿撤",承诺是"已经表过态所以不愿改口";前者是经济性的,后者是身份性的。

## E — 可执行步骤 (Execution)

1. **定位那个"最初的赞同"**
   - 完成标准: 明确指出用户是在哪一步、对什么作出了第一次表态或承诺,以及它有多小。
   - 判停条件: 若用户从未作出任何表态,只是单纯改变了想法,跳到步骤 4,说明这不是承诺机制。
2. **分离两股力量**
   - 完成标准: 把"这件事本身的好处"与"我不想显得前后不一致"分开列出来,让用户看清各自占多大分量。
3. **给出脱身的合法路径**
   - 完成标准: 提供具体话术,把"反悔"重新表述为"基于新信息作出修正"——这既保住了自我形象的一致性,又允许改变决定;明确指出一致性应该指向"我是一个讲道理的人",而不是"我是一个永不改口的人"。
4. **若用户是设计方:检查伦理边界**
   - 完成标准: 明确指出该机制常被用作操纵手段;给出判据——用户如果知道全貌还会同意吗?拒绝路径是否与同意路径同等容易(不应把"稍后"伪装成拒绝)?

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方是靠先给好处来换取回报(送小礼物后要捐款)——那是互惠。
- 用户只是单纯改变了想法、从未作出过任何表态:贴"承诺机制"的标签会误导。
- 用户已经投入大量金钱/时间而非表态:更接近沉没成本谬误。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给反例,但明确提示该模型常被推销与界面设计用作操纵手段。(书中明示)
- 最常见的误用:把"坚持到底"的美德和"被一致性绑架"混为一谈——修正一个基于错误前提的承诺是理性的,不是失信。(推导,非书中明示)
- 作为设计方使用时,"稍后注册"这类写法属于黑暗模式(dark-patterns),短期提升转化、长期损耗信任。(推导,非书中明示)

### 容易混淆的邻近模型

- 与认知失调(cognitive-dissonance): 认知失调是承诺机制背后的**心理不适感**本身,承诺是它被利用的**路径**;谈感受用前者,谈话术用后者。
- 与沉没成本谬误: 两者都让人"继续投入",但一个的锚是说过的话,另一个的锚是花掉的钱。
