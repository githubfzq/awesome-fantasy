# 眼镜蛇效应（cobra effect）

## R — 原文 (Reading)

> 针对这种更为特殊的情况，有一个被称为"眼镜蛇效应"（cobra effect）的思维模型，形容的就是尝试某种解决方案却让问题变得更糟糕的现象。
>
> — 《思维模型》, 第2章 > 许愿须谨慎

---

## I — 方法论骨架 (Interpretation)

眼镜蛇效应描述的是干预的**反效果**：你为了解决一个问题而设计的方案，最终让这个问题变得更严重。它比一般的"方案无效"更糟——方案不但没用，还成了问题的放大器。

机制有两步。第一步，激励改变了被治理对象的行为，使他们开始利用激励本身：既然每条眼镜蛇能换赏金，那就养蛇。第二步，当激励被取消时，被人为放大的存量会一次性回流——养殖的蛇被放归野外——于是问题比干预之前更严重。河内按老鼠尾巴发赏金的例子同理：捕手割下尾巴放走老鼠，让它们回去繁殖出更多老鼠。

最关键的判据是这一句：**你的方案是否创造了一个"靠问题存在而获利"的新群体？** 如果有，你就埋下了一颗反效果种子——这个群体会主动维护问题，甚至扩大问题，因为问题就是他们的收入来源。

作者因此把它与古德哈特定律连起来使用：制定激励制度时必须遵守古德哈特定律、提防不当诱因，否则"眼镜蛇和耗子泛滥成灾"。它是激励设计的事前检查项，而不是事后惊叹。

---

## A1 — 书中的应用 (Past Application)

### 案例: 英属印度的眼镜蛇赏金与河内的老鼠尾巴

- **问题**: 英属印度时期眼镜蛇泛滥，政府决定为每条上交的死眼镜蛇发放赏金。初期蛇的数量确实下降，但随后当地人开始养殖眼镜蛇以领取赏金。政府发现后终止了政策，养殖者把蛇放归野外，眼镜蛇数量反而比政策前更多。
- **方法论的使用**: 作者用这两个案例展示"方案创造新获利群体"的结构：赏金让"蛇的存在"从成本变成了资产，于是有人开始生产蛇；政策终止后这批人为存量回流。法属越南河内按老鼠尾巴发赏金，捕手割下尾巴后放走老鼠让它们继续繁殖，是同一结构的另一个实例。
- **结论**: 制定激励制度时必须提防不当诱因，否则眼镜蛇和耗子泛滥成灾。作者把它与古德哈特定律并列，作为设计任何奖励机制前的必查项。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计悬赏或补贴：bug  bounty、拉新奖励、内容创作激励、节能减排补贴、举报奖励。
2. 推出治理专项：清理违规内容、打击刷单、整治安全隐患，需要预判对方会怎么"配合"。
3. 按结果付费的合作：外包按修复数量计费、咨询按节省金额分成、安全公司按发现漏洞数收费。
4. 复盘一个"越治越糟"的局面：为什么投入越多，问题越严重。
5. 评估任何"用奖励改变行为"的方案，检查是否制造了新的获利群体。

### 语言信号 (用户的话里出现这些就应激活)

- "我们打算按发现的数量给奖励"
- "这个补贴发出去，会不会有人专门来薅"
- "越治理越多了，怎么回事"
- "取消之后反而更严重了"
- "他们好像在靠这个问题赚钱"
- "cobra effect / perverse incentive / bounty / backfired"

### 与相邻 skill 的区分

- 与 `mm-goodhart-s-law` 的区别: 古德哈特定律是"指标失去信息价值"（数字与真实价值脱钩），眼镜蛇效应是"问题被放大"（客观状况变糟）。顺序上通常先有指标被刷，再有靠问题牟利的群体出现；前者是度量的病，后者是干预的病。
- 与 `mm-perverse-incentives` 的区别: 不当诱因是泛称，眼镜蛇效应是其中最具破坏性的一类——特指方案反过来放大了原问题，而不只是让行为跑偏。
- 与 `mm-hydra-effect` 的区别: 九头蛇效应强调"砍掉一个长出两个"的**反弹**（移除压力后系统反弹），眼镜蛇效应强调"有人开始生产问题"的**激励扭曲**；前者成因常在生态/系统的补偿反应，后者成因在人的套利行为。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写清"原问题"的客观度量**
   - 必须先有一个不依赖方案的基线指标（蛇的野生数量、漏洞的真实存量）。
   - 完成标准: 一句可观测的基线定义。
   - 判停条件: 若无法定义基线，先补度量，否则无法判断"更糟"。
2. **推演方案改变了谁的行为**
   - 列出所有被方案影响的人，逐个问：新方案让他多赚钱/少吃亏的方式是什么？
   - 完成标准: 得到一张"主体—新获利方式"表。
3. **检查核心判据：有没有人靠问题存在而获利**
   - 在上表中找出"问题越严重他越受益"的主体。
   - 完成标准: 明确指出是否存在该群体；若无，降级为一般的不当诱因检查。
   - 判停条件: 若不存在，可继续本 skill 的轻量版（只做退出预案）。
4. **为获利群体设计反套利约束**
   - 手段：奖励与真实结果的滞后核验、随机抽检、奖励上限、禁止"自产自销"（自己制造问题再解决）、把奖励改为与基线下降幅度挂钩而非绝对数量。
   - 完成标准: 每条套利路径至少 1 条封堵措施。
5. **预先设计退出方案**
   - 因为取消激励会让被放大的存量一次性回流，必须提前安排退出节奏与承接措施。
   - 完成标准: 写明"若终止/缩减该方案，被人为放大的存量如何处理"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 方案尚未改变任何人行为、问题也没恶化时：那是"方案无效"，不是眼镜蛇效应。
- 问题变糟由外部因素导致（季节、竞争、宏观）而非方案本身：归因错误会导致砍掉有效方案。
- 纯粹的指标失真（数字好看但事实没变）：那是古德哈特定律，问题本身没有变严重（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 作者提醒：制定激励制度时必须遵守古德哈特定律、提防不当诱因，否则"眼镜蛇和耗子泛滥成灾"——这是书中明确给出的警告，应作为设计激励的必查项而非可选项。
- 容易忽略退出环节：即使激励期有效，取消后被人为放大的存量会一次性回流，造成比干预前更糟的结果（书中明示的机制）。
- 容易把"有人钻空子"当成执行不力而加大激励力度，这会进一步放大问题（推导，非书中明示）。

### 容易混淆的邻近模型

- 与古德哈特定律：两者常被连用以至于混用。判据是——问题本身有没有变严重？变了 → 眼镜蛇效应；没变只是数字失真 → 古德哈特定律。
- 与九头蛇效应：九头蛇是"压下去又弹回来"（系统补偿），眼镜蛇是"有人开始养蛇"（人为套利）；前者需要更柔和的持续压力，后者需要改激励结构。
