# 策略与战术（strategy versus tactics）

## R — 原文 (Reading)

> 通常来说，策略是大局，战术则是细节。策略是长期的，界定最终的成功是什么样子；策略则是短期的，界定下一步要达到的目标。
>
> — 《思维模型》, 第8章 > 为谁安排什么岗位

---

## I — 方法论骨架 (Interpretation)

策略与战术是同一个行动体系的两个层级：**策略是大局、长期，回答"最终的成功长什么样"；战术是细节、短期，回答"下一步要打到哪里"**。两者缺一不可，但混层是团队最常见的失效方式——要么只有愿景没有下一步，要么天天打胜仗却离目标越来越远。

层级随岗位高度上移。**岗位越高，越需要策略而非仅战术**。这条推论直接解释了彼得原理为什么会重要：一个战术执行出色但不擅制定策略的人，被提拔到战略岗上，组织就同时失去了一个好的执行者和得到了一个糟的决策者。

关键判据是**提问方式**：眼前这句话回答的是"我们要去哪里、什么叫赢"，还是"接下来这一步做什么"。前者是策略，后者是战术。当一场讨论里所有人都只说后者，说明策略层缺失；当所有人只说前者，说明战术层缺失。

两者不是高低贵贱关系，而是配套关系。没有战术的策略是口号，没有策略的战术是瞎忙。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 会议/规划文档里全是具体动作和排期，但没人说得清"做成什么样算成功"。
2. 反过来：团队反复讲愿景和方向，落到本周要做什么就卡住。
3. 提拔或招聘中高层岗位，需要评估候选人是策略型还是战术型，判断他能否胜任更高层级。
4. 某人执行极强但升职后表现下滑，需要定位是不是策略能力没跟上。

### 语言信号

- "我们讨论半天都在抠细节，方向还没定"
- "这个愿景很好，但下周到底做什么"
- "他执行一流，但一让他定方向就懵"
- "三年后我们要成什么样"
- "别跟我讲战略，告诉我这周干啥"
- "Is this a strategy or just a tactic?" / "we're winning battles but losing the war"

### 与相邻 skill 的区分

- 与 `mm-peter-principle` 的区别: 彼得原理描述"人被提升到他不胜任的层级"这一现象；本 skill 给出其中一种具体失效机理——**战术出色但不会定策略的人被放到战略岗**。前者是现象，后者是机理之一。
- 与 `mm-north-star` 的区别: 北极星是一个**单一关键指标**，属于策略层的落地工具；本 skill 是层级划分框架，用来判断讨论落错层了没有。
- 与 `mm-ooda-loop` 的区别: 包以德循环是**战术层的快速迭代机制**（观察-判断-决策-行动），处理的是节奏；本 skill 处理的是层级。

## E — 可执行步骤 (Execution)

1. **判定当前讨论落在哪一层**
   - 完成标准: 把发言归类为"定义成功"（策略）或"定义下一步"（战术），指出当前是否只有一层。
2. **若缺策略层，先补成功定义**
   - 完成标准: 写出一句可验证的"最终成功是什么样"，含时间跨度和判定标准；不含实现路径。
   - 判停条件: 若用户明确只要执行建议，跳过本步。
3. **若缺战术层，从策略倒推下一步**
   - 完成标准: 输出一个具体的下一步目标，并说明它如何服务于第 2 步的成功定义。
4. **按岗位高度校准层级配比**
   - 完成标准: 对涉及的人给出策略/战术时间配比建议——越高的岗位策略占比越高，并据此判断当前岗位安排是否错配。
5. **评估晋升/招聘候选人的策略能力**
   - 完成标准: 用"能否独立定义成功标准、能否在信息不全时定方向"两个问题给出判断；若不能，提示战略岗风险（参见 `mm-peter-principle`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 任务已明确、只需排期和执行——强行上升到策略层是浪费。
- 需要快速反应的危机现场——此时应直接给战术动作（参见 `mm-ooda-loop`）。
- 策略已由更高层定死、本层只有执行权的场景——此时讨论策略属于越位。

### 容易误用的地方

- （推导, 非书中明示）书中未给局限，但由"岗位越高越需要策略"可推知：把"策略"当成比"战术"更高级的工作是一种误读，两者的关系是配套而非等级；一线岗位做不好战术同样致命。
- （推导, 非书中明示）用层级划分来回避决策（"这是战略问题，不急"）是常见逃避方式；模型的作用是让两层都被补齐，不是让人躲进上层。

### 容易混淆的邻近模型

- **彼得原理（peter-principle）**: 现象层面的"升到不胜任"，本 skill 解释其中一类原因。
- **北极星（north-star）**: 策略层的指标化工具，不是层级框架本身。
