# 特洛伊木马（Trojan horse）

## R — 原文 (Reading)

> "特洛伊木马"可以指任何看似无害甚至诱人，诱使你放下戒备的东西，例如礼物。

> — 《思维模型》, 第7章 > 底线在哪儿

---

## I — 方法论骨架 (Interpretation)

特洛伊木马指的是:任何看似无害、甚至诱人,从而诱使你放下戒备的东西——最典型的形态就是"礼物"。

它为什么有效:它同时利用了**互惠**与**好奇心**。礼物触发回报义务,而人对主动送上门的好处天然缺乏警惕——安全检查是针对"威胁"设计的,不是针对"好处"设计的。一旦东西被放进内部(进城、装进系统、接入内网),防御就不再适用,攻击即从内部发动。

关键判据有两个:**一是"好处"是否在你提出需求之前主动出现**(你没要,它来了);**二是接受这个好处是否需要你降低检查标准**(跳过扫描、跳过审批、跳过核实)。两项同时成立时,基本可以判定为木马。

书中还给出了一个配套的常识规则:"如果某件事听起来好得难以置信,那它通常都不是真的。"这不是严格的证明,但作为第一道过滤器极其实用。

需要注意的是,本书把木马归入"底线在哪儿"一节的黑暗模式家族——说明它的核心不是技术问题,而是**意图问题**:用伪装取代了说服。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 收到来源不明的硬件(U盘、充电宝、设备)或软件包,且未经过常规安全检查就想使用。
2. 对方在谈正事之前先给了一份意外的好处(礼品、免费试用、资源扶持),并希望你"先装上/先接入再说"。
3. 用户在设计采购、访客、供应链或终端安全流程,需要堵住"礼物入口"。
4. 用户在评估一个合作方,对方的条件好得不合常理。

### 语言信号

- "这是送您的,顺便装一下就行"
- "免费给你们的,先用起来"
- "不用走安全扫描,我们的东西绝对没问题"
- "先接入吧,合同后补"
- "条件好得我都有点不敢信"
- "free gift" / "just plug it in" / "too good to be true" / "skip the security check"

### 与相邻 skill 的区分

- 与 `mm-dark-patterns` 的区别: 黑暗模式是**上位类别**,涵盖进入、留存、退出的全流程操纵;木马专指**入口动作**——用诱人的东西绕过防御检查。极难取消订阅属于黑暗模式但不是木马;伪装成礼物的恶意程序既是木马也是黑暗模式。
- 与 `mm-bait-and-switch` 的区别: 木马的礼物是**真的给你**,危险藏在里面(你不设防);诱购的诱饵**根本不存在或不打算卖给你**,是为了把你引来再调包(你看错)。前者绕过的是安全检查,后者抬高的是心理预算。
- 与 `mm-reciprocity` 的区别: 互惠是**机制**(收到好处想回报),木马是**对该机制的武器化使用**,加上了"隐藏的第二重意图"。

## E — 可执行步骤 (Execution)

1. **确认这是一份"主动送上门的好处"**
   - 完成标准: 明确指出该好处出现在用户提出需求之前,且用户并未主动索取。
   - 判停条件: 若对方给出的是透明、常规的商务条件而非意外好处,移交常规商务评估。
2. **检查接受它是否需要降低检查标准**
   - 完成标准: 回答三问——是否需要跳过安全扫描、审批或核实?是否有"先装上/先接入,手续后补"的要求?提供方是否拒绝提供可独立验证的来源?
3. **执行"好得难以置信"过滤**
   - 完成标准: 明确回答——如果把它换成现金,这个好处是否还合理?若明显超出正常商业尺度,按书中规则先假定它不是真的。
4. **给出处理动作**
   - 完成标准: 给出具体动作——隔离环境下先检查/沙箱运行、走完既定审批再接入、拒绝任何"先接入后补手续";若已接入,则按安全事件处理(断网、取证、排查横向移动)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 意图透明、条件对等的正常商务赠礼、样品、免费试用:没有隐藏的第二重意图,不是木马。
- 用户抱怨的是"用起来容易、退出很难"——那是黑暗模式中的退出障碍,不是木马。
- 把一切好意都当恶意:长期合作方基于真实关系的正常往来不应被过度怀疑。

### 容易误用的地方

- 书中未给出木马的边界,但给出配套常识规则:"如果某件事听起来好得难以置信,那它通常都不是真的。"(书中明示)
- 木马的危险不在于礼物本身的价值,而在于它**绕过了本应执行的检查程序**——真正要守住的是流程,不是礼物。(推导,非书中明示)
- 把木马只理解为"电脑病毒"会漏掉线下形态:过分热情的合作方、条件好得离谱的投资条款,结构相同。(推导,基于书中将木马归入黑暗模式的线下形态)

### 容易混淆的邻近模型

- 与诱购(bait-and-switch): 礼物是真的(危险藏在里面) vs 诱饵是假的(为了引你进来调包)。
- 与黑暗模式(dark-patterns): 入口手法与整体类别。
