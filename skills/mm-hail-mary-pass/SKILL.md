# 孤注一掷（Hail Mary pass）

## R — 原文 (Reading)

> 你也可以采用"孤注一掷"（Hail Mary pass，直译"万福马利亚传球"）战术。也就是说，为了成功铤而走险，做最后一次努力。
>
> — 《思维模型》, 第7章 > 终局

---

## I — 方法论骨架 (Interpretation)

"Hail Mary pass" 来自美式橄榄球：比赛快结束时落后方扔出一记超长距离的绝望传球，成功率极低，接到的概率很小——因为此时输已成定局，不传也是输，传了还有一线希望。

它的结构是一个**特定的期望值情形**：

- 常规方案的期望值 ≈ 0（或已确认失败）；
- 这一搏的成功率低（可能 5%-15%）；
- 但**失败的额外代价也接近于零**——反正不这么做也是输。

注意第二点最容易被忽略："失败代价低"不是因为它不冒险，而是因为**不做的基线已经是最差结果**。如果放弃这一搏你还能保住 70 分，那就不是 Hail Mary，那是把 70 分押上去赌 100 分——是赌博，不是战术。

关键判据只有一条：**如果这一搏失败，我的处境会比不做它更糟吗？** 不会——才成立；会——那你在赌，不是在搏。

作者同时给出它的反面提醒：有时你不得不按当时能想到的最佳策略撤退，即使退场不够优雅；但"一条路走到头"长期结果更糟。也就是说，孤注一掷是**终局里的合法选项，不是中局的常规策略**——把它当成日常打法，长期必输。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 投标/竞标截止前，常规方案已无望，只剩一个非常规提案可以试。
2. 产品在关停边缘，团队讨论要不要做一个冒险的大改版搏一次。
3. 求职/申请只剩最后一所学校或一家公司，在想要不要发一封非常规的邮件。
4. 关系已濒临结束，用户考虑做最后一次大动作挽回。
5. 用户在"再赌一把"和"体面收手"之间摇摆，需要判断基线是不是真的已经最差。

### 语言信号 (用户的话里出现这些就应激活)

- "反正也没别的办法了，搏一把吧"
- "死马当活马医"
- "就剩最后一次机会了"
- "不试也是输，试了还有点希望"
- "要不要赌一把"
- "Hail Mary / last-ditch effort / long shot / nothing left to lose"

### 与相邻 skill 的区分

- 与 `mm-endgame` 的区别: 终局是**阶段框架**（剩余变量少、应锁定收益或最小化损失）；孤注一掷是终局里可选的一种**具体手段**。先判定处于终局，再判断要不要搏。
- 与 `mm-exit-strategy` 的区别: 退出策略是体面收手、保住剩余价值；孤注一掷是不收手、押最后一次。二者常常是同一个时刻的两个选项，需要做对照比较。
- 与 `mm-burn-the-boats` 的区别: 破釜沉舟是主动自绝退路以**提升执行力**（让团队只能向前），是在过程中用的；孤注一掷是在最后时刻用的一次性动作，不改变团队结构。
- 与 `mm-expected-value` 的区别: 期望值分析是通用核算工具；本 skill 是它在"基线已为最差"这一特殊情形下的应用，重点是识别失败代价是否真的为零。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认基线真的已经是最差**
   - 完成标准: 明确写出"如果什么都不做，最可能的结果是什么"。若这个结果尚可接受（不是失败），说明这不是 Hail Mary，跳到步骤 5 改用期望值比较。
2. **穷举常规方案并确认已穷尽**
   - 完成标准: 列出至少 3 个尚未尝试的常规动作并说明为何无效。列不出 3 个，说明还没到孤注一掷的时候，回到常规方案。
3. **核失败代价，而非只看成功率**
   - 完成标准: 明确列出这一搏失败的额外损失（钱、时间、声誉、关系、机会），并回答"这些损失在不做的情况下会不会同样发生"。若会——成立；若不会——判为赌博，停止。
4. **限定投入上限与止损时点**
   - 完成标准: 给这一搏设定明确的时间盒和资源上限（例如"两周、不超过 X 元/人天"），到点即停，不追加。
   - 判停条件: 若用户拒绝设定上限，说明这不是战术而是失控投入，暂停推进。
5. **准备不优雅的撤退方案**
   - 完成标准: 写下"如果失败，我在 48 小时内做什么"的具体动作清单（通知谁、保住什么、如何收尾）。作者提醒：有时你不得不按当时能想到的最佳策略撤退，即使退场不够优雅。
6. **执行后立刻复盘**
   - 完成标准: 无论成败，记录这一搏的实际成功率与代价，用于校准未来判断——避免把"上次赌赢了"当成"这种做法可行"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 还有多个未尝试的常规选项——此时应做常规努力，而不是跳到最后一搏。
- 失败的额外代价很高（押上房子、健康、核心关系、他人利益）——这是赌博，不是战术。
- 用户只是厌倦了常规努力、想用一个大动作逃避枯燥的执行——孤注一掷救不了执行问题。
- 可以体面退出并保住大部分价值时——作者明确说"一条路走到头"长期结果更糟。

### 容易误用的地方

- 书中明示：作者提醒有时你不得不按当时能想到的最佳策略撤退，即使退场不够优雅；但"一条路走到头"长期结果更糟。
- （推导, 非书中明示）最常见的误用是**把基线误判为最差**——因为焦虑会让人觉得"不做就完了"，而实际还有可接受的退路。建议先做步骤 1。
- （推导, 非书中明示）幸存者偏差：我们看到的成功案例都是搏赢的，搏输的人不会写复盘，这会系统性高估这一战术的价值。
- （推导, 非书中明示）连续使用孤注一掷（每次都"最后一搏"）说明规划出了问题，应回到中局的布局能力，而不是反复依赖绝招。

### 容易混淆的邻近模型

- **破釜沉舟（burn the boats）**: 过程中主动自绝退路以提升执行，改变的是团队激励结构。
- **退出策略（exit strategy）**: 同一时刻的另一个选项——体面收手 vs. 最后一搏，应先比较再选。
