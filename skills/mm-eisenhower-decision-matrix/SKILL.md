# 艾森豪威尔决策矩阵（Eisenhower Decision Matrix）

## R — 原文 (Reading)

> 重要的事通常不紧急，紧急的事通常不重要。
>
> — 《思维模型》, 第3章 > 你能做好任意一件事

---

## I — 方法论骨架 (Interpretation)

这个矩阵用两个维度——紧不紧急、重不重要——把待办切成四块，每块对应一种处置方式：

- **紧急且重要（第一象限）**：立即做。
- **重要但不紧急（第二象限）**：重点投入。深度工作、学习、健康、关系、长期规划都在这里，它才是通向长远目标最快的路。
- **紧急但不重要（第三象限）**：委派、外包，或者干脆忽略。
- **不紧急也不重要（第四象限）**：尽量少花时间。

为什么值得专门用一个模型？因为人的默认行为是错的。紧急的事自带压力和截止时间，会自动抢占注意力；重要的事往往没有 deadline，于是被无限期推后。结果是第三、四象限的干扰持续挤占第二象限，你永远在做"看起来必须马上做"的事，重要的事一件也没完成。

这个模型的真正判据不是分类本身，而是**你有没有守住第二象限**。分类是手段，把时间真的投给"重要不紧急"才是目的。

## A1 — 书中的应用 (Past Application)

### 案例: 紧急医疗事故 vs 消磨时间的工作

- **问题**: 面对一大堆待办，人们往往凭"哪个在催我"来决定顺序，导致时间分配与真实重要性严重脱节。
- **方法论的使用**: 作者用四象限给事务定位——第一象限举例是处理紧急医疗事故（紧急且重要，立即做）；第四象限举例是消磨时间的工作、大多数电子邮件、无须动脑的手机游戏（既不紧急也不重要，应尽量少花时间）。
- **结论**: 判断标准不是"急不急"，而是"重不重要"。多数人时间被第三、四象限吃掉，应该主动把资源挪回第二象限。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户列出一堆待办/需求/任务，问"先做哪个""这些怎么排"。
2. 用户长期感觉很忙但没进展，或总在救火，怀疑自己的时间分配有问题。
3. 用户在考虑某件事该不该自己做、要不要交给别人或外包，需要一个判断依据。

### 语言信号 (用户的话里出现这些就应激活)

- "事情太多，不知道先做哪个"
- "每天都在救火，重要的事一直没动"
- "这个要不要我自己做，还是交给别人"
- "哪些事其实可以不做"
- "how do I prioritize all this"

### 与相邻 skill 的区分

- 与 `mm-parkinson-s-law-of-triviality` 的区别: 琐碎定律处理**群体讨论**中重要议题被冷落的现象；矩阵处理**个人/组织待办**的排序与处置方式。
- 与 `mm-deep-work` 的区别: 矩阵把"重要不紧急"挑出来，深度工作解决挑出来之后怎么真正推进它。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把所有待办列全，不要边列边排**
   - 完成标准: 得到一份不短于用户实际事务量的清单，每条是一个可交付的动作，不是模糊主题。
2. **对每条做两个判断：紧不紧急、重不重要，分别填入四象限**
   - 完成标准: 每条都落在唯一象限里。"重要"的判据是对长期目标有没有实质贡献；"紧急"的判据是有没有真实截止时间或立即后果。
   - 判停条件: 若超过一半条目无法判断重要性，先帮用户澄清目标（可转向塞尔定律/目标澄清），不要硬分类。
3. **按象限给出处置：第一立即做、第二排进日程、第三委派或忽略、第四删减**
   - 完成标准: 每个象限都有明确的下一步动作；第三象限至少给出委派对象或"不做的理由"。
4. **检查第二象限是否被真正占住，并把它写进日程**
   - 完成标准: 日程中存在明确分配给第二象限事项的重复时段，而不是"有空再说"。
5. **给出防止第三、四象限回灌的措施**
   - 完成标准: 至少 2 条（如消息批量处理、会议准入标准、邮件默认不即时回复）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有一件事可做、不存在排序问题时，套四象限是形式主义。
- 需要精确比较投入产出或做资源分配决策时，矩阵只能给出粗分类，应转向成本收益分析、机会成本等定量模型。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示的局限：前提是你能把各项活动正确归入象限，而判断"什么重要"本身很难。作者随即引入塞尔定律和帕金森琐碎定律来辅助判断——说明这个矩阵的短板正在于"重要性"的主观性。
- （推导, 非书中明示）"紧急"常被误判为"重要"：别人催的事天然显得紧急，会把真正的第二象限继续挤掉。

### 容易混淆的邻近模型

- 与 2×2 矩阵（2-2-matrices）混淆：2×2 是通用的图形化分类工具，本矩阵是它的一个具体实例，带有明确的处置规则。
- 与帕累托法则（pareto-principle）混淆：帕累托找的是"少数高产出的那一撮"，矩阵给的是"按紧急/重要定处置方式"。
