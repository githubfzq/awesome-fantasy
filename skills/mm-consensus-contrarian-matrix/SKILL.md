# 顺势-逆势矩阵（consensus-contrarian matrix）

## R — 原文 (Reading)

> 可以用2×2的矩阵来解释投资行业。在一个维度上，你可能投对了，也可能投错了。在另一个维度上，你可以选择顺势操作，也可以选择逆势操作。
>
> — 《思维模型》, 第9章 > 秘密武器

---

## I — 方法论骨架 (Interpretation)

很多人以为，做对选择就能赚钱。这个矩阵说明这是错的。

把下注拆成两个独立维度。横轴是**结果**：你可能对，也可能错。纵轴是**立场**：你选择了和大家一样的方向（顺势），还是相反的方向（逆势）。四个格子：

- **顺势且正确**：你赢了，但赔率极低。因为所有人都押同一匹马，赌注涌入会把赔率压到几乎无利可图。
- **顺势且错误**：最糟的一格——你亏钱，而且你不是一个人在亏。
- **逆势且错误**：很常见。大多数人之所以不去逆势，恰恰是因为逆势通常是错的。
- **逆势且正确**：唯一产生超额回报的格子。赔率高，因为几乎没人和你抢这块蛋糕。

为什么赔率会随人数变化？因为**赔率本身反映的就是有多少人同意你**。众包出来的赔率，就是大众对这个方向概率的集体估计。所以"大家都看好"这个事实，已经通过赔率提前把你的收益抽走了——你买的是已经被定价过的正确。

那么逆势什么时候才划算？答案不是"与众不同"，而是一个严格的条件：**你掌握了别人不了解的信息，因此你知道真实概率远高于大众的估计**。这才是逆势的唯一正当理由。没有额外信息支撑的逆势，只是在第四格通往第三格（逆势且错误）的路上。

书里引用贝索斯的提醒非常重要：**"你只需要记住，逆势之人通常是错的。"** 芒格则从另一头说，模仿大众会引起均值回归——跟着人群走长期只能拿到平均回报。两句话合起来才是完整的结论：模仿大众拿不到超额收益，但逆势本身也不提供正确性，唯一值钱的是你的**信息优势**。

关键判据一句话：**我之所以和大众不同，是因为我知道什么别人不知道的事？** 如果答不上来，你大概率处在"逆势且错误"这一格。

## A1 — 书中的应用 (Past Application)

### 案例: 风险投资界的 eBay 下注
- **问题**: 要不要投资一个看起来很荒唐的项目？当时风险投资界普遍认为投 eBay 是疯了——他们用"卖豆袋公仔"（Beanie Babies 这类收藏品）来描述这门生意，语气里写满了轻视。在共识看来，这不值得下注。
- **方法论的使用**: 这正是矩阵的第三格 vs 第四格之间的判断：牌桌上的大多数人（顺势方）认为它会失败，所以赔率极低几乎无人下注；而少数下注的人处在逆势位置。这里的关键不在于"反着来"的勇气，而在于这些投资人对这门生意的**真实运行机制有不同于大众的判断**——他们看到的是一个可被验证的市场结构，而不是一个"收藏品网站"的标签。
- **结论**: 那些没有被共识吓退的公司赚了大钱。作者用这个例子说明矩阵中最有价值的一格长什么样：**在别人不敢下注的地方，用你掌握的额外判断力下注，才有可能拿到超额回报**。而这也是为什么作者紧接着就引用贝索斯的话泼冷水——逆势之人通常是错的，eBay 是幸存下来的那一个，不是常态。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **准备下一个明显的赌注（投资、选题、职业方向、公司战略）**: 用户有一个明确判断并准备投入，需要先问"有多少人和我站在一起"，因为这直接决定了赔率。
2. **因为"所有人都在做"而犹豫要不要跟**: 用户面临 FOMO，需要看清顺势的收益上限已经被定价掉了。
3. **正在坚持一个没人看好的方向，怀疑自己**: 用户需要一个诚实的检验——他到底是掌握了额外信息，还是单纯在逆势犯错的路上。
4. **评估某个"热点"机会值不值得进**: 用户想追热点，需要知道拥挤程度就是负收益本身。

### 语言信号 (用户的话里出现这些就应激活)

- "现在所有人都看好这个赛道，我要不要跟？"
- "我觉得他们全都搞错了，只有我看明白了"
- "没人看好我的项目，但我坚信能成"
- "这个机会是不是已经太拥挤了"
- "别人都说不行，我要不要坚持"
- "这个领域已经很热了，现在进还有肉吃吗"
- "Everyone is betting on this." / "Nobody believes in this idea." / "Is it too late to get in?" / "I think the consensus is wrong."

### 与相邻 skill 的区分

- 与 `mm-2-2-matrices` 的区别: 2×2 矩阵是**通用工具**（怎么构造和使用二维分类），顺势-逆势矩阵是它在一个具体问题上的**实例**。用户想学怎么建矩阵用前者，用户要判断一次下注的赔率用后者。
- 与 `mm-consequence-conviction-matrix` 的区别: 后果-信心矩阵问的是"后果有多严重 × 我有多确信"，用于决定**要不要快速行动**；顺势-逆势矩阵问的是"我对不对 × 我和大众是不是同向"，用于判断**赔率高不高**。一个是行动节奏，一个是仓位回报。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确这次下注的具体断言与时间表**
   - 完成标准: 把"下注"写成一句可证伪的陈述（"X 会在 Y 时间内达成 Z"）。含糊的信念无法定位到矩阵的哪一格。
   - 判停条件: 若无法写出可证伪的断言，说明还没有形成判断，先回去补信息。
2. **测量共识位置**
   - 完成标准: 给出当前市场/圈内对该断言的主流意见证据（价格、赔率、融资热度、从业者普遍态度、搜索热度），并把共识强度粗略定为"几乎一致 / 多数 / 分歧明显 / 几乎无人认同"。
3. **把结论落到四个格子之一**
   - 完成标准: 明确说出用户当前在"顺势/逆势 × 对/错"的哪一格，并据此说明期望回报结构——顺势正确则空间有限，逆势正确则赔率最高，顺势错误与逆势错误都是亏损，但逆势错误往往更孤独、更容易被过早证伪。
4. **做信息优势审查（最关键的一步）**
   - 完成标准: 要求用户回答"我凭什么知道别人不知道的东西？"，并列出具体条目。逐一检查每条是否真的只有他知道、是否可被对手在一周内补全。
   - 判停条件: 若审查后没有任何一条成立，直接告知：此时逆势是增大风险而非增大收益，建议改为顺势或缩小仓位。这是贝索斯"逆势之人通常是错的"的直接应用。
5. **据此给出仓位与退出建议**
   - 完成标准: 给出与格子匹配的仓位建议（逆势且信息优势成立 → 值得重仓但需分批；顺势 → 期望有限，只值配置的钱；无信息优势的逆势 → 极小仓位或不做），并写下"如果我错了，会先看到什么证据"的可观测证伪信号。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **没有"胜负"可言的主观选择**（喜欢什么颜色、和谁结婚）: 矩阵依赖"对/错"这个维度，主观偏好不适用。
- **低风险的可逆日常决策**: 收益本来就小，没有分析赔率的价值，反而制造决策负担。
- **用户正在寻求情感支持而非决策建议**: 直接套"你可能是错的"会变成否定；先接住情绪，再决定是否使用本模型。

### 书中警告的失败模式 / 容易误用的地方

- **书中明示**: 贝索斯提醒"你只需要记住，**逆势之人通常是错的**"——逆势不等于正确，绝大多数逆势下注是在第三格而不是第四格。
- **书中明示**: 芒格指出模仿大众会引起**均值回归**——长期跟着人群做，你只能拿到平均回报，但这不等于反向操作就能赚钱。
- （推导, 非书中明示）**把"我觉得他们错了"当成信息优势**: 这是最常见误用。信息优势必须是**具体、可陈述、别人确实没有**的东西，而不是对大众判断的否定感。E 段第 4 步就是为拦住这个误用设计的。
- （推导, 非书中明示）**幸存者偏差污染**: 人们记得 eBay，不记得同时期一百个没人看好且真的失败的项目。用个别逆势成功案例论证逆势策略，本身就是错的。

### 容易混淆的邻近模型

- **逆向思维（inversion）**: 逆向思维是一种思考技巧（从反面推演问题，如"怎样保证失败"），顺势-逆势是**关于市场共识的定位**；两者名字都带"逆"，但完全不相干。
- **平均值回归（regression-to-the-mean）**: 说的是极端表现之后会回到平均；这里引用它只是用来批评盲目模仿大众，它的核心命题与本模型的赔率结构无关。
