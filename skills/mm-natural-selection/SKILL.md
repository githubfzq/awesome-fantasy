# 自然选择（natural selection）

## R — 原文 (Reading)

> 深色斑点蛾的兴衰属于自然选择（natural selection）。自然选择是推动生物进化的进程。
>
> — 《思维模型》, 第4章 > 开篇（师法自然）

---

## I — 方法论骨架 (Interpretation)

自然选择的机制是一个筛选循环：群体中存在差异；某些性状在当前环境下带来存续与繁殖优势；携带这些性状的个体活下来并繁衍，于是这些性状在基因库中的占比逐代上升。

关键在于**优势是相对于环境定义的**。环境一变，原本中性的性状可能突然变成优势，也可能变成劣势——这就是为什么"好不好"没有绝对答案。

同样的筛选逻辑不只作用于生物，也作用于社会里的创意、实践和产品：它们需要适应不断变化的品位、规范与技术。作者举了一个直白的例子：把 50 年前大获成功的公司、电影、书籍原样搬到今天首发，大部分不会成功——不是它们变差了，是环境变了。

判据是：在当前环境下，这个性状/做法是否带来存续与传播上的优势。存活下来的不是最聪明或最强壮的，而是最能适应变化的。

---

## A1 — 书中的应用 (Past Application)

### 案例: 曼彻斯特斑点蛾

- **问题**: 为什么同一个物种中，深色个体的占比会在几十年里发生近乎彻底的反转？
- **方法论的使用**: 工业革命期间，煤炭污染把树皮熏深，原本显眼（易被鸟捕食）的深色蛾反而获得了伪装优势，占比从 0.01% 升到 98%；1956 年《清洁空气法案》之后树皮变浅，选择压力反转，趋势也随之逆转。作者借此说明优势由环境定义。
- **结论**: 兴衰不取决于性状本身的"好坏"，而取决于它与当前环境的匹配；作者进一步指出，把 50 年前大获成功的公司、电影、书籍搬到今天首发，大部分都不会成功。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在问"为什么这种做法/产品在这个环境里大行其道，换到我们这儿就不灵"。
2. 用户所处的环境发生了明显变化（政策、技术、用户习惯、平台规则），想判断原有做法还能不能活。
3. 用户在解释某个现象为何盛行或消亡，需要一个结构性解释而不是归因于个人能力。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么这套做法在那边有效，在我们这就不行"
- "环境变了，原来的经验不管用了"
- "这个产品是不是已经被淘汰了"
- "适者生存，不适应就被淘汰"
- "why did this work back then but not now"

### 与相邻 skill 的区分

- 与 `mm-lindy-effect` 的区别: 林迪效应回答"它还能存在多久"（存在越久预期寿命越长）；自然选择回答"它为什么在当前环境下被选中或淘汰"。
- 与 `mm-disruptive-innovations` 的区别: 颠覆性创新描述新进入者如何从边缘颠覆在位者，是具体路径；自然选择是更一般的筛选机制。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定被筛选的对象和它所处的环境**
   - 完成标准: 明确指出"谁在被筛选"和"环境是什么"（市场、平台、组织、文化）。
2. **列出环境目前奖励什么性状（选择压力是什么）**
   - 完成标准: 写出至少 3 条当前环境实际在奖励的特征，用可观察的证据支撑，而不是主观评价。
3. **判断对象当前携带的性状与选择压力是否匹配**
   - 完成标准: 给出"匹配 / 中性 / 不匹配"的明确结论及理由。
   - 判停条件: 若环境近期没有发生实质变化，本模型解释力有限，退出。
4. **找出环境发生了什么变化，导致原有优势失效或反转**
   - 完成标准: 明确指出变化点及其时间，并说明它如何改变了选择方向。
5. **给出适应方向：应该改变哪些性状，以及代价**
   - 完成标准: 至少 2 条具体的适应动作，并说明各自需要的投入与可能的取舍。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 涉及道德与价值判断的场合（要不要保留某种文化、如何对待弱势群体），"适者生存"不能作为规范依据。
- 短期波动与偶然事件主导的结果（一次运气、一场黑天鹅），套用选择机制会给出过度合理的解释。

### 书中警告的失败模式 / 容易误用的地方

- 书中未提生物学局限，但强调"适应性"才是关键——存活下来的不是最聪明或最强壮的，而是最能适应变化的。
- （推导, 非书中明示）容易与幸存者偏差叠加：只看到活下来的样本并归纳其"优势性状"，忽略了同样具备该性状却死掉的那些。

### 容易混淆的邻近模型

- 与幸存者偏差（survivorship-bias）混淆：幸存者偏差是**观察错误**（只看活下来的样本），自然选择是**筛选机制**本身。
- 与反脆弱（antifragile）混淆：反脆弱指能从波动中获益，适应变化是它的一个子集，本模型只讲被筛选，不讲从中变强。
