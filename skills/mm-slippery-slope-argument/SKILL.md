# 滑坡论（slippery slope argument）

## R — 原文 (Reading)

> 这个理论指出，一件小事会导致无法避免的连锁反应和（在提出这一观点的人看来）糟糕的结果。

> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

滑坡论主张:**一件小事会不可避免地引发连锁反应,最终导致糟糕的结果**。

它通常被当作谬误,原因是**链条上的每一环都不是必然发生的**。整个论证的强度取决于最弱的那一环,而只要有一环只是"有可能"而非"必然",整条链就不是不可避免的,只是可能的。把"可能发生"说成"无法避免",正是这个论证最典型的跳跃。

但书里给了一个很重要的修正,这是本模型最容易被忽略的部分:**它不是非黑即白的**。作者用枪支管制的例子说明——"如果允许枪支管制,最终政府会夺走所有枪支"这个说法极不可能成立,但禁止突击步枪**很可能导致**加强对类似武器的管制。也就是说,**部分骨牌确实会倒**。

所以正确的用法不是"这是滑坡谬误,驳回",而是**把链条拆开,逐环评估概率与机制**:
- 哪一环有真实的机制支撑(利益驱动、法律先例、技术耦合、行为惯性)?
- 哪一环只是联想?
- 即使链条成立,会滑到什么程度,是滑到第二步还是滑到底?

判据是:**不要问"会不会滑坡",要问"能滑到第几步、每一步靠什么机制推动"。** 整体接受和整体否定都是偷懒。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在讨论规则、政策或先例,有人说"这个口子一开就收不住了"。
2. 用户自己在论证一个风险,需要检验自己是不是在滑坡。
3. 用户在决策时面对"小让步会不会导致大失控"的担心,需要把它拆成可评估的链条。
4. 用户在辩论中遇到对方用极端后果来吓阻当下的小改动。

### 语言信号

- "一旦开了这个先例,以后就收不住了"
- "下一步他们就要……了"
- "这个口子不能开"
- "迟早会变成……"
- "那以后是不是谁都可以"
- "slippery slope" / "thin end of the wedge" / "where does it end" / "opens the door to"

### 与相邻 skill 的区分

- 与 `mm-domino-effect` 的区别: 多米诺骨牌效应描述**一个真实的、有机制的连锁反应**(倒一个推倒下一个,物理或结构上有耦合),滑坡论是**一个论证形式**,常被用来宣称连锁反应不可避免;前者要评估机制,后者要先拆链条再评估机制。
- 与 `mm-broken-windows-theory` 的区别: 破窗理论主张**容忍小恶会鼓励重罪**(是关于秩序信号的主张,效果本身存疑),滑坡论是关于**论证有效性**的检验工具;破窗常被用来支撑滑坡式论证。
- 与 `mm-cascading-failure` 的区别: 连锁故障是**系统内部**的级联失效(有明确的耦合与工程机制),滑坡论多用于**规则、行为、政策**领域的主观推演。

---

## E — 可执行步骤 (Execution)

1. **把论证拆成显式的链条**
   - 完成标准: 写出 A → B → C → … → Z 的每一步,每一步必须是一个可判断的命题;对方没说清的环节要补出来并要求其确认。
2. **逐环标注机制与概率**
   - 完成标准: 每一环标注"靠什么机制推动"(利益、先例、技术耦合、模仿、惯性)与"大致概率";没有任何机制支撑的环节直接标记为联想。
3. **找出最弱的一环并定位"滑到哪里"**
   - 完成标准: 明确指出最弱环节,并回答"即使成立,最可能停在第几步"——按书中的提醒,部分骨牌确实会倒,不要一概驳回。
4. **给出可操作的刹车点**
   - 完成标准: 若链条部分成立,给出阻断措施(设边界条件、加审核、限期、可逆化、明确例外),把"滑坡"变成"可控的斜坡";若链条不成立,明确说明为什么不成立。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 链条每一环都有明确机制与实证支撑(工程级连锁故障、法律上的明确先例效应):那是真实级联,不是滑坡论证。
- 把它当成万能反驳武器:书中明确指出部分骨牌确实会倒,一律按谬误驳回会漏掉真实风险。(书中明示)
- 对方只是在列举风险清单(多件事可能各自发生),而非主张必然连锁:那不构成本模型讨论的对象。

### 容易误用的地方

- 作者指出:禁止突击步枪极不可能导致政府取缔所有枪支,但很可能导致加强类似武器管制——**部分骨牌确实会倒**。(书中明示)
- 反向误用:因为滑坡论常被误用,就把所有"会有后续影响"的担心都斥为滑坡。(书中明示的直接推论)
- 只看结论是否极端,不拆链条:极端结论也可能是真的,判断必须落在环节上。(推导,非书中明示)

### 容易混淆的邻近模型

- 与多米诺骨牌效应(domino-effect): 论证形式 vs 真实的连锁机制。
- 与破窗理论(broken-windows-theory): 检验工具 vs 一个存疑的秩序主张。
