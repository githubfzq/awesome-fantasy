# 皮格马利翁效应（Pygmalion effect）

## R — 原文 (Reading)

> 皮格马利翁效应（Pygmalion effect）这个模型指的就是，当你试图满足别人对自己的期待时，别人的期待值越高，你的表现提升越明显。
>
> — 《思维模型》, 第8章 > 释放潜能

---

## I — 方法论骨架 (Interpretation)

他人对你的期待越高，你为符合这个期待而提升的表现就越明显。它属于**自我实现的预言**（self-fulfilling prophecy）家族：期待改变期待者的行为（给更多机会、更多反馈、更多耐心），进而改变被期待者的实际表现。

反向是**魔像效应（golem effect）**：期待降低导致表现变差。这意味着期待不是一个中性变量——低期待同样在起作用，只是方向相反。

实证支持相当强：2009 年《领导力季刊》荟萃分析综合 200 项研究（美国国防部资助）发现，寄予高期待的皮格马利翁式领导风格，比传统方法、魅力型、激励型、变革型、愿景型领导技巧都更有效。

但要注意作者给出的限定：**高期待本身不足以让人发挥全部潜能**，可是低期待或无期待会严重妨碍其发挥。这是一个"必要不充分"的关系——你可以用它阻止伤害，但不能指望单靠它创造奇迹。

所以操作上的结论是：**高期待须配支援系统**。书中明确警告：对人寄予高期待并不断敦促其接受挑战，可能使其筋疲力尽或焦虑不安。

关键判据：我对这个人表达出来的期待，有没有配套的实质投入（时间、反馈、资源）？没有，就只剩压力。

### 案例: 200 项领导力研究的荟萃分析

- **问题**: 书中未给企业案例，引用的是美国国防部资助的 200 项领导力研究荟萃分析。

- **结论**: 寄予高期待的皮格马利翁式领导风格，比传统方法、魅力型、激励型、变革型、愿景型领导技巧都更有效。作者同时提醒：初始教学环境下的研究饱受批评，而在组织领导等其他环境中效果显著。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 管理者/老师/家长意识到自己可能对某个人期待过低，需要校准。
2. 想通过期待与信任提升团队产出，但担心变成压力。
3. 某个人长期被贴"不行"的标签，表现确实越来越差。
4. 用户在评估"我是不是对他要求太低了/太高了"。

### 语言信号 (用户的话里出现这些就应激活)

- "他其实可以做得更好，但我一直没敢交给他"
- "我早就说他不行，果然不行"
- "我对他期望很高，但他总达不到"
- "是不是我对他们要求太低了"
- "新人我一般先安排简单活儿"
- "high expectations / self-fulfilling prophecy"

### 与相邻 skill 的区分

- 与 `mm-golem-effect` 的区别: 魔像效应是同一枚硬币的反面（低期待导致表现变差）；两者机制相同、方向相反，实际使用时应一起检查。
- 与 `mm-fixed-mindset-versus-growth-mindset` 的区别: 成长型思维是**自我信念**通道，靠改变本人对能力的看法；皮格马利翁效应是**他人期待**通道，靠改变环境对个体的投入。
- 与 `mm-observer-expectancy-bias` 的区别: 观察者期望偏差是研究者/观察者**误读结果**使其符合预期（测量污染）；皮格马利翁效应是期待**真实改变**了被期待者的表现。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘查自己对该人的实际期待水平**
   - 完成标准: 写出 2-3 条可观察证据（交给他什么难度的任务、多久反馈一次、犯错时怎么处理），据此判断期待是高是低。
2. **检查是否存在魔像效应**
   - 完成标准: 明确回答"我有没有用低期待对待某人，而他的表现也随之变差"。
3. **把期待显式表达出来**
   - 完成标准: 给出一句具体的高期待表述（指向"我相信你能做到 X"这类具体任务，而非空洞的"你很优秀"）。
4. **配套支援系统**
   - 完成标准: 列出随期待一起给到的具体支持（时间、反馈频率、资源、容错空间）——书中明确要求。
   - 判停条件: 若无法提供任何支援，明确告知用户：只提高期待而不给支援会导致筋疲力尽或焦虑不安，此时不应上调期待。
5. **设定疲劳监测点**
   - 完成标准: 给出观察指标（加班时长、情绪信号、主动求助频率）与复查节点，防止高期待演变为过度施压。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 期待需要匹配真实能力上限——对明显超出物理/资质限制的目标表达高期待只会造成羞辱。
- 无法提供任何支援时（书中明确：高期待须配支援系统）。
- 用它给"压榨"背书：不断敦促某人接受挑战会使其筋疲力尽或焦虑不安。

### 书中警告的失败模式 / 容易误用的地方

- 初始教学环境下的研究饱受批评，其他环境（如组织领导）效果显著——不要把它当成放之四海皆准的教育万能药。
- 对人寄予高期待并不断敦促其接受挑战，可能使其**筋疲力尽或焦虑不安**，需配套支援系统。
- **高期待本身不足以让人发挥全部潜能**——它能防止低期待的伤害，但不能替代能力建设。
- （推导, 非书中明示）公开的"高期待标签"在同侪间会产生比较压力，可能让未被点名的人落入魔像效应。

### 容易混淆的邻近模型

- **魔像效应（golem effect）**: 反向机制，应成对检查。
- **观察者期望偏差（observer expectancy bias）**: 测量被污染 vs 表现被真实改变。
