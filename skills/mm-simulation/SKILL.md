# 仿真模拟（simulation）

## R — 原文 (Reading)

> 接下来，你可以用软件来模拟系统，也就是所谓的“仿真模拟”（simulation）。事实上，通过现有的软件，你可以在电脑屏幕上绘制系统的示意图，然后转换成能够运作的仿真模拟。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

仿真模拟是把系统思考的产物变成能跑的东西：先用软件在屏幕上**画出系统示意图**，再把它**转换成能够运作的模型**，设定初始条件，然后观察这个系统随着时间如何演化。

它解决的是静态分析的盲区。决策树和成本收益分析都是快照，它们默认世界不动；但真实系统里，你今天的动作会改变明天的状态，而明天的状态又决定后天的选择。仿真模拟就是让时间真正跑起来。

它的独特价值在于能让你**实时观察系统如何适应外部变化**——比如勒夏特列原理那样的自行调整过程，肉眼在静态推演中很难看出来。这直接提升你预测黑天鹅与其他事件的能力。

作者推荐两款在线软件：Insight Maker 和 True-World。输出的概率与结果不是终点，可以再喂给决策树或成本收益分析做决策。

关键判据：这个系统是否存在"状态随时间累积、且当前状态影响下一步"的特征？有，静态工具就不够，得上仿真。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在分析一个有反馈和延迟的系统（库存补货、排队积压、用户增长与留存），静态公式算不准。
2. 用户想知道某项改变推行后，系统在半年/一年内会怎么演化，而不是只看即时效果。
3. 用户想观察系统如何自行适应外部冲击（价格调整后市场如何回摆）。
4. 用户要为黑天鹅或极端情形做预测，需要看系统在压力下的动态行为。

### 语言信号
- "这个系统会怎么演化"
- "跑一下看看长期会变成什么样"
- "静态公式算出来的和实际差太多"
- "调整之后市场会怎么回摆"
- "能不能建个模型模拟一下"
- "simulate it" / "run a model" / "system dynamics"

### 与相邻 skill 的区分
- 与 `mm-systems-thinking` 的区别: 系统思考是**先把系统看全**的视角与画图动作，仿真模拟是**让画好的图随时间跑起来**的工具；前者产出结构，后者产出时间轨迹。
- 与 `mm-monte-carlo-simulation` 的区别: 蒙特卡洛是**多次独立运行、每次随机**，用来逼近结果的概率分布；普通仿真模拟是**单次运行看系统演化**。前者给分布，后者给过程。
- 与 `mm-decision-tree` 的区别: 决策树是静态的概率与收益快照，仿真模拟给的是随时间演化的轨迹；仿真的输出可以再喂给决策树。

## E — 可执行步骤 (Execution)

1. **先画出系统示意图**
   - 用纸或软件（书中推荐 Insight Maker、True-World）列出要素、相互作用与反馈回路。
   - 完成标准: 得到一张含至少 3 条反馈回路的系统图。
   - 判停条件: 若系统是静态的、无时间累积效应，停止本 skill，改用决策树或成本收益分析。
2. **把图转成可运行模型**
   - 给每条关系配上量化规则（速率、阈值、延迟）。
   - 完成标准: 模型能跑通，初始状态与已知历史数据大致吻合。
3. **设定初始条件并运行**
   - 完成标准: 跑出系统随时间变化的轨迹，标出关键转折点。
4. **改变外部条件，观察系统如何自行调整**
   - 施加冲击（涨价、断供、需求翻倍），观察系统是否部分抵消该变化（勒夏特列原理）。
   - 完成标准: 至少跑 3 组不同外部条件，写出系统适应的模式与滞后时间。
5. **把输出喂给下游决策工具**
   - 完成标准: 把仿真得到的概率与结果作为输入，接入决策树或成本收益分析，得出具体决策。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 一次性的静态比较（选 A 还是选 B、当期成本谁低）：仿真成本远超收益。
- 系统边界与关系完全未知时：画不出来的系统也仿不出来，先做调研。
- 把仿真输出当成对未来的真实预测：它只是你那张图的推演结果。

### 容易误用的地方
- 书中未给出边界说明（本章要点仅建议：对复杂系统或决策空间考虑进行仿真模拟）；书中也未给具体仿真算例，仅说明可设置初始条件观察系统随时间变化。
- 模型可靠性完全取决于图有没有画对：缺一条关键反馈回路的仿真比不做仿真更危险，因为它输出的数字看起来很可信。（推导，非书中明示）
- 参数拍脑袋：反馈强度、延迟时间这类参数往往没有数据支撑，应做敏感性分析看结论对参数是否稳健。（推导，非书中明示）

### 容易混淆的邻近模型
- 与蒙特卡洛模拟（Monte Carlo simulation）：单次运行看过程 vs. 多次随机运行看分布。
- 与系统思考（systems thinking）：工具 vs. 视角，仿真是系统思考的下一步。
