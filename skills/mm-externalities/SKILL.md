# 外部性（externalities）

## R — 原文 (Reading)

> 我们前面一直在谈论的这些意料之外的后果，有个来自经济学的名称——"外部性"（externalities）。它指的是，在未经某个实体同意的情况下，源自外部的事物造成了后果（无论是好是坏）。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

外部性是一个追责模型，核心判据只有一句：**有没有人承担了后果，却既没有参与决策，也没有得到补偿（或没有被收费）**。只要这个条件成立，不管后果是好是坏，都是外部性。工厂排污让附近居民承担健康成本是负外部性；公司让工人学急救，工人业余时间救人是正外部性。

它为什么重要？因为价格信号失真。当制造损害的人不用为损害付钱，他的"成本"就低于社会的真实成本，于是这项活动会被过度生产；反过来，正外部性因为无法收费，会被生产不足。市场自己不会纠正这个偏差，因为受影响的一方根本不在交易里。

所以标准的解法方向叫**内部化（internalization）**：用税收、罚款、规章、诉讼等手段，让制造者把后果的成本真正付出来，使价格高到足以覆盖它造成的社会成本。科斯定理则给出了另一条路——有时候当事方可以自己谈拢（见 `mm-coase-theorem`）。

实用价值在于把它当成一个**前瞻性清单**而不是事后追责工具：在推出任何方案前主动追问四件事——会出现什么溢出效应、谁会受影响、有没有公共资源被搭便车、会不会演变成公地悲剧。

## A1 — 书中的应用 (Past Application)

### 案例: 工厂污染与工人急救培训

- **问题**: 一家工厂把废气排到空气里，附近居民承受健康与清洁成本，但他们既没有参与工厂的生产决策，也没有拿到任何补偿。反过来，同一家公司出资让工人接受急救培训，工人在业余时间用这些技能救了人——社会得到了收益，而公司并未因此收费。
- **方法论的使用**: 作者用"是否经过同意、是否有补偿/收费"作为唯一判据，把这两件看起来完全无关的事归为一类：前者是负外部性，需要内部化（让工厂付出代价）；后者是正外部性，说明市场会供给不足，可能需要补贴或公共提供。
- **结论**: 判断外部性不看后果的大小，看"决策权与后果承担是否分离"。这个判据一旦建立，后续该用税收、罚款、规章还是补贴，就变成了一个技术选择问题。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 上线一个功能/政策/活动前做副作用盘点：它会影响哪些没参与决策的人？
2. 团队或部门的成本被转嫁给别人：技术债甩给下游、客服成本甩给合作方、招聘的筛选成本甩给用人部门。
3. 公共资源被搭便车：共享文档只改不维护、共用带宽被占满、开源项目只索取不贡献。
4. 为一个损害设计补偿或惩罚机制：该罚款、该征税、还是该规定配额？
5. 争论"这事该谁买单"：上下游扯皮、跨部门成本归属、平台与商家的责任划分。

### 语言信号 (用户的话里出现这些就应激活)

- "这又不是我们部门的问题"
- "凭什么要我们承担这个"
- "没人问过我们就改了"
- "反正不用我们付钱"
- "大家都用，没人维护"
- "externalities / side effects / spillover / who bears the cost / free rider"

### 与相邻 skill 的区分

- 与 `mm-coase-theorem` 的区别: 外部性负责**识别**问题（谁承担了未补偿的后果），科斯定理负责**判断解法**（能否靠当事方自行交易内部化）。先用外部性发现，再用科斯定理选路。
- 与 `mm-tragedy-of-the-commons` 的区别: 公地悲剧是外部性的一种具体形态——资源是共享的、使用者互相施加成本；外部性范围更广，也包括一对一的、非共享资源的情形。
- 与 `mm-moral-hazard` 的区别: 道德风险是"因为有人兜底所以敢冒险"，外部性是"后果落到了没参与决策的人身上"。前者的关键变量是风险承担者与决策者分离，后者的关键变量是后果承担者与决策者分离。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出受影响方，并逐一过判据**
   - 对每一方问：他是否参与了这个决策？他是否得到了补偿或被收费？
   - 完成标准: 得到一张表，标出所有"未参与决策却承担后果"的一方。
   - 判停条件: 若所有受影响方都在交易内且价格已覆盖成本，停止本 skill。
2. **给每个外部性定方向（正/负）与量级**
   - 尽量换算成可比较的单位（金额、小时、健康风险、故障率）。
   - 完成标准: 每项外部性有方向与一个粗略量级，并标注估算方法。
   - 判停条件: 若量级显著小于决策本身的收益且不可逆风险低，可记为"接受"并跳到步骤 5。
3. **检查是否滑向公地悲剧**
   - 问：是否存在共享资源，且每个使用者的边际收益私有、边际成本公有？
   - 完成标准: 明确回答是/否；若是，转 `mm-tragedy-of-the-commons` 的处理路径（配额或产权）。
4. **为负外部性选择内部化手段**
   - 在税收、罚款、规章、诉讼、披露中至少比较两种，说明各自的执行成本与副作用（注意 `mm-goodhart-s-law` 与 `mm-cobra-effect`）。
   - 完成标准: 选定一种并写明"让制造者付出的价格 ≥ 后果成本"。
   - 判停条件: 若产权明确、双方理性、交易成本低，优先走 `mm-coase-theorem` 的自行交易路径。
5. **为方案补一遍前瞻清单**
   - 主动追问：会出现什么溢出效应、谁受影响、有没有公共资源被搭便车、会不会沦为公地悲剧。
   - 完成标准: 四问均有书面答案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯粹的内部成本核算：如果所有成本已经落在决策者自己身上，没有外部性可言，用成本收益分析即可。
- 双方已在价格中充分协商的交易：这是市场正常运行，不是外部性。
- 把"我不喜欢这个结果"当成外部性：必须有可辨识的、落在具体一方身上的后果，不能是抽象不满（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 书中未提本模型的局限，但强调制度设计者应"提前考虑"负外部性并设计内部化机制——也就是说，事后追责的效率远低于事前设计（书中明示的方向）。
- 容易只看到负外部性而忽略正外部性，导致对公共品的投入不足（推导，非书中明示）。
- 内部化手段本身会催生新外部性或不当诱因（如按数量罚款导致的数据瞒报），需与 `mm-cobra-effect`、`mm-goodhart-s-law` 配合使用（推导，非书中明示）。

### 容易混淆的邻近模型

- 与溢出效应：日常语言中两者混用，但严格说外部性强调"未经同意 + 未补偿"这一规范判据，溢出效应只是描述影响扩散的事实，不含价值判断。
- 与道德风险：两者都涉及"成本由别人承担"，但道德风险是事前的行为扭曲（因为有保险所以敢冒险），外部性是事后的成本归属（损害已经落到第三方）。
