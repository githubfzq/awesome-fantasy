# 互惠（reciprocity）

## R — 原文 (Reading)

> 你会觉得有义务回馈（或回报）别人的好意，无论你原本需不需要帮忙。
>
> — 《思维模型》, 第7章 > 影响力模型

---

## I — 方法论骨架 (Interpretation)

互惠是西奥迪尼影响力六原则之一,也是跨文化普遍存在的社会关系准则:别人给了你好处,你就有义务回报。

关键在于机制上的一点——**触发亏欠感的是"给予"这个动作本身,而不是这份好处对你有没有用**。所以主动赠送**未被索要**的东西,能大幅提升对方给予回报的概率:你没有机会拒绝,而亏欠感已经产生了。餐厅送薄荷糖就是这个原理,你没要那颗糖,但你还是会多给小费。

为什么成立:人类社会把互惠当作关系的基础规范,违背它要付出社会代价。这个倾向强到足以覆盖理性计算——即使那份好处你根本不需要,"不还"依然让你不舒服。

关键判据:**问"我是不是正在回报一份我根本没要过的东西"**。如果答案是,那你此刻的决定就不是基于这件事本身的价值,而是基于清偿一笔单方面开出的账单。

作者也指出它的问题面:当互惠被用于获取政治影响力(如游说捐款换取投票),这天生的倾向就成了问题。

---

## A1 — 书中的应用 (Past Application)

### 案例: 餐厅的薄荷糖与小费

- **问题**: 怎样让顾客多给小费?直接要求显然不行。
- **方法论的使用**: 服务员在结账时送薄荷糖——一份顾客没有索要的小小好处。作者给出具体数据:送一块糖小费增加 3%,送两块增加 14%,送两块再加一句好话则增加 23%。
- **结论**: 回报的冲动由"给予"动作触发,与好处本身的大小、是否被需要关系不大;一点点未被索要的好意,就能换来不成比例的回报。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户收到免费试用、赠品、咨询服务后,被要求购买或签约,感到"不买不好意思"。
2. 用户在谈判中被对方先让一步,于是觉得自己也该让步,怀疑被套路。
3. 用户在做销售、募捐、社区运营,想提高对方的回应率,需要知道机制与伦理边界。
4. 用户意识到自己的人情往来正在影响专业判断(如采购、招生、评审)。

### 语言信号 (用户的话里出现这些就应激活)

- "人家都送我东西了,不买不好意思"
- "欠了个人情,不好拒绝"
- "他先帮了我,我得还回去"
- "免费试用了这么久,总得买点什么"
- "拿人手短"
- "I owe them one" / "they gave me a free..." / "feel obligated to return the favor"

### 与相邻 skill 的区分

- 与 `mm-commitment` 的区别: 互惠的驱动力是**亏欠感**(对方先给你好处),承诺的驱动力是**一致性**(你自己先表过态);看那股力量来自外部给予还是内部表态。
- 与 `mm-liking` 的区别: 喜好靠的是"我喜欢这个人所以愿意答应",互惠靠的是"我欠这个人所以必须回报";即便你讨厌对方,互惠依然生效。
- 与 `mm-social-proof` 的区别: 社会认同靠"别人都这么做"的行为暗示,不需要有人专门给你东西;互惠一定存在一个"给予"的动作。

## E — 可执行步骤 (Execution)

1. **定位那个"给予"动作**
   - 完成标准: 明确指出对方在什么时候、给了什么,以及这份好处是否是用户主动索要的。
   - 判停条件: 若不存在给予动作,只是用户先表过态,改用承诺模型。
2. **分离两股力量**
   - 完成标准: 把"这件事本身值不值得"与"我欠了人情"分开列出,让用户看清各自的分量;明确指出触发亏欠感的是给予动作本身,与好处是否被需要无关。
3. **给出脱身或重新定价的路径**
   - 完成标准: 提供具体做法——把好处折算成市场价并明确归还/谢绝(把人情转成明账),或用等价的、边界清晰的回报方式清偿,避免被迫用重大让步来还一份小人情。
4. **若用户是设计方:检查伦理边界**
   - 完成标准: 给出判据——这份给予是否意在绕过对方的理性判断?对方能否无成本地拒绝?并明确提醒:作者指出互惠被用于获取政治影响力时,这天生的倾向就成了问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 正常的礼尚往来与长期关系维护:把它一律解读为操纵会破坏健康的社会关系。
- 对方是靠让你先表态来推进(先问"你是不是也觉得……"):那是承诺模型。
- 纯粹的价格/功能比较场景:没有给予动作,套用只会制造怀疑。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确指出:当互惠被用于获取政治影响力(如游说捐款换取投票)时,这天生的倾向就成了问题。(书中明示)
- 因为触发亏欠感的是"给予"动作本身而非好处是否有用,接受未被索要的东西前应先想清楚代价。(推导,非书中明示)
- 常见误用:把互惠当成唯一的说服手段,忽略了它只能换来一次性的、被动的回报,不能建立真正的信任。(推导,非书中明示)

### 容易混淆的邻近模型

- 与承诺(commitment): 两者都能让人"不好意思拒绝",但一个锚是外部给予,一个锚是自我表态;防守方式也不同——互惠要去清偿或谢绝,承诺要去重新表述。
- 与不当诱因(perverse-incentives): 互惠是心理机制,不当诱因是制度设计缺陷;当"送礼"被制度化进流程(如采购收礼),就从前者的个人心理问题升级为后者的制度问题。
