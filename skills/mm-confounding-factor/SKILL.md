# 混淆因素（confounding factor）

## R — 原文 (Reading)

> 所谓的"混淆因素"是指某个也许并非显而易见的第三方因素。这个因素既会影响假定的原因，也会影响观察到的效应，进而造成混淆，使人们无法得出正确结论。
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

混淆因素是某个不易察觉的第三方变量，它同时影响假定的原因和观察到的效应。因为混淆因素与原因、效应**都相关**，它会把两者的相关性全部或部分"偷走"——让人误判因果的强度，甚至误判因果的**方向**。

这个"偷走"的机制值得细看：假设 X 对 Y 其实毫无影响，但存在一个变量 Z，Z 同时提升 X 和 Y。那么在数据里 X 和 Y 会呈现强相关，而且这个相关完全由 Z 造成。更危险的情形是 Z 让真实的正向因果看起来是负的（辛普森悖论的一类），此时你得到的结论连方向都是错的。

操作判据只有一条，但极其有效：**看到一个因果故事，就追问"有没有第三个变量同时推动了两边"**。这条追问要针对具体机制，而不是泛泛地"可能有其他因素"——有效的混淆因素必须能被指名，并且能说清它如何同时作用于两端。

主要破解手段是**随机化**：随机分配使两组在所有维度上（包括你没想到的维度）期望相同，从而一次性打散所有已知与未知的混淆因素。这也是随机对照实验被称为"黄金标准"的原因。

书中特别提醒：混淆因素**常被忽略**，且在无法随机化的研究中（如孕期吸烟），它会与选择性偏差同时出现——两种污染叠加，结论要格外谨慎。

## A1 — 书中的应用 (Past Application)

### 案例: 接种流感疫苗后感冒

- **问题**: 很多人接种流感疫苗后仍然感冒，于是得出"疫苗没用甚至有害"的结论。
- **方法论的使用**: 作者指出真凶是"流感季节"这个混淆因素——那本就是一年中最易生病的时段，它同时推动了"去接种疫苗"和"出现感冒症状"这两件事。此外，症状多半来自疫苗无法预防的普通感冒。
- **结论**: 接种与感冒的相关性完全由季节性这一第三方因素造成；不控制它就得出"疫苗导致感冒"的因果结论是错的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在解读一份观察性研究或内部数据对比，准备据此下结论——需要先把可能的混淆变量列出来。
2. 用户在设计实验或数据分析方案——需要在开跑前排查对比组是否可比、需要控制哪些变量。
3. 用户在比较两个群体（用了功能的 vs. 没用的、参加培训的 vs. 没参加的）——需要检查两组在被比较维度之外本来就不一样。
4. 用户看到一个反直觉的行业结论——需要找出被忽略的第三变量。

### 语言信号 (用户的话里出现这些就应激活)

- "这两组数据差距这么大，是不是就是它的效果？"
- "有没有什么我们没考虑到的因素？"
- "这两个群体本来就不太一样吧？"
- "会不会是季节性/时间/人群差异造成的？"
- "Is there something else driving both?"
- "Are these two groups actually comparable?"

### 与相邻 skill 的区分

- 与 `mm-correlation-does-not-imply-causation` 的区别: 后者是**总原则**（别急着下因果结论），本 skill 是**具体路径**（错在这个第三方变量）。前者告诉你"有问题"，本 skill 告诉你"问题在哪里、怎么排除"。
- 与 `mm-selection-bias` 的区别: 选择性偏差是**样本进入比较的方式**有问题（谁被选进来了）；混淆因素是**一个额外变量**同时影响两端。二者经常同时出现且互相放大，但纠正手段不同：前者靠改进抽样，后者靠随机化或统计控制。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出因果三角**
   - 明确：假定的原因 X、观察到的效应 Y、候选的第三变量 Z。
   - 完成标准: 写出明确的 X → Y 主张。
2. **头脑风暴候选混淆变量（逐个指名）**
   - 问：有什么东西会同时提高 X 和 Y？常见来源：时间/季节性、人群特征、地域、严重程度、自我选择。
   - 完成标准: 至少 3 个**具体的、被指名的**候选变量；每个都要说清"它如何同时推动 X 和 Y"。
   - 判停条件: 若只能泛泛说"可能有别的因素"而指名不出任何具体 Z，说明这不是混淆问题，停止本 skill，回到 `mm-correlation-does-not-imply-causation` 做一般性提示。
3. **评估每个候选的影响力**
   - 对每个 Z 判断：它与 X、Y 的相关强度如何？如果控制住它，X-Y 的相关会消失还是只是减弱？
   - 完成标准: 标出最重要（最可能颠覆结论）的 1-2 个 Z。
4. **给出排除方案**
   - 首选随机化；不可行时用分层/匹配/统计控制；并说明残余不确定性。
   - 完成标准: 给出 1 个可执行的排除方案 + 一段关于残余风险的诚实说明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有真正的随机化设计——随机化已在期望上打散了所有混淆因素（含未知的）。
- 指名不出具体变量时——泛泛地说"可能有混淆因素"是伪怀疑，不产生信息。
- 纯描述性统计（只想描述现状，不做因果推断）——无需控制混淆。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给系统性排除方法，只强调"常被忽略"。（书中明示）
- 在无法随机化的研究中（如孕期吸烟），混淆因素与选择性偏差会同时出现，结论必须格外谨慎。（书中明示）
- 过度控制风险：控制了本不该控制的变量（如中介变量，它位于因果链上而非混淆项），会把真实的因果效应也一起消掉。（推导，非书中明示）

### 容易混淆的邻近模型

- 与**选择性偏差**: 见 A2 区分——额外变量 vs. 样本进入方式，二者常共存。
- 与**虚假相关**: 虚假相关是**纯随机**造成的；混淆因素是**一个真实存在的第三变量**造成的。
