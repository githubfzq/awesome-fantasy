# 内向型与外向型（introverts versus extroverts）

## R — 原文 (Reading)

> 经常需要跟别人互动（例如销售）、参与大型群体活动（例如会议）的团队角色，会更适合外向型的人。相反，需要独立工作（例如编程）的团队角色会更适合内向型的人。
>
> — 《思维模型》, 第8章 > 齐心协力

---

## I — 方法论骨架 (Interpretation)

内向与外向的差别不在"会不会社交"，而在**能量从哪里补充**。外向者在大群体互动中充电，独处久了会疲乏；内向者在独处与小范围深度交流中充电，长时间高密度社交会持续放电。同一个人在两种环境下的产出差距，往往比技能差距还大。

由此推出的排岗原则很直接：**按角色的互动密度匹配能量类型**。销售、商务拓展、主持大型会议、高频客户对接这类角色，天然适配外向者；编程、写作、长期规划、财务建模、深度研究这类需要连续安静时间的角色，天然适配内向者。

关键判据是**稳定性**：人格特质一旦确立不会迅速变化。所以正确的动作是"选一个符合这个人格的角色"，而不是"改变人格去适应角色"。让内向者硬扛销售岗，或者把外向者整天关在独立办公室里写文档，都是在跟能量来源对抗，成本极高且效果有限。

作者本人就是内向者，他们喜欢阅读、写作、规划、创建东西（程序和电子表格）这类角色——这不是退而求其次，而是把长板放在长板位置上。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在给团队成员分派角色或招聘：纠结"这个人业务能力够，但不太爱说话，能不能让他去跑客户"。
2. 某人绩效持续不达标，但技能评估没问题——怀疑是角色与性格错配（内向者被放在高频社交岗，或外向者被放在长期孤立岗）。
3. 用户自己想"我是不是该变得更外向一点才能升职"，或计划强迫自己/他人大量社交来改善处境。
4. 设计团队日程与协作方式：会议数量、开放办公、随时打扰 vs. 整块专注时间，谁会因此被消耗。

### 语言信号

- "他技术很强但不爱跟客户说话，要不要让他转销售锻炼一下"
- "我一开一天会就整个人废掉了"
- "这个岗位是不是得招个外向的"
- "他太闷了，融入不了团队"
- "我是不是太内向了，所以升不上去"
- "Should I push myself to be more extroverted?" / "Is he too quiet for this role?"

### 与相邻 skill 的区分

- 与 `mm-big-five-personality-traits` 的区别: 内外向是大五人格里的**一个维度**；大五用来做更完整的团队画像，本 skill 只处理"互动密度是否匹配"这一个判断。
- 与 `mm-managing-to-the-person` 的区别: 以人为本的管理讲的是"对每个人用不同的管理方式"；本 skill 讲的是"把不同的人放到不同的角色上"，一个管方法，一个管位置。
- 与 `mm-eq-versus-iq` 的区别: 情商是能力维度（可以练），内外向是能量维度（基本稳定）；判断"他能不能读懂客户情绪"用情商，"他在这个岗位上会不会被耗尽"用内外向。

## E — 可执行步骤 (Execution)

1. **先确认是不是能量错配，而不是能力不足**
   - 完成标准: 明确回答"这个人的技能是否已达标"。技能不达标是培训问题，退出本 skill。
2. **量出角色的互动密度**
   - 完成标准: 把该角色一周的时间切成"高频对外互动"和"连续独立工作"两块，给出大致小时数占比。
3. **判定本人能量类型**
   - 完成标准: 用一个具体判据定性——长时间独处后他是更有精神还是更蔫？大型活动结束后他想充电还是想续摊？
4. **匹配或调整**
   - 完成标准: 若匹配，明确说明"角色就是按这个性格选的"，不要再加改造建议；若错配，给出**换角色 / 拆分角色 / 调整协作方式**三个选项中的可执行项（例如把客户演示交给外向同事、把方案撰写留给他）。
5. **明确否决"改人格"方案**
   - 完成标准: 若用户提出"逼他多社交/我自己硬练外向"，要指出人格特质稳定，改造成本高于调岗成本，并给出调岗的具体替代方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 问题是技能、知识或经验不足——这不是性格错配，培训与历练才是对症手段。
- 只需判断"他是否擅长读懂他人情绪"——那是情商维度，见 `mm-eq-versus-iq`。
- 角色本身互动密度中等且可自主调节——此时人格影响很小，不必上升到模型层面。

### 容易误用的地方

- 书中明示：除内/外向之外还存在许多人格维度，内/外向只是**日常工作中最有用的一个**，不可当作唯一分类标准。用它给人贴死标签、否认其他维度（尽责性、开放性、亲和性）会造成误判。
- （推导, 非书中明示）"内向 = 不能做销售/管理"是过度外推。书中只说这类角色"更适合"外向者，内向者在深度关系型销售、一对一客户成功上往往表现很好，判据应是互动**密度与形式**，而非岗位名称。

### 容易混淆的邻近模型

- **大五人格（big-five-personality-traits）**: 内外向是它的子集；本 skill 是单维度快判。
- **以人为本的管理（managing-to-the-person）**: 管理方式的差异化，不是角色分配的差异化。
