# 观察者效应（observer effect）

## R — 原文 (Reading)

> 另一个值得警惕的陷阱是观察者效应（observer effect）。也就是说，某物带来的影响取决于你的观察方式，甚至取决于观察者本身。
>
> — 《思维模型》, 第2章 > 许愿须谨慎

---

## I — 方法论骨架 (Interpretation)

观察者效应说的是：测量结果里混进了"测量这件事本身"造成的变化，所以你看到的不是事物本来的样子，而是它被观察时的样子。

它有两种形态。第一种是**物理性的**：测量必须介入对象才能完成，介入就是改变。检测轮胎压力必须先放掉一些气——测完的胎压已经不是测之前的胎压了。第二种是**社会性的**，也更常见：被观察者知道自己在被看，行为就变了。大老板来视察时，员工打扮更光鲜、表现更卖力；摄像机前的人很难坦率。

第二种形态为什么重要？因为在组织里，观察几乎总是**记名**的，且观察者几乎总是**有权力的**。被评价的人会理性地给出"最有利于自己的版本"。书中直接给了一个可操作的对比：记名与不记名调查中，人们对同事的评价会完全不同。

所以关键判据是：**被观察的对象能不能感知到观察，并且有没有动机做出反应？** 只要两个答案都是"是"，数据就被污染了。由此推出书里的实践建议：设计测量与调研时应优先匿名，或至少评估匿名与否带来的行为差异。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 设计员工调研、360 评估、绩效访谈，担心大家不说真话。
2. 做用户访谈、可用性测试、焦点小组，担心用户迎合。
3. 上线监控、埋点、行为看板后，团队行为明显改变（为了看板数字做事）。
4. 现场检查、飞行检查、领导走访——拿到的数据是否代表日常。
5. 实验设计：控制组是否因为知道自己在实验里而改变行为。
6. 复盘一份数据："为什么走访时一切正常，走了就出问题"。

### 语言信号
- "老板一来大家表现特别好"
- "调研结果太正面了，不太真实"
- "摄像头下面谁都不自然"
- "匿名的话会不会说得真一点"
- "我们装了监控之后行为就变了"
- "observer effect / Hawthorne effect / people act differently when watched"

### 与相邻 skill 的区分
- 与 `mm-observer-expectancy-bias` 的区别: 观察者期望偏差是**观察者自己**的期待影响了结果的解读或记录（研究者看到他期望看到的结果），本 skill 是**被观察者**因被观察而改变行为；一个是观察端失真，一个是被观察端失真。
- 与 `mm-blinded-experiment` 的区别: 盲测是消除观察污染的一种**具体手段**（不让参与者/实验者知道分组），本 skill 是识别"要不要盲、盲谁"的判据。
- 与 `mm-response-bias` 的区别: 反应偏差聚焦**回答内容**的系统性歪曲（如倾向于选中间项），本 skill 聚焦**行为与状态**因被观察而发生的真实改变；前者是答得不准，后者是做得不同。
- 与 `mm-nonresponse-bias` 的区别: 无反应偏差是"没回答的人"造成的样本偏差，本 skill 是"回答了但已因被观察而变形"。

## E — 可执行步骤 (Execution)

1. **确认被观察对象能否感知观察**
   - 问：他知道自己在被看吗？以什么方式知道？
   - 完成标准: 明确"可感知 / 不可感知 / 部分感知"。
   - 判停条件: 若完全不可感知（无埋点的历史日志、无感采集），退出本 skill。
2. **确认他有没有动机做出反应**
   - 问：表现得好/坏对他有什么后果？观察者对他有多大的权力？
   - 完成标准: 写出具体的利害；观察者权力越大，扰动越强。
3. **判断这是物理型还是社会型扰动**
   - 物理型：测量是否必须改变对象才能完成（如放气测胎压）。
   - 社会型：被观察者的行为改变。
   - 完成标准: 标注类型；物理型只能校正，社会型可以降低。
4. **降低扰动：按强度选手段**
   - 候选：完全匿名（最强）→ 第三方代收 → 延后告知观察目的 → 无感知的行为日志 → 延长观察期让行为回归基线 → 盲法（不让执行者知道研究假设）。
   - 完成标准: 选定至少 1 条，并说明它降低了哪一部分扰动。
5. **做一次匿名 vs 记名的差异评估**
   - 书中的建议：至少评估匿名与否带来的行为差异。
   - 完成标准: 明确将如何评估（小样本对照、历史基线对比、分批实施）。
6. **在结论里声明残余扰动**
   - 完成标准: 报告里写明"本数据是在何种观察条件下取得的，可能高估/低估什么"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 对象对观察无反应能力（服务器日志、已固化的历史数据、物理量且不因测量改变的指标）：不存在行为扰动。
- 扰动已经衰减到可忽略（观察期足够长、被观察者已习惯）：继续套用只会徒增成本（推导，非书中明示）。
- 用户要的是合规留痕或威慑效果本身（监控的目的就是让人守规矩）：此时"行为改变"正是目标，不是偏差（推导，非书中明示）。

### 容易误用的地方
- 把观察者效应当成"数据不可信"的同义词：它只说明数据带有**观察条件的印记**，方向通常可预测（更正面/更努力），可以校正也可以声明，不是一律作废（推导，非书中明示）。
- 只做匿名不做对照：匿名降低了扰动，但没有告诉你降低了多少；书里的建议是**评估匿名与否带来的行为差异**，这一步最常被省掉（推导，非书中明示）。
- 忽略"观察者是谁"这个变量：同一份问卷，HR 发和第三方发，结果会不同；这是模型里"甚至取决于观察者本身"这一半（书中明示）。
