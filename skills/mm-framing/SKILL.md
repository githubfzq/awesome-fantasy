# 框架效应（framing）

## R — 原文 (Reading)

> 叫作"框架效应"（framing），指的是你展示情况或做解释的方式。
>
> — 《思维模型》, 第1章 少犯错 > 各持己见

---

## I — 方法论骨架 (Interpretation)

同一组事实，可以装进不同的框架里呈现，而**接收者的结论会随框架改变**，尽管事实一点没变。

为什么会这样？因为人不是先把事实接收进来、再做判断；人是借着框架来理解事实的。框架决定了：什么被当成前景、什么被当成背景；哪个数字是参照点；这件事被归入哪个类别（"损失"还是"收益"、"机会"还是"威胁"、"常态"还是"事故"）。一旦归类完成，判断就基本定型了，而归类这一步发生在意识之前。

书中强调它有**两面性**：

- 作为**陷阱**: 陈述者用框架争取有利反应，接收者若不察觉就会被牵着走。
- 作为**技巧**: 你自己也可以选择框架，而且多个框架可能都成立、只是呈现了不同视角。

应对方法非常具体：**听到任何新想法时后退一步，主动想出两三种其他描述方式，再下判断**。如果换一种说法你的结论就变了，说明你的结论不是从事实来的，而是从框架来的。

关键判据（两问）：
1. 换一种说法，我的结论会不会跟着变？会 → 我被框架影响了。
2. 这个框架把什么放进了前景、把什么藏进了背景？它让我忽略了什么？

## A1 — 书中的应用 (Past Application)

### 案例: "离职去寻找更好的机会" 与盗窃率文章的两个标题
- **问题**: 作者要说明同一事实在不同框架下会导出完全不同的理解，以及接收者如果不自觉就会被带走。
- **方法论的使用**: 两个对照。其一，同事说"我离职是为了寻找更好的机会"——这可能是真心话，也可能是他觉得自己被公司忽视、愤然辞职，同一件事的两种框架导向完全不同的后续判断。其二，Ecker 等（2014）的实验：给同一篇关于盗窃率的文章配两个标题——《盗窃案数量上升》与《盗窃率呈下降趋势》——两个标题陈述的都是文中的事实，只是取的参照不同，结果学生对文中事实的**记忆**出现了显著差异。
- **结论**: 框架不只影响当下的判断，还影响事后的记忆。因此听到一个说法时，主动构造替代框架不是可选项，而是获取事实的必要步骤。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **被别人的一段话说服，但说不清为什么**: 汇报、提案、销售话术、新闻标题、朋友圈长文。需要把框架拆出来看看是不是被带着走了。
2. **同一个数据可以有两种讲法**: "成功率 90%" vs "失败率 10%"；"省了 5 万" vs "少赚了 5 万"；"存活率" vs "死亡率"。需要判断哪种讲法是中性的、哪种在引导。
3. **准备自己的汇报/提案/定价/沟通**: 需要选择一个既诚实又有效的框架。
4. **双方各执一词但其实说的是同一件事**: 争论卡在措辞上，需要把两种框架都写出来，看事实层面是否真的有分歧。
5. **读新闻/看报告时的防御性阅读**: 标题、图表起点、比较基准、时间窗口都在设定框架。

### 语言信号 (用户的话里出现这些就应激活)

- "他这么一说我好像就被说服了"
- "同一件事，怎么换个说法感觉完全不一样"
- "这话我该怎么说才合适"
- "这个数据怎么呈现比较好"
- "标题这么写是不是有点片面"
- "我们说的是同一件事吗"
- "How should I frame this?" / "That's just spin." / "Put a positive spin on it."

### 与相邻 skill 的区分

- 与 `mm-anchoring` 的区别: 锚定是**第一个数字/说法**锁定了后续判断的区间（数量上的牵引）；框架效应是**整体叙事角度**决定了理解与归类。书中把锚定描述为"你遇到的第一则发挥框架效应的信息"——锚是框架的一种特例，专指数值型、先发型的框架。
- 与 `mm-reframe-the-problem` 的区别: 重新定义问题是**换问题本身**（也许我们该解决的不是 X 而是 Y），用于寻找新解；框架效应是**同一事实的换表述**，用于检测与选择呈现方式。
- 与 `mm-loss-aversion` 的区别: 损失规避是框架效应最常见的**心理机制**——把同一件事框成"损失"比框成"收益"更有冲击力；框架效应是更上层的呈现现象。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先分离事实与框架**
   - 完成标准: 把听到/读到的话拆成两层——(a) 可核查的事实与数字；(b) 包装它们的框架（参照点、归类、前景/背景、措辞的情感色彩）。
   - 判停条件: 若事实层本身存疑或无法核查，先停止框架分析，转向事实核实——框架问题的前提是有确定的事实。
2. **为该事实生成 2-3 个替代框架**
   - 完成标准: 至少 3 种表述，且它们必须**(i) 同样真实**、(ii) 视角明显不同（例如：绝对数 vs 比率、收益 vs 损失、同比 vs 环比、个体故事 vs 统计分布、短期 vs 长期）。
   - 判停条件: 若生成的替代框架中有不真实的（夸大了或隐瞒了关键事实），丢弃重来——这一步的目的是看清事实，不是练话术。
3. **测试结论是否随框架漂移**
   - 完成标准: 依次问用户（或自己回答）"在这个框架下你会怎么决定"，记录每个框架下的结论。若结论不一致，明确指出：结论不是从事实推出的，而是被框架推出的。
4. **追问框架藏了什么**
   - 完成标准: 对每个框架写出"它让我注意到什么、又让我忽略什么"（分母是什么、基准年是哪年、成本项有没有被算进去、反面案例有没有被提到）。
5. **选择框架（如用于自己的表达）或选择中性表述（如用于自己的判断）**
   - 完成标准: **用于判断**时，选信息最完整、基准最明确的那一种，并显式写出被舍去的框架及其影响；**用于表达**时，选择框架的同时必须保证关键事实（分母、基准、反面证据）没有被隐藏。
   - 判停条件: 若用户选择的框架会掩盖关键事实或误导接收者，明确拒绝并说明理由，改为提供中性版本。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **事实本身尚未确定时**: 框架分析的前提是"事实确定、表述可变"。事实还不清就先核实，此时讨论怎么说是本末倒置。
- **存在客观正确表述的技术场景**（推导, 非书中明示）: 安全规程、法律条文、医疗剂量等场景，追求的是无歧义而非有效呈现，框架的选择空间应当被压缩到最小。
- **用来操纵他人**: 用框架隐藏关键事实（藏掉分母、藏掉副作用、藏掉反面证据）已不是框架效应而是欺骗，本 skill 明确拒绝为此服务。

### 书中警告的失败模式 / 容易误用的地方

- **书中未给明确边界，只强调多种框架可能都说得通，但表达截然不同的视角**（`boundary` 字段原文）。这意味着：发现框架存在，不等于发现了谁在撒谎——可能只是视角不同。
- （推导, 非书中明示）**替代框架不真实**: 为了"平衡"而编造一个同样有偏向但方向相反的表述，只是换了一个方向的误导。替代框架必须同样真实。
- （推导, 非书中明示）**只拆别人不拆自己**: 用户在准备自己的汇报时最容易忘记自己也在用框架。第 4 步的"它让我忽略什么"必须同样施加于自己选择的框架。
- （推导, 非书中明示）**框架疲劳**: 对每句话都做框架分析会让人无法行动。只对影响判断的关键陈述使用。

### 容易混淆的邻近模型

- **锚定（anchoring）**: 是框架效应的一个数值化、先发化的特例——第一个数字锁定了后续判断。
- **最善意的解释（most-respectful-interpretation）**: 是在人际冲突中选择对对方动机最善意的那个框架；框架效应是中性工具，指出各种框架的存在与影响，不预设哪个更善意。
