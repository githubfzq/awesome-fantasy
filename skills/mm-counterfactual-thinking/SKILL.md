# 反事实思维（counterfactual thinking）

## R — 原文 (Reading)

> 这称为反事实思维（counter-factual thinking），也就是想象过去发生的事与实际发生的相反。
>
> — 《思维模型》, 第6章 > 谨防未知的未知数

---

## I — 方法论骨架 (Interpretation)

反事实思维就是**针对过去提出"如果……会怎么样"**：如果我接受了那份工作会怎样？如果我上了另一所学校会怎样？如果我没有做那份兼职会怎样？

它和情景分析是同一套动作在时间轴上的镜像——情景分析把"如果……会怎么样"投向未来，反事实思维把它投向过去。它的用途不是怀旧，而是**改善决策过程**：通过认真推演那条没走的路，你能看清自己当时的判断里哪些是对的、哪些纯属运气，下次才能做出更好的选择。

但作者给了两条硬约束。第一，**必须连同负面连锁一起想**——不能只想象另一条路的积极后果。人的本性是只美化没选的那条路，那样反事实思维就变成了自我折磨。第二，**蝴蝶效应**的提醒：微小改变会引发连锁反应，所以不能假设"改变一样东西，其他东西全都保持原样"。

这个模型的产出不是"我当年错了"，而是"我对因果的理解哪里需要更新"。

关键判据：你想用它改善未来的决策，还是想用它证明自己当年受害了？后者就不要启动。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在复盘一个已发生的结果，想知道"这到底是决策好还是运气好"。
2. 用户陷在后悔里（没接那个 offer、没早点入行、卖早了），需要把情绪转化为可用的判断。
3. 用户在做复盘，需要把"结果好"和"过程对"区分开。
4. 用户要评价一个历史决策的质量，而结果已知（结果偏误风险高）。

### 语言信号
- "如果当初我接受了那份工作"
- "要是没卖那么早就好了"
- "早知道就……"
- "是不是我当时选错了"
- "换条路会不会更好"
- "if only I had..." / "what if I had taken that job" / "in hindsight"

### 与相邻 skill 的区分
- 与 `mm-thought-experiment` 的区别: 反事实思维针对**过去**（如果当时没那么做），思维实验面向**未来或虚构情形**（如果发生 X）；时间轴方向相反，其他操作几乎一样。
- 与 `mm-hindsight-bias` 的区别: 后见之明偏差是**认知陷阱**（事后觉得自己早就知道会这样），反事实思维是**对抗它的工具**——认真推演另一条路，才能意识到结果并非必然。
- 与 `mm-butterfly-effect` 的区别: 蝴蝶效应是反事实思维的**限制条件**（微小改变会连锁放大，所以不能假设其他不变），不是它的替代。

## E — 可执行步骤 (Execution)

1. **明确要翻转的那个决策点**
   - 完成标准: 写清一个具体的、当初确实有选择余地的岔路口（不是事后虚构的选项）。
2. **推演另一条路——先只写积极后果**
   - 完成标准: 列出另一条路上所有看起来更好的结果。
3. **强制补写负面连锁**
   - 问：那条路上会发生什么坏事？哪些我现在拥有的东西根本不会存在？
   - 完成标准: 负面后果条目数不少于正面条目数；若做不到，说明推演还不诚实，回到步骤 2。
4. **检查"其他不变"的假设**
   - 用蝴蝶效应检验：这个改变会连带改动哪些其他条件？
   - 完成标准: 至少找出 2 处"其实不可能保持不变"的地方。
5. **提炼对决策过程的改进，而不是对结果的评价**
   - 完成标准: 输出 1-2 条下次可复用的决策规则，并明确区分"结果好"与"过程对"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 用来反复美化没走的那条路：这会把工具变成自我折磨，书中明确要求连同负面后果一起想。
- 对完全无法获取任何信息的反事实强行推断：蝴蝶效应会让结论失真。
- 该决定早已做出且不可更改、复盘也无法产生任何可复用规则时：收益接近零。

### 容易误用的地方
- 蝴蝶效应提醒：微小改变会引发连锁反应，所以不能假设"改变一样东西，其他东西全都保持原样"。（书中明示）
- 不要只考虑另一种选择的积极后果。（书中明示）
- 反事实推演的样本只有一个真实结果，无法验证：它更新的是你对因果的信念，不是事实。（推导，非书中明示）

### 容易混淆的邻近模型
- 与思维实验（thought experiment）：过去 vs. 未来/虚构，时间轴方向相反。
- 与后见之明偏差（hindsight bias）：工具 vs. 陷阱。
