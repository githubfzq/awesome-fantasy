# 以牙还牙（tit-for-tat）

## R — 原文 (Reading)

> 你可以从一开始就选择合作，然后对方怎么做，你就照葫芦画瓢。不过，你要等到对方的背叛行为呈现出一定的规律，再实施报复。
>
> — 《思维模型》, 第7章 > 参与博弈

---

## I — 方法论骨架 (Interpretation)

以牙还牙是重复博弈中的一个具体策略,规则极简:**开局先合作,此后照搬对方上一轮的做法**。

它为什么有效:善意开局先启动合作循环,对等报复让背叛变得得不偿失——你坑我一次,下一轮我就坑回去,于是背叛的净收益被抹平。报复是可信的(因为你真的会做),所以理性对手会选择不背叛,合作由此稳定维持。

书里最关键、也最容易被漏掉的一句是:**要等到对方的背叛行为呈现出一定规律,再实施报复**。这不是宽宏大量,而是因为一次失误和一次蓄意背叛在信息上无法区分,反应过度会毁掉一段本可以卓有成效的关系。误报复的代价往往高于被坑一次的代价。

它也解释了信誉的来源:反复展示善意,会让人愿意成为你的盟友;反之被视为"叛徒",则无人愿意与你合作。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 长期合作方/同事/客户有一次不配合或违约,用户在纠结要不要立刻反击。
2. 用户被人反复占便宜,想建立一种既不吃亏又不撕破脸的相处方式。
3. 用户在设计平台或团队规则(互评、资源分配),想让"合作"成为自发均衡。
4. 用户担心自己报复过度,把一段本来不错的关系彻底毁掉。

### 语言信号 (用户的话里出现这些就应激活)

- "他怎么对我,我就怎么对他"
- "这次被坑了,要不要也坑回去"
- "要不要给他点颜色看看"
- "我一直是好好先生,结果总被欺负"
- "怎么既不吃亏又不撕破脸"
- "tit for tat" / "an eye for an eye" / "reciprocate" / "retaliate"

### 与相邻 skill 的区分

- 与 `mm-iterated-game` 的区别: 重复博弈是**情境**(博弈会反复发生,未来报复使合作成为可能),以牙还牙是这个情境下的一个具体**策略**。先判断会不会再见,再决定怎么打。
- 与 `mm-reciprocity` 的区别: 互惠是影响力原则(别人给了你好处你就想回报,常被用作说服手段);以牙还牙是博弈策略,双向对称——既回报善意也回报背叛,且服务于长期均衡。
- 与 `mm-burning-bridges` 的区别: 过河拆桥是永久切断关系;以牙还牙保留了随时恢复合作的通道(对方一改你也改),这正是它比"绝交"优越的地方。

## E — 可执行步骤 (Execution)

1. **确认存在下一轮**
   - 完成标准: 明确回答"之后还会不会再打交道";若是一次性交往,指出没有报复的载体,应改用合同/押金等外部手段,不要套用本策略。
2. **先判断这是失误还是背叛**
   - 完成标准: 核查三件事——对方是否知情、是否从中获益、此前是否有过类似行为;明确给出"单次失误"或"疑似背叛"的判定。
   - 判停条件: 若判定为单次失误或可解释的外部原因,选择继续合作并明确表达一次,不报复。
3. **对等回应,而不是加倍报复**
   - 完成标准: 若判定为背叛,采取与对方上一轮行为**对等**的回应,并让对方清楚知道这是对其行为的回应;不做超出对等范围的惩罚。
4. **等规律出现再升级**
   - 完成标准: 记录每次行为;只有在重复出现(书中表述为"呈现出一定的规律")后才提高回应强度或改变合作条件,并说明这是升级而非一时冲动。
5. **始终留恢复通道**
   - 完成标准: 明确向对方说明"你恢复合作,我就恢复合作";让合作可以随时重建,而不是一次性判死刑。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 一次性、匿名、无后续交往的博弈:没有下一轮,报复无从实施。
- 对方的"背叛"其实是无心失误或外部不可抗力:报复会把合作者变成敌人。
- 双方实力严重不对等、对方不在乎你的对等回应时:报复不构成威慑,需要外部机制。
- 涉及人身安全、违法或严重背信时:应诉诸规则/法律,而不是私下对等报复。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确提醒不要过度反应——单次失误就报复会毁掉卓有成效的关系。(书中明示)
- 常见误用:把"以牙还牙"执行成"加倍奉还",引发报复螺旋,双方陷入互相升级。(推导,非书中明示)
- 常见误用:在一次性场景里仍想"报复",结果只是让自己付出额外成本而无收益。(推导,非书中明示)

### 容易混淆的邻近模型

- 与互惠(reciprocity): 互惠偏"回报善意"的说服力原则,以牙还牙是双向对称的长期博弈策略。
- 与重复博弈(iterated game): 前者是策略,后者是它成立的前提情境。
