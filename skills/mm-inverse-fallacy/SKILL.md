# 逆谬误（inverse fallacy）

## R — 原文 (Reading)

> 他们弄混了"事件B发生的条件下事件A发生的概率"P（A | B） 与"事件A发生的条件下事件B发生的概率"P（B | A）。这被称为逆谬误（inverse fallacy）。
>
> — 《思维模型》, 第5章 > 具体情况具体分析

---

## I — 方法论骨架 (Interpretation)

逆谬误是把一个条件概率**掉了个方向**当成同一个数：把 P(A|B) 和 P(B|A) 混为一谈，默认两者数值应该接近。

为什么这个直觉是错的？因为两个概率的**分母（条件集）完全不同**，而分母的大小可以差好几个数量级。

书中的例子极其锋利：

- P(90 岁前患乳腺癌 | 携带 BRCA 突变) ≈ **80%**
- P(携带 BRCA 突变 | 90 岁前患乳腺癌) ≈ **5%–10%**

同一对事件，方向一换，从 80% 掉到不到 10%。原因是：携带突变的人极少，而乳腺癌患者里绝大多数并没有这种突变。正向概率的分母是"极小的突变人群"，反向概率的分母是"庞大的患者人群"——分母不一样，商自然天差地别。

关键判据：**每次听到条件概率，先问"这里的分母（条件）是哪一群人？"** 再问"我想要的那个结论，分母是不是同一群人"。方向一变，数值可以完全不可比。

这个谬误之所以顽固，是因为正向说法（"突变者大多会患病"）在因果上听起来就是对的，而人会把"因果上说得通"误当成"反向概率也高"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 医学/风控/安全领域解读检测结果："检测出阳性是不是就得了这个病"。
2. 用"成功者都有某特征"来论证"有某特征就能成功"（创业、投资、招聘中的典型误推）。
3. 看数据报告时把"在 A 群体中 B 的比例"直接读成"在 B 群体中 A 的比例"。
4. 争论"大多数事故都发生在某某条件下，所以某某条件很危险"这类安全归因。

### 语言信号

- "既然大多数 A 都是 B，那这个 B 肯定也是 A"
- "得了这个病的人检测都是阳性，所以阳性就是得了病"
- "那些成功的创始人都辍学了，所以辍学更容易成功"
- "出事故的车大多超速了，所以超速一定危险"
- "反过来也成立吧 / it must work the other way too"

### 与相邻 skill 的区分

- 与 `mm-conditional-probability` 的区别: 条件概率是**工具**（怎么正确计算 P(A|B)），逆谬误是**用错这个工具的特定错误模式**。需要算条件概率用前者，发现有人把方向搞反了用本 skill。
- 与 `mm-base-rate` 的区别: 基础比率是解释"为什么反向概率会那么低"的**原因**（分母里混进了大量无关人群）；逆谬误是这个原因导致的**表面症状**。两者常一起出现，但追问"分母是谁"会更根本地命中问题。
- 与 `mm-false-positive` 的区别: 假阳性是检测系统在**单次判断**上的错误类型；逆谬误是人在**推理方向上**犯的错。阳性结果不可信是基础比率问题，不是检测不准。

## E — 可执行步骤 (Execution)

1. **把原话翻译成 P(X|Y) 的形式**
   - 明确写出：已知的概率是哪个方向？用户想要的结论是哪个方向？
   - 完成标准: 得到两个带竖线的表达式，且能指出它们方向相反。
2. **分别圈出两个分母，比较其规模**
   - 问：P(A|B) 的分母是 B 群体，P(B|A) 的分母是 A 群体，这两个群体哪个大？差多少倍？
   - 完成标准: 给出两个条件集规模的定性或定量比较。
   - 判停条件: 若两个分母规模接近（同一群人的两种切分），反转影响不大，可说明风险较低后结束。
3. **用具体数字代入，算出真实的反向概率**
   - 造一个 1000 人的假想总体，把四类人（A且B / A非B / 非A且B / 非A非B）的人数填进去，直接从表中读出反向概率。
   - 完成标准: 给出反向概率的具体数值，并展示它与正向概率的差距。
4. **指出结论应如何修正**
   - 明确告诉用户：原论证不成立或强度被严重高估，正确的表述是什么。
   - 完成标准: 用户能说出"我应该问的是哪个概率"，并知道下一步该去查哪个分母的数据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 两个方向的条件概率在数值上确实相近（例如两个群体规模相当、或事件高度共现）：此时指出谬误意义不大（推导，非书中明示）。
- 用户本来就在正确使用正向概率做预测（"突变者患病风险高"本身就是有用信息）：不要因为"可能被反向误用"就否定它（推导，非书中明示）。

### 容易误用的地方

- 书中未提边界，但案例本身暗示：这类谬误在**低基础比率 + 高敏感性**的场景危害最大（罕见病筛查、罕见风险识别），因为这些场景两个方向的概率差得最远（推导，非书中明示）。
- （推导，非书中明示）纠正时容易走向另一个极端：宣称"检测完全没用"。实际上正向概率仍然有信息量，正确做法是用贝叶斯把它更新成后验，而不是全盘否定。
- （推导，非书中明示）容易只说"你搞反了"而不给出真实数值。没有数字的纠正很难让人真正改观，步骤 3 的假想总体表是必要的。

### 容易混淆的邻近模型

- 基础比率谬误（base-rate-fallacy）：忽略先验发生率直接把似然当后验。逆谬误可以看作它的一种典型触发路径。
- 合取谬误（conjunction-fallacy）：在概率大小关系上犯错，而非在条件方向上犯错。
