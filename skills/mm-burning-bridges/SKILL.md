# 过河拆桥（burning bridges）

## R — 原文 (Reading)

> 你的退出策略应该避免"过河拆桥"（burning bridges），或者说破坏与某些个人或组织的关系，免得事后无法回头
>
> — 《思维模型》, 第7章 > 终局

---

## I — 方法论骨架 (Interpretation)

过河拆桥指的是：**在退出时破坏与某个人或组织的关系，使得你事后无法通过"那座桥"回来。** 桥是双向通道，一旦烧掉，未来你需要推荐信、回聘、合作、信息、背书时，这条路就不存在了。

为什么人会这么做？因为拆桥在短期内**有真实的情绪收益**——把憋了很久的话说出来，很爽。作者没有否认这一点，他只是指出这笔交易不划算：换来的暂时满足，抵不上失去未来可能性的长期代价。

它为什么特别不划算？因为行业圈子通常比想象的小，且**人的记忆对"离开的方式"记得比"离开的原因"更牢**。你为什么走会被淡化，你走时怎么表现的会被反复提起——尤其被那些留下来的人提起。

关键判据是：**未来我有没有可能需要再通过这座桥？** 注意这不是问"我还想不想跟这个人打交道"，而是问"这个网络里的人会不会出现在我的未来路径上"。在多数职业与行业场景里，答案是会。

作者把它放在"退出策略"这一章，说明它是退出时的**执行纪律**：退出的决定可以坚决，退出的方式应当留余地。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备离职，想写一份"把这些年的问题全说出来"的告别信或朋友圈。
2. 与合作方/客户终止合作，打算在群里或行业圈公开表态。
3. 准备退出一个社群、组织、合伙关系，考虑发一段措辞激烈的声明。
4. 已经吵翻了，在纠结要不要补一句更狠的、或要不要删掉刚发出去的话。
5. 被裁/被辞退，正在想要不要在社交媒体上曝光前东家。

### 语言信号 (用户的话里出现这些就应激活)

- "走之前我得把话说清楚"
- "忍了很久了，反正要走了"
- "我要在群里把这事说清楚"
- "要不要拉黑/删好友"
- "他们这样对我，我凭什么给他们体面"
- "don't burn bridges / leave on good terms / should I say what I really think on my way out"

### 与相邻 skill 的区分

- 与 `mm-scorched-earth` 的区别: 焦土战术是毁掉**资源**（记录、资产、数据）让谁都用不了；过河拆桥是毁掉**关系**让回不来。前者通常不可逆且伤及自身，后者只是关闭通道。用户说"我要把资料全删了/全公开"是焦土。
- 与 `mm-burn-the-boats` 的区别: 破釜沉舟是**主动烧掉自己的退路**以激励团队向前，方向朝前、是策略；过河拆桥是退出时破坏关系，方向朝后、是失误。名字相似但方向相反，书中特别澄清了这一点。
- 与 `mm-exit-strategy` 的区别: 退出策略是"如何退出"的整体方案设计；过河拆桥是执行退出时要避免的**具体错误**。
- 与 `mm-preserving-optionality` 的区别: 保留可能性是通用原则（保留未来选项）；不拆桥是它在退出场景下的具体体现。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认退出决定本身已经成立**
   - 完成标准: 用户能确认"我已经决定要走"这件事不再摇摆。
   - 判停条件: 若还在犹豫，先处理去留决策，暂缓讨论退出方式。
2. **清点这座桥未来的价值**
   - 完成标准: 列出未来 1-3 年内可能仍需通过此人/此组织的 2-3 件事（推荐、合作、客户转介、信息、回聘、共同朋友圈）。若清单为空，说明桥的价值低，可以接受更直率的表态。
3. **分离"事实陈述"与"情绪释放"**
   - 完成标准: 把想说的话分成两栏——客观可陈述的事实（可保留）与情绪性评判（建议删除）。只保留前者。
4. **改写退出表述**
   - 完成标准: 产出一版具体措辞，做到三点：不点名攻击、不公开羞辱、为未来合作留一句可能性。
5. **完成可被记住的交接**
   - 完成标准: 给出交接清单（文档、待办、对接人），并确认在离开前完成——这是最有效的"不拆桥"证据，比任何措辞都有说服力。
6. **若已经拆了，评估是否需要修复**
   - 完成标准: 判断是否值得发一条简短、不辩解的致意；给出具体措辞或明确建议不再追加动作（有时沉默比补救更好）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 对方存在持续伤害、骚扰、霸凌或违法情形——此时切断联系、留证、求助是正确动作，不是"拆桥"，不要劝用户维持体面。
- 用户需要主动断掉退路来逼自己前进（如辞职创业、宣布截止日）——那是破釜沉舟，方向相反。
- 涉及公共利益、安全问题需要公开警示他人时，如实陈述不等于拆桥。
- 关系已经完全终结且无交集可能（跨行业、跨地域的一次性合作）——此时过度经营的体面并无必要。

### 容易误用的地方

- 书中明示：作者指出这么做能得到暂时的满足，但不值得冒事态升级、断绝联系的风险。
- （推导, 非书中明示）把"不拆桥"误解为"不能说真话"——可以陈述事实与感受，区别在于是否攻击人格、是否公开羞辱。
- （推导, 非书中明示）反向误用：为了维持表面和气而给出不真实的离职原因或虚假好评，这会在未来需要真实背书时反噬。
- （推导, 非书中明示）在社交媒体的公开表态是当代最难撤回的拆桥方式——发出去之前按本 skill 检查一遍。

### 容易混淆的邻近模型

- **破釜沉舟（burn the boats）**: 名字相近、方向相反——主动自绝退路以向前，是策略而非失误。
- **焦土战术（scorched earth）**: 毁资源 vs. 毁关系，且通常更极端、更伤己。
