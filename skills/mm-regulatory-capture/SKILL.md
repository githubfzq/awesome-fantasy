# 管制俘获（regulatory capture）

## R — 原文 (Reading)

> 有一个模型就以监管导致的“进入壁垒”为核心，称为管制俘获（regulatory capture）。它是指监管机构或立法者被自己本该监管的特殊利益集团俘获，最终在竞争中保护这些利益集团。
>
> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

监管本来是为了约束某个行业，结果反过来成了这个行业的护身符。这就叫管制俘获。它的产物很具体：**监管制造出的进入壁垒**，把潜在竞争者挡在门外，让已经在里面的安稳赚钱。所以它也是一种护城河——只不过是从外部授予的，而不是自己建出来的。

为什么会这样？书里给了两个成因，都很朴素：

**一是组织成本的不对称。** 受益方是一个有组织、有钱、天天盯着这件事的**利益集团**，他们会持续游说；而受损的是分散的个人——每个人损失一点点，没人会为了那一点点钱去组织起来。一边天天在，一边从来不出现，结果自然偏向天天在的那一边。

**二是旋转门。** 监管者心里清楚自己离职后可以去被监管的行业拿高薪。这条不需要任何恶意交易，仅仅是这条通道的存在，就已经足以让当下握着手的人变软。

值得注意的是它**不限于政府**。书中点明职业许可制度就是政府之外的例子：**控制执照数量就能限制从业者进入**。美国需要执照的工作从 1950 年代的约 5% 上升到约 25%，美容执照的办理耗时从纽约的 232 天到艾奥瓦的 490 天——这些数字很难用"保护消费者安全"来解释。

最要紧的一点在于：**最坏的情况不是腐败**。作者说得很清楚：最坏情况是显而易见的腐败，但**通常是出于善意自然发生的**——监管者并未寻求充分反馈、没做综合评估（这正是可得性偏差与证实偏差在起作用：他听到的都是天天出现的那群人的声音，看不见沉默的大多数）。这个解释很重要，因为它意味着要医治它，靠抓坏人是不够的。

解药书里给的是布兰代斯的那句话：**阳光是最好的消毒剂**——提高透明度与事后问责，能减少俘获。

判据一句话：**这项监管的受益者是不是一个有组织的少数群体，而成本被摊到了不成组织的大多数头上？**

## A1 — 书中的应用 (Past Application)

### 案例: 核管理委员会与职业许可
- **问题**: 监管机构为什么会系统性地放松对自己监管对象的要求？是因为有人被收买，还是别的原因？
- **方法论的使用**: 作者用了两类证据。第一类是美联社对美国核管理委员会的调查：该机构反复削弱或不执行已有的安全标准——其中一个具体结果是，把阀门泄漏的限额放宽到了原来的 20 倍，使得老旧反应堆可以"达标"。这里看到的是典型的俘获后果：标准的执行尺度偏向了被监管方，而不是出于安全。**值得注意的是它没有停留在"有人腐败"这个解释上**。第二类是职业许可：美国需要执照的工作占比从 1950 年代的约 5% 升到约 25%，美容执照的办理耗时长到纽约 232 天、艾奥瓦 490 天——这种进入壁垒保护的是已经在里面的人。
- **结论**: 两类证据合起来说明，俘获的主要形态不是明显的腐败，而是**出于善意的自然发生**——监管者未寻求充分反馈、未做综合评估，只听得见有组织的行业方的意见。因此作者在最后给出的对症解药是布兰代斯的阳光：**提高透明度与事后问责**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **遇到一项明显偏袒行业内既得利益者的规定**: 用户感到"这规则奇怪地保护的就是被管的那批人"，需要识别机制而不是停留在抱怨。
2. **想进入某个受牌照/资质限制的市场**: 需要判断门槛的真实目的是安全还是准入控制，并据此选择策略。
3. **评估某个行业的竞争格局为什么长期不变**:  incumbents 多年不倒且缺乏创新，要看是不是有一条由监管提供的护城河。
4. **参与行业标准制定或公共政策讨论**: 需要预判"受伤的人分散、受益的人在场"会造成的结构性偏向。

### 语言信号 (用户的话里出现这些就应激活)

- "这个规定明明是在保护那些被监管的公司"
- "为什么这个牌照这么难考/要这么久"
- "监管部门为什么不管他们"
- "行业协会主导了整个标准的制定"
- "这个门槛说是为了安全，但看起来是在挡新人"
- "监管者离职后都去了被监管的公司"
- "The regulator is captured." / "Why does this license take so long?" / "The rules protect the incumbents."

### 与相邻 skill 的区分

- 与 `mm-barriers-to-entry` 的区别: 进入壁垒是**结果态**（进入某市场的门槛高），管制俘获是造成这种门槛的**一条具体政治成因**。这个壁垒可能来自规模、资本、技术；只有当它被监管规则制造出来时才是俘获。
- 与 `mm-principal-agent-problem` 的区别: 委托代理问题说的是**代理人（监管者）追求自身利益而非委托人利益**的一般结构；管制俘获是它在监管场景里的具体形态，并额外给出了成因（利益集中 vs 受损分散、旋转门）和解药（阳光）。问"为什么代理人偏离了委托人"用前者，问"这个监管机构为什么保护行业"用后者。
- 与 `mm-revolving-door` 的区别: 旋转门是成就俘获的**两条成因之一**（离职后可去被监管行业拿高薪）；管制俘获是包含它在内的**整体现象与分析框架**。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认受益方是不是有组织的少数群体**
   - 完成标准: 明确指出这项规则保护了谁的名字（具体企业/协会/持照者群体），以及他们是否有持续游说的能力（专职人员、预算、常驻 presence）。
   - 判停条件: 若受益方与受损方都同样有组织（例如两家企业长期对打），则这不是俘获，停在这里并说明。
2. **确认成本是不是落在分散的多数人头上**
   - 完成标准: 估算每个受损个体分摊到的损失金额，并说明为什么它没有高到让任何人有动力去组织反对。这是俘获能长期维持的核心原因。
3. **检查是否存在旋转门**
   - 完成标准: 给出可核查的事实：监管/立法方人员流向被监管行业的记录、时间间隔、薪酬落差。若查不到，明确说"未发现证据"而不是推定成立。
4. **先排除"善意发生"这个更常见的解释**
   - 完成标准: 检查并记录监管者是否征求了充分反馈、是否做过综合评估。按书中明示，通常是出于善意自然发生的（可得性偏差与证实偏差），默认应当先怀疑这一条，只有在有直接证据时才升级到腐败假设。
5. **看它是否真的制造了进入壁垒**
   - 完成标准: 用具体数据检验准入效果——牌照数量是否受限、审批耗时（如纽约 232 天 / 艾奥瓦 490 天这类可比数据）、从业占比的变化趋势。拿不到数据的，明确标注为待验证。
6. **给出解药与参与路径**
   - 完成标准: 按布兰代斯的建议具体化：明确列出可以提高透明度的动作（公开会议记录与游说登记、披露标准制定过程中的各方意见、公开审批时长数据）与可以加强事后问责的动作（回溯性评估、责任追究机制），并为本轮给出用户能够参与的一两个具体抓手。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **只是在权衡某项监管的利弊**: 那是政策分析，不预设俘获，直接做成本收益分析。
- **用户需要的是合规咨询**（怎么拿到牌照、怎么满足要求）: 分析俘获不能帮他通过审批。
- **没有监管方存在的纯粹市场竞争**: 没有监管，就没有可被俘获的对象。

### 书中警告的失败模式 / 容易误用的地方

- **书中明示**: **最坏情况是显而易见的腐败，但通常是出于善意自然发生的**——监管者未寻求充分反馈、未做综合评估（可得性偏差、证实偏差在起作用）。这是最重要的一条：默认假设应当是"善意的疏忽"，而不是"有人收了钱"。轻易指控腐败既不准确，也会让讨论立刻失焦。
- （推导, 非书中明示）**把任何对自己不利的规则都称为俘获**: 这是常见误用。俘获要求"受益方有组织、受损方分散"这一结构性条件，仅凭"这条规定对我不利"不足以成立。第 1、2 步就是为此设的检验。
- （推导, 非书中明示）**忽视它也发生在政府之外**: 书中特意点出职业许可制度，说明俘获不限于政府监管机构。只盯着公务员会漏掉行业协会、认证机构这类场景。
- （推导, 非书中明示）**只看意图、不看效果**: 俘获可以从完全善意的过程中产生。判断依据是实际产生的准入效果，而不是参与者的主观善意——E 段第 5 步的量化检验因此是必要的。

### 容易混淆的邻近模型

- **政府失灵（government-failure）**: 管制俘获是政府失灵的**一种成因**，前者是更大的分类。
- **道德风险（moral-hazard）**: 它描述被保护者因不必承担后果而行为变形；管制俘获描述的是规则为什么会偏向保护者。二者可以叠加——被俘获的监管既制造了壁垒，也让被保护者敢于承担更大风险。
