# 认知失调（cognitive dissonance）

## R — 原文 (Reading)

> "认知失调"指的是同时持有两个相互矛盾、彼此不协调的观念而备感压力。
>
> — 《思维模型》, 第1章 少犯错 > 进步总在葬礼后

---

## I — 方法论骨架 (Interpretation)

认知失调描述的是一种**心理压力**：你脑子里同时装了两个不能同时为真的东西——"我是个理性的人"和"我又一次做了那个蠢决定"——这种不协调本身让人难受，大脑会本能地去消解它。

消解有两条路：要么修正观点（"我上次判断错了"），要么把矛盾信息合理化地抛在脑后（"那次情况特殊""源头数据有问题""别人也一样"）。大脑几乎总是选第二条，因为它更省力，也因为它保护的是"我没错"这个更上位的感觉。所以这个模型的重点不是"人会犯错的感受"，而是**人会为不修正而付出额外的解释成本**。

关键判据只有一句：**我此刻是在修正观点，还是在给观点找解释？** 找解释的特征是：解释不能被证伪、解释只在自己的事上成立、解释数量随着证据增多而增多。这也是为什么认知失调是证实偏差的燃料——只要先消解了矛盾，就不需要去看反面证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户为一个已经投入的决定辩护，且证据正在变坏（项目、投资、招聘、分手与否）。
2. 用户复述一段自相矛盾的话而自己没察觉（"我很在意健康" + "我天天熬夜"）。
3. 用户的解释越来越多、越来越细，但结论始终不变。
4. 用户在批评别人做了某件事，而自己正在做同一件事。
5. 用户明确表达内心的烦躁/别扭，但说不清为什么。

### 语言信号
- "我觉得没问题，只是数据口径不对"
- "道理我都懂，但这次情况不一样"
- "我不是不认错，我是觉得……（一串解释）"
- "我自己都说服不了自己"
- "听着很矛盾是吧，可是……"
- "cognitive dissonance / rationalizing / I know it doesn't add up"

### 与相邻 skill 的区分
- 与 `mm-confirmation-bias` 的区别: 证实偏差是"只挑支持自己的证据看"（行为在收集端），认知失调是"已经撞上矛盾证据后怎么把它消化掉"（行为在处理端）。一个是过滤器，一个是消解器。
- 与 `mm-backfire-effect` 的区别: 逆火效应是被摆出反面证据后**立场更强硬**，认知失调是立场不变但**解释变多**；前者是加固，后者是打补丁。
- 与 `mm-self-serving-bias` 的区别: 自利性偏差是归因式的好了归我、坏了归环境，认知失调的范围更宽，任何两个观念的冲突都算，不必涉及成败归因。

## E — 可执行步骤 (Execution)

1. **把用户同时持有的两个观念分别摆出来**
   - 写成"A：……"和"B：……"，用用户自己的措辞。
   - 完成标准: 两句话并列，用户承认两句都是自己相信的。
2. **确认它们是否真的互斥**
   - 问一句："如果 A 为真，B 还能为真吗？"
   - 完成标准: 用户给出"不能"或"能，因为……"。
   - 判停条件: 若用户给出的是可成立的限定条件（真例外），则不是认知失调，退出本 skill。
3. **把用户已经给出的解释列成清单**
   - 逐条标上：可证伪 / 不可证伪；只在此事成立 / 同类事也成立。
   - 完成标准: 至少 3 条解释被分类，并指出有几条属于不可证伪。
4. **做一次"换人会怎么判"测试**
   - 问："同样这些事实，如果是你同事/竞品发生的，你会怎么解释？"
   - 完成标准: 用户给出一个与自辩不同的解释，说明解释是位置依赖的。
5. **把矛盾转成可检验的一句话**
   - 例如："下个月留存若不回升到 X，就说明方向有问题。"
   - 完成标准: 产出一条有阈值、有时间点、可被事实推翻的陈述。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 双方观点不同的正常争论：那是分歧，不是失调。
- 用户已经在主动找反面证据、主动证伪自己：说明失调并未发生，不需要干预。
- 用户的矛盾陈述源于信息不全而非心理防御：此时缺的是信息，不是提醒（推导，非书中明示）。

### 容易误用的地方
- 容易变成"你在自我辩护"的贴标签式指控，引发防御而不是反思（推导，非书中明示）。更有效的做法是把两个观念并排摆出来让用户自己看。
- 书中把认知失调定位为证实偏差等有害影响得以持续的**根源**，因此只消除一次失调不等于修好判断——还要改信息输入的习惯（书中明示）。
- 容易把"合理的例外说明"误判为失调：关键在于解释是否可证伪，而不是解释是否存在（推导，非书中明示）。
