# 动态平衡（homeostasis）

## R — 原文 (Reading)

> 具体是指机体针对某个特定目标（如体温）持续对自身进行调节。
>
> — 《思维模型》, 第4章 > 别跟自然对着干

---

## I — 方法论骨架 (Interpretation)

动态平衡是系统的自我稳定机制：它围绕某个目标值持续监测，一旦偏离就启动反向修正，竭力把状态拉回原处。太冷就发抖产热，太热就流汗降温——两个方向相反的机制同时存在，只为了守住同一个体温。

关键洞察是：**这不是故障，这是设计**。社会、组织、家庭、个人都会围绕核心文化价值观或被考核的指标表现出同样的自我稳定，目的是"保护自己"。所以当你推动改变时，你面对的不是"对方不配合"，而是一整套有明确目标的调节回路。

推论有三条。第一，改变之所以被弹回，往往不是力度不够，而是你没识别那个正在被保护的目标值。第二，系统会绕路——堵住一条路，它会从另一条路回到目标值（就像游说团体总能找到绕过法规的新方式继续注资）。第三，所以在动手之前，必须先识别并预先对冲那些与你背道而驰的潜在机制，否则你的干预会被反向吸收。

判据是：如果我推一把，系统会朝哪个方向回弹？回弹到什么值？谁在维护那个值？

## A1 — 书中的应用 (Past Application)

### 案例: 美国竞选财务制度改革屡屡失败

- **问题**: 立法者反复通过限制政治献金的法规，但金钱总能以新形式继续流入选举。
- **方法论的使用**: 把竞选资金系统看作围绕"资金影响力"自我稳定的机体——法规堵住一个渠道，游说团体就找到另一个新方式继续注资。
- **结论**: 单点封堵无效，因为系统在保护一个目标值，而不是在执行某条具体规则；必须识别并同时对冲所有替代通路。

### 案例: 为了减肥而多锻炼，结果食欲大增

- **问题**: 增加运动量想减肥，身体却用更强的饥饿感把体重拉回原点。
- **方法论的使用**: 承认身体在围绕"体重设定点"做自我调节，锻炼造成的能量缺口会被食欲增加反向补偿。
- **结论**: 预先对冲——有人锻炼后服用慢消化蛋白粉以保持饱腹感，抵消那条反向回路。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户推了一项改革（新流程、新考核、新规矩），几周后被悄悄绕过、打回原形——需要帮他找出被保护的目标值和绕行路径。
2. 用户在做个人改变（减肥、早起、戒手机），每次反弹——需要识别身体的补偿回路并预先对冲。
3. 用户在设计激励或 KPI，担心引发扭曲——需要预判系统会把这个指标稳定在什么值上、会牺牲什么来守住它。
4. 用户困惑于"明明大家都知道这样不好，为什么组织就是不改"——需要指出那不是愚蠢，是自我稳定在起作用。

### 语言信号 (用户的话里出现这些就应激活)

- "我们改了三次了，每次都弹回原样。"
- "上有政策，下有对策。"
- "越减越胖 / 越忙越乱 / 越想早睡越睡不着。"
- "大家都觉得该改，但就是推不动。"
- "Every time we change the rule, they find a workaround."
- "It always snaps back to where it was."

### 与相邻 skill 的区分

- 与 `mm-inertia` 的区别: 惯性是"不动"（维持当前运动状态，缺乏外力就不变）；动态平衡是"主动回弹"（偏离后启动反向修正把它拉回来）。惯性的系统被推一下会移动，动态平衡的系统被推一下会回来。
- 与 `mm-cobra-effect` 的区别: 眼镜蛇效应讲的是激励设计错误导致**越解决越糟**的意外后果；动态平衡讲的是系统**回到原状**的自我修正。前者结果是恶化，后者结果是复原。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别被保护的目标值**
   - 追问：系统在努力维持什么不变？是体重、利润率、权力结构、团队规模、还是"不得罪人"的文化？
   - 完成标准: 写出一句"这个系统在把 ___ 维持在 ___"；若写不出，改用 `mm-inertia` 或直接说明这不是动态平衡场景。
2. **枚举反向修正回路**
   - 找出至少 2 条系统用来回归目标值的机制（正式规则之外的潜规则也算，如"大家会互相提醒别太突出"）。
   - 完成标准: 至少 2 条具体机制，每条都能指出是谁/什么在执行它。
3. **预测绕行路径**
   - 针对用户打算采取的措施，推演：系统会从哪条我没堵的路绕回去？
   - 完成标准: 至少 1 条明确的绕行预测。
4. **设计对冲动作**
   - 对每条反向回路配一个对冲措施（如锻炼后的蛋白粉），而不是加大主推力。
   - 完成标准: 每条已识别的反向回路都有对应的对冲动作。
   - 判停条件: 若被保护的目标值本身是合理且不该打破的（如人体血糖稳定、组织的核心价值观），则停止"打破它"的方案，改为"顺着它设计"——回到步骤 1 重新框定问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯机械设备或无反馈回路的技术故障——没有自我调节主体，套用只会拟人化。
- 需要立刻止损的紧急场景（生产事故、安全事件）——先止血，再做机制分析。
- 用户只是需要情绪支持而非机制分析时——"他就是不改"有时指向的是关系问题，不是系统问题。

### 书中警告的失败模式 / 容易误用的地方

- 动态平衡会让我们保留并非最优的安排——有害的人际关系、糟糕的组织流程、毫无成效的政府政策。（书中明示）
- 改变极具破坏性，抵制变化"合情合理"——不要在分析中把对方妖魔化为"保守派"。（书中明示）
- 过度使用风险：把一切反弹都解释为"系统在自我保护"，可能掩盖真正的执行不力或资源不足。（推导，非书中明示）

### 容易混淆的邻近模型

- 与**勒夏特列原理（le Chatelier's principle）**: 化学中的平衡移动同样是对扰动的反向回应，两者机制高度相似，但动态平衡强调生物学/社会系统的"目标值"与"主动性"。
- 与**惯性**: 见上文 A2 区分——一个是不动，一个是回弹。
