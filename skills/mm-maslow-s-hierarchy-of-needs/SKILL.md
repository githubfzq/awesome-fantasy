# 马斯洛需求层次（Maslow's hierarchy of needs）

## R — 原文 (Reading)

> 马斯洛指出，要想发挥出全部潜力（他称之为“自我实现”状态），首先需要满足基本的精神和物质需求：生理（食物、水等）、安全（避难所、免于恐惧等）、爱（人际关系、支持等）和自尊。
>
> — 《思维模型》, 第8章 > 释放潜能

---

## I — 方法论骨架 (Interpretation)

马斯洛认为，人只有底层基本需求（生理、安全、爱、自尊）得到满足后，才能发挥全部潜力，进入他称为**自我实现**的状态。层级从下到上是：生理 → 安全 → 爱与归属 → 自尊 → 自我实现。

这个模型在今天最有用的地方不是它的金字塔图，而是它提供的**诊断顺序**：当某人无法充分发挥潜能时，先检查是哪一个底层需求没有被满足，而不是先去怀疑能力或态度。

书中给出的映射非常实用：

- **冒名顶替综合征** → 反映「自尊」层未满足；
- **混乱的人际关系、正在闹分手** → 反映「爱/归属」层未满足；
- **在食物匮乏或暴力环境中长大的孩子有学习障碍** → 源于「安全」层未满足。

换句话说，很多看起来是"能力问题""动力问题"的现象，往下一层看其实是"某个底层需求在漏"。在漏的那一层修，比在顶层喊口号有效。

这个模型也接受批评：批评家质疑这些层次是否真的存在、是否因文化或环境而异。作者的态度很务实——**"思考这个模型有助于弄清为什么没能充分发挥潜力"**，把它当作诊断清单而非严格的心理学定律。

关键判据：这个人是不是"能做好但做不出来"？如果是，往下查需求层；如果确实不会做，那是能力问题，本模型不适用。

---

## A1 — 书中的应用 (Past Application)

### 案例: 三种"发挥不出潜力"的层级归因

- **问题**: 人为什么有能力却发挥不出来？
- **方法论的使用**: 书中把三种常见现象映射到需求层次——冒名顶替综合征被解释为「自尊」层需求未满足；闹分手中的人归属层未满足；在食物匮乏或暴力环境中长大的孩子学习困难，源于「安全」层未满足。
- **结论**: 按层级从下往上逐层排查，比笼统地归因于"不够努力"更能找到真正的阻塞点。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队成员有能力但长期状态低迷，绩效说不清原因地下降。
2. 用户自己"什么都具备了却提不起劲"，需要自诊。
3. 管理者在设计激励方案，想知道该从哪一层下手。
4. 团队士气整体低落，用户怀疑是文化/氛围问题。

### 语言信号 (用户的话里出现这些就应激活)

- "他明明能做，就是发挥不出来"
- "最近整个人状态不对"
- "团队一点士气都没有"
- "我什么都不缺，但就是提不起劲"
- "大家好像都不太有归属感"
- "why isn't she performing up to her potential / basic needs"

### 与相邻 skill 的区分

- 与 `mm-impostor-syndrome` 的区别: 冒名顶替综合征是一个**具体现象**，本模型把它定位为「自尊层未满足」的**一种表现**；诊断用马斯洛，干预用三步法。
- 与 `mm-aligning-incentives` 的区别: 激励一致假设人是被外部回报驱动的，靠调整利益结构；马斯洛指出若底层需求未满足，外部激励基本无效。
- 与 `mm-scarcity` 的区别: 稀缺描述资源不足对认知带宽的占用（机制层面）；本模型给出的是需求层级清单（结构层面），可用于定位是哪一类稀缺。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认前提是"能做好但做不出来"**
   - 完成标准: 明确排除能力不足与流程障碍。
   - 判停条件: 若确实是能力问题，退出本 skill，转为能力建设方案。
2. **从最底层逐层排查**
   - 完成标准: 依次检查生理（睡眠、饮食、健康）、安全（收入稳定性、工作保障、免于恐惧）、爱与归属（人际关系、团队融入）、自尊（被认可、是否被羞辱），每层给出"满足 / 存疑 / 明显未满足"。
3. **定位阻塞层并停止上查**
   - 完成标准: 明确指出最低的那个未满足层级——修复它比继续往上查更有价值。
4. **给出该层的具体补救动作**
   - 完成标准: 针对定位到的层级给出 1-2 个可执行的动作（例：安全层 → 明确续约/绩效预期；归属层 → 修复关键关系；自尊层 → 公开认可具体贡献）。
5. **标注模型的不确定性**
   - 完成标准: 提醒用户这些层次是否真的存在、是否因文化或环境而异存在争议，本诊断是启发式而非定论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 明确的能力不足或流程/资源问题——往下查需求层会掩盖真问题。
- 涉及临床心理健康问题（抑郁、创伤）——应转专业帮助，本模型不是诊断工具。
- 用它来替代表面上的尊重：把一切不满都解释为"底层需求没满足"，会变成对合理诉求的敷衍。

### 书中警告的失败模式 / 容易误用的地方

- 批评家质疑：这些层次是否真的存在、是否因文化或环境而异。作者的态度是"思考这个模型有助于弄清为什么没能充分发挥潜力"——把它当诊断清单，不当定律。
- （推导, 非书中明示）层级顺序并非严格：现实中人会在底层未满足时仍追求高层需求，不要用它去否定某人的追求。
- （推导, 非书中明示）在组织中套用时，"安全"层常被误解为只指人身安全，实际还包括收入稳定、免于被随意解雇与羞辱。

### 容易混淆的邻近模型

- **冒名顶替综合征（impostor syndrome）**: 本模型可解释它（自尊层未满足），但干预手段来自另一模型。
- **激励一致（aligning incentives）**: 外部利益通道，在底层需求未满足时效果有限。
