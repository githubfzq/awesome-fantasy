# 套利（arbitrage）

## R — 原文 (Reading)

> 利用同一产品在两种不同情况下的价格差，这种做法称为套利（arbitrage）。
>
> — 《思维模型》, 第9章 > 开篇

---

## I — 方法论骨架 (Interpretation)

同一个东西，在 A 处值 50 块，在 B 处值 200 块，你在 A 买、在 B 卖，中间的差额就是套利。

价差为什么会存在？因为**买卖双方没有在同一个价格上相遇**。造成这种错位的通常是四类摩擦：信息不对称（B 处的人不知道 A 处有货）、地理阻隔（跨地区运输麻烦）、渠道区隔（不同平台的用户互不重叠）、归类差异（同一个东西被归到不同类别，被不同的买家群体看到）。

为什么价差一定是短暂的？因为**套利行为本身就在消除价差**。你在 A 处买入会增加 A 处需求、推高 A 价；你在 B 处卖出会增加 B 处供给、压低 B 价。更关键的是，一旦别人看见你在赚这个钱，会立刻模仿，供给涌入，价差被竞争抹平。作者明确说"像这样的价格差往往不会持续太久"。

由此得出这个模型最重要的含义：**套利不需要任何持续优势**。它不要求你技术更好、品牌更强、成本更低，只要求你比别人**先看到**并且**动作快**。所以它无法积累，也护不住——你能做，别人明天也能做。

关键判据：这个机会的利润来自**结构性优势**（我能做你做不了）还是**短暂的时间差**（我先看到）？如果是后者，它就是套利，必须不断寻找下一个机会才能维持收入，而不是把这个机会做深。

## A1 — 书中的应用 (Past Application)

### 案例: 劳伦的 eBay 婚纱转卖
- **问题**: 同一件设计师婚纱，在不同的商品分类下，被完全不同的人群看到，因而被给出完全不同的价格——而卖家和买家都没意识到这件事。
- **方法论的使用**: 劳伦在 eBay 上以 50 美元在"装扮和变装"类别下买到一件设计师婚纱，然后把它重新挂到"二手婚纱"类别，以 200 多美元转手。这里的价差来源不是商品本身有任何变化，而是**归类差异造成的受众错位**：找婚纱的人不会去逛"装扮和变装"，所以真正需要它的人根本没看见那个 50 美元的挂单。改一个分类标签，就把它挪到了愿意付高价的人群面前。
- **结论**: 作者用这个例子给整章定调——套利是真实存在的赚钱方式，但它靠的是发现一处**暂时的错位**，而不是建立了任何可以守得住的东西。正因为如此，它被定位为"持续竞争优势"的对立面，是本章随后要讲的所有护城河模型的反例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **发现两个市场/平台/渠道对同一件事定价差很多，想赚这个差价**: 需要先判定价差来源与可持续性，而不是直接投入。
2. **评估一门生意是不是"赚差价的"**: 需要看清它没有护城河、收入不可持续，从而决定是当作现金流还是当作事业。
3. **讨论竞争优势时混淆了"暂时的价差"和"结构性的优势"**: 需要把套利与持续竞争优势明确区分开。
4. **做跨境、跨平台、跨人群的贸易或投放时**: 需要识别摩擦在哪一侧（信息/地域/渠道/归类），并据此判断机会大小。

### 语言信号 (用户的话里出现这些就应激活)

- "这个东西在国内卖 50，到国外能卖 200"
- "我发现两个平台价格差挺大，能不能搬？"
- "这不就是赚信息差吗"
- "黄牛是怎么赚钱的？"
- "这个生意门槛太低，别人一学就会"
- "我们现在的收入主要靠信息不对称，能持久吗？"
- "Is this just arbitrage?" / "Buy low, sell high." / "There's a price gap between these two markets."

### 与相邻 skill 的区分

- 与 `mm-sustainable-competitive-advantage` 的区别: 二者在书中被明确定义为**对立面**。套利靠短暂的时间差和信息差，不需要任何持续优势，会被竞争快速抹平；持续竞争优势来自规模、品牌、网络效应等难以复制的结构性因素，能长期保持。判断一个机会属于哪一类，就看"别人明天能不能照做"。
- 与 `mm-market-power` 的区别: 市场支配力是"提价还能保住客户"的定价权，是持续竞争优势的**标志**；套利者没有任何定价权，他只是被动接受两个市场已经存在的价格，靠跑在别人前面赚钱。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认这是不是同一件东西**
   - 完成标准: 明确两边交易的对象是否实质等价（同一商品/同一服务/同一注意力）。若不等价（有附加服务、有品牌溢价、有风险差异），价差可能合理，本模型不适用。
   - 判停条件: 若不等价，结束并说明这是差异化定价而非套利。
2. **定位价差来源**
   - 完成标准: 归类为信息不对称 / 地理阻隔 / 渠道区隔 / 归类差异（可多选），并给出证据。不同来源决定不同的抹平速度。
3. **估算抹平速度与可提取总量**
   - 完成标准: 给出三个数字：单次利润率、每月可执行次数上限（流动性约束）、预计价差还能存在多久。据此算出这门生意的**总收入上限**，而不只是单次利润率。
   - 判停条件: 若总收入上限低于用户的机会成本，直接建议不做。
4. **判断它能不能转成结构性优势**
   - 完成标准: 明确回答"能不能"：执行这个套利的过程，会不会沉淀出规模、独家渠道、数据、品牌或关系？若能，指出该把利润再投到哪里去建护城河；若不能，明确告知这是消耗性现金流，应规划退出或寻找下一个机会。
5. **给出时间盒与止损线**
   - 完成标准: 因为价差必然衰减，必须为这笔生意设定明确的时间盒（做多久）与止损线（利润率跌到多少就撤），并预先列出 2-3 个候选的下一波机会方向。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **寻找长期战略/护城河时**: 书中明确定位套利是持续竞争优势的对立面，用它来做战略规划方向就错了。
- **价差已被多数人发现时**: 利润已被竞争抹平，剩下的只有执行风险。
- **价差来自合规或法律风险时**: 那不是套利机会，是风险敞口。

### 书中警告的失败模式 / 容易误用的地方

- **书中明示**: 作者明确指出"像这样的价格差往往不会持续太久"，套利是持续竞争优势的对立面，**不能作为长期护城河**。这是本模型最重要的一句话。
- （推导, 非书中明示）**把套利收入当成估值基础**: 用"我们月赚 X 万"去融资或扩张，若 X 全来自套利，扩张只会加速暴露它的不可持续性。
- （推导, 非书中明示）**只看单次利润率，不看可提取总量**: 很多套利的单次利润率极高但流动性极低（一个月只能做几单），总收入微不足道。必须算总量。
- （推导, 非书中明示）**误判价差来源**: 把"因为别人有品牌所以卖得贵"当成归类差异，会得出"我也挂过去就能卖同价"的错误结论。

### 容易混淆的邻近模型

- **规模经济（economies-of-scale）**: 规模变大让成本下降，从而能持续低价，这是可以守的；套利的低价来自暂时的错位，守不住。二者都能"卖得比别人便宜"，但机理完全不同。
- **网络效应（network-effects）**: 用户越多价值越高，形成正循环，是护城河；套利没有任何正循环，反而每次执行都在消灭自己的机会。
