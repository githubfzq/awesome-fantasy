# 选择性偏差（selection bias）

## R — 原文 (Reading)

> 研究中的吸烟者将是选择继续吸烟的人。这可能会引起一种偏差，也就是所谓的"选择性偏差"（selection bias）。在存在"选择性偏差"的情况下，无法确保"是否吸烟"是不同实验组之间唯一的区别因素。
>
> — 《思维模型》, 第5章 > 隐藏的认知偏差

---

## I — 方法论骨架 (Interpretation)

要判断"A 导致了 B"，逻辑上必须保证两组之间**只有 A 不同**。随机分组正是为这一点而发明的：它把人的各种特征（性格、家境、动机）平均摊到两边，让"是否接受处理"成为唯一系统性差别。

一旦分组不是随机的，而是让人自己走进去的，这个保证就消失了。继续吸烟的孕妇，同时也更可能做出其他医学上存疑的选择；把孩子送进名校的父母，同时也更有经济实力、更重视教育。于是两组之间的差距里，混进了"是什么样的人会选这条路"这一整包因素。

关键判据是两个问题：**"是什么让这个样本呈现出非随机性？"** 以及 **"这个样本欠缺了什么？"** 作者并未主张废止这类研究，只是要求：从非随机实验得出结论时必须特别谨慎，并在解读时把偏差当成结论的一部分。

---

## A1 — 书中的应用 (Past Application)

### 案例: 孕期吸烟研究与择校研究

- **问题**: 想研究孕期吸烟对胎儿的影响、想研究名校是否真的提升了学生成绩，但都不能把人随机分配去吸烟或随机分配学校。
- **方法论的使用**: 作者指出，研究中能观察到的吸烟者，是"违背医嘱仍然选择继续吸烟"的那批人——她们可能同时做出其他医学上存疑的选择，因此"是否吸烟"不再是组间唯一的区别因素。同样的逻辑用于择校：名校成绩好、录取率高，很大一部分可以由选择性偏差解释——是父母的经济实力与对教育的重视，把孩子送进了名校，而不是名校单独制造了这些结果。
- **结论**: 非随机分组下，组间差异不能干净地归因于所研究的那个因素；必须追问自选择带来的一整包伴随特征，并在下结论时把偏差计入。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用"用了某功能的用户留存更高"来论证该功能提升了留存。
2. 看到"名校/名企出来的人成就更高""喝红酒的人更健康"这类结论，问是不是真的。
3. 分析一份用户调研、员工敬业度调查或 A/B 分流不均匀的数据，问能不能下结论。
4. 评估医学/社会科学观察性研究（如"孕期吸烟与低体重儿"）的可信度。

### 语言信号 (用户的话里出现这些就应激活)

- "用了这个功能的用户，留存明显更高"
- "是不是他们本来就不一样？"
- "这个调查的样本有没有代表性"
- "非要说 A 导致了 B，说得通吗"
- "Is this just selection bias?"

### 与相邻 skill 的区分

- 与 `mm-survivorship-bias` 的区别: 幸存者偏差专指**失败者整批不进样本**（离职员工、被击落的飞机）；选择性偏差泛指任何非随机分组造成的混杂，样本里仍然看得到"另一组"。
- 与 `mm-confounding-factor` 的区别: 混淆因素是具体那第三个变量（如父母收入）；选择性偏差是**造成它出现的分组机制**——先有非随机分组，才让混淆因素分布不均。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认分组机制**
   - 完成标准: 能明确说出"是谁决定每个个体进哪一组的"——研究者随机指派，还是个体/环境自选。
   - 判停条件: 若是真随机分组且执行无缺陷，直接停止，不要调用本 skill 的质疑框架。
2. **追问"是什么让样本呈现非随机性"**
   - 完成标准: 至少列出 2 个可能同时驱动"选择进入该组"和"结果"的特征（书中模板：更冒险、更重视教育、更有钱）。
3. **追问"样本欠缺了什么"**
   - 完成标准: 指出哪一类个体从未获得进入样本的机会，以及缺失方向会让结论偏向乐观还是悲观。
4. **重述结论并降级**
   - 完成标准: 把原本的因果句改写为"相关 + 自选择"句，并给出可补救的办法（随机化、匹配、把混淆变量纳入回归、明确写出偏差方向）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分组本来就是随机指派且执行良好的实验（随机对照实验的核心卖点正是消除自选择）。
- 用户只是想描述样本本身（"我们这批用户里有多少人用了功能"），不做跨组归因。

### 书中警告的失败模式 / 容易误用的地方

- 作者并非主张废止这类研究，而是强调**"根据非随机实验得出结论时必须特别谨慎"**，并把偏差纳入解读。
- （推导，非书中明示）把"存在选择性偏差"当成"结论一定错"是过度使用：偏差有方向也有大小，正确的动作是估计它有多大，而不是一句"有偏差"就否掉全部信息。

### 容易混淆的邻近模型

- 幸存者偏差（survivorship-bias）：失败者完全缺席样本的特殊情形。
- 混淆因素（confounding-factor）：造成组间不可比的那个具体第三变量。
