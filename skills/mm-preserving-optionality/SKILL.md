# 保留可能性（preserving optionality）

## R — 原文 (Reading)

> 另一个来自经济学的模型"保留可能性"（preserving optionality）可以略微削弱"路径依赖"的局限性。所谓的"保留可能性"，就是做出能保留未来选择权的决定。
>
> — 《思维模型》, 第2章 > 越来越热

---

## I — 方法论骨架 (Interpretation)

保留可能性是路径依赖的解药：既然过去的决定会锁死未来的选项，那就主动做出**能保留未来选择权**的决定。它的价值不在于"选得更好"，而在于"晚一点再选"——把决定推迟到信息更充分的时候。

具体手段有几类：把超额利润投入"未雨绸缪基金"，让自己在被迫做选择时有退路；投入时间学习未来用得上的新技能，保持可迁移性；在信息更充分之前推迟拍板（中性思考，不预设立场）；选择多个领域都很强的平台而不是过早定点。

它为什么有效？因为信息是随时间的推移而增加的，越晚做决定，决策质量越高——前提是晚做不会让你失去什么。

关键判据是一个比较：**保留一个选项的成本 vs 该选项未来对你的价值**。成本低于未来价值就保留，反之就果断放弃。

但要诚实：保留可能性本身有成本。保留众多选项通常需要更多资源、更多时间——全职工作同时想重返学校、名下多栋房子、同时负责多个项目，都会显著增加成本。作者明确指出"保留可能性也得适度"，需要在保留可能性与路径依赖之间找到平衡。

## A1 — 书中的应用 (Past Application)

### 案例: 大学选校与劳伦的运筹学

- **问题**: 大学新生面临专业与学校的选择。作者的建议是选一所多个感兴趣领域都很强的高校，而不是急于定校、过早锁定方向。作者之一劳伦自己的经历是：为了保留可能性选择了宽泛的运筹学，而不是狭隘的生物统计学。
- **方法论的使用**: 两者的取舍点在于"这个选择关掉了多少未来的门"。宽泛的运筹学保留了向多个方向走的可能，狭隘的生物统计学则更早锁定。作者的判据是保留一个选项的成本与该选项未来价值的比较。
- **结论**: 但作者也给出了代价——劳伦因为迟迟不确定方向，最终多读了一年才毕业。这印证了书中明确的提醒：保留可能性也得适度，保留众多选项通常需要更多资源、增加成本，需要在保留可能性与路径依赖之间找到平衡。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需要过早定点、但又不确定方向时：选专业、选第一份工作、选技术栈、选创业方向。
2. 面对一个长约束缚（多年合同、独家协议、绑定平台），犹豫签不签。
3. 信息还不充分但被催着拍板：要不要推迟决定、推迟多久。
4. 规划财务与技能：需要多少"未雨绸缪基金"、该学什么来保持可迁移性。
5. 已经保留了太多选项，感觉资源被摊薄、迟迟无法深入：需要判断该不该收敛。

### 语言信号 (用户的话里出现这些就应激活)

- "现在定下来会不会太早"
- "我不想把自己锁死"
- "以后还能换吗"
- "要不要先都试试"
- "我什么都想保留，结果什么都做不深"
- "preserving optionality / keep my options open / stay flexible / defer the decision"

### 与相邻 skill 的区分

- 与 `mm-path-dependence` 的区别: 路径依赖是**约束**（选项被过去锁定），保留可能性是**对策**（刻意保留选择权）。两者必须平衡看——只讲保留会摊薄资源，只讲锁定的现实会放弃能动空间。
- 与 `mm-reversible-vs-irreversible-decisions` 的区别: 可逆/不可逆决策给出的是**决策速度的规则**（能退回来就快速试错），保留可能性给出的是**选项管理的策略**（该不该为某个选项付保留费）。前者管"多快决定"，后者管"保留几个选项"。
- 与 `mm-de-risking` 的区别: 去风险化是"把关键不确定性逐个消除掉以便行动"，保留可能性是"不消除不确定性，而是让自己不被任何一个结果困住"。前者主动降低风险，后者保持退路。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出这个决定会关掉哪些未来的门**
   - 明确：选定之后，哪些选项将不再可用或成本极高？
   - 完成标准: 至少 2 个被关闭的具体选项。
   - 判停条件: 若没有选项被关闭（决定完全可逆），停止本 skill，改用快速试错路径。
2. **估算每个选项的未来价值**
   - 问：如果未来我要走这条路，它值多少？实现的概率有多大？
   - 完成标准: 每个被关闭的选项有一个价值×概率的粗略估计。
3. **计算保留该选项的成本**
   - 包括：资金（未雨绸缪基金、多付的费用）、时间（多读一年、多学一门）、注意力（同时推进多个项目）。
   - 完成标准: 每个保留动作有明确的成本数字或时间量。
4. **逐个比较并做出取舍**
   - 成本 < 未来价值×概率 → 保留；反之 → 果断放弃。
   - 完成标准: 每个选项有"保留/放弃"的明确结论与理由。
5. **设置收敛触发条件，防止无限保留**
   - 因为保留有成本且容易变成拖延，必须写明：什么信号出现时必须收敛、什么时间点必须决定。
   - 完成标准: 有具体的时间点或可观测信号，并提醒用户参考劳伦多读一年的教训。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 信息已经充分、拖延本身在产生成本时：此时应果断决定，继续保留只是在推迟（推导，非书中明示）。
- 决定本身完全可逆、保留不需要任何成本时：直接快速试错即可，无需专门的期权管理。
- 资源已经严重摊薄、需要聚焦才能突破时：此时的主要矛盾是过度保留，而非锁定（书中明示的方向）。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确指出"保留可能性也得适度"：保留众多选项通常需要更多资源、增加成本（全职工作时想重返学校、名下多栋房子、同时负责多个项目），需要在保留可能性与路径依赖之间找到平衡——这是书中明示的核心边界。
- 作者用自己的经历给出代价：劳伦为保留可能性选了宽泛的运筹学，但因为迟迟不定方向最终多读了一年才毕业（书中明示）。
- 容易把"保留选项"当成逃避决定的借口。必须设置收敛触发条件（推导，非书中明示）。

### 容易混淆的邻近模型

- 与路径依赖：一枚硬币的两面，需要同时评估。只强调一方都会走向极端——过度锁定或过度涣散。
- 与分析瘫痪：保留可能性是有成本的主动策略（付费买期权），分析瘫痪是无产出地持续收集信息；判断方法是看有没有为保留付出明确代价、有没有设收敛条件。
