## 使用方式：这不是流程，是菜单

十二法是**并列的**，没有先后顺序。按自己的类型与当下条件**任选一种**。

作者强调：成败取决于**决心**，而非喜好。他的原话（f33）是——

> "不管是多大的痛苦，只要集中全副精神来面对它，我就能有效地减轻痛苦，并让它转变成正面的感觉。要做到这样，必须有决心，我把这样的决心叫做'爱意'。"

**共同原理只有两条**（这是所有十二法的内核）：
1. **不评判地充分感受**——不把它深埋、不归咎伴侣、不用怒气麻痹。
2. **让某种比痛苦更大的东西进来**——呼吸、爱、灵魂之光、或单纯的注意力。

## 十二法

| | 方法 | 说明 |
|---|---|---|
| **A** | 向感觉吸入空气 | 找到情绪对应的身体部位，把呼吸导向那里，约六分钟后感觉会完全改变 |
| **B** | 吹气球 | 想象把感觉吹进气球，看着它膨胀、飘走 |
| **C** | 能量中心 | 沿能量中心（脉轮）引导感受 ⚠️ 有信仰前提 |
| **D** | 克里希那穆提的方法 | 做一个"容器"，不加诠释地容纳感觉 |
| **E** | 艺术家的方法 | 把感觉画出来、写出来、唱出来 |
| **F** | 运用肢体表达 | 用身体动作把感觉表达出来 |
| **G** | 去散个步 | 让感觉决定前进路线，感到平静即停（洗碗、吸尘、跑步同理） |
| **H** | 笔者的方法 | 观想感觉的颜色与声音，逐层深入其中心 |
| **I** | 听听感觉说什么 | 问这个感觉它想告诉你什么 |
| **J** | 释放重负 | 把重负交出去 |
| **K** | 感谢的效用 | 数算值得感谢的事——与「沟通受阻时主动表达感谢」是同一机制 |
| **L** | 分享你压抑的感情 | 像拔瓶塞，把一直压着的东西以健康方式释放 |

---

## 选型建议

- **有身体感受基础的人** → A（向感觉吸入空气）/ C / F
- **想象力强的人** → B / E / H
- **愿意开口的人** → I / L
- **最普适、无信仰前提的三项** → **A**（呼吸导向身体部位）、**G**（散步）、**L**（分享）

⚠️ C（能量中心/脉轮）有信仰前提，对不接受的读者不适用。

⚠️ L（分享压抑的感情）需要**分辨哪些可以分享**——"别火上浇油"。在冲突白热化时分享全部感受，会升级冲突而非释放。

---

## 时间参考

> "情绪停留不超过六分钟，除非你为它建造了一个家。"

即：情绪本身是短暂的，大约六分钟就会过去；**除非**你开始喂养它——为它编故事、找证据、反复咀嚼。

**这是判断"我在感受它"还是"我在喂养它"的实用标尺。** 若超过六分钟仍在其中，通常说明已经从"感受"滑入了"编故事"。

---

## 使用边界

- **不是急救手段**：十二法用于日常的情绪处理，不用于急性危机或创伤闪回。
- **不替代专业帮助**：若反复使用无效，说明情绪问题已超出自助范围。
- **不可证伪性提醒**：书中没有给任何一法的有效性证据，只有作者的自我介绍。把它当作**可尝试的菜单**，不要当作有保证的方案。
