# 均值（mean）

## R — 原文 (Reading)

> 均值（也称为"平均值"或"期望值"）衡量的是集中趋势（central tendency），或者说是数值趋于集中（centered）的位置。

> — 《思维模型》, 第5章 > 钟形曲线

---

## I — 方法论骨架 (Interpretation)

均值回答的是"这批数据的典型值大概在哪里"——把所有数值加总后除以个数。它是最常用的集中趋势指标，也是最容易在不知不觉中被误用的一个。

关键性质：**均值对极值毫无抵抗力**。只要往数据集里塞一个足够大的数，均值就会被拉走，而中位数纹丝不动。

书里用两组对比把这个性质讲透了：

- **体温数据集**：均值 98.25、中位数 98.3、众数 98 华氏度——三者几乎重合，因为分布是对称的。此时用哪个都行，均值是安全的代表。
- **2016 年美国家庭收入**：均值 83143 美元，中位数 59039 美元——相差 40%。因为收入是右偏的，少数极高收入把均值拉了上去。此时"平均家庭收入"描述的那个家庭，现实中几乎不存在。

所以判据是一条：**先看分布是否对称，再决定均值能不能当代表**。对称分布下均值、中位数、众数三者接近，均值好用；偏斜分布下均值会指向一个大多数人都够不着的位置。

作者还顺手拆了一个流传甚广的迷思：98.6 华氏度"并不是什么神奇的数值"，最新测得的平均体温更接近 98.2，而且女性略高于男性、一天中从早到晚上升约 0.5 摄氏度——即所谓"正常值"本身就是一个带条件的均值，不是一个固定常数。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要汇报"我们的平均客单价/平均响应时长/平均评分"，需要判断这个口径会不会误导听众。
2. 用户看到"平均收入/平均薪资"这类公开数据，想理解为什么和自己身边感受差这么远。
3. 用户发现均值在短期内剧烈跳动，怀疑被个别极值拉动，需要确认。
4. 用户要在均值、中位数、众数之间选一个作为北极星指标或 SLA 口径。

### 语言信号

- "我们的平均值是多少？"
- "这个平均数是不是被几个大单拉高了？"
- "为什么平均收入跟我的感受不一样？"
- "该看平均还是看中位数？"
- "98.6 度不是标准体温吗？"
- "average" / "mean vs median" / "is the average skewed?"

### 与相邻 skill 的区分

- 与 `mm-outliers` 的区别: 离群值讲的是**那个格格不入的数据点本身**要不要识别和处理；均值讲的是**它对汇总量的影响**。处理顺序是先找离群值，再算均值。
- 与 `mm-standard-deviation` 的区别: 均值给中心位置，标准差给围绕这个中心的分散程度。只有一个均值无法判断"典型"是否真的典型。
- 与 `mm-central-limit-theorem` 的区别: 中心极限定理说的是**样本均值**这个统计量本身的分布趋近正态，是关于多次抽样的定理；单个数据集的均值只是一个数。

## E — 可执行步骤 (Execution)

1. **问这个均值描述的是什么决策** — 完成标准: 明确用户拿它做什么（定目标、做汇报、算容量）；若决策依赖尾部（最慢的 5%、最大损失），直接指出均值不适用。
2. **同时算出中位数并与均值对比** — 完成标准: 得到两者数值；若差距 <5%，判定分布近似对称，均值可用；若差距显著，判定偏斜。
3. **判断偏斜方向并给出解释** — 完成标准: 说明是少数高值把均值拉高还是少数低值拉低，并指出"这个均值描述的那个人/那次请求在现实中是否存在"。
4. **检查极值影响** — 完成标准: 做一次"去掉最大 1% 后均值变化多少"的敏感性检验，量化极值的拉动幅度。
5. **给出口径建议** — 完成标准: 明确建议用均值、中位数还是两者并列汇报，并说明各自适合回答什么问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **决策依赖尾部而非中心**: SLA 承诺、风险敞口、容量规划这类场景要看 P95/P99 或最大值，均值会系统性地掩盖问题。
- **分布是多峰的**: 如果用户明显分成两群（免费用户 + 付费用户），均值指向的是两群之间的空地，对谁都不典型。
- **用来描述定性数据**: 对颜色、类别这类非数值数据，众数才有意义，均值无从计算。

### 容易误用的地方

- **把均值当成"正常的那个值"**: 作者特意指出 98.6 华氏度并不是什么神奇的数值，真实平均体温更接近 98.2，且随性别和一天中的时间变化——"平均值"不等于"标准值"或"应有的值"。（书中明示）
- **忽略均值背后分布的条件性**: 同一个均值可以由完全不同的分布产生，只看均值会丢失全部形状信息。（推导, 非书中明示）
