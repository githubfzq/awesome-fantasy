# 反应偏差（response bias）

## R — 原文 (Reading)

> 另一种可能无意中导致的偏差是"反应偏差"（response bias）。尽管某些类型的人不回应会导致出现"无反应偏差"，但就回应的人来说，各类认知偏差可能导致他们无法做出准确或真实的回应。

> — 《思维模型》, 第5章 > 隐藏的认知偏差

---

## I — 方法论骨架 (Interpretation)

无反应偏差是"人没来"，反应偏差是"人来了，但说的是假话或不准确的真话"。

它的要害在于：回应者**不是不愿意配合，而是没有能力或没有安全感给出准确答案**。书里列举了六条通道：

1. **问题措辞**——诱导性、误导性的问法直接把答案框住（"您是不是也觉得这个功能很方便？"）。
2. **问题顺序**——前一道题启动的想法会影响后一道题的答案。
3. **记忆不准**——"过去三个月您用了几次"这类问题，人根本记不清，只能现场编一个合理的数字。
4. **难以用数字表达感受**——"满意度打 1-10 分"要求人把模糊感受压成一个刻度，压的过程本身就丢信息。
5. **只讲对自己有利的事**——自利性偏差让受访者自然地修饰自己在故事里的角色。
6. **担心报复而撒谎**——书里点名的员工敬业度调查场景：即使匿名，只要存在被识别的可能，人就会给出安全的答案。

判据：问自己"**回答这个问题，对受访者有没有代价、有没有难度？**" 只要有，答案就会朝"代价最小、最容易给出"的方向漂移，而不是朝真相。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在写问卷/访谈提纲，想在发放前把诱导性措辞、顺序效应、难量化的问题挑出来。
2. 用户拿到自报数据（使用时长、满意度、习惯频率、自评绩效），要判断它能不能当事实来用。
3. 数据出现极端一致（98% 满意、所有人都说会推荐），用户怀疑不是真实分布。
4. 用户要调查一个敏感话题（违规、离职真实原因、对管理层的意见），担心匿名仍不够。

### 语言信号

- "大家都说满意，但好像没人敢说真话。"
- "这个问题是不是问得有点诱导？"
- "让他们自己报使用时长准吗？"
- "已经匿名了，为什么还是没人提意见？"
- "response bias" / "social desirability" / "leading question" / "self-reported data"

### 与相邻 skill 的区分

- 与 `mm-nonresponse-bias` 的区别: 无反应偏差是**没填的人**让样本不完整；反应偏差是**填了的人**让内容不可信。前者补访可缓解，后者补访无效，只能改问法或换数据源。
- 与 `mm-selection-bias` 的区别: 选择性偏差发生在"谁进入样本"；反应偏差发生在"样本给出什么答案"，是测量环节而非抽样环节的偏差。
- 与 `mm-framing` 的区别: 框架效应是同一信息的不同表述改变决策，是普遍心理规律；反应偏差是它在**问卷与访谈场景**里的具体后果，还额外包含报复恐惧、记忆限制等非框架因素。

## E — 可执行步骤 (Execution)

1. **逐题扫描诱导性措辞** — 完成标准: 把每道题改写为中立表述（去掉"是不是也觉得""众所周知"等），并确认正反面选项都给出。
2. **检查题目顺序** — 完成标准: 确认前面的题目不会启动影响后面答案的思路；必要时对整体感受类问题放在具体细节题之前，或随机化顺序。
3. **把"回忆题"换成"记录题"** — 完成标准: 凡涉及过去行为的频率/时长，改为查日志或缩短回溯窗口（"上周"而非"过去三个月"）。
4. **评估报复风险** — 完成标准: 判断受访者是否可能被识别（小样本、唯一部门、可交叉比对字段）；若有风险，改用第三方访谈、聚合到最小组规模、或换间接问法。
5. **与客观数据交叉验证** — 完成标准: 至少拿一个自报指标与行为日志/系统数据对撞，给出偏差幅度估计，然后决定该自报数据能否单独使用。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **回应率极低、样本本来就不完整时**: 先解决无反应偏差，否则你是在给一个已被筛过的样本修措辞。
- **指标可由系统直接记录**: 用户使用时长、点击次数这类数据用日志即可，做自报问卷是主动引入本可避免的偏差。

### 容易误用的地方

- **以为匿名就消除了报复恐惧**: 书里明确说人们可能因为担心遭到报复而撒谎；小样本、可交叉比对的字段会让"匿名"失效，匿名是必要条件不是充分条件。（书中明示的偏差来源；推论部分为蒸馏补全）
- **把偏差归咎于受访者不诚实**: 六条通道里有记忆限制和量化困难，属于能力问题而非诚实问题，处理方式完全不同。（书中明示通道；分类推论为蒸馏补全）
