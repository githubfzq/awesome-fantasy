# 正态分布（钟形曲线）（normal distribution）

## R — 原文 (Reading)

> 这类数据集的直方图呈现类似的钟形曲线：中间是一堆接近均值的数值，而随着离均值越来越远，数值越来越少。当一组数据呈现这种形状时，通常表明它源于正态分布（normal distribution）。
>
> — 《思维模型》, 第5章 > 钟形曲线

---

## I — 方法论骨架 (Interpretation)

正态分布（normal distribution）描述的是随机现象所有可能结果的分布概率，全部概率加起来是 100%。它画出来是一条钟形曲线：中间堆着大量接近均值的数值，离均值越远，数值越少。

它的威力在于**只需要两个参数就能完整刻画**：均值决定中心位置，标准差决定胖瘦。由此得到一条经验法则——约 68% 的值距均值不到 1 个标准差，约 95% 不到 2 个，几乎全部（99.7%）不到 3 个。有了它，你就能把"这个数正常吗"变成一个可以算的问题：算出它偏离几个标准差，就知道它有多罕见。

关键判据是**先确认形状再用法则**。自然界有很多现象确实服从正态分布（如身高），但作者明确提醒：还有许多其他常见概率分布适用于不同情况，并非所有数据都是正态的。

## A1 — 书中的应用 (Past Application)

### 案例: 美国成年男女身高分布

- **问题**: 想对"街上随机一个人的身高"做出合理猜测，并给出可信范围。
- **方法论的使用**: 作者用美国疾控中心数据绘制男女身高分布——两个分布均值不同，但都呈典型钟形。据此可以推断：街上随机一位女性身高约 162 厘米，一半概率落在 155–170 厘米之间，不足 147 或超过 178 厘米的不到 5%。
- **结论**: 一旦确认数据近似正态，用"均值 + 标准差"就能直接给出点估计与区间估计，无需逐个枚举。作者同时提醒：还有许多其他常见概率分布适用于不同情况，并非所有数据都是正态的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一批数据，想判断某个具体数值（一个用户的耗时、一笔订单金额、一次考核分）是"正常波动"还是"异常"。
2. 需要给出区间预测（"大概落在什么范围"）而不只是一个平均数。
3. 设定阈值、异常检测规则、SLA 指标，需要知道几个 sigma 对应多少比例。
4. 看到直方图/分布图，问"这像什么分布、能不能用正态分布的工具"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个数值算异常吗"
- "大概百分之多少的人会落在……之间"
- "偏离均值几个标准差"
- "画出来是不是钟形曲线"
- "Is this normally distributed?"

### 与相邻 skill 的区分

- 与 `mm-central-limit-theorem` 的区别: 中心极限定理解释**为什么样本均值会趋近正态**（哪怕原始数据不是）；正态分布本身只是描述**某一批数据的形状**。
- 与 `mm-fat-tailed-distributions` 的区别: 肥尾分布中极端值远比正态预测的常见，用 68-95-99.7 会严重低估尾部风险。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先看形状，再谈参数**
   - 完成标准: 用直方图/分位数检查是否符合钟形（对称、中间厚两边薄），并特别留意尾部是否过厚。
   - 判停条件: 若明显偏斜或厚尾，停止使用正态工具，改用合适的分布（肥尾/幂律等）。
2. **估出均值与标准差**
   - 完成标准: 给出两个参数的数值及其来源。
3. **套用经验法则给出区间**
   - 完成标准: 明确给出 1σ/2σ/3σ 对应的比例（约 68% / 95% / 99.7%）与目标区间。
4. **回答"有多罕见"**
   - 完成标准: 把目标值换算成偏离几个标准差，并给出它所处的大致百分位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 数据明显厚尾或幂律（收入、网站流量、爆款内容、保险赔付），此时正态会严重低估极端事件。
- 样本极少（只有几个点），连分布形状都无法判断时，硬套钟形曲线没有依据。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确指出：**还有许多其他常见概率分布适用不同情况，并非所有数据都是正态的**（书中并配图列举了其他分布）。
- （推导，非书中明示）"通常表明"不等于"证明"——直方图看起来像钟形，也只是提示而非确认，尾部样本少时尤其看不出来。

### 容易混淆的邻近模型

- 中心极限定理（central-limit-theorem）：解释均值的抽样分布为何正态。
- 肥尾分布（fat-tailed-distributions）：正态假设失效、极端值被低估的情形。
