# 军备竞赛（arms race）

## R — 原文 (Reading)

> 这个术语最初是形容两个或两个以上国家为了可能发生的武装冲突而制造武器，也可以引申形容任何一种愈演愈烈的竞争。
>
> — 《思维模型》, 第7章 > 开篇引言

---

## I — 方法论骨架 (Interpretation)

军备竞赛最初指两国为可能发生的武装冲突而制造武器,引申为任何一种愈演愈烈的竞争:双方为争夺**相对**优势不断加码,消耗掉本可用于他处的资源,而且没有明确的终点。

它为什么稳定:在单次博弈里,任一方单独裁减都会让自己处境变糟——你减了对方不减,你就落后了。于是"继续加码"成为一个稳定但双输的均衡。这本质上是囚徒困境的现实映射:个体理性导致集体次优。

关键判据有两条:第一,投入的主要目的是**压过对手**,而不是获得绝对收益(造更多武器本身不带来安全,只带来相对安全);第二,**退出即意味着相对落后**,所以没人敢先停。

规避方式:个人层面,把钱花在能真正带来满足感的事物上,而不是花在"比邻居多"上;组织层面,靠独特的价值定位做差异化,而不是在同一个维度上硬拼。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在和一个明确的对手反复加码(竞品补贴战、抢人大战、投放竞价),投入越来越大、收益却没有相应增长。
2. 用户在一个"所有人都在堆"的指标上焦虑(学历、加班时长、孩子补习班、婚礼排场),想判断该不该跟。
3. 用户在评估是否要进入一个竞争激烈的赛道,想看清进去之后会不会被迫持续加码。
4. 用户想退出某个消耗战但担心被甩下,需要一条退出路径。

### 语言信号 (用户的话里出现这些就应激活)

- "对手一加我们就得跟着加"
- "谁先停谁吃亏"
- "大家都在卷,我不卷就落后了"
- "投入越来越大,但好处没多多少"
- "这样下去什么时候是个头"
- "arms race" / "escalating competition" / "keeping up with competitors"

### 与相邻 skill 的区分

- 与 `mm-prisoner-s-dilemma` 的区别: 囚徒困境是抽象的博弈结构(两个选项、四种结果、背叛占优);军备竞赛是这一结构在现实中的典型映射,且强调的是**持续多轮、不断加码**的动态过程。用囚徒困境画矩阵,用军备竞赛判断现实处境。
- 与 `mm-war-of-attrition` 的区别: 消耗战比的是"谁先撑不住",胜者最终独得收益,退出即出局;军备竞赛中没有终局胜利,双方持续投入只是为了维持相对位置,停不下来。
- 与 `mm-zero-sum` 的区别: 零和描述收益结构(你多我就少);军备竞赛描述投入 escalation 的动态,而且往往是**负和**——双方总投入远超总收益。

---

## E — 可执行步骤 (Execution)

1. **确认这是否真的是军备竞赛**
   - 完成标准: 明确回答两个判据——投入的主要目的是压过对手还是获得绝对收益?退出是否意味着相对落后?两个都成立才适用。
   - 判停条件: 若加码确实带来绝对收益(如研发投入带来真实的技术领先与定价权),明确说明这不是军备竞赛,不要劝退。
2. **把双方的总投入与总收益算出来**
   - 完成标准: 估算双方各自追加投入后的净收益变化;明确指出这是否为负和——即双方都加码后处境是否比都不加码时更差。
3. **找退出或改规则的杠杆**
   - 完成标准: 至少给出一条具体路径——差异化(换到对手不跟的维度)、设置上限(公开承诺封顶、行业自律)、建立沟通(把单次博弈改造成可协调的重复博弈)、或直接退出并把资源转到能带来绝对收益的地方。
4. **个人场景:换算成满足感**
   - 完成标准: 把这笔追加投入换算成"它实际能带来多少满足感/真实收益",与"仅仅是不落后"区分开;给出把钱与时间改投他处的具体建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 双方在不同维度竞争、加码带来真实绝对收益(技术研发、能力建设):那是正常竞争,不是军备竞赛。
- 单方面加码就能锁定胜局、且存在明确终点的竞争:更像消耗战而非军备竞赛。
- 把它当成"别竞争了"的通用劝辞:模型只识别双输均衡,是否退出仍需按步骤 2 的账来定。

### 书中警告的失败模式 / 容易误用的地方

- 书中未给明确反例,但给出了规避方式:个人把钱花在能带来满足感的事物上;组织靠独特价值定位差异化,而非在同一维度硬拼。(书中明示)
- 常见误用:把一切激烈竞争都叫军备竞赛,从而合理化放弃。判断标准是绝对收益是否为零/为负,不是竞争激烈程度。(推导,非书中明示)
- 常见误用:认为"只要我更努力就能赢"——在负和结构中,更努力只会让双方投入更高,相对位置不变。(推导,非书中明示)

### 容易混淆的邻近模型

- 与囚徒困境(prisoner's dilemma): 军备竞赛是它的现实版本,区别在前者强调持续多轮的加码动态。
- 与向邻居看齐(keeping up with the Joneses): 后者是军备竞赛在个人消费层面的表现,机制相同但常用于描述心理动机。
