# 参照系（frame of reference）

## R — 原文 (Reading)

> 在物理学中，你的视角被称为"参照系"（frame of reference），这也是爱因斯坦相对论中的核心概念。
>
> — 《思维模型》, 第1章 少犯错 > 各持己见

---

## I — 方法论骨架 (Interpretation)

参照系借自物理学：火车里的乘客觉得自己和桌上的杯子是静止的，站台上的人却看到整列车高速掠过——两个描述都对，因为它们的坐标系不同。相对论把它推到极致：除了光速，连时间都随参照系而变。

这个模型为什么重要？因为**你从来不是"客观地"在看世界，你总是从某个坐标在看**。而你的坐标由你的生活经历、当前处境、利益与身份决定——这些东西你往往意识不到，于是把自己的描述当成"事实本身"，把别人的描述当成"偏见"或"错误"。

作者给的操作方法有两步。第一步是**意识到自己的参照系**：先说出"我站在这里，所以我看到的是……"。第二步是**借用他人的参照系**：当你不确定时，主动去问、去想象"换一个人站在别处，他会怎么描述同一件事"。这两步合起来并不要求你放弃立场，只是把"我的版本"降级为"其中一个版本"。

判据：**换一个人站在别处，他会怎么描述同一件事？** 如果你答不上来，说明你还没看见自己的参照系。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. **两个人对同一件事的描述完全不同且都坚信自己**：会议上各说各话、复盘时责任归属争执不下。
2. **跨部门/跨角色沟通失败**：销售觉得产品不给力、产品觉得销售乱承诺，双方都觉得对方不了解情况。
3. **评估他人表现时给出的评价特别斩钉截铁**："他就是不上心""客户就是难搞"。
4. **跨文化、跨地区、跨代际的判断**：对某个做法的"常识"在另一群人那里完全不成立。
5. **自己刚换岗位/换环境，需要重新校准判断**（推导, 非书中明示）。

### 语言信号
- "他怎么会这么想？明明就是……"
- "我们俩看到的完全不是一回事"
- "站在他的角度，我也说不准"
- "我是不是因为自己在这个位置才这么看"
- "换我我可能也会这样"
- "Why do we see this so differently?" / "From their point of view…"

### 与相邻 skill 的区分
- 与 `mm-framing` 的区别: 框架效应关心的是**同一信息的呈现方式如何改变决策**（措辞、参照点、损失/收益表述）；参照系关心的是**观察者所处的位置如何改变他看到的内容**。一个是信息包装，一个是观察者坐标。
- 与 `mm-third-story` 的区别: 第三方故事是冲突中"中立旁观者会讲的版本"，是一次具体的产出；参照系是更底层的认识工具，是构造第三方故事的前提——你得先能进入别人的坐标系，才写得出第三方故事。
- 与 `mm-mirroring` 的区别: 镜映是一种**沟通技巧**（模仿对方姿态语言以建立亲和）；参照系是**认知工具**（真的去理解对方看到了什么）。前者偏技法，后者偏认识论。

## E — 可执行步骤 (Execution)

1. **显式标出用户当前的参照系**
   - 完成标准: 写出 1-3 条构成当前视角的具体坐标（角色/利益/经历/时间压力），例如"你是被考核交付速度的一方，所以你看到的是延期风险"。
2. **列出至少两个其他相关方的参照系**
   - 完成标准: 为每个相关方写出"他站在哪里、他手上有什么信息、他被什么指标驱动"，各 1-2 句。
3. **用每个参照系各复述一遍同一事实**
   - 完成标准: 输出 N 个版本的"同一件事"，确认它们在各自坐标系内都自洽；若某个版本不成立，说明该参照系信息不足，回去补。
4. **找出版本之间的真实分歧点**
   - 完成标准: 明确写出分歧来自"看到的事实不同"（信息差）、"坐标不同"（利益/角色差）还是"事实判断本身不同"（可验证）；不同类型给出不同处理建议。
   - 判停条件: 若分歧被判定为利益冲突而非视角差异，退出本 skill——换视角解决不了利益分配问题。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **纯事实校验**：数字对不对、日期是不是 3 号，这类问题有唯一答案，不存在"视角不同"。
- **价值或利益冲突**：对方并非看错了，而是想要不同的东西，此时把问题说成"视角差异"是在回避真正的谈判。

### 容易误用的地方
- **书中未给边界**。以下基于机制推导：
- （推导, 非书中明示）**变成"各人有各人的道理"的和稀泥**：参照系用于**理解分歧来源**，不是用来取消判断。有些坐标系确实更接近事实。
- （推导, 非书中明示）**把视角差异当成人身缺陷的反面**：承认对方有参照系，不等于承认对方出于恶意或出于善意——那是归因问题，交给基本归因错误系列处理。
- （推导, 非书中明示）**无限递归**：意识到自己的参照系后，不必再追问"我意识到参照系的这个意识又站在哪个参照系"，那是哲学问题不是决策问题。
