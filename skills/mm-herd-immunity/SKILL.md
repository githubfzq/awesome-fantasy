# 群体免疫效应（herd immunity）

## R — 原文 (Reading)

> 还要再加上一个模型——群体免疫效应（herd immunity）。只有存在合格的宿主可供感染，疾病才能传播开来。但当绝大多数人都接种了疫苗时，合格的新宿主就为数不多了，因为（群体中的）大多数人都因为接种过疫苗而免疫了。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

疾病传播需要一条连续的"合格宿主链"：A 传给 B，B 传给 C。接种的作用不只是保护接种者本人，更是把链条上的环节换成不可燃的材料。当接种率越过某个阈值，链条在统计意义上断裂，病原体找不到下一个宿主，于是连那些没有接种的人也被间接保护了——这就是群体免疫。

关键特征是**阈值非线性**：在阈值以下，多一个人接种的边际收益是平滑的；越过阈值，传播网络整体坍缩，收益陡增。反过来也一样，接种率一旦跌破阈值，疫情不是"稍微多一点"，而是以快得多的速度重新爆发。阈值本身不是固定数字，它随病原体的传染性变化（书中给麻疹约为 95%）。

作者真正想让人迁移的是这个结构，而不只是流行病学：任何"可被模仿或传染的行为"都有同样的阈值。违规行为如果没被惩治的比例越过阈值，就会迅速扩散并固化为新常态——意大利"只有傻瓜才交税"的避税文化就是社会规范版的群体免疫崩溃。

判据是两条同时成立：**存在可被模仿/传染的行为**，以及**存在一批未受惩罚的违规存量**。只有这两件事同时存在，阈值逻辑才成立。

---

## A1 — 书中的应用 (Past Application)

### 案例: 麻疹疫苗与"只有傻瓜才交税"

- **问题**: 1963 年麻疹疫苗问世前，美国每年约 50 万人感染、400 多人死亡。近年反疫苗运动让接种率跌破阈值，2017 年明尼苏达州出现 75 例麻疹感染，其中多数未接种疫苗。作者指出，同一结构也解释了社会规范的崩坏：意大利普遍存在的避税文化，其口号就是"只有傻瓜才交税"。
- **方法论的使用**: 作者把"传播链上的合格宿主"抽象成"可被模仿的行为载体"。在疾病场景里载体是未免疫者，在规范场景里载体是"违规却没被追究的人"。两者都遵循同一条曲线：越阈值后自我强化，跌破阈值后同样自我强化。
- **结论**: 你保护的从来不只是自己。接种（或守规）的价值大部分是给群体的外部收益；同理，纵容一次违规的成本也不只是这一次，而是把群体往阈值方向推了一格。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在论证"覆盖率/参与率要定到多少"——疫苗、安全培训、代码评审覆盖、合规签署、团队新流程的采纳比例。
2. 在纠结"我自己要不要参与"——"别人都打了我是不是可以不打"、"大家都这么干我一个人守规矩没意义"。
3. 在诊断一个规范为何突然崩坏——作弊、逃票、虚假报销、会议室占用不登记，昨天还很少，今天遍地都是。
4. 在设计激励或惩罚制度时，需要判断"抓多少、罚多重才能让行为停下来"。
5. 在评估恢复成本——一个已经越过阈值的坏规范，要花多大力气才能扭转回来。

### 语言信号 (用户的话里出现这些就应激活)

- "是不是打的人够多了我就不用打了"
- "就我一个人守规矩也没用啊"
- "大家都在这么做"
- "要达到多少比例才有效"
- "怎么突然之间全都这样了"
- "herd immunity / threshold / critical mass / free rider"

### 与相邻 skill 的区分

- 与 `mm-critical-mass` 的区别: 临界量强调"达到某个规模后系统能自我维持"（增长侧），群体免疫强调"达到某个比例后传播链断裂"（防御侧）；一个问"要多少才能滚起来"，一个问"要多少才能停得下来"。
- 与 `mm-tipping-point` 的区别: 临界点是描述"越过某点后状态突变"的通用曲线，群体免疫是它的一个具体机制实例（宿主链断裂）；群体免疫一定涉及传染/模仿，临界点不一定。
- 与 `mm-tragedy-of-the-commons` 的区别: 公地悲剧讲个体理性导致共享资源枯竭，动力是"多拿一点"；群体免疫讲未受惩罚的违规存量扩散，动力是"模仿"。前者需要配额，后者需要把违规率压回阈值以下。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认是否存在"传染机制"**
   - 明确写出传播载体是什么：病原体、可观察的行为、可在社交网络中复制的做法。
   - 完成标准: 能用一句话说清"A 的行为如何增加 B 做同样事的概率"。
   - 判停条件: 若不存在模仿/传染路径（例如纯粹独立的个人偏好），停止本 skill，改用一般性的阈值或激励分析。
2. **估算阈值，而不是拍脑袋定目标**
   - 找出该情境的参考阈值（书中麻疹约 95%），或说明为什么本情境的阈值更高/更低（传染性越强阈值越高）。
   - 完成标准: 给出一个带理由的数字区间，并标注不确定性。
3. **测量当前覆盖率与"未受惩罚的违规存量"**
   - 两个数字都要：合规/免疫的比例，以及违规但未被追究的数量或比例。
   - 完成标准: 得到两个量化指标；若无法量化，明确写出"数据缺口"而不是跳过。
4. **判断当前处在阈值的哪一侧，并说明后果的不对称性**
   - 阈值以上：维持成本低；阈值以下：恢复成本远高于维持成本（作者语"把妖魔从瓶子里放出来容易，塞回去难"）。
   - 完成标准: 明确一句"我们在阈值之上/之下，因此策略应是维持/抢救"。
5. **给出把比例推过阈值的具体杠杆**
   - 方向：提高参与便利度、强制全员（如强制车险）、对未参与者加价、公开化违规以消除可模仿的"安全违规"信号。
   - 完成标准: 至少 2 条可执行动作，每条注明预计把覆盖率推高多少、成本是什么。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有传染/模仿机制的场景：个人独立选择的集合不适用阈值逻辑，硬套会得出错误的"必须全员"结论。
- 纯粹的多数决或投票问题：那是决策规则问题，不是传播链问题。
- 需要精确预测具体数字时：阈值依赖传染性参数，书中只给了麻疹的约 95%，其他场景需要实测或建模，不能引用书里的数字（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 作者提醒：一旦跌破阈值造成持久伤害，"把妖魔从瓶子里放出来容易，想把它塞回去可就难了"。底特律、新奥尔良衰败区的恢复成本远高于维持成本——这是本书明确给出的核心警告。
- 容易误把"我一个人无所谓"当成合理推理。群体的价值恰恰来自个体不这么想，这是典型的搭便车结构（推导，非书中明示）。
- 容易忽略"未受惩罚的违规存量"这一变量，只盯着官方覆盖率数字（推导，非书中明示）。

### 容易混淆的邻近模型

- 与逆向选择：两者都有正反馈坍缩，但逆向选择的动力是"高风险者留下、低风险者退出"（风险池恶化），群体免疫的动力是"未免疫/未受罚者成为传播载体"。一个恶化的是质量，一个恶化的是数量。
- 与从众效应：从众效应描述个体跟随多数，不要求阈值，也不产生"保护未参与者"的溢出；群体免疫必须有阈值和溢出。
