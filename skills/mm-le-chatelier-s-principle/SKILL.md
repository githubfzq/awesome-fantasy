# 勒夏特列原理（Le Chatelier's principle）

## R — 原文 (Reading)

> 在一个已经达到平衡的化学系统中，如果改变反应条件（例如温度、体积或压强等），系统就会自行调整，进入全新的平衡状态，这个过程通常能抵消部分条件变化。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

这条原理从化学借来，但适用于一切"已达平衡、且内部主体会做出反应"的系统：**你改变外部条件，系统不会乖乖停在你推到的位置，而是会自行调整进入一个新平衡，并且这个调整通常抵消掉一部分你施加的变化**。

要准确理解它，有两个常见误读必须避开。第一，它**不是说系统围绕某个预定值调节**——不是" homeostasis 式的回归设定点"，而是系统会对外界刺激做出反应并部分抵消之。第二，它只抵消**部分**，不是全部。所以改动依然有效，只是效果比你按静态假设算出来的小。

它和生物学里的动态平衡（homeostasis）是近亲，但落点不同：动态平衡强调"维持稳定"，勒夏特列强调"施加改动后的部分回摆"。

为什么重要？因为人在做政策或商业预测时几乎总是默认"其他条件不变"。新税种推出后，长期税收收入会低于按当前行为估算的预期——因为人们会为避税调整自己的行为。忽略这一点，你的预测会系统性偏乐观。这个自行调整的过程，可以用仿真模拟实时观察到。

关键判据：系统里的主体（人、组织、市场）有没有能力根据新规则改变自己的行为？有，就得算进回摆。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在预测一项新政策、新定价、新考核的长期效果，且预测建立在"大家行为不变"的假设上。
2. 用户发现某项措施推行初期有效、后来效果衰减，想知道为什么。
3. 用户在估算一项改动能带来多少收益，需要给"长期实际值"打个折。
4. 用户担心改动会引发对策行为（刷指标、避税、绕流程）。

### 语言信号
- "按这个改动，长期能多赚 X"
- "为什么刚开始有效，后来就没用了"
- "他们肯定会想办法绕过去"
- "上有政策下有对策"
- "如果人们改变行为，结果会怎样"
- "the system will adapt" / "people will game it"

### 与相邻 skill 的区分
- 与 `mm-homeostasis` 的区别: 动态平衡强调系统**维持**某个状态（体温、血糖），勒夏特列强调系统对**外部施加的改动**做出部分抵消；前者是守，后者是应。
- 与 `mm-cobra-effect` 的区别: 眼镜蛇效应是**抵消演变成反向恶果**的极端情形（激励导致问题加剧），勒夏特列是更一般的"部分抵消"规律；前者是后者失控的版本。
- 与 `mm-perverse-incentives` 的区别: 不当诱因关注**激励设计错了导致的行为扭曲**，勒夏特列关注**任何外部条件改变后系统的自适应回摆**，不要求激励设计本身有错。

## E — 可执行步骤 (Execution)

1. **确认系统已达平衡且主体会反应**
   - 问：这个系统当前是稳定的吗？里面的主体有能力根据新规则改变行为吗？
   - 完成标准: 两个问题都有明确答案；若系统是静态的、无适应主体，停止本 skill。
2. **先按静态假设计算"天真预期"**
   - 完成标准: 得出一个明确的数字（增收多少、效率提升多少），作为基准。
3. **逐一找出会被改变的行为**
   - 列出各相关方为适应新条件可能做出的调整（避税、刷指标、换供应商、改消费习惯）。
   - 完成标准: 至少 3 条具体的行为调整，每条写明谁会做、成本多高。
4. **估算抵消幅度，给出长期预期**
   - 完成标准: 明确写出"抵消部分而非全部"的修正后数字，以及达到新平衡所需的大致时间。
   - 判停条件: 若抵消后效果反向（问题反而加剧），跳到步骤 5 按眼镜蛇效应处理。
5. **设计抗回摆的方案或设观察期**
   - 完成标准: 给出降低可规避性的具体设计（减少套利空间、设多重指标），并设定观察回摆的信号与时间窗。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 一次性、无适应主体的物理/技术操作（换一台更快的机器、改一个算法参数）：没有主体会调整行为，也就没有回摆。
- 系统尚未达到任何平衡、正处于剧烈变动期：谈"新平衡"没有参照点。
- 把它当成"任何改动都没用"的犬儒借口：原理明确说抵消的是部分，不是全部。

### 容易误用的地方
- 书中未给出边界说明，但强调它只抵消"部分"条件变化，不是完全抵消。（书中明示）
- 误读为"系统会回到原设定值"：作者特别澄清它不意味着系统围绕某个预定值调节，而是对刺激做出反应并部分抵消。（书中明示）
- 忽略达到新平衡的时间：短期数据看起来有效、长期才回摆，用短期结果判断长期效果会误判。（推导，非书中明示）

### 容易混淆的邻近模型
- 与动态平衡（homeostasis）：维持稳定 vs. 改动后的部分回摆。
- 与眼镜蛇效应（cobra effect）：一般的部分抵消 vs. 抵消到反向恶化的极端情形。
