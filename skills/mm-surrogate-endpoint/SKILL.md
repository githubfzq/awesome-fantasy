# 代理指标（替代终点）（surrogate endpoint / proxy measure）

## R — 原文 (Reading)

> 所谓的"代理终点"，是一个与他们想要测量的"终点"极为接近的指标。"代理"是指其他事物的替身。这个思维模型还可以用于其他领域，包括代理投票（例如缺席投票）和代理战争
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

我们真正关心的很多东西，本身是量不出来的：一所大学好不好、一个人健不健康、一个产品有没有价值。代理指标（surrogate endpoint）的做法，是找一个与之"极为接近"、又能被客观测量的替身，把不可比的东西变成可比的数字，从而让争论可以落地。

它之所以成立，是因为代理与真终点之间通常存在一条因果链：代理改善，真终点也跟着改善。但这条链不是逻辑必然，而是一次经验押注——链上任何一环断了，代理就会带着结论跑偏。最锋利的反例是：一种药确实降低了心律失常的发生率，却同时提高了猝死率，于是"心律失常发生率"根本不是"活得久"的合格代理。

关键判据只有一句：**当这个代理改善时，我真正关心的结果是否也改善了？** 代理不必完美，但必须同步；而且因为它是间接的，它天然更容易遭到质疑。

---

## A1 — 书中的应用 (Past Application)

### 案例: 大学排名、BMI、IQ 与抗心律失常药

- **问题**: 大学质量、肥胖、智力都是无法直接读数的事物，决策和比较却急需一个数字。
- **方法论的使用**: 作者指出，人们正是靠代理指标把这些概念变成可比较的数字——《美国新闻与世界报道》用毕业率、录取数据、学术声誉综合排名"大学质量"；用 BMI 衡量肥胖、用 IQ 衡量智力。随后作者用抗心律失常药做反例：药物降低了心律失常发生率（代理改善），却提高了猝死率（真终点恶化），因此它不是合适的替代终点。
- **结论**: 代理指标是把不可测量之物变可测量的必要工具，但它必须接受"代理—真终点是否同步"的检验；选中错误的代理，会得到方向完全相反的结论。作者也点明，正因为它间接，大学排名、BMI、IQ 这三例都曾遭到严厉抨击。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计 KPI / OKR / 考核方案，团队选中了一个特别容易取数的数字当目标（工单数、代码行数、通话时长、点击率）。
2. 读到"研究表明 X 能降低 Y"的新闻或论文，Y 是一个中间指标，用户想知道能不能据此改变行为。
3. 用某个产品指标（留存、DAU、NPS）论证"用户价值提升了"，或反过来质疑别人的论证。
4. 招聘、评优、投资判断中用学历 / 证书 / 面试分 / 营收增速代替"实际能力"或"长期健康"。

### 语言信号 (用户的话里出现这些就应激活)

- "我们就用这个指标来考核吧"
- "这个数据涨了，就说明产品变好了"
- "有没有一个简单的数字能衡量 XX"
- "研究表明吃 XX 能降低 YY 指标"
- "What's a good proxy for ..."

### 与相邻 skill 的区分

- 与 `mm-goodhart-s-law` 的区别: 古德哈特定律讲"指标一旦变成目标，就不再是好指标"——人围绕指标博弈导致失真；代理指标讲的是**选指标那一步**链条断裂，与有没有人博弈无关。
- 与 `mm-confounding-factor` 的区别: 混淆因素是因果路径上混进了第三个变量；代理指标是**被测量的对象本身被替换**了。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **逼出真终点**
   - 完成标准: 能用一句不含任何指标的话说出"我真正想改变的结果是什么"（例如"让用户愿意明年续费"，而不是"提高 DAU"）。
2. **列出候选代理，并画出从代理到真终点的因果链**
   - 完成标准: 链上每一环都写成一个可被检验的因果假设，而不是"感觉它们相关"。
   - 判停条件: 若某一环只能靠直觉支撑，把该代理降级为"观察项"，不作为结论依据。
3. **搜反例——历史上是否存在"代理改善、真终点没改善甚至恶化"的证据**
   - 完成标准: 至少主动检索/回忆该类代理的已知翻车案例（书中模板：抗心律失常药降低了心律失常却提高猝死率）。
   - 判停条件: 若找到此类反例，立即停止用该代理下结论，跳到步骤 4。
4. **宣布适用边界并加一道低频直接校验**
   - 完成标准: 明确写出"这个代理在什么条件下会失效"，并安排一个周期性直接测量真终点的动作（哪怕频率很低、成本很高）。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 真终点本身就可以直接、低成本地测量——此时直接测，绕道代理只会引入额外误差。
- 讨论的是纯价值判断或一次性定性选择（例如"这个品牌调性对不对"），硬找一个数字反而丢信息。

### 书中警告的失败模式 / 容易误用的地方

- 作者明确说代理指标**"更容易遭到抨击，因为它是间接的"**，并指出大学排名、BMI、IQ 三个例子都曾遭到严厉抨击。
- 使用时必须验证代理与真终点同步；只因为代理"好测量"就选用它，是最常见的误用。
- （推导，非书中明示）代理一旦被写进考核，会诱发针对数字本身的博弈，使链条从"代理跟随真终点"变成"代理脱离真终点"——这与古德哈特定律相接壤。

### 容易混淆的邻近模型

- 古德哈特定律（goodhart-s-law）：关注指标成为目标后的**人为博弈**失真。
- 混淆因素（confounding-factor）：关注因果推断中混入的第三变量。
