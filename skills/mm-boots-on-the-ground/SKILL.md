# 脚踏实地（boots on the ground）

## R — 原文 (Reading)

> 它的本义是指军事冲突中的地面部队脚踏战靴，通常引申为"为了在军事战役中取得成功，你需要让战靴踏在地面上，因为只靠远距离作战（例如只使用空中力量）无法实现最终目标"。
>
> — 《思维模型》, 第8章 > 携手共进

---

## I — 方法论骨架 (Interpretation)

军事原义：只靠空中力量这类**远距离作战无法实现最终目标**，必须有地面部队实际到场。

**为什么成立**：远距离手段能投放信息、施加压力，却无法完成"赢得人心"这类需要**互动与信任**的目标。书中的逻辑是：要赢得人心，就需要脚踏实地与民众互动，使外部干预更有人情味，而不能只从远距离传播信息。信任是双向互动的产物，单向广播造不出信任。

书中给的美国国内对应实践是**社区警务**：警察在社区内花时间与民众建立联系，从而赢得被监督保护群体的信任。注意这里的机制——不是"多宣传警察多好"，而是**花时间待在那里、建立联系**。

**迁移到组织中的关键判据**：领导者的对应做法是**以身作则，而非坐在象牙塔里空谈文化**。书中列出的常见说法是：卷起袖管、进入战壕、表明你是"我们中的一员"。

由此得到最实用的检验：**你想推动的东西，你自己是否出现在它发生的地方？** 如果你在推文化却从不在一线出现，你用的是空中力量；文化这类目标是地面目标，空中力量够不着。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司价值观/新制度发布好几个月，一线毫无变化，用户在考虑再发一轮通知。
2. 管理者想推行某种工作方式（如客户导向、质量优先），但团队只当口号。
3. 远程/多地团队士气低落，总部感觉"指令下不去"。
4. 外部合作方、社区、用户对己方缺乏信任，用户想靠 PR、公告、宣传材料解决。
5. 新任管理者接手团队，还没建立起信任就想推动变革。
6. 用户自己是创始人/高管，困惑"为什么我说的没人听"。

### 语言信号 (用户的话里出现这些就应激活)

- "制度发了，但没人当回事"
- "再发一封全员邮件强调一下"
- "为什么我说的下面不执行"
- "怎么让一线真的改变行为"
- "他们不信任我们"
- "做个宣传片/公告澄清一下"
- "boots on the ground / lead by example / they don't trust us / nothing changes after the announcement"

### 与相邻 skill 的区分

- 与 `mm-winning-hearts-and-minds` 的区别: 赢得人心是**目标**（让人们真心认同）；本 skill 是**达成该目标的必要手段**（必须亲自到场互动）。书中把两者直接连起来：赢得人心需要脚踏实地。前者讲要什么，后者讲怎么做。
- 与 `mm-commandos` 的区别: 突击队员、步兵与警察区分的是**不同规模的部队类型与适用场景**；本 skill 讲的是"地面部队必须到场"这一条原则，与部队类型选择是不同层次的问题。
- 与 `mm-culture-eats-strategy-for-breakfast` 的区别: 那句名言说文化压过战略；本 skill 指出**文化是地面目标**——你不能靠发文件建立文化，只能靠领导者以身作则。前者讲优先级，后者讲落地方式。
- 与 `mm-managing-to-the-person` 的区别: 以人为本的管理是**对每个人用不同管理方式**的原则；本 skill 强调的是**物理/实际在场**这个前置条件。不先到场，差异化也无从谈起。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先识别目标是"地面目标"还是"信息目标"**
   - 完成标准: 明确判定。信息目标（通知版本号、公布流程变更）靠广播即可；地面目标（改变行为、建立信任、推行文化）必须到场。
   - 判停条件: 若是纯信息目标，说明"此处不需要 boots on the ground"，直接优化传播渠道，结束。
2. **定位"地面"在哪、谁该上去**
   - 完成标准: 明确指出具体场域（哪条业务线、哪个办公点、哪类客户现场、哪个社群）以及必须亲自到场的人（通常就是用户本人或决策者，不能委派代言）。
3. **设计互动而非宣讲**
   - 完成标准: 给出 2-3 个具体的到场动作，标准是每个动作都包含**双向互动**（现场办公、跟班、当面答疑、一起解决问题），而非单向宣讲。参考社区警务的机制：花时间待在那里、建立联系。
4. **明确以身作则的具体行为**
   - 完成标准: 列出领导者本人要做的示范动作（卷起袖管做一线工作、进入战壕承担最难的部分），每条都要能被一线观察到。要点是表明自己是"我们中的一员"。
5. **设定到场频率与观察指标**
   - 完成标准: 给出可执行的频率（如每周半天在现场）与 1-2 个观察指标（一线是否开始主动反馈、行为是否变化），并约定 4-8 周后复盘；指标不变则先检查到场是否真实发生、是否委派了他人。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 目标本就是信息传递（发布公告、同步进度）——到场是浪费。
- 已经有可信的人在一线，问题出在别处（如资源不足、目标不清）。
- 组织规模太大，领导者无法覆盖所有一线——需要与分层管理结合，不能只靠个人到场。
- 冲突或安全情境下不适合亲自到场——先解决安全问题。

### 容易误用的地方

- 书中未给本模型的边界说明，以下均为基于机制推导。
- （推导, 非书中明示）把"到场"做成巡查与督导。书中强调的是**互动与赢得人心**（社区警务是花时间建立联系），到场如果变成检查工作，反而会削弱信任。
- （推导, 非书中明示）委派他人代替自己到场。书中组织语境的说法是领导者以身作则、表明你是"我们中的一员"，这要求本人到场；委派 PR 或中层，就退化成了远距离作战。
- （推导, 非书中明示）以为一次到场就够。信任是重复互动的累积，社区警务的机制明确要求"花时间"，一次性亮相不产生效果。
- （推导, 非书中明示）忽略到场后的行为一致性。人到了却言行与主张相悖，破坏力大于不到场。
- （推导, 非书中明示）用它否定远程协作。模型针对的是信任与行为改变类目标，不适用于常规的信息协同工作。

### 容易混淆的邻近模型

- **赢得人心（winning hearts and minds）**: 是目标；本 skill 是达成它的必要手段。
- **以身作则 / 文化吃掉战略**: 讲文化的重要性与优先级；本 skill 讲文化这类目标无法靠远距离手段达成。
