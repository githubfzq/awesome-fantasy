# 间隔效应（spacing effect）

## R — 原文 (Reading)

> 这个模型解释了如果每次学习之间存在时间间隔，而不是将等量内容压缩在较短的时间内，学习效果会更好。也就是说，正如我们在第三章中提到的，“填鸭式教学”通常不是最佳策略。
>
> — 《思维模型》, 第8章 > 熟能生巧

---

## I — 方法论骨架 (Interpretation)

间隔效应说的是：**同样的学习总量，分散在多个时间点上比压缩在短时间内效果更好**。填鸭式教学之所以通常不是最佳策略，就是因为压掉了间隔。

机制在于"回想"本身才是记忆强化的动作。刚学时认真研究一遍，第二天或几天后再回想确认，之后只需偶尔回想——间隔可以随时间不断扩大。如果不按这个节奏回来回想，就会遗忘。

它对刻意练习有一条重要补正：**不要"彻底掌握一项再练下一项"，而要轮流练习各项技能**。作者用健身房作比：逐步加量、轮流锻炼每块肌肉，而不是把一块肌肉练到极限再换下一块。

关键判据：**你有没有安排"回来回想"这个动作**。只安排"学新内容"的时间表，无论总量多大，都不是间隔学习。

实践证据：多邻国（Duolingo）和 Quizlet 这类在线教学平台按间隔强化记忆；间隔播放广告比连续播放效果好——后者说明这个效应不止于人脑的记忆，它在注意力和说服力层面同样成立。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备考试/认证，打算用一两周集中突击，或已经突击过但考完就忘。
2. 学一项新技能（语言、乐器、编程框架），发现"当时会了，两周后全忘"。
3. 设计培训计划或团队学习计划，要决定是集中办班还是分期进行。
4. 设计广告投放、内容推送、用户触达的节奏——连播 vs. 间隔。

### 语言信号

- "下周考试，我这周突击一下"
- "学完就忘，是不是我记性差"
- "是先练熟这个再练下一个，还是一起练"
- "复习应该安排在什么时候"
- "培训是集中三天还是每周一次"
- "I crammed for it and forgot everything" / "how often should I review?"

### 与相邻 skill 的区分

- 与 `mm-deliberate-practice` 的区别: 刻意练习规定**练什么、怎么练**（攻弱点、要反馈、出舒适区），间隔效应规定**什么时候练**（分散、间隔递增、多技能轮流）。两者是同一训练计划的两个维度。
- 与 `mm-10000-hour-rule` 的区别: 一万小时给**总量级**，间隔效应给**分布方式**；同样的一万小时，间隔分布与集中分布的效果差别很大。
- 与 `mm-deep-work` 的区别: 深度工作强调**单次连续无干扰的时长**，看起来与"分散"矛盾，其实互补——每一次学习时段内部要足够深，时段之间要足够散。

## E — 可执行步骤 (Execution)

1. **确认目标是不是长期记住**
   - 完成标准: 若只需即刻使用一次（查完就用），退出本 skill，直接一次性解决即可。
2. **把总内容切成小块并排到多个时间点**
   - 完成标准: 输出一张时间表，明确每次学习的量与日期；同一内容不得只出现一次。
3. **设定递增的回想间隔**
   - 完成标准: 给出具体的间隔序列（如 学后当天 → 次日 → 3 天后 → 1 周后 → 1 月后），并为每次回想明确"只回想、不重学"的动作。
4. **改为多技能轮流**
   - 完成标准: 若涉及多项子技能，把"练熟 A 再练 B"改成 A/B/C 轮换，并在计划里体现轮换顺序（健身房类比）。
5. **选择或搭建间隔工具**
   - 完成标准: 指定具体的承载方式——间隔重复软件、日历提醒、或既有平台（多邻国、Quizlet 一类），确保第 3 步的间隔真的会被触发。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要立刻使用且无需长期保留的信息——临时查阅即可，排间隔是浪费。
- 内容具有强逻辑结构、理解后不易忘（如一个推导过程）——理解型内容更需要深度加工而非重复回想。
- 距离使用节点极近且总量很小——此时集中处理是合理取舍。

### 容易误用的地方

- （推导, 非书中明示）书中未提局限。由机制可推导：间隔必须搭配**主动回想**，"隔一段时间再看一遍"只是分散的重复阅读，效果远低于回想，这是最常见的执行偏差。
- （推导, 非书中明示）间隔过长会导致完全遗忘、回想失败，此时等于重新学习，反而降低效率；间隔应随掌握程度逐步拉长而非一开始就拉得很长。
- （推导, 非书中明示）"间隔播放广告比连续播放效果好"是书中给出的说服场景应用，不等于间隔越多越好——超过一定频次会转为干扰。

### 容易混淆的邻近模型

- **刻意练习（deliberate-practice）**: 规定练什么，本 skill 规定何时练。
- **深度工作（deep-work）**: 时段内要深、时段间要散，二者互补而非冲突。
