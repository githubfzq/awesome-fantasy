# 科学方法（scientific method）

## R — 原文 (Reading)

> 从形式上看，科学方法是一个严密的循环，包括进行观察、提出假设、检验假设、分析数据、提出新理论。
>
> — 《思维模型》, 第4章 > 开篇（师法自然）

---

## I — 方法论骨架 (Interpretation)

科学方法是一个循环，不是一个步骤：观察 → 提出假设 → 检验假设 → 分析数据 → 提出新理论，然后带着新理论重新进入观察。

它背后的前提很朴素：**你不可能一下子就找到最佳安排**。无论是个人效率、产品方案还是健身计划，最优解都藏在无数可能的组合里，只能靠持续试验一步步逼近。

因此它真正的价值不是"严谨"，而是**对抗"适应性检验"**——现实会不断检验你的做法是否还适用，而科学方法给你一套主动、可迭代的应对方式：不断完善自己做的内容和方式，从而持续提高效率。

落到日常，它叫"实验思维"：把工作和生活当成可以迭代的实验，而不是一次性定终身的选择。判据是——这个说法可以被观察数据推翻吗？如果永远无法被推翻，那它就不是假设，只是信念。

---

## A1 — 书中的应用 (Past Application)

### 案例: 作者的个人效率试验 / 哪种健身计划你真能坚持

- **问题**: 面对"怎样安排才最有效率""哪种饮食或健身方案最好"这类问题，靠想和靠看别人的经验都得不到答案。
- **方法论的使用**: 作者以个人工作效率为例，持续试验不同的日程安排、软件、组织方式和流程，每一轮都用实际结果修正下一轮，从而越来越接近最佳安排。同样的思路也适用于节食与健身——真正要问的不是"哪种计划理论上最好"，而是"哪种健身计划是你真能坚持下去的"。
- **结论**: 你不可能一下子找到能实现最佳绩效的安排，只能通过长期迭代逐步逼近；这个循环本身就是对抗环境变化的工具。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在几个做法之间举棋不定，想知道"到底哪个真的有效"而不是听谁说得好。
2. 用户准备做一次改动（改版、调价、换流程），想先小范围验证再推广。
3. 用户凭直觉或个例下了结论，需要被拉回到可验证的轨道上。

### 语言信号 (用户的话里出现这些就应激活)

- "这样做到底有没有用，怎么验证"
- "我觉得可能是因为……但也不确定"
- "要不要先小范围试一下"
- "试了几次感觉都差不多，说不清哪个更好"
- "how do I know if this actually works"

### 与相邻 skill 的区分

- 与 `mm-experimental-mindset` 的区别: 实验思维是把一切都当实验的**心态与习惯**；科学方法是具体的**循环步骤**（观察—假设—检验—分析—新理论）。
- 与 `mm-randomized-controlled-experiment` 的区别: 随机对照实验是检验环节的一种严格设计（有对照组和随机分配），本模型是更通用的完整循环。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **观察：把当前状况与待解释的现象写清楚，附上已有数据**
   - 完成标准: 现象可度量，且不是"感觉不好"这类无法观测的表述。
2. **提出假设：写成一句可被推翻的陈述，并说明预期会观察到什么**
   - 完成标准: 假设形如"如果 X 成立，那么做 A 之后 Y 会变成 Z"，且明确写出证伪条件。
   - 判停条件: 若无法设想任何反证，说明这不是可检验的假设，退出并转为澄清问题。
3. **设计检验：确定变量、对照、样本与观测周期**
   - 完成标准: 明确"改什么、不改什么、怎样算一组、跑多久"，并尽量设置对照组。
4. **执行并分析数据**
   - 完成标准: 结果与预期对照，明确"支持 / 不支持 / 数据不足"三者之一，不模糊带过。
   - 判停条件: 若数据量不足以判断，明确说明并延长周期或扩大样本，不要提前下结论。
5. **提出新理论，进入下一轮循环**
   - 完成标准: 写出修正后的看法与下一轮要试的具体改动，形成闭环。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性、不可逆的重大决策（买房、结婚、辞职），没法"试一轮再来"，应转向决策树、情景分析等。
- 结果无法观测或周期极长的议题（教育长期影响、文化塑造），硬做实验会得到伪结论。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示：你不可能一下子就找到能帮你实现最佳绩效的安排，需要长期迭代，不能指望一次试验定论。
- （推导, 非书中明示）一次试验就下结论、或只看支持自己猜想的数据，会把科学方法用成确认偏差的遮羞布。
- （推导, 非书中明示）变量同时改太多，就分不清是哪个改动起了作用，等于没做实验。

### 容易混淆的邻近模型

- 与原假设 / 统计显著性（null-hypothesis / statistical-significance）混淆：那些是检验环节的技术工具，本模型是包含它们的整体循环。
- 与 A/B 测试混淆：A/B 测试是本模型在产品和运营中的一次具体实施，范围窄得多。
