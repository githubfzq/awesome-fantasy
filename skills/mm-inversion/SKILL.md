# 逆向思维（inversion / inverse thinking）

## R — 原文 (Reading)

> 反过来思考问题能解锁全新的策略和解决方案。例如，大多数人投资的出发点是"多赚钱"，逆向思考就是把出发点换成"不亏本"。
>
> — 《思维模型》, 第1章 少犯错 > 章首

---

## I — 方法论骨架 (Interpretation)

正向提问和反向提问的信息量并不对称。问"我怎样才能成功"，答案空间是开放的：路径无数、无法穷举、每条都缺少明确的终止条件，于是你只能凭直觉挑一条走。问"我怎样一定会失败"，答案空间却是收敛的：导致失败的做法通常有限、可枚举、且边界清晰（不做调研、All in 单一客户、现金流断裂、忽视合规）。

这个不对称来自一个事实：**成功往往是多因一果，失败常常是一因就够**。成功需要所有条件同时成立，失败只需要一个条件崩塌。因此"避免失败"是一个约束更强、更容易操作的目标。

书的用法是把它当成**出发点**而不是完整决策法：先把"多做正确的事"反转成"少犯错"，得到一份可以逐条打勾的检查清单，再去正向设计。反过来想的价值不在于否定正向目标，而在于它能解锁正向思维看不见的策略——比如健康饮食的逆向解（照旧去常去的那家餐馆，只在菜单里挑相对健康的）就比正向解（自己买菜在家做饭）阻力小得多，因而真的能坚持。

关键判据有三条：
1. 正向求解是否已经卡住，或正向答案是否多到无从下手？是，就反转。
2. 反转之后能不能列出**具体、可观察、可执行**的失败做法（而不是"不努力"这种空话）？
3. 这些失败做法能不能被逐一排除或设防？

---

## A1 — 书中的应用 (Past Application)

### 案例: 健康饮食的正向解 vs. 逆向解
- **问题**: 想吃得健康，但正向做法（自己采购保质期内的食材、天天在家做饭）需要改变整套生活习惯，多数人坚持不下来。
- **方法论的使用**: 不去问"我该怎样吃得最健康"，而是问"如果照旧去我常去的那家餐馆，我怎么做能让这顿饭相对健康一点"——在既有行为框架内做最小的反向优化。
- **结论**: 逆向解不追求最优，但因为它不要求改变习惯，实际执行率和长期效果往往好过被放弃的正向最优解。作者用它说明：反转不只是换个角度，而是能生成一整套正向思维根本列不出来的策略。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **目标太大、太抽象，无法下手**：用户说"我想把副业做起来""我想财务自由""我想团队效率更高"，但说不出下一步。正向路径无限多，此时反转成"什么一定会让这件事黄掉"。
2. **方案已定，需要最后一道防线**：方案看着挺好，用户隐约不安但说不出哪里不对。反转成"如果这件事三个月后失败，最可能的原因是什么"，做一次失败预演（pre-mortem）。
3. **行为改变类问题反复失败**：用户多次尝试某个好习惯都坚持不下来（健身、存钱、写作）。正向设计总是假设一个"理想的自己"，逆向设计则承认现有习惯不动，只在其内部寻找可行解。
4. **要给用户一份可打勾的清单**：用户需要的不建议，而是防错机制（发版前的检查项、签约前的红线、上线前的回滚预案）。

### 语言信号 (用户的话里出现这些就应激活)

- "我想做成 X，但不知道从哪下手"
- "总觉得哪里会出问题，但说不上来"
- "万一搞砸了怎么办"
- "你帮我想想最坏的情况"
- "我试过好几次都没坚持下来"
- "给我一份避坑清单 / 检查清单"
- "How could this fail?" / "What's the worst case?" / "Let's invert this."

### 与相邻 skill 的区分

- 与 `mm-murphy-s-law` 的区别: 墨菲定律只是断言"凡可能出错必出错"，给出的是心态与兜底意识；逆向思维是一套**生成策略的操作**——先反转问题，再穷举失败路径，再逐条排除，产出的是新选项而不只是预案。
- 与 `mm-unforced-error` 的区别: 主动失误关注的是**已经犯下的、本可避免的错**（事后归因）；逆向思维是**事前**主动构造失败清单来预防。一个是复盘工具，一个是设计工具。
- 与 `mm-de-risking` 的区别: 去风险化是在现实世界里**用最低成本检验**某条关键假设；逆向思维不动手实验，只是在思维层面翻转问题来打开选项空间。通常先逆向列出可能死法，再去风险化验证最致命的那条。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出用户的原始正向目标，并确认它是否"卡住"**
   - 完成标准: 能用一句话复述用户的目标；并判断出它是"路径过多无从下手"还是"路径已明确只需择优"。
   - 判停条件: 若是后者（目标明确、只需比较 A/B 方案），停止本 skill，转向成本收益分析或决策树。
2. **把目标反转成失败提问**
   - 完成标准: 生成一句明确的反向问句，形如"如果这件事在 [时间] 内彻底失败，最可能的原因是什么？" / "要想保证搞砸，我应该怎么做？"。禁止写成"怎样不成功"这种无信息量的同义反复。
3. **穷举失败路径，直到 8-15 条**
   - 完成标准: 每条都必须是**具体的、可观察的行为或条件**（"上线前没做灰度""把 80% 收入押在单一客户""没留 3 个月现金流"），而不是"不努力""心态不好"这种不可操作的词。
   - 判停条件: 若连 5 条具体的都列不出，说明用户对这个领域缺乏基本事实，先回到信息收集，不要硬凑。
4. **按"致命性 × 发生概率"排序，取前 3 条**
   - 完成标准: 给出排序理由，前 3 条是那种"只要它发生，整件事就崩"的路径。
   - 判停条件: 若某条路径已被用户现有的做法覆盖，直接划掉，不占用前 3。
5. **为前 3 条各设计一条防线或一次检验**
   - 完成标准: 每条防线是可执行的动作（加一道检查、设一个阈值、做一次低成本验证），并写明由谁在什么时候做。
   - 判停条件: 若防线的成本高于它防范的损失，删掉它，改为"接受这个风险"并明确告知用户。
6. **回到正向，输出反转带来的新策略**
   - 完成标准: 至少给出 1 条"只有反转后才想得到"的策略——即不改变用户现有习惯或约束、但在其内部更优的做法（对应书中健康饮食那个餐馆解）。若列不出，说明反转没产生增量，如实告知。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **目标明确、约束清晰、只需择优时**：比如"两个 offer 选哪个""这笔钱存定期还是买国债"。此时反转只会增加噪音，直接做成本收益分析或期望值计算即可。
- **纯创造性/探索性问题**：想一个广告 slogan、设计一个 logo、起一个名字。这类问题没有"失败路径"可穷举，反转不会产生有效约束。
- **危机已经发生、正在救火时**：此时需要的是止损和止血（stop-the-bleeding），不是穷举失败清单。逆向是事前和事后复盘工具，不是实时救火工具。

### 书中警告的失败模式 / 容易误用的地方

- **逆向只能缩小失败面，不能替代正向的目标设定**（书中明示）。作者把它定位为"出发点"而非完整决策法。只做避坑会得到一个"什么都不做就一定不会错"的保守解——避开了所有失败，也避开了所有收益。
- （推导, 非书中明示）把"反转"做成同义反复：把"怎样成功"换成"怎样不失败"是没用的，必须换成**具体的失败动作**才有信息量。
- （推导, 非书中明示）穷举清单过长会退化为焦虑清单。若超过 15 条，说明没有做第 4 步的排序，应强制收敛到前 3 条。

### 容易混淆的邻近模型

- **反向思维（working backwards）**: 从期望的终局倒推当下该做什么，是时间轴上的倒推；逆向思维是**目标性质的取反**（成功 ↔ 失败），两者不是一回事。
- **pre-mortem（事前验尸）**: 是逆向思维的一种团队化、流程化实现形式；逆向思维是更通用的个人思考动作。
