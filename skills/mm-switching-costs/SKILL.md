# 转换成本（switching costs）

## R — 原文 (Reading)

> 如果客户认为转换成本（switching costs）非常高，因此被当前使用的服务锁定，拥有有效“护城河”的组织和个人就创造出了“锁定效应”（lock-in）。
>
> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

**转换成本（switching costs）** 是客户改用其他供应商所需付出的代价。代价越高，客户越难被抢走。

**它描述什么**：转换成本的形式远不止钱。书中列出的来源包括：**取消服务费、值得信赖的关系、新设备成本、学习曲线**。此外还有网络效应与品牌亲和力。当客户认为这些成本的总和太高，就会被当前使用的服务锁定——这就是"锁定效应"。

**为什么成立**：人做决策时比较的不是"新方案好不好"，而是"新方案的好处减去迁移代价，是否还大于现状"。即使新方案客观上更优，只要迁移代价超过它带来的增量收益，理性选择就是不动。因此**留存不只取决于产品好不好，还取决于离开疼不疼**。

**关键判据**：转换成本是**客户感知到的成本**，不是你账面上的成本。你以为迁移很容易，客户觉得要重学一遍、要跟老板解释、要冒数据丢失的风险——感知才是决定行为的那个数。

**它不只存在于商业**：书中明确指出，转换成本同样来自**情绪与心理成本**、**搬家成本**、**机会成本**。人们因为亲朋好友都在某个社交平台上分享照片而感觉走不掉；雇主因为某个关键员工不可或缺而被锁定（甚至出现了"关键人物保险"）。

**怎么用**：

- 防守方：找出转换成本中最高的一项，加固它——这是护城河最实在的组成部分。
- 进攻方：想抢走客户，不能只证明"我更好"，必须同时**降低对方的迁移代价**（迁移工具、数据导入、并行过渡）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 客户流失率居高不下，产品评价不差，但就是留不住人。
2. 要设计留存机制/会员体系，想知道该加固哪一条。
3. 作为买方在评估"要不要换掉现在的供应商/系统/工具"。
4. 个人层面在评估跳槽、搬家、分手的实际代价，说不清为什么迟迟不动。
5. 作为进攻方，想从竞品手里抢客户，但对方产品并不比你好。

### 语言信号

- "客户为什么留不住"
- "换掉现在这套要花多少代价"
- "迁移成本太高了，动不了"
- "我们是不是被这家供应商绑定了"
- "他们产品没我们好，为什么客户不换"
- "想跳槽但总觉得有什么拽着我"
- "switching costs / migration cost / too expensive to switch / we're locked in / switching barrier"

### 与相邻 skill 的区分

- 与 `mm-lock-in` 的区别: 转换成本是**原因**（客户要付出的代价）；锁定效应是**结果状态**（因此被绑住、难以脱离）。要设计或量化成本用本 skill；要判断"我是不是被困住了、该不该承受代价脱离"用锁定效应。
- 与 `mm-moat` 的区别: 护城河是**总称**——所有让你难以被攻击的东西；转换成本只是护城河的**一种来源**（还有网络效应、规模经济、管制俘获、品牌等）。要分析护城河全貌用 moat，要深挖其中"迁移代价"这一条用本 skill。
- 与 `mm-barriers-to-entry` 的区别: 进入壁垒阻止**新玩家进来**；转换成本阻止**已有客户离开**。两者同属护城河的两面，但方向相反——一个管入口，一个管出口。高转换成本对你来说是护城河，对想抢客户的你来说就是壁垒。
- 与 `mm-network-effects` 的区别: 网络效应是"用的人越多越好用"，其产生的不可脱离感**只是转换成本的一个来源**；本 skill 覆盖的范围更广（财务、关系、学习曲线、情绪等），网络效应只是其中一格。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确切换的双方与方向**
   - 完成标准: 写清"从 A 换到 B"具体指什么（谁在换、换成什么、什么时间点）。方向不清则成本无法列举。
2. **穷举所有要付出的成本，不只看钱**
   - 完成标准: 至少覆盖六类——财务成本（违约金、新设备/新订阅、迁移服务费）、流程成本（停机时间、数据迁移、重新对接）、关系成本（值得信赖的对接人、与供应商的默契）、学习成本（学习曲线、团队重培训）、网络与生态成本（插件、集成、协作方都在原平台）、情绪与心理成本（不确定感、沉没投入、对未知的抵触）。
   - 判停条件: 若用户只列出了财务成本，明确指出这是最常见的漏项，强制补齐其余五类。
3. **区分客观成本与感知成本，并估算量级与持续时间**
   - 完成标准: 每项标出是"实际会发生"还是"客户以为会发生"，给出粗略量级（人天/金额/月数）和它是**一次性**还是**持续性**的。
4. **找出最高的一项并采取对应动作**
   - 完成标准: 明确指出成本最高的那一项。防守方 → 给出加固它的具体动作；进攻方 → 给出降低它的具体动作（迁移工具、数据导出、并行期、兜底承诺）；个人 → 给出能否把这项成本降下来的方案。
5. **反向检查：成本是否高到引发反感**
   - 完成标准: 判断加固手段是否会让客户产生被困感——高到一定程度，转换成本会从留存机制变成怨恨来源（见边界）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 客户根本没考虑过离开（需求刚被满足、尚无替代方案）——此时不需要分析迁移成本。
- 纯产品力问题（产品明显不如竞品）——抬高转换成本只是延缓流失，不是解法。
- 判断"我是不是被困住了、该不该脱离"——那是锁定效应的任务。
- 一次性交易、无复购无续期的场景——转换成本没有作用对象。

### 容易误用的地方

- （推导, 非书中明示）只算财务成本。书中明确列出取消服务费、信赖关系、新设备成本、学习曲线，并指出情绪与心理成本、搬家成本、机会成本同样造成锁定。只算钱会严重低估真实的迁移阻力。
- （推导, 非书中明示）用提高转换成本替代提升产品价值。这在产品体验上就是"黑暗模式"——让取消难、导出难、退订难。它能在短期内压住流失数字，但会积累怨恨，并在竞争环境变化时一次性反噬。
- （推导, 非书中明示）以为转换成本是永久的。学习曲线会随产品趋同而消失，数据迁移会随工具成熟而变便宜，网络效应会随用户关系迁移而衰减。转换成本需要持续再投资。
- （推导, 非书中明示）忽略进攻方视角。想抢走客户时，证明"我更好"通常不够——必须同时把对方的迁移代价降下来，否则对方客户即使认同你也动不了。
