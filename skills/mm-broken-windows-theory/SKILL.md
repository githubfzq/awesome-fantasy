# 破窗理论（broken windows theory）

## R — 原文 (Reading)

> 能够看见的轻罪罪证（例如某个社区中的破窗）会营造鼓励重罪（例如谋杀）的氛围。

> — 《思维模型》, 第7章 > 唯一的制胜法宝就是别参战

---

## I — 方法论骨架 (Interpretation)

破窗理论主张:**可见的轻罪痕迹(比如社区里的破窗)会营造出鼓励重罪的氛围**。

它的机制是一个**信号与传染**的类比:破掉的窗没人修,传递出"这里没人管"的信号;这个信号会同时作用于两类人——潜在的违规者觉得代价更低,守规矩的人觉得守规矩没意义、进而退出。于是小的失序如果不管,会自我强化,滑向更混乱的状态。作者把它归入"守住底线"这一类思路:在事情还小的时候介入,比等到失控后收拾更省力。

**但书里给了非常明确的保留**:相关的干预措施对减少犯罪的效果**目前尚不明确**,**只靠传染类比不足以为证**。这一点必须写在最前面——破窗理论是一个**待检验的假设**,不是已确立的规律。作者把它和入门毒品理论放在一起讲,正是因为它们共享同一个结构:**用"小会导致大"的直觉替代了因果证据**。

所以正确的用法是:
- 把它当作**一个值得测试的方向**,而不是决策的充分理由;
- 关注它真正可验证的部分——**环境线索确实会影响人的行为**(这一点相对可靠),而不是"修窗户能降低谋杀率"(这一点存疑);
- 若要用它推动治理,必须配套衡量,不能靠直觉认定有效。

关键判据是:**你是在主张一个机制(线索影响行为),还是在主张一个效果(治理小恶能降重罪)?** 前者可以接受,后者需要证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想推动团队/社区/产品的规范治理,理由是"小问题不处理会带坏整体风气"。
2. 用户在评估一项"从严治理小违规"的措施(零容忍、强制规范、自动拦截)是否值得投入。
3. 用户观察到环境变差(代码质量下滑、公共区域脏乱、流程被绕过),想判断该从哪里入手。
4. 用户被别人用破窗理论要求加大处罚力度,需要判断这个论证的分量。

### 语言信号

- "小问题不管,大家就会跟着来"
- "风气坏了就很难拉回来"
- "要不要对这种小事也严格起来"
- "反正都这样了,我也没必要认真"
- "先从最明显的地方抓起"
- "broken windows" / "zero tolerance" / "if we let this slide"

### 与相邻 skill 的区分

- 与 `mm-slippery-slope-argument` 的区别: 滑坡论是**检验论证形式的工具**(逐环检查是否必然),破窗理论是**一个关于秩序信号的具体主张**;破窗式论证常常正是需要被滑坡论检验的对象。
- 与 `mm-gateway-drug-theory` 的区别: 两者结构相同(小导致大)且书中都标注证据存疑;区别在领域——破窗讲的是**环境与秩序信号**,入门毒品讲的是**个体行为的递进**;书中明确把亏本销售列为入门毒品理论的真实版本。
- 与 `mm-zero-tolerance-policy` 的区别: 零容忍是**一种具体政策**(对所有违规一律从严),破窗是**用来支持它的理论**;理论存疑时,政策的代价需要单独评估。

## E — 可执行步骤 (Execution)

1. **区分"机制主张"与"效果主张"**
   - 完成标准: 明确指出用户说的是哪一层——环境线索会影响行为(相对可靠),还是治理小恶能降低重罪(证据尚不明确);后者必须标为待验证。
2. **定位可见的具体"破窗"**
   - 完成标准: 列出 3-5 个可见的、具体的轻罪痕迹(未修复的窗、长期未处理的小缺陷、被公开绕过的流程),而不是笼统的"风气不好"。
   - 判停条件: 若说的其实是重大违规,不适用本模型。
3. **设计小成本修复动作**
   - 完成标准: 每个"破窗"给出一个可执行、低成本、可见的修复动作与负责人;优先选那些不依赖强执法就能完成的。
4. **坚持配套衡量,不靠直觉认定有效**
   - 完成标准: 明确引用书中保留——干预效果尚不明确、只靠传染类比不足为证;给出可观测指标与对比方式(前后对比或分组对比),并预设"若无效则停止"的条件。
5. **检查代价**
   - 完成标准: 列出从严治理的副作用(误伤、信任下降、执行成本),并说明为什么这些代价在当前规模下是可接受的。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 用它单独支撑强硬执法或零容忍政策:书中明确指出干预效果尚不明确,只靠传染类比不足为证。(书中明示)
- 把"环境线索影响行为"直接等同于"治理小恶能降重罪":这是两个强度差别很大的主张。
- 用"风气"掩盖真正的结构性问题(激励机制、资源不足、流程缺陷):修窗户解决不了设计错误。

### 容易误用的地方

- 作者明确指出:相关干预措施对减少犯罪的效果"目前尚不明确",只靠传染类比不足为证。(书中明示)
- 把破窗当成既成事实的结论来引用,而不是待检验假设。(书中明示的直接推论)
- 只挑最容易抓的小违规来立威:这既不能验证理论,还会制造不公平感。(推导,非书中明示)
- 忽略相关性方向:可能是重罪高发地区本来就更容易出现破窗,而不是破窗导致重罪。(推导,非书中明示)

### 容易混淆的邻近模型

- 与入门毒品理论(gateway-drug-theory): 同构(小导致大)且同样证据存疑,领域不同。
- 与零容忍政策(zero-tolerance-policy): 理论依据与具体政策。
