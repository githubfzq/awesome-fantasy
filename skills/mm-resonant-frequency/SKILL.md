# 共振频率（resonant frequency）

## R — 原文 (Reading)

> 共振频率（resonant frequency）模型可以用于描述上述现象。这个模型来自物理学，可以解释为什么发出适当的音高能震碎玻璃——因为每个物体都有不同的自然振动频率。
>
> — 《思维模型》, 第9章 > 缺少执行的愿景不过是幻想

---

## I — 方法论骨架 (Interpretation)

物理原义：**每个物体都有不同的自然振动频率**；当外界激励的频率与之吻合时，**能量在匹配频率上不断累积**，振幅急剧放大——足以震碎玻璃。

**为什么成立**：不匹配的激励每一轮都在与物体的运动方向相抵消，能量互相抵消；匹配的激励每一轮都**叠加**在上一轮的余量上，于是微小的持续输入也能累积成远超输入比例的剧烈反应。差别不在投入大小，而在**相位是否对齐**。

**借用到商业的逻辑**：真正的产品/市场匹配带来的**不是小幅改善，而是爆发式增长**——表现在增长曲线上与售罄这样的现象上。书里用"十倍团队"作类比：真正的共振不是好上一两倍，而是好上许多倍。

由此得到最实用的判据：**当你加大投入却看不到成比例的效果时，问题通常不是力度不够，而是频率不对。** 在这个隐喻里，"频率"指的就是你的产品/内容与市场需求之间的对齐程度。

反过来也成立：一旦对上频率，**不需要成比例地加大投入**就能获得远超比例的回报。这是区分"还没对上"与"已经对上"的最强信号。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 营销/投放预算翻倍，转化却几乎没动，用户在纠结要不要继续加钱。
2. 产品功能越加越多，用户增长依然平缓，团队疲惫。
3. 某个改动突然带来远超预期的反响，用户想知道为什么、能不能复制。
4. 招人、开会、推制度都很用力，但组织毫无反应。
5. 用户在两个方向上犹豫：是加大投入还是换个做法。
6. 复盘一次意外的爆发式增长，想提取可复用的规律。

### 语言信号 (用户的话里出现这些就应激活)

- "预算翻倍了，怎么还是没效果"
- "我们做了这么多，用户就是不买账"
- "突然就爆了，不知道为什么"
- "投入产出完全不成比例"
- "是不是该换个方向试试"
- "一下子就售罄了"
- "doubled the budget, no results / suddenly took off / nothing moves the needle"

### 与相邻 skill 的区分

- 与 `mm-product`（产品/市场匹配）的区别: 产品/市场匹配是**要达成的状态**；本 skill 提供的是**识别与解释它的物理隐喻**——尤其强调"对上之后回报不再是线性比例"。诊断匹配程度用 product；解释为什么加力无效、为什么会爆发，用本 skill。
- 与 `mm-critical-mass` 的区别: 临界量讲的是**需要积累到多少量**才能自持（量的门槛）；本 skill 讲的是**输入的频率是否对齐**（质的匹配）。堆到临界量但频率不对依然不会共振。
- 与 `mm-tipping-point` 的区别: 临界点描述**越过某点后状态突变**这一现象；本 skill 解释**突变背后的机制**（匹配频率上的能量累积）。前者描述曲线形状，后者解释成因。
- 与 `mm-network-effects` 的区别: 网络效应是**一种具体的增长机制**（用户增加带来价值增加）；本 skill 是关于投入与产出非线性的**通用隐喻**，不限定具体机制。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认是不是非线性现象**
   - 完成标准: 对比投入增幅与产出增幅。若两者大致成比例，这是线性问题（资源不足或效率问题），本 skill 不适用。
   - 判停条件: 若确认是线性投入不足，直接转资源/效率分析。
2. **区分"力度不够"与"频率不对"**
   - 完成标准: 明确提出判断并给出依据。判据：若在较低投入下已经出现不成比例的正向反馈（自然增长、主动推荐、售罄），说明频率已对上，问题是力度；若投入持续增加而反馈始终微弱，说明频率不对。
3. **定位"频率"具体指什么**
   - 完成标准: 把抽象的"对齐"落到可检验的维度——对产品是目标用户与核心场景，对营销是信息与受众，对组织是激励与成员真实动机。每个维度给出当前的对齐程度判断。
4. **频率不对时：停止加力，改为扫频**
   - 完成标准: 给出 2-3 个具体的替换/调整实验（换受众、换信息、换场景、换激励方式），每个实验要小而快，目的是**找到对齐点**而非扩大规模。明确建议：在找到之前不加大投入。
5. **频率已对上时：确认共振信号再加力**
   - 完成标准: 列出观察到的共振信号（增长加速、用户主动传播、供不应求），并明确"不是好上一两倍，而是好上许多倍"这一量级标准；确认后再集中资源放大。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 投入与产出大致成比例——这是线性问题，用资源与效率分析。
- 需要判断"还差多少量才能自持"——用临界量。
- 需要具体的增长机制设计——用网络效应/飞轮。
- 物理/工程场景下的真实共振计算——本 skill 是隐喻用法，不做物理计算。

### 容易误用的地方

- 书中未给本模型的边界说明，以下均为基于机制推导。
- （推导, 非书中明示）把"没效果"一律归因于没共振，从而无限期地换方向。也可能是投入本身远低于必要水平，或是执行质量差。应当先用第 1 步排除线性情形。
- （推导, 非书中明示）认为只要找到频率就一劳永逸。物体的自然频率会随状态改变（产品演进、市场变化、团队成长），需要重新扫频。
- （推导, 非书中明示）混淆"共振"与"量大"。共振的关键是**匹配**而非规模；在错误频率上堆量，只会放大浪费。
- （推导, 非书中明示）用它给"再加一把力"背书。模型恰恰提示：在频率未对上时，加力不是解法。
- （推导, 非书中明示）把"好上一两倍"当成共振。书中明确：真正的共振是好上**许多倍**，不是小幅改善。

### 容易混淆的邻近模型

- **临界量（critical mass）**: 量的门槛；本 skill 是质的匹配。
- **临界点（tipping point）**: 描述突变现象；本 skill 解释突变的机制。
