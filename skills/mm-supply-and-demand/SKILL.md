# 供求关系（supply and demand）

## R — 原文 (Reading)

> 与哈驰魔法蛋一样，市场价格（在这个例子中是薪酬待遇）与供求关系有关。
>
> — 《思维模型》, 第9章 > 开篇

---

## I — 方法论骨架 (Interpretation)

市场价格由**供给量与需求量的相对关系**决定：稀缺则价高，过剩则价低。书里把它直接用在劳动力市场上——你的薪酬就是你这个技能组合的市场价。

**为什么成立**：价格不是由成本、努力或价值感决定的，而是由"有多少人想要"与"有多少人能提供"的相对关系决定的。这解释了大量反直觉现象：投入多年苦读的专业未必高薪，因为决定价格的是需求端和竞争者数量，不是投入端。

书里的两个对照案例把这个机制讲得很清楚：

- **美国护士**：需求大而新毕业生供给有限 → 起薪诱人。
- **历史学博士**：人数很少（供给少），但终身教职更少（需求更少）→ 求职极难。

第二个案例是关键：**供给少本身不值钱，供给相对于需求少才值钱。** 只看"干这行的人不多"会得出完全错误的结论。

**两条提升价格的杠杆**（书中明示）：

1. 选择**长期需求大**的行业。
2. 培养**市场重视的独特技能**。

**最重要的边界**：光有独特技能不够——若市场对该技能无需求（如奥运选手的技能），仍无支配力。独特性必须与市场重视同时成立。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 选专业、转行、选 offer，问"哪个方向更有前景"。
2. 想涨薪，在考虑学一项新技能/考一个证，要判断值不值。
3. 困惑于"我很努力、能力也不差，为什么薪水上不去"。
4. 招聘时定薪困难，不理解为什么某个岗位市场价这么高。
5. 创业选赛道，想判断这个市场的价格空间。
6. 解释某个商品/资产价格异常涨跌的原因。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么这个岗位薪水这么高"
- "学什么技能比较值钱"
- "哪个行业更有前景"
- "我很努力但薪水一直上不去"
- "这个价格凭什么这么贵"
- "这行是不是饱和了"
- "is this skill in demand / what's the market rate / why are nurses paid so much"

### 与相邻 skill 的区分

- 与 `mm-perfect-competition` 的区别: 供求关系决定**市场价格是多少**；完全竞争描述**你能否偏离那个价格**。在完全竞争中你只能接受供求决定的价格。两者常连用但回答的是不同问题。
- 与 `mm-market-power` 的区别: 市场支配力衡量的是**你影响价格的能力**；供求关系是**价格本身的来源**。独特技能 + 市场需求 = 支配力，本 skill 是支配力的上游解释。
- 与 `mm-scarcity` 的区别: 稀缺只描述**供给端**；本 skill 强调供给与需求的**相对关系**。书中历史学博士的案例正是稀缺却不值钱的反例——只看稀缺会出错。
- 与 `mm-opportunity-cost` 的区别: 机会成本衡量"放弃了什么"，用于**选择比较**；本 skill 解释"价格为什么是这样"，用于**理解定价**。选行业时可以先用本 skill 判断价格，再用机会成本比较取舍。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先明确要定价的对象是什么**
   - 完成标准: 精确界定——是某项技能组合、某个岗位、某类商品还是某个市场。界定模糊会导致供求口径错乱（如"程序员"太宽，"某框架的资深工程师在某城市"才有效）。
   - 判停条件: 若用户其实在问"我能否要价高于市场"，转 `mm-market-power`。
2. **分别估计需求端与供给端，不要只估一端**
   - 完成标准: 需求端给出"有多少买方/雇主在争抢、趋势是增是减"；供给端给出"有多少合格提供者、进入门槛多高、供给增长多快"。两边都要有依据。
3. **做相对比较，识别"稀缺却不值钱"陷阱**
   - 完成标准: 明确给出供给与需求的相对关系结论。特别检查：是否存在"供给很少但需求更少"的情形（历史学博士式）——这是最常见的误判。
4. **检验独特性是否"被市场重视"**
   - 完成标准: 若用户打算靠独特技能提价，明确验证市场对该技能是否有真实需求。书中警告：奥运选手的技能极度独特但无市场需求，仍无支配力。独特性 ≠ 支配力。
5. **落到两条杠杆上的具体动作**
   - 完成标准: 给出可执行选择——(a) 转向长期需求大的领域的具体方向；(b) 培养市场重视的独特技能的具体清单。每条都要说明预期在多长时间内影响价格，并提示本模型给的是结构性方向，不是短期价格预测。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要短期价格预测——本模型解释结构性水平，不预测波动。
- 价格由管制、议价协议或单一买家决定时——市场机制不主导。
- 问题实为"我能否要价高于市场"——用市场支配力。
- 评估是否该进入某市场——用进入壁垒与市场支配力组合。

### 容易误用的地方

- 书中明示：**光有独特技能不够**——若市场对该技能无需求（如奥运选手的技能），仍无支配力。独特性必须与市场重视同时成立。
- （推导, 非书中明示）只看供给端就下结论。历史学博士案例说明"干这行的人很少"完全可能对应"机会更少"，必须两边都估。
- （推导, 非书中明示）把努力程度或投入成本代入定价。价格由供求相对关系决定，与个人或生产者的投入无关。
- （推导, 非书中明示）忽略时间维度。书中的两条杠杆之一明确是"**长期**需求大的行业"，用当下的紧缺外推未来会踩到供给涌入的时滞（今天稀缺的技能，几年后可能供给过剩）。
- （推导, 非书中明示）用它给薪酬不公辩护。模型解释价格形成，不评价价格是否正当。

### 容易混淆的邻近模型

- **稀缺（scarcity）**: 只描述供给端；本 skill 强调供求的相对关系。
- **市场支配力（market power）**: 本 skill 解释价格来自哪里；支配力衡量你能不能改变它。
