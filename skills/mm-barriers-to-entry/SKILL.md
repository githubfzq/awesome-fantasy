# 进入壁垒与退出壁垒（barriers to entry / barriers to exit）

## R — 原文 (Reading)

> “护城河”引出的两个相关概念是进入壁垒（barriers to entry）和退出壁垒（barriers to exit）。它们会阻止个人或企业进入、退出市场或某种局面。
>
> — 《思维模型》, 第9章 > 激活力场

---

## I — 方法论骨架 (Interpretation)

**进入壁垒（barriers to entry）** 与 **退出壁垒（barriers to exit）** 是从"护城河"引出的两个相关概念：**它们会阻止个人或企业进入、退出市场或某种局面**。

**它描述什么**：护城河是双向的。进入壁垒挡住想进来的人，退出壁垒挡住想出去的人。两者共同决定了一个局面的**粘性结构**：好生意通常"难进易退"或"难进难退但回报足够高"，最糟的是"易进难退"——谁都能来抢，而你走不掉。

**为什么成立**：壁垒改变的是可选行动的集合，而不是行动的质量。进入壁垒决定了**未来会有多少竞争者**，退出壁垒决定了**你自己在判断错误时能否止损**。这两件事分别对应收益端的确定性与风险端的下限。

**壁垒的形式远比"钱"多样**，书中列举了：

- **商业机密**——可口可乐的配方。
- **高额投资**——建一座大工厂。
- **政府法规**——牌照、审批、合规成本。
- **需重建整个生态**——新移动操作系统要与 iOS、安卓竞争，必须重建含数千款应用的应用商店。
- **长学制与高学费**——职业层面的壁垒。
- **个人契约**——竞业协议、伴侣协议、婚姻，同样构成重要的**退出**壁垒。

**关键判据**：不要只看壁垒的**高度**，要看它的**可持续期**与**可绕过性**。一座很高但两年后会被技术抹平的墙，不如一座不高但二十年内无人能绕的墙。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估一个市场值不值得进——进去有多难、进来后会不会立刻被抄。
2. 进入之后才发现退出代价很高，需要复盘当初漏判了什么。
3. 想给自己的业务构建壁垒，不知道该往哪个方向投。
4. 个人层面：考虑一个需要长学制/高学费/竞业协议的职业选择。
5. 在签一份含退出条款的合约（竞业、对赌、长期租约、合伙协议）之前。
6. 看到一个"谁都能做"的赛道，判断它会不会迅速变成红海。

### 语言信号

- "这个市场门槛高不高"
- "谁都能做,我们进去还有机会吗"
- "进去容易出来难"
- "签了竞业协议是不是就被套牢了"
- "要重建整个生态,这代价太大了"
- "我们该建什么样的护城河"
- "barriers to entry / barriers to exit / entry barrier / moat / regulatory hurdle / exit cost"

### 与相邻 skill 的区分

- 与 `mm-moat` 的区别: 护城河是**总称与结果**（你有多难被攻击）；进入/退出壁垒是它的**两个具体侧面**。要评估护城河全貌用 moat，要拆成"入口挡什么、出口挡什么"来逐项盘点用本 skill。
- 与 `mm-switching-costs` 的区别: 转换成本是**退出壁垒的一种具体形式**——客户改用别家的代价。本 skill 覆盖面更广（机密、资本、法规、生态、契约），且同时管进口与出口。要深挖客户迁移这一条用转换成本，要看完整壁垒结构用本 skill。
- 与 `mm-lock-in` 的区别: 锁定效应是**被困者的状态与脱离决策**；退出壁垒是**造成这种状态的结构性清单**。要判断"我是不是被困住、该不该脱离"用锁定效应，要列出障碍并评估净效应用本 skill。
- 与 `mm-beachhead` 的区别: 壁垒回答**能不能进、要不要进**；滩头堡回答**既然要进，从哪里进**。前者是可行性判断，后者是路径选择——顺序是先壁垒后滩头堡。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分别列两张清单，不要只列进入**
   - 完成标准: 明确产出"进入壁垒清单"与"退出壁垒清单"各一份。
   - 判停条件: 若用户只列了进入壁垒，明确指出这是最常见的漏判——退出壁垒决定你亏多少，必须单独列。
2. **给每项壁垒打三个分：高度 / 可持续期 / 可绕过性**
   - 完成标准: 每项都标出——有多高（需要多少资源才跨得过）、能维持多久（会不会被技术或法规变化抹平）、能不能绕过去（有没有侧门）。
   - 判停条件: 若某壁垒"很高但两年内会被抹平"或"很高但存在明显侧门"，在结论中降级处理，不能照高度计分。
3. **判断净效应，归入四象限**
   - 完成标准: 明确给出局面属于哪一种——**难进难退**（高投入高粘性，赌注大）、**难进易退**（最优结构）、**易进易退**（打价格战）、**易进难退**（最危险，谁都能来抢而你走不掉）。
4. **若进入壁垒过低：给出可构建的壁垒候选**
   - 完成标准: 至少给出 2 条针对该场景的可构建壁垒（机密/数据积累、资本规模、法规牌照、生态集成、品牌、转换成本），并说明构建成本与见效周期。
5. **若退出壁垒过高：先设计退出路径再决定进不进**
   - 完成标准: 给出具体的退出条款/阶段化解绑方案（分期承诺、对赌上限、可转让条款、竞业范围与期限的谈判要点），并明确"谈不下来就不进"的红线。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 已进入且退出条款不可更改——此时盘点壁垒没有操作空间，应转向应对。
- 纯产品力或执行力问题——壁垒分析不解决"做不出来"。
- 只需量化客户迁移代价的采购决策——用转换成本。
- 快速变化的早期市场，壁垒尚未成型——过早的壁垒评估会给出虚假的确定性。

### 容易误用的地方

- （推导, 非书中明示）只看进入不看退出。书中明确把两者作为一对概念提出，因为**退出壁垒决定你判断错误时的亏损下限**。易进难退是最危险的结构。
- （推导, 非书中明示）把规模当成壁垒。规模只有在带来成本优势、数据优势或生态锁定时才是壁垒；单纯的"我们做得早、体量大"不构成阻止进入的障碍。
- （推导, 非书中明示）以为壁垒是永久的。可口可乐配方靠的是持续保密，应用商店生态靠的是持续投入，法规牌照可能被政策取消。必须评估可持续期与可绕过性。
- （推导, 非书中明示）忽略个人层面的退出壁垒。书中点名了竞业协议、伴侣协议、婚姻，以及长学制与高学费——这些都是签约前就要谈的条件，签完再评估已无意义。
