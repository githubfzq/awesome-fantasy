# 2×2矩阵（2 × 2 matrices）

## R — 原文 (Reading)

> 你应该参加高影响、低成本的活动，忽略低影响、高成本的活动。
>
> — 《思维模型》, 第4章 > 从混沌到有序

---

## I — 方法论骨架 (Interpretation)

2×2 矩阵的做法是：取两个二元维度交叉，得到四个象限，每个象限配一条明确的行动规则。它的价值不在于信息量——四象限装不下多少信息——而在于**把混乱压缩成可执行的分类**。

书中用"哪些活动值得参加"演示了完整用法：取"影响高/低"×"成本高/低"，得到四条规则——参加高影响低成本的，忽略低影响高成本的，另两个象限视具体情况权衡。

这个框架的威力来自三个特点。第一，**强迫你显式化维度**：你必须说出"我到底按什么在分"，这本身就消除了大量隐含混乱。第二，**每个象限必须落到动作**：只分类不给行动规则的矩阵是无效的自娱自乐。第三，**它可以自制**：作者强调你还可以开发自己的思维模型（自制 2×2 矩阵）来简化混乱系统——它不是一套固定模板，而是一种可复用的构造法。

判据是：选出的两个维度，是否真的能把当前的选项**分开**？如果两个维度高度相关（比如"重要"和"紧急"总是一起出现），矩阵会退化成一条对角线，失去意义。

---

## A1 — 书中的应用 (Past Application)

### 案例: "哪些活动值得参加"矩阵

- **问题**: 面对大量活动邀约，如何决定去哪些、不去哪些？
- **方法论的使用**: 作者以"影响（高/低）× 成本（高/低）"自制了一个矩阵：高影响低成本的必去；低影响高成本的忽略；离家不远的会议属于高影响高成本，视时间与资金而定；走廊对面的低影响活动只花一小时，因成本太低也许值得一去。
- **结论**: 关键是不要只看"有没有影响"或只看"贵不贵"，而是两个维度交叉后分别给规则——尤其注意"低影响但成本极低"这类容易被一刀切砍掉、其实值得做的象限。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户手上有一堆待办/候选方案/活动/需求，需要快速分出优先级——需要帮他挑两个合适的维度并给每象限配行动规则。
2. 用户想把一团乱麻的局面讲清楚给别人听（汇报、对齐）——需要一个可视化、一眼可懂的简化框架。
3. 用户在两个维度之间反复权衡、无法决断（又要快又要好、又要便宜又要全）——需要把权衡显式化为四象限。
4. 用户有了一个自制的分类法，想验证它是否成立——需要检查维度区分度与行动规则完整性。

### 语言信号 (用户的话里出现这些就应激活)

- "这些事我该怎么排优先级？"
- "能不能画个框架让我一眼看清？"
- "哪些该做、哪些干脆别做了？"
- "又想快又想好，不知道怎么取舍。"
- "How do I prioritize all of these?"
- "Can you put this in a simple framework?"

### 与相邻 skill 的区分

- 与 `mm-eisenhower-decision-matrix` 的区别: 艾森豪威尔矩阵是一个**固定的、特定的** 2×2（重要 × 紧急，用于时间管理）；2×2 矩阵是**通用的构造法**，用户可以自制任意两个维度。前者是后者的一个实例。
- 与 `mm-cost-benefit-analysis` 的区别: 成本收益分析做**连续量化**的净收益计算，适合精确比较少数方案；2×2 矩阵做**离散分类**，适合快速处理大量选项。前者更精确但更慢，后者更粗但更快。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确待分类的对象集合**
   - 问：要被分进四个格子的是什么？（活动、需求、客户、任务、人？）先列全，不要边分边想。
   - 完成标准: 得到一个明确的待分类清单。
2. **挑选两个维度（最关键的一步）**
   - 从候选维度里选出两个：它们应该彼此独立，且能把清单真正分开（不是所有东西都挤在一个格子里）。
   - 完成标准: 试填后每个象限都有内容，且不出现"所有项目都在一条对角线上"的退化。
   - 判停条件: 若两个维度高度相关导致退化，立刻换维度；若换两次仍退化，说明这不适合 2×2，改用 `mm-cost-benefit-analysis` 或散点图。
3. **给每个象限配一条行动规则**
   - 四格都要有动作，包括"忽略"和"视情况权衡"——后者也要写明按什么权衡。
   - 完成标准: 四个象限各有一句可执行的规则，无空缺。
4. **填入对象并检查异常格**
   - 把所有对象填进去，重点检查"低影响但成本极低"这类容易被误杀的格子。
   - 完成标准: 清单中每一项都落到了某个象限，并给出最终的行/不行动结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要多维度加权或连续量化的决策（投资决策、复杂选型）——四格装不下，会丢信息。
- 两个维度高度相关的情形——矩阵退化，比不用框架更糟。
- 需要用精确数字说服他人的场合——2×2 是定性工具，不能替代量化论证。

### 书中警告的失败模式 / 容易误用的地方

- 可能引起误解，因为大多数事物并不能清晰划分为非此即彼的两极，而是连续统一体；补救方法是在 2×2 基础上画散点图。（书中明示）
- 常见误用：把大量东西塞进一个格子然后不了了之——矩阵的价值在于行动规则，不在于分类本身。（推导，非书中明示）

### 容易混淆的邻近模型

- 与**黑白谬误**: 2×2 矩阵**故意**把连续体切成两极以获得行动力；黑白谬误是**误以为**本来就只有两极。前者是有意识的简化，后者是无意识的认知错误。
- 与**散点图（scatter plot）**: 散点图是书中给的对 2×2 的补救手段——当你需要看到连续分布而非四个格子时，用它替代。
