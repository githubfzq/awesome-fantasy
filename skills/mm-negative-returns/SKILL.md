# 负收益（negative returns）

## R — 原文 (Reading)

> 实际上，在超过限度后还继续坚持，只会让情况变得更糟糕，从“收益递减”变成“负收益”（negative returns）。

> — 《思维模型》, 第3章 > 事半功倍

---

## I — 方法论骨架 (Interpretation)

收益递减只是"涨得慢了"，负收益是"开始往回走"：越过某个临界点后继续投入，总体结果不升反降。这是量变引发的质变——曲线掉头向下。

它常发生在"追求完美反而适得其反"的场景：再改一版方案越改越乱，再练一组力量受伤停训三个月，考前开夜车让记忆与论文质量一起变差。书中明确指出这是**通往职业倦怠的快车道**，并以日本的"过劳死"（karoshi）作为极端例证。

关键判据只有一条：**追加投入之后，产出或健康/动力是否开始净下降**。判据之所以重要，是因为进入负收益的人通常感觉不到——他们感觉到的只是"还差一点就成了"，于是继续加码，形成"投入更多→结果更差→再投入更多"的恶性循环。

书中的三条例证揭示了同一个结构性特征：少年棒球投手全年高强度训练导致大量手肘韧带置换手术、很多孩子两年后因伤或失去兴趣再也不打球——**负收益的代价不只落在当下产出上，还会摧毁继续做这件事的能力与意愿**。因此作者的建议是：在**进入**负收益之前退出，而不是等到崩溃。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户连续高强度工作/备考/训练后，产出明显下滑，却仍在考虑"再加把劲"。
2. 用户为一个"已经够好"的方案反复打磨，越改越不满意、交付时间一拖再拖。
3. 用户出现健康或动力信号（失眠、厌恶、免疫力下降、情绪耗竭），仍在坚持原有节奏。
4. 用户管理的团队在赶项目，需要判断该加人加班还是该砍范围、宣布完成。

### 语言信号

- "再熬一晚上就能搞定了"
- "越改越不满意，但又说不上哪不对"
- "已经练到这个程度了，停了就前功尽弃"
- "最近一想到这件事就烦，但进度不能停"
- "团队都快撑不住了，还要不要继续冲"
- "negative returns / burning out / overtraining / overtime is killing productivity"

### 与相邻 skill 的区分

- 与 `mm-law-of-diminishing-returns` 的区别: 收益递减是**斜率变缓**（投入还有正回报，只是变少），负收益是**总量掉头向下**（投入带来净损失）。前者问"还要不要加"，后者问"是不是该撤"。
- 与 `mm-law-of-diminishing-utility` 的区别: 那个模型在**消费端**（多享受一次还爽不爽），本模型在**投入端**（多投入一份是赚是赔）。
- 与 `mm-nothing-in-excess` 的区别: 过犹不及是一条告诫（好事过头成坏事），本模型给出可操作的识别信号与退出判据。

## E — 可执行步骤 (Execution)

1. **确认当前处于曲线哪一段**
   - 问：最近一次追加投入之后，结果是变好、持平、还是变差？
   - 完成标准: 明确归类为"仍在上升""边际递减"或"已经下降"。
   - 判停条件: 若答案是"变好"，本 skill 不适用，直接结束；若是"边际变缓但仍在涨"，转 `mm-law-of-diminishing-returns`。
2. **找出负收益的三个信号**
   - 产出信号：同样一小时的有效产出是否低于上个月？
   - 健康信号：睡眠、身体、情绪是否出现恶化？
   - 动力信号：是否从"想做"变成"不得不做"？
   - 完成标准: 三类信号逐项给出是/否，至少一类为是才算确认。
3. **算清继续投入的真实代价**
   - 不只算当下产出，还要算**未来做这件事的能力是否被消耗**（受伤停训、离职、倦怠后半年恢复期）。
   - 完成标准: 给出一句代价陈述，形如"再撑两周可能换来三个月的停摆"。
4. **在临界点之前退出，而不是等崩溃**
   - 明确建议停手或大幅减量，并给出替代路径：砍范围、宣布完成、换人、延长期限。
   - 完成标准: 给出至少一个具体的替代方案与一个明确的停手时间点。
   - 判停条件: 若用户坚持"再试最后一次"，要求他先设定一个客观的中止条件（如"这版再改不好就发上一版"）。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 仅边际变缓但总量仍在上升：那是收益递减，建议优化而非撤退。（书中明示：负收益是"从收益递减变成"的下一阶段）
- 短期冲刺且明确知道代价（发版前一周加班）：这是有意识的取舍，不属于被模型蒙蔽的误判。（推导，非书中明示）
- 用户要的是"怎么提效"而非"该不该停"：应改用时间管理或流程类工具。（推导，非书中明示）

### 容易误用的地方

- 把"不舒服"当成"负收益"。刻意练习本来就不舒服，但产出仍在上升，此时退出会损失长期复利。（推导，非书中明示）
- 用负收益给"不想努力了"背书。判据必须是**客观的产出/健康下降**，不能是主观意愿下降。（推导，非书中明示）
- 书中未提反例，但明确强调应在**进入**负收益之前退出——等到崩溃再撤，代价已经付过了。（书中明示）

### 容易混淆的邻近模型

- 与收益递减法则：一个是"涨得慢"，一个是"开始跌"。两者是同一条曲线的相邻两段，临界点就是区分点。
- 与沉没成本谬误：沉没成本解释"为什么人会继续加码"，负收益描述"继续加码的客观后果"。常同时出现。
