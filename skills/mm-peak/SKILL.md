# 峰值（peak）

## R — 原文 (Reading)

> 另一个思维模型描述了事物流行程度开始滑坡的那个点。这个模型就是“峰值”（peak），例如“性别歧视峰值”或“脸书网峰值”。

> — 《思维模型》, 第4章 > 别跟自然对着干

---

## I — 方法论骨架 (Interpretation)

峰值是事物**流行程度或产出达到最高点、此后开始滑坡**的那个转折点。它的用法很有特点：书里把它当成一个可加前缀的构词框架——"性别歧视峰值""脸书网峰值""石油峰值"——意思是"从此以后，X 只会比现在少"。

越过峰值后，下降速度可能极慢，但**趋势必然反转**。这是本模型最关键的承诺：不是说会暴跌，而是说方向变了。

它与林迪效应互补：林迪效应说明**能活多久**（已经存在越久的东西，预期剩余寿命越长），峰值说明**何时开始下滑**。一个是寿命问题，一个是转折点问题——两者回答的是不同问题，不能互换。

但作者给出了一个非常重要的警告：**峰值预测极易出错。** 书中的"石油峰值"例子就是反例：1919 年美国地质调查局的戴维·怀特预测美国石油产量峰值"很可能在未来三年内"过去，但至今未出现。原因是**需求剧增催生了地下开采新技术**（页岩油、水力压裂），年产量持续上升——**供给曲线会因为价格信号与技术进步而移动，历史产量曲线并不包含这个信息**。

所以关键判据是：**不要只看历史产量/流行度曲线，要看底层结构性变化**。作者列举的真正该看的东西是：气候变化、太阳能兴起、电动车成本竞争力、自动驾驶与拼车——这些是会让需求与供给同时改变的力量，而不是曲线外推。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断某个平台/产品/行业的用户增长是否已过顶点，该不该调整投入。
2. 讨论"XX 是不是已经过了最好的时候"（房价、某个技术栈、某类职业）。
3. 看到"石油峰值""煤炭峰值""人口峰值"这类预测，需要判断其可信度。
4. 制定长期战略时，需要为"趋势反转"而不是"线性外推"做准备。
5. 想表达"这件事以后只会更少"的判断，需要一个精确的说法。

### 语言信号

- "XX 是不是已经到顶了"
- "用户增长见顶了，下一步怎么办"
- "这个行业是不是在走下坡路"
- "现在是不是最好的时候了"
- "都说要见顶了，可信吗"
- "peak oil / peak Facebook / has X peaked / past its prime"

### 与相邻 skill 的区分

- 与 `mm-lindy-effect` 的区别: 林迪效应回答**还能活多久**（存在越久，预期剩余寿命越长），峰值回答**何时开始下滑**。一个说寿命，一个说拐点——对同一事物可以给出相反的建议，必须分开问。
- 与 `mm-s-curves` 的区别: S 形曲线描述**增长—饱和—放缓的完整形状**（顶部是平台期，不一定下降），峰值只标记**开始下滑的那一点**。S 曲线顶部之后可能长期平台，峰值意味着掉头。
- 与 `mm-inflection-point` 的区别: 拐点是**曲率变化的通用点**（可向上可向下），峰值专指**由升转降的那一个特定拐点**。

## E — 可执行步骤 (Execution)

1. **明确"峰值"的对象与度量口径**
   - 说清到底什么在见顶：产量、用户数、流行度、市场份额？
   - 完成标准: 有一个可观测的单一指标，而不是笼统的"不行了"。
2. **先做历史曲线外推，并把它当作零假设**
   - 画出历史趋势，看外推结果。
   - 完成标准: 得到一条基线预测。
   - 判停条件: 明确标注这只是零假设，不能作为结论。
3. **列出会移动供给曲线的力量**
   - 用石油峰值的教训：需求上升会催生开采新技术，供给曲线会移动，历史曲线不含这个信息。
   - 完成标准: 至少列出 3 项可能让"产量/供给"上升的技术或价格驱动因素。
4. **列出会改变需求的结构性变化**
   - 按作者的示范，关注真正的结构性力量：气候变化、太阳能兴起、电动车成本竞争力、自动驾驶与拼车。
   - 完成标准: 至少列出 3 项结构性需求侧变化，并说明各自的方向与量级。
5. **给出区间判断而非单点峰值年份**
   - 书中明确指出峰值预测极易出错，因此输出"在什么条件下会见顶"的条件式判断，而不是"某年见顶"。
   - 完成标准: 结论形如"若 X 不发生，5-10 年内见顶；若 X 发生，峰值将被推迟"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 判断某事物能存活多久：那是林迪效应，峰值不回答寿命问题。（推导，非书中明示）
- 短期波动的择时（这只股票这个月见顶了吗）：峰值是长期结构性概念，用于短期交易属于误用。（推导，非书中明示）
- 用历史曲线做简单外推就下结论：书中石油峰值的例子正是这种错误的经典案例。（书中明示）

### 容易误用的地方

- 把"增速放缓"当成"已经见顶"。增速放缓可能只是进入平台期（S 曲线顶部），未必掉头向下。（推导，非书中明示）
- 忽略供给/技术对峰值位置的移动。石油峰值被反复证伪的原因就是新技术被需求激发出来。（书中明示）
- 以为越过峰值就会快速下跌。书中明确指出下降速度可能极慢。（书中明示）
- 把"希望它见顶"当判断依据。对不喜欢的事物（性别歧视）人们会过早宣布已过峰值。（推导，非书中明示）

### 容易混淆的邻近模型

- 与林迪效应：一个是"还能活多久"，一个是"何时开始下滑"。二者常被混用，但结论可以完全相反。
- 与 S 形曲线：S 曲线顶部是平台，峰值是掉头；平台期可能持续很久，误判为峰值会导致过早撤退。
