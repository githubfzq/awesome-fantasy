# 终局（endgame）

## R — 原文 (Reading)

> 在国际象棋中，当大部分棋子被吃掉并移出棋盘后，你就进入了所谓的"终局"（endgame）阶段。"终局"也被引申为指某个事件过程的最终阶段。
>
> — 《思维模型》, 第7章 > 终局

---

## I — 方法论骨架 (Interpretation)

国际象棋把一局棋分成开局、中局、终局三个阶段，因为**棋盘上剩下的东西变了，最优打法就变了**。中局棋子多、可能性多，值得为位置和主动权投入；终局棋子少、变量少，剩下的不是"争取优势"而是"把已有的优势兑现成胜势，或把劣势收敛成和棋"。

推广到一般情境：任何持续性的冲突或项目都有阶段，而**阶段变了，评价指标必须跟着变**。

- 中局的评价指标是**位置**：我有没有更多选择、更强的势、更大的回旋余地。
- 终局的评价指标是**兑现**：我能不能把位置变成确定的结果。

为什么这个切换重要？因为中局的打法在终局是有害的。中局鼓励保留可能性（preserving optionality）、鼓励试探、鼓励为长期布局牺牲短期收益；终局里这些动作的价值归零——剩余变量太少了，回旋的空间已经不在，此时继续"保留可能性"就变成了"拖延兑现"。

关键判据是：**剩余的可变因素还有多少？** 当主要变量已定、剩下的只是执行与收尾时，你就已在终局。此时正确的动作是锁定收益（把优势转成可交付、可签、可验收的结果）或最小化损失（把劣势的尾巴剪短）。

作者把这一章与退出策略、过河拆桥、孤注一掷等放在一起，正说明终局的核心议题是：**怎么收场。**

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 项目已投入大半、接近交付，团队仍在不断改需求、加功能、优化架构。
2. 谈判/招聘/融资进入最后一两轮，用户在犹豫要不要再争取更多条件。
3. 一段长期竞争（市场份额之争、内部晋升之争）快要见分晓。
4. 长期项目已明显不会成功，用户在"再撑一下"和"现在收手"之间摇摆。
5. 用户描述一件拖了很久的事，问"现在该怎么收场"。

### 语言信号 (用户的话里出现这些就应激活)

- "都到这一步了，怎么收尾"
- "大局已定，接下来该做什么"
- "已经没什么可变数了"
- "该落袋为安了吧"
- "最后这段该怎么打"
- "we're in the endgame / how do we close this out / closing stages"

### 与相邻 skill 的区分

- 与 `mm-exit-strategy` 的区别: 退出策略解决的是"要不要走、怎么走"的**方案设计**；终局是**阶段判定**——先确认你已处于最终阶段，再决定是锁定还是退出。用户问"我该不该撤"用退出策略，问"现在这个阶段该怎么打"用终局。
- 与 `mm-hail-mary-pass` 的区别: 孤注一掷是终局中的一种**具体手段**（最后一搏）；终局是阶段框架，手段可以是锁定收益，也可以是最后一搏。
- 与 `mm-preserving-optionality` 的区别: 保留可能性是中局的核心价值；进入终局后它的价值大幅下降，继续保留往往等于不敢兑现。二者常构成张力。
- 与 `mm-two-front-wars` 的区别: 两线作战讲的是同时应对多个战场的负担问题，与阶段无关。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定是否真的进入终局**
   - 完成标准: 列出剩余的主要可变因素（人、钱、时间、外部条件），若已不足 3 项且都不可由你显著改变，判定为终局。
   - 判停条件: 若仍有可主动改变的关键变量，说明还在中局，不激活本 skill，回到中局打法（争取位置、保留选项）。
2. **重设评价指标**
   - 完成标准: 明确写出终局目标只有两类之一——**锁定收益**或**最小化损失**，并把它替换掉原来的"争取更好位置"类指标。两者要挑一个，不能都要。
3. **清点剩余筹码**
   - 完成标准: 列出此刻手上仍可动用的资源（已获得的成果、关系、信誉、时间、现金），作为兑现或止损的本钱。
4. **设计收官动作**
   - 完成标准: 若选锁定：给出把成果转为确定结果的具体动作（签、验收、交付、公告、回款），并明确何时宣布结束。若选止损：给出剪短尾巴的动作清单与停止时点。
5. **剪掉不再产生价值的动作**
   - 完成标准: 列出当前仍在继续但已无法改变终局结果的活动（继续优化、继续说服已决定的人、继续试探），明确停止它们。
6. **定结束条件与复盘点**
   - 完成标准: 写下"达到 X 即为结束"的客观条件，以及结束后的复盘安排。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 事情仍在早期、选项还在快速增加——此时谈终局会过早放弃布局。
- 用户其实在问"该不该退出"，而不是"这个阶段怎么打"——优先用退出策略。
- 局面出现重大外部变化、阶段被重新打开（新竞争者入场、需求重置）——此时应重新判定阶段，不要沿用终局打法。
- 一段需要长期经营的关系（亲子、婚姻、长期合伙）不适用"锁定收益后宣布结束"的框架。

### 容易误用的地方

- 书中未提边界；以下为基于机制推导的警告（推导, 非书中明示）。
- 误判阶段是最常见的失败：在中局用终局打法（过早收敛、放弃布局），或在终局用中局打法（还在铺摊子、继续保留选项而不兑现）。
- 终局的"最小化损失"容易被拖延——因为承认损失的心理成本高于继续投入的账面成本，这与沉没成本谬误叠加。
- 把"结束"等同于"放弃"：终局锁定收益其实是把已获得的成果确定下来，是兑现而非撤退。

### 容易混淆的邻近模型

- **退出策略（exit strategy）**: 与终局高度相关但侧重不同——退出策略是方案，终局是阶段。
- **孤注一掷（Hail Mary pass）**: 终局中可能采用的一种高风险手段。
