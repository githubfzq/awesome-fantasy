# P值（p-value）

## R — 原文 (Reading)

> 衡量结果是否具有统计显著性的最终标准是P值（p-value，也称"假设概率"）。它的正式定义是：假设原假设是真的，得出等于或大于观测结果的概率。
>
> — 《思维模型》, 第5章 > 是对还是错

---

## I — 方法论骨架 (Interpretation)

P 值回答的问题很窄：**如果原假设为真（根本没有效应），观测到这么大甚至更大的差异，概率是多少？** 例如 P=0.01 意味着：若这款助眠应用完全无效，观测到如此大差异的概率只有 1%。P 值小于设定的假阳性率（通常 5%），就称结果"具有统计显著性"。

它的本质是"在原假设下数据有多极端"的度量，**不是"原假设有多可能为真"的度量**，也不是"效应有多大"的度量。这两点混淆是它最著名的危害。

作者点明了三条局限：未找出显著结果不等于确信不存在效应；P 值小也不意味着结果可重复；不应只按阈值下结论，而应更多关注测出的差异与置信区间。

---

## A1 — 书中的应用 (Past Application)

### 案例: 助眠应用研究中的 P=0.01

- **问题**: 实验观测到使用组与对照组之间存在差异，需要判断这个差异能否否定"应用无效"的原假设。
- **方法论的使用**: 作者把观测差异放在原假设（以 0 为中心）的钟形曲线上看其位置——P=0.01 对应图中左侧钟形曲线最末端、接近右侧曲线的中间值。
- **结论**: 观测结果更符合"两组差异 15%"的对立假设，而非原假设，因此可以否定原假设。作者随即给出三条警告：没有显著结果不等于确信无效应；P 值小不代表可重复；应更关注测出的差异与置信区间，而不是只盯阈值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到 p 值要对外宣称"结果显著/结论成立"。
2. 有人把 "p=0.03" 说成"只有 3% 的可能这个结论是错的"。
3. 实验不显著，用户想直接写"证明两者无差别"。
4. 讨论要不要把显著性阈值从 0.05 收紧。

### 语言信号 (用户的话里出现这些就应激活)

- "p<0.05，所以结论成立了"
- "p 值是原假设不成立的概率吧"
- "没做出显著性，就说明两者没差别"
- "p 值越小效果越强吧"
- "Is p = 0.04 good enough?"

### 与相邻 skill 的区分

- 与 `mm-null-hypothesis` 的区别: 原假设是**被检验的命题**；P 值是**在该命题下数据极端程度的度量**。
- 与 `mm-confidence-interval` 的区别: 置信区间直接给出效应量的可能范围，作者明确建议**更多关注测出的差异与置信区间**，而不是只按阈值下结论。

---

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **复述 P 值的准确定义**
   - 完成标准: 用"假设原假设为真，得出等于或大于观测结果的概率"这句话解释当前 p 值，纠正若存在的方向性误读。
2. **与显著性阈值比较并判定**
   - 完成标准: 明确说出"是否越过设定的假阳性率（通常 5%）"。
   - 判停条件: 若不显著，直接跳到步骤 4，禁止表述为"证明无效应"。
3. **同时报出效应量与置信区间**
   - 完成标准: 给出实际观测到的差异大小及其区间，因为作者建议更关注这些而非阈值。
4. **标注可重复性限制**
   - 完成标准: 明确写出"P 值小不意味着结果可重复"，并提示若做了多重检验还需考虑数据捕捞问题。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只做描述性统计、不做假设检验时，P 值无从谈起。
- 用户已改用效应量 + 置信区间（或贝叶斯口径）做判断时，不必再把讨论拉回阈值。

### 书中警告的失败模式 / 容易误用的地方

- **未能找出显著结果不等于确信不存在效应**——"没有证据证明存在"不等于"有证据证明不存在"。
- **P 值小也不意味着结果可重复。**
- **不应只按阈值下结论**，而应更多关注测出的差异与置信区间。
- （推导，非书中明示）P 值对样本量极敏感：样本足够大时，任何微小效应都能显著；样本小时，真实的大效应也可能不显著。

### 容易混淆的邻近模型

- 统计显著性（statistical-significance）：P 值越过阈值后的标签，本身不是效应量。
- 数据捕捞（data-dredging）：通过多次检验人为制造小 P 值的做法。
