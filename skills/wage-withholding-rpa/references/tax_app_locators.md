# 扣缴端 UI 定位器记录（tax_app_locators）

本文件记录「自然人电子税务局（扣缴端）」各步骤所用 UIA 控件定位信息。
**首次上线前必须用 `python wage_rpa.py --discover "<窗口标题>"` 抓取 UIA 树，并把下面的 `?` 补全。**
`wage_rpa.py` 当前用「控件可见文本（name）」直接匹配，多数按钮无需改；标注 `?` 的是需要确认/可能需回退图像匹配的点。

## 应用启动
- 可执行路径（示例，按实际安装填写到 `RPA_TAX_APP` 或 locators）：`C:\Program Files (x86)\自然人电子税务局扣缴端\EEnterprise.exe`
- 窗口标题（title_re）：`自然人电子税务局`
- 主界面关键字：`综合所得申报`

## 图像匹配回退（可选）
当某控件 UIA 拿不到时，截取该按钮 PNG 存入 VM（如 `C:\rpa\tpl\xxx.png`），
用 `rpa.py locate --image C:\rpa\tpl\xxx.png --confidence 0.9` 取中心点，
再 `mouse_click --x --y`。模板图需随分辨率/主题一致。
