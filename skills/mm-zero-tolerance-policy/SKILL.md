# 零容忍政策（zero-tolerance policy）

## R — 原文 (Reading)

> 即使很小的违规行为也会招致严厉惩罚。
>
> — 《思维模型》, 第7章 > 改变战局

---

## I — 方法论骨架 (Interpretation)

普通处罚是**分级**的：先警告、再轻罚、屡犯才重罚。零容忍砍掉了这个梯度——无论情节轻重，只要触线就是顶格后果。书里举的是"零容忍毒品政策"：初犯即解雇或开除学籍。

它的机制是**用确定性换掉严厉性的犹豫**。分级处罚给了对方一个可计算的试探空间：第一次反正只是警告，那就试一次。零容忍把这个空间压缩到零，让"试一下"这个选项从收益矩阵里直接消失——这也是它被视为画红线的极端形式的原因。

但代价同样确定：

1. **你失去了裁量权**，也就失去了区分"恶意再犯"和"无知初犯"的能力，误伤不可避免。
2. **执行成本被前置**——一旦有人真的初犯，你必须立刻顶格执行，没有缓冲。
3. **它会被检验**——对方可能故意叫你摊牌（call your bluff），看你是不是真的下得了手。

关键判据是：**你是否愿意且能够在第一个初犯者身上就顶格执行？** 如果那个人是你最喜欢的员工、最优质的客户，你还能执行吗？能，政策才是真的；不能，就别立这条政策。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 制定公司制度：作弊、贪腐、数据泄露、骚扰等行为是否"发现即开除"。
2. 平台/社区治理：刷单、引战、抄袭是否"一次即永久封禁"。
3. 育儿或班级管理：某类行为（说谎、霸凌、玩手机）要不要"零容忍"。
4. 用户正在气头上，说"以后再有人迟到一律罚款"，需要判断这是政策还是情绪。
5. 已有零容忍政策但执行不下去，用户在想要不要放宽或取消。

### 语言信号 (用户的话里出现这些就应激活)

- "这种事必须零容忍"
- "发现一次就开除 / 直接封号"
- "不给第二次机会"
- "规矩就是规矩，没什么好商量的"
- "不管什么原因，一律顶格处理"
- "zero tolerance / no second chances / one strike and you're out"

### 与相邻 skill 的区分

- 与 `mm-red-line` 的区别: 红线是**一条具体界线 + 一个特定后果**，可以有梯度；零容忍是**取消梯度本身**，初犯即顶格。用户问"要不要给一次机会"，是二者的分界。
- 与 `mm-deterrence` 的区别: 威慑讲效力主要来自被抓到的确定性；零容忍是通过"确定性的严厉"来提高威慑，但**不解决发现率问题**——抓不到的话，顶格处罚毫无意义。
- 与 `mm-broken-windows-theory` 的区别: 破窗理论主张及时处置小的失序以防恶化，但仍可分级处理；零容忍则是无论大小一律顶格。
- 与 `mm-call-your-bluff` 的区别: 叫你摊牌是零容忍最可能遭遇的检验动作。用户说"有人故意犯一次看我敢不敢"，应切到叫你摊牌。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定被禁止的行为**
   - 完成标准: 写出一个客观可判定的行为定义，剔除"态度不好"这类需主观解释的项。
   - 判停条件: 若行为无法客观判定，立即停止——不可判定的行为配上不可撤销的重罚，只会制造任意执法。
2. **确认发现率（Detection Rate）**
   - 完成标准: 估算该类行为当前被发现的比率。若低于约 50%，先解决发现机制（留痕、抽查、举报通道），再谈处罚力度。
3. **算误伤成本**
   - 完成标准: 列出 2-3 个"非恶意但会触线"的真实情形（新人不懂规矩、系统误判、被陷害），并给出每种情形下的处置方案。若无法给出可接受方案，说明不该零容忍。
4. **做"第一个人"测试**
   - 完成标准: 明确回答"如果第一个触线者是最得力的员工/最重要的客户，我是否仍顶格执行？"答否则改设计——缩小适用范围或留出申诉通道。
5. **补上程序正义**
   - 完成标准: 政策文本包含三件事：行为定义、统一的执行流程、申诉与复核渠道。三者缺一，政策在第一次真执行时就会崩。
6. **预演兑现并设复核点**
   - 完成标准: 写下执行动作与责任人，并约定 1-3 个月后复核一次：违规率是否下降、有无明显误伤、执行是否被打了折扣。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 违规行为后果轻微且可逆（迟到、忘填表）——顶格处罚的代价远超问题本身。
- 该行为很大程度上由能力不足或流程缺陷造成——应改流程、加校验、做培训，重罚治不了不会做。
- 发现率低到形同虚设——此时零容忍只是纸面威慑，且一旦偶然执行会被视为任意执法，反噬信任。
- 需要保留专业裁量（医疗、安全、法务判断）——一刀切会逼出隐瞒与谎报。

### 容易误用的地方

- 书中明示：问题是对方可能叫你摊牌——若你不兑现，信誉受损、威慑失效；因此你必须准备好把威胁付诸实践。
- 书中案例提示：零容忍毒品政策会因初犯就解雇或开除学籍——这说明它的后果是**不可逆**的，一旦误判无法挽回。
- （推导, 非书中明示）零容忍容易催生**隐瞒文化**：既然没有改正机会，当事人会全力遮盖而非上报，小问题因此变成大问题。
- （推导, 非书中明示）把零容忍当态度宣示而非可执行制度——宣布时很强硬、执行时层层例外，最终比没有政策更损害公信力。

### 容易混淆的邻近模型

- **红线（red line）**: 更通用的"界线 + 后果"工具，可以分级；零容忍取消了分级。
- **破窗理论（broken windows theory）**: 强调对小失序的**及时**处置，未必顶格。
