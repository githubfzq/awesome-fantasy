## exit 74 时间线（已解决 ✅）

- start #1: "Developer App Certificate is not trusted" → 用户信任后通过

- start #4 卡 14 分钟 → 日志发现 "Unlock 范祖权的iPhone to Continue"（手机锁屏）

- 排除项：profile 过期/设备未注册/bundle ID 不匹配/锁屏/未信任

## 有用命令

```sh
# 设备状态（paired ≠ USB connected）
xcrun devicectl list devices

# 手机上的 WDA 服务直接探测
curl -s http://127.0.0.1:18100/status

# 找占用端口的 forward 进程
lsof -iTCP:18100 -sTCP:LISTEN
pgrep -fl forward.mjs

# profile 有效期检查
P=$(ls ~/Library/Developer/Xcode/UserData/Provisioning\ Profiles/ | head -1)
security cms -D -i ".../Provisioning Profiles/$P" | plutil -p - | grep -E "Expiration|TeamID"

# 设备侧日志（排 exit 74 类问题）
brew install libimobiledevice
idevicesyslog > /tmp/syslog.txt   # 后台跑，触发 start 后 grep
```
