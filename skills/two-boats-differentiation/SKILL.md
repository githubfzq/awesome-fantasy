# 两条船：粘连与自我区分

## R — 原文 (Reading)

> "粘连是两人之间人为的结合，其基础是对归属感和重要性的互相需求。"

> — 克里斯多福·孟，第七章 从粘连中解放

> "自我区分是当个人留在自己船上的同时，仍然与伴侣分享共同旅程的过程。"

> — 克里斯多福·孟，第七章 从粘连中解放 · 自我区分

> "当伴侣选择跟随自己的偏好时，你会真正地支持对方，哪怕这意味着他们会离开你单独航行……而且无论离开多久，你都支持。"

> — 克里斯多福·孟，第七章 从粘连中解放

> "折中给人带来的唯一满足就是知道对方和自己输得一样多。"

> — 克里斯多福·孟，第七章 从粘连中解放

## I — 方法论骨架 (Interpretation)

这个 skill 只处理一件事：**在这段关系里，我有没有为了不失去对方而压着自己。** 它不评价你们亲密不亲密、也不劝你靠近或拉开。

**一、作者重新标记了一个词。** 我们通常称之为"亲密""承诺""我们是一体的"的东西，作者叫它**粘连**——两人之间人为的结合，基础是**对归属感和重要性的互相需求**。一旦对方成为我重要性的唯一供给源，我就必须监控他的言行以保证供给不断：他能去哪、能做什么、得让我觉得特殊。自发性意味着失控，失控意味着供给风险，于是关系里所有的自发、创造和惊喜被磨平，接着憎恶、挫折、"老一套"的无聊感降临——而这些感觉越强，彼此的特殊感反而越薄。**这是"激情为什么会消退"的一个非典型解释：不是不爱了，是粘连的反噬。**

**二、判据是压抑，不是距离（本 skill 的核心，V2 推导）。** 书中把粘连默认为需要解决的问题，但没有区分物理距离与心理粘连。因此：**同住一个屋檐下，但我不敢说出真实偏好 = 仍是粘连；两地分居、各自有事业，但我不压抑 = 已经是两条船。** 反过来，"我们几乎不见面但我觉得空虚"不是本 skill 的问题；"我们天天在一起但我从不敢提我想去哪里"才是。

**三、分歧的四个选项，不是两个。** 常识只给两个：谈成共识，或折中。作者说这两条都有问题——双赢共识耗时极长且**一般根本达不成**；折中的唯一满足是"知道对方和我输得一样多"，它把船带向"没有一方真正想去的地方，或哪里都去不了"。所以要分清三件事：
- **一致**＝愿意敞开考虑对方的观点并共同制订行动计划，它产生顺流。**快乐不依赖于一致**——不一致的价值是当**信号**用，它帮你觉察此刻自己是否体验到快乐。
- **共识**＝所有当事人就如何共处做出决定。社会默认"共识 = 健康、分歧 = 不和谐"，作者明确否认共识对关系是至关重要的：**你如何处理分歧，基本上决定了你整个人生的方向。**
- **折中**＝双方输得一样多。
- **第四条路：两条船**。共识不可达、折中会双输时，每人跟随自己的偏好。偏好反映你的本质天性，它带你去的方向未必与对方相同，"这未必意味着关系就此结束"，未来某个时点会再相会——"他们从来没有真正分开过"。

**四、最锋利的自测：他去做自己的事，我支持吗？** 当伴侣选择跟随自己的偏好时，我能不能真正支持他，**哪怕这意味着他会离开我单独航行、无论离开多久**？能 → 自我区分；不能，且涌上来的是"我不再必不可少""我会失去特殊地位""我就是单独一人了" → 粘连。配套的一条次级判据：**关心**伴侣的感受，和**时刻惦记**着伴侣的感受，是两回事——后者导致怜悯，再陷入拯救者强迫症；无法自拔地想着伴侣，是在**同时自找苦吃和逃避痛苦**（你很难受，但太沉浸在故事里，就认不出自己的不快乐了）。

**五、行为层的落地：管好你自己的事。** 你有一家店，隔壁还有一家，你总跑到隔壁看人家怎么管理，照看自己生意的时间就只剩百分之五十。三格划分见 E 段第 5 步。

**六、两条船 ≠ 疏远，也不等于"各过各的"。** 作者的原话是"**单独一个人，但没有断联**"；自我区分是"留在自己船上的**同时**，仍然与伴侣分享共同旅程"，偏好相同时陪伴彼此。

## A1 — 书中的应用 (Past Application)

### 案例 1：一艘船政策——1969 届与 1972 届的高中毕业纪念册（第七章，作者）
- **问题**：多数文化把婚姻看成两人共乘一条船，而船常常是男人的：女人抛下家人朋友、改姓、协助男人完成他的梦想和目标——"她离开自己的船，登上了男人的船，承认男人是船长"。
- **方法**：作者翻看哥哥肯（1969 届）与自己（1972 届）的毕业纪念册，比较"你这辈子想做些什么"这一栏的答案分布。
- **结论**：相隔三年，女性的选项从"妻子和母亲／秘书／空姐"扩展到生物化学家、工程师、建筑师、医生，"甚至有些女孩子公然声称：如果她们结了婚，她们要保留自己的姓"。但作者指出：即便有这些变化，**人们仍然普遍认为婚姻就是两人共乘一条船**——自由增加了，掌舵却变难了，于是社会鼓励双方努力达成完全共识，行不通就折中。
- **结果**：这个"一艘船政策"是全书对粘连的结构性解释：**问题不在谁掌舵，而在只有一条船。** 作者同时标注了自己的性别视角局限——情绪劳动的结构性分配未被处理。

### 案例 2：狂热追求共识，一头撞到自己的墙（第七章，作者自曝失败）
- **问题**：在"两条船"这个想法出现前，作者"坚定地、近乎狂热地"相信所有冲突必须通过共识解决、让双方完全满意；并且相信只要自己先放下立场朝中心走，就会看到妻子迈出同样的一步。
- **方法**：以自身婚姻做长期自然实验——连对方如何开车、去超市走哪条路线这种小事都没法一致，所以练习机会充分。
- **结论**："真正实现百分之百双赢结局的，只有屈指可数的几次。"诊断是——"我虽然有狂热的动力，想要实现完全共识，但往往是一头撞到了自己的墙上——那堵防卫和不安全感的墙壁！"根因："我更在意的是让自己是对的，而不是达成真正的共识。"
- **结果**：两条船这个选项就是从这次失败里长出来的。同时给出了唯一的例外领域：**孩子**。育儿是他们婚姻中最和谐的方面，真正原因在于**他们把意见一致作为共同的优先选项**——不是因为议题本身不冲突，而是因为一致被设成了优先项。

### 案例 3：管好你自己的店（第七章，虚拟读者的追问）
- **问题**：读者问："除了走过程外，自己还想做点什么，或练习些什么，好加把油。"又追问："如果我的爱人为某事难过，这就是我的事，不是吗？"
- **方法**：作者只答一句"管好你自己的事"，再用相邻两家店的比喻给出效率论证，然后做精确切分：**伴侣怎么做、怎么感受＝伴侣的事；我对伴侣的感受和反应＝我的事；伴侣在我面前显现出什么样子＝我的事（因为反映了我的内在体验）。** 针对"这听起来好自私"的反驳，作者澄清：不是说伴侣受伤或身处困境时你不去安慰，而是**"不要为了让你自己好受些去安慰伴侣"**，先照料你的内疚感；你的过程是你的事，关心并支持伴侣是你的事，伴侣的感受是他自己的事。
- **结论**：判据只有一句——**我做这件事，是为了让谁好受？** 为了让我自己好受 → 我在管别人的事。
- **结果**：这条是两条船在行为层的配套，用来防止"各走各的"被用成冷漠。反向适用同样成立：伴侣想来管我的事时——"你伴侣做什么是你伴侣的事，你对伴侣如何反应是你自己的事"。

> 附（第七章类型学材料，见 E 段第 2 步）：造成分歧的六大关键领域、处理分歧的七种状态自检，以及作者在咨询记忆中反复遇到的四类僵局（性频率不匹配转向色情或外遇／一方持家花钱、另一方偷偷高风险投资亏光／体罚 vs 放任的管教冲突／婆婆搬进来掌管家务、或沉迷工作让另一方觉得被遗弃），结局通常是离婚、分居，或作者所称的"婚内离婚"。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. 有一个自己真正想去的方向（城市、工作、学习、生活方式），但因为怕伴侣不高兴而一直没提。
2. 在一件具体的事上永远谈不拢，反复在"说服他"和"算了听他的"之间来回，需要一个第三方选项。
3. 一想到伴侣去做自己的事（独自旅行、见朋友、投入爱好）就慌，或者反过来：用"你去吧我没事"压着真实的不快。
4. 把"我们是一体的""夫妻就该同心"当成否决自己单独决定的理由。
5. 明知道自己在争对错，但停不下来；争完只剩短暂的满足和一股奇怪的内疚。
6. 一天里大量时间在推测伴侣的状态、预演对话、复盘争执，并把它自我认证为"我很在乎这段关系"。

### 语言信号（用户的话里出现这些就应激活）

- "我不敢说真实想法，怕他不高兴／怕他生气"
- "为了他我放弃了自己的方向／我早就放下那个打算了"
- "我们永远达不成共识／每次都是我让步"
- "他去做自己的事我就慌／我会有种被抛下的感觉"
- "我付出了这么多，他却说我不够支持他"
- "我们是一体的，我怎么能只考虑自己"
- "我脑子里全是他的事，他难不难过、他怎么想我"
- 英文：*I lost myself in the relationship* / *I can't be myself around him* / *we can never agree* / *I gave up my own plans for him* / *I'm afraid he'll leave if I say what I want* / *I feel abandoned when he does his own thing*

### 与相邻 skill 的区分（★防撞车关键）

- **与 `family-loyalty-attachment`（第 1 册，★最高危同源）**：两者同源——第 1 册的**依附情结**（为避免被离弃而把自己塑造成对方会喜欢的样子，牺牲真我）与本册的**粘连**（基于归属感与重要性需求的互相结合）是同一机制的两种表述。**划界按「来源」与「对象」两条轴切：**
  - `family-loyalty-attachment` 管**原生家庭模式的重演与死忠**——对象是我从小学会的规矩、父母的期待、家族的复制（含反向复制）。
  - 本 skill 管**当下这段关系里的粘连与自我区分**——对象是我此刻在这个伴侣面前有没有压抑、有没有为留住他而放弃自己的方向。
  - **分辨句（直接用）**：用户说"我变成了我妈那样／我发誓绝不跟他爸一样／我在重复他们的模式／我不知道自己真正想要什么" → `family-loyalty-attachment`；用户说"我不敢跟他提我想搬去的那个城市／我一提自己的打算他就说我自私／我们在这个事上永远谈不拢" → 本 skill。
  - **一句定位问**：这个"不敢"，指向的是**我从小学会的规矩**，还是**此刻这个伴侣的反应**？前者 → 那个；后者 → 本 skill。
  - **双向交接**：本 skill 第 1 步若发现压抑的内容可追溯到"我从小就这样""我妈也是这样" → 转 `family-loyalty-attachment` 做完模式识别，再回来做当下关系里的偏好表达；反过来，那个 skill 处理中发现用户的痛点是"我此刻正在为留住伴侣而压着自己" → 转本 skill。
  - **收窄声明**：为避免重合，本 skill 的触发面收窄为「**当下关系 + 具体的分歧或被放弃的方向 + 压抑**」。纯"我不知道自己想要什么""我一直在讨好""我和他暗中较劲"这一类自我描述，默认归 `family-loyalty-attachment`，本 skill 不抢。

- **与 `sacrifice-indulgence-pendulum`（第 1 册）**：那个的判据是「**有没有喜悦** + **能不能接受感谢**」，对象是**具体的付出-回报失衡事项**（家务、育儿、让步、感谢）。本 skill 的判据是「**有没有压抑**」，对象是**关系中的自我边界与人生方向**（我的偏好、我敢不敢说、我支持不支持他去）。分辨句："我每天做饭接孩子，他连句谢谢都没有" → 那个；"我放弃了那个外派机会，而且从没敢跟他提我其实想去" → 本 skill。**交接**：本 skill 判为"压抑 = 是"，且压抑的内容是一笔具体的付出-回报账 → 转那个；那个判为失衡，但用户真正的痛是"我连自己想要什么都不知道了" → 转本 skill（或先转 `family-loyalty-attachment`）。

- **与 `polarity-quadrant-mapping`（本册，并行构造）**：那个是**定位工具**——用"我对伴侣的看法"反推我在依赖/独立象限里的**位置**（第六章极性模型）。本 skill 是**行动层**——给定一个具体的分歧，在一致/共识/折中/两条船之间做**选择**，判据是压抑。分辨句："我在这段关系里到底是依赖型还是独立型""我怎么老是遇到这种人" → 那个；"我们在这个事上永远谈不拢，我该让步还是各走各的" → 本 skill。**注意两者的交集**：都涉及独立/依赖，但象限描述**你在哪**，本 skill 给出**你怎么做**。用户问"我是哪一种" → 那个；"我该怎么办" → 本 skill。

- **与 `quantum-tunnel-surrender`（第 1 册）**：那个是**决策层的跃迁**——两个都不想要的左右为难，直接想象"如果现在已经在爱中我会怎么做"然后照做。本 skill **不涉及去留决策**。分辨句："我该走还是该留" → 那个；"我先弄清楚我在这段关系里压着什么" → 本 skill。**硬约束**：本 skill 不得把"各有一艘船"输出成分手的暗示；若用户把两条船读成"那就分开吧"，立即澄清——作者明说"单独一个人，但没有断联"，且破除粘连不必离开关系。

- **与 `process-walk`（本册）**：本 skill 第 6–7 步出现的不适感交给它。但**"走过程"不是技巧、不是疗愈、不是步骤**——作者三次专门否认，写成"7 步练习清单"就把它降级成了它要取代的东西。本 skill 只在用户说不出偏好、或对"他去走自己的路"起反应时路由过去，不做流程拆解。

## E — 可执行步骤 (Execution)

> **第 0 步：安全拦截（不可跳过，先于一切判别）**
> 命中以下任一条，**立即停止本 skill 的全部向内工作**，转向安全评估与资源连接：
> 1. 关系中存在**身体暴力、威胁、破坏物品或阻挡去路**；2. 存在**监控、社交隔离、经济控制、限制人身自由**；3. 存在针对**儿童、老人或其他无议价能力第三方**的伤害（**含体罚分歧**）；4. 存在**成瘾、长期欺骗、财务隐瞒**（**含外遇**）；5. 用户正在用"这是我设计的功课""他在帮我成长""这是你的梦"来解释**正在发生的伤害**；6. 用户出现**闪回、解离、惊恐发作、自杀意念**，或因使用本方法**中断了正在进行的专业治疗**；7. 用户报告"**各走各的之后我更该留下了**"。
> **完成标准**：七条逐条过完，得到明确的是/否。**若任一命中，不再执行以下步骤。**
> **本单元的特有拦截**：第 2 条与第 3 条在本 skill 中命中率最高——"各有一艘船""管好你自己的事"在控制关系里会被读成不干预许可，在儿童安全议题上会取消保护责任（见 B 段）。

### 第 1 步：压抑检测（本 skill 的核心判据）★
- 只问三句，逐句要明确的是/否：
  1. **"在这段关系里，有没有一个你真正想要的、但从没说出口的东西？"**（方向、偏好、决定、想去的地方）
  2. **"你不说，是因为怕什么？"**——若答案是"怕他不高兴／怕他觉得我自私／怕他离开／怕关系会变" → **压抑 = 是**。
  3. **"如果说了，你预期会怎样？"**
- **完成标准**：三句都有明确答案，且用户能说出**一个具体的、被压着的东西**（不是"我好像不太自由"这种抽象）。
- **判停条件（三条，命中即跳转）**：
  - **压抑 = 否，且用户的核心困扰是物理距离、见面频率、异地** → **本 skill 不适用，立即结束。** 判据是压抑不是距离：分居但不压抑 = 已经是两条船，这不是问题。明确告知用户这一点。
  - **压抑 = 否，且用户描述的是"我付出很多、他没回报"** → 转 `sacrifice-indulgence-pendulum`。
  - **压抑 = 是，但压抑的对象可以追溯到原生家庭（"我从小就这样""我妈也是这样"）** → 转 `family-loyalty-attachment`，完成后再回第 5 步。
- **时间盒**：若 10 分钟内用户说不出任何具体的被压着的东西，不要继续深挖——**这不是失败，是有效答案**，跳到第 6 步做偏好识别。

### 第 2 步：把分歧定位到领域，并做硬排除
- 请用户从第七章的六大关键领域里认领（前五个通常最关键，第六个有时会成为导火索）：
  **性爱**（频率、风格偏好、受外人吸引、互相取悦）／**金钱**（花钱方式、投资领域、花钱重点、钱是谁的）／**孩子**（管教方式、教育、饮食、陪伴时间的质量与数量）／**姻亲**（配偶父母的影响与干预、注意力分配、需遵守对方父母的价值观）／**特殊性**（对伴侣的关注度；因工作、朋友、兴趣爱好或瘾头而欠缺关注）／**生活习惯**（杂乱 vs 条理、家务分配、健康与外表）。
- **硬排除（不可"各走各的"的领域）**：若分歧落在**体罚或任何针对儿童/老人/无议价能力第三方的对待方式**、**成瘾**、**外遇**、**财务隐瞒/欺骗** → **回到第 0 步**。第七章把它们与性爱频率、家务分配并列在同一份清单里，这是分类错误：偏好分歧的默认处理是"各走各的 + 走过程"，成瘾/欺骗/儿童安全的默认处理是**设限 + 专业干预 + 信息透明**。**不要把清单当作"这些都可以各走各的"来使用。**
- **完成标准**：用户能说出"我们的分歧在____领域"，且已确认不在硬排除名单上。

### 第 3 步：七状态自检 + 在四个选项里定位
- **（a）七状态自检**（逐条问"这像不像你"，可多选，取最高频的一档）：
  1. 撤退，挖掘战壕、捍卫自己的立场，**甚至愿意牺牲关系**也要按自己的方式来；
  2. 撤退，捍卫立场，若伴侣给你你想要的，可以做**特定的让步**；
  3. 撤退，捍卫立场，**寻求外部增援**，强调你的立场是正义凛然的，并在谈判中应用增援；
  4. 撤退，一段时间后面对自己顽固坚守立场的动机，承认反应过度，开始谈判、寻求共识，**但通常只能达到某种折中**；
  5. 设法安抚对方，**即使这意味着在对你很重要的议题上折中**；
  6. **不惜代价也要和睦相处**，向对方的要求让步，而不顾自己想要的东西；
  7. **坚持不懈地沟通，直到达成完全满意的双赢共识为止**。
  **关键反转（必须告知用户）**：第 7 种听上去最"正确"，作者随后自曝这正是他"坚定地、近乎狂热地支持"的立场，结果是"一头撞到了自己的墙上——那堵防卫和不安全感的墙壁"，真正实现百分之百双赢的**只有屈指可数的几次**。所以状态 7 不是终点。
- **（b）在四个选项里定位**：**一致**（愿意敞开考虑对方观点、共同制订行动计划 → 顺流）／**共识**（所有当事人就如何共处做出决定，耗时极长且通常不可达）／**折中**（双方输得一样多，把船带向没有人真正想去的地方）／**两条船**（各随偏好，未来某时再会）。
- **完成标准**：用户能说"我平时大致在第____种状态，我一直在要的是____"。
- **判停条件**：若落在**状态 6**（不惜代价和睦相处、完全让步）→ **跳过第 4 步，直接进第 6 步做偏好识别**。此时追问"你是不是其实想要共识"会被读成责备，并强化让步。

### 第 4 步：我是想要共识，还是想要自己是对的？（三问）
- 三问，按顺序，每问都要用户自己答：
  1. **"坚持自己是对的，给你带来了什么？"**——作者的自答：短暂的满足感、同样短暂的轻松感，以及**奇怪的内疚感**（为了坚持对而不惜伤害他人感情）。
  2. **"就算你当真是对的，为什么还需要如此猛烈地捍卫呢？"**（真立场应不辩自明）
  3. **"这个信念在保护什么、抵御什么？"**——答案：保护小我，抵御真相。"自以为是其实与指鹿为马并没什么两样；可以说，自以为是就是信念的盔甲。"（第七章 · 坚持自己是对的）
- **完成标准**：用户对第 1 问能给出自己的三样"收获"，并对第 2 问答是/否。
- **判停条件**：若第 1 问的答案是"没有内疚感，我很确定" → 可能确实在要共识，回到第 3 步的一致档，不要强行套"你要的是对"。**不要用这三问去压用户认错**——它会变成本 skill 最容易伤人的一步。
- **边界说明**：若用户仍在防卫中（只能论证对方错、说不出自己的偏好），本章的处方是**先卸防卫再谈偏好**："如果有防卫，你就不舒服，而不适感是一道门，能让你穿越防卫，到达更大的和谐"。此时转 `process-walk`，卸下防卫后再回第 6 步。

### 第 5 步：管好你自己的事（三分 + 动机检验）
- 请用户把当前的在意的事分进三格：
  | 格 | 判据 | 例子 |
  |---|---|---|
  | **伴侣的事**（你的事） | 伴侣怎么做、怎么感受 | 他怎么安排他的周末、他难不难过 |
  | **我的事（反应层）** | 我对伴侣的感受和反应；伴侣在我面前显现出什么样子（因为它反映我的内在体验） | 我因为他难过而产生的内疚、焦虑、恐慌 |
  | **老天的事** | 既不是我的反应、也不是我能改变的（**书中原文的第三格写作"你的过程是你的事，关心并支持你的伴侣是你的事"**；流传版本常称之为"老天的事"，本 skill 按书中原文使用） | 我的过程、我对他的关心与支持 |
- 然后做**动机检验**（唯一且锋利）：**"我做这件事，是为了让谁好受？"** 为了让我自己好受 → 我在管别人的事；出于关心 → 才是我的事。
- **完成标准**：用户能把当前纠结的事指进一格，并回答"为了让谁好受"。
- **判停条件（本册高危风险，必须执行）**：
  - 若用户用"那是他的事"来合理化**不设防、不求助、不离开**，或对**家中其他成员**（孩子、老人）受到的对待也套用同一原则 → **立即停止使用三分法**，回到第 0 步。作者的限定是"**不要为了让你自己好受些去安慰伴侣**"，这个限定在传播中极易脱落。
  - 若用户描述的是**反复推测伴侣状态、预演对话、复盘争执**，并称之为"我很在乎" → 判为**时刻惦记**（不是关心），直接告知："关心伴侣的感受与时刻惦记着伴侣的感受，这两者有巨大的区别。时刻惦记往往导致怜悯，然后又让你陷入了拯救者的强迫症中。"（第七章）并说明：无法自拔地想着伴侣，是在**同时自找苦吃和逃避痛苦**——你很难受，但太沉浸在故事里，就认不出自己的不快乐了。此时转 `process-walk`。

### 第 6 步：说出我的偏好
- 问：**"如果不考虑他的反应，你在这件事上真正想要的是什么？"**
- 若答不出（这是粘连的典型症状），改用小颗粒度的问题：这个周末我想怎么过？这顿饭我想吃什么？这个假期我想去哪？
- 说明偏好的性质：偏好不是需求，它反映你的本质天性以及天性想要的体验（探索家、冒险家、哲学家、老师、艺术家……），是"由心而发的冲动"；而**障碍只是一个信号，告诉我们这是坐下等待的时间**。
- **完成标准**：用户能给出一个**具体的、不依赖对方反应**的偏好（"我想每周有一个晚上单独待着"是，"我想我们别再吵了"不是）。
- **判停条件**：若 10 分钟内仍说不出任何具体偏好 → **不要继续挖**，明确告知"说不出偏好本身就是一个有效结果，说明此刻防卫还在"，转 `process-walk`，下次再从本步开始。

### 第 7 步：出口路由（三个出口，必须选一个并说清）
- **出口 A（一致 / 可达成的共识）**：双方能敞开考虑对方观点 → 共同制订行动计划，把**一致设为共同优先选项**（这是作者婚姻里育儿领域唯一不受分歧困扰的原因——不是议题不冲突，是一致被设成了优先项）。完成标准：产出一个双方都同意的、具体的下一步动作。
- **出口 B（两条船）★**：共识不可达、折中会双输 → 各自表达并跟随自己的偏好。然后做**最锋利的自测**：**"当伴侣选择跟随自己的偏好时，你能真正支持他吗——哪怕这意味着他会离开你单独航行、无论离开多久？"**
  - 能 → 自我区分成立。明确说明：这不是疏远，也不是分手前兆——"**单独一个人，但没有断联**"，自我区分是"留在自己船上的同时仍然分享共同旅程"，偏好相同时陪伴彼此。
  - 不能，且涌上来的是"我不再必不可少""我会失去特殊地位""我就是单独一人了" → 判为粘连，进入出口 C。
  - **完成标准**：用户能说出"我的偏好是____，他的偏好是____，我支持他去做"，且这句话里**没有附加条件、没有"但是"**。
- **出口 C（仍有不适感）**：对"他去走自己的路"起反应、或说不出偏好、或仍在防卫 → 转 `process-walk`。**注意高危误读词**：不要用"你去走个过程"打发用户，也不要把它写成步骤清单——过程不是技巧、不是疗愈、不是步骤（作者三次专门否认）；它是"在你能记起来时"让觉知回到不适感上。
- **终止条件（对冲不可证伪性，贯穿第 1–7 步）**：**若走完本流程，用户得到的结论仍是"我还需要更努力地不粘连／我压抑得还不够少" → 本 skill 失败。** 回到第 1 步重新做压抑检测；若第二轮仍如此，停止使用本 skill 的框架，改问一个外部问题："在这件事上，你本周能为自己做的一个具体改变是什么？"并考虑转 `sacrifice-indulgence-pendulum` 或专业支持。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **异地恋、见面频率、物理距离类问题**——**判据是压抑不是距离**。分居但不压抑 = 已经是两条船；同住但压抑 = 仍是粘连。用本 skill 处理"我们多久见一次面"会把方法用反。
- **关系中存在家暴、精神虐待、PUA、跟踪、监控、经济控制、限制人身自由**——此时"各有一艘船"给控制方提供了完美话术（"你有你的船，我有我的船，所以你管不着我做什么"），给被控制方提供了放弃设限的信号。先做安全评估，见第 0 步。
- **涉及儿童、老人、无议价能力第三方的对待方式**（**含体罚分歧**）——不是偏好差异，是有明确受害方且可能造成身体伤害的问题。第七章全文对第三方零保护性说明，本 skill 对此做了与作者原意相反的修订。
- **成瘾、外遇、长期欺骗、财务隐瞒**——这三类不是偏好差异，是涉及欺骗、失控或承诺破坏的行为，临床上有明确干预指征。用"各走各的 + 走过程"处理会延误戒断、财务隔离与专业干预。
- **走还是留的决策**——转 `quantum-tunnel-surrender`。本 skill 不产出任何去留建议。
- **原生家庭模式的重演**（"我变成了我妈那样""我发誓绝不跟他一样""我不知道自己真正想要什么"）——转 `family-loyalty-attachment`。
- **具体的付出-回报失衡**（家务、育儿、经济分工）——转 `sacrifice-indulgence-pendulum`。
- **用户正处在急性崩溃、闪回、解离或惊恐发作中**——本 skill 需要观察位，崩溃中拿不到。

### 安全红线（第 0 步，逐条拦截）

命中任一，**立即停止一切向内归因的方法，转向安全评估与资源连接**：① 身体暴力、威胁、破坏物品或阻挡去路；② 监控、社交隔离、经济控制、限制人身自由；③ 针对儿童、老人或无议价能力第三方的伤害（含体罚分歧）；④ 成瘾、长期欺骗、财务隐瞒；⑤ 用"这是我设计的功课""他在帮我成长""这是你的梦"解释**正在发生的伤害**；⑥ 闪回、解离、惊恐发作、自杀意念，或因使用本方法中断正在进行的专业治疗；⑦ 报告"各走各的之后我更该留下了"——这是奖励函数被劫持的确定性信号。

### 作者在书中警告的失败模式

- **把控制当成亲密、把共识当成健康（CE-B10）**：核心失败模式。作者列的证据是"一艘船政策"（一方离开自己的船、登上对方的船并承认对方是船长）与共识强迫症。**预警信号**：对伴侣的行程/社交/消费有知情要求并称之为"在乎"；认为"有分歧 = 关系不健康"；用"我们是共同体"否决对方单独的决定；把对方追求自己的偏好读作对关系的背叛。**机制**：粘连的底层是特殊性需求——一旦对方成为重要性的唯一供给源，就必须对其行为实施全面监控，否则供给会中断；所以粘连**必然**走向限制与可预测性。
- **共识狂热（作者自曝）**：他"坚定地、近乎狂热地"相信所有冲突必须通过共识解决，结果只有屈指可数的几次真正双赢，"一头撞到了自己的墙上——那堵防卫和不安全感的墙壁"。根因是"我更在意的是让自己是对的，而不是达成真正的共识"。**这是本 skill 存在的理由：两条船是为这个失败准备的第三方选项。**
- **把反刍当成关心（CE-B12）**：一天中大量时间花在推测伴侣状态、预演对话、复盘争执上，并自我认证为"我很在乎这段关系"。实际功能是双重的：**既在受苦，又在逃避自己的痛苦**（注意力全在对方身上，就认不出自己的不快乐）。判别极简：如果你满脑子想着伴侣，你一定在难受——**难受本身是要走过程的信号，不是要继续想下去的信号**。预警信号：独处时反复预演对话；对伴侣的情绪高度敏感、对自己的迟钝；关心之后感到耗竭而非联结；用"我只是担心他"来解释焦虑。
- **"管好你自己的事"变成不干预许可（CE-S06，本册高危）**：在粘连/过度干涉情境下是良药，在控制/虐待情境下会变成三样东西——对施害者行为的**不干预许可**（"他怎么对我是他的事"）；对第三方伤害的**旁观许可**（"管好自己的事"直接取消保护责任）；对**求助行为的否定**（向他人求助在逻辑上就是"去管别人的事"）。作者的限定"不要为了让你自己好受些"在传播中极易脱落。**机制**：一条边界建议的适用域取决于关系中的权力分布——在对称关系中"各自管好自己"是对等的；在不对称关系中它只约束弱势方，因为强势方的"事"本来就包含对弱势方的控制。
- **"给伴侣完全的自由"在控制关系中变成放弃边界（CE-S09）**：控制方可以把监控、限制社交、经济控制包装成"我在追随我的偏好"；被控制方则失去对控制行为设限的理由（既然要支持对方"无论离开多久"）。作者自己给过判别——粘连的定义是"基于**互相**需求的人为结合"，关键词是"互相"——但这条判别**没有被写成使用前的检查项**。
- **把两条船当成疏远 / 分手前兆**：作者明确"**单独一个人，但没有断联**"，并说破除粘连不必离开关系。若用户把"各有一艘船"读成"那就分开吧"，立即澄清。

### 作者的盲点 / 时代局限

- **不可证伪的封闭系统（本册最强反对意见）**：做到了 = 你真的自我区分了；做不到 = 你还在粘连里／你还没到入茧阶段。**这个结构让方法无法被检验。** 对冲已写入 E 段：每一步都有可观察的完成标准；第 1 步与第 6 步各设 **10 分钟时间盒**；第 7 步设全局终止条件——若结论仍是"我压抑得还不够少"，本 skill 判为失败并转向外部动作。
- **V1 单章来源（必须注明）**：「粘连／自我区分／船」仅出现在 **3/11 章**（第七章 40 次，第 0 章 1 次、第 10 章 2 次），**是本书内的单章概念**。一致性/共识/折中虽然跨 9/11 章（第七章 30 次、第六章 9 次），但粘连与自我区分本身没有跨章复现，跨册才成立（与第 1 册 `family-loyalty-attachment` 的依附情结同源）。**因此本 skill 的证据强度弱于 `specialness-vs-love`（11/11）与 `process-walk`（9/11），使用时不应把它当作全书主干方法。**
- **"情绪成熟的水平往往相同"这个前提**：作者明说"亲密关系中的两人往往成熟水平相同"。在不对称关系（控制、经济依赖、照护责任）中这个前提不成立，而两条船的适用域恰恰取决于权力分布——作者自己给了判别（"互相"需求），却没做成使用前检查项。本 skill 已把它写进第 0 步。
- **"阶段不可由意志推进"**：作者明说从未听说有人靠意志力从一个阶段进展到下一个阶段。这直接取消了所有 actionable 建议的有效性基础——包括本 skill 的七个步骤。因此每一步都必须带可观察的完成标准，且不得把"你还在第一阶段"当作解释失败的理由。
- **体罚、成瘾、外遇、财务隐瞒被列为普通分歧领域**：分类错误导致的干预降级。本 skill 已在第 2 步做硬排除，这与作者原意相反。
- **作者的划界被判定为不够**：他试图用"我只谈情绪不适，不谈身体伤害"来划界。五点失效——① 虐待的核心伤害形态**正是情绪不适**；② 划界是一次性的，全书再未回归；③ 划界是排他的而非累积的；④ 作者自己守不住（同章用掠走妻子并企图谋杀的罗波那演示"连敌人也只是在演好自己的角色"）；⑤ 全书**零处**写有"如果你正在经历 X，请不要使用本书的方法"。因此**不能依赖作者的划界**，第 0 步的拦截集是必需的。
- **性别视角局限**：作者用 1969/1972 届毕业纪念册论证女性选择的扩展，但情绪劳动的结构性分配、照护责任、经济依赖这些现实约束未被处理。用"你压抑了自己"解释一个被结构性负担困住的人，是苛责。
- **证据基础与样本局限**：唯一的疗效证据是作者自己的婚姻（N=1），且他自评"情绪上只是从六岁提升到八岁"。案例全部是北美中产异性恋模板。近二十五年的依恋神经科学、情绪调节（DBT/ACT）、复杂型 PTSD 研究完全未纳入。
- **两条 agent 特异性风险**：① 用户可能把你的回答转发给伴侣，作为"权威说你该干涉我"的证据——**本 skill 的判别结果不得用作要求对方改变的依据，也不得用作拒绝对方合理诉求的依据**；② 同一句追问（"你到底想要什么"）在用户安全时是洞察工具，在脆弱时是攻击——**按用户当下状态设限，而不是按句子内容**。

### 容易混淆的邻近方法论

- **不是"保持独立 / 给彼此空间"的常识建议**：常识的独立是一个**距离**概念（多见面、少见面）。本 skill 的判据是**压抑**，与距离无关——这正是 V2 推导出来的核心补丁，也是它唯一的强增量。
- **不是设立边界**：边界是**外部动作**（禁止对方做什么、我要做什么）。本 skill 是**内部判别 + 选择**（我有没有为归属感而压着自己；在一致/共识/折中/两条船里选哪个）。两者相邻：第 7 步出口 B 就是把"不再压抑"转成一个具体的、可说出口的偏好。
- **不是鲍文（Bowen）家庭系统的自我分化**：两者都讲 differentiation，且都否认"分离 = 分化"。但鲍文的分化是**跨代家庭系统**的概念（多代传递过程、情绪截断、三角关系），操作上指向原生家庭；本 skill 的自我区分是**当下的、关系内的**，判据是"能否支持对方离开"与"有没有压抑"，且作者明确"破除粘连不必离开关系"。术语相近，不要混用。
- **不是依恋理论里的"独立型"**：依恋类型描述的是早期照料关系形成的内在工作模型；本 skill 的粘连指的是**基于归属感与重要性需求的、互相的**人为结合，是一个关系层面的结构描述，不是个体特质。
- **本册 5 个高危误读词在本 skill 中的处理**：① **过程**——不是技巧、不是疗愈、不是步骤，第 7 步出口 C 只在用户有不适感时路由，不做流程拆解；② **接纳**——不是忍着，第 1 步判为"压抑"时**禁止**建议用户接纳现状；③ **欣赏**——不指向对象、不是找优点，本 skill 不使用；④ **痛苦 vs 受苦**——第 5 步的"时刻惦记"是**受苦**（对痛苦的拒绝），不是关心；⑤ **故事囚牢**——与第 1 册受害者监牢同源但**出口不同**：本册说"问题根本不需要被解决"，所以第 7 步不给"谁对谁错"的裁决。
