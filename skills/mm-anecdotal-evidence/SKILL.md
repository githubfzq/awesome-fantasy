# 轶事证据（anecdotal evidence）

## R — 原文 (Reading)

> 所谓的"轶事证据"，就是以非正式手段收集的源于私下传闻的证据。当你根据轶事证据进行概括归纳，或是将轶事证据看得比科学证据更重要时，就会遇到麻烦。
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

轶事证据是以非正式手段收集的、源于私下传闻的证据。它的问题不是"假"——那些事往往真的发生过——而是它**在统计上没有推断能力**。

具体来说，轶事证据只证明"某事件有可能发生"，不提供该事件发生的概率，更无法给出两组之间的风险比。听到"我爷爷每天抽一包烟活到八十岁"，你得到的全部信息是"抽烟者活到八十是可能的"；你没有得到任何关于"抽烟者 vs. 不抽烟者活到八十的概率之比"的信息——而后者才是决策需要的。

它的产生机制是**选择性分享**：人们更愿意传播异常、糟糕或奇妙的经历。司空见惯的事没人讲，所以流传的轶事天然不具代表性（unrepresentative）。这意味着轶事的分布被系统性扭曲了，越是离奇的故事越容易到达你耳边。

由此推出操作性判据，两条问题：

1. **这个样本是怎么被选出来的？**（谁在讲？为什么是这条被讲出来？）
2. **反例为什么没被传播？**（那些"抽烟六十岁就走了"的人不会出现在故事里。）

书中也给了它应有的位置：轶事可以用来"提出假设"，只是不能用来"验证结论"。怀疑论者舍默指出："轶事思维是生而有之的，科学思维则需要训练得来"——这解释了为什么这个错误如此顽固，也说明纠正它是一次需要刻意练习的思维训练。

## A1 — 书中的应用 (Past Application)

### 案例: 四个典型错误推论

- **问题**: 作者列举了日常生活中最常见的几类用轶事推翻统计的错误推论。
- **方法论的使用**: 四个例子——"今年下了场大雪所以全球变暖是骗人的""爷爷每天抽一包烟活到八十岁""打完流感疫苗后又流鼻涕又咳嗽"等；作者指出顺势疗法广告惯用此类巧合轶事。
- **结论**: 这些推论的共同结构是：用一个（或被选择性传播的少数）个案，去否定一个关于概率与趋势的结论。局部天气反常不能推翻长期气候趋势，个别长寿烟民不能否定吸烟的风险比。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户用身边个案来否定一个统计结论（"我认识的某某就是反例"）——需要区分"存在反例"与"结论被推翻"。
2. 用户在评估某个产品、疗法、方法的效果，手上的证据只有几个故事——需要提示去找系统性证据。
3. 用户正被一篇充满动人故事的营销或伪科学内容说服——需要拆穿它用轶事替代证据的手法。
4. 用户在做用户研究/访谈，担心过度依赖个别用户的说法——需要把"用访谈提假设、用数据验证"的流程立起来。

### 语言信号 (用户的话里出现这些就应激活)

- "我有个朋友就是这么做的，效果特别好。"
- "可是我认识的某某抽了一辈子烟也活到九十。"
- "我自己用了都说好，还要什么数据？"
- "网上好多人分享了这个经历，还能有假？"
- "It worked for my friend, so it must work."
- "I've never had a problem doing it this way."

### 与相邻 skill 的区分

- 与 `mm-availability-bias` 的区别: 可得性偏差讲的是**你为什么会高估**某类事件的概率（因为容易想起来）；轶事证据讲的是**你手上证据的类型**本身不足以支持推断。前者是认知偏差机制，后者是证据质量问题——轶事往往通过可得性偏差发挥作用。
- 与 `mm-survivorship-bias` 的区别: 幸存者偏差是**样本被筛选**（失败者已消失、你看不到）；轶事证据是**证据形式不合规**（样本是非正式收集的传闻）。一个讲"样本怎么来的"，一个讲"证据是什么形式"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认结论的形式**
   - 问：这个轶事被用来支持的是"有可能发生"还是"大概率会发生在你身上"？
   - 完成标准: 明确区分。若只是主张"有可能"，轶事其实够用，无需纠错。
2. **追问样本来源**
   - 问：这个案例是怎么被选出来的？为什么是它而不是别的被讲出来？
   - 完成标准: 指出至少 1 条选择性分享/传播的机制。
3. **追问反例的沉默**
   - 问：相反的案例去哪了？它们为什么没被传播？
   - 完成标准: 明确指出反例被系统性低估的原因。
4. **给出正确的证据层级建议**
   - 把轶事放回"提出假设"的位置，并指出验证它需要的证据类型（对照组、系统性数据、样本量）。
   - 完成标准: 给出 1 条具体的下一步验证方式。
   - 判停条件: 若用户是在倾诉情绪、寻求共情而非做判断，先共情，不要在此刻纠错。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是在倾诉个人经历、寻求共情时——此时纠错是残忍且无效的。
- 用来提出假设的早期探索阶段——轶事在这里有正当价值。
- 研究罕见事件或个体独特性时（罕见病、极端个案研究）——个案本身就是核心证据。

### 书中警告的失败模式 / 容易误用的地方

- 书中未否定轶事的价值：它可以用来"提出假设"，只是不能用来"验证结论"。（书中明示）
- 怀疑论者舍默指出"轶事思维是生而有之的，科学思维则需要训练得来"——所以这不是智商问题，需要刻意训练。（书中明示）
- 反向风险：把"这是轶事"当作万能否定句，用来回避一切自己不喜欢的个人叙述。（推导，非书中明示）

### 容易混淆的邻近模型

- 与**可得性偏差**: 见 A2 区分——证据形式 vs. 认知机制。
- 与**幸存者偏差**: 证据形式 vs. 样本筛选。
