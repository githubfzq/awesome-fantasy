# 逆向选择（adverse selection）

## R — 原文 (Reading)

> 当各方都根据自己拥有的信息，选择认为对自己有利的交易时，就称为"逆向选择"（adverse selection）。知道自己需要看牙的人更有可能去买看牙险。不幸的是，这提高了所有人购买看牙险的价格。
>
> — 《思维模型》, 第2章 > 危险行业

---

## I — 方法论骨架 (Interpretation)

逆向选择是信息不对称在市场层面的后果。当一方比另一方更清楚自己的风险状况时，他会据此决定"要不要进场"：知道自己需要看牙的人更愿意买牙科保险，知道自己车况差的人更愿意卖车。结果是进场者的平均风险高于全体平均。

接下来是一个正反馈的恶性循环：高风险者占比上升 → 赔付/成本上升 → 价格上升 → 对低风险者来说更不划算 → 更多低风险者退出 → 风险池进一步恶化。这个循环会自我强化，直到市场彻底崩溃。

值得注意的是，它与"突破群体免疫阈值"在结构上是同构的：两者都是越过某个临界点之后的自我强化坍缩，而且一旦坍缩就很难逆转。区别只在于退化的是"风险池的质量"还是"免疫覆盖率"。

破解方向有三条：强制全员参与（车险、ACA 强制投保），把高风险者重新拉进池子；按风险差异化定价（人寿保险对烟民加价），让低风险者不必补贴高风险者；或者干脆恢复信息对称（Carfax 把柠檬赶出市场）。

关键判据：**进场者的构成是否系统性偏向某一端，且这种偏向会反过来加重问题本身？**

## A1 — 书中的应用 (Past Application)

### 案例: 柠檬市场与 ACA 的保费螺旋

- **问题**: 二手车市场上买家分不清"柠檬"（劣质车）和"蜜桃"（优质车），只愿意付均价；于是"蜜桃"的卖家觉得不划算而退出，均价随之下降，又逼退下一批好车，最终市场沦为"柠檬"市场。同样的结构出现在 ACA（平价医疗法案）的州立互助健康险：政策设计者担心健康人宁愿交罚款也不投保，只留下已患病者，导致保费螺旋上升。
- **方法论的使用**: 作者用同一条正反馈曲线解释两个场景——信息不对称使进场者偏向高风险一端，价格上升又加速另一端退出。两者的解法却相反：二手车市场靠 Carfax 恢复信息对称、把"柠檬"赶出市场；而 ACA 的目标恰恰是确保已患病者不被赶出市场，因此必须强制健康人参保。
- **结论**: 同样是逆向选择，先明确"你要把谁赶出去、把谁留下"，才能选对解法——恢复信息对称、强制参与、还是差异化定价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计一个互助/共担机制：互助保险、团队轮值、共享带宽、内部结算池，担心只有高消耗者参与。
2. 平台上的商品或服务出现"劣币驱逐良币"：好卖家流失、好内容被淹没、好候选人退出流程。
3. 定价时发现赔付率/成本率持续恶化，且客户结构在变。
4. 招聘或招生：某一类人特别积极，另一类人根本不来，导致筛选质量下降。
5. 推出补贴或福利后，发现领的人大多不是目标人群。

### 语言信号 (用户的话里出现这些就应激活)

- "来买的都是最需要的人"
- "好的都跑了，剩下的越来越差"
- "保费/成本一直在涨，客户结构也在变"
- "好车卖不上价，只能不卖了"
- "我们补贴发出去，全被不该领的领走了"
- "adverse selection / lemons / death spiral / risk pool"

### 与相邻 skill 的区分

- 与 `mm-asymmetric-information` 的区别: 信息不对称是**条件**，逆向选择是**后果**。只有信息落差导致"进场者结构系统性偏移、并反向加重问题"时，才构成逆向选择。
- 与 `mm-moral-hazard` 的区别: 逆向选择发生在**签约前**（谁选择进来），道德风险发生在**签约后**（进来之后行为变冒险）。这是最常被混淆的一对，判断方法是问时间。
- 与 `mm-herd-immunity` 的区别: 两者都是越阈值后的自我强化坍缩，但逆向选择恶化的是风险池的**质量**（高风险者留下），群体免疫恶化的是**覆盖率**（传播载体变多）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认存在私有信息**
   - 写出：进场者知道、而定价方/另一方不知道的是什么（自身风险、真实质量）。
   - 完成标准: 一句"进场者 privately 知道 X"。
   - 判停条件: 若不存在私有信息，停止本 skill。
2. **验证进场结构是否系统性偏移**
   - 比较进场者与全体（或潜在可进场者）的关键指标均值。
   - 完成标准: 得到一个偏移方向和大致幅度；若无偏移，停止本 skill。
3. **画出正反馈环并找临界点**
   - 写出链条：结构偏移 → 成本上升 → 价格上涨 → 低风险者退出 → 结构进一步偏移。
   - 完成标准: 明确标出哪一环最快、是否有 death spiral 的迹象（价格与结构同时恶化）。
4. **先确定目标：要把谁留下**
   - 明确是要把高风险者赶出去（二手市场），还是必须留下他们（医疗保险）。这决定解法方向。
   - 完成标准: 一句明确的目标陈述。
5. **据此选择解法**
   - 恢复信息对称（质检报告、历史记录、认证）→ 把差的一方赶出去。
   - 强制全员参与（强制投保、全员分摊）→ 让低风险者无法退出。
   - 差异化定价（按风险分级定价、对烟民加价）→ 让低风险者不必补贴。
   - 完成标准: 选定至少 1 条，写明它如何打断步骤 3 画出的环。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 双方信息对称、进场者无系统性偏移的市场：价格上升可能只是成本上升，不是逆向选择。
- 变化发生在签约之后：那是道德风险，用错模型会推出错误的解法（调自担比例 vs 调准入结构）。
- 把任何"客户变差了"都归为逆向选择：需要先排除获客渠道变化、竞争环境变化等其他解释（推导，非书中明示）。

### 书中警告的失败模式 / 容易误用的地方

- 作者指出二手车市场靠 Carfax 恢复信息对称把"柠檬"赶出市场，而 ACA 的目标相反——确保已患病者不被赶出市场，因此必须强制健康人参保。方向搞反会让解法完全失效，这是书中明确给出的对比。
- 它是个正反馈过程，早期迹象（结构轻微偏移）看起来无害，等到价格明显上升时往往已经接近临界点（推导，非书中明示）。
- 强制参与虽然有效，但带有强制性与分配争议，需要同时评估可接受度（推导，非书中明示）。

### 容易混淆的邻近模型

- 与柠檬市场：柠檬市场是逆向选择在二手车市场的具体案例，逆向选择是通用机制；保险、招聘中也有逆向选择但不称柠檬市场。
- 与选择性偏差：选择性偏差是统计/研究方法上的取样偏差（样本不能代表总体），逆向选择是市场参与者的**主动**选择导致的构成偏移；一个是观察者的错误，一个是参与者的行为。
