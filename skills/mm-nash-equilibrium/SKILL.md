# 纳什均衡（Nash equilibrium）

## R — 原文 (Reading)

> 纳什均衡是一个策略组合，其中任何一名玩家改变策略都会导致双方的结果恶化。
>
> — 《思维模型》, 第7章 > 参与博弈

---

## I — 方法论骨架 (Interpretation)

纳什均衡回答的问题是:**这个博弈最终会停在哪?** 定义:一组策略组合,其中任何一方单方面改变策略,都会使自己的(书中表述为双方的)结果恶化。

它的预测力来自稳定性:如果现在的局面不是均衡,那至少有一个人能通过改变做法让自己更好,他就会改;只有当每个人都"没有单方面改善的空间"时,局面才会停住。所以纳什均衡是最可能出现的结果——**除非采取措施改变博弈参数**。

关键的一点是:均衡点未必是好结果,它只是"没人愿意先动"的稳定点。囚徒困境的均衡是双重背叛(各判 5 年,而不是都沉默的 1 年);军备竞赛的均衡是双方继续增加军备(双输)。

另一个关键点:协作解(双赢)往往不稳定——任一方都可以通过背叛改善自身处境。所以要维持合作,不能靠默契,必须改参数或引入重复博弈。

关键判据:先确认"有没有人能单方面变好";如果有,那还不是均衡,局面会继续移动。

---

## A1 — 书中的应用 (Past Application)

### 案例: 双重背叛与军备竞赛

- **问题**: 博弈会稳定在什么结果上?合作的双赢解能不能维持?
- **方法论的使用**: 作者用两个例子说明均衡点的性质——囚徒困境中,均衡是"双重背叛判 5 年",虽然双方都知道都沉默只要 1 年;军备竞赛中,均衡是"双方都继续增加军备",即双方都不想要的双输局面。
- **结论**: 均衡只是稳定点,不是好结果。协作解不稳定,因为任一方都可通过背叛改善自身处境;要维持合作必须改变参数或引入重复博弈。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户看到一个行业里"所有公司都在做某件大家都不喜欢的事"(疯狂补贴、高强度加班、过度广告),想知道会不会停。
2. 用户身处一个僵局:谁都不满意,但谁先改谁吃亏。
3. 用户在设计规则或平台机制,想预测新规则下大家最终会收敛到什么行为。
4. 用户试图推动合作,需要知道为什么口头约定撑不住。

### 语言信号 (用户的话里出现这些就应激活)

- "大家都在这么干,谁也停不下来"
- "谁先改谁吃亏,所以就这么耗着"
- "这个局面会稳定在哪"
- "明明都不想要这个结果"
- "签了协议也没用,还是会有人偷偷违反"
- "Nash equilibrium" / "no one wants to move first" / "stable outcome"

### 与相邻 skill 的区分

- 与 `mm-prisoner-s-dilemma` 的区别: 囚徒困境是**一个具体的博弈**,纳什均衡是**找稳定点的通用工具**;囚徒困境的均衡是双重背叛,军备竞赛的均衡是持续加码——同一个工具,不同的局。
- 与 `mm-payoff-matrix` 的区别: 收益矩阵是**表示形式**(把各种组合的收益摆成表),纳什均衡是在这张表上做的**求解动作**;先有矩阵,再找均衡。
- 与 `mm-iterated-game` 的区别: 单次博弈的均衡往往是坏结果;重复博弈改变了参与者的收益结构,合作才可能成为均衡。先问"是不是一次性的"。

## E — 可执行步骤 (Execution)

1. **确定玩家与各自的策略集**
   - 完成标准: 写出有哪些玩家、每人有哪些可选策略。
   - 判停条件: 若只有一方、另一方是自然随机性,改用决策树。
2. **摆出收益矩阵**
   - 完成标准: 每种策略组合下各玩家的收益都填入表中,形成完整的收益矩阵。
3. **逐个格子检查"能不能单方面变好"**
   - 完成标准: 对每一种组合,检查是否有人能通过单方面换策略改善自己;若无人能改善,标记为均衡。可找出 0 个、1 个或多个均衡。
4. **评价这个均衡好不好**
   - 完成标准: 明确指出均衡点与合作解(如果有)之间的差距,并回答"这是大家想要的结果吗";若协作解存在但不稳定,明确说明原因——任一方都可通过背叛改善自身。
5. **若要改变结局,改参数**
   - 完成标准: 给出具体的参数改动(引入重复互动、可执行的惩罚、提高背叛成本、改变信息结构、引入第三方),并说明它如何移动均衡点;明确指出指望默契或口头协议是无效的。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单方面决策问题:没有策略互动就没有均衡。
- 局面尚未收敛、正在剧烈变化中:均衡是稳态概念,对过渡期没有预测力。
- 玩家不是理性自利的(受强制、严重信息不足、或受情绪主导):均衡假设玩家会正确计算自身利益。

### 书中警告的失败模式 / 容易误用的地方

- 书中强调: 协作解(双赢)不稳定,因任一方都可通过背叛改善自身处境;要维持合作必须改变参数或引入重复博弈。(书中明示)
- 把"均衡"误读为"最优"——均衡只是稳定点,可能是一个双输点。(书中明示)
- 存在多个均衡时,模型本身不告诉你会落在哪一个,需要靠历史、惯例或协调机制来判断。(推导,非书中明示)

### 容易混淆的邻近模型

- 与占优策略(dominant strategy): 占优策略是"无论对方怎么做我都选它",是单方面的性质;纳什均衡是"给定对方的选择,我不想改",是组合的性质。占优策略组合一定是均衡,反之不然。
- 与公地悲剧: 公地悲剧的过度使用是多人博弈的均衡结果,分析工具仍是纳什均衡,只是玩家更多、声誉更难建立。
