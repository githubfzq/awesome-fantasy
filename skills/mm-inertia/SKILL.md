# 惯性（inertia）

## R — 原文 (Reading)

> 惯性（Inertia）是指物体拒绝改变当前的运动状态。
>
> — 《思维模型》, 第4章 > 别跟自然对着干

---

## I — 方法论骨架 (Interpretation)

惯性是物体拒绝改变当前运动状态的属性：静止的想继续静止，运动中的想继续按原方向运动。质量越大，让它停下或转向所需的力就越大。

把这个物理事实搬到观念和组织上，解释力出奇地好：

- **观念惯性**：来自早年家庭与地域文化形成的、从未被质疑过的核心信念。这类信念因为从未被检视，时间越久越难扭转——不是因为它们更正确，而是因为它们的"质量"更大。
- **组织惯性**：来自长期执行的战略与流程，会让组织做出明知并非最优的决策。

为什么值得单独当一个模型？因为惯性的存在意味着**改变需要持续施加的力，而不是一次性的决定**。你宣布"从今天起改"通常是不够的。

作者的应对方式很直接：质疑自己的前提假设，主动审视那些"看起来是事实"的旧观念。判据是——这个做法/信念，是我验证过的，还是只是我一直这么做的？

要注意的是，惯性并不总是坏事：作者也建议主动为组织的观念与规范创造惯性（也就是文化），让好的东西长期留存下来。

---

## A1 — 书中的应用 (Past Application)

### 案例: 小行星灭绝说与"每天吃几个鸡蛋"

- **问题**: 很多我们当作常识的东西，其实是特定年代的产物，而且早已被修正，但人们的直觉还停留在原地。
- **方法论的使用**: 作者举了两个例子说明观念的惯性与时代性——我们父母读书时还没学过"小行星导致恐龙灭绝"（该理论 20 世纪 80 年代才提出，如今又开始受到质疑）；20 世纪 80 年代对饱和脂肪与胆固醇的排斥早已被修正，但想到"每天吃几个鸡蛋"我们还是会踟蹰。
- **结论**: 观念的质量来自时间与从未被质疑，而非正确性；因此应对方式是主动质疑前提假设，重新审视那些"看起来是事实"的旧观念。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户描述"道理都懂但就是改不动"，无论发生在个人习惯还是组织转型上。
2. 用户发现自己在用一个从未验证过的假设做决策，或团队用"我们一直这么做"作为理由。
3. 用户在推动一项变革，想知道为什么阻力这么大、需要多持久的力。

### 语言信号 (用户的话里出现这些就应激活)

- "我们知道该改，但就是推不动"
- "一直都是这么做的"
- "这个观念我从小就这么认为"
- "转型太难了，组织太大掉不了头"
- "we know we should change but nothing moves"

### 与相邻 skill 的区分

- 与 `mm-strategy-tax` 的区别: 惯性是**性质**（抗拒改变），战略税是**后果**（为维护战略而被迫付出非最优代价）。惯性是原因，战略税是它落到战略上的表现。
- 与 `mm-path-dependence` 的区别: 路径依赖强调"过去的选择限制了现在的可选项"；惯性强调"改变需要持续的力，质量越大越难转"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定那个"改不动"的东西：做法、流程还是信念**
   - 完成标准: 明确写出要改变的对象及其当前状态。
2. **估算它的"质量"：存在多久、被多少人共享、有没有被公开质疑过**
   - 完成标准: 从时间、人数、是否被检验三个维度给出评估，判断惯性大小。
3. **把它拆成"事实"与"假设"，逐个追问假设的出处**
   - 完成标准: 至少列出 3 条被当作事实的假设，并标注每条的来源（亲验/他人告知/时代背景）。
   - 判停条件: 若这些假设经得起检验，说明不是惯性问题，应转向其他阻力分析。
4. **给出施加持续力的方案，而不是一次性宣布**
   - 完成标准: 至少 3 条持续机制（反复沟通、制度与流程固化、新默认、阶段性检查点），并明确由谁持续推动。
5. **判断这个惯性是否值得保留**
   - 完成标准: 明确回答"这是该打破的旧观念，还是该固化的文化/规范"，后者应转为主动维护。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 变革阻力来自明确的利益冲突或资源不足时，那是激励与资源问题，用惯性解释会掩盖真实矛盾。
- 需要快速试错的场景（早期产品探索），刻意保持低惯性反而更合适，不必急于固化。

### 书中警告的失败模式 / 容易误用的地方

- 书中明示：惯性并非全是坏事——作者建议主动为组织的观念与规范创造惯性（即文化），使之长期留存。
- （推导, 非书中明示）把所有阻力都归为"惯性"，会把真实的反对意见污名化为保守，从而关掉有价值的反馈通道。

### 容易混淆的邻近模型

- 与牛顿第一运动定律（newton-s-first-law-of-motion）混淆：后者是物理定律本身，本模型是它被借用到观念与组织上的思维模型。
- 与锁定效应（lock-in）混淆：锁定效应强调因转换成本而无法离开，惯性强调改变本身需要持续的力。
