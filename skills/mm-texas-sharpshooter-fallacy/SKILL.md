# 得州神枪手谬误（Texas sharpshooter fallacy）

## R — 原文 (Reading)

> 这个谬误得名于一个笑话，说的是一个人来到一座谷仓，发现谷仓侧墙上画着许多靶子，每个靶子中央都有一个弹孔。他先是为射手的精准度惊叹不已，后来才发现，射手是在乱射一通后绕着弹孔画的靶子。
>
> — 《思维模型》, 第5章 > 信不信由你

---

## I — 方法论骨架 (Interpretation)

得州神枪手谬误的核心机制是**方向反转**：正常的推理是"先定假设 → 再收数据检验"；这个谬误是"先有数据 → 再从中挑出显著的簇 → 反过来宣称这是有意为之的模式"。因为靶子是按弹孔画的，命中率必然是 100%，这个"证据"不携带任何信息量。

关键判据：这个模式是在**看到数据之前**就预测好的，还是在**看到数据之后**才圈定的？前者是检验，后者是编故事。

为什么它容易骗人：在人足够多、维度足够多的情况下，几乎总能找到某个子群体表现出极端值——这是随机性保证会发生的，不是发现。你在 20 个细分维度里找一个 p<0.05 的结果，期望就能找到一个。

要注意这个谬误针对的不是探索性分析本身（探索是合法且必要的，很多好假设正是这样产生的），而是把探索的结果直接当作已验证的结论来用。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户从一堆数据里"看出"了一个模式、簇或异常聚集，并准备据此行动。
2. 用户在复盘时说"我早就知道会这样"，并从历史数据里挑出支持这一说法的证据。
3. 用户看到"某个地区/某类人群/某个时间段异常高发"的报道，问是不是有原因。
4. 用户从 A/B 测试的多个细分维度里挑出一个显著的结果，想据此上线。

### 语言信号

- "数据里明显有个聚集。"
- "这几个案例都集中在一起，肯定有原因。"
- "我早就说过了吧，你看这里。"
- "在这个细分人群里效果特别显著。"
- "这个地区明显高发。"
- "There's a clear cluster / look at this pattern / I called it."

### 与相邻 skill 的区分

- 与 `mm-clustering-illusion` 的区别: 聚集性幻觉是**认知错觉**——在真正随机的分布里"看出"簇（人眼在随机点云里总会看到聚集）；得州神枪手是**推理过程的错误**——先有数据后画靶。二者常同时出现，判别点不同：前者问"这个簇是否超出随机应有的程度"，后者问"这个簇是先预测的还是后圈定的"。
- 与 `mm-data-dredging` 的区别: 数据捕捞是反复检验各种切分直到 p<0.05（方法论问题，可用多重比较校正）；得州神枪手是围绕已有结果事后定义目标（逻辑问题）。前者可以统计修正，后者只能靠预先注册假设来避免。
- 与 `mm-spurious-correlation` 的区别: 虚假相关是两个变量之间的伪相关；得州神枪手的表现形式更一般，也包括空间簇、时间簇、子群体极端值。判据：看这个"发现"是变量之间的，还是某个子集上的。

## E — 可执行步骤 (Execution)

1. **问清靶子的绘制时间**
   - 直接问："这个模式是在看数据之前就写下来的，还是看到之后才总结的？"
   - 完成标准: 得到明确回答。
   - 判停条件: 若是事先提出的假设且分析方案预先确定，停止本 skill——这是正常检验，转向检查其统计功效。
2. **还原射击次数**
   - 列出分析过程中实际检验过多少个维度、子集、时间段、变量对。
   - 完成标准: 给出一个具体数字（哪怕是粗估）；多数人会严重低估这个数字。
3. **算随机基线**
   - 在这么多检验下，随机出现这种强度的簇的期望次数是多少？
   - 完成标准: 给出粗算并与实际观察到的簇数对比；若观察值不超过期望值，判定为噪声。
4. **锁定靶心定义**
   - 追问这个簇的边界是怎么定的：为什么划在这条街、为什么取这个年龄段、为什么从这个时间点开始？
   - 完成标准: 指出边界选择的自由度；若边界可以任意滑动就仍能"显著"，判定为事后圈定。
5. **要求预先注册再验证**
   - 让用户在独立数据上、用事先定死的边界重新检验。
   - 完成标准: 给出具体的验证设计——固定边界 + 独立数据 + 明确指标。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 假设是在看到数据前就提出、且分析方案预先确定的——这是正常研究，不是谬误。
- 用户只是在做探索性分析，并且明确知道结论待验证——探索本身合法。
- 观察到的簇远远超出随机基线（真正异常）——此时应认真调查，而不是一律归为事后圈定。

### 容易误用的地方

- 书中未给出该模型的边界说明。（以下为推导，非书中明示）
- 反向误用：把这个谬误当作拒绝任何事后发现的挡箭牌。事后发现的正确处理是"降级为待验证假设 + 独立数据复验"，不是"一律不信"。
- 最容易失守的地方是 A/B 测试的细分分析：整体不显著但"25-34 岁 iOS 用户"显著，几乎总是得州神枪手。

### 容易混淆的邻近模型

- **聚集性幻觉**: 认知错觉 vs. 推理错误，见 A2 区分。
- **后见之明偏差（hindsight bias）**: 后见之明是"事后觉得自己早就知道"的记忆扭曲；得州神枪手是"事后圈定证据来证明自己早就知道"的推理行为。前者是感觉，后者是做法。
