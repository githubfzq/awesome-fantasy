# 公共物品（public goods）

## R — 原文 (Reading)

> 搭便车现象在使用公共物品（public goods）时相当常见。所谓的"公共物品"包括国家军队、广播电视，甚至是我们呼吸的空气。
>
> — 《思维模型》, 第2章 > 无意伤邻

---

## I — 方法论骨架 (Interpretation)

公共物品由两个特征定义：**广泛的可用性**（难以排除任何人使用）和**非竞争性**（一个人使用不显著减少他人的可用量）。国防、广播电视、空气是书中给出的例子——你没法把没付钱的人挡在国防保护之外，而你多呼吸一口空气也不影响别人。

这两个特征直接决定了它的脆弱性。因为难排他，理性个体会选择不付钱也能用；因为非竞争，每个人的"白用"对他人几乎没有可见损害。于是搭便车在公共物品上极其常见，供给方收不回成本，最终结果是供给不足甚至无人供给——这就是公共物品问题的核心，它也正是通向公地悲剧的入口。

因此书中给出的结论是：一旦公共物品供给不足，需要外部力量以税收、扩大专利保护、共同承担开发成本等方式去纠正。未来可能救命的新型抗生素就是一个例子：它的价值在于保护公众健康（公共物品属性），但私人市场价值极低，药企没有动力研发，所以需要政府设计激励机制，否则所有人都会搭便车、产量永远不足。

判据很简单：**能不能低成本地把不付费者挡在外面、多一个人用会不会挤占别人？** 两个都答"不能/不会"，你面对的就是公共物品。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断某项投入该由谁买单：行业共性技术、基础研究、开源基础设施、安全与合规。
2. 内部平台/中台建设：各业务线都在用，但没有一条线愿意单独出钱建。
3. 解释"明明社会价值巨大，市场却不供给"：如抗生素研发、公共数据、基础科研。
4. 设计供给机制：税收、强制分摊、专利延展、共同承担成本、政府补贴。
5. 判断一个东西该做成开放公共品还是收费产品。

### 语言信号

- "这个东西大家都需要，但没人愿意出钱建"
- "社会价值很大，但商业上算不过来账"
- "能不能做成公共的、开放的"
- "这个平台全公司都在用，成本该谁承担"
- "public goods / 公共品 / 基础设施 / 非竞争性 / 难排他"

### 与相邻 skill 的区分

- 与 `mm-free-rider-problem` 的区别: 公共物品是**对象**（难排他、非竞争的资源），搭便车是**行为**（不付成本白用）。顺序是先判定对象属性，再诊断行为；没有公共物品属性就没有搭便车问题。
- 与 `mm-tragedy-of-the-commons` 的区别: 公地悲剧的资源是**竞争性**的（你多放一头牛，别人的草就少一分），公共物品是**非竞争性**的（你多听一次广播，别人不受影响）。前者的问题是过度使用，后者的问题是供给不足。
- 与 `mm-externalities` 的区别: 外部性讲的是行为对第三方的未定价影响（可以是负的），公共物品讲的是物品本身的属性；二者常同时出现，但分析入口不同——前者看行为外溢，后者看物品属性。

## E — 可执行步骤 (Execution)

1. **用两个特征判定是不是公共物品**
   - 分别回答：能否低成本排他？一个人的使用是否明显减少他人可用量？
   - 完成标准: 两个问题都有明确答案。
   - 判停条件: 若任一答案为"能排他"或"明显挤占"，则不是（纯）公共物品，转一般的市场/定价分析。
2. **算清楚社会价值与私人价值的落差**
   - 分别估算：这件事对所有人的总价值，与对单个供给方可回收的价值。
   - 完成标准: 得出两个数字及其差额，并说明差额来自哪（搭便车者不付费）。
3. **确认供给不足是否正在发生**
   - 检查现有供给量是否显著低于社会最优（如研发投入停滞、基础设施年久失修）。
   - 完成标准: 至少一条可观测的供给不足证据。
4. **设计供给机制**
   - 书中给出的手段：政府以税收出资、扩大专利保护、共同承担开发成本；企业内则可做成本分摊、总部出资、强制使用费。
   - 完成标准: 每条机制都说明"钱从哪来、谁被迫不再搭便车"。
5. **为供给方建立可持续回报**
   - 让供给方的收益覆盖成本并可持续，否则纠正只是延缓枯竭。
   - 完成标准: 写出供给方的盈亏平衡路径。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 排他成本低、竞争性强（如一件商品、一次服务）：那是普通私人物品，套公共物品框架会得出错误的"必须政府/总部出资"结论。
- 讨论纯竞争战略（份额、定价战、差异化）：属性判定不对口，用市场支配力类模型更合适（推导，非书中明示）。
- 资源实际已拥挤（会拥堵的道路、会过载的服务器）：此时已具备竞争性，属于"拥挤型公共物品/公地"，应按公地悲剧处理（推导，非书中明示）。

### 容易误用的地方

- 书中未给出本模型的边界，以下为基于机制推导：把所有"有价值但赚不到钱"的事都归为公共物品。很多事赚不到钱是因为需求不足或模式不对，而非难排他（推导，非书中明示）。
- 认为公共物品只能由政府供给。书中说的是"需要某种外部干预"，并不限定形式，企业内部的总部出资、行业联盟共担也是同一思路（推导，非书中明示）。
- 忽略非竞争性会随规模消失：用户量达到容量上限后，公共物品会变成拥挤品，机制需要跟着变（推导，非书中明示）。
