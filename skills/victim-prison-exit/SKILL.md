# 故事囚牢：三角实时标注与脱离

> 本 skill 是**两册合并版**。第 1 册提供「为什么同一个模式换人换环境仍重演」的解释与出口；
> 第 2 册提供「在一段话之内实时标注自己站在哪个角落」的可执行动作，以及一个新的退出方式。
> 两册讲的是同一个模型（改编自卡普曼戏剧三角形），作者自己在第 2 册把它重写了一遍并加了退出路径。

>
> — 克里斯多福·孟，第 1 册 第四章 内省 · 受害者的监牢

## I — 方法论骨架 (Interpretation)

这是全书最难自我觉察的一层，因为它处理的不是**事件**，而是**你此刻在讲故事的哪个位置上**。

三个角落各有明确的内部定义，不要按字面理解成"三个人"：

- **受害者** = 你的核心信念（源自孩童时期对弱小身体的认同）。体验顺序是：先感到被遗弃 / 不配得 / 心碎中的一两项，之后是更深的无力、无助、无价值。作者指出，关系问题的**核心情绪成分通常是不配得**。
- **迫害者** = 愤怒地找坏家伙的那个部分。它对准伴侣，也常常**对准你自己**（攻击你的过错和弱点），还会扩大到每个相关的人、包括很久以前的旧人。
- **拯救者** = 与感觉脱离、改用理智逻辑分析、不断给建议的那个部分。它擅长编织错综复杂的故事来解释你为什么有这种感觉，却**"没有能力真正理解或回应感觉"**。作者对它的判词最狠：在关系议题上"**拯救者不是出路，从来都不是**"。他自曝"我甚至在拯救者的角落挂牌开业，当咨询师、工作坊导师和灵性老师"。

把它们串起来的，是**"为什么"这个自问**。问"为什么"，会同时激活三个角落：受害者（放大不堪重负）→ 迫害者（找东西指责）→ 拯救者（分析解释）→ 方案失败 → 退回受害者与迫害者 → 再回到拯救者。你会身不由己地跳，**但通常不断回到拯救者**。

所以本 skill 的操作核心不是"看清自己处在三角里"（那是常识自我判定），而是**实时按语言形态标注**：我现在这句话属于哪个角落。

两册的**真正差异在"问题是什么"**：

- 第 1 册说：问题是伪装的礼物，出口是**跳脱问题框架 + 百分百负责 + 单边行动**——任何单边行动都不需要对方配合。
- 第 2 册说：**问题根本不需要被解决**。问题只是**出租车**，它的用处是把你送到感觉的门口；一下车（进入感觉），故事就不重要了。而且作者明确否认"放下"——"**过程中不涉及放下**。放下是我们给自己讲的故事的一部分。"

最后是出口的动作差异：第 1 册是"选择不要再当一个受害者"；第 2 册是**逐个道谢后离开**——感谢拯救者给过鼓舞人心的体验，靠近迫害者并感谢它"无可挑剔地完成了本职工作"（它强化了"我是个无力的人"这个信念），然后走到受害者那里**拥抱它、不折不扣地接纳自己的脆弱性与人性**。不是摧毁这三个部分，是致谢后告辞。

## A1 — 书中的应用 (Past Application)

### 案例 1：肩膀酸痛的四个月（第 1 册，作者亲历）
- **问题**：某天早上醒来肩膀酸痛，之后四个月看遍医生都没好。
- **方法论的使用**：作者回头检视，发现自己一整天都在三角里轮换——先抱怨（受害者）→ 对生气并用力按摩（迫害者兼拯救者）→ 热水久冲（拯救者）→ 向妻子抱怨（受害者）→ 妻子替他按摩并怪罪床垫（进入她的拯救者/迫害者）→ 看按摩师、吃止痛药、被草药医师批评运动过度 → 物理治疗师说问题在胆囊 → 治两个月后说是心理层面、建议看心理咨询。
- **结论**：他想的全是"怎样让身体恢复正常"，完全忽略了身体要传达的信息。**所有这些都是拯救者动作，全部回避了真正的议题。**
- **结果**：脚注揭晓——肩膀和胆囊的问题，与他对父亲的愤怒有关，那份怒气一直压抑着。当他用诚挚的方式响应、原谅自己以及父亲，肩膀就不痛了。

### 案例 2：结婚三个月，妻子一走过我身边我就去找吸尘器（第 1 册，作者婚姻自述）
- **问题**：妻子怀孕初期身心不适，作者坐在桌前，妻子从身后经过，他立刻跳起来找吸尘器，打算大扫除后再洗碗、劈柴、折衣服。
- **方法论的使用**：追溯根源——七八岁时母亲很不快乐，他认定她的不快乐是自己的错，得出"让她开心起来是我的责任"。
- **结论**：二十五年后身边又出现一个不快乐的女性，他除了打扫房子想不出别的方案——**在了解自己的动机之前，潜意识已经驱使他去找吸尘器了**。
- **结果**：他由此定义**依附**：为确保不被离弃而把自己塑造成伴侣会喜欢的样子，"这根本不能算是结合，应该叫做奴役才对"。

### 案例 3：约翰忘了买鸡蛋（第 2 册，三角的实时换角演示）
- **问题**：玛丽一句"您买鸡蛋了吗？"，几句话之内升级到约翰低吼"我真希望我三个都做了！"，然后摔门而去。
- **方法论的使用**：作者把这段对话**原样重印了第二遍，逐句标注三个角落**。摘录连续几句即可见换角之密：
  > "好了，好了，我现在就出去买**（拯救者）**，"约翰说道，声音有点泄气**（受害者）**。
  >
  > "算了，晚饭马上就好了**（迫害者）**。我晚点再出去买吧**（受害者）**，反正你也很可能买错**（迫害者）**。"
>
> - **结论**：这段不到两百字的对话里，两人合计换位**二十余次**，且大量句子**同时占据两个角落**（书中直接标注"受害者/迫害者"）。这是本 skill 最硬的一条事实：**位置在一句话之内就会移动**——所以"我处在三角的哪个位置"这个问题本身提法就错了，要问的是"我**这句**在哪个位置"。
- **结果**：事后玛丽给姐姐珍妮打电话巨细无遗地复述，珍妮"过去十年一直在听玛丽的抱怨"，再把故事转述给自己的老公和特定的朋友家人。作者给这一幕的命名是——"**欢迎来到故事国度！**"

### 案例 4：作者自己走出囚牢（第 2 册，第四章结尾）
- **问题**：作者自述年轻时还是毛毛虫阶段，"我就是过不了反应这一关"，恐惧和愤怒让他猛烈抨击任何问题。
- **方法论的使用**：中年时他发现，"服务的根源是我自己在拯救者的角落找到了一处仙境"，于是**逐个道谢**：感谢拯救者给了许多鼓舞人心的体验 → 靠近迫害者、感谢它"无可挑剔地完成了本职工作"（强化了"我是个有局限的无力的人"这个信念）→ 走到受害者那里拥抱它、接纳自己的脆弱性与人性。
- **结论**：作者写道——"从那天开始，想改变我妻子的渴望消退了，而我对她的接纳和欣赏却与日俱增。"
- **结果**：他穿过"无门之门"时遇到的第一个人就是妻子——还是她十八岁的样子。**注意这是作者本人的灵性体验叙事，不是可复制的流程；它的可执行部分只有"致谢三个部分然后离开"这个动作。**

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. 一段对话或一次争执里，用户自己察觉到**角色在变**："我一开始是在跟他解释，不知道怎么就开始骂他了。"
2. 用户正在**分析、解释、给建议**，且讲得停不下来——自己在讲道理却觉得空虚。
3. 用户在追问"**为什么**"：为什么他这样对我 / 为什么这种事总发生在我身上。
4. 用户描述三角外的**观察者视角**："我知道我又在三角里了，但事情总得有人做啊。"
5. 长期觉得"我是被牺牲的那个"，付出与回报严重失衡且积怨已深。
6. 反复陷入同一种关系模式，换人换环境也没用。
7. 强烈地认定"都是他的错"，且这个判断让自己既愤怒又无力。

### 语言信号（用户的话里出现这些就应激活）

- "吵着吵着我就变成他那样了"
- "我又在替他收拾 / 我知道不该管但我忍不住"
- "凭什么总是我……"
- "不知不觉我就开始讲道理了"
- "为什么这会发生在我身上"
- "我说不上来刚才那句话是怎么变味的"
- "换了三份工作/两段关系，还是同样的**处境**"
- 英文：*I suddenly became the one attacking him* / *I keep rescuing him* / *why is it always me* / *I couldn't stop explaining* / *it's all his fault*

### 与相邻 skill 的区分

- 与 `eight-questions-communication` 的区别：那个处理**单次冲突的对话流程**（把这次谈完）；本 skill 处理**说话过程中位置的移动**。若用户说"我想跟他谈但怕谈崩" → 用那个；若用户说"谈着谈着我就变成指责他的人了" → 用本 skill。
- 与 `sacrifice-indulgence-pendulum` 的区别：那个处理**具体付出事项有没有喜悦**（家务、让步、育儿）；本 skill 处理**角色位置**。长期后再有多少件具体的事，都还是**受害者位的一种表现**。
- 与 `power-struggle-old-wound` 的区别：那个做**单次冲突的归因**（这次引爆了哪个旧痛）；本 skill 做**位置标注**。若能定位到具体旧伤 → 用那个；若描述的是长期身份感或此刻的话变形 → 用本 skill。
- 与 `relationship-purpose-inversion` 的区别：**"每一任都变成同一种人"用那个**，本 skill 只收**"换了人/换了环境，同样的处境仍重演"**。两者的差异：前者关注**对方的性质**，后者关注**自己的位置**。
- 与 `three-manipulation-modes` 的区别：那个判别**我从伴侣那里索取快乐的手法**（赚取/证明/索取）；本 skill 判别**此刻我在哪个角落**。索取阶段的强硬，常见的落脚点就是迫害者位，但不能反过来——拯救者位也是昂贵的索取手段。
- 与 `truth-based-communication` 的区别：那个做**开口前的五问自检**（我在防卫吗？我在投射吗？我诚实吗？）；本 skill 做**说出口之后位置的追踪**。开口前用那个，说崩了用本 skill。

## E — 可执行步骤 (Execution)

> **前置检查 0：安全筛查（不可跳过，也不用因为用户温和就略过）**
> 先判断这是**内心三角**还是**真实的外部加害**。方法：请用户举出**具体的、可被第三方观察到的事实**。
> - 能举出具体事实（被打、被威胁、经济被控制、社交被隔离、被系统性贬低、涉及儿童安全）→ **立即停止本 skill 的全部后续步骤**，转安全评估与专业转介。在真实加害关系中做"百分百负责"会造成严重二次伤害。
> - 举不出具体事实，或事实强度远小于情绪强度 → 继续。

1. **实时标注（本 skill 的核心动作，绝大多数人第一次就能做对）**
   - 请用户挑出刚才自己说的**一句话**，判断它属于哪个角落：
     - **受害者** —— 不堪重负、生气、焦虑、无力瘫痪感，加"为什么这会发生在我身上"
     - **迫害者** —— 指责、批评、评判、找毛病（对象可以是对方、**也可以是自己**）
     - **拯救者** —— 解释、分析、建议、讲道理、"我们应该怎么解决"
   - 完成标准：用户能在**一段对话里标出至少两次位置移动**。最常见的发现是"我以为我只有一个位置"。
   - 判停条件：若用户坚持"我一直是受害者，我从来没迫害过谁" —— 不要硬推，直接进入步骤 3（必要行为查验），怨气会在那里浮出来。

2. **揪出"为什么"（这一步后面各步才有效）**
   - 请用户把刚才的问句改成陈述：把"**为什么**他会这样 / **为什么**这种事发生在我身上" → 改成"**我在体验什么**"（被遗弃 / 不配得 / 心碎）。
   - 原理：作者原话——"'为什么'会导致谎言"。问"为什么"会同时原地启动三个角落。
   - 完成标准：用户能用**三道门中的一个词**命名此刻的体验。命名不了就退到步骤 4，不要强问。

3. **必要行为查验（本书没有写，是本 skill 为应对真实困境补的判据）**
   - 当用户说"我知道自己在三角里，但事情总得有人做啊"时，**不要**教他放下或退出。
   - 判据两条：**① 做的时候有没有怨气 ② 有没有让对方继续无能**。
     - 无怨气 + 未架空对方 = **功能性必要行为**（照护病患、育儿、危机处理），**不是**拯救者位，不必停。
     - 有怨气，或替他做让他越来越不做 = 这是真正的拯救者位置。
   - 完成标准：用户能明确指出是**两条判据中的哪一条**踩进了拯救者位；若是前者，本 skill 到此为止，转回照护安排本身。

4. **识别招募行为（长期模式才用）**
   - 问：为了让这出戏演下去，我**借助了谁来填补另外两个空缺**？（我扮演受害者，就把对方放到迫害者位；我扮演拯救者，就把对方放到受害者位。）
   - 完成标准：用户能指出至少一个"我把某人安排到了某个角色上"的具体动作。
   - 这一步是转折点——它把"我被动受害"改成"我在无意识地导演"。**只发现一次招募不算成果**，要看到反复性的模式。

5. **责任定位（十阶段量表，用于长期模式）**
   - 请用户在"责任态度的十个阶段"上标出位置：① 这是别人的责任 → ② 我应该负责但我不想 → …… → ⑩ 我创造了这个烂摊子，我百分百负责。
   - 完成标准：能说出一个具体级数并说明理由。
   - **重要**：不要要求用户跳到第十级。这个量表的价值是**诚实定位**，不是道德逼迫。**百分百负责 ≠ 百分百归咎**——负责指"我有能力回应（response-able）"，不是"这件事是我造成的"，这个区分每次都要讲清楚。

6. **跳脱问题框架（第 1 册）／故事只是出租车（第 2 册）**
   - 第 1 册路径：把"我该怎么解决这个问题"改成"我要长成什么样的人，才能让这个问题不再是个问题？"
   - 第 2 册路径：**问题不是待解决的东西，它只是把你送到感觉门口的出租车**。一旦进入感觉，故事不重要了。适用于用户已经讲了很多遍事情经过、却毫无进展时。
   - 完成标准：用户能说出**现在进场的是什么体验**（而不是理清了事情经过）。
   - **不要**说"你要学会放下"——作者明确：**过程中不涉及放下**。转向感觉，故事自己消失。

7. **单边行动（第 1 册的出口）**
   - 明确："**争吵需要两个人参与，要解决争执却只要一个人就够了。**"
   - 请用户选定一个**不需要任何人配合就能做**的动作。
   - 完成标准：执行条件 100% 在自己手里（例："我不再替他收拾"可以；"他得先道歉"不行）。

8. **致谢三个部分后离开（第 2 册的出口，与步骤 7 二选一即可）**
   - 不是摧毁、不是打败，而是**逐个道谢后离开**：感谢拯救者给过的体验 → 感谢迫害者"无可挑剔地完成了本职工作" → 走到受害者那里拥抱它、接纳自己的脆弱性与人性。
   - 完成标准：用户能分别对三个位置说出一句"谢谢你做了 ___"，并在说完后把注意力转回身体上的感觉（这一步接 `process-walk`）。
   - **判停条件**：若用户在此处开始"我应该更感恩"式的自我要求 → 立即停止，回到步骤 1。这一步的目的是松手，不是加一层功课。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **关系中存在身体暴力、威胁、破坏物品或阻挡去路** —— 立即停用，转安全评估。
- **存在监控、社交隔离、经济控制、限制人身自由** —— 同上。
- **涉及儿童、老人或无议价能力第三方的伤害或体罚分歧** —— 第 2 册第七章把"体罚孩子"列为普通分歧领域之一，全书对第三方零保护性说明，此处必须补上。
- **存在成瘾、长期欺骗、财务隐瞒** —— 第 2 册同样把它们列为普通分歧；用"走过程"处理会延误戒断与财务保护。
- **用户正在用"这是我的功课""他在帮我成长""这是我的梦"来解释正在发生的伤害** —— 这是最危险的信号，立即停用。
- **用户出现闪回、解离、惊恐发作、自杀意念，或因使用本方法中断了正在进行的专业治疗** —— 停止，转专业资源。
- **用户报告"看了三角之后我更觉得我该留下"** —— 这是奖励函数被劫持的确定性信号，立即停止向内归因。
- **真实的外部不公**（职场歧视、结构性压迫、制度性伤害）：把系统性不公诠释为内心三角，是对现实的遮蔽，也是责备受害者。
- **只需要资源或信息**（法律援助、经济支持、照护安排）：不要上框架，直接给资源。

### 作者在书中警告的失败模式

- **问"为什么"**：作者第一课就是"'为什么'会导致谎言"。这是入囚牢的启动按钮。
- **停在拯救者位**：这是最隐蔽的失败模式。拯救者擅长编织故事来解释感觉，"**却没有能力真正理解或回应感觉**"。作者本人在此角落"挂牌开业"了多年。
- **以为「放下故事」是步骤之一**：作者明确否认。**转向感觉，故事才消失；把放下当动作，等于又讲了新故事。**
- **在真实加害关系中做"百分百负责"**：会直接转化成"是我创造了这个烂摊子"，延迟离开、加重自责。
- **把三个角落当成三个人的立场**：它们是一个人心智的三个方面。识别为"谁在迫害谁"就退化成普通的人际归因，这是本 skill 最常见的误用。

### 作者的盲点 / 时代局限

- **两册立场冲突已由作者本人处理**（第 2 册第八章）：第 1 册把「百分百负责 / 百分百认错」设为出口准则；第 2 册作者收回了它——他写道，实现真正的伴侣关系"要求百分之百的诚实、百分之百的负责，还有百分之百认错的意愿"，而"**我从没有达到这样的标准，每当我在重要关系中产生什么冲突，这个标准就会悄悄地折磨我**"，并认出这是"应该"在幕后运转。
- **本册最危险的新主张：「你的伴侣完美地按剧本演出」「也许我是个木偶」**。责任取消是**双向的**——施害者完全可以引申为"我的暴力也是设计"。第 1 册没有这个风险，本册独有。
- **不可证伪的封闭系统**：第 2 册比第 1 册更封闭——走过程有用 = 你走对了；没用 = 你还在"自我改进号列车"上，或你还没到"入茧"阶段。这个结构无法被检验。步骤 1（实时标注，可立即验证）、步骤 3（必要行为双判据）、步骤 7（单边行动 100% 在自己手里）是仅有的三个客观把手，必须严格使用。
- **模型本身是心理学公共知识**：卡普曼戏剧三角形在原著已被作者承认是"改编"。本 skill 的真实增量只有两个——**实时按语言形态标注**，以及**作者自己添加的退出路径**（第 1 册没有出口）。如果把本技能讲成"介绍一下卡普曼三角"，它就没有价值。
- **立场利益绑定**：作者是工作坊导师，其商业模式依赖"痛苦有深层意义、需要被引导才能穿越"这一前提。第四章结尾那个"穿过无门之门遇到十八岁的妻子"的体验叙事，同时也是一个招生广告。
- **作者自己的划界不够**：他试图用"我只谈情绪不适，不谈身体伤害"来免责（第 2 册第二章），但① 精神虐待的核心伤害形态**正是情绪不适** ② 这个划界全书只出现一次 ③ 他把"身体伤害"设为唯一例外，等于宣布情绪领域没有例外 ④ **他自己没守住**——同章末尾他用掳走妻子并企图谋杀的敌方角色演示"连敌人也只是在演好自己的角色"。

### 容易混淆的邻近方法论

- **不是卡普曼三角的标准用法**：标准用法识别互动中的角色分配（谁在迫害谁）；作者把它**内化**了——三个角色都是你自己心智的方面，周遭的人只是被招募来填满另外两个位置。这是作者的独特增量。
- **不是"都是你的错"**：百分百负责不等于百分百**归咎**。
- **不是"别把自己当受害者就好"**：简单劝人"别当受害者"是有害的，它跳过步骤 1–4 的定位与查验，只留下道德要求。
- **不是要求你退出必要的照护**：见步骤 3。照护病患、育儿、危机处理中的必要行为不是拯救者位——判据是**有无怨气**与**是否让对方继续无能**。把这两条漏掉，本 skill 会让用户在该行动的地方抽身。
