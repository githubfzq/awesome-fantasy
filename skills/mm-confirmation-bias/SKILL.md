# 证实偏差（confirmation bias）

## R — 原文 (Reading)

> 人类收集和解释新信息时往往带有偏见，以此证实自己先前存在的观念，这种倾向被称为"证实偏差"（confirmation bias）。
>
> — 《思维模型》, 第1章 少犯错 > 进步总在葬礼后

---

## I — 方法论骨架 (Interpretation)

它有两个动作，不只有一个：

1. **收集时的偏见**: 主动去找支持自己结论的证据，不去找（或根本没想过去找）可能推翻它的证据。
2. **解释时的偏见**: 面对同一条中性甚至相反的证据，把它解释成支持自己的。

为什么这么顽固？因为**质疑自己的核心假设在心理上代价极高**。一个结论往往不只是结论，它还连着已经投入的时间、已经公开的表态、以及自我形象。推翻它要付三重代价，于是大脑默认选择保护它，而且这个选择是自动发生的——你不会意识到自己在筛选。

书中给了一个很有力的旁证：**局外人反而更容易做出突破**。颠覆行业的新公司常由行业外人士创立，科学突破常由领域外的人做出——不是因为他们更聪明，而是因为他们不深信现有范式（没什么要保护的）、也不怕声誉受损（没什么可损失的）。这从反面证明了证实偏差的根源是**心理投入**而非智力缺陷。

因此对抗它不能靠"我要客观"这种决心，必须靠结构：

- **灰度思考**: 在听完所有相关事实与论据前不下判断——没有结论，就没有要证实的结论。
- **魔鬼辩护人**: 刻意站在反方，为既定决策找反对理由。

关键判据（一问）：**我上一次主动去找能推翻自己结论的证据，是什么时候？** 答不上来，就说明正在偏差里。

---

## A1 — 书中的应用 (Past Application)

### 案例: 局外人的突破与"冈瓦纳陆桥"
- **问题**: 作者要说明证实偏差如何阻碍进步，以及为什么突破常常来自外部。
- **方法论的使用**: 两个对照。其一，作者指出许多颠覆行业的新公司由行业外人士创立、许多科学突破由领域外的人做出——因为局外人不深信现有范式，也不怕声誉受损，因而不必耗费心力保护既有结论。其二，作为反面，地质学家宁可坚持没有实证支持的"冈瓦纳陆桥"理论（假设曾存在连接大陆的陆地桥梁），也不愿深究魏格纳的大陆漂移说——为了不让既有框架崩塌，他们接受了一个证据更弱的替代解释。
- **结论**: 证实偏差的代价不是"看错一件事"，而是**为了保住一个结论，接受一个证据更弱的解释**。对抗它的工具不是更努力地思考，而是改变流程：灰度思考与魔鬼辩护人。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **用户已经站定一个结论，正在收集支持材料**: 想创业、想分手、想投资、想辞退某人、想证明某个判断——而且已经做了不少功课。
2. **需要评估一份论证是否可靠**: 对方给了一堆证据，需要看是不是只挑了有利的、反例去哪了。
3. **争论中双方都拿得出证据**: 典型的"各持己见"，需要看双方各自的搜索范围。
4. **复盘一个失败的判断**: 当初明明有预警信号，为什么没人当回事。
5. **做研究/调研/尽调时**: 需要主动设计反面证据的搜索路径。

### 语言信号 (用户的话里出现这些就应激活)

- "我查了很多资料，都支持我的想法"
- "有没有什么反面意见？" （且用户自己没找）
- "我觉得我已经想得很清楚了"
- "他们给的例子挺多的，但总觉得哪里不对"
- "当初明明有信号，怎么大家都没看见"
- "我是不是有点先入为主"
- "Am I being biased?" / "Let me play devil's advocate." / "What would prove me wrong?"

### 与相邻 skill 的区分

- 与 `mm-thinking-gray` 的区别: 灰度思考是**预防**手段——推迟判断，让结论尚未形成，因而无从证实；证实偏差是**病症**本身。书中把灰度思考明确列为对抗证实偏差的工具之一。
- 与 `mm-devil-s-advocate-position` 的区别: 魔鬼辩护人是**治疗**手段——在结论已形成后，刻意从反方攻击它；同样被书中列为对抗证实偏差的工具。灰度是事前，魔鬼辩护人是事后。
- 与 `mm-paradigm-shift` 的区别: 范式转换是**共同体层面**的现象（一个领域集体忽略反常）；证实偏差是其得以维持的**个体心理机制**。规模不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **显性化当前结论与其来源**
   - 完成标准: 写出用户当前持有的那个结论，以及它形成的时间与依据。明确标注用户在其上投入了什么（时间、金钱、公开表态、身份认同）——投入越重，偏差风险越高。
2. **审计已有证据的收集方式**
   - 完成标准: 把已收集的证据分成"支持/中性/反对"三堆，并检查搜索路径：用户是**主动去找过**反对证据，还是只是在支持性材料里没遇到？若从未主动搜索过反面，明确指出这是偏差的强信号。
3. **强制构造反面证据搜索**
   - 完成标准: 写出 3 条**能推翻该结论**的具体条件（"如果 X 成立，我的结论就错了"），并针对每一条去查找现实证据，而不是想象中的反例。
   - 判停条件: 若这 3 条根本无法被检验，说明结论不可证伪，明确告知用户这已不是证实偏差问题而是论证无效。
4. **用魔鬼辩护人攻击结论**
   - 完成标准: 以最强而非最弱的形式陈述反方论点（书中引用芒格："如果我不比对方更了解他的论点，就绝不允许自己发表任何意见"），并试着比对方更好地陈述它。
5. **检查解释环节（不只是收集环节）**
   - 完成标准: 挑出 1-2 条中性或轻微相反的证据，检查用户有没有把它解释成支持自己的。若有，明确标出这种重新解释。
6. **输出修正后的结论与置信度**
   - 完成标准: 给出保留/修正/推翻的明确判断、修正后的置信度，以及"什么证据出现会让我改变"的具体条件。
   - 判停条件: 若结论已被强证据（对照实验、可重复数据）锁定，停止，不要为了"平衡"而人为削弱它。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **需要快速行动时**: 证实偏差校正需要时间与搜索成本。紧急情况下先按最佳判断行动，事后复盘再校正。
- **结论已被强证据锁定时**: 有随机对照实验、可重复数据、直接观测支撑的结论，不必为了显得客观而人为保留怀疑空间。
- **纯表达与情感支持场景**: 用户只是在倾诉，不需要被挑战证据链。

### 书中警告的失败模式 / 容易误用的地方

- **书中未给明确边界，但给了两个对抗工具：灰度思考与魔鬼辩护人**（`boundary` 字段原文）。也就是说，作者的处理方式是流程化的，而不是靠提高自觉。
- （推导, 非书中明示）**只用于攻击别人**: 最常见的误用是拿"你有证实偏差"去否定对方，而对自己的结论不施加同样的检验。本 skill 必须首先施加于用户自己的结论。
- （推导, 非书中明示）**假装寻找反证**: 找一堆稻草人式的弱反例然后轻松驳倒，不等于搜索了反面证据。第 4 步要求以最强形式陈述反方。
- （推导, 非书中明示）**用偏差怀疑一切**: 不能因为"人都有证实偏差"就认为所有结论都同等可疑。证据强度才是判据。

### 容易混淆的邻近模型

- **不证实偏差（disconfirmation-bias）**: 指对**自己不喜欢的**结论施加更严格的证据标准——是证实偏差的镜像，常同时出现。
- **动机性推理（motivated reasoning）**: 是证实偏差的上位概念，包含"为了达成某个情感目标而推理"；证实偏差特指围绕既有观念的证据处理。
