# 市场失灵（market failure）

## R — 原文 (Reading)

> "市场失灵"指的是，在没有外部干预的情况下，开放市场会产生次优结果，或者说失灵。为了纠正市场失灵，必须有某个外部力量通过某种方式进行干预。
>
> — 《思维模型》, 第2章 > 危险行业

---

## I — 方法论骨架 (Interpretation)

市场失灵是一个**判定**，不是一个解释：在没有外部干预时，开放市场自行运转的结果比它本来能达到的更差。它说的是"这个市场自己走不到好结果"，因此必须有某个外部力量介入。

要注意它只是一张**入场券**：它论证了干预的必要性，却**不指定干预形式**。管制、税收、补贴、产权界定、可交易许可，都可能是对的解法，也可能都是错的。判断失灵只是第一步。

书中列了若干典型征兆：公地悲剧（资源被过度使用）、外部性（成本或收益没有被定价）、道德风险（风险由别人承担）、信息不对称（一方比另一方知道得多）。抗生素的例子很典型：过度使用导致抗药性普及，这是负外部性；而新型抗生素的社会价值（约 5000 亿美元）与私人市场价值（对耳部感染实为负数）严重脱节，是第二种失灵，结果是大药企停止研发。

关键判据：**有没有人的成本/收益没有被计入交易价格，或者有没有人无法进入这个市场？** 前者是外部性，后者是公共品与信息问题。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 讨论某个行业要不要监管、能不能靠自律（环保、平台、金融、医疗）。
2. 观察到资源被过度使用（渔场、草场、带宽、公共设施、注意力）。
3. 一个社会价值很高但没人愿意做的东西供给不足（基础研究、罕见病药、公共基础设施）。
4. 用户问"这到底是企业的问题还是市场机制的问题"。
5. 准备设计干预方案前，先确认失灵真的存在且类型正确。

### 语言信号
- "这个靠市场自己解决不了吧"
- "是不是该出政策管一管"
- "大家都这么做，最后谁都没得用"
- "明明社会很需要，但没公司愿意做"
- "成本是别人在承担"
- "market failure / needs regulation / tragedy of the commons / free rider"

### 与相邻 skill 的区分
- 与 `mm-government-failure` 的区别: 市场失灵是"市场自己走不到好结果"，政府失灵是"纠正它的干预本身也失灵"；两者是前后相继的检查项，作者明确要求看完前者必须看后者。
- 与 `mm-externalities` 的区别: 外部性是市场失灵的**一种具体成因**（成本收益没有被定价），本 skill 是**总判定**，涵盖外部性、公地悲剧、道德风险、信息不对称等多种征兆。
- 与 `mm-tragedy-of-the-commons` 的区别: 公地悲剧是共享资源被过度使用这一种失灵形态，本 skill 是它所属的更大类目。
- 与 `mm-moral-hazard` 的区别: 道德风险是"风险与回报分属不同实体"导致的失灵，本 skill 把它列为征兆之一，不负责具体机制分析。

## E — 可执行步骤 (Execution)

1. **先排除"这只是你不喜欢的结果"**
   - 问：结果是低效的（有改进空间且没人得利受损），还是只是分配不合你意？
   - 完成标准: 说明这个结果为什么是"次优"——存在一种能让至少一方更好而无人更差的安排。
   - 判停条件: 若只是分配争议，退出本 skill，那是价值判断不是失灵。
2. **给失灵归类**
   - 逐项排查：负外部性、正外部性（供给不足）、公地悲剧、信息不对称、道德风险、市场支配力（垄断/进入壁垒）。
   - 完成标准: 指出主类型，并列出可能叠加的次类型。
3. **定位"没被定价的那一项"**
   - 写清：谁的什么成本/收益，没有进入谁的决策。
   - 完成标准: 一句完整的"X 的 Y 成本由 Z 承担，且 Z 未获补偿"。
4. **量化失灵的规模**
   - 用粗略估算给出量级：受影响的规模 × 单位损害。
   - 完成标准: 得到一个数量级数字，用于判断值不值得干预。
5. **确认市场自身是否已无解**
   - 检查：有没有私人方案正在出现（认证、合约、纵向整合、品牌溢价）？
   - 完成标准: 说明为什么私人方案不够（交易成本过高、产权无法界定、搭便车）。
6. **转交干预设计，并强制做政府失灵检查**
   - 完成标准: 明确写出"接下来要设计干预，且必须同步做 mm-government-failure 检查"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 结果只是不合你意但资源配置是有效的：那是分配偏好问题，不是失灵。
- 市场已经在自我修正（新技术、新合约、新中介正在出现）：过早干预会锁死更优解（推导，非书中明示）。
- 用户已经在问"用哪种方式干预"：此时应直接进入干预工具设计，不必再论证失灵是否存在。

### 容易误用的地方
- 作者明确提醒：纠正市场失灵的干预本身也可能失灵（见政府失灵）。**判定失灵不等于证明了某个具体干预是对的**——这是本 skill 最容易被越界的地方（书中明示）。
- 把"有外部性"直接等同于"必须政府管制"：书中指出干预形式可以是管制，也可以是科斯式的市场方案（如总量控制与交易）（书中明示）。
- 用市场失灵解释一切不满意的价格：高价可能来自稀缺或竞争不足，需先区分成因（推导，非书中明示）。
