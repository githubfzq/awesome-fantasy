# 效用值（utility values）

## R — 原文 (Reading)

> 由于这些新数值不仅仅包含你需要支付的成本，所以它们被称为效用值（utility values），反映了你在各种情况下的总体相对偏好。
>
> — 《思维模型》, 第6章 > 化繁为简

---

## I — 方法论骨架 (Interpretation)

效用值是把**有形与无形的成本收益合并成的一个数**，它反映你在该情境下的**总体相对偏好**，而不只是你要付多少钱。

它解决的是决策树/成本收益分析里最常见的一个漏洞：很多真正影响决策的东西没有市场价格。书中给了两个例子：

- 两场**票价相同**的演唱会，你偏爱的那场给你更多"效用"——同样的钱，不同的满足。
- 催促承包商的**焦虑与麻烦**是"失去效用"带来的额外成本——它不出现在账单上，但真实存在。

做法是把这些额外负担**按主观价值"计入"（price in）决策树的树叶**。于是每个结果最后只剩一个数，可以直接比较和求期望。

书中泳池派对的案例展示了它的威力——**纳入效用后结论直接反转**：

- 承包商拖延两周：多付 500 美元之外，担忧与催促值 1000 美元 → 该结果从 2500 美元升到 **3500 美元**
- 搞砸要重做：从 3000 美元升到 **5000 美元**
- 结论：新承包商"搞砸"那一支的代价从 3000 升到 5000，**应选旧承包商**

作者也诚实承认了它的短板：**效用值可能难以估算**（功利主义的弊端之一）。但他仍建议尽可能使用，因为它能反映你的真实偏好、带来更满意的决策。

关键判据：**当两个方案在金钱上接近、但你心里明显偏向某一个时，那个偏差就是还没被计价的效用差——把它估出来，而不是忽略它。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 两个方案价格/成本接近，但直觉上明显更想选某一个，说不清为什么。
2. 决策中含大量无形成本：要催促、要谈判、要担责、会得罪人、会焦虑。
3. 在决策树或成本收益分析里，某些分支"感觉很差"但账面上看不出差别。
4. 纠结"便宜但麻烦"和"贵但省心"这类经典取舍。
5. 团队决策中，各方对"值不值"的判断无法用统一尺度比较。

### 语言信号

- "便宜是便宜，但太折腾了"
- "多花点钱买个省心"
- "这个虽然省钱，但我一想到要盯就烦"
- "焦虑和麻烦这些怎么算进成本"
- "账面上差不多，但我就是不想选那个"
- "peace of mind is worth something / price in the hassle"

### 与相邻 skill 的区分

- 与 `mm-cost-benefit-analysis` 的区别: 成本收益分析是**加总与比较的框架**，效用值是填进这个框架的**计价单位**。当成本收益表里有条目无法定价时，就需要效用值来补位。
- 与 `mm-decision-tree` 的区别: 决策树提供**分支结构与概率**，效用值提供**树叶上的数值**。书中的应用场景正是"把效用计入决策树的树叶"，两者是配套的。
- 与 `mm-expected-value` 的区别: 期望值是**对已定价结果做概率加权**；效用值解决的是**定价本身**（尤其是无形项）。先有效用值，期望值才算得对。

## E — 可执行步骤 (Execution)

1. **列出所有结果，标出哪些只有金钱成本、哪些还有无形得失**
   - 完成标准: 每个结果都被标注"纯金钱"或"含无形项"，无形项被具体写出（焦虑、麻烦、声誉、时间、关系损耗）。
2. **对每个无形项问：我愿意付多少钱来避免它？**
   - 用替换检验：如果要多花 X 元就能彻底免除这个麻烦，X 到多少你会愿意付？
   - 完成标准: 每个无形项得到一个主观货币估值，并注明这是主观值而非市价。
   - 判停条件: 若某项实在无法估值，不要强行编数字，改为标注"未计价项"并在最终结论中单独列出。
3. **把估值加回对应的结果，得到每个结果的效用值**
   - 有形成本 + 无形项估值 = 效用值。
   - 完成标准: 每个结果只剩一个数（如书中：2500 → 3500 美元；3000 → 5000 美元）。
4. **重算期望值并检查结论是否翻转**
   - 完成标准: 明确说明纳入效用后最优方案是否改变（书中案例：从选新承包商翻转为选旧承包商）。
   - 判停条件: 若结论未变，说明无形项不足以影响决策，可说明后简化处理。
5. **做一次敏感性检查**
   - 问：我的主观估值要差多少，结论才会变回去？
   - 完成标准: 指出结论对哪个估值最敏感，提醒用户重点核对那一项。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 所有因素都有明确市场价格、且用户不关心无形项：直接比价即可，引入效用值是多余的复杂度（推导，非书中明示）。
- 用户明确拒绝把主观感受量化（认为某些东西不可估价）：强行赋值会引发抵触，此时应改为定性并列呈现（推导，非书中明示）。

### 容易误用的地方

- 书中明示的局限：**效用值可能难以估算**（功利主义的弊端之一）。作者仍建议尽可能使用，因为它能反映真实偏好、带来更满意的决策。
- （推导，非书中明示）容易给出虚假的精确度：把焦虑标成"1000 美元"看起来客观，实际是主观估计。应保留数量级意识并做敏感性检查（步骤 5）。
- （推导，非书中明示）容易只给好处估值、忘了给"省心""声誉""心情"这些正向效用也计价。无形项不只有成本。

### 容易混淆的邻近模型

- 期望值（expected-value）：对已定价结果的概率加权，是本 skill 的下游步骤。
- 机会成本（opportunity-cost）：有明确市价的放弃项；效用值处理的是没有市价的那部分。
