# 效忠者 vs. 雇佣兵（loyalists versus mercenaries）

## R — 原文 (Reading)

> 即使面对逆境，效忠者也会致力于促进组织发展。相比之下，雇佣兵主要是为了赚钱，所以更有可能离开组织，去寻求更大的回报。
>
> — 《思维模型》, 第8章 > 携手共进

---

## I — 方法论骨架 (Interpretation)

这是给团队成员做的一个二分：**效忠者**在逆境中仍致力于组织发展；**雇佣兵**主要为钱工作，遇到更高回报就走。

关键不在于给个人贴标签（同一个人在这家公司是效忠者、在那家可能是雇佣兵），而在于：**这是一个可被组织行为改变的状态变量**。弗雷德·威尔逊给出了吸引效忠者的四个要素：

1. **领导力**——人们忠于自己深信的领导者。
2. **使命**——有人为此放弃 2~3 倍薪酬。
3. **价值观和文化**——人希望在适合自己的地方工作。
4. **地点**——在湾区与纽约，员工持续被更高的金钱、股权、上升空间、职权诱惑；在卢布尔雅那、滑铁卢、匹兹堡这类地方建公司，更可能拥有效忠者。

**为什么成立**：雇佣兵只对价格敏感，而价格竞争你永远赢不了——总有人出得起更高价。效忠者对使命、领导者、文化归属敏感，这些是**不可比价**的，因此才是可持续的留人机制。这也解释了书中的观察：出类拔萃的人才愿意放弃 2~3 倍薪酬，只因相信自己在做的事。

**关键判据**：作者给得很明确——**如果你想长期拥有十倍团队，打造文化应当是首要目标**，因为文化是吸引和留住效忠者的关键。反过来说，如果你发现自己只能靠加薪留人，说明前三个要素已经失效了。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 核心员工被竞对高薪挖走，用户在纠结要不要跟价。
2. 团队流失率高，且离职原因都写着"薪酬"，用户考虑整体涨薪。
3. 要长期搭一支能打的团队，问"怎么才能让人留下来"。
4. 创业选办公地点/招聘城市，考虑人才稳定性。
5. 新任管理者接手团队，想知道前任留下的是效忠者还是雇佣兵。
6. 公司处在逆境（融资不顺、业务下滑），担心人心涣散。

### 语言信号 (用户的话里出现这些就应激活)

- "核心开发被挖走了，要不要跟价留"
- "离职面谈都说钱少，是不是该集体涨薪"
- "怎么让团队愿意长期待下去"
- "大家就是为了拿工资，一点主人翁意识都没有"
- "公司现在困难，我怕人跑光"
- "我们在哪个城市招人更稳定"
- "loyalists or mercenaries / how do we retain top talent / outbid the offer"

### 与相邻 skill 的区分

- 与 `mm-cultural-dimensions` 的区别: 文化维度谱系是**刻画文化**的坐标工具（严密/松散等四组）；本 skill 把文化当作**吸引效忠者的四要素之一**，是目的导向的用法。前者是描述，后者是留人策略。
- 与 `mm-culture-eats-strategy-for-breakfast` 的区别: 那句名言讲文化的**优先级高于战略**；本 skill 进一步给出"文化是吸引和留住效忠者的关键"这一具体机制，并补上领导力、使命、地点三个要素。
- 与 `mm-hypergrowth-dilutes-culture` 的区别: 超速增长稀释文化讲的是**文化怎么被冲淡**（一年内规模扩大过半，太多未融入的新人）；本 skill 讲的是**文化用来干什么**（吸引效忠者）。前者是文化的失败模式，后者是文化的功能。
- 与 `mm-aligning-incentives` 的区别: 激励一致是让**自利行为支持目标**的制度设计；本 skill 指出单靠钱（激励）只能吸引雇佣兵，还需要使命与文化这类非价格要素。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先判断本次要处理的是"留谁"还是"为什么留不住"**
   - 完成标准: 明确是个案（某个具体的人要走）还是结构性问题（流失率/整体心态）。
   - 判停条件: 若是纯薪酬带宽与市场对标问题，转薪酬设计，不启动本 skill。
2. **对关键成员逐个定性：效忠者还是雇佣兵**
   - 完成标准: 每人给出判断 + 依据。判据是行为而非表态：逆境时的反应、主动承担份外事的情况、谈论工作时的焦点（事情本身 vs. 报酬与职级）。至少覆盖核心成员。
3. **用四要素逐项诊断吸引力缺口**
   - 完成标准: 对领导力、使命、价值观和文化、地点四项逐一给出"当前状态 / 具体缺口"，每项都要落到可观察的事实（如"使命：公司没人能说清我们为什么存在"）。
4. **先补非价格要素，再谈钱**
   - 完成标准: 针对缺口给出 2-3 个具体动作（如领导者增加一对一与方向宣讲、明确并反复讲使命、调整招聘城市策略）。明确说明：若只能靠加薪留人，说明前三要素已失效，跟价只能买到时间。
5. **对个案给出具体处置**
   - 完成标准: 若对方是雇佣兵且已拿更高报价，明确建议"不必跟价，做好交接与知识转移"；若对方是效忠者却在走，优先用领导力与使命层面的对话挽留，而非只谈钱。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 短期项目制、外包、季节性用工——本来就是雇佣兵结构，谈效忠是错配。
- 薪酬确实显著低于市场——先解决公平性问题，谈使命感会显得虚伪。
- 组织本身在剥削员工（欠薪、无底线加班）——此时谈忠诚是道德问题不是管理问题。
- 用于给员工的合理薪酬诉求贴"雇佣兵"标签来压制——这是模型最常见的滥用。

### 容易误用的地方

- （推导, 非书中明示）把效忠者/雇佣兵当成**人的固定属性**。书中的四要素框架表明这是状态变量：同一个人换个领导者、换个使命，归属可能完全不同。
- （推导, 非书中明示）用"不给高薪"来合理化低薪。书中说的是有人**主动放弃** 2~3 倍薪酬，前提是他们本来就值那个价。这不是压薪的依据。
- （推导, 非书中明示）认为雇佣兵毫无价值。某些阶段（冷启动、明确的一次性任务）雇佣兵是合适的，模型没有说组织里只能有效忠者。
- （推导, 非书中明示）忽略地点这一要素的可操作性有限：公司已在大都市时，"搬去小城市"通常不是可行动作，此时更现实的替代是减少与本地高价机会的对比暴露。
- 书中未给本模型的边界说明，以上除标注外均为基于机制推导。

### 容易混淆的邻近模型

- **超速增长稀释文化**: 描述文化被冲淡的机制；本 skill 说明文化被冲淡后留不住效忠者的后果。
- **激励一致（aligning incentives）**: 用制度让自利支持目标；本 skill 指出纯金钱激励的天花板。
