# 荟萃分析（meta-analysis）

## R — 原文 (Reading)

> 有些（但并非全部）系统综述包含荟萃分析（meta analysis），也就是运用统计技巧将来自多项研究的数据纳入一次分析。
>
> — 《思维模型》, 第5章 > 能否重现

---

## I — 方法论骨架 (Interpretation)

荟萃分析是**用统计技巧把多项研究的数据合并进一次分析**，从而得到一个比任何单项研究都更可靠的总体估计。

它的机制非常直接：**合并数据等于放大样本量**。样本量变大，标准误差变小、置信区间变窄，于是能检出单项研究测不出来的较小效应。这本质上就是样本量权衡在多研究层面的应用。

书中最直观的例子是 FiveThirtyEight 对民调数据做荟萃分析，以更好地预测大选结果——单份民调误差范围大且互相矛盾，汇总之后精度显著提升。

需要厘清的关系：**系统综述是"找全研究"的流程，荟萃分析是"合并数据"的技巧。** 书里说得清楚——有些但并非全部系统综述包含荟萃分析。两者是包含关系，不是同义词。

作者列出了三条明确缺陷，决定了它的能力上限：

1. **各研究设计或样本差异太大时，合并会出问题**（异质性）。
2. **无法消除原始研究本身的认知偏差**——垃圾进，垃圾出。
3. **受发表偏倚影响**：只能涵盖已发表的结果，没发表的研究进不来。

关键判据：**合并前先问"这些研究是在测同一个东西吗"。** 设计、样本、测量方式差异过大时，合并出来的数字是精确但无意义的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 同一问题已有多个独立研究/多次 A/B 测试，想得到总体效应量。
2. 单项研究样本小、结论不稳定，希望通过合并提升精度。
3. 多份民调/多份预测互相矛盾，需要汇总出一个更可靠的估计。
4. 评审他人做的荟萃分析，需要检查其是否可信。
5. 决定是否值得为某个问题投入新研究（先看现有证据合并后是否已足够）。

### 语言信号

- "能不能把这些研究的结果合并起来看"
- "每项研究都不显著，放一起会不会显著"
- "总体效果到底有多大"
- "这几份民调该信哪个"
- "异质性太高还能合并吗"
- "pool the results / combined effect size / forest plot"

### 与相邻 skill 的区分

- 与 `mm-systematic-review` 的区别: 系统综述是**找全并评估研究**的流程，荟萃分析是**合并数据**的统计技巧。前者可以独立存在，后者通常嵌在前者之中（书中明示：有些但并非全部系统综述包含荟萃分析）。
- 与 `mm-publication-bias` 的区别: 发表偏倚是荟萃分析**无法克服**的三大缺陷之一；荟萃分析能缩小随机误差，却修不了"没发表的研究看不见"这个系统性缺口。
- 与 `mm-sample-size` 的区别: 样本量权衡讨论**单项研究**里精度与成本的取舍；荟萃分析通过合并**跨研究**地获得样本量，是绕开单项成本限制的一条路。

## E — 可执行步骤 (Execution)

1. **确认合并的前提：这些研究在测同一个东西**
   - 检查：研究对象、干预/暴露、对照、结局指标是否可比。
   - 完成标准: 明确判定"可合并"或"异质性过大，只能做描述性综合"。
   - 判停条件: 若设计或样本差异太大，停止合并，改为叙述性总结并说明原因（书中明示缺陷一）。
2. **系统找全研究，而不是挑手边这几项**
   - 完成标准: 检索方案与纳入排除标准已事先确定，可被第三方复现。
   - 判停条件: 若只是随手挑了几个研究，结论不可靠，先回到系统综述流程。
3. **提取效应量与样本量，按精度加权合并**
   - 样本大、误差小的研究给更大权重；不要做简单平均。
   - 完成标准: 给出合并效应量及其置信区间。
4. **检验异质性**
   - 问：各研究结果的差异是否超出随机误差能解释的范围？
   - 完成标准: 给出异质性判断；若异质性高，改用随机效应模型或放弃单一合并值。
5. **检查发表偏倚，并标注结论的确定性**
   - 询问是否存在未发表研究、检查效应量与样本量的分布形态。
   - 完成标准: 明确写出"受发表偏倚影响的可能性"与"原始研究偏差无法被本方法消除"这两条保留意见。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 只有一两项研究：没有可合并的对象（推导，非书中明示）。
- 研究间设计、样本、测量差异过大：合并会出问题，应改为描述性综合（书中明示缺陷一）。
- 想修复原始研究的缺陷：荟萃分析做不到，它只缩小随机误差（推导，非书中明示）。

### 容易误用的地方

- 书中明示缺陷一：**各研究设计或样本差异太大时合并会出问题**。
- 书中明示缺陷二：**无法消除原始研究本身的认知偏差**。合并不会让有偏的研究变正确。
- 书中明示缺陷三：**受发表偏倚影响**，只能涵盖已发表的结果。
- （推导，非书中明示）容易把"合并后置信区间更窄"误当成"结论更正确"。窄的区间只代表随机误差小，如果原始研究有系统性偏差，区间越窄只是越精确地指向错误的答案。

### 容易混淆的邻近模型

- 系统综述（systematic-review）：找全研究的流程，可包含也可不包含荟萃分析。
- 发表偏倚（publication-bias）：荟萃分析最主要的系统性威胁。
