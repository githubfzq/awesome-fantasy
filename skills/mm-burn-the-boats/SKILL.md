# 破釜沉舟／越过卢比孔河（burn the boats / crossing the Rubicon）

## R — 原文 (Reading)

> "破釜沉舟"（burn the boats，直译"烧毁船只"）仍被视为自绝退路（crossing the point of no return）的方式之一。有时候，人们也会称之为"越过卢比孔河"（crossing the Rubicon）。
>
> — 《思维模型》, 第7章 > 终局

---

## I — 方法论骨架 (Interpretation)

故事原型是两个：1519 年科尔特斯率 600 人登陆墨西哥后弄沉船只，士兵们知道回不去了，只能打赢阿兹特克帝国；公元前 49 年恺撒率军越过卢比孔河，等于向罗马元老院宣战，再无回头路。

机制很直接：**当"撤退"仍然是一个可选策略时，人在困难时刻会持续计算"要不要撤"**，这个持续的内心计算本身消耗注意力与士气，并且让团队保留一份"不必全力以赴"的余地。移除退路后，这个选项从决策空间里消失，所有资源被压向唯一出路。

用博弈论的语言说，这是一个**公开且不可逆的承诺（commitment）**：它不只改变你自己的心态，也改变对手的预期——对手知道你不会退，他的收益矩阵随之改变（这正是它与威慑的连接）。

它的代价同样直接：承诺模型能提升胜率，但**不能改变基础概率**。如果方向本身是错的，破釜沉舟只是让你更高效地抵达失败。

关键判据有两条：
1. **方向是否已经充分验证？** 未验证就自绝退路，是把探索押成赌博。
2. **失败后的处境我能否承受？** 破釜沉舟适用于"失败会痛但能重建"的情形，不适用于"失败即毁灭"。

作者特别澄清：科尔特斯是**使船沉没**而非烧毁（"burn the boats"是翻译遗留），且与"过河拆桥"方向相反——前者主动切断自己的退路以激励团队向前，后者是破坏与他人的关系。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在犹豫要不要辞职全职做自己的项目，觉得"留着工作就永远做不成"。
2. 想公开宣布一个激进的产品截止日或转型决定，逼团队背水一战。
3. 考虑砍掉旧产品线/旧版本，把所有资源压在新方向上。
4. 个人决策：要不要退学、搬家、结束一段关系来"逼自己一把"。
5. 用户在激情状态下说"我要不留退路"，需要判断是决心还是冲动。

### 语言信号 (用户的话里出现这些就应激活)

- "我想把工作辞了专心做这个"
- "不给自己留后路"
- "背水一战 / 没有退路才能赢"
- "打算公开承诺一个激进的时间点"
- "我要把旧的全部砍掉，只做新的"
- "burn the boats / cross the Rubicon / no way back / all in"

### 与相邻 skill 的区分

- 与 `mm-burning-bridges` 的区别: **方向相反，书中最重要的澄清。** 破釜沉舟是主动切断**自己的退路**以向前，是策略；过河拆桥是退出时破坏**与他人的关系**，是失误。判断方法：被毁掉的是"我的退路"还是"我与人的关系"。
- 与 `mm-commitment` 的区别: 承诺是通用模型（事前自我约束以提升可信度与执行力）；破釜沉舟是承诺最极端的形式——不可逆、公开、单点。
- 与 `mm-forcing-function` 的区别: 强制函数是**用机制制造行动压力**（如设定截止日、公开排队）；破釜沉舟是强制函数的一种极端实现，区别在于是否不可逆。
- 与 `mm-scorched-earth` 的区别: 焦土毁的是**资源**（谁都用不了，含自己），动机是报复或掩盖；破釜沉舟毁的是**退路**，动机是凝聚与向前。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先验证方向，再谈断退路**
   - 完成标准: 列出支持这个方向的 2-3 条**外部证据**（已付费用户、已验证的需求、已有收入、他人承诺），而不是内部热情。
   - 判停条件: 若拿不出外部证据，明确建议不要破釜沉舟，改用可逆的小步验证。
2. **确认可逆性代价**
   - 完成标准: 回答"如果失败，我退回到哪、需要多久恢复"。若答案是"无法恢复"（法律、健康、家庭基本保障），判定不适用，停止。
3. **区分要断的是"退路"还是"关系"**
   - 完成标准: 明确写出准备切断的东西。若是退路（时间、资金、旧方案）——继续；若是关系（与同事、合作方、家人）——改用 `mm-burning-bridges` 重新评估。
4. **选择最小不可逆剂量**
   - 完成标准: 给出 2-3 个强度递减的方案（例：从"每周投入 20 小时 + 公开截止日"到"全职 + 公开宣布"），推荐能达到同样凝聚效果但可逆性最强的那一档。
5. **设计对外表达**
   - 完成标准: 若是公开承诺，写下一句具体、有日期、可验证的宣告，并明确它向团队和对手传递的信息。
6. **设失败判定点**
   - 完成标准: 即使退路已断，仍要设定"什么信号出现说明方向错了"的观测指标与转向规则——断退路不等于放弃纠偏。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 方向尚未被任何外部证据验证——此时应小步试错，破釜沉舟只会提高失败的效率。
- 失败后果不可逆或威胁基本生存（健康、家庭、法律、他人利益）。
- 环境高度不确定、需要保留多个选项（早期探索、多变市场）——与"保留可能性"直接冲突。
- 用户在情绪高峰（愤怒、被羞辱后、刚受刺激）做出的决定——先降温 48 小时再评估。

### 容易误用的地方

- 书中明示：作者澄清两点——科尔特斯是**使船沉没**而非烧毁（"burn the boats"为翻译遗留）；此战术与"过河拆桥"方向相反（前者主动切断自己的退路以激励团队，后者破坏关系）。这是最容易被混淆的一处。
- 书中未给其他边界；以下为推导（推导, 非书中明示）。
- 破釜沉舟提升的是**执行强度**，不是**方向正确性**。它是最容易被误用的"决心替代品"——用不可逆的牺牲来代替对这个方向的认真验证。
- 对团队而言，领导者断自己的退路是激励，断**别人的**退路是胁迫。若受影响的人没有参与这个决定，这个动作会摧毁信任。
- 幸存者偏差：科尔特斯和恺撒都赢了，所以他们的故事被留下。历史上沉船后全军覆没的例子不会被写进教科书。

### 容易混淆的邻近模型

- **过河拆桥（burning bridges）**: 书中明确澄清二者方向相反——本 skill 断自己的退路，那个毁与人的关系。
- **承诺（commitment）**: 更通用的上游模型，破釜沉舟是其最极端形态。
