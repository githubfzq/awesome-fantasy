# 习得性无助（learned helplessness）

## R — 原文 (Reading)

> "习得性无助"（learned helplessness）会让某些人在缺少帮助的情况下难以取得进步。这个概念是指，随着逐渐适应艰难处境，人们会不再试图摆脱困境。
>
> — 《思维模型》, 第1章 少犯错 > 换位思考

---

## I — 方法论骨架 (Interpretation)

塞利格曼的实验是这样的：一组狗反复遭受无法预测、无法逃避的电击。之后把它们放进一个**很容易逃脱**的箱子里——只要跳过矮闸就能避开电击。未曾受过电击的狗迅速跳出；而受过随机电击的那组，大多直接躺倒、哀鸣、等待电击结束，**根本没有尝试**。

关键在最后一个词：不是"逃不掉"，是**没有尝试**。逃脱路径是敞开的，它们放弃了。

这个"放弃"是被**学会**的。在先前的经验里，行为与结果之间没有关联——做什么都没用，于是一个预期被建立起来："我的行为不会改变结果"。这个预期一旦形成，会迁移到全新的、实际上可控的环境中。人身上是同一个机制：长期失业者不再投简历、长期被否定的学生不再举手、长期被驳回的提案不再提。

破解方式也来自实验本身：研究者必须**把狗拖过矮闸几次**，让它亲身体验到"我的动作有效果"，之后它才开始自己跳。也就是说，破解不是靠鼓励、讲道理或证明"其实你可以"，而是靠**重新建立行为与结果之间的联结**——必须让本人真实地体验到一次"我做了，事情真的变了"。

关键判据（用于区分能力问题与无助问题）：**他是做不到，还是已经不再相信自己做得到？** 若是后者，那么追加能力培训是无效的，必须先恢复"行为有效"的体验。

一个重要的边界（书中明示）：**不要因此犯下基本归因错误**——把他人的不行动归因为"他就是懒/没上进心"，而忽略了处境与习得的预期。他们多半只是需要适当的指导。

## A1 — 书中的应用 (Past Application)

### 案例: 塞利格曼的电击狗实验与"住房优先"政策
- **问题**: 作者要说明习得性无助是真实存在且可被逆转的，并把它从实验室接到现实政策上。
- **方法论的使用**: 两个对照。其一，如上：受过随机电击的狗在可逃脱的箱子里躺倒等待，未受电击的狗迅速逃出；研究者需要把它拖过矮闸几次，它才恢复主动。其二，现实中针对长期流浪者的"住房优先"（Housing First）政策——先提供公寓并配一对一社工，而不是要求他们先戒瘾、先就业、先"证明自己准备好"。犹他州实施后长期流浪汉减少了 72%，每年人均节省约 8000 美元。
- **结论**: 长期处于"做什么都没用"的处境中，人会停止尝试，即使机会出现。有效的帮助不是训导，而是先改变处境、让人重新获得"行为有效"的体验——这比让对方继续在旧处境里"努力"更有效，成本也更低。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **自己反复受挫后不想再试**: 求职被拒多次、创业失败过、投稿被拒、健身反复中断，用户说"算了，我不是这块料"。
2. **想推动他人但推不动**: 下属、孩子、伴侣、同事"怎么推都不动"，用户已经把它归因为懒或不上进。
3. **设计帮助/培训/管理机制**: 需要知道为什么"讲道理+鼓励"没用，以及什么样的设计才能真正起效。
4. **判断该坚持还是该接受**: 需要先确认——这个处境是"真的改不了"，还是"我以为改不了"。
5. **长期处于被否定环境后的自我怀疑**: 用户明明有成绩，却坚信自己不行。

### 语言信号 (用户的话里出现这些就应激活)

- "反正做了也没用"
- "我就是不行 / 我不是这块料"
- "怎么努力都一样，算了"
- "他怎么推都推不动，太懒了"
- "我已经不想试了"
- "以前也试过，没用"
- "Nothing I do makes a difference." / "Why bother?" / "I've given up on that."

### 与相邻 skill 的区分

- 与 `mm-fundamental-attribution-error` 的区别: 基本归因错误是**误把处境导致的行为归因为品性**（"他就是懒"）；习得性无助给出的是那个被忽略的**处境机制**。书中明确把两者连在一起：不要把他人的不行动归因为品性，他们多半只是需要适当的指导。
- 与 `mm-activation-energy` 的区别: 活化能处理的是**启动门槛太高**（第一步太难，所以没开始）；习得性无助处理的是**对结果的预期为零**（不是难，是认为做了也没用）。对策不同：前者降低门槛，后者重建行为—结果的联结。
- 与 `mm-fixed-mindset-versus-growth-mindset` 的区别: 固定型思维是**关于能力可否改变的信念**（"我不擅长这个"）；习得性无助是**关于行为是否有效的预期**（"我做什么都改变不了结果"）。前者靠认知重塑，后者靠真实的有效体验。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认处境是否真的不可改变**
   - 完成标准: 明确回答"这件事客观上还有可行动的空间吗？"——列出至少 2 条在当前条件下确实可做的、能改变结果的动作。
   - 判停条件: 若处境确实不可改变（已定的规则、不可逆的事实），停止本 skill，转向接受与止损（exit-strategy），不要鼓励无效尝试。
2. **区分"做不到"与"不相信自己做得到"**
   - 完成标准: 用关键判据提问并给出判断：用户/对象是能力不足，还是预期为零。若为能力不足，转向技能培养（deliberate-practice），本 skill 不主打。
3. **追溯无助是在哪一段经验里被习得的**
   - 完成标准: 找出那段"做了也没用"的具体经历（多少次尝试、间隔多久、反馈是什么），并说明这个预期如何从那里迁移到了现在这个其实不同的场景。
4. **设计一个"必定有效"的最小行动**
   - 完成标准: 该行动必须满足三条：**(i) 小到几乎不可能失败**；**(ii) 结果清晰可见**；**(iii) 在很短时间内（最好当天）能看到变化**。写明确切的行动、预期结果、观察时间。
   - 判停条件: 若找不到满足三条的行动，说明当前拆解还不够细，继续拆小，不要将就。
5. **执行并把"行为 → 结果"的因果显式指给用户看**
   - 完成标准: 结果出现后，明确指出"这个变化是你刚才那个动作带来的"——这一步不能省略，它是重建联结的核心。禁止在这一步泛泛夸奖（"你很棒"），必须绑定到具体因果。
6. **逐步加大剂量，形成连续的证据链**
   - 完成标准: 设计 3-5 次递进的行动，每次的成功概率仍然偏高（不要一次跳太大），让用户积累多条"我做了，事情变了"的证据。
7. **（若对象是他人）先改变处境，再要求行动**
   - 完成标准: 对应"住房优先"的思路：先提供能让他成功的条件（资源、支持、降低的环境阻力），再谈期望。同时避免把不行动归因为品性。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **处境真的无法改变时**: 此时需要的是接受、止损与重新定向，而不是设计"必定有效的小行动"——那会变成廉价的鼓励，第二次失效会加深无助。
- **用来给他人贴标签**: 说"他就是习得性无助"是把一个解释变成了一个诊断，会强化对方的"我不行"身份。本模型用于设计帮助，不用于评判人。
- **临床抑郁等心理健康问题**（推导, 非书中明示）: 若表现符合抑郁症等临床状况，应建议寻求专业帮助，本 skill 不能替代临床干预。

### 书中警告的失败模式 / 容易误用的地方

- **不只出现在艰难处境，日常中（公开演讲、新技术）也会出现**（书中明示）。不要以为只有极端困境才会产生习得性无助——几次公开演讲失败、几次学不会新工具，就足以让人形成"我不是这块料"的预期。
- **别因此犯下基本归因错误**（书中明示）：看到他人不行动，不要归因为"他们懒/没上进心"。他们多半只是需要适当的指导。这条明确针对的是观察者，不是当事人。
- （推导, 非书中明示）**用讲道理替代有效体验**: 告诉对方"其实你可以的"无效。实验里真正起效的是被拖过矮闸——必须让本人真实体验到行为有效，认知说服不能替代。
- （推导, 非书中明示）**第一步设计得太大**: 若"最小行动"仍有失败可能，失败会成为新的无助证据，比不做更糟。宁可小到荒谬。

### 容易混淆的邻近模型

- **基本归因错误（fundamental-attribution-error）**: 是对无助者的典型误判方式，书中明确要求避免。
- **皮格马利翁效应（pygmalion-effect）**: 是他人期望如何塑造表现（高期望→高表现）；习得性无助是自身预期如何抑制行动（零预期→不行动）。一个是外界施加，一个是内在形成。
